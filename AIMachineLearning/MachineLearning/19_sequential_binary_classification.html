02

핵심 개념

가중합 → 확률 → Class

Step 1·2의 수식 보완

z = w₁x₁ + w₂x₂ + b
p = σ(z) = 1 / (1 + e−z)

z는 Sigmoid 이전의 점수, p는 모델이 계산한 Class 1 확률이다. Class 0 확률은 1−p로 해석한다. 출력 하나로 이진 분류를 표현하는 방식이며, 모든 이진 분류 구현이 반드시 이 구조여야 한다는 뜻은 아니다.

가중합 z
→
Sigmoid 확률 p
→
p > 0.5
→
Class 1 또는 0
원문 임계값으로 판정한 보완 예시
확률 p p > 0.5 Class
0.9 True 1
0.5 False 0
0.1 False 0
원문은 >이고 >=가 아니다. 정확히 0.5이면 Class 0이다. 예측 확률 0.9869, 예측 Class 1, Test Accuracy 1.0은 서로 다른 값이다.

왜 필요한가?
이진 로지스틱 회귀의 계산 구조를 Layer로 표현한다.
입력 Shape
Sample 기준 (2,), Batch 기준 (B,2).
출력·반환값
모델 출력 Shape (B,1).
실행 후 변화
W=(2,1), b=(1,)의 구조와 초기값이 생성된다. 아직 정답으로 학습하지 않았다.
위의 주석은 원문을 보존했다. 은닉층의 Sigmoid 사용에 관한 문장은 포화·기울기 전달 문제의 맥락으로 읽고 절대적인 사용 금지로 일반화하지 않는다. 이번 모델에는 애초에 은닉층이 없다.

σ′(z) = σ(z)(1−σ(z))

Sigmoid 출력이 0이나 1에 가까워지면 미분값이 작아진다는 수식적 설명이다. 이 설명을 근거로 원본에 없는 은닉층을 있다고 해석하지 않는다.

그림처럼 이해

가중합의 Shape와 결정 경계

입력 (B,2)
→
@ W (2,1)
→
+ b (1,)
→
가중합 (B,1)
→
Sigmoid (B,1)

2 × 1 + 1 = 3 Parameters

B는 Batch의 Sample 수다. 두 Weight와 Bias 하나를 학습한다. 입력·출력 Node 수를 단순히 더해 Parameter를 세는 것이 아니라 Dense의 가중치 연결과 Bias를 계산한다.

확률의 변화

p=σ(z)는 비선형 함수다. Class 1 확률을 내보낸다.

0.5 기준의 결정 경계

p=0.5 ⇔ z=0이므로 w₁x₁+w₂x₂+b=0이다. 두 Feature 평면에서 직선 형태다.

경계식은 모델 구조에서 도출한 보완 설명이다. 원본은 학습 후 W,b를 출력하지 않으므로 실제 학습된 직선의 계수를 임의로 쓰지 않는다.

13

Loss 해석

맞힌 Class가 같아도 BCE는 다를 수 있다

Step 1·2의 Loss 수식과 계산 예시

L = −[y log(p) + (1−y) log(1−p)]

정답이 1이면 −log(p), 정답이 0이면 −log(1−p)다. 정답 Class에 더 적절한 확률을 줄수록 Loss가 작아진다. 여러 Sample에서는 손실을 집계한다.

정답 1을 가정한 보완 계산
Class 1 확률 p > 0.5 판정 BCE
0.9 정답 약 0.1054
0.6 정답 약 0.5108
0.1 오답 약 2.3026

앞의 두 경우는 Accuracy 관점에서 같지만 Loss는 다르다. 이번 직접적인 최적화 대상은 BCE이고 Accuracy는 관찰 지표다. R²는 이번 원본에서 사용하지 않는다.

θ ← θ − η∇θL

θ는 w₁,w₂,b이며 η는 실제 SGD 학습률 0.01이다. 위는 학습 업데이트를 설명하는 수식이지 원문에 직접 작성된 계산 루프가 아니다.

Sigmoid 확률과 Logit을 혼동하지 않는다. 이번 출력은 이미 Sigmoid 확률이다. Sigmoid 이전 점수를 전달하는 from_logits=True 구성과 섞지 않는다. 원본 Loss·출력층을 조용히 교체하지 않는다.

원문 설정: [S1] p.172. 보완 수식: [D4], [D6]. 표는 원본 출력이 아닌 계산 예시.

Train / Validation / Test

왜 실제 학습은 7개이고 검증은 1개인가?

원본 데이터와 Keras 분리 규칙을 적용한 보완 계산

floor(8 × (1−0.1)) = floor(7.2) = 7

학습 경계가 7이므로 앞의 7개를 학습하고 마지막 1개를 검증한다. Keras는 NumPy 배열의 마지막 부분을 셔플 전에 Validation으로 분리한다. 매 Epoch 새로운 한 점을 무작위 선택하는 것이 아니다.

실제 사용 Sample과 Class 구성
용도 X Shape y Shape Class 0 / 1
원본 Training 전체 (8,2) (8,1) 4 / 4
Weight 학습 부분 (7,2) (7,1) 4 / 3
Validation (1,2) (1,1) 0 / 1
별도 Test 배열 (2,2) (2,1) 1 / 1

Validation: [[6.0, 2.5]] → [[1.0]]
실제 검증 비율: 1/8 = 12.5%

학습 7개
→
Batch Size 1
→
7 Step / Epoch
→
1001 Epoch
→
7007번 학습 Step
분리는 fit 내부의 사용 방식이다. 원래 X_train 배열 자체가 (7,2)로 바뀌는 것은 아니다. 같은 학습 일곱 Sample을 반복하며 데이터가 7007개로 늘어나지 않는다.
