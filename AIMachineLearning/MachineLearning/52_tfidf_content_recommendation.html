TF-IDF 핵심 개념

단어 빈도와 전체 Corpus에서의 희소성을 함께 본다

TF Term Frequency

현재 Document 안에서 해당 Term이 얼마나 나타나는가?

×
IDF Inverse Document Frequency

전체 Corpus에서 해당 Term이 얼마나 흔하지 않은가?

TF-IDF = TF × IDF
중요

“많이 나온 단어 = 무조건 중요”가 아니다. 모든 영화 줄거리에 흔한 단어라면 IDF에 의해 중요도가 낮아질 수 있다.

Cosine Similarity

22,304차원 Movie Vector 사이의 방향을 비교한다

cosine(A,B) = (A · B) / (||A|| × ||B||)
1 같은 방향에 가까움
0 공유 Feature가 거의 없음
높을수록 추천 우선순위 상승
Cosine Similarity는 추천 정확도가 아니다.

예를 들어 0.449338은 “정확도 44.93%”가 아니라 두 TF-IDF Vector 사이의 유사도다.

def recommend_movie(movie_index):
    '''
    인자로 받은 인덱스(영화)의  overview와
    유사도가 가장 높은 영화 10개를 반환하는 함수
    movie_index:영화의 인덱스
    '''
    try:
        index_cosSim = list(
            enumerate(
                cos_sim[movie_index]
            )
        )

        index_cosSim_reverse = sorted(
            index_cosSim,
            key=lambda x: x[1],
            reverse=True
        )

        index_cosSim_reverse_top10 = (
            index_cosSim_reverse[1:11]
        )

        movie_top10 = [
            idx[0]
            for idx in
            index_cosSim_reverse_top10
        ]

    except Exception as e:
        print(e)

        return (
            f'{movie_index}는 존재하지 않은 영화 인덱스 입니다'
        )

    return (
        df_copy['title']
        .iloc[movie_top10]
    )

출력 문구에는 49999라고 적혀 있지만 실제 코드는 마지막 Row, 즉 Index 4999를 사용한다.

③ Recommendation Function 내부 0.99대 예시

Function 주석에는 0.997, 0.999 등의 값이 남아 있지만 현재 TF-IDF의 실제 Toy Story 최고 비자기 유사도는 약 0.449338이다.

④ “TF-IDF는 단어 빈도가 중요”

원문 설명의 핵심 취지는 맞지만, 보다 정확하게는 TF와 IDF를 함께 사용한다.

Data Leakage · Overfitting · Underfitting

Supervised Learning의 진단 용어를 상황에 맞게 적용한다

Data Leakage

현재 Catalog 전체를 TF-IDF로 Fit하여 Item-to-Item Similarity를 만드는 현재 목적에서는 이를 곧바로 Leakage라고 부르지 않는다.

단, 별도 평가 문제라면 Train에서 Fit하고 Validation/Test에는 Transform만 해야 한다.

Overfitting

Train Loss와 Validation Metric이 없으므로 현재 Notebook에서 일반적인 Overfitting 여부를 직접 판단할 수 없다.

Underfitting

추천 결과가 마음에 들지 않는다고 곧바로 Underfitting이라고 부를 수 없다.

Learning Rate

Gradient Update가 없으므로 이번 TF-IDF Pipeline에는 Learning Rate가 없다.

6개다.

954개다.
