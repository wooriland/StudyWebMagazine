Step 3 완성

01 · PROBLEM DEFINITION

실습 목표와 문제 정의

이번 실습의 목표는 영어 문장을 입력받아 한국어 문장을 생성하는 Sequence-to-Sequence 모델을 구현하는 것입니다.

왜 Seq2Seq를 배우는가?

앞에서 공부한 감성 분석은 문장 전체를 읽고 긍정 또는 부정처럼 하나의 결과를 출력했습니다. 하지만 기계번역은 입력도 문장이고 출력도 문장입니다. 입력과 출력의 길이가 반드시 같을 필요도 없습니다.

이전 학습 — Many-to-One

"이 영화 정말 재미있다" ↓ RNN / LSTM ↓ 긍정

여러 단어를 읽고 하나의 결과를 분류합니다.

이번 학습 — Many-to-Many

"Return immediately" ↓ Encoder → Decoder ↓ "빨리 와"

시퀀스를 읽고 새로운 시퀀스를 생성합니다.

핵심 문제

영어 문장 전체를 어떻게 수치 데이터로 변환하고, Encoder의 상태에 담은 뒤, Decoder가 그 정보를 활용하여 한국어 단어를 순서대로 생성하게 할 것인가?

실습을 통해 구현하는 기능

  • 영어-한국어 병렬 말뭉치를 읽는다.
  • 문장을 정제하고 단어 사전을 만든다.
  • 문장을 정수 ID와 Embedding Vector로 변환한다.
  • Encoder와 Decoder LSTM을 구성한다.
  • Teacher Forcing으로 번역 모델을 학습한다.
  • 새 영어 문장을 입력받아 한국어 문장을 생성한다.
  • Loss, Accuracy와 실제 번역 품질을 비교한다.

03 · DATA SHAPE

X / y 구조와 Tensor Shape

일반적인 분류 모델에서는 하나의 X와 하나의 y를 사용합니다. Seq2Seq에서는 Decoder 자체에도 입력이 필요하므로 학습 데이터의 흐름이 세 개로 나뉩니다.

Encoder Input

encoder_in_pad (1000, 10) 영어 입력 시퀀스

Decoder Input

decoder_in_pad (1000, 10) SOS + 이전 정답

Decoder Target

decoder_out_pad (1000, 10) 다음 정답 + EOS

Teacher Forcing을 위한 시퀀스 이동

원래 문장 <SOS> 나는 학생이다 <EOS>
Decoder Input <SOS> 나는 학생이다
Decoder Target 나는 학생이다 <EOS>

설명용 가상 문장입니다. 원본 첫 데이터의 실제 Decoder Input은 <SOS> 가, Target은 가 <EOS>입니다.

Shape 전체 흐름

Input (B, 10) 정수 토큰
→
Embedding (B, 10, 128) 밀집 벡터
→
Encoder (B, 256) × 2 h와 c
→
Decoder (B, 10, 1947) 단어 확률
처리 단계 Shape 축의 의미
전체 정수 시퀀스 (1000, 10) 문장 수 × Timestep
Batch Input (B, 10) 배치 크기 × Timestep
Encoder Embedding (B, 10, 128) 배치 × 시점 × 임베딩
Encoder Hidden State (B, 256) 배치 × Units
Encoder Cell State (B, 256) 배치 × Units
Decoder Embedding (B, 10, 128) 배치 × 시점 × 임베딩
Decoder LSTM (B, 10, 256) 배치 × 시점 × Units
Softmax Output (B, 10, 1947) 배치 × 시점 × Vocabulary
Decoder Target (B, 10) 각 시점의 정답 토큰 ID
Shape 해석에서 가장 중요한 차이

10은 시퀀스의 최대 길이입니다. 128은 단어 하나의 Embedding Dimension입니다. 256은 LSTM의 Hidden/Cell State 차원입니다. 1947은 Vocabulary Size입니다.

B는 배치 크기입니다. 1,000개 샘플을 Batch Size 32로 묶으면 대부분의 배치는 32개이고 마지막 배치는 8개입니다. 중간 계층 Shape은 원본 모델 설정을 통해 해석한 것입니다.

04 · PREPROCESSING

전처리 — 문장을 숫자로 변환하기

신경망은 문자열을 그대로 계산하지 않습니다. 영어와 한국어 문장을 먼저 정제하고, 단어 사전을 만든 뒤 정수 ID로 변환해야 합니다.

1

한국어 문장 정제

사용자 정의 함수인 preprocess_korean()을 사용합니다. 원본 저장 결과에는 가.가 가로, 안녕.이 안녕으로 정제된 결과가 나타납니다.

2

SOS / EOS 추가

한국어 정답 앞에 시작 토큰, 뒤에 종료 토큰을 추가합니다.

<SOS> 가 <EOS>
3

Decoder Input / Target 분리

Input에서는 마지막 EOS를 제거하고, Target에서는 첫 SOS를 제거하여 한 칸 이동한 두 시퀀스를 구성합니다.

4

영어 구두점 제거

정규식 re.sub()으로 영어 문장의 구두점을 제거합니다. 예를 들어 Go.가 Go가 됩니다.

5

공통 단어 사전 생성

Encoder Input, Decoder Input, Decoder Target의 문자열을 합쳐 하나의 단어 사전을 만듭니다. 원본의 Vocabulary Size는 1,947입니다.

6

Integer Encoding / Padding

모든 단어를 정수 Token ID로 변환한 뒤 최대 길이 10에 맞춰 Padding합니다.

06 · MODEL ARCHITECTURE

Encoder–Decoder LSTM

원본은 Keras의 Model Subclassing 방식으로 Encoder, Decoder, Seq2Seq 클래스를 정의합니다.

ENCODER — 입력 문장 이해

English Token IDs (B, 10)
↓
Embedding (B, 10, 128)
↓
Dropout 0.2 학습 시 적용
↓
Encoder LSTM 256 Units
↓
Hidden State h (B, 256)
Cell State c (B, 256)

DECODER — 번역 문장 생성

Decoder Token IDs (B, 10)
↓
Embedding (B, 10, 128)
↓
Dropout 0.2 학습 시 적용
↓
Decoder LSTM 256 Units · initial_state=[h,c]
↓
Dense + Softmax (B, 10, 1947)
Encoder의 최종 h, c → Decoder의 initial_state

LSTM의 상태 이해

상태 설명 Shape
Hidden State 현재 시점의 출력·전달 상태 (B, 256)
Cell State 장기 정보를 유지하는 내부 상태 (B, 256)

return_sequences와 return_state

설정 역할
return_state=True 최종 Hidden State와 Cell State 반환
return_sequences=True 모든 timestep의 출력 시퀀스 반환

Seq2Seq의 기본 원리

Encoder의 상태 계산

Encoder(X) → (h, c)

Decoder의 단어 생성

Decoder(이전 단어, h, c) → 다음 단어

전체 번역 확률

P(Y|X) = ∏ P(yₜ | y₁,...,yₜ₋₁,X)

기본 Seq2Seq의 한계

Encoder는 긴 입력 문장의 정보를 마지막 상태 h, c에 압축해야 합니다. 길고 복잡한 문장에서는 정보가 손실될 수 있습니다. 이런 고정 크기 상태의 병목을 보완하기 위해 다음 단원에서 Attention을 사용합니다.

② Encoder LSTM 클래스 
class Encoder(tf.keras.Model):

    def __init__(self, units, vocab_size, embedding_dim):
        super(Encoder, self).__init__()

        self.embedding = keras.layers.Embedding(
            vocab_size,
            embedding_dim
        )

        self.dropout = keras.layers.Dropout(0.2)

        self.lstm = keras.layers.LSTM(
            units,
            return_state=True
        )

    def call(self, inputs, training=None):

        x = self.embedding(inputs)

        x = self.dropout(x, training=training)

        _, hidden_state, cell_state = self.lstm(x)

        return [hidden_state, cell_state]
입력: (B,10)
Embedding: (B,10,128)
출력: h와 c 각각 (B,256)
역할: 입력 문장을 상태 벡터로 표현합니다.
③ Decoder LSTM 클래스 
class Decoder(tf.keras.Model):

    def __init__(self, units, vocab_size, embedding_dim):
        super(Decoder, self).__init__()

        self.embedding = keras.layers.Embedding(
            vocab_size,
            embedding_dim
        )

        self.dropout = keras.layers.Dropout(0.2)

        self.lstm = keras.layers.LSTM(
            units,
            return_sequences=True,
            return_state=True
        )

        self.dense = keras.layers.Dense(
            vocab_size,
            activation='softmax'
        )

    def call(self, inputs, initial_state, training=None):

        x = self.embedding(inputs)

        x = self.dropout(x, training=training)

        x, hidden_state, cell_state = self.lstm(
            x,
            initial_state=initial_state
        )

        x = self.dense(x)

        return x, hidden_state, cell_state
입력: Decoder 토큰과 Encoder의 h,c
LSTM 출력: (B,10,256)
Softmax 출력: (B,10,1947)
역할: 각 timestep에서 다음 단어의 확률을 계산합니다.
④ Seq2Seq 학습과 추론

학습에서는 정답 시퀀스 전체를 Decoder에 전달합니다. 추론에서는 SOS부터 시작해 자신이 예측한 단어를 다음 입력으로 사용합니다.

학습 분기 — 원본 Cell 044 발췌 
if training:

    context_vector = self.encoder(
        inputs['enc_inputs']
    )

    decoder_outputs, _, _ = self.decoder(
        inputs=inputs['dec_inputs'],
        initial_state=context_vector

추론 분기 — 원본 Cell 044 발췌 
context_vector = self.encoder(inputs)

target_seq = np.array(
    [[self.start_token]],
    dtype=np.float32
)

results = []

for i in range(self.time_steps):

    decoder_output, decoder_hidden, decoder_cell = self.decoder(
        target_seq,
        initial_state=context_vector
    )

    decoder_output = np.argmax(
        decoder_output,
        axis=-1
    ).astype(np.int32)

    results.append(decoder_output)

    if np.array(decoder_output).item() == self.end_token:
        break

    target_seq = decoder_output

    context_vector = [
        decoder_hidden,
        decoder_cell
    ]

return np.array(results).reshape(
    (1, len(results), 1)
)

def predict_preprocessing(
    sentence,
    is_will_delete_stopword=False
):

    if not is_will_delete_stopword:
        sentence = word_tokenizer.preprocess_korean(
            sentence,
            True
        )

    encoding_vector = word_tokenizer.make_integer_encoding(
        sentence
    )

    return encoding_vector


def predict(model, question_inputs):

    results = model(
        inputs=question_inputs,
        training=False
    )

    return results.flatten()


def translation(question):

    question_inputs = predict_preprocessing(
        [question]
    )

    results = predict(
        seq2seq,
        question_inputs
    )

    results = index_to_word(
        results,
        EOS_TOKEN,
        tokenizer
    )

    return results

10 · LOSS / ACCURACY

Metric 해석

Sparse Categorical Crossentropy

Decoder는 각 timestep에서 1,947개 단어에 대한 확률을 계산합니다. 정답 Token ID에 해당하는 확률이 높아질수록 손실은 작아집니다.

Token Loss = -log(P(정답 단어))
정답 확률 0.9 Loss ≈ 0.105
정답 확률 0.5 Loss ≈ 0.693
정답 확률 0.1 Loss ≈ 2.303

위 확률은 Crossentropy 수식 설명용 예시이며 원본의 개별 토큰 예측 출력이 아닙니다.

Metric의 차이

Metric 측정 내용 원본 사용
Training Loss 정답 Token ID에 대한 예측 손실 사용
Token Accuracy 토큰 위치별 정답 일치율 사용
Validation Loss 미학습 데이터의 손실 미구현

한 문장이 하나의 단어로 구성되어 있어도 최대 길이가 10이면 Padding으로 나머지 위치가 채워집니다. Padding까지 정답 예측에 포함되면 실제 의미 있는 단어의 정확도와 평가 결과가 달라질 수 있습니다.

11 · COMMON MISTAKES

자주 하는 실수

01. Timestep과 Embedding Dimension을 혼동한다.

(1000,10)의 10은 문장의 최대 시퀀스 길이입니다. 단어 하나의 임베딩 차원은 128입니다. 둘은 다른 축을 의미합니다.

02. Decoder Input과 Target을 동일하게 만든다.

Input은 SOS로 시작하고 Target은 EOS로 끝나야 합니다. 한 timestep 이동된 관계를 유지해야 다음 단어를 예측할 수 있습니다.

03. Hidden State와 Cell State를 혼동한다.

LSTM은 h와 c 두 상태를 사용합니다. 원본 Decoder는 Encoder가 계산한 두 상태를 initial_state로 전달받습니다.

04. 정수 Token ID와 Embedding Vector를 혼동한다.

Token ID는 단어 번호인 정수입니다. Embedding은 단어를 표현하는 실수 벡터입니다. 원본 추론 시작 토큰의 float32 dtype은 점검 대상입니다.

05. EOS와 Padding을 같은 의미로 생각한다.

EOS는 생성 종료를 학습하는 특수 토큰입니다. Padding은 배열 길이를 맞추기 위한 값입니다. 두 토큰을 구분해야 합니다.

06. Validation 없이 Overfitting 여부를 판단한다.

학습 Loss가 낮아졌다는 것만으로 일반화 성능을 알 수 없습니다. Train과 Validation Loss를 비교해야 합니다.

07. 영어와 한국어 전처리를 혼용한다.

원본의 추론 코드에서는 영어 입력에 한국어 전처리 함수를 호출합니다. 학습과 추론의 영어 전처리 규칙을 확인해야 합니다.

08. 학습 Accuracy를 번역 정확도로 해석한다.

Token Accuracy와 문장 단위 의미 정확도는 다릅니다. 특히 Padding과 Teacher Forcing이 평가 결과에 영향을 줄 수 있습니다.

09. 학습과 추론의 반환 Shape 차이를 무시한다.

원본의 학습 분기는 확률 Tensor, 추론 분기는 생성 토큰 배열을 반환합니다. 일반적인 evaluate()와 배치 추론에 적용하려면 출력 계약을 점검해야 합니다.

10. Learning Rate만 변경하면 해결된다고 생각한다.

Loss가 감소하지 않는 원인은 학습률뿐 아니라 잘못된 전처리, 데이터 부족, Shape 불일치, Padding, 모델 구현에도 있을 수 있습니다.

15 · INTERVIEW / REVIEW

면접 포인트와 복습 질문

질문을 펼치기 전에 스스로 답해 보세요. 이 단원의 핵심은 단순 용어 암기가 아니라 코드의 입력, 출력, Shape, 학습 이유를 함께 설명할 수 있는지입니다.

Q01. Seq2Seq란 무엇입니까?

입력 시퀀스를 처리하여 새로운 출력 시퀀스를 생성하는 모델 구조입니다. 기계번역과 같은 Many-to-Many 문제에 활용합니다.

Q02. Encoder와 Decoder의 역할은 무엇입니까?

Encoder는 입력 문장을 상태 벡터로 표현하고, Decoder는 그 상태를 이용해 출력 문장을 생성합니다.

Q03. LSTM의 Hidden State와 Cell State는 무엇입니까?

Hidden State는 현재 시점의 출력·전달 상태이고, Cell State는 장기 정보를 유지하는 내부 상태입니다.

Q04. Encoder에서 return_state=True를 사용하는 이유는?

마지막 Hidden State와 Cell State를 받아 Decoder 초기 상태로 전달하기 위해서입니다.

Q05. Decoder의 return_sequences=True는 왜 필요합니까?

각 timestep에서 단어를 예측해야 하므로 모든 시점의 출력이 필요하기 때문입니다.

Q06. Teacher Forcing이란 무엇입니까?

학습 시 이전 예측값 대신 실제 정답 단어를 Decoder의 다음 입력으로 제공하는 방식입니다.

Q07. 학습과 추론의 Decoder 입력은 어떻게 다릅니까?

학습에서는 이전 정답 단어를 사용하고, 추론에서는 이전에 생성한 예측 단어를 사용합니다.

Q08. SOS, EOS, PAD의 차이는 무엇입니까?

SOS는 시작 토큰, EOS는 문장 생성 종료 토큰, PAD는 길이를 맞추기 위한 토큰입니다.

Q09. (1000,10)에서 10은 무엇입니까?

최대 Timestep입니다. Embedding Dimension 128과 구분해야 합니다.

Q10. Decoder 출력이 (B,10,1947)인 이유는?

B개 문장의 10개 시점마다 1,947개 단어의 확률을 계산하기 때문입니다.

Q11. Sparse Categorical Crossentropy를 사용하는 이유는?

정답을 One-Hot Vector가 아닌 정수 Token ID로 표현하기 때문입니다.

Q12. Greedy Decoding이란 무엇입니까?

각 시점에서 가장 확률이 높은 단어 하나를 선택하는 방식입니다. 전체 문장 확률의 최적 해를 보장하지는 않습니다.

Q13. Accuracy 0.8877은 어떤 의미입니까?

원본 학습 로그의 토큰 위치 정확도입니다. 독립 테스트의 번역 품질을 뜻하지 않습니다.

Q14. Data Leakage는 어떻게 예방합니까?

데이터를 먼저 분할하고, Tokenizer와 학습 가능한 전처리 요소는 Train 데이터만으로 학습해야 합니다.

Q15. Padding Mask가 필요한 이유는?

의미 없는 Padding 위치가 LSTM 상태와 Loss/Accuracy에 부정적인 영향을 주지 않도록 하기 위해서입니다.

Q16. Overfitting과 Underfitting을 어떻게 판단합니까?

Training Loss와 Validation Loss를 비교합니다. 원본에는 Validation 기록이 없어 과적합을 확정하기 어렵습니다.

Q17. 원본에 evaluate()를 바로 추가하면 어떤 문제가 있습니까?

원본 call()이 학습에서는 확률 Tensor를 반환하지만 추론에서는 정수 Token ID를 반환합니다. 따라서 일반적인 Keras 평가 함수와 출력 형식이 맞지 않을 수 있습니다.

Q18. 다음 단원에서 Attention을 배우는 이유는?

Encoder 마지막 상태에 전체 문장을 압축하는 정보 병목을 줄이고, Decoder가 필요한 입력 시점의 정보를 선택적으로 참조할 수 있게 하기 위해서입니다.
