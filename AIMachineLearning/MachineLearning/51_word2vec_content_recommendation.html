Text Preprocessing

Stopword·Punctuation을 제거하고 Lowercase로 통일한다

preprocess() 

def preprocess(text):

    tokens = word_tokenize(
        text
    )

    stop_words = set(
        stopwords.words(
            'english'
        )
    )

    punctuations = set(
        string.punctuation
    )

    filtered = [
        word.lower()
        for word in tokens

        if word.lower()
            not in stop_words

        and word
            not in punctuations
    ]

    return filtered

def get_sentence_vector(
    tokens,
    model
):

    sentence_vectors = [
        model.wv[word]
        for word in tokens
        if word in model.wv
    ]

    if len(
        sentence_vectors
    ) == 0:

        return np.zeros(
            model.vector_size
        )

    return np.mean(
        sentence_vectors,
        axis=0
    )

Cosine Similarity

Vector 크기보다 방향의 유사성을 비교한다

cosine(A,B) = (A · B) / (||A|| × ||B||)
1 매우 비슷한 방향
0 직교에 가까움
-1 반대 방향

이번 추천에서는 Similarity가 클수록 해당 영화를 앞 순위로 배치한다.

Similarity ≠ Accuracy

0.99의 Similarity는 추천 정확도 99%라는 뜻이 아니다.

def recommend_movie(movie_index):

    try:

        index_cosSim = list(
            enumerate(
                cos_sim[
                    movie_index
                ]
            )
        )

        index_cosSim_reverse = sorted(
            index_cosSim,
            key=lambda x: x[1],
            reverse=True
        )

        index_cosSim_reverse_top10 = (
            index_cosSim_reverse[
                1:11
            ]
        )

        movie_top10 = [
            idx[0]
            for idx
            in index_cosSim_reverse_top10
        ]

    except Exception as e:

        print(e)

        return (
            f'{movie_index}는 존재하지 않은 '
            '영화 인덱스 입니다'
        )

    return (
        df_copy['title']
        .iloc[movie_top10]
    )

다음 단원의 핵심 비교

Word2Vec은 단어의 문맥 관계를 학습하지만, TF-IDF는 한 단어가 특정 문서에서 얼마나 중요한지를 빈도 기반으로 계산한다.

Overview → Token → Word2Vec → Word Vector → Movie Vector → Cosine Similarity → Ranking → Recommendation 구조를 이해하면 자연어 Embedding을 실제 콘텐츠 기반 추천 시스템으로 연결하는 전체 Pipeline을 이해한 것이다.
