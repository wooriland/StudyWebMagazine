Model Architecture

Embedding → LSTM → BN → Dense → Dropout → Sigmoid

원문 실행문 발췌 

def create_model():
    model = keras.Sequential()

    model.add(keras.layers.Input(shape=(word_tokenizer.time_steps,)))

    model.add(
        keras.layers.Embedding(
            input_dim=word_tokenizer.voca_size,
            output_dim=64
        )
    )

    model.add(keras.layers.LSTM(units=64))
    model.add(keras.layers.BatchNormalization())

    model.add(
        keras.layers.Dense(
            units=128,
            activation='relu',
            kernel_initializer='he_normal',
            kernel_regularizer=keras.regularizers.l2(0.01)
        )
    )

    model.add(keras.layers.Dropout(0.5))
    model.add(keras.layers.Dense(1,activation='sigmoid'))

    model.compile(
        optimizer='adam',
        loss='binary_crossentropy',
        metrics=['acc']
    )

    return model

Embedding

정수 Token 56개를 64차원 Vector Sequence로 바꾼다

Input (B,56)
→
Embedding (B,56,64)

4286 × 64 = 274,304 Parameters

Model 외부에서는 2차원 정수 배열 `(B,56)`을 넣는다. LSTM이 실제 받는 입력은 Embedding이 만든 3차원 실수 Tensor `(B,56,64)`다.
17

LSTM

길이 56의 Sequence를 하나의 64차원 표현으로 요약한다

LSTM Input (B,56,64)
→
LSTM Output (B,64)

`return_sequences=True`를 사용하지 않았으므로 모든 Timestep 출력을 반환하지 않고 마지막 Sequence Representation만 다음 Layer로 전달한다.

4 × (64×64 + 64² + 64) = 33,024 Parameters

def predict_naver_review(sentence):
    '''
    리뷰 예측용 함수
    sentence : 사용자 리뷰
    '''

    sentence = word_tokenizer.preprocess_korean(sentence,True)

    encoding_vector= word_tokenizer.make_integer_encoding(sentence)

    y_pred = model.predict(encoding_vector)

    return (y_pred[0] > 0.5).astype(dtype=np.float32)
