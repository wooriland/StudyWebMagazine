01핵심 개념 · 특징 추출 능력을 재사용하기

음식 사진 한 장을 치즈케이크·도넛·감자튀김·아이스크림·타코야키 중 하나로 분류합니다. 이미지마다 하나의 정답을 선택하는 단일 레이블 다중 클래스 분류입니다.

왜 전이학습을 하나요?

큰 CNN을 처음부터 학습하려면 많은 이미지와 계산이 필요합니다. 다른 데이터에서 배운 경계·질감·형태의 특징을 가져오면 새 문제를 학습하는 출발점으로 활용할 수 있습니다.

이번 단원에서 학습하는 부분

ResNet50의 특징 추출 부분은 고정하고 새 Dense 분류층만 음식 데이터로 학습합니다. 기반 모델까지 다시 학습하는 미세조정은 원본에 없습니다.

용어와 실제 설정
개념 의미 이번 코드
사전학습 다른 데이터로 미리 학습 ImageNet 가중치
전이학습 배운 특징을 새 문제에 활용 음식 5종 분류
Top 제거 기존 분류 부분 제외 include_top=False
Freeze 가중치 업데이트 제외 base_model.trainable=False
Fine-tuning 기반 모델도 추가 학습 원본에서는 하지 않음
Inference 학습된 모델로 예측 계산 model.predict(...)

ResNet을 그림처럼 이해

입력 x ─────────────────────┐
   └─ 여러 층의 연산 F(x) ──┤
                            ↓
                        F(x) + x

입력 경로를 더하는 잔차 연결이 핵심입니다. 더할 때 Shape가 달라지면 입력 경로에도 변환이 필요합니다. 이번 실습은 잔차 블록을 직접 구현하지 않고 이미 구현·학습된 ResNet50을 사용합니다.

구조와 학습 여부는 별개입니다. include_top=False만으로 가중치가 고정되지 않습니다. trainable=False만으로 기존 1,000클래스 분류층이 없어지지도 않습니다.

온라인 증강은 배치를 읽을 때 변형합니다. 원본 파일을 자동으로 추가 저장하지 않으며 원본 이미지 수는 그대로입니다. 증강 강도가 클수록 항상 좋은 것은 아닙니다.

RGB → BGR → 평균 차감

원본 RGB 픽셀:  [10, 20, 30]
BGR 순서 변경: [30, 20, 10]
채널 평균 차감: [103.939, 116.779, 123.680]
결과:          [-73.939, -96.779, -113.680]

음수 값은 정상입니다. float32 변환과 0~1 스케일 변환은 다릅니다. 이번 ResNet50 전처리는 RGB→BGR·평균 차감이며 ResNet50V2의 −1~1 전처리와 구분합니다. 이 함수는 Resize나 배치 축 추가를 하지 않습니다.

② 기반 모델을 고정하고 음식 분류층 연결

원문 활성 코드 · 셀 15~16

def create_model():
    base_model = ResNet50(
        include_top=False,
        input_shape=(IMAGE_HEIGHT, IMAGE_WIDTH, IMAGE_CHANNEL)
    )

    base_model.trainable = False

    custom_model = Flatten()(base_model.output)

    custom_model = Dense(
        units=128,
        activation='relu',
        kernel_initializer='he_normal'
    )(custom_model)

    custom_model = Dense(
        units=256,
        activation='relu',
        kernel_initializer='he_normal'
    )(custom_model)

    custom_model = Dropout(0.3)(custom_model)

    output = Dense(
        IMAGE_CLASS,
        activation='softmax'
    )(custom_model)

    print(f'base_model.input:{base_model.input}')

    return tf.keras.models.Model(
        inputs=base_model.input,
        outputs=output
    )
model = create_model()
model.summary()
무엇·왜?
ImageNet 특징을 이용하는 음식 5종 모델을 구성합니다.
입력 Shape
(B,224,224,3)
출력 Shape
(B,5)
실행 후 변화
새 Dense 가중치가 초기화되고 model이 새 모델로 바뀝니다. 아직 음식 데이터로 학습하지 않았습니다.

Dense(...)(custom_model)은 층을 만든 후 이전 출력 텐서에 연결하는 함수형 API 문법입니다. He 초기화는 ReLU를 사용하는 새 Dense층에 적용합니다.

고정은 계산 생략이 아닙니다. 기반 모델은 계속 특징을 계산하지만 가중치를 업데이트하지 않습니다. 고정된 기반 모델 내부 BatchNormalization의 이동 통계도 유지됩니다. 새 분류층의 Dropout은 fit에서 작동하고 predict/evaluate에서는 꺼집니다.

두 번째 model 생성 셀을 건너뛰면 기존 (B,1000) 모델을 사용할 수 있습니다. 레이블 0~4는 1,000클래스에서도 범위상 유효하므로 즉시 오류가 나지 않을 수 있습니다.

07그림처럼 이해 · Shape와 파라미터

  1. Image(B,224,224,3)
  2. ResNet50 · 고정(B,7,7,2048)
  3. Flatten(B,100352)
  4. Dense 128 · ReLU(B,128)
  5. Dense 256 · ReLU(B,256)
  6. Dropout 0.3(B,256)
  7. Dense 5 · Softmax(B,5)
  8. Argmax · axis=1(B,)

ResNet50 내부에는 합성곱·정규화·활성화·잔차 연결 등의 연산이 들어 있습니다. 이 블록의 결과가 특징 맵입니다. 7×7×2048=100352이며 Flatten은 배치 축을 유지한 채 나머지 축을 펼칩니다.

Loss · Sparse Crossentropy

정답 클래스 확률 p에 대해 한 샘플의 손실은 −log(p)입니다. sparse 정답은 클래스 번호입니다. 원핫 정답이면 손실 함수 구성도 맞춰야 합니다.

Adam · Accuracy

Adam은 Loss를 줄이도록 가중치를 업데이트합니다. 원문은 학습률을 지정하지 않았고 공식 기본값은 0.001입니다. acc는 선택한 클래스와 정답의 일치 비율입니다.

정답 확률과 한 샘플의 Loss
정답 확률 −log(p) 해석
0.9 약 0.105 정답에 높은 확률
0.5 약 0.693 정답 확신이 낮아짐
0.2 약 1.609 5클래스 균등 확률
0.01 약 4.605 정답에 매우 낮은 확률

Loss는 오답률이 아니고 1을 넘을 수 있습니다. Softmax 출력을 사용하므로 logits용 손실 설정을 임의로 섞지 않습니다. 같은 정답 판정이라도 확률 차이는 Loss에 반영되지만 Accuracy에는 정답 한 건으로 반영됩니다.

R²는 왜 사용하지 않나요?

회귀의 R²는 1 − 오차제곱합 / 평균 기준 제곱합입니다. 정답 값이 변하는 일반적인 회귀에서 1은 완벽한 예측, 0은 평균 예측 수준이며 음수도 가능합니다. 음식 번호 0~4에는 크기·거리의 의미가 없어 이 분류 성능을 R²로 평가하지 않습니다. 필요하면 Accuracy에 클래스별 Precision·Recall·F1·혼동행렬을 보완합니다.

    → 관련 이미지 그룹 단위로 Train / Val / Test 분리
    → Train에만 학습용 무작위 증강

같은 원본의 변형·연속 촬영 장면이 분할 사이에 섞이면 완전히 새로운 이미지에 대한 성능을 과대평가할 수 있습니다. 테스트 점수를 반복해서 보며 설정을 고르는 것도 테스트 정보를 모델 선택에 사용하는 것입니다.

정상적인 일관성

학습·평가에 같은 고정 전처리를 적용합니다. ImageNet의 고정 평균을 사용하는 것 자체는 현재 테스트 데이터의 정보를 학습에 유출하는 행위가 아닙니다.

20면접 포인트 · 질문으로 다시 설명하기

Q1. 이번 실습에서 전이한 것은 무엇인가요?

ImageNet으로 학습된 ResNet50의 특징 추출 부분과 가중치입니다. 음식 분류층은 새로 초기화하고 학습합니다.

Q2. include_top=False와 trainable=False의 차이는?

전자는 기존 분류 구조 제거, 후자는 가중치 업데이트 제외입니다. 서로 대체할 수 없습니다.

Q3. Freeze했는데 왜 계산 시간이 걸리나요?

매 이미지의 특징을 계산하는 순전파는 필요합니다. 새 분류층의 학습도 계속 진행합니다.

Q4. 왜 학습·예측 전처리를 같게 하나요?

모델이 학습한 채널·값 범위의 규칙을 유지하기 위해서입니다. 이번 전처리에 /255를 임의로 추가하지 않습니다.

Q5. Sparse 정답인데 출력이 5개인 이유는?

정답은 번호 하나로 표현하지만 모델은 다섯 후보의 확률을 계산합니다. y는 (B,), 예측은 (B,5)입니다.

Q6. Softmax와 Argmax는 어떻게 다른가요?

Softmax는 확률 분포를 만들고 Argmax는 가장 큰 값의 인덱스를 선택합니다. 배치별 선택은 axis=1입니다.

Q7. Flatten에는 가중치가 없는데 왜 모델이 커지나요?

펼친 100,352개 값을 Dense 128에 연결하면서 약 1,284만 개의 가중치·편향이 생기기 때문입니다.

Q8. Dropout은 노드 수나 Shape를 줄이나요?

아닙니다. 학습 중 일부 활성값을 무작위로 0으로 만들며 Shape와 노드 수는 유지합니다.

Q9. 79.84%와 97.47%는 각각 무엇인가요?

전자는 저장된 학습 Accuracy, 후자는 한 타코야키 이미지의 예측 확률입니다. 둘 다 독립 테스트 정확도는 아닙니다.

Q10. Loss가 줄면 과적합이 없나요?

아닙니다. 검증 Loss가 함께 어떻게 변하는지 봐야 합니다. 원본은 검증 기록이 없습니다.

Q11. fit·evaluate·predict의 차이는?

fit은 가중치 학습, evaluate는 정답과 비교한 지표 계산, predict는 입력의 예측값 계산입니다.

Q12. 음식 5종에 decode_predictions를 쓰지 않는 이유는?

그 함수는 ImageNet 1,000클래스 매핑용입니다. 이번에는 학습 폴더의 클래스 매핑을 사용합니다.

Q13. 미세조정할 때 주의할 점은?

기반 모델의 학습 대상을 변경한 뒤 재컴파일하고 작은 학습률·검증 자료·BatchNormalization 동작을 점검합니다.

Q14. seed=42면 완전히 같은 결과인가요?

그 설정 하나가 초기 가중치·Dropout·모든 연산의 동일성을 보장하지 않습니다. 전체 실행 환경과 난수 상태를 함께 관리합니다.

Q15. 증강 후 무작위 분할하면 왜 위험한가요?

같은 원본의 변형이 학습·테스트에 나뉘면 모델이 이미 본 장면으로 평가받을 수 있습니다.

Q16. 분류 번호 0~4에 R²를 쓰면 안 되나요?

번호에는 연속적인 크기·거리 의미가 없습니다. 분류 지표로 평가하고 R²는 회귀 맥락에서 해석합니다.
