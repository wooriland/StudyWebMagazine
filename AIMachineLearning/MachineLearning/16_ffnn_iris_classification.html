AI Machine Learning PART 2. 퍼셉트론과 FFNN ML 16

FFNN · Iris · Tabular Data · Sparse Label · Softmax

FFNN으로 붓꽃 종류 분류하기

4개의 수치 Feature를 가진 Iris Tabular Dataset을 이용하여 3-Class Multiclass Classification을 수행한다. 데이터를 Train/Test로 분리하고, 4 → 64(ReLU) → 16(ReLU) → 3(Softmax) 구조의 FFNN을 학습한다. 정수 Label을 One-Hot으로 변환하지 않고 Sparse Categorical Crossentropy를 사용하는 구조를 이해하며, 작은 Dataset에서 Validation과 Test Metric이 크게 흔들릴 수 있다는 점까지 확인한다.

이번 단원의 핵심 Pipeline

Iris Dataset → 4 Numeric Features → Train/Test Split → Dense 64 → ReLU → Dense 16 → ReLU → Dense 3 → Softmax → Class 0 / 1 / 2
(batch,4) → (batch,64) → (batch,16) → (batch,3)

학습 목표

  • Iris Dataset이 이미지가 아닌 Tabular Numeric Dataset임을 설명할 수 있다.
  • X_train.shape=(120,4)의 의미를 설명할 수 있다.
  • test_size, stratify, random_state의 역할을 설명할 수 있다.
  • 이번 Notebook에 Flatten, Scaling, One-Hot Encoding이 없는 이유를 설명할 수 있다.
  • 4 → 64 → 16 → 3 Model Architecture와 Shape 흐름을 설명할 수 있다.
  • 각 Dense Layer의 Parameter 수를 직접 계산할 수 있다.
  • Integer Label과 Sparse Categorical Crossentropy의 관계를 설명할 수 있다.
  • Softmax가 3개 Class Probability를 출력한다는 것을 설명할 수 있다.
  • batch_size=1이 실제 학습 흐름에 미치는 의미를 설명할 수 있다.
  • Validation Sample 24개와 Test Sample 30개에서 Accuracy가 크게 흔들릴 수 있는 이유를 설명할 수 있다.
  • 원본 코드 주석과 현재 저장 Output을 구분할 수 있다.
  • 원본 Notebook에 predict()가 존재하지 않는다는 것을 구분할 수 있다.

Error Reading

오류 메시지 읽는 법

주의

아래는 원본 Notebook에 저장된 Exception이 아니라, 동일 코드를 변경하거나 확장할 때 만날 수 있는 대표 오류다.

1. Input Shape Error

expected shape=(None, 4)
found shape=(None, 3)

Model은 4 Feature를 기대하는데 실제 입력 Feature가 3개인 상황이다.

2. Matrix Dimension Error

(batch,4) @ (4,64)

행렬곱의 연결 Dimension이 맞는지 확인한다.

3. dtype Error

X가 문자열이나 object dtype이 아니라 Numeric Tensor/Array인지 확인한다.

4. Label / Loss 불일치

Sparse Categorical Crossentropy를 사용할 때 Target이 Integer Class 형태인지 확인한다.

5. NaN Loss

NaN/Inf 입력, Learning Rate, 잘못된 전처리, 수치 불안정 등을 확인한다.

Q1. Iris Dataset은 이미지 데이터입니까?

아닙니다. 4개의 수치 Feature를 가진 Tabular Dataset입니다. 원본 Notebook 제목의 이미지 분석 표현과 실제 데이터 형태를 구분해야 합니다.

Q2. X_train.shape=(120,4)은 무엇을 의미합니까?

120개의 Training Sample이 있고 각 Sample마다 4개의 Feature가 있다는 뜻입니다.

Q3. 왜 Flatten이 필요 없습니까?

Sample 하나가 처음부터 `(4,)`의 1차원 Feature Vector이기 때문입니다.

Q4. stratify=y는 무엇입니까?

Train/Test Split에서 Class 비율을 비슷하게 유지하도록 하는 옵션입니다.

Q5. random_state=42는 무엇을 고정합니까?

train_test_split의 분할 Randomness를 고정합니다. TensorFlow Weight 초기화까지 자동으로 고정하는 것은 아닙니다.

Q6. 이번 Model Architecture는 무엇입니까?

4 → 64(ReLU) → 16(ReLU) → 3(Softmax)입니다.

Q7. 첫 번째 Dense Parameter가 왜 320개입니까?

4×64개의 Weight와 64개의 Bias를 합쳐 320개입니다.

Q8. 두 번째 Dense Parameter가 왜 1,040개입니까?

64×16개의 Weight와 16개의 Bias를 합쳐 1,040개입니다.

Q9. Output Parameter가 왜 51개입니까?

16×3 Weight와 3 Bias를 합쳐 51개입니다.

Q10. 전체 Parameter 수는 얼마입니까?

총 1,411개이며 모두 Trainable Parameter입니다.

Q11. 왜 Sparse Categorical Crossentropy를 사용합니까?

Target이 One-Hot이 아니라 0,1,2 Integer Class Label이기 때문입니다.

Q12. Optimizer와 Learning Rate는 무엇입니까?

Adam Optimizer이며 Learning Rate는 0.001입니다.

Q13. batch_size=1은 어떤 의미입니까?

한 Sample씩 Forward/Backward Propagation을 수행하고 Parameter를 업데이트한다는 뜻입니다.

Q14. 왜 Epoch당 96 Step입니까?

Train 120개 중 Validation 20%를 제외하면 실제 Training Sample이 96개이고, Batch Size가 1이기 때문입니다.

Q15. Validation Accuracy 100%를 그대로 믿으면 안 되는 이유는 무엇입니까?

Validation Sample이 24개밖에 없어 몇 개 Prediction 변화만으로 Accuracy가 크게 바뀔 수 있기 때문입니다.

Q16. 현재 저장된 Test Accuracy는 얼마입니까?

약 0.7333, 즉 약 73.33%입니다.

Q17. 원본 주석과 실제 평가 결과가 어떻게 다릅니까?

원본 주석에는 약 98% Accuracy와 10,000 Test Sample 관련 문구가 남아 있지만, 실제 Iris Test는 30개이며 저장 Accuracy는 약 73.33%입니다.

Q18. 이번 원본 Notebook에는 predict()가 있습니까?

없습니다. 원본은 evaluate와 Train/Validation Curve 시각화까지 수행합니다.
