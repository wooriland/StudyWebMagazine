Metric 해석

Box와 Pose를 같은 하나의 정확도로 합치지 않는다

Metric Box Pose
Precision 0.959 0.912
Recall 0.857 0.857
mAP50 0.943 0.875
mAP50-95 0.752 0.487
Box mAP ≠ Pose mAP
mAP ≠ Classification Accuracy
Pose Metric ≠ R²

Keypoint가 숫자 좌표라는 이유만으로 일반 회귀 지표인 R²를 이번 Pose 평가에 사용하지 않는다.

25

Data Leakage

이번 Notebook에서는 새 Split을 만들지 않는다
