Keypoint 좌표 위치.

kobj_loss

Keypoint 존재·신뢰 관련.

cls_loss

객체 Class.

dfl_loss

Bounding Box 위치 분포.

사람 위치 학습
+

+
관절 위치 학습
+

15

Batch·Epoch

Train 이미지가 4장이라 한 Epoch는 1 Batch다

Train Images = 4
Batch Size = 16
4 < 16

Training Log = 1 / 1 per Epoch
1 Batch / Epoch × 100 Epoch = 약 100 Training Batch 진행
Instances 열은 Dataset 사람 수가 아니다.

Training 로그의 Instances는 20, 16, 15, 7 등 Epoch마다 달라진다. Augmentation 결과와 Batch 상태가 반영되므로 이를 원본 Dataset 사람 수로 읽지 않는다.

Box(P R mAP50 mAP50-95)

Pose Metric

사람의 Keypoint 위치 품질.

Pose(P R mAP50 mAP50-95)
중요

사람 Box를 정확히 찾았더라도 팔꿈치·손목·무릎 같은 Keypoint 좌표는 부정확할 수 있다.

Accuracy ≠ Pose mAP
R² ≠ Pose Metric
Training Loss ≠ Validation Metric
19

Data Leakage · Overfitting · Underfitting

작은 Dataset에서 성능 변화를 조심해서 해석한다

Overfitting 점검

사전학습 모델의 높은 초기 성능
↓
Training 4장
↓
100 Epoch Fine-tuning
↓
Validation Pose Metric 급락

과적합이나 지나친 Fine-tuning, 사전학습 Representation 손상 등을 점검할 강한 신호다.

원인을 하나로 단정하지 않는다.

Validation도 4장뿐이라 Metric 변동성이 매우 클 수 있다.

Underfitting 점검

이번 모델은 처음부터 높은 Validation 결과를 보이므로 명확한 초기 Underfitting이었다고 볼 근거는 부족하다.

Data Leakage 점검

원문만으로 실제 중복 이미지가 있었는지 확인할 수 없다. 따라서 누수가 있었다고 단정하지 않는다.

점검 대상 질문
동일 이미지 Train·Val에 중복되었는가?
연속 영상 Frame 거의 같은 장면이 양쪽에 나뉘었는가?
증강 이미지 원본과 변형본이 서로 다른 Split에 있는가?
사람·장면 동일 촬영 세션이 Train·Val 양쪽에 있는가?

xy와 xyn의 차이

xy는 Pixel 기반 좌표, xyn은 이미지 크기로 정규화한 좌표다.

Q1. Object Detection과 Pose Estimation의 차이는?
Object Detection은 객체 Class와 Bounding Box를 찾고, Pose Estimation은 객체 내부의 신체 Keypoint 위치까지 찾는다.
Q2. 이번에 사용하는 모델은?
yolo11s-pose.pt 사전학습 Pose Model이다.
Q3. Dataset은 무엇인가?
coco8-pose.yaml을 사용한다.
Q4. Train과 Validation 이미지는 몇 장인가?
각각 4장이다.
Q5. Class는 몇 개인가?
person 한 Class다.
Q6. kpt_shape=[17,3]은?
17개 Keypoint와 Keypoint당 3개 차원을 의미한다.
Q7. Label의 세 번째 차원은?
YAML 주석 기준 visibility다.
Q8. Predict data의 세 번째 차원은?
Keypoint Confidence다.
Q9. flip_idx는 왜 필요한가?
좌우 반전 시 Left·Right Keypoint 의미를 올바르게 교환하기 위해 필요하다.
Q10. 어떤 Loss를 사용하는가?
box_loss, pose_loss, kobj_loss, cls_loss, dfl_loss가 로그에 나타난다.
Q11. 실제 Optimizer는?
자동 선택된 AdamW다.
Q12. 실제 초기 Learning Rate는?
원본 자동 선택 로그 기준 0.002다.
Q13. Epoch는 몇 번인가?
100 Epoch를 실행한다.
Q14. Epoch 100이 최적인가?
아니다. best.pt의 Validation 결과가 훨씬 좋다.
Q15. best Epoch 번호는?
원본에는 정확한 번호가 명시되지 않아 확정하지 않는다.
Q16. Box mAP와 Pose mAP 차이는?
Box는 사람 위치 탐지, Pose는 Keypoint 위치 품질을 평가한다.
Q17. Predict 결과는 몇 명인가?
저장 출력 기준 3 persons다.
Q18. Model Input Shape는?
(1,3,416,640)이다.
Q19. Keypoint Shape는?
(3,17,3)이다.
Q20. xy와 xyn 차이는?
xy는 Pixel 좌표, xyn은 원본 이미지 크기로 정규화한 좌표다.
Q21. conf=0.5와 keypoints.conf는 같은가?
아니다. 객체 Detection Threshold와 개별 Keypoint Confidence다.
Q22. show_boxes=False는 Object Detection 중지인가?
아니다. Box 렌더링을 숨기는 설정이다.
Q23. results[0].keypoints의 타입은?
원본 저장 출력 기준 Keypoints 객체다.

없다. YAML의 test 항목은 비어 있다.
