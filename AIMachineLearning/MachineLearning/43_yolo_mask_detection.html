LETTERBOX · BGR / RGB

04. 전처리와 색상 채널

원문은 이미지 경로를 전달합니다. 이미지 읽기, 비율을 고려한 크기 조정과 패딩, 채널·축 순서 및 모델 입력 자료형 처리는 Ultralytics 내부에서 진행됩니다.

imgsz=640이라고 모든 추론 Tensor가 640×640인 것은 아닙니다. 조건에 따라 최소 직사각형 패딩이 적용되며 이번 로그는 640×544입니다. 실제 Shape는 로그로 확인합니다.

입력·표시 형식
대상 일반적인 형식 주의
OpenCV / NumPy 이미지 HWC · BGR · uint8 · 0~255 직접 Tensor로 넣는 형식과 다름
모델용 Tensor BCHW · RGB · 부동소수점 직접 만들 때 값 범위와 축을 확인
Matplotlib / PIL 표시 RGB BGR을 그대로 표시하면 색상 해석이 바뀜

픽셀 채널 변환

[B, G, R] → [R, G, B]

image[:, :, ::-1]은 H와 W를 유지하고 마지막 채널 축만 뒤집습니다.

크기가 같아도 의미는 다름

BGR과 RGB 모두 Shape는 (H, W, 3)입니다. Shape 검사만으로 채널 오류를 찾을 수 없습니다.

NumPy 반전 축
코드 변화 Shape
image[::-1, :, :] 상하 반전 · 높이 축 유지
image[:, ::-1, :] 좌우 반전 · 너비 축 유지
image[:, :, ::-1] 채널 순서 반전 유지

이 표는 HWC 배열 기준입니다. figsize=(10,10)은 표시 Figure 크기이며 픽셀 크기나 모델 입력 Shape를 바꾸지 않습니다. 그림 파일의 렌더링 크기도 모델 Shape와 다릅니다.

EVALUATION · DATA LEAKAGE

05. Train / Validation / Test

이번 Notebook은 새로운 분할을 만들지 않습니다. model.val()은 기존 Validation을 평가하며, 새 사진 한 장의 예측은 정답과 비교한 Test 지표를 만들지 않습니다.

데이터 분할의 역할
분할 목적 이번 단원
Train 가중치 학습 이전 ML 42에서 사용
Validation 모델·설정 선택과 검증 154장·711객체 평가
Test 확정 조건의 독립적인 최종 평가 원문에서 별도로 실행하지 않음

같은 원본·유사 사진·연속 프레임이 학습과 평가에 걸쳐 있으면 성능이 과대평가될 수 있습니다. Test 결과를 반복 보며 모델이나 conf를 고르면 Test도 설정 선택에 관여합니다. 가중치를 로드한다고 이런 누수가 자동으로 해결되지는 않습니다.

보충 코드 · 실제 YAML 파일과 분할이 존재할 때

metrics = model.val(data="mask_config.yaml", split="val")
test_metrics = model.val(data="mask_config.yaml", split="test")

함수 이름은 둘 다 val()이지만 평가할 분할은 split으로 구분합니다. Test는 검증에서 선택한 조건을 고정한 뒤 사용합니다. 이 코드는 원문에서 실행된 코드가 아닙니다.

06. Model Architecture — 학습된 YOLO11s

이번에는 CNN 층을 직접 조립하지 않습니다. 학습한 마스크 3클래스 체크포인트를 YOLO(...)로 불러옵니다. 파일 이름이 best.pt라고 항상 같은 모델은 아니므로 model.names도 확인합니다.

  1. 입력 이미지
  2. Backbone 특징 추출
  3. Neck 특징 결합
  4. Detection Head
  5. Confidence·NMS
  6. 좌표 복원·Results

위 흐름은 이해를 위한 개념도입니다. 이미지 전체를 하나로 분류하는 Flatten → Dense → 클래스 하나의 흐름과 달리, 여러 객체의 위치와 클래스를 함께 예측합니다.

10. Metric과 Loss 해석

지표의 질문과 의미
항목 정의·해석
Confidence 개별 탐지 점수. 전체 Accuracy도, 검증된 보정 확률도 아님
IoU 두 박스의 교집합 면적 / 합집합 면적
Precision TP / (TP + FP) · 찾았다고 한 것 중 정답
Recall TP / (TP + FN) · 정답 객체 중 찾아낸 것
F1 2PR / (P + R) · 같은 평가 조건의 P와 R의 조화평균
AP / mAP 한 클래스의 Precision–Recall 관계 요약 / 클래스 평균
mAP50 / mAP75 정답 매칭 IoU 0.50 / 0.75에서의 mAP
mAP50-95 IoU 0.50~0.95를 0.05 간격으로 평가하여 평균
Accuracy / R² 이번 원문의 탐지 평가 지표가 아님. 이미지 정답률·회귀 설명력과 구분

TP는 클래스와 위치 조건을 만족해 매칭된 탐지, FP는 정답으로 인정되지 않은 탐지, FN은 놓친 정답 객체입니다. 하나의 정답에 여러 박스를 그렸다고 모두 TP가 되지 않습니다. 전체 요약 P/R을 711에 곱해 정확한 객체 개수를 역산하지 않습니다.

NMS IoU

예측 박스끼리의 중복을 처리하는 기준입니다.

평가 IoU

예측 박스와 정답 박스가 충분히 일치하는지 판단하는 기준입니다.

metrics.box.maps는 클래스별 AP50-95 배열이고 metrics.names로 대응을 확인합니다. 객체에는 P–R, F1–Confidence, P–Confidence, R–Confidence 곡선 정보도 있습니다. 긴 배열을 이미지나 모델 가중치로 오해하지 않습니다. confusion_matrix 객체가 존재한다는 것과 원문에서 그 행렬을 실제 표시했다는 것은 다릅니다.

Loss와 Optimizer — 이전 학습과의 연결
항목 역할 이번 실행
box_loss 박스 위치·크기 학습 학습 곡선을 새로 생성하지 않음
cls_loss 클래스 학습 학습 곡선을 새로 생성하지 않음
dfl_loss 박스 경계 회귀의 분포 표현 학습 학습 곡선을 새로 생성하지 않음
Optimizer / Learning Rate 학습의 가중치 갱신 방식·크기 이번 val/predict에서 새로 설정·업데이트하지 않음
0.0ms loss는 시간입니다. 손실 값이 0이거나 완벽한 예측이라는 뜻이 아닙니다. Loss는 학습 최적화의 척도이고 mAP는 탐지 결과를 평가하는 지표입니다. mAP50-95=0.631을 “사진 정답률 63.1%”라고 부르지 않습니다.

비교 실험은 데이터·모델·임계값·입력 크기·장치를 기록하고 한 번에 바꾸는 요인을 제한합니다. 검증에서 조건을 고른 뒤 독립 Test로 평가합니다.

15. 면접 포인트와 복습 질문

질문을 눌러 답을 확인합니다. 먼저 자신의 말로 설명해 보세요.

이 Notebook에서 새로 학습하나요?

아닙니다. 체크포인트 로드·검증·추론·결과 활용이 중심입니다.

val과 predict의 차이는?

val은 정답과 비교해 지표를 계산하고 predict는 새 이미지의 탐지 결과를 만듭니다.

best.pt만 있으면 검증 가능한가요?

검증 이미지·정답 라벨·설정에도 접근할 수 있어야 합니다.

객체 탐지의 y는 무엇인가요?

이미지마다 개수가 다른 객체의 클래스와 박스 정보입니다.

results[0]은 무엇인가요?

첫 번째 이미지의 Results입니다. 첫 번째 객체가 아닙니다.

(1, 3, 640, 544)의 의미는?

배치 1, 채널 3, 높이 640, 너비 544의 BCHW입니다.

plot과 모델 입력의 Shape가 다른 이유는?

모델에는 전처리된 Tensor를 넣고 plot은 원본 좌표계의 시각화 배열을 반환합니다.

BGR을 RGB로 바꾸는 이유는?

OpenCV 계열 배열과 Matplotlib의 채널 해석 순서가 다르기 때문입니다.

image[:, :, ::-1]은 좌우 반전인가요?

HWC에서 채널 반전입니다. 좌우 반전은 image[:, ::-1, :]입니다.

conf=.7은 정확도 70%인가요?

아닙니다. 개별 탐지를 결과에 남길 최소 점수 기준입니다.

Confidence와 mAP는 어떻게 다른가요?

개별 탐지 점수와 정답이 있는 데이터셋의 평가 지표라는 차이가 있습니다.

mAP50과 mAP50-95는?

IoU 0.50만의 평가와 0.50~0.95 여러 기준을 평균한 평가입니다.

NMS IoU와 평가 IoU는?

예측끼리 중복 처리하는 기준과 예측·정답을 매칭하는 기준입니다.

to_json은 파일을 저장하나요?

문자열을 반환합니다. 저장하려면 파일 쓰기가 필요합니다.

두 박스가 보이면 정확도 100%인가요?

정답과 위치·클래스를 비교하지 않았으므로 그렇게 평가할 수 없습니다.

이번 결과로 과적합을 확정할 수 있나요?

학습·검증·독립 Test와 학습 기록이 더 필요합니다.

추론 오류를 Learning Rate로 고치나요?

추론은 학습 업데이트가 없습니다. 입력·모델·임계값·도메인부터 점검합니다.

0.0ms loss는 무엇인가요?

처리 시간입니다. 손실 값 0이 아닙니다.

R²를 사용하지 않는 이유는?

R²는 연속값 회귀의 설명력 지표이며 이번 탐지 평가에 사용하지 않습니다.

마스크 탐지에는 result.masks를 쓰나요?

이번은 착용 상태를 박스로 찾는 탐지이므로 boxes를 다룹니다.
