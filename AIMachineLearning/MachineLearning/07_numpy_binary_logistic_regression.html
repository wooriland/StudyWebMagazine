NumPy 이진 로지스틱 회귀

이번 단원은 Linear Regression에서 Binary Classification으로 넘어가는 중요한 전환점입니다. NumPy만 사용하여 z = XW + b의 선형 Score를 만들고, Sigmoid로 0~1 Probability로 변환한 뒤, Binary Cross Entropy를 계산하고, 직접 Gradient를 구해 Weight와 Bias를 갱신합니다. 마지막에는 0.5 Threshold를 적용해 Class 0 또는 Class 1을 결정합니다.

X → XW+b → Sigmoid → Probability → BCE → Gradient → Update → Class

학습 목표

  • Binary Classification 문제에서 Logistic Regression이 왜 필요한지 설명할 수 있다.
  • X_train=(8,2), y_train=(8,1)의 의미를 설명할 수 있다.
  • Weight W=(2,)와 Bias Scalar의 역할을 이해할 수 있다.
  • z = X @ W + b의 Shape 흐름을 설명할 수 있다.
  • Sigmoid가 선형 Score를 Probability로 바꾸는 원리를 설명할 수 있다.
  • (8,)과 (8,1)의 차이를 NumPy Broadcasting 관점에서 설명할 수 있다.
  • Binary Cross Entropy Loss를 코드와 수식으로 이해할 수 있다.
  • p-y가 Gradient 계산에 등장하는 이유를 이해할 수 있다.
  • Full-Batch Gradient Descent로 W와 b를 직접 갱신할 수 있다.
  • Decision Boundary와 Threshold 0.5의 관계를 설명할 수 있다.
  • Probability와 Class를 구분할 수 있다.
  • Accuracy 100%를 Dataset 크기와 함께 해석할 수 있다.

13

Training Loop

원본 학습 코드 전체 흐름

losses = []

for epoch in range(epochs + 1):

    # 1. Linear Score
    z = X_train @ W + b

    # 2. Probability
    y_pred = sigmoid(
        z
    ).reshape(-1,1)

    # 3. Binary Cross Entropy
    loss = -np.mean(
        y_train
        * np.log(
            y_pred + 1e-8
        )
        +
        (1 - y_train)
        * np.log(
            1 - y_pred + 1e-8
        )
    )

    losses.append(
        loss
    )

    # 4. Gradient
    dW = np.mean(
        (y_pred - y_train)
        * X_train,
        axis=0
    )

    db = np.mean(
        y_pred - y_train
    )

    # 5. Parameter Update
    W -= learning_rate * dW
    b -= learning_rate * db

    # 6. Log
    if epoch % 100 == 0:
        print(
            f"Epoch {epoch:4d}: "
            f"Loss = {loss:.4f}, "
            f"W = {W}, "
            f"b = {b:.4f}"
        )
Forward → Probability → Loss → Gradient → Update → Repeat

Common Mistakes

자주 하는 실수

1. Logistic Regression을 연속값 예측 회귀로 생각한다

이름과 달리 최종 목적은 Classification입니다.

2. z=XW+b 자체가 Probability라고 생각한다

Sigmoid를 통과해야 0~1 Probability가 됩니다.

3. Sigmoid Output을 Class라고 생각한다

Sigmoid Output은 Probability이고 Threshold 이후가 Class입니다.

4. BCE와 MSE를 같은 Loss라고 생각한다

이번 Binary Classification은 BCE를 사용합니다.

5. (8,)과 (8,1)을 같은 Shape이라고 생각한다

NumPy Broadcasting 결과가 달라집니다.

6. reshape를 불필요한 문법이라고 생각한다

Gradient 계산을 올바르게 유지하는 핵심입니다.

7. ravel()과 reshape(-1,1)을 같은 용도로 사용한다

서로 반대 방향의 Shape 변환입니다.

8. epochs=1000이면 Loop가 1000회라고 생각한다

원본은 range(epochs+1)이므로 1001회입니다.

9. Accuracy 100%를 일반화 성능으로 해석한다

Test Sample이 2개뿐입니다.

10. 빈 Cell의 Output 2에 의미를 붙인다

검토 메모상 이전 실행 Output이 남은 것으로 보고 임의 해석하지 않습니다.

Interview

면접 포인트

Q1. Logistic Regression은 왜 Classification 모델인가요?

선형 Score를 Sigmoid로 Probability로 변환한 뒤 Threshold를 적용하여 Class를 결정하기 때문입니다.

Q2. Sigmoid의 역할은 무엇인가요?

임의의 실수 z를 0~1 범위로 변환하여 Class 1 Probability처럼 해석할 수 있게 합니다.

Q3. X_train.shape=(8,2)는 무엇을 의미하나요?

Training Sample 8개와 Feature 2개를 의미합니다.

Q4. W.shape=(2,)인 이유는 무엇인가요?

Feature 2개 각각에 대응하는 Weight가 하나씩 필요하기 때문입니다.

Q5. 왜 y_pred를 (8,1)로 reshape하나요?

y_train=(8,1)과 올바르게 Error를 계산하고 X_train과 Broadcasting하여 Gradient를 만들기 위해서입니다.

Q6. Binary Cross Entropy는 무엇인가요?

Binary Label과 Model Probability 차이를 확률 관점에서 평가하는 Loss입니다.

Q7. BCE에서 1e-8을 더하는 이유는?

log(0)을 피하고 Numerical Stability를 확보하기 위해서입니다.

Q8. Sigmoid와 BCE를 함께 쓰면 Gradient가 어떻게 되나요?

Linear Score z에 대한 Gradient가 p-y 형태로 간단하게 정리됩니다.

Q9. 이번 Optimizer는 무엇인가요?

별도의 객체 없이 직접 구현한 Full-Batch Gradient Descent입니다.

Q10. Decision Boundary는 왜 z=0인가요?

Sigmoid에서 σ(0)=0.5이고, 이번 Threshold가 0.5이기 때문입니다.

Q11. Probability와 Class는 무엇이 다른가요?

Probability는 0~1의 연속값이고, Class는 Threshold 이후의 0 또는 1 값입니다.

Q12. Accuracy 100%면 완벽한 Model인가요?

아닙니다. 이번 Test Dataset은 Sample이 2개뿐이므로 일반화 성능 100%라고 판단할 수 없습니다.

Q13. Full-Batch Gradient Descent란?

한 번의 Parameter Update를 위해 전체 Training Sample의 Gradient를 사용하는 방식입니다.

Q14. compile()이나 fit()이 왜 없나요?

NumPy로 Forward, Loss, Gradient, Update 과정을 직접 작성했기 때문입니다.
