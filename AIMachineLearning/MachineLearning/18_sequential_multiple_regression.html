그림처럼 이해

3 → 10 → 10 → 1의 Shape 흐름

Input
3 Features
(B,3)
→
Hidden 1
10 · ReLU
(B,10)
→
Hidden 2
10 · ReLU
(B,10)
→
Output
1 · Linear
(B,1)

H₁ = ReLU(XW₁ + b₁)
H₂ = ReLU(H₁W₂ + b₂)
ŷ = H₂W₃ + b₃

B는 Batch의 Sample 수다. Dense는 Feature 차원을 바꾸고 Sample 축은 유지한다. 이 구성에서 ReLU는 값을 변환하지만 Shape는 유지한다. 마지막 층의 Linear 여부만으로 전체 함수의 선형성을 판단하지 않는다.

행렬곱·Bias·활성화의 연결
단계 가중합 활성화 후 Shape
Hidden 1(B,3) @ (3,10) + (10,)ReLU → (B,10)
Hidden 2(B,10) @ (10,10) + (10,)ReLU → (B,10)
Output(B,10) @ (10,1) + (1,)Linear → (B,1)

θ는 세 Layer의 Weight와 Bias를 포함한다. 이 식은 SGD 업데이트의 보완 표현이다. 원본은 1e-6을 택한 이유나 최적값을 입증하는 비교 실험을 제공하지 않는다. 학습률 숫자만으로 속도·안정성을 확정하지 않는다.

Loss / Metric

MSE·MAE와 Accuracy·R²를 혼동하지 않는다

MSE · 학습 Loss

mean((y − ŷ)²)

오차의 제곱 평균이다. Target 단위의 제곱이며 큰 오차에 더 큰 영향을 받는다.

MAE · 관찰 Metric

mean(|y − ŷ|)

절대 오차의 평균이다. Target과 같은 단위로 읽지만 이번 원본은 Target 단위를 설명하지 않는다.

이번 최적화 목적은 MSE다. MAE를 Metric으로 지정했다고 두 목적 함수를 동시에 최적화하는 것은 아니다. 원본은 Accuracy도 R²도 설정하지 않는다.

Test MAE 1.4381을 ‘정확도’나 원·점·시간으로 임의 변환하지 않는다. 해당 Test Set에서 Target 값 기준 평균 절대 오차가 약 1.4381 이라는 범위로 읽는다.

# 보완 코드: 원본 fit() 이후 실행. 모델을 다시 학습하지 않는다.
from sklearn.metrics import r2_score

pred_2d = model.predict(X_test, verbose=0)
y_true = np.asarray(y_test)

if y_true.ndim != 1:
    raise ValueError(f"정답 Shape를 확인하세요: {y_true.shape}")

expected_shape = (y_true.shape[0], 1)
if pred_2d.shape != expected_shape:
    raise ValueError(
        f"예측 Shape가 예상과 다릅니다: {pred_2d.shape}, "
        f"예상={expected_shape}"
    )

pred_all = pred_2d.ravel()
if y_true.shape != pred_all.shape:
    raise ValueError(
        f"정답/예측 Shape 불일치: {y_true.shape}, {pred_all.shape}"
    )

if not np.isfinite(y_true).all() or not np.isfinite(pred_all).all():
    raise ValueError("정답 또는 예측값에 NaN/Inf가 있습니다.")

print("전체 예측값:", pred_all)
if y_true.size < 2 or np.all(y_true == y_true[0]):
    print("R²는 Sample 수 또는 Target 변동 조건을 확인해야 합니다.")
else:
    print("추가 계산한 R²:", r2_score(y_true, pred_all))

실무 연결

모델을 쓰기 전에 입력과 결과의 의미를 고정한다

Feature 계약

같은 수치 세 개라도 순서·단위가 다르면 다른 입력이다. Training과 Prediction에서 같은 의미를 유지한다. 현재 원본의 누락된 이름을 임의로 채우지 않는다.

Metric 해석

MAE는 Target 단위의 오차다. 단위가 없으면 약 1.4381이라는 수치 범위로만 해석한다. 회귀 결과를 ‘정확도 몇 %’로 바꾸지 않는다.

모델 상태와 재현성

새 모델인지 추가 fit 상태인지, 어느 데이터와 설정으로 학습했는지 기록한다. 분할 Seed가 모델 초기화·학습 순서까지 모두 고정하지는 않는다.

동일 조건 비교

같은 데이터 분리·Metric·평가 기준으로 선형 기준 모델과 은닉층 모델을 비교한다. 주석의 결론과 저장된 증거를 구분한다.

면접 포인트와 자기 점검

질문에 먼저 답한 뒤 펼쳐 확인한다.

Q1. 다중 회귀의 다중은 무엇인가?

입력 Feature가 여러 개라는 뜻이다. 이번은 세 입력으로 연속값 하나를 예측한다.

Q2. dataset=(25,4)에서 왜 X는 (25,3)인가?

마지막 열을 정답으로 분리하고 앞의 세 열만 사용하기 때문이다.

Q3. X_train과 y_train Shape는?

(20,3)과 (20,)이다. 전체 25개 중 Test 20%를 제외한 값이다.

Q4. Validation은 있는가?

원본 fit에 validation_split·validation_data가 없으므로 별도 Validation은 없다.

Q5. 실제로 실행한 모델은 선형 모델인가?

주석의 선형 모델이 아니라 ReLU 은닉층 두 개를 가진 3→10→10→1 회귀 모델이다.

Q6. 출력층 Linear와 모델 전체 선형성은 같은가?

다르다. 은닉층에 ReLU가 있으므로 전체는 비선형 관계를 표현할 수 있다.

Q7. Parameter 161개는 어떻게 계산하는가?

(3×10+10)+(10×10+10)+(10×1+1)=40+110+11이다.

Q8. get_weights 목록이 여섯 개인 이유는?

세 Dense의 Weight와 Bias가 [W1,b1,W2,b2,W3,b3]로 들어가기 때문이다.

Q9. Optimizer와 학습률은?

SGD 객체를 만들고 learning_rate=1e-6, 즉 0.000001을 지정한다.

Q10. 이번 Loss와 Metric은?

MSE를 줄이도록 학습하고 MAE를 관찰한다. Accuracy와 R²는 원본에 없다.

Q11. 20/20과 1000 Epoch은 무엇인가?

Training 20개를 Batch 1로 처리하므로 한 Epoch에 20 Step이다. 같은 Training을 1000회 반복한다.

Q12. History 반환과 history 변수는?

fit은 History를 반환하지만 원본은 history 변수에 대입하지 않았다.

Q13. Test 평가값 두 개는?

저장값은 MSE 약 5.6013, MAE 약 1.4381이다. 두 번째 값이 Accuracy는 아니다.

Q14. evaluate의 1/1은?

Test 5개를 기본 평가 Batch 크기 32에서 한 Batch로 처리한 결과다. 학습 업데이트 횟수가 아니다.

Q15. 단일 Prediction Shape는?

X_test[0]은 (3,), 바깥 배열을 추가한 입력은 (1,3), 결과는 (1,1)이다.

Q16. 저장 Prediction과 실제값은?

172.48648과 172.0이다. 두 값으로 계산한 절대 오차는 약 0.48648이다.

Q17. R²가 얼마인가?

원본은 계산하지 않았다. 전체 Test 정답과 전체 Prediction으로 별도 계산해야 한다.

Q18. 은닉층이 더 좋다는 결론은 입증되어 있는가?

원문에 그런 주석이 있지만 동일 조건의 선형 모델 결과가 함께 저장되지 않아 개선 폭까지 확인할 수 없다.
