B는 현재 Sample 수다. Input(shape=(28,28))의 shape는 Sample 하나의 규격이고, None은 Batch 크기 미고정이라는 뜻이다. 원문은 Channel 축을 추가하지 않으므로 입력을 (N,28,28,1)로 바꾸어 설명하지 않는다.

def create_model():

    #1.입력층을 정의
    inputs=keras.Input(shape=(28,28),name='InputLayer')
    #2. Flatten층
    flatten=keras.layers.Flatten(name='FlattenLayer')(inputs)

    #4.두번째 은닉층
    hidden2 = keras.layers.Dense(units=64,activation='relu',kernel_initializer='he_normal',name='HiddenLayer2')(hidden1)
    #5.출력층
    #<<숫자 분류용 출력 텐서>>
    outputs_1 = keras.layers.Dense(10,activation='softmax',name='OutputLayer1')(hidden2)
    #<<짝/홀수 분류용  출력 텐서 >>
    #입력층+출력층 으로 구성된 신경망 모델이다(짝/홀수 분류 정확도:0.86)
    # outputs_2 = keras.layers.Dense(1,activation='sigmoid',name='OutputLayer2')(flatten)#Flatten층의 출력값을 입력값으로
    #입력층+은닉층1+은닉층2+출력층 으로 구성된 신경망 모델이다(정확도:0.987)
    #은닉층이 많을수록 데이타의 특징을 더 잘 추출한다
    #단,은닉층이 깊어지면 모델이 복잡해지고 학습해야할 파라미터가 증가해서 학습속도가 느려지고
    #과적합에 빠질 위험이다
    outputs_2 = keras.layers.Dense(1,activation='sigmoid',name='OutputLayer2')(hidden2)#은닉층2의 출력값을 입력값으로

    #모델객체 생성
    #다중 출력으로 모델 구성 outputs=[KerasTensor1,KerasTensor2,...]
    #다중 입력으로 구성시는 inputs=[KerasTensor1,KerasTensor2,...]으로 구성 한다
    model=keras.Model(inputs=inputs,outputs=[outputs_1,outputs_2])
    return model

Loss·공유 Gradient

두 손실의 가중합으로 공동 학습한다

Step 1·2의 수식·계산·해석

Lnumber = −(1/B)∑i∑k=0…9 yi,k log pi,k
Leven/odd = −(1/B)∑i[ ti log qi + (1−ti) log(1−qi)]

숫자 정답이 2라면 그 Sample의 손실은 −log(p₂)로 읽는다. 짝홀에서 q는 짝수일 확률이다. 짝수 정답 t=1이면 −log(q), 홀수 정답 t=0이면 −log(1−q)가 핵심이다.

두 출력 모두 모델 안에 Softmax·Sigmoid가 있으므로 이전 Logit 실습의 from_logits=True 구성을 그대로 옮기지 않는다.

Ltotal = Lnumber + 0.5 × Leven/odd

첫 Epoch의 표시값을 대입하면 0.2632 + 0.5 × 0.1438 = 0.3351로, 저장 Training 전체 Loss와 같다.

가중치 0.5가 뜻하지 않는 것
오해 구분
짝홀 Sample 절반만 사용 전체 손실에 계수를 곱한다.
확률·Accuracy를 절반으로 표시 출력값·Metric 자체를 나누는 설정이 아니다.
짝홀 학습률을 0.0005로 지정 Adam 학습률은 별도의 0.001이다.
가중치 합 1.5로 다시 나누기 원문은 가중합이다.
Parameter 이동량이 언제나 절반 Adam의 갱신은 단순 비례 이동으로 단정하지 않는다.

∇θsLtotal = ∇θsLnumber + 0.5∇θsLeven/odd

θs는 공유 Parameter다. 공유 은닉층은 두 손실의 영향을 함께 받는다. 숫자 출력층은 숫자 손실 경로, 짝홀 출력층은 가중치가 적용된 짝홀 손실 경로에 연결된다. 독립 학습한 두 모델을 마지막에 합친 것과 다르다.

Step 1·2의 Metric 해석·계산

원문의 acc는 정답·출력 Shape에 맞는 정확도 방식으로 연결된다. 숫자 출력은 Categorical Accuracy, 짝홀 출력은 Binary Accuracy로 읽는다. Binary Accuracy의 기본 임계값은 0.5다.

숫자 Accuracy = 숫자 Class를 맞힌 수 / N
짝홀 Accuracy = 짝·홀수 Label을 맞힌 수 / N

Test 10,000개에 대한 계산
과제 저장 정확도 맞힌 수 틀린 수
숫자 약 97.40% 9,740개 260개
짝·홀수 약 98.69% 9,869개 131개

개수는 저장 정확도에서 환산한 것이며 원본이 오분류 이미지 목록을 추출한 것은 아니다. Loss는 정답 확률의 크기를 반영하고 Accuracy는 최종 Class의 일치를 센다. 전체 Loss 0.1396을 오분류율 13.96%로 읽지 않는다.

두 과제를 동시에 맞힌 비율은 원본에 없다. 두 정확도를 평균·곱으로 합쳐 정확한 동시 정답률이라고 부를 수 없다. 두 오류가 겹치는 Sample 정보가 필요하다.

R²는 회귀 지표다. 이번 숫자 번호는 Class Index이므로 번호 차이를 회귀 오차처럼 계산하지 않는다. 원문에 R²는 없다.
