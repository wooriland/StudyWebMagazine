Bounding Box
Object

Segmentation Mask
Object

실제 객체 영역에 가까운 Pixel 영역.

Box ≠ Mask

Object 1 (N₁,2)

dtype

Float Polygon 좌표를 int32 Pixel 좌표로 변환한다

YOLO 출력 Float 81.211, 119.86
→

OpenCV의 Polygon Drawing에서는 이미지 Pixel 위치를 정수 좌표로 사용하기 위해 원본 코드가 np.int32로 변환한다.

↓

Python String
imencode() 반환값

첫 번째 값은 Encoding 성공 여부, 두 번째 값은 Encoding된 Byte Buffer다.

File Base64

저장된 JPEG 파일도 Binary로 읽어 Base64로 변환할 수 있다

교안 원문 

with open(
    'segmentation_outline.jpg',

    image_bytes
).decode(
    'utf-8'

Memory 방식 NumPy Image → imencode() → Base64
File 방식 JPEG File → Binary Read → Base64
Base64는 Metric이 아니다.

긴 `/9j/4AAQ...` 문자열은 JPEG Binary를 Text로 Encoding한 데이터다.
