원본 Notebook

올바른 원칙

Train / Test Split ↓ Selector.fit(X_train, y_train) ↓ transform(X_train) ↓ transform(X_test)

Test는 Feature 선택 과정에 참여하지 않습니다.

Common Mistakes

자주 하는 실수

1. 상관관계 높은 Feature만 쓰면 무조건 좋아진다고 생각한다

이번 실습에서는 13개 → 3개로 줄인 뒤 R²가 오히려 낮아집니다.

2. f_regression의 F를 F1-score라고 생각한다

통계적 F와 Classification의 F1은 다른 개념입니다.

3. SelectKBest를 전체 Dataset에 fit한다

Test Target 정보가 Feature Selection에 들어가 Leakage가 발생합니다.

4. StandardScaler를 전체 Dataset에 fit한다

Test Feature의 통계 정보가 Training 준비에 들어갑니다.

5. Scaling 결과가 같으니 Leakage가 중요하지 않다고 생각한다

Metric이 같아도 평가 절차가 올바르다는 뜻은 아닙니다.

6. R²를 Accuracy라고 부른다

R²는 Regression Metric입니다.

7. MSE를 % 정확도로 읽는다

MSE는 제곱 오차의 평균입니다.

8. coefficient가 크면 무조건 Feature Importance가 크다고 생각한다

Feature Scale과 다중공선성을 함께 고려해야 합니다.

9. RandomForest가 항상 LinearRegression보다 좋다고 생각한다

이번 Dataset과 Split에서의 결과일 뿐입니다.

10. Boston Housing을 현대 실서비스 데이터로 그대로 사용한다

오래된 Dataset과 Feature의 맥락을 반드시 고려해야 합니다.

Q5. R²란 무엇인가요?

모델이 Target 변동을 어느 정도 설명하는지 나타내는 Regression Metric입니다.

Q6. R² 0.669는 Accuracy 66.9%인가요?

아닙니다. R²와 Classification Accuracy는 다른 지표입니다.

Q7. SelectKBest는 무엇인가요?

각 Feature를 score_func로 평가하고 상위 k개의 Feature를 선택하는 도구입니다.

Q8. f_regression의 F는 F1-score인가요?

아닙니다. f_regression의 F는 통계적 F 값이며, F1-score는 Classification Metric입니다.

Q9. 왜 Feature Selection도 Leakage가 될 수 있나요?

전체 X와 y를 이용해 Feature를 선택하면 Test Target 정보까지 Feature Selection에 영향을 주기 때문입니다.

Q10. 왜 StandardScaler도 Train에만 fit해야 하나요?

Test Dataset의 평균과 표준편차 정보가 Training 준비 과정에 들어오는 것을 막기 위해서입니다.

Q11. Feature를 13개에서 3개로 줄였는데 왜 성능이 떨어졌나요?

단독 상관관계가 낮은 Feature도 여러 Feature와 함께 사용될 때 추가적인 예측 정보를 제공할 수 있기 때문입니다.

Q12. coefficient가 크면 Feature Importance도 항상 큰가요?

아닙니다. Feature Scale과 다중공선성 등도 함께 고려해야 합니다.

Q13. RandomForest의 R²가 더 높으면 항상 더 좋은 모델인가요?

이번 Dataset과 Split에서 더 높은 결과를 보였다는 뜻이며, 다른 조건에서도 항상 우수하다고 일반화할 수는 없습니다.

Q14. Error Analysis는 왜 필요한가요?

전체 Metric만으로는 특정 Sample이나 특정 데이터 영역의 큰 Prediction 실패를 발견하기 어렵기 때문입니다.

오늘의 암기 포인트

506 × 13 → 404 × 13 + 102 × 13 → LinearRegression → MSE / R²
13 Features → SelectKBest → 3 Features → RM / PTRATIO / LSTAT
  • X는 (506,13)이다.
  • Train은 (404,13), Test는 (102,13)이다.
  • CHAS와 RAD는 float로 변환한다.
  • 기본 평가 Metric은 MSE와 R²다.
  • R²는 Accuracy가 아니다.
  • SelectKBest의 k는 Hyperparameter다.
  • f_regression의 F와 F1-score는 다르다.
  • Selector와 Scaler의 fit은 Train에만 수행한다.
  • Metric뿐 아니라 개별 Prediction Error도 확인한다.
