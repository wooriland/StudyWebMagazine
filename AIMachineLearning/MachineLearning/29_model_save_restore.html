전처리

X는 float32 /255, y는 정수 Class 그대로

교안 원문 · Cell 5

#데이타 전처리
X_train = X_train.astype(np.float32)/255
X_test  = X_test.astype(np.float32)/255
무엇을 하는가?
X를 float32로 변환하고 255로 나눈다.
왜 필요한가?
원문의 0~1 범위 실수 입력을 준비한다.
입력 Shape
Train (60000,28,28), Test (10000,28,28).
출력·반환값
Shape는 동일하다.
실행 후 변화
X의 dtype·범위가 바뀐다. 이미지 수·크기·y는 유지된다.
128 / 255 ≈ 0.50196 설명용 Pixel 계산. 모델 실행 결과가 아니다.

astype는 자료형 변환, /255는 고정 상수에 의한 값 범위 조정이다. 평균·표준편차를 계산하는 표준화와 다르다. y의 7은 밝기가 아니라 Class이므로 나누지 않는다.

전처리 Cell만 다시 실행하면 X를 다시 255로 나눌 수 있다. 저장 파일을 로드해도 이 모델 밖 전처리가 자동 실행되지는 않는다.

학습과 추론에서 입력 규격을 유지한다. 모델 내부에 Flatten이 있으므로 이번 원문에는 모델 밖 Flatten이나 Channel 축 추가가 없다.
