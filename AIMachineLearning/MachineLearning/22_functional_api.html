Layer·KerasTensor·배열·Parameter를 구분한다

Dense(...)(flatten)의 첫 괄호는 Layer 객체를 만들고, 두 번째 괄호는 그 Layer에 이전 Tensor를 전달한다. 원문의 hidden1은 Layer 객체가 아니라 Layer 호출의 반환 Tensor다.

KerasTensor는 실제 이미지를 계산한 결과가 아니라 모델의 연결을 정의하는 Tensor다. model.output을 조회했다고 Test 10,000개의 예측이 생기는 것은 아니다. 실제 Prediction 배열은 model.predict(X_test)로 얻는다.

B는 현재 Sample 수다. 모델 구성 중 표시되는 None은 Batch 크기를 고정하지 않았다는 뜻이지 0개나 축이 없다는 뜻이 아니다. Input(shape=(28,28))에는 Batch 크기를 넣지 않는다.

Grayscale이지만 원문 입력은 (N,28,28)이다. 원문에 없는 Channel 축을 추가해 (N,28,28,1)로 설명하지 않는다.

Rank와 Shape: (B,28,28)은 축 3개, (B,784)는 축 2개다. Shape는 축 길이이고, 행렬곱 (B,784) @ (784,128)에서는 안쪽 784가 일치해야 한다.

Adam의 0.001을 사용한 것과 최적값을 찾은 실험은 다르다. 적응적 업데이트라고 학습률의 영향이 없어지는 것은 아니다. 이번 파일에 Schedule·학습률 후보 비교가 있다는 뜻도 아니다.

성능 개선의 출발점: 현재 상태와 평가 범위를 기록 → 입력·Label·모델 연결 점검 → Validation 기준으로 조건 비교 → 최종 Test 평가. 이는 보완 방향이며 새 개선 결과를 만든 기록이 아니다.

API의 표현력과 정확도 우위를 구분한다

이번의 Layer Call은 다음의 분기·공유·다중 출력으로 이어진다. Layer에 이름을 붙이면 연결을 조회하고 설명하는 데 도움이 된다. 그러나 이번 모델이 이미 복잡한 분기나 다중 입력을 구현한 것은 아니다.

이전 Layer의 출력 Tensor를 다음 Layer에 전달하고 입력·출력 Tensor로 Model을 만든다.

Q2. Dense(...)(x)의 두 괄호는?

Layer 객체 생성과 그 Layer를 Tensor로 호출하는 단계다.

아니다. Layer 호출로 반환된 Tensor다.

기호적 입력 규격과 실제 이미지 배열의 차이다.

Q5. Shape의 None은?

Batch 크기를 모델 구성에서 고정하지 않았다는 뜻이다.

Q6. (B,10)이면 다중 출력인가?

이번은 출력 Tensor 하나에 열 개 Class 확률이 있는 단일 출력이다.

Q7. 전체 Parameter와 학습 변수 수는?

수치 Parameter 109,386개, Kernel·Bias 세 쌍의 변수 Tensor 여섯 개다.

Q8. compile에서 처음 Weight가 생기는가?

이번 모델은 compile 전에 Summary·Weight를 조회한다. compile은 학습 규칙 설정이다.

Q9. Categorical Cross-Entropy를 쓰는 이유는?

이번 y는 One-Hot이고 출력은 Softmax 확률이기 때문이다.

Q10. 학습률·Epoch·Batch는?

0.001, 10 Epoch, NumPy 입력에서 Batch Size를 생략해 기본 32다.

Validation을 제외한 48,000개를 32개씩 처리한다.

아니다. 이번은 셔플 전 마지막 20%를 검증용으로 분리한다.

Q13. History가 원본에 있는가?

반환 객체는 있지만 history 변수 대입과 Loss 곡선은 없다.

Q14. 조회된 Weight가 최종 학습값인가?

원본 순서상 fit 이전이므로 최종 학습 결과라고 설명하지 않는다.

Q15. 원본 Test 결과는?

저장 Loss 약 0.08893, Accuracy 약 97.73%다.

One-Hot에서 실제 숫자 Index를 복원하기 위해서다.

예를 들어 X_test[1:2]로 (1,28,28)을 유지한다.

아니다. 원본에 해당 시점의 Weight 저장·복원 절차가 없다.

이 기록만으로는 결론 낼 수 없다. 구조와 학습 조건 등이 함께 달라졌다.
