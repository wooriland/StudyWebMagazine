AI Machine Learning PART 2. 퍼셉트론과 FFNN ML 11

XOR · Logistic Regression · NumPy · Gradient Descent

로지스틱 회귀로 XOR 문제 이해하기

NumPy만 사용하여 로지스틱 회귀 형태의 LogicCircuit을 직접 구현한다. AND·OR·NAND 논리 게이트는 학습되지만, 하나의 선형 결정 경계를 사용하는 모델은 XOR를 해결하지 못한다는 사실을 Loss와 Prediction 결과로 확인한다. 이후 NAND와 OR의 출력을 새로운 Feature로 만들고 AND 모델의 입력으로 전달하여 XOR를 구성한다.

이번 단원의 가장 중요한 흐름

X → XW + b → Sigmoid → Cross Entropy → Gradient → W / b Update → Predict

학습 목표

  • NumPy로 구현된 로지스틱 회귀의 입력 → 선형 계산 → Sigmoid → Loss → Gradient → Parameter Update 흐름을 설명할 수 있다.
  • X.shape = (4,2), W.shape = (2,1), h.shape = (4,1)의 의미를 설명할 수 있다.
  • AND·OR·NAND는 단일 선형 모델로 학습되지만 XOR는 그렇지 않은 이유를 설명할 수 있다.
  • Sigmoid가 비선형 함수인데도 단일 로지스틱 회귀의 결정 경계가 선형인 이유를 설명할 수 있다.
  • XOR 학습 시 Loss가 약 2.773 근처에서 정체되는 의미를 이해할 수 있다.
  • NAND와 OR의 출력을 새로운 Feature로 만들어 XOR를 구성하는 흐름을 설명할 수 있다.
  • 교안 원문의 grad_W 구현과 통합교안 검토 메모를 구분해서 이해할 수 있다.

Code Example

Sigmoid 함수

교안 원문 
def sigmoid(z):
    return 1 / (1 + np.exp(-z))
무엇을 하는가?

선형 계산값 z를 0과 1 사이의 값으로 변환한다.

입력 Shape (N,1)
출력 Shape (N,1)
실행 후 변화

값의 범위가 -∞ ~ +∞에서 0 ~ 1로 변한다.

중요

Sigmoid 자체는 비선형 함수지만, sigmoid(Wx+b) 하나만 사용하는 로지스틱 회귀의 Threshold 0.5 결정 경계는 여전히 Wx+b=0이다.

09

Code Example

LogicCircuit 클래스

교안 원문 구조 
class LogicCircuit:

    def __init__(self, x, y, lr):
        self.__x = x.reshape(-1, 2)
        self.__y = y.reshape(-1, 1)

        self.__W = np.random.rand(
            self.__x.shape[1],
            1
        )

        self.__b = np.zeros(1)

        self.__lr = lr

    def __loss_func(self):
        delta = 1e-5

        z = np.dot(
            self.__x,
            self.__W
        ) + self.__b

        h = sigmoid(z)

        return -np.sum(
            self.__y * np.log(h + delta)
            +
            (1 - self.__y)
            * np.log((1 - h) + delta)
        )
변수 Shape 의미
self.__x (4,2) 훈련 입력
self.__y (4,1) 정답
self.__W (2,1) 두 Feature의 Weight
self.__b (1,) 출력 Bias
z (4,1) 선형 계산 결과
h (4,1) Sigmoid 예측 확률
10

Loss

Cross Entropy Loss

- [ y log(h) + (1-y) log(1-h) ]

정답 y = 1

-log(h)

예측 확률 h가 1에 가까울수록 Loss가 작아진다.

정답 y = 0

-log(1-h)

예측 확률 h가 0에 가까울수록 Loss가 작아진다.

이번 코드의 특징

np.mean()이 아니라 np.sum()을 사용하므로 네 Sample의 Loss를 합산한다.

왜 delta = 1e-5를 더하는가?

log(0) → 수치 문제 → h + delta

확률값이 0 또는 1에 매우 가까워질 때 로그 계산이 무한대로 발산하는 상황을 완화한다.

Training

fit() — 학습 흐름

교안 원문 
def fit(self, epochs):

    for step in range(epochs):

        # 순전파
        z = np.dot(
            self.__x,
            self.__W
        ) + self.__b

        h = sigmoid(z)

        # Gradient 계산
        grad_W = np.mean(
            np.dot(
                self.__x.T,
                (h - self.__y)
            )
        )

        grad_b = np.mean(
            h - self.__y
        )

        # Parameter Update
        self.__W -= self.__lr * grad_W
        self.__b -= self.__lr * grad_b

        if step % 2000 == 0:
            print(
                f"step {step}, "
                f"loss={self.__loss_func():.4f}"
            )
1 Forward XW+b
↓
2 Activation Sigmoid
↓
3 Error h-y
↓
4 Gradient grad_W / grad_b
↓
5 Update W -= lr × grad
↓
6 Repeat epochs

Review Note

통합교안 검토 메모 — grad_W Shape

교안 원문 
grad_W = np.mean(
    np.dot(
        self.__x.T,
        (h - self.__y)
    )
)
검토 메모
X.T : (2,4) × (h-y) : (4,1) → (2,1) → np.mean() → scalar

Weight는 두 개이므로 Weight별 Gradient를 유지하려면 Gradient 결과의 Shape도 각 Weight와 대응되어야 한다. 그러나 원문에서는 전체 배열에 np.mean()을 적용하여 scalar 하나로 축약된다.

학습 원칙

이 페이지에서는 원본 코드를 임의로 수정하지 않는다. 원문 코드는 원문대로 제시하고, Shape 문제는 검토 메모로 별도 설명한다.

Prediction

predict() — 확률을 0/1로 변환

def predict(self, x_test, threshold):

    z = np.dot(
        x_test,
        self.__W
    ) + self.__b

    h = sigmoid(z)

    pred = []

    for value in h:

        if value > threshold:
            pred.append(1)

        else:
            pred.append(0)

    return pred
x_test → XW+b → Sigmoid → Probability → 0.5 → 0 / 1
Threshold 조건

원문은 value > 0.5이면 1, 그렇지 않으면 0으로 분류한다.

실제 저장 Loss인 약 2.7731과 가깝다. 따라서 개념적으로는 모델이 XOR를 의미 있게 분리하지 못하고 약 50:50 수준의 애매한 예측 상태에 머무는 것으로 이해할 수 있다.

Common Mistakes

자주 하는 실수

01

XOR는 Epoch가 부족해서 실패했다고 생각한다.

핵심 문제는 학습 횟수가 아니라 단일 선형 모델의 표현력이다.

02

Learning Rate를 바꾸면 XOR가 해결된다고 생각한다.

Learning Rate는 업데이트 크기를 조절하지만 모델의 선형 결정 경계 구조 자체는 바꾸지 못한다.

03

Sigmoid가 비선형이므로 XOR도 자동으로 해결된다고 생각한다.

단일 sigmoid(Wx+b)의 분류 경계는 여전히 Wx+b=0이다.

04

X_test를 완전히 새로운 데이터라고 생각한다.

실제로는 X_train의 네 논리 조합을 순서만 바꾸어 사용한다.

05

y Shape가 계속 (4,)라고 생각한다.

모델 내부에서는 reshape(-1,1)을 통해 (4,1)이 된다.

06

grad_W의 Shape를 확인하지 않는다.

원래 `(2,1)` 형태가 기대되지만 원문 코드의 전체 np.mean()으로 scalar가 된다.

07

모델 결합 자체를 MLP라고 생각한다.

이번에는 세 모델을 외부에서 연결한다. 다음 단원에서 하나의 Neural Network 내부에 Hidden Layer를 만든다.

08

“스태킹과 같다”를 정식 StackingClassifier라고 이해한다.

교안의 표현은 모델 출력이 다음 모델의 입력이 된다는 구조적 비유다.

Error Reading

오류 메시지 읽는 법

구분

아래 오류는 원본 Notebook의 저장 Exception이 아니라, 동일 코드를 수정하거나 확장할 때 발생할 수 있는 대표적인 오류다.

1. Matrix Shape Error

ValueError:
shapes (...) not aligned

행렬곱에서 연결되는 차원이 맞지 않을 때 발생한다.

(batch, feature) @ (feature, output)

2. Broadcasting Error

ValueError:
operands could not be broadcast together

배열끼리 연산할 때 각 축의 크기가 Broadcasting 규칙에 맞지 않는 경우다.

3. dtype Error

X_train = np.array([
    ["0", "1"],
    ["1", "0"]
])

문자열 배열은 np.dot(), np.exp() 등의 수치 연산에서 문제가 될 수 있다.

4. exp Overflow

RuntimeWarning:
overflow encountered in exp

Weight 또는 z가 지나치게 커지면 np.exp(-z) 계산이 수치적으로 불안정해질 수 있다.

5. log(0)

Cross Entropy 계산에서 log(0)을 피하기 위해 원문은 delta = 1e-5를 추가한다.

Interview Point

면접 포인트

Q1. XOR가 단층 퍼셉트론에서 중요한 이유는 무엇입니까?

XOR는 하나의 선형 결정 경계로 분리할 수 없기 때문에 단층 선형 분류기의 표현력 한계를 보여주는 대표적인 문제입니다.

Q2. Sigmoid가 비선형인데 왜 XOR를 해결하지 못합니까?

sigmoid(Wx+b) 하나의 구조에서 Threshold 0.5의 결정 경계는 Wx+b=0이므로 입력 공간에서는 여전히 선형입니다.

Q3. X_train의 Shape는 무엇입니까?

(4,2)입니다. 4개의 Sample과 2개의 Feature를 의미합니다.

Q4. Weight Shape가 (2,1)인 이유는 무엇입니까?

입력 Feature가 2개이고 출력 노드가 1개이기 때문입니다.

Q5. 이번 Notebook의 Loss는 무엇입니까?

이진 분류를 위한 Binary Cross Entropy 형태를 사용합니다. 원문에서는 각 Sample Loss를 np.sum()으로 합산합니다.

Q6. Optimizer를 사용합니까?

Keras Optimizer 객체는 사용하지 않고 Gradient를 직접 계산하여 W -= lr * grad_W 형태로 업데이트합니다.

Q7. XOR Loss가 약 2.773에서 멈춘 것은 어떻게 해석할 수 있습니까?

모델이 XOR를 제대로 구분하지 못하고 약 0.5 수준의 애매한 확률을 출력하는 상태에 가까운 것으로 이해할 수 있습니다. 다만 원본 Gradient 구현 문제도 수치에 영향을 줍니다.

Q8. XOR는 최종적으로 어떻게 해결합니까?

NAND와 OR 모델의 출력을 새로운 Feature로 만든 뒤 그 값을 AND 모델에 입력합니다.

Q9. 이번 Notebook의 grad_W 검토 메모는 무엇입니까?

Weight별 Gradient는 Shape를 유지해야 하지만 원문은 전체 np.mean()으로 `(2,1)` 값을 scalar로 축약합니다.

Q10. 이번 실습이 MLP와 어떻게 연결됩니까?

현재는 사람이 NAND와 OR라는 중간 표현을 직접 만들지만, 다음 MLP에서는 Hidden Layer가 중간 표현을 내부 학습으로 생성합니다.

Caution

헷갈리기 쉬운 개념

Sigmoid는 비선형이므로 XOR를 풀 수 있다?

X 단일 sigmoid(Wx+b)의 결정 경계는 여전히 선형이다.

XOR는 Learning Rate가 나빠서 실패했다?

X 핵심은 모델 표현력 부족이다.

X_test는 완전히 새로운 Dataset이다?

X 같은 네 논리 입력을 다른 순서로 사용한다.

grad_W Shape는 (2,1)로 그대로 유지되는가?

X 원문은 np.mean()으로 scalar로 축약한다.

모델 세 개를 연결했으므로 이미 MLP인가?

X 이번에는 독립 모델을 외부에서 연결한 구조다.
