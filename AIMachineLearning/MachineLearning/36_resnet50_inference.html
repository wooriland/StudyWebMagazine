01 핵심 개념 · 학습된 모델로 답을 계산하기

이번 실습의 목표는 사진 한 장을 읽어 ResNet50에 넣고, 가장 높은 점수를 받은 ImageNet 클래스를 해석하는 것입니다. 모델을 처음부터 훈련하거나 새로운 분류층을 학습하지 않습니다. 원본 첫 셀도 파라미터를 업데이트하지 않고 예측만 한다고 설명합니다.

왜 배우나요?

실제 서비스에서는 학습보다 이미 만들어진 모델을 호출하는 일이 자주 일어납니다. 모델 파일을 불러오는 것만으로 끝나지 않고 입력 크기·색상 순서·전처리·출력 레이블까지 일치시켜야 올바른 예측을 얻습니다.

어떤 문제인가요?

이미지 전체를 하나의 클래스로 분류하는 단일 레이블 다중 클래스 분류입니다. 동물의 위치를 박스로 찾거나 개체 수를 세는 객체 탐지 실습이 아닙니다.

사전학습·추론·전이학습 구분
용어 의미 이번 실습
사전학습 다른 데이터로 이미 가중치를 학습해 둠 ImageNet 가중치 사용
추론, Inference 고정된 가중치로 입력의 출력을 계산 model.predict 실행
전이학습 기존 지식을 새 과제에 활용하여 모델 구성·학습 새 분류층이나 추가 학습 없음
미세조정, Fine-tuning 사전학습된 층도 추가 학습 실행하지 않음
평가, Evaluation 예측과 실제 정답을 비교하여 성능 측정 정답 y와 평가 코드 없음

include_top=True + weights='imagenet'이므로 기존 ImageNet 분류층까지 가져옵니다. 파일명에 DogvsCat이 있어도 출력이 자동으로 고양이·개 두 클래스로 바뀌지는 않습니다.

  1. load_img는 파일을 읽고 높이·너비를 224×224로 맞춥니다. 기본 RGB 모드로 읽으므로 채널은 3개입니다.

입력 → 출력 Shape
(1,224,224,3) → (1,224,224,3). 함수가 크기 조정이나 배치 축 추가를 대신하지는 않습니다.
실행 후 변화
dog_image_array_output에 전처리 결과가 연결됩니다. 이름의 output은 전처리 출력이며, 모델에서는 입력 X입니다.

원본 저장 출력 Shape (1,224,224,3)와 float32 배열이 저장되어 있습니다. 배열에는 음수도 들어갑니다. 음수라는 이유만으로 오류라고 판단하지 않습니다.

같은 셀을 다시 실행할 때의 함정

np.newaxis로 만든 배열은 원본 배열과 메모리를 공유할 수 있습니다. NumPy 경로의 preprocess_input도 입력 배열을 제자리에서 변경할 수 있으므로, 같은 변수에 전처리를 반복하면 이미 변환된 값에 변환이 다시 적용될 수 있습니다. 

# 보충 예제: 새로 읽은 RGB 배열에서 시작하고 복사본을 전처리합니다.
fresh_image = image.load_img(
    './datasets/cnn/new_dog.jpg',
    target_size=(224, 224),
    color_mode='rgb'
)

09 그림처럼 이해 · 데이터와 모델의 Shape 흐름

  1. Image · RGB (224,224,3)
  2. Batch + 전처리 (B,224,224,3)
  3. Conv·BN·ReLU·Pooling 공간 특징 추출
  4. Residual blocks F(x) + shortcut(x)
  5. 최종 Feature Map (B,7,7,2048)
  6. Global Average Pooling (B,2048)
  7. Dense + Softmax (B,1000)
  8. 클래스별 점수 이미지별 합 ≈ 1
  9. Top-k 해석 클래스 ID·이름·점수

B는 배치에 들어 있는 이미지 수입니다. 원본은 한 장이므로 B=1입니다. Conv·ReLU·Pooling은 내부 연산의 개요이며 실제 ResNet50은 여러 잔차 블록과 BatchNormalization을 포함합니다. 

잔차 연결의 개념
입력 x ─────────── shortcut ─────┐
   └─ 여러 층의 연산 F(x) ──────┤
                                ↓
                     F(x) + shortcut(x)

GAP의 개념
7×7 위치의 값을 채널별 평균 → 채널 2,048개는 유지
(B,7,7,2048)                → (B,2048)

잔차 경로끼리 더하려면 Shape가 맞아야 하므로 필요할 때 shortcut에도 변환이 들어갑니다. 이번 실습에서는 내부 블록을 새로 구현하지 않습니다.

입력 → 출력 Shape

실행 후 변화
y_pred가 생성됩니다. 가중치는 학습되지 않습니다. argmax는 가장 큰 값 자체가 아니라 위치를 반환합니다.

axis=1을 읽는 방법

y_pred.shape = (이미지 수, 클래스 수)
                    axis=0      axis=1

argmax(axis=1)
→ 각 이미지의 클래스 축에서 가장 큰 값의 위치를 선택

sum(axis=1)
→ 각 이미지의 클래스 확률을 합함 → 이미지마다 약 1

원문의 y_pred.sum()은 배열 전체의 합입니다. 한 장이면 약 1이지만 B장 배치라면 약 B가 됩니다. 여러 장에서는 y_pred.sum(axis=1)로 이미지별 합을 확인합니다.

추가 검토 이 셀에는 저장된 실행 출력이 없습니다. 원문 주석의 1.0000001을 실제 저장 결과로 인용하지 않습니다. 부동소수점 계산에서 합이 1과 조금 다른 것은 가능하지만 실제 값은 실행해서 확인해야 합니다. argmax의 정수 인덱스도 원본 저장 출력으로 확인되지 않았습니다.

Softmax는 클래스별 값 zᵢ를 exp(zᵢ)/Σexp(zⱼ)로 바꿉니다. 합이 1인 분포를 만들지만, 높은 점수가 항상 실제 세계의 정답 확률과 정확히 일치한다는 보장은 없습니다.

13 Loss·Metric · 점수와 성능을 구분하기

이번 출력으로 알 수 있는 것과 추가 데이터가 필요한 것
항목 정의 원본에서 확인 가능한가?
예측 확률 한 이미지에 대한 클래스별 Softmax 점수 상위 5개 저장 결과 있음
Top-1 Accuracy 최고 점수 클래스가 정답인 이미지의 비율 정답 데이터가 없어 계산하지 않음
Top-5 Accuracy 상위 5개 안에 정답이 있는 이미지의 비율 후보 출력만으로는 계산 불가
Cross-Entropy Loss 실제 정답 클래스에 준 확률을 평가 원본에 계산 없음
R² 연속값 회귀의 설명력 지표 이 클래스 분류의 평가 지표로 사용하지 않음

Loss는 무엇을 보나요?

정답이 하나인 다중 클래스 분류에서 해당 정답의 확률을 p_true라 하면 Cross-Entropy는 −ln(p_true)입니다. 정답 확률이 높을수록 작아집니다. 정답이 collie라고 가정할 경우 저장 점수 0.9889854의 Loss는 약 0.0111입니다. 이는 조건을 둔 계산 예시이며 원본에서 측정한 Loss가 아닙니다.

Accuracy는 맞혔는지를 보고 Loss는 정답 확률도 반영합니다. 예를 들어 정답을 맞힌 두 이미지라도 정답 확률이 0.51과 0.99이면 Loss는 다릅니다. 반대로 틀린 클래스에 과도하게 확신하면 Loss가 커질 수 있습니다.

R²를 클래스 번호에 적용하면 왜 안 되나요?

R²는 일반적으로 1 − SSE/SST이며 연속적인 수치 예측을 평가합니다. 실제 값에 변동이 있을 때 1은 완벽한 예측, 0은 평균 예측 수준, 음수는 그보다 나쁜 결과를 뜻합니다. ImageNet의 클래스 번호는 크기나 거리 의미가 없는 식별자이므로 번호 간 차이에 회귀 지표를 적용하지 않습니다.

보충 예제 · 정답이 확보되었을 때만 평가하기

원본에 없는 평가 확장 아래는 이미 구한 확률과 실제 정답으로 Metric을 계산하는 함수입니다. 모델을 새로 학습하거나 원본에 없는 평가 결과를 만들어 제시하는 코드가 아닙니다. 

def classification_scores(probabilities, y_true):
    probabilities = np.asarray(probabilities)
    y_true = np.asarray(y_true)

    assert probabilities.ndim == 2
    assert probabilities.shape[1] == 1000
    assert y_true.ndim == 1
    assert len(y_true) == len(probabilities)
    assert len(y_true) > 0
    assert np.issubdtype(y_true.dtype, np.integer)
    assert np.all((0 <= y_true) & (y_true < 1000))

    top1_indices = np.argmax(probabilities, axis=1)
    top5_indices = np.argsort(probabilities, axis=1)[:, -5:]

    top1_correct = top1_indices == y_true
    top5_correct = np.any(
        top5_indices == y_true[:, np.newaxis],
        axis=1
    )

    return {
        'top1_accuracy': float(np.mean(top1_correct)),
        'top5_accuracy': float(np.mean(top5_correct))
    }
입력 조건
probabilities: (N,1000), y_true: (N,). 정답은 같은 ImageNet 클래스 순서의 정수 0~999이고 샘플 순서도 같아야 합니다.
중간 Shape
Top-1 인덱스 (N,), Top-5 인덱스 (N,5), 비교용 정답 (N,1), 정답 포함 여부 (N,).
출력과 변화
두 Accuracy를 담은 사전을 반환합니다. 가중치는 바뀌지 않습니다. 함수 정의만으로 실제 평가가 실행되지는 않습니다.

고양이=0, 개=1로 새로 만든 라벨을 ImageNet 번호로 사용하면 안 됩니다. 모델의 예측을 정답으로 복사해서 평가해도 안 됩니다. 최종 성능을 측정하려면 독립적인 평가 이미지와 올바른 정답이 필요합니다.

def predict_one_image(model, image_path, top=5):
    img = image.load_img(
        image_path,
        target_size=(224, 224),
        color_mode='rgb'
    )
    rgb_array = image.img_to_array(img)

    model_input = preprocess_input(
        rgb_array[np.newaxis, ...].copy()
    )

    probabilities = model.predict(model_input, verbose=0)
    top_results = decode_predictions(probabilities, top=top)[0]

    return probabilities, top_results

아무 사진이나 넣을 수 있다는 것과 그 사진의 정답 클래스가 ImageNet 1,000개 안에 있다는 것은 다릅니다. 해당 클래스가 없어도 모델은 기존 클래스 중 점수를 배분하므로 높은 점수만으로 “분류 가능한 대상”이라고 보장할 수 없습니다.

16 자주 하는 실수 · Data Leakage·Shape·dtype

Data Leakage · 독립적으로 평가했는가?

원본은 데이터 분할이나 새 학습을 하지 않으므로 여기서 데이터 누수가 발생했다고 단정할 근거는 없습니다. 다만 평가로 확장할 때는 원본과 증강 이미지, 같은 장면의 연속 사진, 중복 파일이 학습·검증·테스트에 섞이지 않도록 관리합니다. 테스트 결과를 보고 전처리나 모델을 반복 선택하면 테스트의 독립성이 약해집니다.

새 파일명이라는 사실만으로 ImageNet 사전학습 데이터와 중복되지 않는다고 증명되지는 않습니다. 반대로 이 사진이 사전학습에 포함되었다고 단정할 근거도 없습니다. ImageNet에서 정해진 평균을 전처리에 사용하는 것 자체는 현재 테스트 데이터에서 통계를 학습하는 누수와 다릅니다.

18 성능 개선 · 학습 진단과 추론 진단을 구분하기

필수 개념과 이번 단원에서의 적용 범위
개념 학습 중 관찰하는 대표 현상 이번 실습의 판단
Overfitting 훈련에는 잘 맞지만 검증 성능이 상대적으로 나쁨 훈련·검증 곡선이 없어 판정 불가
Underfitting 훈련과 검증 모두 충분히 맞추지 못함 한 장의 예측 실패만으로 판정 불가
Learning Rate가 너무 큼 업데이트가 커져 Loss 진동·불안정 가능 원본은 가중치 업데이트가 없어 조정 대상 아님
Learning Rate가 너무 작음 학습 진행이 느리거나 제한된 시간에 충분히 학습하지 못함 원본에 Learning Rate 설정 없음
입력 분포 차이 실제 서비스 사진이 사전학습 사진과 다름 추론 결과가 나쁠 때 확인할 주요 원인
클래스 범위 불일치 원하는 정답이 기존 클래스에 없음 1,000클래스 목록이 과제에 적합한지 확인

예측이 이상할 때의 확인 순서

  1. 사진 경로와 실제 내용을 확인합니다. RGB·224×224·4차원 배치인지 확인합니다.
  2. ResNet50 전처리를 새 RGB 배열에 한 번만 적용했는지 확인합니다.
  3. ImageNet 가중치, include_top=True, 1,000클래스 출력인지 확인합니다.
  4. 관심 대상이 ImageNet 클래스 범위에 포함되는지 확인합니다.
  5. 다양한 실제 이미지와 정답으로 오류 유형을 분석합니다. 한 장의 높은 점수만으로 성능을 결론 내리지 않습니다.
  6. 새 과제의 클래스가 필요하면 전이학습으로 분류층을 구성합니다. 기반 모델 미세조정은 추가 학습 단계에서 별도로 검토합니다.

새 학습을 한다면 과적합에는 데이터 다양성·적절한 증강·정규화·학습 종료 시점 등을, 과소적합에는 학습량·모델 표현력·입력과 라벨 품질 등을 점검할 수 있습니다. 이러한 조치는 원본에서 실행한 개선 실험이 아닙니다.

단순히 Learning Rate를 바꿔서 기존 predict 결과를 개선하지는 못합니다. 먼저 입력 처리와 과제 적합성을 확인하고, 실제 추가 학습이 필요한지 판단합니다.

20 면접 포인트 · 질문에 답하며 복습하기

Q1. 이번 단원은 왜 전이학습 실습이 아닌가요?

원본의 분류층과 사전학습 가중치를 그대로 사용하고, 새 데이터로 파라미터를 학습하지 않기 때문입니다.

Q2. include_top=True는 무엇을 의미하나요?

ImageNet 분류 부분까지 포함합니다. 이번 설정에서 결과는 1,000개 클래스 확률입니다.

Q3. 사진 한 장인데 왜 4차원인가요?

이미지 한 장의 높이·너비·채널 세 축 앞에 이미지 수를 나타내는 배치 축이 필요하기 때문입니다.

Q4. float32 배열이면 0~1 범위인가요?

아닙니다. dtype는 값의 저장 형식입니다. img_to_array 직후 float32여도 픽셀 값은 일반적으로 0~255입니다.

Q5. ResNet50 V1 전처리는 무엇인가요?

RGB를 BGR로 바꾸고 채널별 ImageNet 평균을 뺍니다. 이번 모델에서는 /255를 추가하지 않습니다.

Q6. 원문의 /255는 모델 입력 정규화인가요?

해당 식은 imshow에 넘기는 임시 표시용 계산입니다. 모델 입력 변수에 재대입하지 않습니다.

Q7. 전처리 후 음수나 이상한 색이 나오면 오류인가요?

음수는 평균 빼기의 정상 결과일 수 있습니다. 이상한 색과 Clipping 경고는 모델용 배열을 RGB 표시 규칙으로 보여 줄 때 생길 수 있습니다.

Q8. np.squeeze는 전처리를 되돌리나요?

아닙니다. 길이 1인 축만 제거합니다. 채널 순서나 픽셀 값은 복원하지 않습니다.

Q9. predict 전에 compile이나 trainable=False가 필요한가요?

이 추론에는 둘 다 필요하지 않습니다. predict는 가중치를 최적화하지 않으며 학습 설정과 추론 모드는 구분해야 합니다.

Q10. argmax(axis=1)는 무엇을 반환하나요?

각 이미지에서 가장 큰 클래스 점수의 정수 인덱스를 반환합니다. 점수 자체나 클래스 이름을 반환하지 않습니다.

Q11. decode_predictions는 무엇을 하나요?

ImageNet의 클래스 순서에 맞춰 예측 점수를 ID·이름·점수 튜플로 해석합니다. 새로 학습한 임의의 클래스에는 자체 매핑이 필요합니다.

Q12. top=5이면 출력층이 다섯 개인가요?

아닙니다. 출력층은 1,000개이고 그중 상위 다섯 후보를 선택해서 보여 줍니다.

Q13. 98.8985%를 정확도라고 해도 되나요?

안 됩니다. 한 이미지에 대한 collie 예측 점수입니다. Accuracy는 여러 예측과 실제 정답의 일치 비율로 계산합니다.

Q14. Top-5 출력과 Top-5 Accuracy의 차이는?

출력은 후보 목록이고 Accuracy는 실제 정답이 그 후보 안에 포함된 이미지의 비율입니다.

Q15. 전처리 셀을 반복 실행할 때 왜 조심하나요?

입력 메모리가 공유되거나 제자리 변경이 일어나 이미 전처리된 값에 변환을 반복할 수 있습니다. 새 RGB 배열의 복사본을 사용합니다.

Q16. 이 예측만으로 과적합과 Learning Rate를 논할 수 있나요?

원본에는 훈련·검증 곡선이나 Optimizer 업데이트가 없습니다. 학습 진단을 하려면 별도 학습·검증 자료가 필요합니다.

Q17. R²가 적합하지 않은 이유는?

클래스 인덱스는 수치적 거리 의미가 없는 범주 식별자입니다. 연속값 회귀용 R²를 적용하지 않습니다.

Q18. 다음 단원에서 달라지는 것은?

MobileNet V1의 기존 분류층을 제외하고 고양이·개용 새 분류층을 추가해 학습합니다. 전처리와 출력 클래스 의미도 바뀝니다.

오늘의 암기 포인트

  1. 이번 실습은 추가 학습 없는 추론이다.
  2. ImageNet 가중치와 기존 분류층을 그대로 쓴다.
  3. 사진 한 장은 224×224×3이다.
  4. 모델 입력은 (1,224,224,3)이다.
  5. float32와 0~1 범위는 별개다.
  6. ResNet50 V1은 BGR 전환과 평균 빼기를 쓴다.
  7. 표시용 /255를 모델 전처리와 혼동하지 않는다.
  8. 전처리는 새 RGB 배열에 한 번 적용한다.
  9. squeeze는 축만 제거한다.
  10. predict는 가중치를 학습하지 않는다.
  11. 출력은 (1,1000)이다.
  12. 배치별 확률 합은 sum(axis=1)로 확인한다.
  13. argmax는 점수의 위치를 반환한다.
  14. decode는 ImageNet 클래스 이름을 연결한다.
  15. top=5는 후보 다섯 개를 보여 준다.
  16. 예측 점수는 정확도가 아니다.
  17. 정답 y가 없으면 실제 Loss·Accuracy를 계산할 수 없다.
  18. 다음 단원은 새 두 클래스 분류층을 학습한다.

헷갈리기 쉬운 개념

전처리 output ↔ 모델 output
dog_image_array_output은 모델 입력이고 y_pred가 모델 출력입니다.
None ↔ 1
None은 모델 정의의 가변 배치 자리, 1은 실제 이미지 장수입니다.
Shape ↔ dtype ↔ 값 범위
배열 모양, 자료형, 숫자 범위는 각각 확인해야 합니다.
trainable ↔ training
학습 대상 여부와 학습/추론 동작 모드는 다른 개념입니다.
확률 합 ↔ Accuracy
Softmax 합이 1이라는 성질은 정답을 맞혔다는 뜻이 아닙니다.
ImageNet ID ↔ 배열 인덱스
n02106030 같은 클래스 식별자와 출력 배열의 정수 위치는 다릅니다.
저장 출력 ↔ 주석 ↔ 예상 Shape
원본에 저장된 사실, 작성자의 설명, 구조상 계산한 결과를 구분합니다.
이미지 분류 ↔ 객체 탐지
이미지 전체의 클래스 예측과 객체별 위치·개수 예측은 다릅니다.
