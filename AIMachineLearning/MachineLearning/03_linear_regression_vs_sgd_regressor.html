LinearRegression과 SGDRegressor 비교

ML 01과 ML 02에서는 NumPy로 직접 Prediction, Loss, Gradient, Parameter Update를 구현했습니다. 이번 단원부터는 scikit-learn의 Estimator → fit() → coef_/intercept_ → predict() 흐름으로 이동합니다. 동일한 키 → 몸무게 회귀 문제를 LinearRegression과 SGDRegressor로 각각 학습하며, Shape 규칙과 학습 방식의 차이를 비교합니다.

NumPy 직접 학습 → Estimator → fit() → coef_ / intercept_ → predict()

학습 목표

  • scikit-learn의 기본 학습 흐름인 Estimator 생성 → fit → predict 구조를 설명할 수 있다.
  • 입력 X가 (n_samples, n_features) 형태의 2차원 배열이어야 하는 이유를 설명할 수 있다.
  • (9,)과 (9,1)의 차이를 이해할 수 있다.
  • reshape(-1,1), reshape(1,-1), reshape(1,1)의 용도를 구분할 수 있다.
  • coef_와 intercept_를 Weight와 Bias로 연결할 수 있다.
  • LinearRegression과 SGDRegressor가 같은 선형식을 다른 방식으로 학습한다는 것을 이해할 수 있다.
  • SGDRegressor에서 max_iter, eta0, tol 등의 의미를 이해할 수 있다.
  • Training 결과와 일반화 성능을 구분할 수 있다.
  • 다음 단원의 Scaling, Train/Test Split, Regularization 학습으로 연결할 수 있다.

Common Mistakes

자주 하는 실수

1. X=(9,) 그대로 fit한다

X는 (n_samples, n_features)의 2D 구조가 필요합니다.

2. y도 무조건 (9,1)이어야 한다고 생각한다

단일 Target 회귀에서는 y=(9,)을 사용할 수 있습니다.

3. reshape(-1,1)과 reshape(1,-1)을 혼동한다

Sample 축과 Feature 축의 의미가 완전히 다릅니다.

4. predict(150.9)라고 호출한다

새로운 X도 (n_samples, n_features) 구조여야 합니다.

5. coef_를 Prediction이라고 생각한다

coef_는 Weight이고 Prediction은 predict()의 결과입니다.

6. LinearRegression = BGD라고 외운다

통합교안 검토 메모에서도 지나친 단순화라고 지적합니다.

7. max_iter=100이면 반드시 100 Epoch이라고 생각한다

최대 반복 횟수이며 먼저 수렴할 수 있습니다.

8. SGD Loss는 항상 감소해야 한다고 생각한다

확률적 업데이트 특성 때문에 진동할 수 있습니다.

9. Prediction 하나로 성능을 비교한다

Metric과 Test Dataset이 필요합니다.

10. X_train이라는 이름 때문에 Test Dataset도 있다고 생각한다

실제 Notebook에서는 별도의 Split을 하지 않습니다.

Interview

면접 포인트

Q1. scikit-learn의 fit()은 무엇을 하나요?

전달받은 X와 y를 이용해 모델의 Parameter를 학습하고 Estimator 내부 상태를 변경합니다.

Q2. 왜 X는 2차원이어야 하나요?

일반적으로 X는 (n_samples, n_features) 구조를 사용하기 때문입니다.

Q3. (9,)과 (9,1)의 차이는 무엇인가요?

(9,)은 1차원 Vector이고, (9,1)은 9개의 Sample과 1개의 Feature를 가진 2차원 배열입니다.

Q4. reshape(-1,1)은 언제 사용하나요?

여러 Sample과 하나의 Feature를 가진 데이터를 (n_samples,1)로 만들 때 사용합니다.

Q5. coef_와 intercept_는 무엇인가요?

각각 학습된 Weight와 Bias입니다.

Q6. predict([[150.9]])처럼 이중 리스트를 사용하는 이유는?

Sample 1개와 Feature 1개를 (1,1)의 2차원 구조로 전달하기 위해서입니다.

Q7. LinearRegression과 SGDRegressor의 차이는?

둘 다 선형회귀 모델이지만 Parameter를 구하는 방식이 다릅니다. SGDRegressor는 Gradient 기반 반복 최적화를 사용하며 Learning Rate와 Feature Scale의 영향을 크게 받을 수 있습니다.

Q8. max_iter=100이면 반드시 100 Epoch인가요?

아닙니다. 최대 반복 횟수이며 수렴 조건이 먼저 만족되면 더 일찍 종료될 수 있습니다.

Q9. SGD Loss는 반드시 매 Epoch 감소하나요?

아닙니다. 확률적 업데이트 특성 때문에 중간에 증가하거나 진동할 수 있습니다.

Q10. Training 결과만으로 모델 성능을 판단할 수 있나요?

아닙니다. 일반화 성능을 확인하려면 Validation 또는 Test Dataset과 Metric이 필요합니다.

Q11. LinearRegression을 BGD라고 부르면 되나요?

그렇게 완전히 동일시하면 지나치게 단순화된 설명입니다. scikit-learn의 실제 LinearRegression 해법과 Gradient Descent를 구분해서 이해하는 것이 좋습니다.

Q12. SGDRegressor에서 Scaling이 중요한 이유는?

Gradient 기반 학습은 Feature Scale에 따라 Parameter Update의 크기와 수렴 안정성이 크게 달라질 수 있기 때문입니다.

오늘의 암기 포인트

Estimator → fit() → coef_ + intercept_ → predict()
X 구조 (n_samples, n_features)
  • X=(9,)은 fit에 바로 사용할 수 없다.
  • Feature 하나를 가진 9개의 Sample은 X=(9,1)이다.
  • coef_는 Weight다.
  • intercept_는 Bias다.
  • fit()은 학습이다.
  • predict()는 학습된 모델을 이용한 추론이다.
  • 새로운 Sample 하나도 2차원 Shape으로 전달한다.
  • SGDRegressor는 Scale과 Learning Rate에 민감하다.
