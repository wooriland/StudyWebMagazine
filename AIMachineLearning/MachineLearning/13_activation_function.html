활성화 함수

같은 입력값을 Step, Sigmoid, Tanh, ReLU, Leaky ReLU, Softmax 에 각각 통과시켜 출력 형태를 비교한다. 활성화 함수가 신경망에 비선형성을 부여하는 이유와 각 함수의 출력 범위, Gradient 특성, 대표적인 문제점을 이해하고, 이후 실제 FFNN에서 Hidden Layer와 Output Layer에 어떤 활성화 함수를 사용할지 준비한다.

이번 단원의 핵심 흐름

입력 x → Activation Function → 변환된 출력 → 그래프 시각화 → 함수별 특성 비교
Step Sigmoid Tanh ReLU Leaky ReLU Softmax

학습 목표

  • 활성화 함수가 신경망에서 필요한 이유를 설명할 수 있다.
  • Linear Layer만 여러 개 연결했을 때의 한계를 설명할 수 있다.
  • Step, Sigmoid, Tanh, ReLU, Leaky ReLU의 함수 형태와 출력 범위를 설명할 수 있다.
  • Sigmoid와 Tanh의 Vanishing Gradient 문제를 설명할 수 있다.
  • ReLU의 장점과 Dying ReLU 문제를 설명할 수 있다.
  • Leaky ReLU가 음수 영역에서 작은 Gradient를 유지하는 이유를 설명할 수 있다.
  • Softmax가 다른 활성화 함수와 달리 Vector 전체를 함께 계산한다는 점을 설명할 수 있다.
  • 원본 Softmax 시각화와 일반적인 다중분류 Softmax의 axis 차이를 구분할 수 있다.
  • Binary Classification, Multiclass Classification, Regression에서 Output Activation을 어떻게 선택하는지 연결할 수 있다.

Core Concept

활성화 함수는 왜 필요한가?

Linear z = Wx + b
→
Activation h = f(z)
→
Next Layer 새로운 Representation

신경망의 각 Layer에서는 먼저 Weight와 Bias를 이용한 선형 계산을 수행하고, 그 결과를 활성화 함수로 변환한 뒤 다음 Layer로 전달한다.

Activation이 없다면

Linear ↓ Linear ↓ Linear

여러 선형 변환을 이어도 전체를 다시 하나의 선형 변환으로 표현할 수 있다.

비선형 Activation이 있다면

Linear ↓ Non-linear Activation ↓ Linear

입력을 새로운 비선형 Feature Space로 변환할 수 있다.

ML 12와 연결

이전 MLP에서 Hidden Layer에 Sigmoid를 사용한 이유가 바로 Linear Layer 사이에 비선형성을 추가하기 위해서였다.

Source Code

6개 활성화 함수 정의

교안 원문 
def step_function(x):
    return np.where(x > 0, 1, 0)


def sigmoid(x):
    return 1 / (1 + np.exp(-x))


def tanh(x):
    return np.tanh(x)


def relu(x):
    return np.maximum(0, x)


def leaky_relu(x, alpha=0.01):
    return np.where(
        x > 0,
        x,
        alpha * x
    )


def softmax(x):
    # 오버플로우 방지를 위해 최대값 빼줌
    # x가 벡터일 때
    exp_x = np.exp(
        x - np.max(x)
    )

    return exp_x / np.sum(
        exp_x,
        axis=0
    )

Sigmoid

Sigmoid — 0과 1 사이의 부드러운 S Curve

def sigmoid(x):
    return 1 / (
        1 + np.exp(-x)
    )
출력 범위 0 ~ 1
x = 0 0.5
대표 연결 Binary Output
큰 음수 ≈ 0 → 0 0.5 → 큰 양수 ≈ 1

미분

σ'(x) = σ(x)(1-σ(x))

최대 Gradient는 약 0.25이며, 입력 절댓값이 커지면 Gradient가 0에 가까워진다.

Vanishing Gradient

깊은 Network에서 작은 Gradient가 반복적으로 곱해지면 앞쪽 Layer로 갈수록 Gradient가 매우 작아질 수 있다.

11

Tanh

Tanh — -1과 1 사이의 S Curve

def tanh(x):
    return np.tanh(x)
출력 범위 -1 ~ 1
x = 0 0
중심 Zero-centered
큰 음수 ≈ -1 → 0 0 → 큰 양수 ≈ 1

미분

tanh'(x) = 1 - tanh²(x)
주의

Sigmoid보다 0 중심이라는 장점이 있지만, 큰 양수·음수 영역에서 Gradient가 작아지는 Saturation과 Vanishing Gradient 문제는 여전히 존재한다.

ReLU — 음수는 0, 양수는 그대로

def relu(x):

ReLU(x) = max(0, x)

x > 0 x

장점

  • 계산 구조가 단순하다.

문제

Leaky ReLU

Leaky ReLU — 음수 영역에도 작은 Gradient 유지

함수 정의 
def leaky_relu(
    x,
    alpha=0.01

    return np.where(
        x > 0,
        x,

x > 0 x
x ≤ 0 αx
기본 α 0.01
교안 코드에서 꼭 구분

함수 정의의 기본값은 alpha=0.01이지만, 실제 Plot에서는 leaky_relu(x, 0.1)을 호출한다.

Default α = 0.01
≠
이번 그래프 α = 0.1
Dying ReLU 완화

음수 영역에서도 Gradient를 완전히 0으로 만들지 않고 작은 값 α를 유지하도록 설계한 ReLU 변형이다.

14

Softmax

Softmax — 여러 Logit을 확률 분포로 변환

교안 원문 
def softmax(x):

    exp_x = np.exp(
        x - np.max(x)
    )

    return exp_x / np.sum(
        exp_x,
        axis=0
    )
Logits [z1, z2, z3, ...]
→
exp e^z
→
Normalize / Σe^z
→
Probability 합 = 1
다른 함수와의 차이

Sigmoid나 ReLU는 각 원소를 독립적으로 변환할 수 있지만, Softmax의 각 출력값은 같은 Vector 안의 다른 모든 값과 함께 계산된다.

15

Numerical Stability

왜 Softmax에서 최대값을 빼는가?

큰 Logit [1000, 1001, 1002]
→
직접 exp() Overflow 위험
[1000, 1001, 1002]
− max
[-2, -1, 0]
→
안정적인 exp 계산

모든 Logit에서 동일한 상수를 빼도 Softmax의 상대적인 비율은 유지되므로 최대값을 빼서 수치적으로 안정적인 계산을 수행한다.

Selection Guide

문제 유형에 따른 Output Activation

Binary Classification Sigmoid
Dense(1) → 0 ~ 1

하나의 클래스 Probability로 해석한다.

Multiclass Classification Softmax
Dense(classes) → Σp = 1

각 클래스에 속할 Probability Distribution을 만든다.

Regression Linear
Dense(1) → 실수값

교안 흐름에서는 별도 Activation을 지정하지 않는다.

Common Mistakes

자주 하는 실수

01

활성화 함수는 단순히 신호를 켜고 끄는 함수라고 생각한다.

Step Function에는 잘 맞는 설명이지만, 현대 Neural Network에서는 입력 Representation을 비선형적으로 변환하는 역할까지 포함한다.

02

Layer를 많이 쌓으면 자동으로 비선형 Model이 된다고 생각한다.

Linear Transformation만 반복하면 전체를 하나의 Linear Transformation으로 합칠 수 있다.

03

Step Function을 Hidden Layer에서 그대로 사용하면 된다고 생각한다.

Gradient 기반 Backpropagation에 적합하지 않다.

04

Sigmoid가 모든 Layer에 가장 적절하다고 생각한다.

깊은 Hidden Layer에서는 Vanishing Gradient가 문제가 될 수 있다.

05

Tanh에는 Vanishing Gradient가 없다고 생각한다.

큰 양수·음수 영역에서는 Tanh도 Gradient가 0에 가까워진다.

06

ReLU에는 Gradient 문제가 없다고 생각한다.

음수 영역 Gradient가 0이어서 Dying ReLU가 발생할 수 있다.

07

이번 Leaky ReLU Plot의 α가 0.01이라고 생각한다.

함수 Default는 0.01이지만 실제 Plot은 0.1을 전달한다.

08

Softmax를 Sigmoid처럼 원소별 함수라고 생각한다.

Softmax는 같은 Vector 안의 모든 Logit을 함께 사용한다.

09

이번 Softmax Plot을 일반적인 Multiclass Softmax라고 생각한다.

이번에는 400개 x 값을 하나의 Vector로 보고 정규화한다.

10

Softmax에서 Shape만 보고 axis를 확인하지 않는다.

Softmax에서는 어느 축의 합을 1로 만들지 반드시 확인해야 한다.

구분

아래 오류들은 원본 Notebook에 저장된 Exception이 아니라, 동일 코드를 수정하거나 확장할 때 발생할 수 있는 대표적인 오류다.

    "-1",
    "0",
    "1"

문자열 배열은 np.exp(), np.tanh(), np.maximum() 등의 수치 연산에 적합하지 않다.

Activation Input → numeric dtype

overflow encountered in exp

매우 큰 절댓값이 들어오면 np.exp(-x) 계산이 불안정해질 수 있다.

3. Softmax Overflow

큰 Logit에 바로 np.exp()를 적용하면 Overflow가 발생할 수 있다.

x - np.max(x)

4. Softmax Axis 의미 오류

코드 자체는 실행되더라도 정규화할 축을 잘못 선택하면 Probability의 의미가 잘못될 수 있다.

Softmax는 Shape와 Axis를 함께 확인한다.

실무 연결

FFNN

다음 단원부터 실제 Keras Dense Layer에 Activation을 문자열로 지정한다.

Dense(1) → Linear Output

Backpropagation

Activation → Derivative → Gradient Flow

활성화 함수 선택은 순전파뿐 아니라 역전파 Gradient 전달에도 영향을 준다.

Interview Point

면접 포인트

Q1. 활성화 함수는 왜 필요합니까?

Linear Layer 사이에 비선형성을 추가하여 신경망이 복잡한 비선형 관계를 표현할 수 있도록 하기 위해 필요합니다.

Q2. Linear Layer만 여러 개 연결하면 왜 문제가 됩니까?

비선형 Activation이 없으면 여러 Linear Transformation을 하나의 Linear Transformation으로 합칠 수 있기 때문입니다.

Q3. Step Function의 단점은 무엇입니까?

임계값 기반 출력은 직관적이지만 Gradient 기반 Backpropagation 학습에 적합하지 않습니다.

Q4. Sigmoid의 출력 범위는 무엇입니까?

0과 1 사이이며 x=0일 때 0.5입니다.

Q5. Sigmoid의 대표적인 문제는 무엇입니까?

입력 절댓값이 큰 영역에서 Gradient가 0에 가까워져 깊은 Network에서 Vanishing Gradient를 유발할 수 있습니다.

Q6. Sigmoid와 Tanh의 차이는 무엇입니까?

Sigmoid는 0~1 범위이고, Tanh는 -1~1 범위이며 0을 중심으로 합니다.

Q7. ReLU의 수식은 무엇입니까?

max(0, x)입니다. 음수는 0, 양수는 입력값을 그대로 출력합니다.

Q8. Dying ReLU란 무엇입니까?

입력이 계속 음수 영역에 머물러 ReLU 출력과 Gradient가 0이 되고, 해당 뉴런의 Parameter가 거의 업데이트되지 않는 현상입니다.

Q9. Leaky ReLU는 Dying ReLU를 어떻게 완화합니까?

음수 영역을 완전히 0으로 만들지 않고 αx 형태의 작은 Gradient를 유지합니다.

Q10. 이번 Notebook의 Leaky ReLU alpha는 얼마입니까?

함수 정의의 기본값은 0.01이고, 실제 그래프를 그릴 때는 0.1을 전달합니다.

Q11. Softmax는 무엇을 합니까?

여러 Logit을 서로 비교하여 각 클래스 Probability로 변환하고, 결과 Probability의 총합을 1로 만듭니다.

Q12. Sigmoid와 Softmax의 차이는 무엇입니까?

Sigmoid는 각 값을 독립적으로 변환할 수 있지만, Softmax는 같은 Vector의 모든 값을 함께 사용하여 상대적인 Probability Distribution을 만듭니다.

Q13. Softmax에서 최대 Logit을 빼는 이유는 무엇입니까?

exponential 계산의 Overflow를 줄이고 수치적으로 안정적인 계산을 하기 위해서입니다.

Q14. Softmax에서 axis가 중요한 이유는 무엇입니까?

어느 차원을 하나의 Class Vector로 보고 Probability의 합을 1로 만들 것인지 결정하기 때문입니다.

Q15. 이번 Notebook의 Softmax 검토 메모는 무엇입니까?

현재 x.shape=(400,)인 Vector 전체를 하나의 클래스 Vector처럼 정규화하므로, 일반적인 (batch, classes) 구조에서 Sample별로 Softmax를 적용하는 방식과 다릅니다.

Q16. 문제 유형별 Output Activation을 설명해 주세요.

교안 흐름에서는 이진 분류는 Sigmoid, 다중 분류는 Softmax, 회귀는 별도의 Activation을 지정하지 않는 Linear Output으로 연결합니다.
