사용자 두 명이 공통으로 평가한 Movie가 적으면 Cosine Similarity가 낮거나 불안정하게 나타날 수 있다.

15

Cosine Similarity

Rating Vector의 방향이 비슷한 사용자를 찾는다

cosine(A,B) = (A · B) / (||A|| × ||B||)
User A [5, 1, 4, 0, 5, ...]
User B [5, 1, 5, 0, 4, ...]
Cosine Similarity ≠ Accuracy

0.56이라는 값은 추천 정확도 56%가 아니라 두 User Rating Vector의 방향 유사도다.

def get_recommend_items(user_id):
    '''
    user_id : 사용자 아이디
    user_id랑 가장 유사한 사용자에게
    user_id가 평점 5점을 준 아이템(추천 아이템)들을 반환하는 함수
    단,유사한 사용자가 이미 평점을 준 아이템은 제외한다
    '''

    #user_id 사용자가 평점을 준 아이템(영화)의 인덱스들 구하기
    rank_items_by_user_id=user_item_matrix.loc[
        user_id,
        :
    ]

    #MovieID와 rank를 컬럼 인덱스로 하고 정수 인덱스를 행 인덱스로 하는 데이타 프레임으로 변경
    df_rank_items_of_user_id=rank_data_of_1th.to_frame(
        name='rank'
    ).reset_index()

    #평점이 5인 아이템만 추천
    recommend_items=df_rank_items_of_user_id.query(
        'rank ==5'
    )['MovieID'].values

    #user_id와 가장 유사도가 높은 사용자
    #user_with_high_similarity=np.argmax(user_similarity[user_id-1,:])+1
    index_cosSim = list(
        enumerate(
            user_similarity[
                user_id-1
            ]
        )
    )

    index_cosSim_reverse = sorted(
        index_cosSim,
        key=lambda x: x[1],
        reverse=True
    )

    user_with_high_similarity=index_cosSim_reverse[1]

    print(
        'user_with_high_similarity:',
        user_with_high_similarity
    )

    #가장 유사도가 높은 사용자가 평점을 매긴 아이템들
    items_of_user_with_high_similarity=user_item_matrix.loc[
        user_with_high_similarity[0],
        :
    ].to_frame(
        name='rank'
    ).reset_index().query(
        'rank > 0'
    )['MovieID'].values

    #가장 유사도가 높은 사용자가 추천 아아템중 평점을 매기지 않은 아이템들
    recommend_items_no_rank =[]

    for item in recommend_items:
        if item not in items_of_user_with_high_similarity:
            recommend_items_no_rank.append(
                item
            )

    return recommend_items_no_rank

추가 원문 대조

함수 안에는 두 가지 핵심 의미 연결 문제가 있다

① 입력 user_id의 Rating을 읽지만 사용하지 않음 
rank_items_by_user_id =
    user_item_matrix.loc[user_id, :]

바로 다음 Candidate 생성에서는 rank_items_by_user_id가 아니라 rank_data_of_1th를 사용한다.

② Array Position을 UserID Label처럼 사용 
user_with_high_similarity =
    index_cosSim_reverse[1]

user_item_matrix.loc[
    user_with_high_similarity[0],
    :
]

Tuple 첫 값은 enumerate()에서 얻은 Array Position인데, 이를 Pandas .loc[]의 UserID처럼 사용한다.

원본을 수정한 코드로 바꾸어 제시하지 않는다.

학습 매거진에서는 “원본은 이렇게 작성되어 있고, 왜 의미상 주의가 필요한가”를 분리해서 보여준다.
