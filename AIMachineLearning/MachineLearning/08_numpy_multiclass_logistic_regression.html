NumPy 다중 로지스틱 회귀

ML 07의 이진 로지스틱 회귀를 3개 Class를 구분하는 Multiclass Classification으로 확장합니다. Binary Classification의 Sigmoid + Binary Cross Entropy + Threshold 구조가 이번 단원에서는 Softmax + Categorical Cross Entropy + argmax 구조로 바뀝니다. 특히 (N,2) @ (2,3) → (N,3)이라는 Matrix Shape 흐름을 이해하는 것이 핵심입니다.

X → XW+b → Softmax → Class Probabilities → CCE → P-Y → Update → argmax

학습 목표

  • Binary Classification과 Multiclass Classification의 차이를 설명할 수 있다.
  • X_train=(12,2), y_train=(12,1)의 의미를 설명할 수 있다.
  • Class Index를 One-Hot Encoding하여 (12,3)으로 바꾸는 이유를 설명할 수 있다.
  • W=(2,3), b=(1,3)이 필요한 이유를 설명할 수 있다.
  • X @ W → Z의 Matrix Multiplication Shape을 추적할 수 있다.
  • Softmax가 Class별 Probability Distribution을 만드는 원리를 이해할 수 있다.
  • Softmax에서 최대값을 빼는 Numerical Stability 기법을 설명할 수 있다.
  • keepdims=True가 Broadcasting에 왜 필요한지 설명할 수 있다.
  • Categorical Cross Entropy Loss를 이해할 수 있다.
  • Softmax + CCE Gradient의 핵심이 P-Y라는 것을 설명할 수 있다.
  • dW=(2,3), db=(1,3) Shape을 설명할 수 있다.
  • Binary의 Threshold와 Multiclass의 argmax() 차이를 설명할 수 있다.
  • meshgrid와 contourf를 이용한 Class별 Decision Region 시각화 흐름을 이해할 수 있다.

09

Activation

Softmax — Class별 Probability 만들기

def softmax(z):

    exp_z = np.exp(
        z
        - np.max(
            z,
            axis=1,
            keepdims=True
        )
    )

    return exp_z / np.sum(
        exp_z,
        axis=1,
        keepdims=True
    )
Logits [2.0, 1.0, 0.2]
→
Softmax [p0, p1, p2]
→
Sum p0+p1+p2 = 1

왜 Softmax 전에 최대값을 빼는가?

큰 Logit [1000, 2000, 3000] ↓ np.exp(z)

→

Optimizer

Full-Batch Gradient Descent

W (2,3) ↔ dW (2,3)

왜 Full-Batch인가?

한 Epoch마다 12개의 Training Sample 전체를 사용해 하나의 Gradient를 계산하고 Parameter를 한 번 Update하기 때문입니다.

16

Training Loop

NumPy로 직접 구현한 fit()

losses = []

for epoch in range(epochs + 1):

    # 1. Forward
    z = X_train @ W + b

    # 2. Softmax Probability
    y_pred = softmax(z)

    # 3. Categorical Cross Entropy
    loss = -np.mean(
        np.sum(
            y_onehot
            * np.log(
                y_pred + 1e-8
            ),
            axis=1
        )
    )

    losses.append(loss)

    # 4. Gradient
    dW = (
        X_train.T
        @
        (
            y_pred - y_onehot
        )
    ) / n_samples

    db = np.mean(
        y_pred - y_onehot,
        axis=0,
        keepdims=True
    )

    # 5. Update
    W -= learning_rate * dW
    b -= learning_rate * db

    # 6. Log
    if epoch % 100 == 0:
        print(
            f"Epoch {epoch:4d}: "
            f"Loss = {loss:.4f}"
        )
Forward → Softmax → CCE → P-Y → Gradient → Update → Repeat

Common Mistakes

자주 하는 실수

1. Softmax를 Sigmoid와 완전히 같은 함수라고 생각한다

Softmax는 여러 Class Score를 서로 비교해 합이 1인 분포를 만듭니다.

2. W Shape을 여전히 (2,)라고 생각한다

Class가 3개이므로 W는 (2,3)입니다.

3. y_train을 그대로 CCE와 비교한다

원본은 One-Hot Target (12,3)을 사용합니다.

4. One-Hot Encoding을 Feature 전처리라고 생각한다

이번에는 Target Label 표현을 바꾸는 과정입니다.

5. Softmax에서 최대값을 빼면 결과가 달라진다고 생각한다

Probability 비율은 유지되고 Numerical Stability만 좋아집니다.

6. keepdims=True가 단순 옵션이라고 생각한다

올바른 Broadcasting Dimension을 유지하는 핵심입니다.

7. Multiclass에도 Threshold 0.5를 적용한다

이번 원본은 가장 큰 Probability의 Index를 argmax로 선택합니다.

8. argmax가 Probability를 반환한다고 생각한다

가장 큰 값의 위치, 즉 Class Index를 반환합니다.

9. Accuracy 100%를 완벽한 일반화 성능으로 본다

Test Sample은 3개뿐입니다.

10. 저장되지 않은 Epoch 1000 Loss를 추측한다

Source와 Saved Output 차이를 그대로 구분해야 합니다.

Interview

면접 포인트

Q1. Softmax Regression이란 무엇인가요?

Logistic Regression을 다중 Class로 확장하여 각 Class의 Logit을 Softmax Probability로 변환하는 Multiclass Classification 모델입니다.

Q2. Sigmoid와 Softmax의 차이는?

Sigmoid는 각각의 값을 0~1로 변환할 수 있고, Softmax는 여러 Class Score를 함께 정규화해 합이 1인 Probability Distribution을 만듭니다.

Q3. W가 왜 (2,3)인가요?

Feature가 2개이고 Class가 3개이므로 Feature와 Class의 모든 조합에 Weight가 필요하기 때문입니다.

Q4. b가 왜 (1,3)인가요?

Class 0, 1, 2마다 Bias 하나씩 필요하기 때문입니다.

Q5. One-Hot Encoding은 왜 하나요?

Softmax Output과 같은 Class Dimension을 가진 Target Matrix를 만들어 CCE와 Gradient를 계산하기 위해서입니다.

Q6. np.eye(3)[y]는 무엇을 하나요?

Identity Matrix의 Row를 Class Index로 선택하여 Class 번호를 One-Hot Vector로 변환합니다.

Q7. Softmax에서 최대값을 왜 빼나요?

exp 계산에서 Overflow를 줄여 Numerical Stability를 확보하기 위해서입니다.

Q8. 최대값을 빼도 Probability가 같은 이유는?

모든 Logit에 같은 상수를 빼면 생기는 공통 지수항이 Softmax의 분자와 분모에서 상쇄되기 때문입니다.

Q9. keepdims=True는 왜 필요한가요?

Row Maximum을 (N,1) 형태로 유지하여 (N,C) Logit Matrix와 올바르게 Broadcasting하기 위해서입니다.

Q10. Categorical Cross Entropy란?

One-Hot Target과 Multiclass Probability Distribution 사이의 손실을 측정하는 대표적인 Classification Loss입니다.

Q11. Softmax + CCE Gradient의 핵심은?

Logit에 대한 Error 항이 P-Y 형태로 정리됩니다.

Q12. dW Shape은 왜 (2,3)인가요?

X.T=(2,N)와 P-Y=(N,3)를 Matrix Multiplication하면 (2,3)이 되며 W와 동일한 Shape입니다.

Q13. Multiclass에서는 왜 Threshold가 아니라 argmax를 쓰나요?

여러 Class Probability 중 가장 높은 값을 가진 Class Index를 선택하기 때문입니다.

Q14. Accuracy 100%면 완벽한 Model인가요?

아닙니다. 이번 Test Dataset은 Class별 한 개씩 총 3개 Sample뿐입니다.

Q15. 이번 Optimizer는 무엇인가요?

전체 Training Sample을 사용해 Gradient를 계산하는 Full-Batch Gradient Descent를 직접 구현했습니다.

Q16. 이 구조가 Neural Network와 어떻게 연결되나요?

Dense Layer의 출력 Logit을 Softmax로 변환하고 Categorical Cross Entropy를 사용하는 다중분류 출력 구조와 직접 연결됩니다.
