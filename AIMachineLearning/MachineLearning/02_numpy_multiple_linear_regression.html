ML 02 Notebook 37 NumPy Multiple Regression Shape

NumPy로 구현하는 다중 선형회귀

ML 01에서는 하나의 Feature와 하나의 Weight를 이용해 단순 선형회귀를 직접 구현했습니다. 이번 단원에서는 Feature를 X1, X2, X3 세 개로 확장하면서 입력 X를 행렬로, Weight를 Vector로 표현합니다. np.dot(X, W) + b로 예측하고, MSE와 Feature별 Gradient를 계산하여 Weight Vector 전체를 직접 학습합니다.

Scalar → Vector → Matrix × Vector → Feature별 Gradient → Weight Vector Update

학습 목표

  • 단순 선형회귀와 다중 선형회귀의 차이를 설명할 수 있다.
  • X.shape = (100, 3)을 100개의 Sample과 3개의 Feature로 해석할 수 있다.
  • Feature가 3개이면 W.shape = (3,)이 되는 이유를 설명할 수 있다.
  • np.dot(X, W)의 Matrix-Vector 연산과 Shape 변화를 설명할 수 있다.
  • (100,)과 (100, 1)의 차이를 이해할 수 있다.
  • Gradient 계산에서 reshape(-1, 1)이 필요한 이유를 설명할 수 있다.
  • mean(axis=0)을 사용하면 Feature별 Gradient 3개가 남는 이유를 설명할 수 있다.
  • MSE → Gradient → Parameter Update의 학습 흐름을 다중 선형회귀에서도 설명할 수 있다.
  • 이번 NumPy 직접 구현이 다음 단원의 scikit-learn 학습으로 어떻게 연결되는지 설명할 수 있다.

Reshape

왜 reshape(-1, 1)이 필요한가?

reshape 전

Error = (100,)
(100,) × (100,3)

원하는 Broadcasting 불가

→

reshape 후

Error = (100,1)
(100,1) × (100,3)

결과 (100,3) 

error = y_pred - y

error.shape
# (100,)

error = error.reshape(-1, 1)

error.shape
# (100, 1)
-1의 의미

reshape(-1, 1)에서 -1은 전체 원소 수를 기준으로 행 개수를 NumPy가 자동 계산하라는 의미입니다.

08

Axis

mean(axis=0)은 무엇을 하는가?

Error × X
X1 방향 X2 방향 X3 방향
e₁X₁₁ e₁X₁₂ e₁X₁₃
e₂X₂₁ e₂X₂₂ e₂X₂₃
... ... ...
e₁₀₀X₁₀₀,₁ e₁₀₀X₁₀₀,₂ e₁₀₀X₁₀₀,₃
shape = (100, 3)
mean(axis=0) ↓
dW [dW1, dW2, dW3] shape = (3,)

axis=0은 100개 Sample 방향으로 평균을 계산하고, 열인 Feature 3개는 유지합니다. 따라서 W1, W2, W3 각각에 대응하는 Gradient 3개가 남습니다.

Notebook Code

원본 Notebook의 핵심 코드

교안 원문 구조

아래 코드는 원본 Notebook의 실행 흐름을 임의로 다른 알고리즘으로 변경하지 않고 정리한 것입니다.

1. Library

import numpy as np
import matplotlib.pyplot as plt

2. Dataset 생성

# 독립변수가 3개(X1, X2, X3),
# 정답 선형회귀식은
# y = 3*X1 + 2*X2 + 1*X3 + 5라고 가정

np.random.seed(42)

n_samples = 100

X = np.random.rand(
    n_samples,
    3
) * 10

print(X.shape)

X[:5]

3. Target 생성

W_true = np.array([3, 2, 1])

b_true = 5

noise = np.random.randn(
    n_samples
)

y = (
    np.dot(X, W_true)
    + b_true
    + noise
)

y.shape

y[:5]

4. Parameter 초기화

W = np.random.rand(3)

b = np.random.rand()

W, b

5. Hyperparameter 설정

learning_rate = 0.001

epochs = 25000

6. Training Loop

for epoch in range(epochs):

    # 예측값 계산
    # (100,3) @ (3,) + scalar
    # → (100,)
    y_pred = np.dot(X, W) + b


    # 손실 함수: MSE
    loss = np.mean(
        (y_pred - y) ** 2
    )


    # Gradient
    #
    # error:
    # (100,)
    #
    # reshape:
    # (100,1)
    #
    # X:
    # (100,3)
    #
    # 결과:
    # (100,3)
    #
    # axis=0 평균:
    # (3,)
    dW = 2 * np.mean(
        (y_pred - y).reshape(-1, 1)
        * X,
        axis=0
    )

    db = 2 * np.mean(
        y_pred - y
    )


    # Parameter Update
    W -= learning_rate * dW

    b -= learning_rate * db


    # 중간 결과 출력
    if epoch % 1000 == 0:
        print(
            f"Epoch {epoch:4d}: "
            f"Loss = {loss:.4f}, "
            f"W = {W}, "
            f"b = {b:.4f}"
        )

7. 최종 Parameter 출력

print(
    f"\n학습 완료: "
    f"W = {W}, "
    f"b = {b:.4f}"
)

12

Training Flow

한 Epoch에서는 무엇이 일어나는가?

  1. 1
    Prediction y_pred = np.dot(X, W) + b

    현재 Weight Vector와 Bias를 이용해 100개의 예측값을 계산합니다.

  2. 2
    Error y_pred - y

    각 Sample의 예측값과 실제값 차이를 계산합니다.

  3. 3
    MSE mean((y_pred - y)²)

    현재 모델 전체의 Training Loss를 계산합니다.

  4. 4
    Reshape error.reshape(-1, 1)

    Feature별 Gradient 계산이 가능하도록 Error를 Column Vector로 바꿉니다.

  5. 5
    dW mean(error × X, axis=0)

    W1, W2, W3에 대응하는 Gradient 3개를 계산합니다.

  6. 6
    db mean(error)

    Bias에 대한 Gradient를 계산합니다.

  7. 7
    Parameter Update W -= learning_rate * dW b -= learning_rate * db

    Loss가 감소하는 방향으로 Parameter를 변경합니다.

  8. 8
    Repeat

    위 과정을 25,000 Epoch 동안 반복합니다.

18

Common Mistakes

자주 하는 실수

1. (100,3)의 3을 Sample 수라고 생각한다

100이 Sample 수이고, 3이 Feature 수입니다.

2. W를 하나의 숫자로 생각한다

Feature가 3개이므로 W 역시 (3,) Vector입니다.

3. W_true와 W를 혼동한다

W_true는 Dataset 생성용, W는 실제 학습 대상입니다.

4. np.dot()을 단순 원소별 곱셈으로 생각한다

이번 코드의 np.dot(X, W)은 Matrix-Vector Multiplication입니다.

5. reshape(-1,1)을 의미 없는 코드로 생각한다

Error를 Column Vector로 만들어 X와 Feature별로 Broadcasting하기 위해 필요합니다.

6. axis=0을 빼도 된다고 생각한다

Sample 방향으로 평균을 계산하여 Feature별 Gradient 세 개를 남기기 위해 필요합니다.

7. MSE를 Accuracy로 읽는다

MSE는 회귀 Loss이며 퍼센트 정확도가 아닙니다.

8. Training Loss만 보고 일반화 성능을 판단한다

이번 Notebook에는 독립적인 Test Dataset이 없습니다.

1. Learning Rate 비교

2. Epoch 비교

실제 프로젝트에서는 독립적인 Test Dataset을 두어 일반화 성능을 확인합니다.

4. R² / MAE / RMSE

MSE Training Loss 이외의 회귀 평가 Metric을 추가로 비교할 수 있습니다.

5. StandardScaler

Feature Scale이 크게 다른 실제 Dataset에서는 Gradient 기반 모델의 학습 안정성과 속도에 영향을 줄 수 있습니다.

6. scikit-learn 비교

Interview

면접 포인트

Q1. 단순 선형회귀와 다중 선형회귀의 차이는 무엇인가요?

단순 선형회귀는 독립변수 하나를 사용하고, 다중 선형회귀는 둘 이상의 독립변수를 사용합니다. 다중 선형회귀는 W1X1 + W2X2 + ... + WnXn + b 형태로 표현할 수 있습니다.

Q2. X.shape=(100,3)은 무엇을 의미하나요?

100개의 Sample과 3개의 Feature를 가진 2차원 입력행렬이라는 뜻입니다.

Q3. 왜 W.shape=(3,)인가요?

Feature가 3개이고 각 Feature마다 학습해야 하는 Weight가 하나씩 필요하기 때문입니다.

Q4. np.dot(X,W)의 결과 Shape은 무엇인가요?

X가 (100,3), W가 (3,)이므로 Matrix-Vector Multiplication 결과는 (100,)입니다.

Q5. 왜 error를 reshape(-1,1) 하나요?

error (100,)을 X (100,3)와 Feature별로 곱하기 위해 (100,1) Column Vector로 변경합니다. 이렇게 하면 NumPy Broadcasting으로 결과 (100,3)을 만들 수 있습니다.

Q6. mean(axis=0)은 왜 사용하나요?

100개의 Sample 방향으로 평균을 계산하고 Feature 3개의 축은 유지하여 dW1, dW2, dW3 세 Gradient를 얻기 위해 사용합니다.

Q7. Parameter와 Hyperparameter의 차이는 무엇인가요?

W와 b는 데이터로부터 학습되는 Parameter이고, Learning Rate와 Epoch는 개발자가 학습 전에 결정하는 Hyperparameter입니다.

Q8. Training Loss가 낮으면 좋은 모델이라고 볼 수 있나요?

Training Dataset에 대해서는 오차가 작다는 의미지만, 새로운 데이터에 대한 일반화 성능을 판단하려면 Validation 또는 Test Dataset 평가가 추가로 필요합니다.

Q9. 다중 선형회귀와 Neural Network는 어떻게 연결되나요?

다중 선형회귀의 XW+b 연산은 Neural Network Dense Layer의 기본 선형 연산과 연결됩니다. 신경망에서는 여러 Output Node를 위해 Weight가 Vector에서 Matrix로 확장되고 비선형 활성화 함수가 추가됩니다.

Q10. 이번 Notebook에서 Test Score가 없는 이유는 무엇인가요?

이번 실습의 목적은 모델 성능 비교보다 Matrix와 Vector를 이용한 다중 선형회귀 및 Gradient 계산 원리를 직접 구현하는 것이기 때문입니다.

오늘의 암기 포인트

Model ŷ = XW + b
X (100,3) @ W (3,) → y_pred (100,)
Error (100,) → reshape → (100,1) × X (100,3) → dW (3,)
  • X.shape=(100,3)은 Sample 100개, Feature 3개다.
  • Feature 3개이므로 W도 Weight 3개를 가진다.
  • Prediction은 np.dot(X,W)+b다.
  • Loss는 MSE다.
  • error는 Gradient 계산 전에 (100,1)로 reshape한다.
  • mean(axis=0) 결과는 Feature별 Gradient (3,)다.
