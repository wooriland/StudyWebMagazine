Common Mistakes

자주 하는 실수

1. Iris는 무조건 Classification이라고 생각한다

문제 유형은 실제 Target을 보고 결정합니다.

2. iris.target이 이번 y라고 생각한다

실제 y는 petal width입니다.

3. 원본의 “분류 문제” 문장을 그대로 외운다

실제 코드와 검토 메모를 함께 봐야 합니다.

4. R²를 Accuracy라고 부른다

둘은 다른 Metric입니다.

5. score()는 항상 Accuracy라고 생각한다

Regressor의 score()는 R²를 반환합니다.

6. 큰 coefficient = 절대적 Feature Importance라고 생각한다

Scale과 Feature 관계도 함께 봐야 합니다.

7. Decision Tree가 더 복잡하니 더 좋다고 생각한다

이번 실행에서는 LinearRegression보다 낮습니다.

8. RandomForest가 이번에 가장 높으므로 항상 최고라고 생각한다

한 번의 Split 결과입니다.

9. Test Set을 계속 Model Selection에 사용한다

실무에서는 Validation 또는 Cross Validation이 필요합니다.

10. 새 Sample을 (3,)으로 Predict한다

일반적으로 (1,3)의 2D 입력이 필요합니다.

Interview

면접 포인트

Q1. Iris Dataset은 분류 Dataset 아닌가요?

일반적으로 품종을 Target으로 사용하면 Classification입니다. 하지만 이번 Notebook에서는 연속형 petal width를 Target으로 사용하므로 Regression입니다.

Q2. 문제 유형은 무엇으로 결정하나요?

Dataset 이름보다 실제로 예측하려는 Target의 의미와 값의 형태를 보고 판단합니다.

Q3. 이번 X와 y는 무엇인가요?

X는 sepal length, sepal width, petal length이고 y는 petal width입니다.

Q4. X.shape=(150,3)은 무엇인가요?

150개의 Sample과 3개의 Feature를 가진 입력행렬입니다.

Q5. Train/Test Shape은?

X_train은 (120,3), X_test는 (30,3)입니다.

Q6. LinearRegression Weight는 몇 개인가요?

Feature가 3개이므로 Weight도 3개입니다.

Q7. 이번 LinearRegression의 R²는?

저장된 출력 기준 약 0.9271입니다.

Q8. R² 0.927은 Accuracy 92.7%인가요?

아닙니다. R²는 Regression의 결정계수이며 Classification Accuracy와 다른 Metric입니다.

Q9. Regressor의 score()는 무엇을 반환하나요?

이번 scikit-learn Regressor들의 score()는 R²를 반환합니다.

Q10. predict(X_test)의 Shape은 어떻게 변하나요?

입력 X_test는 (30,3)이고, 출력 y_pred는 (30,)입니다.

Q11. DecisionTree의 실제 저장 R²는?

약 0.8453입니다. 원본 주석의 약 0.87과 저장된 실제 출력을 구분해야 합니다.

Q12. RandomForest의 n_estimators=100은 무엇인가요?

Forest를 구성하는 Tree Estimator의 수입니다.

Q13. 복잡한 Model이 항상 더 좋은가요?

아닙니다. 이번 실행에서도 DecisionTree와 XGBoost가 LinearRegression보다 낮은 Test R²를 보입니다.

Q14. 이번 결과만으로 RandomForest를 최종 모델로 선택해도 되나요?

한 번의 Train/Test Split 결과이므로 실무에서는 Cross Validation과 Hyperparameter 검증 등을 추가하는 것이 좋습니다.

오늘의 암기 포인트

Iris → petal width → Regression
X (150,3) → Train (120,3) + Test (30,3) → y_pred (30,)
  • Iris Dataset이라고 해서 항상 Classification은 아니다.
  • 이번 y는 연속형 petal width다.
  • X는 3개의 Feature를 사용한다.
  • LinearRegression의 Weight도 3개다.
  • Regressor의 score()는 R²다.
  • R²와 Accuracy는 다르다.
  • 새 Sample 하나는 (1,3) 구조로 생각한다.
