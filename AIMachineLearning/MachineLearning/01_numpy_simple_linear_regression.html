ML 01 Notebook 36 NumPy Regression

NumPy로 구현하는 단순 선형회귀

이번 단원에서는 ŷ = WX + b 형태의 단순 선형회귀 모델을 NumPy만 사용하여 직접 구현합니다. 이미 완성된 머신러닝 라이브러리에 학습을 맡기지 않고, 데이터 생성 → 예측 → MSE 계산 → Gradient 계산 → W와 b 업데이트 과정을 직접 코드로 작성하면서 머신러닝에서 말하는 학습이 실제로 어떻게 이루어지는지 확인합니다.

수식 → NumPy → 직접 학습 → Loss 감소 → 회귀선 완성

학습 목표

  • 단순 선형회귀의 모델 식 ŷ = WX + b에서 X, W, b, ŷ의 의미를 설명할 수 있다.
  • X.shape = (100, 1)이 100개의 관측치와 1개의 Feature를 의미한다는 것을 설명할 수 있다.
  • 실제값과 예측값의 차이를 MSE로 계산하는 이유를 설명할 수 있다.
  • MSE를 W와 b에 대해 미분하여 dW, db를 구하는 흐름을 이해할 수 있다.
  • Learning Rate를 이용한 Gradient Descent로 W와 b가 반복적으로 갱신되는 과정을 설명할 수 있다.
  • Parameter와 Hyperparameter를 구분할 수 있다.
  • 학습 결과의 W, b, Loss와 최종 회귀선을 올바르게 해석할 수 있다.
  • 이번 단원의 Scalar Weight가 다음 단원의 Vector Weight로 어떻게 확장되는지 설명할 수 있다.

02

Core Concept

단순 선형회귀의 핵심 개념

Model

ŷ = WX + b

X

Feature / 입력값

모델이 예측을 수행하기 위해 전달받는 독립변수입니다. 이번 실습에서는 Feature가 하나입니다.

W

Weight / 가중치

X가 출력값에 얼마나 영향을 주는지를 나타냅니다. 단순 선형회귀에서는 직선의 기울기로 해석할 수 있습니다.

b

Bias / 편향

X가 0일 때 모델이 갖는 기준값입니다. 단순 선형회귀에서는 y축 절편입니다.

ŷ

Prediction / 예측값

현재 W와 b를 이용해 모델이 계산한 예측 결과입니다.

y

Target / 실제값

모델이 맞혀야 하는 실제 정답 데이터입니다.

Loss

MSE

현재 모델의 예측값과 실제값이 얼마나 차이 나는지를 나타냅니다.

09

Notebook Code

원본 Notebook의 핵심 코드

교안 원문 코드

아래 코드는 Notebook 36의 핵심 학습 흐름을 원문 구조 그대로 정리한 것입니다.

1. Library

import numpy as np
import matplotlib.pyplot as plt

2. X 생성

# y = 5x + 10이 정답 회귀선이라고 하자
# 1. 학습에 사용할 관측치 데이터 생성

np.random.seed(0)

X = np.random.rand(100, 1) * 10

3. y 생성

# 2. 학습에 사용할 정답 데이터 생성

W_true = 5
b_true = 10

noise = np.random.randn(100, 1)

y = W_true * X + b_true + noise

4. W와 b 초기화

# 3. 초기 가중치와 바이어스 랜덤하게 설정

W = np.random.rand()
b = np.random.rand()

5. Hyperparameter

# 4. 하이퍼파라미터 설정

learning_rate = 0.001
epochs = 10000

6. Training Loop

# 5. 학습

for epoch in range(epochs):

    # 예측값 계산
    y_pred = W * X + b

    # 손실 함수: 평균제곱오차(MSE)
    loss = np.mean((y_pred - y) ** 2)

    # 경사 계산
    dW = np.mean(2 * (y_pred - y) * X)
    db = np.mean(2 * (y_pred - y))

    # 파라미터 업데이트
    W -= learning_rate * dW
    b -= learning_rate * db

    # 100번마다 출력
    if epoch % 100 == 0:
        print(
            f"Epoch {epoch:4d}: "
            f"Loss = {loss:.4f}, "
            f"W = {W:.4f}, "
            f"b = {b:.4f}"
        )

7. 최종 결과

print(
    f"\n학습 완료: "
    f"W = {W:.4f}, "
    f"b = {b:.4f}"
)

8. 결과 시각화

plt.scatter(
    X,
    y,
    label='Observation data'
)

plt.plot(
    X,
    W * X + b,

plt.xlabel('X')

plt.title('Simple Linear Regression')

Training

한 Epoch에서 무슨 일이 일어나는가?

  1. 1
    Prediction y_pred = W * X + b

    현재 W와 b를 이용해 100개 X에 대한 예측값을 계산합니다.

  2. 2
    Loss np.mean((y_pred - y) ** 2)

    예측값과 실제값의 평균 제곱 오차를 계산합니다.

  3. 3
    Gradient dW / db

    W와 b가 Loss에 미치는 영향을 편미분으로 계산합니다.

  4. 4
    Update W -= lr * dW b -= lr * db

    Loss가 감소하는 방향으로 Parameter를 조금 이동시킵니다.

  5. 5
    Repeat

    같은 과정을 10,000 Epoch 동안 반복합니다.

11

Loss & Gradient

MSE와 Gradient 연결

Prediction
ŷ = WX + b
MSE
MSE = 평균((ŷ - y)²)
Gradient for W
dW = 평균(2 × (ŷ - y) × X)
Gradient for b
db = 평균(2 × (ŷ - y))
왜 dW에는 X가 있고 db에는 X가 없는가?

WX + b를 W에 대해 미분하면 X가 남지만, b에 대해 미분하면 1이 되기 때문입니다.

Common Mistakes

자주 하는 실수

1. W_true와 W를 같은 값으로 생각한다

W_true는 Synthetic Dataset을 만들기 위한 숨겨진 정답이고, W는 모델이 학습으로 찾아가는 Parameter입니다.

2. b_true와 b를 같은 값으로 생각한다

b_true는 데이터 생성용, b는 학습 대상입니다.

3. MSE를 Accuracy로 해석한다

MSE는 회귀 문제의 손실값이지 정답 비율이 아닙니다.

4. Loss가 반드시 0이어야 한다고 생각한다

Noise가 존재하기 때문에 모든 관측치를 하나의 직선으로 정확하게 맞추는 것은 목적이 아닙니다.

5. b가 정확히 10이 아니므로 실패했다고 판단한다

모델은 데이터 생성에 사용한 숫자를 찾는 것이 아니라, 실제로 주어진 Noise 포함 관측 데이터를 가장 잘 설명하는 직선을 찾습니다.

6. Epoch와 Update를 항상 같은 의미로 외운다

이번 Full-Batch 구현에서는 1 Epoch에 한 번 Update하지만, Mini-Batch 학습에서는 한 Epoch 안에서 여러 번 Parameter Update가 발생합니다.

더 위험한 경우 — 오류가 나지 않는 Shape Bug

원본은 다음처럼 Shape을 맞춥니다. 

X.shape
# (100, 1)

noise.shape
# (100, 1)

그런데 Noise를 실수로 다음처럼 만들면 

noise = np.random.randn(100)

Shape은 (100,)이 됩니다. NumPy Broadcasting 때문에 예상하지 못한 2차원 배열로 확장될 수 있으므로 주의해야 합니다.

Underfitting

직접 평가하지 않음

Performance

성능 개선 관점에서 무엇을 볼 수 있는가?

보완 학습

아래 내용은 원본 Notebook의 필수 구현이 아니라 이후 실습으로 확장할 수 있는 학습 방향입니다.

1. Learning Rate 비교

0.1, 0.01, 0.001처럼 값을 바꾸면서 Loss의 수렴 속도를 비교할 수 있습니다.

2. Epoch 수 비교

학습이 충분히 수렴하기 전에 종료한 경우와 충분히 학습한 경우를 비교할 수 있습니다.

3. Train/Test Split

실제 머신러닝 프로젝트에서는 학습 데이터와 테스트 데이터를 분리해 일반화 성능을 확인해야 합니다.

4. R² / MAE / RMSE

이후 실제 회귀 문제에서는 Training Loss뿐 아니라 별도의 회귀 평가 Metric을 함께 확인해야 합니다.

5. scikit-learn과 비교

직접 구현 결과를 이후 LinearRegression과 비교하면 라이브러리가 추상화하는 부분을 이해하기 쉽습니다.

Interview

면접 포인트

Q1. 단순 선형회귀란 무엇인가요?

하나의 독립변수와 연속형 종속변수 사이의 관계를 직선 형태로 모델링하는 회귀 알고리즘입니다. 기본 모델은 ŷ = WX + b이며, 학습을 통해 W와 b를 찾습니다.

Q2. Weight와 Bias의 차이는 무엇인가요?

Weight는 입력 Feature가 출력에 미치는 영향의 크기이며, Bias는 입력이 0이어도 모델이 가질 수 있는 기준값입니다. 단순 선형회귀에서는 각각 기울기와 절편에 해당합니다.

Q3. MSE란 무엇인가요?

실제값과 예측값의 차이를 제곱한 뒤 평균한 값입니다. 회귀 문제에서 대표적으로 사용하는 손실함수입니다.

Q4. 왜 오차를 제곱하나요?

양수와 음수 오차가 서로 상쇄되는 것을 막고, 큰 오차에 더 큰 패널티를 주기 위해서입니다.

Q5. Gradient Descent란 무엇인가요?

손실함수의 Gradient를 계산하고 손실이 감소하는 반대 방향으로 Parameter를 반복적으로 갱신하여 손실이 작은 지점을 찾는 최적화 방법입니다.

Q6. Learning Rate란 무엇인가요?

Gradient를 이용해 Parameter를 갱신할 때 한 번에 얼마나 이동할지를 결정하는 Hyperparameter입니다.

Q7. Parameter와 Hyperparameter의 차이는 무엇인가요?

Parameter는 W와 b처럼 데이터로부터 학습되는 값이며, Hyperparameter는 Learning Rate와 Epoch처럼 개발자가 학습 전에 설정하는 값입니다.

Q8. X.shape=(100,1)은 무엇을 의미하나요?

100개의 관측치와 1개의 Feature를 가진 2차원 입력 데이터라는 의미입니다.

Q9. 왜 Test Dataset이 없나요?

이번 Notebook은 일반화 성능 평가보다 NumPy로 Gradient Descent를 직접 구현하고 학습 원리를 이해하는 것이 목적이기 때문입니다.

Q10. Training Loss가 낮으면 좋은 모델인가요?

Training 데이터에서는 좋은 결과일 수 있지만, 새로운 데이터에서도 잘 동작하는지는 Validation/Test Dataset을 별도로 평가해야 알 수 있습니다.

오늘의 암기 포인트

Model ŷ = WX + b
Predict → Loss → Gradient → Update → Repeat
  • X는 입력, y는 실제 정답이다.
  • W와 b는 모델이 학습하는 Parameter다.
  • Learning Rate와 Epoch는 Hyperparameter다.
  • 이번 Loss는 MSE다.
  • MSE는 Accuracy가 아니다.
  • X.shape=(100,1)은 관측치 100개, Feature 1개다.
