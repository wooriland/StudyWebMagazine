08 · POSITIONAL ENCODING

위치 인코딩 — Token의 순서를 Vector에 추가하기

Transformer에는 LSTM처럼 이전 시점에서 다음 시점으로 상태를 전달하는 순환 구조가 없습니다. 따라서 원본은 사인·코사인 기반 위치 정보를 Token Embedding에 더합니다.

짝수 Feature PE(pos, 2i) = sin(pos / 10000^(2i / D))
홀수 Feature PE(pos, 2i+1) = cos(pos / 10000^(2i / D))
원본 코드 · 위치 인코딩 
def get_position_encoding(
    time_steps,
    emb_dim
):
    depth = emb_dim / 2

    positions = np.arange(
        time_steps
    )[:, np.newaxis]

    depths = np.arange(
        depth
    )[np.newaxis, :]

    angle_rates = 1 / (
        10000 ** (
            2 * depths / emb_dim
        )
    )

    angle_rads = (
        positions * angle_rates
    )

    pos_encoding = np.zeros(
        (time_steps, emb_dim)
    )

    pos_encoding[:, 0::2] = np.sin(
        angle_rads
    )

    pos_encoding[:, 1::2] = np.cos(
        angle_rads
    )

    return tf.cast(
        pos_encoding[np.newaxis, ...],
        dtype=tf.float32
    )

10 · PADDING / CAUSAL MASK

Mask — 현재 위치에서 무엇을 볼 수 있는가?

Padding Mask

Causal / Look-Ahead Mask

Decoder의 현재 위치가 아직 생성하지 않은 미래 위치를 보지 못하게 합니다.

원본 Mask 생성

def make_look_attention_mask(
    self,
    time_steps
):
    lower_triangular = tf.linalg.band_part(
        tf.ones(
            (time_steps, time_steps)
        ),
        -1,
        0
    )

    return tf.cast(
        lower_triangular,
        tf.bool
    )


def make_combined_mask(
    self,
    dec_inputs,
    dec_padding_mask
):
    time_steps = tf.shape(
        dec_inputs
    )[1]

    look_ahead_mask = (
        self.make_look_attention_mask(
            time_steps
        )
    )

    padding_mask = (
        dec_padding_mask[
            :, tf.newaxis, :
        ]
    )

    combined_mask = tf.logical_and(
        look_ahead_mask,
        padding_mask
    )

    return combined_mask
결합 조건 미래가 아님 AND PAD Key가 아님
Keras Boolean Mask의 방향

원본 방식에서는 True가 참조 허용, False가 참조 금지입니다. 다른 라이브러리의 Mask 관례를 그대로 적용하지 않습니다.

class TransformerEncoder(
    layers.Layer
):

    def __init__(
        self,
        embed_dim,
        units,
        num_heads,
        drop_rate,
        **kwargs
    ):
        super().__init__(**kwargs)

        self.supports_masking = True

        self.attention = (
            layers.MultiHeadAttention(
                num_heads=num_heads,
                key_dim=embed_dim
            )
        )

        self.dropout_self_attention = (
            layers.Dropout(
                drop_rate
            )
        )

        self.dropout_ffn = (
            layers.Dropout(
                drop_rate
            )
        )

        self.dense_1 = layers.Dense(
            units,
            activation="relu"
        )

        self.dense_2 = layers.Dense(
            embed_dim
        )

        self.layernorm_1 = (
            layers.LayerNormalization()
        )

        self.layernorm_2 = (
            layers.LayerNormalization()
        )

    def call(
        self,
        enc_inputs,
        mask=None,
        training=False
    ):

        attention_mask = None

        if mask is not None:
            attention_mask = (
                mask[:, tf.newaxis, :]
            )

        attention_output = (
            self.attention(
                query=enc_inputs,
                value=enc_inputs,
                key=enc_inputs,
                attention_mask=attention_mask
            )
        )

        attention_output_1 = (
            self.dropout_self_attention(
                attention_output,
                training=training
            )
        )

        norm_1 = self.layernorm_1(
            enc_inputs
            + attention_output
        )

        x = self.dense_1(
            norm_1
        )

        dense_output = self.dense_2(
            x
        )

        dense_output = (
            self.dropout_ffn(
                dense_output,
                training=training
            )
        )

        return self.layernorm_2(
            norm_1
            + dense_output
        )

    def compute_mask(
        self,
        inputs,
        mask=None
    ):
        return mask

            targets.numpy()
        )

        valid = (
            target_ids != pad_id
        )

        selected_probs = (
            np.take_along_axis(
                probabilities,
                target_ids[..., None],
                axis=-1
            )[..., 0]
        )

        token_losses = -np.log(
            np.clip(
                selected_probs,
                1e-12,
                1.0
            )
        )

        predicted_ids = (
            probabilities
            .argmax(
                axis=-1
            )
        )

        loss_sum += float(
            token_losses[
                valid
            ].sum()
        )

        correct_sum += int(
            (
                (
                    predicted_ids
                    == target_ids
                )
                &
                valid
            ).sum()
        )

        token_count += int(
            valid.sum()
        )

    if token_count == 0:
        raise ValueError(
            "평가할 유효 Token이 없습니다."
        )

    return {
        "non_pad_loss":
            loss_sum / token_count,

        "non_pad_accuracy":
            correct_sum / token_count,

        "valid_tokens":
            token_count
    }

Keras의 자동 Mask·Metric과 동일한 결과를 보장하는 함수가 아니라, 유효 Target Token 기준의 별도 진단 지표입니다. 원본의 Data Leakage 가능성도 이 함수만으로 해결되지는 않습니다.

22 · INTERVIEW / REVIEW

면접 포인트와 복습 질문

질문을 먼저 읽고 직접 설명한 다음 답을 펼쳐 보세요.

Q01. Transformer 챗봇은 어떤 문제입니까?

한국어 질문 시퀀스를 Encoder가 읽고 Decoder가 대응하는 한국어 응답 시퀀스를 생성하는 Sequence-to-Sequence 문제입니다.

Q02. label을 삭제해도 지도 학습인 이유는 무엇입니까?

응답 A 자체가 Target이기 때문입니다. A를 Shift하여 Decoder Target Token 시퀀스로 사용합니다.

Q03. Teacher Forcing은 무엇입니까?

학습 중 이전 모델 예측 대신 이전 정답 Token을 Decoder 입력으로 제공하는 방식입니다.

Q04. Teacher Forcing이 있는데 왜 Causal Mask가 필요합니까?

Shift된 전체 Decoder Input이 한 번에 들어가기 때문에 현재 위치가 미래 입력 위치의 정답 정보를 미리 보지 못하게 해야 합니다.

Q05. Padding Mask와 Causal Mask의 차이는 무엇입니까?

Padding Mask는 PAD 위치를 제한하고, Causal Mask는 아직 생성하지 않은 미래 위치를 제한합니다.

Q06. Positional Encoding은 왜 필요합니까?

순환 구조 없이 Token 순서를 구분하기 위해 Token Embedding에 위치 정보를 추가합니다.

Q07. 이번 원본의 Positional Encoding은 학습됩니까?

사인·코사인 함수로 계산한 고정 Tensor입니다. Token Embedding Weight는 학습됩니다.

Q08. num_heads=8이면 Head당 64차원입니까?

이번 원본에서는 아닙니다. MultiHeadAttention에 key_dim=512를 직접 전달합니다.

Q09. UNITS=2048의 의미는 무엇입니까?

LSTM 상태 차원이 아니라 FFN 중간 Dense 차원입니다. 512 → 2048 → 512로 변환합니다.

Q10. 세 종류의 Attention은 무엇입니까?

Encoder Self-Attention, Decoder Masked Self-Attention, Decoder Cross-Attention입니다.

Q11. Cross-Attention의 Query와 Key/Value는 무엇입니까?

Decoder 중간 표현이 Query이고, Encoder 최종 질문 표현이 Key와 Value입니다.

Q12. Residual Add와 Concat은 어떻게 다릅니까?

Residual Add는 같은 Shape의 값을 원소별로 더해 512차원을 유지합니다. Concat은 Feature를 이어 붙여 차원을 늘립니다.

Q13. 원본의 logits 변수는 실제 Logit입니까?

아닙니다. 최종 Dense에 softmax activation이 있으므로 실제 값은 확률입니다.

Q14. Sparse Categorical Crossentropy를 사용하는 이유는 무엇입니까?

Target이 One-Hot Vector가 아니라 정수 Token ID이기 때문입니다.

Q15. Best Epoch는 몇 번째입니까?

저장된 val_loss 기준으로 Epoch 23의 약 3.00736입니다.

Q16. 왜 Epoch 28에서 EarlyStopping 되었습니까?

Epoch 23 이후 24~28까지 5 Epoch 연속 best val_loss가 개선되지 않았기 때문입니다.

Q17. EarlyStopping 후 모델은 자동으로 Epoch 23 상태입니까?

원본에는 restore_best_weights=True가 없으므로 그렇게 단정할 수 없습니다. 저장 Checkpoint와 현재 모델 상태를 구분합니다.

Q18. Training Accuracy 0.3043은 질문 정답률입니까?

아닙니다. 응답 시퀀스의 Token 위치 분류 Accuracy로 해석합니다.

Q19. 이번 원본 Gradient Warning은 무엇을 뜻합니까?

저장 학습 실행에서 Decoder 일부 Dense Trainable Variable까지 Loss의 Gradient가 존재하지 않는다는 Keras 경고입니다. 실제 GradientTape 등으로 추가 확인해야 합니다.

Q20. Decoder FFN은 코드상 반환 경로에 포함되어 있지 않습니까?

포함되어 있습니다. 따라서 Gradient Warning 원인을 코드 한 줄만 보고 단정할 수 없고, 실제 모델 객체와 실행 그래프를 확인해야 합니다.

Q21. Encoder Dropout 코드에서 확인할 점은 무엇입니까?

Self-Attention Dropout 결과를 계산하지만 첫 Residual Add에서는 Dropout 전 attention_output을 사용합니다.

Q22. Validation이 있으므로 Data Leakage 문제도 해결되었습니까?

아닙니다. 원본은 전체 1,000개로 Vocabulary를 만든 뒤 Train/Validation을 분리합니다.

Q23. 이 챗봇은 여러 대화 턴을 기억합니까?

아닙니다. 매 질문마다 독립적으로 chatbot(question)을 호출합니다.

Q24. 다음 단원에서 무엇이 크게 달라집니까?

다음은 Part 8의 RAG입니다. 모델 내부 Weight에만 의존하는 대신 외부 문서를 검색해 관련 문맥을 LLM에 제공합니다.
