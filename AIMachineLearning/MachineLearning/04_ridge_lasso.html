StandardScaler

왜 Scaling을 하는가?

Standardization z = (x - μ) / σ
Before Feature Scale이 제각각
  • bedrooms: 0 ~ 5
  • size_sqft: 250 ~ 4800
  • floor: 0 ~ 83
  • binary feature: 0 / 1
After 표준화된 Scale
  • 평균 기준 약 0
  • 표준편차 기준 약 1
  • Feature 간 Scale 차이 완화
StandardScaler는 정규분포를 만드는 도구가 아닙니다.

평균과 표준편차 기준으로 값을 표준화하는 것이며 원래 분포 모양 자체를 정규분포로 변환하는 것은 아닙니다.

09

Regularization

왜 Weight에 Penalty를 주는가?

Feature 증가 → Weight 증가 → 모델 복잡도 증가 가능 → Overfitting 위험
↓
Weight가 과도하게 커지는 것에 추가 비용을 부과
Regularization의 핵심

예측 Error만 최소화하는 것이 아니라, 모델 Parameter의 크기도 함께 제한하여 복잡도를 제어합니다.

10

Model Architecture

LinearRegression · Lasso · Ridge 비교

BASE

LinearRegression

Prediction Error

Weight 크기에 별도의 Regularization Penalty를 추가하지 않습니다.

L1

Lasso

Error + α Σ|W|

L1 Penalty를 적용하며 일부 Weight를 정확히 0으로 만들 수 있습니다.

L2

Ridge

Error + α ΣW²

L2 Penalty를 적용해 Weight를 전반적으로 축소합니다.

11

L1 vs L2

Ridge와 Lasso를 그림처럼 비교

Lasso — L1

W1 W2 W3 → 0 가능 W4
Feature Selection 가능

중요하지 않은 Feature의 Weight가 정확히 0이 될 수 있습니다.

Ridge — L2

W1 ↓ W2 ↓ W3 ↓ W4 ↓
전체 Weight Shrinkage

일반적으로 Feature를 유지하면서 Weight의 크기를 작게 만듭니다.

Lasso를 사용하면 항상 Weight가 0이 되는 것은 아닙니다.

이번 Notebook의 Lasso(alpha=0.1) 실행 결과에서도 출력된 12개 Weight는 모두 0이 아닙니다.

12

Hyperparameter

alpha는 무엇인가?

alpha 작음 규제 약함

Weight 자유도가 상대적으로 큽니다.

→
alpha 증가 규제 증가

Weight를 더 강하게 축소합니다.

→
alpha 너무 큼 Underfitting 가능

중요한 관계까지 지나치게 억제할 수 있습니다.

Metric

R² Score를 어떻게 읽는가?

R² = 1

실제 Target을 완벽하게 설명하는 경우입니다.

R² = 0

Target 평균을 예측하는 기준 모델 수준과 연결해서 이해할 수 있습니다.

R² < 0

기준보다도 예측이 좋지 않은 경우 음수가 될 수 있습니다.

R²는 항상 0~1에만 존재하는 Metric이 아닙니다.

원본 주석은 입문 설명으로 0~1을 강조하지만, 실제로는 Prediction이 매우 나쁘면 음수가 될 수 있습니다.

Common Mistakes

자주 하는 실수

1. Ridge와 Lasso를 완전히 다른 회귀식으로 생각한다

기본 선형식은 같고 Regularization 방식이 다릅니다.

2. Ridge=L1, Lasso=L2라고 외운다

Ridge=L2, Lasso=L1입니다.

3. Lasso는 반드시 Feature를 제거한다고 생각한다

Weight를 0으로 만들 수 있지만 반드시 그러는 것은 아닙니다.

4. alpha가 클수록 무조건 좋다고 생각한다

규제가 지나치면 Underfitting이 생길 수 있습니다.

5. StandardScaler가 정규분포를 만든다고 생각한다

평균과 표준편차를 표준화할 뿐입니다.

6. Scaling하면 Shape도 달라진다고 생각한다

Shape은 유지되고 값의 Scale만 변합니다.

7. 전체 데이터에 Scaler를 fit한 뒤 Split한다

Test 정보가 Scaler에 들어가 Data Leakage가 발생합니다.

8. R²는 항상 0~1이라고 생각한다

매우 나쁜 Prediction에서는 음수가 될 수도 있습니다.

9. 미세한 R² 차이를 큰 성능 차이로 해석한다

이번 세 모델의 결과는 사실상 매우 비슷합니다.

10. Loop 후 y_pred가 어느 모델 것인지 잊는다

마지막 Model이 Ridge이므로 최종 y_pred는 Ridge 결과입니다.

11. 새로운 Sample을 (12,)로 바로 predict한다

(1,12)의 2차원 Shape으로 변경해야 합니다.

12. 새로운 데이터에 Scaler를 다시 fit한다

Training 때 fit한 Scaler로 transform만 해야 합니다.

Interview

면접 포인트

Q1. Ridge와 Lasso의 차이는 무엇인가요?

Ridge는 L2 Penalty를 사용하여 Weight를 전반적으로 축소하고, Lasso는 L1 Penalty를 사용하여 일부 Weight를 정확히 0으로 만들 수 있습니다.

Q2. Regularization은 왜 사용하나요?

Weight가 과도하게 커지는 것을 억제하여 모델 복잡도를 제어하고 Overfitting 위험을 완화하기 위해 사용합니다.

Q3. alpha란 무엇인가요?

Regularization 강도를 결정하는 Hyperparameter입니다. 너무 크면 Underfitting이 발생할 수 있습니다.

Q4. Lasso는 항상 Feature를 제거하나요?

아닙니다. Weight를 0으로 만들 수 있지만 실제로 0이 되는지는 Dataset과 alpha에 따라 달라집니다.

Q5. StandardScaler는 무엇을 하나요?

각 Feature를 평균 0, 표준편차 1 기준의 Scale로 표준화합니다.

Q6. StandardScaler를 사용하면 정규분포가 되나요?

아닙니다. Feature Scale을 표준화하지만 데이터의 분포 모양 자체를 정규분포로 만들지는 않습니다.

Q7. 왜 Scaling은 Train/Test Split 후에 해야 하나요?

Scaler가 Test Dataset의 평균과 표준편차를 학습하지 못하도록 하기 위해서입니다. Test 정보가 사용되면 Data Leakage가 발생합니다.

Q8. Data Leakage란 무엇인가요?

Training 과정에서 원래 볼 수 없어야 하는 Test, Validation 또는 미래 정보가 사용되는 문제입니다.

Q9. X_test.shape=(1000,12)은 무슨 뜻인가요?

1000개의 Test Sample과 각 Sample마다 12개의 Feature가 있다는 의미입니다.

Q10. 새로운 Sample을 왜 (1,12)로 만드나요?

scikit-learn의 입력 X는 (n_samples, n_features) 구조를 요구하므로 Sample 1개와 Feature 12개를 명시하기 위해서입니다.

Q11. R²는 무엇인가요?

Regression Model이 Target의 변동을 어느 정도 설명하는지를 나타내는 대표적인 Metric입니다. 1에 가까울수록 좋으며 경우에 따라 음수가 될 수도 있습니다.

Q12. 왜 Accuracy를 사용하지 않나요?

임대료는 연속형 값을 예측하는 Regression 문제이므로 Classification Accuracy를 사용하지 않습니다.

Q13. Ridge와 Lasso의 R²가 거의 같으면 규제가 의미 없나요?

아닙니다. Regularization은 R²뿐 아니라 Weight 크기, 모델 안정성, Feature Selection, Overfitting 제어에도 의미가 있습니다.

Q14. 새로운 데이터에도 scaler.fit()을 해야 하나요?

아닙니다. Training Dataset에서 이미 fit한 Scaler로 transform만 해야 합니다.
