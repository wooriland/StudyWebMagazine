Multi Layer Perceptron · Hidden Layer · Forward · Backpropagation

은닉층을 추가한 MLP로 XOR 해결

단일 선형 모델로 해결하지 못했던 XOR 문제에 Hidden Layer를 추가한다. NumPy로 입력층 → 은닉층 → 출력층을 직접 구성하고, 순전파와 역전파를 구현하여 신경망이 중간 표현을 학습하는 과정을 확인한다.

이번 단원의 핵심 Architecture

Input 2 x1, x2
→
Hidden 4 Sigmoid
→
Output 1 Sigmoid
(4,2) → (4,4) → (4,1)

학습 목표

  • 단층 구조와 MLP의 차이를 설명할 수 있다.
  • 입력층·은닉층·출력층의 역할을 설명할 수 있다.
  • W1=(2,4), W2=(4,1)이 되는 이유를 Shape 관점에서 설명할 수 있다.
  • X → z1 → h1 → z2 → h2 순전파 과정을 설명할 수 있다.
  • loss2와 loss1을 통해 출력층의 오차가 은닉층으로 전달되는 과정을 설명할 수 있다.
  • Sigmoid 미분 h × (1-h)이 역전파에 사용되는 이유를 설명할 수 있다.
  • Hidden Layer가 XOR와 같은 비선형 문제를 표현할 수 있게 하는 이유를 설명할 수 있다.
  • 원본 코드의 Gradient Shape 문제와 개념적으로 기대되는 Shape를 구분할 수 있다.

Loss

Binary Cross Entropy

- mean [ y log(h2) + (1-y) log(1-h2) ]

교안 원문 
def __loss_func(self, h2):

    delta = 1e-5

    return -np.mean(
        self.__y * np.log(h2 + delta)
        +
        (1 - self.__y)
        * np.log(1 - h2 + delta)
    )

정답 y = 1

-log(h2)

h2가 1에 가까울수록 Loss가 감소한다.

정답 y = 0

-log(1-h2)

h2가 0에 가까울수록 Loss가 감소한다.

ML 11과 차이

ML 11에서는 Loss를 np.sum()으로 합산했지만, 이번 ML 12에서는 np.mean()으로 평균을 계산한다.

delta = 1e-5 → log(0) 수치 문제 완화

→ np.mean() → scalar

원문의 행렬곱 결과는 각각 Weight Matrix와 대응하는 Shape를 만들지만, 그 뒤 전체 배열에 np.mean()을 적용하여 scalar 하나로 축약한다. 업데이트 시 NumPy Broadcasting에 의해 동일한 scalar 값이 Weight Matrix 전체에 적용된다.

개념적으로 기대되는 W1 Gradient (2,4)
개념적으로 기대되는 W2 Gradient (4,1)
학습 원칙

원본 코드를 임의로 수정해 다른 코드처럼 제시하지 않는다. 현재 Notebook의 실제 구현과 정확한 Backpropagation에서 기대되는 Gradient Shape를 별도로 구분해서 공부한다.

Gradient Descent

Parameter Update

self.__W2 -= self.__lr * grad_W2
self.__b2 -= self.__lr * grad_b2

self.__W1 -= self.__lr * grad_W1
self.__b1 -= self.__lr * grad_b1

New Parameter = Old Parameter - Learning Rate × Gradient

Learning Rate 1e-2 = 0.01

Prediction

predict() 흐름

def predict(self, x, threshold):

    z1 = np.dot(
        x,
        self.__W1
    ) + self.__b1

    h1 = sigmoid(z1)

    z2 = np.dot(
        h1,
        self.__W2
    ) + self.__b2

    h2 = sigmoid(z2)

    pred = []

    for value in h2:

        if value > threshold:
            pred.append(1)

        else:
            pred.append(0)

    return pred

Non-linearity

왜 Activation Function이 필요한가?

Activation이 없다면

Linear ↓ Linear ↓ Linear

여러 Linear Transformation은 결국 하나의 Linear Transformation으로 합쳐질 수 있다.

Activation이 있다면

Linear ↓ Non-linear Activation ↓ Linear

입력 공간을 비선형적으로 변환하여 더 복잡한 관계를 표현할 수 있다.

Common Mistakes

자주 하는 실수

01

이번 Architecture를 2 → 10 → 1이라고 외운다.

생성자의 기본값은 hidden=10이지만 실제 실습 객체에서는 hidden=4를 전달한다. 이번 실행 기준은 2 → 4 → 1이다.

02

W1 Shape를 (4,2)라고 생각한다.

입력 Feature 2개에서 Hidden Node 4개로 연결하므로 W1.shape = (2,4)이다.

03

W2 Shape를 (1,4)라고 생각한다.

Forward에서는 h1(N,4) @ W2(4,1)이어야 한다.

04

z1과 h1을 같은 값이라고 생각한다.

z1 = XW1+b1, h1 = sigmoid(z1)이다. Shape는 같아도 의미가 다르다.

05

Hidden Layer를 추가하기만 하면 비선형 모델이 된다고 생각한다.

Layer 사이에 비선형 Activation이 있어야 복잡한 비선형 관계를 표현할 수 있다.

06

Prediction이 맞으면 Loss도 거의 0이어야 한다고 생각한다.

Threshold 기준 Classification이 맞더라도 예측 확률의 확신이 낮으면 Loss는 남을 수 있다.

07

저장된 Loss 숫자는 매번 똑같다고 생각한다.

Random Seed가 고정되어 있지 않으므로 다시 실행하면 초기 Weight와 학습 결과 숫자가 달라질 수 있다.

08

원문의 grad_W1 / grad_W2를 정확한 역전파 구현이라고 일반화한다.

통합교안 검토 메모에서 행렬 전체 평균으로 Gradient가 scalar화되는 문제를 지적한다.

Error Reading

오류 메시지 읽는 법

구분

아래 오류는 원본 Notebook 저장 출력에 나타난 Exception이 아니라, 동일 구조를 수정하거나 확장할 때 만날 수 있는 대표적인 오류다.

1. Matrix Dimension Error

ValueError:
shapes (...) not aligned

예를 들어 X=(4,2)인데 W1=(3,4)라면 행렬곱 연결 차원이 다르다.

(batch, feature) @ (feature, hidden)

2. Hidden Node 수 변경 후 Dimension Error

Hidden Node를 8개로 바꾸면 관련 Shape도 함께 변해야 한다. 

W1 : (2,8)
b1 : (8,)
h1 : (4,8)
W2 : (8,1)

3. Broadcasting Error

ValueError:
operands could not be broadcast together

Bias 크기가 Layer Node 수와 맞지 않는 경우 등에서 발생할 수 있다.

z1(N,hidden) + b1(hidden,)

4. dtype Error

X_train = np.array([
    ["0", "1"],
    ["1", "0"]
])

문자열 데이터는 행렬곱이나 np.exp() 같은 수치 연산에서 문제가 될 수 있다.

5. Sigmoid exp Overflow

RuntimeWarning:
overflow encountered in exp

z의 절댓값이 매우 커지면 np.exp(-z) 계산이 수치적으로 불안정해질 수 있다.

6. log(0) 문제

Binary Cross Entropy에서 log(h2)와 log(1-h2)를 사용하므로 원문은 delta=1e-5를 더한다.

Interview Point

면접 포인트

Q1. MLP란 무엇입니까?

Multi Layer Perceptron의 약자로, 입력층과 출력층 사이에 하나 이상의 Hidden Layer를 두고 Weight와 Activation Function으로 연결한 Feedforward Neural Network 구조입니다.

Q2. 이번 MLP Architecture는 무엇입니까?

입력 Feature 2개, Hidden Node 4개, Output Node 1개이므로 2 → 4 → 1입니다.

Q3. W1 Shape가 왜 (2,4)입니까?

입력 Feature 2개가 Hidden Node 4개와 연결되기 때문입니다.

Q4. W2 Shape가 왜 (4,1)입니까?

Hidden Node 4개의 출력을 하나의 Output Node에 연결하기 때문입니다.

Q5. h1은 무엇입니까?

Hidden Layer에서 Sigmoid까지 통과한 출력값이며, 다음 Output Layer가 사용하는 새로운 Feature Representation입니다.

Q6. 순전파란 무엇입니까?

입력 데이터가 Weight, Bias, Activation Function을 거쳐 Hidden Layer에서 Output Layer 방향으로 최종 Prediction을 계산하는 과정입니다.

Q7. 역전파란 무엇입니까?

최종 출력의 오차를 이전 Layer 방향으로 전달하면서 각 Parameter가 Loss에 미친 영향을 계산하고 Weight와 Bias를 수정하는 과정입니다.

Q8. h1 × (1-h1)을 사용하는 이유는 무엇입니까?

Hidden Layer의 Activation이 Sigmoid이므로 Sigmoid의 미분값을 계산하기 위해 사용합니다.

Q9. Hidden Layer가 XOR 해결에 왜 도움이 됩니까?

입력을 새로운 비선형 Representation으로 변환할 수 있기 때문에, 원래 입력 공간에서 하나의 직선으로 표현할 수 없던 관계를 다른 Feature Space에서 표현할 수 있게 됩니다.

Q10. Hidden Layer만 여러 개 쌓으면 비선형 모델이 됩니까?

아닙니다. Layer 사이에 비선형 Activation Function이 필요합니다. Linear Transformation만 연속으로 적용하면 전체를 하나의 Linear Transformation으로 합칠 수 있습니다.

Q11. 이번 Loss는 무엇입니까?

Binary Cross Entropy 형태이며, 원본에서는 np.mean()을 사용해 평균 Loss를 계산합니다.

Q12. Optimizer는 무엇을 사용합니까?

별도의 Keras Optimizer를 사용하지 않고, 직접 계산한 Gradient를 이용해 parameter -= learning_rate × gradient 형태로 업데이트합니다.

Q13. Learning Rate는 얼마입니까?

실제 논리 게이트 실습에서는 1e-2, 즉 0.01을 사용합니다.

Q14. Prediction이 맞는데 Loss가 0이 아닐 수 있습니까?

가능합니다. Classification은 Threshold 기준으로 맞을 수 있지만, 예측 확률이 정답에 매우 가까운 것은 아닐 수 있기 때문입니다.

Q15. 이번 Notebook의 Gradient 구현상 주의점은 무엇입니까?

grad_W1과 grad_W2 계산에서 행렬 전체에 np.mean()을 적용하여 Weight별 Gradient Shape가 scalar로 축약됩니다. 통합교안이 이 부분을 검토 메모로 지적하고 있습니다.
