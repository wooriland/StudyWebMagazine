01 · PROBLEM DEFINITION

실습 목표 — 번역 문제는 같고 계산 구조가 바뀐다

이번 문제는 영어 입력 시퀀스 → 한국어 번역 시퀀스입니다. 내부 모델을 LSTM에서 Transformer로 바꾸어도 Sequence-to-Sequence라는 입력·출력 관계는 유지됩니다.

이전 방식

LSTM 기반 Attention Seq2Seq

입력 토큰 ↓ Encoder LSTM ↓ 전체 출력 + 마지막 h, c ↓ Attention Decoder LSTM

이번 방식

Transformer Encoder–Decoder

입력 토큰 + 위치 정보 ↓ Transformer Encoder ↓ 최종 시퀀스 표현 ↓ Transformer Decoder
LSTM의 마지막 h, c를 전달하는 대신, 위치 정보가 포함된 토큰 벡터를 여러 Transformer 블록으로 처리합니다.

이번에 답해야 하는 핵심 질문

토큰의 위치는 어떻게 표현할까? Encoder와 Decoder는 각각 무엇을 Attention할까? 미래 한국어 정답을 어떻게 가릴까? 최종 확률을 어떻게 번역문으로 바꿀까?

원본은 사전 학습된 번역 모델을 불러오는 코드가 아닙니다. Embedding과 Transformer 블록을 생성하고, 준비한 말뭉치로 직접 학습하도록 작성되어 있습니다.

02 · CORE CONCEPTS

핵심 개념 — Attention 중심의 시퀀스 처리

구성 요소 역할
Token Embedding 정수 토큰을 학습 가능한 실수 벡터로 변환
Positional Encoding 토큰의 위치 정보를 벡터에 추가
Self-Attention 같은 시퀀스 안의 토큰 관계 계산
Cross-Attention Decoder가 Encoder의 원문 정보를 참고
Multi-Head Attention 여러 Head의 투영 공간에서 Attention 수행
FFN 각 토큰의 Feature를 비선형 변환
Residual Connection 기존 표현과 새 계산 결과를 원소별로 더함
LayerNormalization 원본에서는 각 토큰의 마지막 Feature 축 정규화
Padding Mask 의미 없는 PAD 위치의 참조 제어
Causal Mask Decoder가 미래 위치의 정답을 미리 보지 못하게 제어

병렬 학습과 순차 생성은 다르다

학습

이전 정답을 담은 Decoder 입력 전체가 준비되어 있습니다. Mask를 적용하여 여러 위치의 출력을 함께 계산합니다.

생성

아직 다음 토큰을 모릅니다. 직전에 생성한 토큰을 입력에 추가하며 다음 토큰을 순서대로 선택합니다.

입력·출력 관계 P(한국어 문장 | 영어 문장) 학습의 위치별 계산을 병렬화할 수 있다는 것과 번역문 전체를 한 번에 선택한다는 것은 다릅니다.

def get_position_encoding(time_steps, emb_dim):
    depth = emb_dim / 2

    positions = np.arange(time_steps)[:, np.newaxis]
    depths = np.arange(depth)[np.newaxis, :]

    angle_rates = 1 / (10000**(2 * depths / emb_dim))
    angle_rads = positions * angle_rates

    pos_encoding = np.zeros((time_steps, emb_dim))

    pos_encoding[:, 0::2] = np.sin(angle_rads)
    pos_encoding[:, 1::2] = np.cos(angle_rads)

    return tf.cast(
        pos_encoding[np.newaxis, ...],
        dtype=tf.float32
    )

class PositionalEmbedding(layers.Layer):

    def __init__(self, time_steps, input_dim, output_dim, **kwargs):
        super().__init__(**kwargs)

        self.supports_masking = True

        self.token_embeddings = layers.Embedding(
            input_dim=input_dim,
            output_dim=output_dim,
            mask_zero=True
        )

        self.position_encoding = get_position_encoding(
            time_steps,
            output_dim
        )

        self.time_steps = time_steps
        self.emd_dim = output_dim

    def call(self, inputs):
        inputs = self.token_embeddings(inputs)

        inputs *= tf.math.sqrt(
            tf.cast(self.emd_dim, tf.float32)
        )

        inputs = inputs + self.position_encoding[:, :self.time_steps, :]

        return inputs

    def compute_mask(self, *args, **kwargs):
        return self.token_embeddings.compute_mask(*args, **kwargs)

Mask — 어떤 위치를 볼 수 있는가?

이번 원본에는 mask_zero=True와 명시적인 Attention Mask가 있습니다. 이전 단원의 “Attention Mask가 없다”는 설명을 그대로 적용하지 않습니다.

Mask 목적 Shape
Encoder Padding 영어 PAD 식별 (B,S)
Encoder Attention용 Query 축으로 Broadcasting (B,1,S)
Decoder Padding 한국어 PAD 식별 (B,T)
Look-Ahead 미래 위치 제한 (T,T)
Decoder Combined 미래와 PAD Key 조건 결합 (B,T,T)
Cross-Attention 영어 PAD Key 제외 (B,1,S)
Keras Boolean Mask의 방향

True는 참조 허용, False는 참조 금지입니다. True가 “가린 위치”라고 해석하면 반대로 적용됩니다. 4차원 Mask를 항상 직접 만들어야 하는 것도 아닙니다. 공식 API는 (B,T,S)와 Broadcasting을 설명합니다.

마지막 행이 모두 0이 아닌 이유는 원본 수동 결합이 미래 Key와 PAD Key를 제한하기 때문입니다. PAD Query 행을 별도로 전부 가리는 식은 아닙니다. 실제 Keras 내부에서는 자동 Mask와 명시적 Mask가 함께 처리될 수 있으므로, 이 표를 최종 Attention 내부 처리 전체의 관찰 결과로 사용하지 않습니다.

class TransformerEncoder(layers.Layer):

    def __init__(self, embed_dim, units, num_heads, drop_rate, **kwargs):
        super().__init__(**kwargs)

        self.supports_masking = True

        self.attention = layers.MultiHeadAttention(
            num_heads=num_heads,
            key_dim=embed_dim
        )

        self.dropout_self_attention = layers.Dropout(drop_rate)
        self.dropout_ffn = layers.Dropout(drop_rate)

        self.dense_1 = layers.Dense(units, activation="relu")
        self.dense_2 = layers.Dense(embed_dim)

        self.layernorm_1 = layers.LayerNormalization()
        self.layernorm_2 = layers.LayerNormalization()

    def call(self, enc_inputs, mask=None, training=False):
        attention_mask = None

        if mask is not None:
            attention_mask = mask[:, tf.newaxis, :]

        attention_output = self.attention(
            query=enc_inputs,
            value=enc_inputs,
            key=enc_inputs,
            attention_mask=attention_mask
        )

        attention_output_1 = self.dropout_self_attention(
            attention_output,
            training=training
        )

        norm_1 = self.layernorm_1(
            enc_inputs + attention_output
        )

        x = self.dense_1(norm_1)
        dense_output = self.dense_2(x)

        dense_output = self.dropout_ffn(
            dense_output,
            training=training
        )

        return self.layernorm_2(norm_1 + dense_output)

    def compute_mask(self, inputs, mask=None):
        return mask

class TransformerDecoder(layers.Layer):

    def __init__(
        self, embed_dim, units, time_steps,
        num_heads, drop_rate, **kwargs
    ):
        super().__init__(**kwargs)

        self.supports_masking = True
        self.time_steps = time_steps

        self.self_attention = layers.MultiHeadAttention(
            num_heads=num_heads,
            key_dim=embed_dim
        )

        self.cross_attention = layers.MultiHeadAttention(
            num_heads=num_heads,
            key_dim=embed_dim
        )

        self.dropout_self_attention = layers.Dropout(drop_rate)
        self.dropout_ed_attention = layers.Dropout(drop_rate)
        self.dropout_ffn = layers.Dropout(drop_rate)

        self.dense_1 = layers.Dense(units, activation="relu")
        self.dense_2 = layers.Dense(embed_dim)

        self.layernorm_1 = layers.LayerNormalization()
        self.layernorm_2 = layers.LayerNormalization()
        self.layernorm_3 = layers.LayerNormalization()

    def call(
        self, dec_inputs, encoder_outputs,
        self_mask=None, cross_mask=None, training=False
    ):
        attention_output_1 = self.self_attention(
            query=dec_inputs,
            value=dec_inputs,
            key=dec_inputs,
            attention_mask=self_mask
        )

        attention_output_1 = self.dropout_self_attention(
            attention_output_1,
            training=training
        )

        norm_1 = self.layernorm_1(
            dec_inputs + attention_output_1
        )

        attention_output_2 = self.cross_attention(
            query=norm_1,
            value=encoder_outputs,
            key=encoder_outputs,
            attention_mask=cross_mask
        )

        attention_output_2 = self.dropout_ed_attention(
            attention_output_2,
            training=training
        )

        norm_2 = self.layernorm_2(
            norm_1 + attention_output_2
        )

        x = self.dense_1(norm_2)
        dense_output = self.dense_2(x)

        dense_output = self.dropout_ffn(
            dense_output,
            training=training
        )

        return self.layernorm_3(norm_2 + dense_output)

    def compute_mask(self, inputs, mask=None):
        return mask

class Transformer(tf.keras.Model):

    def __init__(
        self, units, voca_size, embed_dim, time_steps,
        num_heads, drop_rate, num_layers, **kwargs
    ):
        super(Transformer, self).__init__(**kwargs)

        self.num_heads = num_heads

        self.encoder_embedding = PositionalEmbedding(
            time_steps, voca_size, embed_dim,
            name="enc_inputs"
        )

        self.decoder_embedding = PositionalEmbedding(
            time_steps, voca_size, embed_dim,
            name="dec_inputs"
        )

        self.dropout_emb_encorder = layers.Dropout(drop_rate)
        self.dropout_emb_decorder = layers.Dropout(drop_rate)

        self.encoders = [
            TransformerEncoder(
                embed_dim, units, num_heads, drop_rate
            )
            for _ in range(num_layers)
        ]

        self.decoders = [
            TransformerDecoder(
                embed_dim, units, time_steps, num_heads, drop_rate
            )
            for _ in range(num_layers)
        ]

        self.dense = layers.Dense(
            voca_size,
            activation="softmax"
        )

    def call(self, inputs, training=False):
        encoder_inputs_embed = self.encoder_embedding(
            inputs['enc_inputs']
        )

        encoder_inputs_embed = self.dropout_emb_encorder(
            encoder_inputs_embed,
            training=training
        )

        decoder_inputs_embed = self.decoder_embedding(
            inputs['dec_inputs']
        )

        decoder_inputs_embed = self.dropout_emb_decorder(
            decoder_inputs_embed,
            training=training
        )

        encoder_padding_mask = self.encoder_embedding.compute_mask(
            inputs['enc_inputs']
        )

        decoder_padding_mask = self.decoder_embedding.compute_mask(
            inputs['dec_inputs']
        )

        decoder_combined_mask = self.make_combined_mask(
            inputs['dec_inputs'],
            decoder_padding_mask
        )

        encoder_outputs = encoder_inputs_embed

        for enc in self.encoders:
            encoder_outputs = enc(
                encoder_outputs,
                mask=encoder_padding_mask
            )

        encoder_decoder_cross_mask = (
            encoder_padding_mask[:, tf.newaxis, :]
        )

        decoder_outputs = decoder_inputs_embed

        for dec in self.decoders:
            decoder_outputs = dec(
                decoder_outputs,
                encoder_outputs,
                self_mask=decoder_combined_mask,
                cross_mask=encoder_decoder_cross_mask
            )

        logits = self.dense(decoder_outputs)
        return logits

    def make_combined_mask(self, dec_inputs, dec_padding_mask):
        time_steps = tf.shape(dec_inputs)[1]

        look_ahead_mask = self.make_look_attention_mask(time_steps)
        padding_mask = dec_padding_mask[:, tf.newaxis, :]

        combined_mask = tf.logical_and(
            look_ahead_mask,
            padding_mask
        )

        return combined_mask

    def make_look_attention_mask(self, time_steps):
        lower_triangular = tf.linalg.band_part(
            tf.ones((time_steps, time_steps)),
            -1,
            0
        )

        return tf.cast(lower_triangular, tf.bool)

import numpy as np


def evaluate_non_pad_tokens(model, dataset, pad_id: int = 0) -> dict:
    """Eager 진단용. 모델 가중치를 업데이트하지 않습니다."""
    loss_sum = 0.0
    correct_sum = 0
    token_count = 0

    for inputs, targets in dataset:
        probabilities = np.asarray(
            model(inputs, training=False).numpy()
        )
        target_ids = np.asarray(targets.numpy())

        if target_ids.ndim != 2 or probabilities.ndim != 3:
            raise ValueError("Target은 (B,T), 확률은 (B,T,V)여야 합니다.")

        if probabilities.shape[:2] != target_ids.shape:
            raise ValueError("Target과 예측의 배치·시점 크기가 다릅니다.")

        if not np.issubdtype(target_ids.dtype, np.integer):
            raise TypeError("Target은 정수 Token ID여야 합니다.")

        vocab_size = probabilities.shape[-1]

        if target_ids.size == 0:
            continue

        if target_ids.min() < 0 or target_ids.max() >= vocab_size:
            raise ValueError("Target ID가 출력 어휘 범위를 벗어났습니다.")

        if not np.isfinite(probabilities).all():
            raise ValueError("예측에 NaN 또는 Inf가 있습니다.")

        if (probabilities < 0).any():
            raise ValueError("확률에 음수가 있습니다.")

        if not np.allclose(
            probabilities.sum(axis=-1), 1.0, atol=1e-4
        ):
            raise ValueError("출력이 Softmax 확률인지 확인하세요.")

        valid = target_ids != pad_id

        selected_probs = np.take_along_axis(
            probabilities,
            target_ids[..., None],
            axis=-1
        )[..., 0]

        token_losses = -np.log(
            np.clip(selected_probs.astype(np.float64), 1e-12, 1.0)
        )

        predicted_ids = probabilities.argmax(axis=-1)

        loss_sum += float(token_losses[valid].sum())
        correct_sum += int(
            ((predicted_ids == target_ids) & valid).sum()
        )
        token_count += int(valid.sum())

    if token_count == 0:
        raise ValueError("평가할 유효 Target 토큰이 없습니다.")

    return {
        "non_pad_loss": loss_sum / token_count,
        "non_pad_accuracy": correct_sum / token_count,
        "valid_tokens": token_count
    }

원본은 토큰마다 모델 전체를 다시 호출합니다. Encoder 출력 재사용이나 Decoder 캐시를 도입하려면 위치 인덱스, Mask, Prefix 길이, 배치별 종료 상태도 함께 설계해야 합니다. 반복문을 단순히 줄이는 것만으로 같은 결과가 보장되는 변경은 아닙니다.

21 · INTERVIEW / REVIEW

면접 포인트와 복습 질문

답변을 접고 질문부터 설명해 보세요. 용어뿐 아니라 원본 코드의 설정과 Shape, 실제 저장 출력의 범위까지 연결하는 것이 복습 기준입니다.

Q01. Transformer에서도 왜 Seq2Seq라고 합니까?

영어 입력 시퀀스를 조건으로 한국어 출력 시퀀스를 생성하기 때문입니다. 내부 계산을 바꾸어도 입력·출력 관계는 유지됩니다.

Q02. 위치 인코딩은 왜 필요합니까?

토큰 벡터에 위치 정보를 제공하기 위해서입니다. 원본은 사인·코사인 Tensor를 Token Embedding에 더합니다.

Q03. 원본의 위치 정보도 학습됩니까?

위치 Tensor는 함수로 계산한 고정값입니다. Token Embedding은 학습되지만 위치 정보가 별도의 학습 가능한 테이블은 아닙니다.

Q04. 두 제곱근 스케일은 어떻게 다릅니까?

Embedding에는 √D를 곱하고, Attention 내적 Score에는 √d_k로 나누는 연산을 사용합니다. 적용 위치와 의미가 다릅니다.

Q05. num_heads=8, key_dim=512는 Head당 64차원입니까?

아닙니다. Keras key_dim은 Head 하나의 Query·Key 차원이므로 원본은 Head당 512차원입니다.

Q06. MHA의 출력이 512차원인 이유는 무엇입니까?

output_shape를 지정하지 않아 Query 입력의 마지막 차원으로 출력 투영하기 때문입니다. 내부 Head 연결 차원과 반환 차원을 구분합니다.

Q07. Encoder Self와 Decoder Cross-Attention은 어떻게 다릅니까?

Encoder Self는 영어 표현에서 Q/K/V 입력을 만듭니다. Cross는 Decoder 중간 표현이 Q, Encoder 출력이 K/V입니다.

Q08. Causal Mask가 필요한 이유는 무엇입니까?

Teacher Forcing 입력 전체에서 현재 위치가 미래 정답 토큰을 미리 보지 못하게 하기 위해서입니다.

Q09. Mask의 대각선을 허용하는 이유는 무엇입니까?

현재 Decoder 입력은 현재 예측할 Target보다 한 칸 이전 토큰입니다. 현재 입력을 보는 것이 현재 정답을 미리 보는 것과 같지 않습니다.

Q10. 원본 Boolean Mask의 True는 무엇입니까?

참조 허용입니다. 참조 금지를 뜻하지 않습니다.

Q11. UNITS=2048은 무엇입니까?

FFN의 중간 Dense 차원입니다. 512차원 입력을 2048로 확장한 뒤 다시 512로 줄입니다.

Q12. 잔차 덧셈은 Concat과 어떻게 다릅니까?

같은 Shape의 원소를 더해 512차원을 유지합니다. Feature를 이어 붙여 차원을 늘리는 Concat과 다릅니다.

Q13. logits 변수는 실제 Logit입니까?

원본의 최종 Dense에 Softmax가 있으므로 확률입니다. 변수명보다 실제 연산을 기준으로 읽습니다.

Q14. 원본의 최종 번역 정확도는 얼마입니까?

확인할 수 없습니다. 첫 Epoch의 3/29 진행 출력만 있으므로 0.0418을 최종 정확도로 사용하지 않습니다.

Q15. Validation이 있으므로 누수 문제도 해결되었습니까?

원본은 전체 사전 구축 뒤에 분할합니다. 평가 정보가 전처리에 들어갈 수 있는 점을 별도로 검토해야 합니다.

Q16. Attention Mask가 있으면 PAD Loss도 올바르게 제외됩니까?

그렇게 단정할 수 없습니다. 입력 참조와 Target 손실·지표 집계는 다른 확인 지점입니다.

Q17. 원본 Encoder Dropout에서 확인한 점은 무엇입니까?

attention_output_1을 계산하지만 후속 Add가 원래 attention_output을 사용합니다. 해당 Dropout 결과가 출력 경로에 반영되지 않습니다.

Q18. EOS가 나오지 않으면 추론 후처리에 어떤 문제가 있습니까?

[1:-1]이 마지막 요소를 무조건 제거하므로 마지막 실제 번역 토큰이 삭제될 수 있습니다.

Q19. 같은 Tokenizer를 쓰면 Embedding도 공유합니까?

원본은 Encoder와 Decoder에 PositionalEmbedding 객체를 각각 만듭니다. 공통 사전과 공유 가중치는 다른 개념입니다.

Q20. 다음 단원은 무엇입니까?
