Sparse는 이미지에 0이 많다는 뜻이 아니라 정답 표현과 관련된다. Training의 loss, 검증의 val_loss, Test 평가의 loss는 계산 데이터가 다르다.

Step 1·2 API 보완 Adam의 기본 학습률은 0.001이다. 원문은 값을 직접 지정·출력하거나 스케줄러를 사용하지 않는다. Adam은 Gradient의 1차·2차 모멘트 상태를 사용하는 Optimizer다.

이번 Test에서 Epoch 7의 수치가 조금 더 좋다고 앞으로 Test가 좋아지는 Epoch를 반복 선택하는 방식으로 바꾸면 평가 독립성이 달라진다.

고정 상수 /255.와 데이터에서 평균·분산·Feature 선택 규칙을 학습하는 전처리를 구분한다. 후자를 추가한다면 Training에 적합하고 검증·Test에는 적용한다.

Overfitting: Training 적합이 새 데이터 성능으로 이어지지 않는 문제다. 위 방향 차이는 점검 신호지만 모든 원인을 밝힌 결과는 아니다. EarlyStopping은 제한 방법이며 Test 향상을 보장하지 않는다.

Underfitting: Training의 관련 패턴도 충분히 익히지 못한 상황이다. 조기 종료가 빨랐다는 사실만으로 확정하지 않고 입력·학습량·모델·최적화를 함께 본다.

Learning Rate: 너무 크면 업데이트가 불안정하고 작으면 느릴 수 있다. 한 번의 Loss 상승만으로 원인을 확정하지 않는다. 원문은 기본 Adam이며 다른 학습률·patience·모델 크기의 비교 실험이 없다.
