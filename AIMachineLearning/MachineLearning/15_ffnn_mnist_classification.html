AI Machine Learning PART 2. 퍼셉트론과 FFNN ML 15

FFNN · MNIST · Flatten · ReLU · Softmax · Multiclass Classification

FFNN으로 손글씨 숫자 분류하기

28×28 MNIST 손글씨 이미지를 784개의 Pixel Feature로 펼친 뒤 Fully Connected Neural Network에 입력한다. Pixel을 0~1로 정규화하고, Label을 One-Hot Encoding한 뒤, 784 → 512(ReLU) → 10(Softmax) 구조로 숫자 0~9를 분류한다.

이번 단원의 핵심 Pipeline

MNIST Image → 28 × 28 → reshape → 784 → / 255 → Dense 512 → ReLU → Dense 10 → Softmax → argmax → 0~9
(batch,28,28) → (batch,784) → (batch,512) → (batch,10)

학습 목표

  • MNIST Dataset의 X와 y 구조를 설명할 수 있다.
  • (60000,28,28)의 의미를 Image Shape 관점에서 설명할 수 있다.
  • 28×28 Image를 왜 784 Feature Vector로 변환하는지 설명할 수 있다.
  • 원본 Notebook이 Keras Flatten Layer가 아니라 NumPy reshape()를 사용한다는 것을 구분할 수 있다.
  • Pixel 값을 0~255에서 0~1로 정규화하는 이유를 설명할 수 있다.
  • 정수 Label과 One-Hot Label의 차이를 설명할 수 있다.
  • 784 → 512 → 10 Model Shape를 설명할 수 있다.
  • ReLU와 Softmax의 역할을 각각 설명할 수 있다.
  • One-Hot Label과 Categorical Crossentropy의 관계를 설명할 수 있다.
  • RMSprop, Learning Rate, Epoch, Batch Size, Validation Split의 역할을 설명할 수 있다.
  • Accuracy와 Cross Entropy Loss의 차이를 설명할 수 있다.
  • Image 한 장을 Predict할 때 (784,) → (1,784)로 바꾸는 이유를 설명할 수 있다.
  • Softmax 10개 Probability에서 argmax로 Class를 결정하는 과정을 설명할 수 있다.

Common Mistakes

자주 하는 실수

01

28×28 Image를 그대로 Dense(784)에 넣는다.

이번 원본에서는 먼저 `(28,28) → (784,)`로 reshape한다.

02

Flatten하면 Pixel 값도 달라진다고 생각한다.

Flatten은 Shape만 바꾸며 Pixel 값 자체는 유지한다.

03

원본이 Keras Flatten Layer를 쓴다고 기억한다.

실제 코드는 NumPy reshape다.

04

/255 이후 Shape도 바뀐다고 생각한다.

값 범위만 0~1로 바뀌고 Shape는 유지된다.

05

One-Hot과 Softmax를 같은 것이라고 생각한다.

One-Hot은 정답 표현이고 Softmax는 Model Output이다.

06

Output Node를 1개로 만든다.

이번 문제는 10-Class이므로 Output Node가 10개다.

07

One-Hot Label에 sparse categorical loss를 쓴다고 외운다.

이번 원본은 categorical_crossentropy를 사용한다.

08

Softmax가 바로 숫자 7을 반환한다고 생각한다.

Softmax는 10 Probability를 반환하고 argmax가 Class를 선택한다.

09

Image 한 장 Prediction에 `(784,)`만 생각한다.

Model 호출에는 Batch Dimension을 추가해 `(1,784)`로 만든다.

10

Accuracy가 높으면 Loss는 볼 필요가 없다고 생각한다.

Loss는 Probability의 확신 정도까지 반영한다.

Error Reading

오류 메시지 읽는 법

주의

아래 오류는 원본 Notebook 저장 출력의 Exception이 아니라 동일 코드를 수정하거나 확장할 때 발생할 수 있는 대표적인 상황이다.

1. Input Shape Error

expected shape=(None, 784)
found shape=(None, 28, 28)

Flatten하지 않은 28×28 Image를 784 Feature Input Model에 넣은 경우를 확인한다.

2. Single Sample Shape Error

(784,)
vs
(1,784)

Prediction 시 Batch Dimension이 필요한지 확인한다.

3. Label / Loss Shape 문제

Output : (batch,10)
Target : (batch,)

`categorical_crossentropy`를 사용한다면 이번 원본처럼 One-Hot Target `(batch,10)`과 맞는지 확인한다.

4. dtype Error

Input이 문자열이나 object dtype이 아닌 수치 Tensor/Array인지 확인한다.

5. NaN Loss

NaN/Inf 입력, 지나치게 큰 Learning Rate, 잘못된 전처리 등을 확인한다.

Interview Point

면접 포인트

Q1. 이번 문제는 어떤 종류의 문제입니까?

MNIST 손글씨를 숫자 0~9 중 하나로 분류하는 10-Class Multiclass Classification 문제입니다.

Q2. X_train.shape=(60000,28,28)은 무엇입니까?

60,000장의 Training Image가 있고, 각 Image가 28×28 Pixel로 구성된다는 뜻입니다.

Q3. 왜 Flatten합니까?

이번 FFNN Dense Model이 `(batch, feature)` Vector 형태를 사용하므로 28×28 Image를 784차원 Vector로 바꾸기 위해서입니다.

Q4. 이번 Notebook은 Keras Flatten Layer를 사용합니까?

아닙니다. NumPy reshape를 사용해 Model 입력 전에 직접 Flatten합니다.

Q5. 왜 Pixel 값을 255로 나눕니까?

0~255 범위의 Pixel 값을 0~1 범위로 정규화하기 위해서입니다.

Q6. One-Hot Encoding은 무엇입니까?

정수 Class 하나를 Class 개수만큼의 Vector로 표현하고, 정답 위치만 1로 만드는 방식입니다.

Q7. 이번 Architecture는 무엇입니까?

784 → 512(ReLU) → 10(Softmax)입니다.

Q8. 전체 Parameter 수는 얼마입니까?

Hidden Layer 401,920개와 Output Layer 5,130개를 합쳐 총 407,050개입니다.

Q9. Output에 Softmax를 사용하는 이유는 무엇입니까?

10개의 Class에 대한 상대적인 Probability Distribution을 만들기 위해서입니다.

Q10. 왜 categorical_crossentropy를 사용합니까?

정답 Label을 One-Hot Vector로 변환했기 때문입니다.

Q11. Optimizer와 Learning Rate는 무엇입니까?

RMSprop이며 Learning Rate는 0.001입니다.

Q12. Epoch당 375 Step이 나오는 이유는 무엇입니까?

Validation 20%를 제외한 48,000개 Training Sample을 Batch Size 128로 나누기 때문입니다.

Q13. Test Accuracy는 얼마입니까?

현재 저장 Output 기준 약 0.9815, 즉 약 98.15%입니다.

Q14. Accuracy와 Cross Entropy의 차이는 무엇입니까?

Accuracy는 최종 Class가 맞았는지를 보고, Cross Entropy는 정답 Class Probability의 크기까지 반영합니다.

Q15. Image 한 장 Prediction Input Shape는 무엇입니까?

Flatten된 `(784,)` Vector에 Batch Dimension을 추가한 `(1,784)`입니다.

Q16. Prediction Output Shape는 무엇입니까?

10개 Class Probability를 가지므로 `(1,10)`입니다.

Q17. 최종 숫자는 어떻게 결정합니까?

Softmax Probability 중 가장 큰 값의 Index를 np.argmax()로 선택합니다.

Q18. FFNN과 CNN의 이미지 처리 차이는 무엇입니까?

이번 FFNN은 Image를 784 Vector로 펼치지만, CNN은 2차원 공간 구조를 유지하면서 Convolution으로 지역 Feature를 학습합니다.
