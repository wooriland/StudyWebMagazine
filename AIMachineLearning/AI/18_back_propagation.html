01 · 핵심 개념

역전파는 Loss에 대한 Parameter별 미분을 구합니다

신경망은 현재 Parameter θ로 예측값을 계산합니다. 역전파는 “이 Parameter를 아주 조금 바꾸면 Loss가 어떻게 변할까?”를 계산하는 방법입니다. 최종 Loss에서 시작해 계산 그래프를 역순으로 따라가며 연쇄법칙을 적용합니다.

Ŷ = F(X; θ)
L(θ) = ℒ(F(X; θ), Y)

입력과 Label을 고정하면 Parameter 변화가 예측 변화와 Loss 변화로 이어지므로 Loss를 Parameter에 대해 미분할 수 있습니다.

학습의 네 가지 역할
단계핵심 질문결과
순전파현재 모델은 어떤 답을 내는가?예측값 Ŷ
손실 계산예측이 학습 목표에서 얼마나 벗어났는가?스칼라 Loss L
역전파각 Parameter의 작은 변화에 Loss가 얼마나 민감한가?Gradient ∇θL

Loss를 계산하거나 Gradient를 구했다는 사실만으로 Parameter가 갱신되지는 않습니다. 실제 값을 바꾸는 단계는 Update입니다.

02 · 등장 배경

예측이 틀렸다는 사실만으로는 수정 방향을 알 수 없습니다

① 순전파만 반복하는 한계

ŷ = wx+b에서 x=2, w=1, b=0이면 답은 2입니다. Parameter를 그대로 두고 같은 계산을 반복하면 계속 2가 나옵니다. 학습에는 Parameter의 변화가 필요합니다.

② Loss 하나로는 부족

Loss가 10이라고 모든 Weight에서 10을 빼지는 않습니다. 입력과 연결 경로가 달라 각 Weight의 영향과 수정 방향도 다릅니다. 필요한 정보는 각 Weight의 Gradient입니다.

③ Hidden에는 직접 정답이 없음

일반적인 지도학습에서는 최종 출력에 대한 Label이 주어집니다. Hidden 값 0.7의 정답을 따로 주는 대신, 그 값의 변화가 최종 Loss에 미치는 영향을 미분으로 연결합니다.

④ 많은 Parameter의 계산 비용

Weight를 하나씩 조금 바꾸고 Loss를 다시 계산하는 수치 미분은 큰 모델에서 비용이 큽니다. 역전파는 중간 계산을 재사용하여 여러 Parameter의 Gradient를 효율적으로 구합니다.

  1. Hidden 추가복잡한 관계 표현
  2. Parameter 증가각 값의 영향 계산 필요
  3. Chain Rule연산별 미분 연결
  4. 역전파기울기를 효율적으로 계산

입력 X와 Label Y는 이 단원의 기본 학습에서 주어진 데이터로 둡니다. 입력 Gradient도 계산할 수 있지만, 일반적인 모델 학습에서는 주로 학습 대상 Weight·Bias를 갱신합니다.

작은 기울기 ≠ 항상 최솟값

한 Parameter의 Gradient가 0인 것과 전체 Gradient가 0인 것은 다릅니다. 전체 Gradient가 0이어도 안장점·평평한 구간 등일 수 있습니다. 학습률을 크게 선택해 유한한 거리를 이동했을 때 Loss 감소가 항상 보장되는 것도 아닙니다.

06 · Chain Rule

한 경로에서는 곱하고, 여러 경로의 기여는 더합니다

u = f(w), L = g(u)라면 w가 u에 주는 영향과 u가 L에 주는 영향을 연결합니다.

∂L/∂w = (∂L/∂u) · (∂u/∂w)
  1. 뒤에서 받은 Gradient∂L/∂u
  2. 현재 연산의 미분∂u/∂w
  3. 앞으로 전달할 Gradient두 값을 곱함

예를 들어 u=3w이고 뒤에서 받은 ∂L/∂u가 4이면, ∂u/∂w=3이므로 ∂L/∂w=12입니다. 각 연산이 자신의 국소 미분을 연결합니다.

작은 연산의 미분
연산국소 미분역전파에서의 역할
v = a+b∂v/∂a=1, ∂v/∂b=1전달받은 기울기를 각 입력에 연결
v = ab∂v/∂a=b, ∂v/∂b=a반대쪽 입력값을 곱함
v = ReLU(a)a>0에서 1, a<0에서 0양수 경로 통과, 음수 경로의 기울기 0

공유 Weight나 여러 뉴런의 연결에서는 여러 경로의 기여를 합산합니다. 역전파는 이 연쇄법칙을 계산 그래프에서 재사용하는 방법입니다. [B]

08 · Loss·미분

Loss가 다르면 역전파를 시작하는 미분도 달라집니다

샘플 하나의 수치 예측에서 제곱손실을 L=(ŷ−y)²로 정하면 미분은 2(ŷ−y)입니다. 앞에 ½를 붙이면 미분에서 2가 상쇄됩니다.

손실과 미분은 한 쌍
Loss 정의예측값에 대한 미분
(ŷ−y)²2(ŷ−y)
½(ŷ−y)²ŷ−y
(1/B) Σᵢ(ŷᵢ−yᵢ)²2(ŷᵢ−yᵢ)/B

양의 상수 ½를 곱해도 이 손실 자체의 최소점 위치는 같지만 Gradient 크기는 달라집니다. 학습률을 그대로 두면 실제 갱신 크기가 달라집니다.

분류에서는 로그 확률을 연결합니다

BCE = −[ y log p + (1−y) log(1−p) ]

일반적인 이진 Label에서 y=1이면 L=−log p입니다. 정답 클래스 확률이 작으면 손실이 크고, 높아질수록 손실이 작아집니다. y=0이면 반대 클래스에 해당하는 확률이 반영됩니다.

다중 클래스의 Cross-Entropy는 L=−Σₖ yₖ log pₖ입니다. One-hot Label이면 정답 클래스의 로그 확률 항이 남습니다. 학습 Loss는 목적 함수이고 Accuracy는 클래스 정답 비율이므로 둘을 같은 값으로 해석하지 않습니다.

09 · 평균·계수

½·Batch·출력 축의 계수를 끝까지 맞춥니다

Batch 크기는 B, 출력 수는 O, 각 원소 오차는 eᵢⱼ=Ŷᵢⱼ−Yᵢⱼ로 둡니다.

평균 방식에 따른 선형 출력 Gradient
손실 정의집계 방식각 출력에 대한 미분
½ ΣᵢΣⱼ eᵢⱼ²모두 합산eᵢⱼ
[1/(2B)] ΣᵢΣⱼ eᵢⱼ²출력 합 · Batch 평균eᵢⱼ/B
[1/(2BO)] ΣᵢΣⱼ eᵢⱼ²전체 원소 평균의 절반eᵢⱼ/(BO)
[1/(BO)] ΣᵢΣⱼ eᵢⱼ²전체 원소 MSE2eᵢⱼ/(BO)

이 페이지 NumPy 코드의 정확한 정의

loss = 0.5 * np.mean((prediction - Y) ** 2)

전체 원소를 평균하므로 선형 출력 Gradient는 (prediction - Y) / prediction.size입니다. prediction.size = B × O입니다.

Step 1의 출력 합·Batch 평균 수식은 분모가 B입니다. 두 방식은 출력이 하나인 O=1에서 일치합니다. 이 페이지의 고정 예제도 O=1입니다.

출력 Gradient에 평균 계수를 반영했다면 Weight·Bias 기여를 모을 때 다시 무조건 평균하지 않습니다. Keras의 손실 함수·클래스와 Reduction 설정도 함께 확인합니다. [E]

10 · 활성화·분류

활성화는 표현을 바꾸고, 미분은 전달되는 기울기를 바꿉니다

Sigmoid

σ(z)=1/(1+e−z)
σ′(z)=σ(z)(1−σ(z))

포화 구간에서 미분이 작아질 수 있습니다. Hidden에 반복되면 다른 인자와 함께 기울기 전달에 영향을 줍니다.

ReLU

ReLU(z)=max(0,z)
z>0: 미분 1 · z<0: 미분 0

0에서는 수학적으로 미분이 정의되지 않습니다. 구현에서 흔히 0을 선택하며, 손계산은 0 경계를 피합니다.

Softmax는 각 클래스가 독립적이지 않습니다

pᵢ = ezᵢ / Σⱼezⱼ
∂pᵢ/∂zᵢ = pᵢ(1−pᵢ)
∂pᵢ/∂zⱼ = −pᵢpⱼ   (i ≠ j)

분모를 공유하므로 다른 Logit이 변해도 pᵢ가 달라집니다. 전체 미분에는 비대각 항이 있으며 p*(1-p)만으로 처리할 수 없습니다.

단일 샘플의 출력·손실 조합
조합활성화 전 z에 대한 Gradient
선형 출력 + ½(ŷ−y)²ŷ−y
Sigmoid + ½(p−y)²(p−y)p(1−p)
Sigmoid + BCEp−y
Softmax + Cross-Entropy; Σₖyₖ=1각 Logit에 대해 pₖ−yₖ

여기서 p−y는 Logit에 대한 결합 미분입니다. Sigmoid 미분을 다시 곱하면 중복 적용입니다. 평균·가중 손실 등의 조건은 별도로 반영합니다.

클래스 선택과 학습 경로를 구분합니다

일반적인 분류 학습에서는 Logit 또는 확률로 Loss를 계산합니다. argmax나 p >= 0.5의 이산 선택은 결과 해석·평가에 사용하며, 이를 일반적인 손실 미분 경로에 먼저 넣으면 Gradient 전달이 어려워집니다.

실제 구현에서는 안정적인 Logit 기반 손실을 사용할 수 있습니다. 예를 들어 Sigmoid Cross-Entropy는 지수 Overflow를 줄이는 동등한 식으로 구현됩니다. [F]

11 · 교안 수식

교안의 두 층 Sigmoid를 연쇄법칙으로 읽습니다

먼저 입력 하나, 은닉 뉴런 하나, 출력 뉴런 하나인 작은 모델을 생각합니다. 이 절은 교안의 Sigmoid 미분 구조를 설명하며, 뒤의 ReLU → Linear 예제와 활성화 함수가 다릅니다.

z₁ = w₁x + b₁   →   o₁ = σ(z₁)
z₂ = w₂o₁ + b₂   →   o₂ = σ(z₂)
L = ½(o₂−y)²
순전파: x → z₁ → o₁ → z₂ → o₂ → L

역방향 미분의 흐름 (오른쪽에서 출발):
∂L/∂x ← δ₁ ← ∂L/∂o₁ ← δ₂ ← ∂L/∂o₂ ← ∂L/∂L=1

시작값 1은 손실 L을 자기 자신으로 미분한 값입니다. 이 예제에서는 x를 학습시키지 않지만, 그 앞까지 계산 경로가 있다면 ∂L/∂x도 Chain Rule로 구할 수 있습니다.

여기서는 δ₁ = ∂L/∂z₁, δ₂ = ∂L/∂z₂로 정의합니다. δ는 활성화 전 값 z에 대한 손실의 미분이지 단순히 Label과 예측의 차이를 부르는 고정된 이름은 아닙니다.

δ₂ = (o₂−y) · o₂(1−o₂)
δ₁ = δ₂ · w₂ · o₁(1−o₁)
두 층 모델의 Parameter별 기울기
ParameterChain Rule로 연결최종 식
w₂출력층까지 온 기울기 × ∂z₂/∂w₂∂L/∂w₂ = δ₂o₁
b₂출력층까지 온 기울기 × 1∂L/∂b₂ = δ₂
w₁첫 층까지 온 기울기 × ∂z₁/∂w₁∂L/∂w₁ = δ₁x
b₁첫 층까지 온 기울기 × 1∂L/∂b₁ = δ₁

첫 층 Weight의 미분을 풀어 쓰면 (o₂−y) · o₂(1−o₂) · w₂ · o₁(1−o₁) · x입니다. 마지막에 o₁을 한 번 더 곱하지 않습니다. 이미 o₁(1−o₁) 안에 Sigmoid의 미분이 반영되어 있습니다.

δ₁을 계산할 때 쓰는 w₂는 갱신 전 값입니다. 모든 기울기를 구한 뒤 네 Parameter를 갱신합니다.

13 · 작은 손계산

행렬 전에, Weight 하나와 Bias 하나로 끝까지 계산합니다

집값 등의 실제 단위를 붙이지 않은 연습용 회귀 모델입니다. x=2, y=4, w=1, b=0, η=0.1로 시작합니다.

ŷ = wx+b    L = ½(ŷ−y)²
∂L/∂w = (ŷ−y)x    ∂L/∂b = ŷ−y
작은 모델의 한 번의 학습
순서계산결과의 의미
1. 순전파ŷ=1×2+0=2현재 예측은 2입니다.
2. 손실L=½(2−4)²=2정답 4와 차이가 있습니다.
3. 출력 미분∂L/∂ŷ=2−4=−2예측을 조금 높이면 손실이 줄어드는 방향입니다.
4. Weight 미분∂L/∂w=(−2)×2=−4현재 w에 대한 변화율입니다.
5. Bias 미분∂L/∂b=−2현재 b에 대한 변화율입니다.
6. Weight 갱신w′=1−0.1×(−4)=1.4음수를 빼므로 w가 커집니다.
7. Bias 갱신b′=0−0.1×(−2)=0.2b도 커집니다.
8. 다시 순전파ŷ′=1.4×2+0.2=3정답 4에 가까워졌습니다.
9. 다시 손실L′=½(3−4)²=0.5이번 갱신에서는 2 → 0.5로 줄었습니다.

기울기가 음수라고 손실이 음수인 것은 아닙니다. 제곱손실은 0 이상이고, 기울기의 부호는 Parameter를 어느 방향으로 조금 움직일지 알려 줍니다.

14 · 17번 예제

17번 순전파 예제를 그대로 이어갑니다

입력 3개 → ReLU 은닉 뉴런 2개 → 선형 출력 1개입니다. 먼저 갱신 전 값을 고정합니다. 행은 샘플, 열은 Feature 또는 뉴런을 나타내는 규칙을 사용합니다.

X = [[1, 2, 3]]                 Y = [[1]]
     Shape (1, 3)                  Shape (1, 1)

W₁ = [[ 0.2, -0.1],            b₁ = [0.1, 0.2]
      [ 0.5,  0.2],
      [-0.2, -0.3]]
     Shape (3, 2)                  Shape (2,)

      [-0.6]]
     Shape (2, 1)                  Shape (1,)
Z₁ = XW₁+b₁ = [[0.7, −0.4]]

첫 은닉 뉴런은 1×0.2 + 2×0.5 + 3×(−0.2) + 0.1 = 0.7입니다. 두 번째는 1×(−0.1) + 2×0.2 + 3×(−0.3) + 0.2 = −0.4이므로 ReLU를 통과하면 0이 됩니다.

17번의 0.3844와 왜 다른가요?

예측값 0.38과 오차 −0.62는 같습니다. 단순 제곱손실은 (−0.62)²=0.3844이고, 이번 손계산은 미분의 계수 2를 정리하기 위해 ½을 붙여 0.1922로 정의했습니다. 같은 예측에 다른 손실 정의를 적용한 결과입니다.

Parameter는 W₁ 6개 + b₁ 2개 + W₂ 2개 + b₂ 1개 = 11개입니다. X·Y, Z₁·H₁·Ŷ를 Parameter 개수에 넣지 않습니다.

15 · 기울기 추적

출력에서 출발해 11개 Parameter의 기울기를 구합니다

① 선형 출력과 손실

dZ₂ = ∂L/∂Z₂ = Ŷ−Y = [[−0.62]]

선형 출력은 Z₂=Ŷ이므로 활성화 미분이 1입니다. dZ₂는 여기서 ∂L/∂Z₂의 코드 이름입니다. 일반적인 미분 기호 dZ₂와 구분해 읽습니다.

② 출력층 Weight와 Bias

dW₂ = H₁ᵀdZ₂ = [[−0.434], [0]]
db₂ = Σ샘플dZ₂ = [−0.62]

첫 Weight에는 0.7×(−0.62)=−0.434, 두 번째에는 0×(−0.62)=0이 전달됩니다.

③ 은닉층 출력까지 전달

dH₁ = dZ₂W₂ᵀ = [[−0.248, 0.372]]

−0.62×0.4=−0.248, −0.62×(−0.6)=0.372입니다. 이때 아직 ReLU 미분을 곱하지 않았습니다.

④ ReLU를 통과

ReLU′(Z₁) = [[1, 0]]
dZ₁ = dH₁ ⊙ ReLU′(Z₁) = [[−0.248, 0]]

⊙는 원소별 곱입니다. 두 번째 경로의 0.372는 Z₁이 음수인 ReLU를 통과하며 0이 됩니다.

⑤ 첫 층 Weight와 Bias

dW₁ = Xᵀ @ dZ₁
     = [[1],      @ [[-0.248, 0]]
        [2],
        [3]]

     = [[-0.248, 0],
        [-0.496, 0],
        [-0.744, 0]]

db₁ = [-0.248, 0]

Weight의 기울기는 ‘그 연결에 들어간 입력 × 그 뉴런까지 전달된 기울기’입니다. Bias의 미분은 입력을 곱하지 않습니다. Batch에서는 샘플별 기여를 더합니다.

이번 샘플에서 두 번째 은닉 뉴런 경로가 0인 것과, 모든 학습 데이터에서 계속 비활성인 ‘죽은 ReLU’는 다릅니다.

  1. 1. Batch 준비X·Y, dtype, 결측치, Shape를 확인합니다.
  2. 2. 순전파현재 Parameter로 Z·활성화·예측을 계산합니다.
  3. 3. Loss 계산정답과 예측을 선택한 손실 함수로 비교합니다.
  4. 4. 역전파같은 계산 상태로 모든 Parameter Gradient를 구합니다.
  5. 5. Optimizer 갱신Gradient와 학습률·상태로 W·b를 갱신합니다.
  6. 6. 기록·반복Loss·Gradient·평가 지표를 기록하고 다음 Batch로 이동합니다.
Epoch 1
  Batch 1 → Forward → Loss → Backward → Update
  Batch 2 → Forward → Loss → Backward → Update
  ...
Epoch 2
  같은 데이터 집합을 다시 학습 (보통 순서를 섞음)
  ...

NumPy로 순전파·역전파·갱신을 직접 확인합니다

NumPy가 준비된 환경에서 아래 코드 전체를 한 번 실행합니다. 난수를 사용하지 않으므로 위 손계산과 비교할 수 있습니다. 이는 구조를 이해하기 위한 수동 역전파 예제이며, 범용 신경망 라이브러리를 새로 만드는 코드는 아닙니다.

import numpy as np

np.set_printoptions(precision=6, suppress=True)

# 1. 갱신 전 상태: 매번 이 값에서 시작합니다.
X = np.array([[1.0, 2.0, 3.0]])
Y = np.array([[1.0]])
W1 = np.array([[0.2, -0.1],
               [0.5,  0.2],
               [-0.2, -0.3]])
b1 = np.array([0.1, 0.2])
W2 = np.array([[0.4], [-0.6]])
b2 = np.array([0.1])
learning_rate = 0.1

# 2. 순전파와 손실: 모든 예측 원소를 평균합니다.
Z1 = X @ W1 + b1
H1 = np.maximum(0.0, Z1)
prediction = H1 @ W2 + b2
loss_before = 0.5 * np.mean((prediction - Y) ** 2)

# 3. 역전파: 아직 W1, b1, W2, b2를 수정하지 않습니다.
dZ2 = (prediction - Y) / prediction.size
dW2 = H1.T @ dZ2
db2 = dZ2.sum(axis=0)

dH1 = dZ2 @ W2.T
dZ1 = dH1 * (Z1 > 0)
dW1 = X.T @ dZ1
db1 = dZ1.sum(axis=0)

# 4. Shape와 유한값을 점검합니다.
assert prediction.shape == Y.shape
assert dW1.shape == W1.shape
assert db1.shape == b1.shape
assert dW2.shape == W2.shape
assert db2.shape == b2.shape
for gradient in (dW1, db1, dW2, db2):
    assert np.isfinite(gradient).all()

print("Z1:", Z1)
print("H1:", H1)
print("dZ2:", dZ2)
print("dH1:", dH1)
print("dZ1:", dZ1)
print("dW1:\n", dW1)
print("db1:", db1)
print("dW2:\n", dW2)
print("db2:", db2)

# 5. 기울기를 모두 구한 다음 Parameter를 갱신합니다.
W1 -= learning_rate * dW1
b1 -= learning_rate * db1
W2 -= learning_rate * dW2
b2 -= learning_rate * db2

# 6. 갱신 후 값으로 새 예측과 손실을 계산합니다.
prediction_after = np.maximum(0.0, X @ W1 + b1) @ W2 + b2
loss_after = 0.5 * np.mean((prediction_after - Y) ** 2)

print(f"prediction: {prediction.item():.7f} -> "
      f"{prediction_after.item():.7f}")
print(f"loss: {loss_before:.10f} -> {loss_after:.10f}")

21 · 자동 미분

자동 미분도 같은 Chain Rule을 계산합니다

TensorFlow의 GradientTape는 추적한 연산으로부터 미분을 계산합니다. tape.gradient는 Gradient를 반환할 뿐 W·b를 직접 갱신하지 않습니다. 아래는 앞의 작은 손계산 x=2, y=4와 같은 예제입니다. [C]

import tensorflow as tf

# 독립적으로 실행하는 작은 회귀 예제입니다.
x = tf.constant(2.0)
y = tf.constant(4.0)
w = tf.Variable(1.0)
b = tf.Variable(0.0)

with tf.GradientTape() as tape:
    prediction = w * x + b
    loss = 0.5 * tf.square(prediction - y)

# 미분값을 구하는 단계
dw, db = tape.gradient(loss, [w, b])
print("gradients:", float(dw.numpy()), float(db.numpy()))

# Parameter를 갱신하는 단계
learning_rate = 0.1
w.assign_sub(learning_rate * dw)
b.assign_sub(learning_rate * db)

prediction_after = w * x + b
loss_after = 0.5 * tf.square(prediction_after - y)
print(f"prediction after: {float(prediction_after.numpy()):.1f}")
print(f"loss after: {float(loss_after.numpy()):.1f}")

이 예제는 TensorFlow가 설치된 별도 환경용 참고 코드입니다. 이번 검증 환경에서는 TensorFlow를 실행하지 않았으며, 위 수치는 작은 모델의 수식으로 확인한 예상 결과입니다. NumPy 예제는 실제 실행 결과와 대조했습니다.

자동화되는 부분과 사람이 정해야 하는 부분
프레임워크가 처리하는 일직접 설계·검증하는 일
추적된 연산에 Chain Rule 적용모델 구조와 Loss가 문제에 맞는지
공유 경로의 Gradient 기여 누적정답·입력 Shape와 Reduction이 의도에 맞는지
Optimizer 호출 시 Parameter 갱신학습률, Batch 크기, 학습·검증 데이터 분리
지원하는 연산의 미분 구현연산이 추적 가능하게 연결되어 있는지

model.fit() 같은 고수준 학습 기능은 순전파·손실·역전파·Optimizer 적용을 묶어서 반복합니다. 자동화되었다고 손실 정의나 데이터 오류까지 자동으로 고쳐 주는 것은 아닙니다.

TensorFlow Tape 밖의 계산, .numpy()로 빠져나간 연산, 추적되지 않은 Tensor, 목표와 연결되지 않은 Variable 등은 예상한 Gradient를 얻지 못하게 할 수 있습니다. None을 무조건 0으로 바꾸기 전에 연결과 추적을 먼저 확인합니다.

메시지는 Python·NumPy·프레임워크 버전에 따라 조금 달라질 수 있습니다. Traceback 마지막 줄에서 오류 종류와 메시지를 보고, 위쪽에서 자신이 작성한 계산 줄을 찾습니다. 아래의 잘못된 코드는 오류 학습용이며 하나씩 분리해서 확인합니다.

① 행렬곱의 안쪽 차원이 다름

② Bias Broadcasting 실패

ValueError: operands could not be broadcast together with shapes (2,4) (3,)

출력이 (2,4)인데 Bias가 (3,)이면 열 4개와 맞지 않습니다. 이 모델에서 Bias는 보통 출력 뉴런 수에 맞는 (4,)입니다.

26 · 실무 연결

실제 프로젝트에서는 계산 원리가 점검 기준이 됩니다

회귀·분류

가격·수요 예측은 출력 단위와 제곱손실의 스케일을 점검합니다. 분류는 Logit·확률·Label 형식과 Cross-Entropy의 조합을 맞춥니다. 같은 역전파 원리라도 Loss와 출력층이 다르면 시작 Gradient가 달라집니다.

CNN

하나의 필터가 여러 위치에서 사용됩니다. 같은 Weight에 도달하는 여러 위치·샘플의 기여를 더해야 합니다. ‘여러 경로는 합산한다’는 원리가 공유 Parameter 학습으로 이어집니다.

RNN

시간에 따라 펼친 계산 그래프에서 같은 Parameter가 반복 사용됩니다. 시간을 따라 미분하는 BPTT와 긴 경로의 기울기 소실·폭발을 이해하는 기반이 됩니다.

Transformer

Attention, 선형 변환, 정규화, Residual 연결도 계산 그래프의 연산입니다. 구조는 복잡하지만 각 경로의 미분을 연결하고 공유 Parameter의 기여를 모으는 원리는 같습니다.

전이 학습·미세 조정

어떤 층을 업데이트 대상으로 둘지 결정합니다. Parameter를 고정하는 것과 그 연산을 통과하는 Gradient 경로를 끊는 것은 다릅니다. 더 앞에 학습할 층이 있으면 고정된 연산을 통해 Gradient가 전달되어야 할 수 있습니다.

27 · 면접 포인트

면접에서는 정의 다음에 이유와 조건을 말합니다

질문을 먼저 읽고 스스로 답한 뒤 펼쳐 확인해 보세요.

Q1. 역전파란 무엇인가요?

스칼라 손실에서 출발해 계산 그래프를 역방향으로 따라가며 Chain Rule로 각 Parameter 등의 미분을 효율적으로 계산하는 방법입니다. Gradient를 구하는 단계이지 Optimizer 갱신 그 자체는 아닙니다.

Q2. 순전파와 역전파의 차이는 무엇인가요?

순전파는 입력에서 예측·손실 등 값을 계산하고, 역전파는 손실이 앞선 값과 Parameter에 얼마나 민감한지 계산합니다. 역함수를 구하거나 입력을 복원하는 과정이 아닙니다.

Q3. Loss 값만으로 학습할 수 없는 이유는 무엇인가요?

Loss는 현재 목적 함수의 값만 알려 줍니다. Gradient 기반 학습에는 많은 Parameter를 어떤 방향으로 움직일지에 대한 정보가 추가로 필요합니다.

Q4. Chain Rule이 왜 필요한가요?

손실이 Weight의 직접적인 함수 하나가 아니라 여러 연산을 합성한 결과이기 때문입니다. 한 경로의 국소 미분을 곱하고 여러 경로의 기여를 더합니다.

Q5. 왜 Gradient를 빼나요?

Gradient는 현재 위치에서 함수가 가장 빠르게 증가하는 방향입니다. 기본 경사하강은 반대 방향으로 작은 이동을 합니다. 유한한 학습률에서 매번 손실 감소가 보장되지는 않습니다.

Q6. 출력층과 은닉층의 Gradient는 어떻게 다른가요?

출력층은 Loss·출력 활성화의 미분에서 시작합니다. 은닉층은 뒤층의 Gradient를 Weight로 전달받은 뒤 자신의 활성화 미분을 적용합니다. 은닉 뉴런마다 직접 Label을 주는 것은 아닙니다.

Q7. Bias Gradient에서 왜 입력을 곱하지 않나요?

z=Wx+b에서 Bias에 대한 국소 미분은 1이기 때문입니다. Batch에서 공유된 Bias의 기여는 샘플 축으로 합산합니다.

Q8. Sigmoid+BCE에서 p−y는 무엇의 미분인가요?

단일 샘플의 표준 BCE와 Sigmoid를 결합했을 때 활성화 전 Logit z에 대한 미분입니다. 평균·가중 조건은 별도로 반영하며 Sigmoid 미분을 다시 곱하지 않습니다.

Q9. MSE와 ½MSE는 같은가요?

같은 데이터에 상수배 관계인 목적 함수이므로 해당 항만 있으면 최솟값 위치는 같지만 Loss와 Gradient의 크기는 다릅니다. 같은 학습률의 업데이트도 달라질 수 있습니다. 다른 정규화 항이 있으면 상대 가중치까지 고려해야 합니다.

Q10. Gradient가 0이면 최적점인가요?

반드시 그렇지는 않습니다. 비활성 ReLU, 포화, 평평한 영역, 안장점 또는 잘못된 계산일 수 있습니다. 최적성은 추가 조건과 관찰이 필요합니다.

Q11. 기울기 소실과 폭발은 왜 생기나요?

깊거나 긴 경로의 미분·Weight가 반복해서 곱해지며 값의 크기가 크게 줄거나 늘 수 있습니다. 활성화, 초기화, 구조, 학습률과 수치 안정성을 함께 점검합니다.

Q12. Batch 크기가 늘면 Parameter 수도 늘어나나요?

아닙니다. 같은 모델의 Parameter를 여러 샘플이 공유합니다. 중간 활성화의 Batch 축과 메모리 사용은 늘 수 있지만 W·b의 Shape는 모델 구조로 정해집니다.

Q13. 자동 미분은 수치 미분인가요?

일반적인 역방향 자동 미분은 연산별 미분 규칙과 Chain Rule을 사용합니다. Parameter를 조금씩 움직여 차분으로 근사하는 수치 미분과 다릅니다. 실제 계산은 부동소수점 오차의 영향을 받습니다.

Q14. Gradient 0과 None은 어떻게 다른가요?

0은 계산된 미분값일 수 있습니다. None은 보통 추적·연결 등으로 해당 미분을 얻지 못했음을 뜻합니다. 프레임워크와 설정을 확인하고 둘을 무조건 같은 것으로 처리하지 않습니다.

Q15. 왜 모든 Gradient를 먼저 구하고 갱신하나요?

하나의 순전파 상태에 대한 같은 Loss의 Gradient를 사용해야 하기 때문입니다. 중간에 뒤층 Weight를 바꾸고 앞층 Gradient를 계산하면 서로 다른 시점의 값이 섞입니다.

Q16. Momentum·Adam도 역전파인가요?

역전파가 얻은 Gradient를 활용하는 Optimizer입니다. 과거 상태나 적응적 스케일을 사용해 Parameter를 갱신하는 규칙이며, Gradient 계산 방법과 역할이 다릅니다.

Q17. 모델의 일부 층을 고정하면 Gradient 경로도 끊나요?

Parameter를 업데이트하지 않는 것과 미분 경로 차단은 다릅니다. 고정된 층 앞에 학습 대상이 있으면 그 층의 연산을 통한 미분이 필요할 수 있습니다.

Q18. 훈련 Loss가 감소하면 좋은 모델인가요?

해당 학습 목적에는 개선 신호이지만 일반화의 증거로 충분하지 않습니다. 검증·테스트 지표, 데이터 누수, 과적합, 배포 조건을 함께 확인해야 합니다.

28 · 스스로 확인

외운 공식을 작은 질문으로 확인합니다

연습 1. w=2, Gradient=−0.5, η=0.1이면 새 w는?

2−0.1×(−0.5)=2.05입니다. 음수 기울기를 빼므로 값이 커집니다.

연습 2. L=(ŷ−y)², ŷ=0.38, y=1이면 출력 Gradient는?

2(0.38−1)=−1.24입니다. ½이 없는 손실이므로 −0.62와 구분합니다.

연습 3. B=2, O=3이고 ½ mean을 쓰면 분모는?

B×O=6입니다. 선형 출력에서 dZ=(Ŷ−Y)/6입니다. 이후 dW·db에서 다시 6으로 나누지 않습니다.

연습 4. Z₁=−0.4, dH₁=0.372인 ReLU의 dZ₁은?

음수 입력의 ReLU 미분은 0이므로 dZ₁=0.372×0=0입니다. 모든 입력에서 영원히 0이라는 뜻은 아닙니다.

연습 5. X Shape (8,3), W₁ Shape (3,2)이면 dW₁ Shape는?

Parameter와 같은 (3,2)입니다. X.T (3,8) @ dZ₁ (8,2)로 확인합니다.

연습 6. 예측 (8,1), 정답 (8,)을 빼면 안전한가요?

이 회귀 예제에서는 안전하지 않습니다. Broadcasting으로 (8,8)이 될 수 있습니다. 샘플별 정답 하나의 의도라면 Label을 (8,1)로 준비합니다.

연습 7. 첫 층 미분 전에 W₂를 갱신했다면 무엇이 문제인가요?

저장한 활성화는 이전 Parameter에서 계산됐는데 전달에 사용하는 W₂는 새 값이어서 동일 시점의 Loss Gradient가 아니게 됩니다. 전체 미분 계산 후 갱신합니다.

한 단계 더: 수치 미분으로 검산하기

∂L/∂θᵢ ≈ [L(θ+εeᵢ) − L(θ−εeᵢ)] / (2ε)

eᵢ는 i번째 Parameter만 1인 방향입니다. 입력·Label과 다른 Parameter를 고정하고, 해당 Parameter만 ±ε만큼 바꾼 뒤 순전파와 Loss를 매번 다시 계산합니다. 수동 역전파 구현을 점검하는 데 유용하지만 모든 Parameter마다 순전파를 여러 번 해야 하므로 일반적인 학습의 대체 수단은 아닙니다.

ε가 너무 크면 근사 오차가, 너무 작으면 반올림 오차가 커질 수 있습니다. ReLU의 0처럼 미분 불가능한 경계를 넘는 지점은 피하고, Dropout 등 무작위성이 있는 계산은 같은 조건으로 고정해야 합니다.

최종 설명 연습: “순전파로 예측하고 → Loss를 계산하고 → Chain Rule로 Gradient를 구하고 → Optimizer가 Parameter를 갱신한다.” 각 화살표에서 값의 의미가 바뀝니다.

오늘의 암기 포인트

  1. 순전파는 값을, 역전파는 미분을 계산합니다.
  2. Loss·Gradient·Update는 서로 다른 단계입니다.
  3. 한 경로는 곱하고, 여러 경로의 기여는 더합니다.
  4. 기본 갱신은 θ ← θ − η∇L입니다.
  5. Gradient는 해당 Parameter와 같은 Shape입니다.
  6. 손실의 계수와 평균 축도 미분에 반영합니다.
  7. 모든 Gradient는 같은 갱신 전 상태로 계산합니다.
  8. @는 행렬곱, *는 원소별 곱입니다.
  9. ReLU 음수 경로의 미분은 0입니다.
  10. Gradient 0·None·NaN·inf를 구분합니다.
  11. 오류가 없어도 Broadcasting이 잘못될 수 있습니다.
  12. Loss 감소만으로 일반화를 보장하지 않습니다.
