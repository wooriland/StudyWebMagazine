앞 단원의 Logistic Regression은 Class 0과 Class 1 중 하나를 판단했습니다. 그러나 붓꽃 품종, 손글씨 숫자처럼 세 개 이상의 Class 중 하나를 골라야 하는 문제에서는 여러 Class의 Score를 동시에 비교해야 합니다.

03 · BINARY vs MULTI-CLASS

11단원의 Sigmoid가 12단원에서는 Softmax로 확장됩니다

11 · BINARY

Logistic Regression

X ↓ z = XW+b ↓ Sigmoid ↓ p = 0.82 ↓ Threshold 0.5 ↓ Class 1
VS
12 · MULTI-CLASS

Softmax Regression

X ↓ [z₀,z₁,z₂] ↓ Softmax ↓ [p₀,p₁,p₂] ↓ Maximum Probability ↓ Class k

04 · CLASS LOGIT

Softmax 전에 Class마다 하나의 Raw Score를 계산합니다

LOGIT
Softmax를 통과하기 전 각 Class에 대해 Model이 계산한 Raw Score
CLASS 0 z₀ = w₁₀x₁ + w₂₀x₂ + b₀
CLASS 1 z₁ = w₁₁x₁ + w₂₁x₂ + b₁
CLASS 2 z₂ = w₁₂x₁ + w₂₂x₂ + b₂
LOGIT VECTOR z = [z₀, z₁, z₂]

이 값들은 아직 Probability가 아닙니다. 단순히 각 Class가 얼마나 적합한지 나타내는 Score입니다.

Logit ≠ Probability

[1.2, 3.4, 0.8]을 120%, 340%, 80%라고 해석하면 안 됩니다. Softmax를 통과하기 전까지는 Raw Score입니다.

05 · SOFTMAX

여러 Class의 Score를 서로 비교 가능한 Probability로 바꿉니다

SOFTMAX FUNCTION pₖ = ezₖ / Σ ezⱼ
STEP 1 Logits [z₀,z₁,z₂]
→
STEP 2 Exponent [e^z₀,e^z₁,e^z₂]
→
STEP 3 전체 합 S = Σe^z
→
STEP 4 Normalize [p₀,p₁,p₂]
PROPERTY 01 pₖ ≥ 0

모든 Probability는 음수가 아닙니다.

PROPERTY 02 Σpₖ = 1

전체 Class Probability의 합은 1입니다.

PROPERTY 03 Relative Comparison

Class Score를 상대적으로 비교합니다.

보완 계산 예제
Logits = [1, 2, 3]
↓
exp ≈ [2.718, 7.389, 20.086]
↓
Softmax ≈ [0.090, 0.245, 0.665]

세 Probability의 합은 약 1이며, 가장 큰 Probability는 Class 2입니다.

06 · PROBABILITY DISTRIBUTION

하나의 숫자가 아니라 Class 수만큼 Probability가 출력됩니다

CLASS 0 0.10

10%

CLASS 1 0.75

75%

CLASS 2 0.15

15%

0.10 + 0.75 + 0.15 = 1.00
PREDICTION A [0.02, 0.96, 0.02] Class 1

Class 1이 상대적으로 매우 우세합니다.

PREDICTION B [0.32, 0.35, 0.33] Class 1

Class 1이 가장 높지만 세 Class가 매우 비슷합니다.

보완 이해

높은 Softmax Probability를 현실 세계의 절대적인 “정답 확률”과 완전히 같은 의미로 해석하지 않습니다. 우선은 Model이 해당 Class에 상대적으로 높은 Score를 주었다고 이해합니다.

VS
SOFTMAX

One-Hot의 핵심

10 · CROSS ENTROPY

실제 정답 Class에 얼마나 높은 Probability를 주었는지 평가합니다

CATEGORICAL CROSS ENTROPY L = -Σ yₖ log(pₖ)
ACTUAL Y = [0,1,0]
vs
PREDICTION P = [0.2,0.7,0.1]
-[ 0×log(0.2) + 1×log(0.7) + 0×log(0.1) ] ↓ -log(0.7)
왜 정답 Class Probability만 남을까?

One-Hot Label에서 정답 Class 위치만 1이고 나머지는 0이기 때문입니다. 따라서 실제 정답 Class의 Probability가 Loss를 직접 결정합니다.

GOOD Actual = [0,1,0] Prediction = [0.01,0.98,0.01] Loss 작음
BAD Actual = [0,1,0] Prediction = [0.80,0.05,0.15] Loss 큼

15 · NUMPY STRUCTURE

코드는 외우기보다 Logit → Softmax → Loss → Update의 역할을 읽습니다

보완 예제

아래 코드는 첨부 Notebook의 원본 Cell을 그대로 복사한 것이 아니라, Step 1·2의 개념을 한 번에 복습하기 위해 정리한 안정적인 Softmax 구조 예제입니다. 

import numpy as np

def softmax(logits):
    # Numerical Stability
    shifted = logits - np.max(
        logits,
        axis=1,
        keepdims=True
    )

    exp_values = np.exp(shifted)

    return exp_values / np.sum(
        exp_values,
        axis=1,
        keepdims=True
    )


# X : (N, D)
# W : (D, K)
# b : (K,)

logits = X @ W + b

# (N, K)
probabilities = softmax(logits)

# 가장 높은 Class 선택
predictions = np.argmax(
    probabilities,
    axis=1
)
X Feature Matrix
W Class별 Weight
b Class별 Bias
logits Raw Scores
softmax() Probability
axis=1 Class 방향
argmax Class 선택
keepdims Shape 유지
왜 최대 Logit을 먼저 빼는가? · 보완 이해

exp(1000)처럼 지나치게 큰 값이 생기면 Overflow 위험이 있습니다. 모든 Logit에서 같은 최대값을 빼면 상대적인 차이는 유지하면서 수치적으로 더 안정적으로 계산할 수 있습니다.

18 · COMMON MISTAKES

다중 분류에서 자주 헷갈리는 개념을 분리합니다

01

Softmax가 가장 큰 값을 고르는 함수다

Softmax는 Class Score를 Probability Distribution으로 변환합니다. 최종 선택은 그 이후 단계입니다.

02

Softmax Output 중 하나는 반드시 0.5 이상이다

아닙니다. [0.34,0.33,0.33]처럼 모든 Probability가 0.5보다 낮을 수 있습니다.

03

Logit은 Probability다

Logit은 Softmax 전의 Raw Score입니다.

04

Softmax와 Cross Entropy는 같은 기능이다

Softmax는 Probability를 만들고, Cross Entropy는 Loss를 계산합니다.

05

Softmax와 argmax가 같은 것이다

Softmax는 Distribution, argmax는 가장 큰 위치를 선택합니다.

06

One-Hot Label은 Prediction Probability다

One-Hot은 실제 정답 표현이고, Softmax Output은 Model Prediction입니다.

07

CCE와 Sparse CCE는 Label Format이 같다

CCE는 One-Hot, Sparse CCE는 Integer Label과 연결해서 이해합니다.

08

Binary Cross Entropy를 그대로 Multi-Class에 사용하면 된다

교안의 기본 구조는 Binary는 BCE, Multi-Class는 CCE 계열입니다.

09

Output Node 수와 Class 수는 상관없다

일반적인 Multi-Class Output은 Class 수만큼 Score를 만들어야 합니다.

10

Softmax를 Hidden Layer의 대표 Activation으로 사용한다

교안 흐름에서는 Hidden Layer는 ReLU 계열, Multi-Class Output은 Softmax로 구분합니다.

11

Multi-Class와 Multi-Label은 같은 문제다

Multi-Class는 여러 Class 중 하나, Multi-Label은 여러 Label이 동시에 가능할 수 있는 다른 문제입니다.

12

Softmax Probability가 높으면 현실에서 무조건 맞다

높은 Probability로 틀릴 수도 있습니다. 현재 Model의 상대적인 Score 관계로 먼저 해석합니다.

exp Overflow

exp(large logit) Stable Softmax

ERROR 05 · 보완

log(0)

log(probability) epsilon / clipping

Output 수 부족

22 · INTERVIEW POINT

“Logit → Softmax → Probability → Cross Entropy” 순서로 설명하면 다중 분류 구조가 흔들리지 않습니다

Q1. Multi-Class Classification이란 무엇인가요?

여러 개의 Class 후보 중 하나의 Class를 선택하는 Classification 문제입니다.

Q2. Logit이란 무엇인가요?

Softmax를 적용하기 전에 Model이 각 Class에 대해 계산한 Raw Score입니다.

Q3. Softmax의 역할은 무엇인가요?

여러 Class의 Logit을 전체 합이 1인 Class별 Probability Distribution으로 변환합니다.

Q4. Softmax Output의 특징은 무엇인가요?

각 Probability가 0 이상이며 모든 Class Probability의 합이 1입니다.

Q5. Sigmoid와 Softmax의 차이는 무엇인가요?

교안 흐름에서는 Sigmoid를 Binary Classification, Softmax를 Multi-Class Classification Output에 연결합니다.

Q6. Softmax와 argmax는 무엇이 다른가요?

Softmax는 Probability Distribution을 만들고, argmax는 가장 높은 Probability의 Index를 선택합니다.

Q7. Multi-Class에서도 Threshold 0.5를 사용하나요?

일반적인 Single-Label Multi-Class 문제에서는 각 Class Probability 중 가장 높은 값을 가진 Class를 선택합니다.

Q8. One-Hot Encoding이란 무엇인가요?

정답 Class 위치만 1이고 나머지 Class 위치는 0으로 표현하는 Label Encoding입니다.

Q9. Cross Entropy는 무엇을 평가하나요?

실제 정답 Class에 Model이 얼마나 높은 Probability를 부여했는지를 Loss로 표현합니다.

Q10. Categorical Cross Entropy와 Sparse CCE의 차이는 무엇인가요?

Categorical Cross Entropy는 One-Hot Label, Sparse Categorical Cross Entropy는 Integer Label과 연결해서 이해합니다.

Q11. Multi-Class Output Node 수는 어떻게 정하나요?

일반적인 Multi-Class Classification에서는 Class별 Score가 필요하므로 Class 수에 맞춰 Output을 구성합니다.

Q12. Softmax와 Cross Entropy를 같이 사용하는 이유는 무엇인가요?

Softmax는 Class별 Probability Distribution을 만들고, Cross Entropy는 그 Distribution이 실제 Label에 얼마나 잘 맞는지 Loss로 계산합니다.

Q13. Decision Region이란 무엇인가요?

Feature Space에서 특정 Class가 가장 높은 Probability를 가져 해당 Class로 Prediction되는 영역입니다.

Q14. Softmax Probability가 높으면 반드시 정답인가요?

아닙니다. Model이 잘못 학습되었다면 높은 Probability로 잘못 Prediction할 수도 있습니다.

Q15. Multi-Class가 되어도 Gradient Descent 원리는 같은가요?

네. Prediction → Loss → Gradient → Parameter Update라는 기본 학습 구조는 계속 유지됩니다.
