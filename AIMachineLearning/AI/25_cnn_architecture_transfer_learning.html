01 · CORE IDEA

대표 CNN의 역사는 설계 문제를 해결해 온 과정입니다

교안의 ImageNet·AlexNet·VGG·GoogLeNet·ResNet·MobileNet 흐름을 구조화

AlexNet → VGG → GoogLeNet → ResNet → MobileNet

AlexNet

대규모 이미지 분류에서 깊은 CNN의 가능성을 보여주었습니다.

VGG

작은 3×3 Convolution을 규칙적으로 반복했습니다.

GoogLeNet

여러 크기의 특징을 병렬로 계산하고 1×1 Conv로 비용을 줄였습니다.

ResNet

입력을 더하는 Skip Connection으로 매우 깊은 모델을 학습했습니다.

MobileNet

공간 연산과 Channel 결합을 분리해 경량화했습니다.

모델 이름보다 “왜 이런 구조가 필요했는가?”를 먼저 설명할 수 있어야 합니다.

06 · VGG

작은 3×3 Convolution을 규칙적으로 반복합니다

등장 질문 큰 Kernel 대신 작은 3×3 Kernel을 반복하면 더 단순하고 깊은 모델을 만들 수 있을까?
BLOCK 1 Conv → Conv → Pool 낮은 Channel·큰 공간
BLOCK 2 Conv → Conv → Pool Channel 증가·공간 감소
BLOCK 3~5 Conv → Conv → Conv → Pool 더 깊은 Feature 계층

VGG-16의 16을 정확히 읽습니다

일반적으로 13개의 Convolution Layer와 3개의 Fully Connected Layer를 합한 16개의 Weight Layer를 의미합니다. “Convolution Layer만 16개”로 읽지 않습니다.

장점

구조가 단순하고 Block 반복 규칙이 명확해 이해하기 쉽습니다.

한계

깊은 Layer와 큰 Fully Connected 부분으로 Parameter가 많습니다.

다음 연결

여러 크기의 Pattern을 동시에 보는 GoogLeNet으로 이어집니다.

07 · VGG FORMULA

작은 Filter 반복은 Receptive Field와 Parameter를 함께 조절합니다

입·출력 Channel을 모두 C로 단순화한 비교
구성 Receptive Field Bias 제외 Weight
5×5 Conv 1회 5×5 25C²
3×3 Conv 2회 약 5×5 18C²
3×3 Conv 3회 약 7×7 27C²

5×5 Conv 1회: 5×5×C×C = 25C²

3×3 Conv 2회: 2×3×3×C×C = 18C²

3×3 Conv 두 번은 유사한 5×5 Receptive Field를 만들면서 더 적은 Weight와 두 번의 ReLU를 사용할 수 있습니다.

08 · GOOGLENET · INCEPTION

여러 크기의 Feature를 병렬 Branch에서 동시에 추출합니다

등장 질문 서로 다른 크기의 Pattern을 동시에 찾고 큰 Kernel의 계산량도 줄일 수 있을까?
Input Feature Map
BRANCH 1 1×1 Conv
BRANCH 2 1×1 → 3×3 Conv
BRANCH 3 1×1 → 5×5 Conv
BRANCH 4 Max Pool → 1×1 Conv
Channel 방향 Concatenate

Multi-Scale

1×1·3×3·5×5·Pooling으로 크기가 다른 특징을 동시에 계산합니다.

Bottleneck

비용이 큰 Conv 전에 1×1 Conv로 Channel 수를 줄입니다.

Global Average Pooling

큰 Fully Connected 부분을 줄이고 Channel별 평균을 사용합니다.

Auxiliary Classifier

깊은 중간 Layer에도 보조 Loss를 전달합니다.

보조 분류기 손실

교안의 개념식: L_total = L_final + 0.3L_aux1 + 0.3L_aux2

장점은 다양한 Scale과 계산 효율이고, 한계는 Branch가 많아 구조와 Shape 관리가 복잡하다는 점입니다.

09 · INCEPTION BOTTLENECK

1×1 Conv로 Channel을 줄이면 큰 Kernel 비용이 감소합니다

직접 3×3 Conv 3×3×32×64 18,432 Weight
VS
1×1 축소 후 3×3 Conv 1×1×32×16 + 3×3×16×64 9,728 Weight

18,432 − 9,728 = 8,704

절감률 ≈ 47.2% · Bias 제외 교안 예제 기준

1×1 Conv는 공간 크기를 크게 보지 않지만, 각 위치에서 Channel 조합을 학습하며 큰 Kernel 앞의 입력 Channel을 줄이는 Bottleneck 역할을 합니다.

10 · RESNET

입력을 건너뛰어 더해 매우 깊은 Network의 학습을 돕습니다

등장 질문 Layer를 더 깊게 쌓아도 입력 정보와 Gradient를 뒤쪽까지 잘 전달할 수 있을까?
x
Conv → BN → ReLU → Conv → BN
Shortcut: x
Add → y
y = F(x) + x

Residual Learning

전체 변환보다 입력에서 필요한 변화량 F(x)를 학습합니다.

Gradient 경로

연산 경로 외에 Shortcut을 통한 직접 경로가 생깁니다.

다양한 깊이

ResNet-18·34·50·101·152 등으로 확장됩니다.

Backbone

분류·탐지·분할·전이 학습의 대표 Feature Extractor입니다.

11 · RESIDUAL FORMULA & SHAPE

직접 Gradient 경로와 Add 가능한 Shape을 함께 확인합니다

y = F(x) + x

∂y/∂x = ∂F(x)/∂x + 1

+1 항은 Shortcut을 통한 직접 Gradient 경로를 수식으로 보여줍니다. 다만 이 구조가 모든 최적화 문제를 자동으로 제거한다는 뜻은 아닙니다.

Add를 위한 Tensor Shape
경우 처리
F(x)와 x의 Shape이 같음 Identity Shortcut으로 바로 Add
공간 크기·Channel이 다름 1×1 Projection Conv와 Stride로 맞춘 뒤 Add

교안의 3.57% Error 표현

특정 ImageNet 평가 지표에서 참고 Human Performance보다 낮은 Error를 기록했다는 범위로 읽습니다. 모든 시각 문제에서 인간 능력을 일반적으로 초과했다는 뜻은 아닙니다.

12 · MOBILENET

공간 연산과 Channel 결합을 분리해 Mobile·Edge 환경을 겨냥합니다

등장 질문 Normal Convolution의 역할을 분리하면 제한된 장치에서도 빠르게 실행할 수 있을까?
STEP 1 Depthwise Conv Channel별 공간 특징
→
STEP 2 Pointwise 1×1 Conv Channel 정보 결합
분리된 두 연산
연산 담당 역할
Depthwise Conv 입력 Channel마다 독립적으로 공간 특징 추출
Pointwise Conv 1×1 Filter로 Channel 결합· 출력 Channel 조절

장점

Parameter·연산량·모델 파일 크기를 줄일 수 있습니다.

사용 환경

Smartphone·Embedded·Edge· 실시간 Camera와 연결됩니다.

한계

지나친 경량화는 표현력과 정확도 Trade-off를 만들 수 있습니다.

주의

Parameter 감소와 실제 Device Latency 감소가 항상 비례하지 않습니다.

13 · MOBILENET PARAMETER

Normal Conv와 Depthwise Separable Conv를 같은 조건에서 비교합니다

예제 조건: Kernel 3×3 · 입력 Channel 32 · 출력 Channel 64 · Bias 제외

Parameter 계산
구성 수식 Weight 수
Normal Conv 3×3×32×64 18,432
Depthwise 3×3×32 288
Pointwise 1×1×32×64 2,048
Separable 전체 288+2,048 2,336
Normal: 18,432 → Separable: 2,336 약 87.3% 감소 · 이 예제 조건

87.3%는 모든 MobileNet 설정의 고정값이 아니라 이번 Kernel·Channel 조건에서 계산한 값입니다.

17 · PRE-TRAINED INFERENCE

ResNet50 전체 ImageNet 모델로 새 이미지를 분류합니다 

import numpy as np

from tensorflow.keras.applications.resnet50 import (
    ResNet50,
    preprocess_input,
)

from tensorflow.keras.applications.imagenet_utils import (
    decode_predictions,
)

from tensorflow.keras.utils import (
    load_img,
    img_to_array,
)


model = ResNet50(
    include_top=True,
    weights="imagenet",
    input_shape=(224, 224, 3),
)

image = load_img(
    "./sample.jpg",
    target_size=(224, 224),
)

image_array = img_to_array(image)

image_batch = np.expand_dims(
    image_array,
    axis=0,
)

image_batch = preprocess_input(
    image_batch
)

prediction = model.predict(
    image_batch,
    verbose=0,
)

print(prediction.shape)
# (1, 1000)

top5 = decode_predictions(
    prediction,
    top=5,
)

for rank, (_, label, score) in enumerate(
    top5[0],
    start=1,
):
    print(
        f"Top {rank}: "
        f"{label} - {score * 100:.2f}%"
    )
  1. Resize 224×224×3
  2. Batch 축 (1,224,224,3)
  3. Preprocess ResNet50 전용 처리
  4. Predict 1,000개 ImageNet Class

18 · TRANSFER LEARNING CODE

ResNet50 Backbone을 동결하고 새로운 5개 Class Head를 연결합니다 

import tensorflow as tf


IMAGE_SIZE = 224
CLASS_COUNT = 5


base_model = tf.keras.applications.ResNet50(
    include_top=False,
    weights="imagenet",
    input_shape=(
        IMAGE_SIZE,
        IMAGE_SIZE,
        3,
    ),
)

base_model.trainable = False


inputs = tf.keras.Input(
    shape=(
        IMAGE_SIZE,
        IMAGE_SIZE,
        3,
    )
)

x = tf.keras.applications.resnet50.preprocess_input(
    inputs
)

x = base_model(
    x,
    training=False,
)

x = tf.keras.layers.GlobalAveragePooling2D()(x)

x = tf.keras.layers.Dropout(0.3)(x)

outputs = tf.keras.layers.Dense(
    CLASS_COUNT,
    activation="softmax",
)(x)


model = tf.keras.Model(
    inputs=inputs,
    outputs=outputs,
)

model.compile(
    optimizer="adam",
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

model.summary()
설정과 의미
설정 의미
weights="imagenet" ImageNet 사전 학습 Weight 사용
include_top=False 기존 1,000 Class Head 제거
trainable=False Backbone Weight 동결
GlobalAveragePooling2D Channel별 Feature를 Vector로 요약
Dense(5) 새로운 5개 Class 예측

19 · RESIDUAL BLOCK CODE

입력과 연산 결과의 Shape이 같은 기본 Residual Block입니다 

import tensorflow as tf


def residual_block(
    inputs: tf.Tensor,
    filters: int,
) -> tf.Tensor:
    shortcut = inputs

    x = tf.keras.layers.Conv2D(
        filters=filters,
        kernel_size=3,
        padding="same",
        use_bias=False,
    )(inputs)

    x = tf.keras.layers.BatchNormalization()(x)
    x = tf.keras.layers.ReLU()(x)

    x = tf.keras.layers.Conv2D(
        filters=filters,
        kernel_size=3,
        padding="same",
        use_bias=False,
    )(x)

    x = tf.keras.layers.BatchNormalization()(x)

    x = tf.keras.layers.Add()([
        x,
        shortcut,
    ])

    return tf.keras.layers.ReLU()(x)

Add 전에 Shape을 확인합니다

공간 크기나 Channel 수가 다르면 Shortcut에 1×1 Projection Conv와 필요한 Stride를 적용해야 합니다.

22 · COMMON MISTAKES

모델 이름·사전 학습·구조 연결 방식을 혼동하지 않습니다

자주 하는 착각과 올바른 해석
착각 올바른 해석
ImageNet은 CNN 모델 Dataset·Benchmark 기반입니다.
더 깊은 모델은 항상 더 정확함 Dataset·과적합·연산·학습 조건을 함께 봅니다.
VGG-16은 Conv가 16개 일반적으로 13 Conv + 3 FC입니다.
Inception Branch는 Add 일반적으로 Channel 방향 Concatenate입니다.
ResNet은 중간 Layer를 실행하지 않음 연산 경로와 Shortcut 경로를 함께 사용합니다.
Skip Add는 Shape이 달라도 가능 Element-wise Add를 위해 Shape을 맞춰야 합니다.
MobileNet은 Conv를 사용하지 않음 Depthwise와 Pointwise Conv를 사용합니다.
Parameter가 적으면 모든 장치에서 빠름 Memory Access·Runtime·Hardware도 영향을 줍니다.
weights="imagenet"이면 내 Class를 예측 기존 1,000개 ImageNet Class 기준입니다.
include_top=False면 Class 확률 출력 Backbone Feature Map이 출력됩니다.
trainable=False면 전체 모델이 학습 안 됨 새롭게 추가한 Head는 학습할 수 있습니다.
모든 preprocess_input은 동일 모델 계열별 전처리를 사용합니다.

25 · INTERVIEW POINTS

구조 이름보다 등장 이유와 정보 전달 방식을 설명합니다

Q1. ImageNet은 무엇인가요?

대표 CNN을 학습·비교하고 사전 학습 Weight를 만드는 기반이 된 대규모 Labeling 이미지 Dataset입니다.

Q2. AlexNet의 핵심은 무엇인가요?

ReLU·Max Pooling·깊은 CNN으로 대규모 이미지 분류에서 CNN의 가능성을 보여준 모델입니다.

Q3. VGG의 설계 원칙은 무엇인가요?

작은 3×3 Convolution을 규칙적으로 반복하여 단순하고 깊은 Feature 추출 Block을 만드는 것입니다.

Q4. VGG-16의 16은 무엇인가요?

일반적으로 13개의 Convolution Layer와 3개의 Fully Connected Layer를 합한 16개의 Weight Layer입니다.

Q5. 작은 3×3 Conv를 반복하는 장점은 무엇인가요?

넓은 Receptive Field를 만들면서 Parameter를 줄일 수 있고, ReLU를 여러 번 적용할 수 있습니다.

Q6. GoogLeNet의 핵심은 무엇인가요?

서로 다른 크기의 Convolution과 Pooling을 병렬 적용하는 Inception Module입니다.

Q7. Inception에서 1×1 Conv를 왜 사용하나요?

비용이 큰 3×3·5×5 Conv 앞에서 Channel 수를 줄여 Parameter와 연산량을 낮추기 위해 사용합니다.

Q8. Inception Branch 결과는 어떻게 합치나요?

Height·Width를 맞춘 뒤 일반적으로 Channel 방향으로 Concatenate합니다.

Q9. ResNet의 핵심 수식은 무엇인가요?

y = F(x) + x입니다.

Q10. Residual Learning은 무엇인가요?

전체 변환을 직접 학습하기보다 입력에서 필요한 변화량 F(x)를 학습하는 관점입니다.

Q11. Skip Connection은 Gradient에 어떻게 도움이 되나요?

입력과 Gradient가 여러 Layer를 건너뛰어 전달될 수 있는 직접 경로를 제공합니다.

Q12. ResNet Add가 실패하는 이유는 무엇인가요?

연산 경로와 Shortcut 경로의 Height·Width·Channel Shape이 서로 다르기 때문입니다.

Q13. MobileNet의 핵심은 무엇인가요?

Normal Convolution을 Depthwise Convolution과 Pointwise Convolution으로 분리하는 것입니다.

Q14. Depthwise와 Pointwise의 역할은 무엇인가요?

Depthwise는 Channel별 공간 특징을, Pointwise는 Channel 결합과 출력 Channel 조절을 담당합니다.

Q15. Parameter가 적으면 실제 추론도 항상 빠른가요?

아닙니다. Hardware·Memory Access·Runtime 최적화가 실제 Latency에 영향을 줍니다.

Q16. Backbone과 Head의 차이는 무엇인가요?

Backbone은 Feature를 추출하고, Head는 Feature를 현재 Task의 최종 출력으로 변환합니다.

Q17. include_top=False의 의미는 무엇인가요?

기존 ImageNet 분류 Head를 제거하고 Backbone Feature를 사용한다는 뜻입니다.

Q18. 사전 학습 추론과 전이 학습의 차이는 무엇인가요?

추론은 기존 Class와 Head를 그대로 사용하고, 전이 학습은 기존 Feature를 새로운 Dataset과 Head에 재사용합니다.
