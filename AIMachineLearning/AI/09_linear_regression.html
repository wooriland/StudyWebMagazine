05 · WEIGHT & BIAS

W는 선의 기울기를, b는 선의 기본 위치를 결정합니다

WEIGHT · W

기울기

W가 바뀌면 선이 얼마나 가파르게 올라가거나 내려가는지가 달라집니다.

BIAS · b

절편

b가 바뀌면 같은 기울기의 선이 위 또는 아래로 이동합니다.

W > 0 Positive Relationship
↗

x가 증가할수록 Prediction도 증가합니다.

W < 0 Negative Relationship
↘

x가 증가할수록 Prediction은 감소합니다.

W ≈ 0 Weak Linear Change
→

x 변화에 따른 Prediction 변화가 작습니다.

이번 단원의 학습 의미

선형회귀가 “학습한다”는 것은 Data에 가장 잘 맞도록 W와 b를 찾는 것입니다.

09 · NUMPY EXAMPLE

교안의 단순 선형회귀는 Model의 학습 과정을 직접 코드로 보여줍니다

AI 이론 과목에서는 코드 문법을 외우기보다 각 코드가 어떤 개념을 구현하는지 연결합니다.

TRUE RELATION y = 5x + 10 + noise
W_true 5
b_true 10
Samples 100
Noise Random 
import numpy as np

# 현재 Parameter로 예측
y_pred = W * X + b

# Loss: Mean Squared Error
loss = np.mean(
    (y_pred - y) ** 2
)

# Gradient
dW = np.mean(
    2 * (y_pred - y) * X
)

db = np.mean(
    2 * (y_pred - y)
)

# Parameter Update
W -= learning_rate * dW
b -= learning_rate * db
X Feature
y Actual
W Weight
b Bias
y_pred Prediction
loss MSE
dW / db Gradient
learning_rate Hyperparameter

예측한다 → 틀린 정도를 계산한다 → 기울기를 계산한다 → W와 b를 고친다

16 · MSE & R²

Error의 크기와 Model의 설명력을 서로 다른 관점에서 봅니다

MSE

Prediction Error

1/N × Σ(y - ŷ)² 작을수록 좋음 ↓

실제값과 Prediction이 얼마나 차이 나는지를 봅니다.

+
R²

설명력

1 - SS_res / SS_tot 일반적으로 클수록 좋음 ↑

Target의 전체 변동을 Model이 얼마나 설명하는지 봅니다.

R²를 평균 Baseline으로 이해하기
Baseline

모든 Sample에 y 평균을 예측

VS
Linear Regression

ŷ = XW+b로 각 Sample을 Prediction

선형회귀 Model이 단순한 평균 Prediction보다 Target의 변화 패턴을 더 잘 설명할수록 R²는 좋은 방향으로 올라갑니다.

구분 MSE R²
관점 Error 크기 Target 변동 설명력
좋은 방향 ↓ 작게 ↑ 크게
이상적 상태 0 1
단위 Target 단위² 무차원
보완 이해 Test Data에서 R²는 음수가 나올 수도 있습니다

교안은 초보 학습 관점에서 R²를 주로 0~1 범위로 소개하지만, 실제 평가에서는 현재 Model이 단순히 Target 평균을 예측하는 Baseline보다도 못할 경우 음수가 나타날 수 있습니다. 따라서 R² < 0을 Python 오류라고 생각해서는 안 됩니다.

18 · SOURCE CAUTION

교안 원문과 보완 검토 내용을 서로 구분해서 공부합니다

CAUTION 01

R² 예제의 산술값

AI 교안의 R² 설명 자체는 학습에 사용하지만, 예시로 표시된 일부 실제값·예측값과 중간 제곱합 및 최종 R² 숫자는 서로 맞지 않는 부분이 있습니다. 따라서 해당 숫자를 HTML에 정답처럼 그대로 복사하지 않고 R²의 의미와 공식 중심으로 사용합니다.

CAUTION 02

NumPy 다중 선형회귀 저장 출력 없음

다중 선형회귀 Notebook에는 코드가 존재하지만 저장된 실행 출력이 없습니다. 최종 W·b·Loss는 재실행 전까지 자료에 없는 정보로 취급합니다.

CAUTION 03

LinearRegression의 내부 해법

선형회귀 문제의 W와 b를 Gradient Descent로 찾을 수 있지만 scikit-learn의 LinearRegression을 BGD나 특정 정규방정식 구현과 완전히 동일하다고 단정하지 않습니다. 교안 통합본도 이 부분을 단순화된 설명으로 검토하고 있습니다.

CAUTION 04

전처리와 Data Leakage

통합 교안의 일부 후속 실습은 Feature Selection 또는 Scaling을 Train/Test 분할 전에 전체 Data에 fit하여 Data Leakage가 생기는 부분이 검토 메모로 표시되어 있습니다. 실무에서는 Training Data에만 fit하고 Test Data에는 transform만 적용하는 흐름을 사용합니다.

19 · LIMITS & COMPLEMENTS

선형회귀는 이해하기 쉽지만 모든 관계를 하나의 선으로 표현할 수는 없습니다

LIMIT 01

Linear Relationship

기본 Model은 Feature와 Target의 관계를 선형식으로 설명합니다. 강한 비선형 관계에서는 표현력이 부족할 수 있습니다.

→ Polynomial / Nonlinear Model
LIMIT 02

Outlier 영향

MSE는 큰 Error를 제곱하기 때문에 매우 멀리 떨어진 Sample이 Loss와 회귀선에 큰 영향을 줄 수 있습니다.

→ Error Distribution 확인
LIMIT 03

Feature 증가와 Overfitting

Feature가 많아지면 Weight 수도 증가하고 Training Data에 지나치게 맞을 위험이 커질 수 있습니다.

→ Ridge / Lasso
LIMIT 04 · 보완 이해

Multicollinearity

거의 같은 정보를 가진 Feature가 여러 개 존재하면 회귀계수 해석이 불안정해질 수 있습니다.

→ Feature 관계 확인
LIMIT 05 · 보완 이해

Extrapolation

Training Data 범위를 크게 벗어난 값을 넣으면 Model은 직선을 그대로 연장하지만 현실도 계속 선형이라는 보장은 없습니다.

→ Training Range 확인
LIMIT 06 · 보완 이해

Correlation ≠ Causation

두 변수가 함께 변한다고 해서 하나가 다른 하나의 직접 원인이라고 바로 결론 내릴 수는 없습니다.

→ Prediction과 인과 해석 구분

21 · COMMON MISTAKES

선형회귀를 단순히 “직선 하나 그리는 공식”으로만 기억하지 않습니다

01

Linear Regression은 Classification이다

선형회귀는 기본적으로 연속적인 숫자를 예측하는 Regression Model입니다.

02

Regression은 곡선을 뜻한다

Regression은 문제 유형이고, Linear Regression은 선형식을 사용하는 회귀 Model입니다.

03

y와 ŷ는 같은 의미다

y는 Actual Target, ŷ는 Model Prediction으로 구분합니다.

04

Weight와 Feature는 같다

Feature는 입력 Data이고, Weight는 Model이 학습하는 Parameter입니다.

05

Weight가 크면 무조건 가장 중요한 Feature다

Feature Scale과 다른 Feature들의 관계 때문에 Weight 절대값만 단순 비교하는 것은 주의해야 합니다.

06

Bias가 음수면 잘못 학습된 Model이다

아닙니다. 교안의 키→몸무게 실습에서도 학습된 Bias는 음수입니다.

07

회귀선은 모든 점을 통과해야 한다

현실 Data에는 Noise가 있으므로 전체 Error를 작게 만드는 선을 찾는 것이 목표입니다.

08

Linear Regression은 Feature 하나만 사용한다

Feature 하나는 Simple, 여러 개는 Multiple Linear Regression입니다.

09

다중 선형회귀도 2D 직선 하나다

Feature가 증가하면 평면 또는 더 높은 차원의 초평면으로 확장됩니다.

10

MSE는 클수록 좋다

반대입니다. 같은 Data와 조건에서는 MSE가 작을수록 Prediction Error가 작은 방향입니다.

11

MSE와 R²는 같은 방식으로 읽는다

MSE는 작아지는 방향, R²는 일반적으로 커지는 방향을 봅니다.

12

R²는 절대로 음수가 될 수 없다

실제 Test 평가에서는 평균 Baseline보다 못한 Model에 음수가 나타날 수 있습니다.

13

Linear Regression = Gradient Descent

Linear Regression은 Model이고, Gradient Descent는 Parameter를 찾는 방법 중 하나입니다.

14

scikit-learn LinearRegression은 반드시 GD다

특정 Library 구현 방식과 선형회귀 문제 자체를 구분해야 합니다.

15

Feature 하나면 X는 항상 1차원이어도 된다

scikit-learn의 입력 X는 (n_samples, n_features) 형태가 필요합니다.

16

Training Data 성능만 좋으면 충분하다

새로운 Data에서도 잘 Prediction하는지 Test Data로 Generalization을 확인해야 합니다.

17

상관관계가 높으면 원인이다

Prediction 관계와 인과관계는 서로 다른 주장입니다.

23 · INTERVIEW POINT

“연속값 → XW+b → Error → W,b 학습” 흐름으로 설명하면 됩니다

Q1. Linear Regression이란 무엇인가요?

하나 이상의 Feature와 연속형 Target 사이의 선형 관계를 모델링하여 숫자를 Prediction하는 지도학습 회귀 Model입니다. Training Data를 잘 설명하는 Weight와 Bias를 찾습니다.

Q2. Regression과 Classification의 차이는 무엇인가요?

Regression은 집값이나 몸무게처럼 연속형 숫자를 Prediction하고, Classification은 정상/암처럼 범주를 Prediction합니다.

Q3. Simple과 Multiple Linear Regression의 차이는?

Simple Linear Regression은 Feature가 하나이고, Multiple Linear Regression은 Feature가 두 개 이상입니다.

Q4. ŷ = Wx + b에서 각 항은 무엇인가요?

x는 Feature, W는 Weight, b는 Bias, ŷ는 Model Prediction입니다. 실제 Target은 y로 구분합니다.

Q5. 선형회귀에서 Weight는 무엇인가요?

Feature가 Prediction에 반영되는 Model Parameter입니다. 단순 선형회귀에서는 회귀선의 기울기와 연결됩니다.

Q6. Bias란 무엇인가요?

Feature와 Weight의 곱에 추가되는 Parameter로, 단순 선형회귀 그래프에서는 y축 절편과 연결됩니다.

Q7. 선형회귀에서 학습한다는 것은 무엇인가요?

Prediction과 실제값의 Error가 작아지도록 Training Data를 가장 잘 설명하는 Weight와 Bias를 찾는 과정입니다.

Q8. MSE는 왜 사용하나요?

Prediction과 Actual의 차이를 제곱한 뒤 평균하여 전체 Prediction Error를 하나의 값으로 표현할 수 있고, 이를 Parameter 학습 기준으로 사용할 수 있기 때문입니다.

Q9. R²는 무엇인가요?

결정계수로, Target의 변동을 현재 회귀 Model이 얼마나 설명하고 있는지를 나타내는 평가 지표입니다.

Q10. MSE와 R²는 어떻게 다르나요?

MSE는 Prediction Error의 크기를 측정하고, R²는 Target 변화에 대한 Model의 설명력을 상대적으로 평가합니다.

Q11. Linear Regression과 Gradient Descent는 같은가요?

아닙니다. Linear Regression은 Prediction Model의 형태이고, Gradient Descent는 그 Model의 Parameter를 찾을 수 있는 Optimization 방법 중 하나입니다.

Q12. scikit-learn에서 X를 왜 2차원으로 사용하나요?

Machine Learning의 입력 Feature Matrix를 (n_samples, n_features) 구조로 표현하기 때문입니다.

Q13. 회귀선이 모든 점을 통과하지 않는 이유는 무엇인가요?

현실 Data에는 Noise와 Model에 포함되지 않은 요인이 존재하기 때문에 모든 관측치를 정확히 통과하기보다 전체 Error를 줄이는 관계를 찾습니다.

Q14. 다중 선형회귀에서 XW의 의미는 무엇인가요?

여러 Feature로 구성된 Matrix X와 각 Feature의 Weight로 구성된 Vector W를 행렬곱하여 Sample별 선형 Prediction을 계산하는 것입니다.

Q15. R²가 음수가 나올 수 있나요?

실제 Test 평가에서는 가능합니다. Model이 단순한 Target 평균 Baseline보다 Prediction을 못할 경우 음수로 나타날 수 있습니다.

Q16. Linear Regression의 대표적인 한계는 무엇인가요?

선형 관계를 가정한다는 점, Outlier에 영향을 받을 수 있다는 점, 다중회귀에서 Feature가 많아질수록 Overfitting과 계수 해석 문제가 생길 수 있다는 점 등이 있습니다.
