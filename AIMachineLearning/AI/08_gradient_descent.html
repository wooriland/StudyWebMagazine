Follow the Slope

경사하강법 Loss가 작아지는 방향을 찾고 Parameter를 한 걸음씩 이동하다

앞 단원에서 Loss를 이용해 현재 Model이 얼마나 틀렸는지 계산했습니다. 하지만 Loss를 계산하는 것만으로 Weight와 Bias가 자동으로 좋아지지는 않습니다.

미분으로 현재 위치의 기울기를 구하고, Gradient의 반대 방향으로 Learning Rate만큼 Parameter를 이동합니다. 이 과정을 반복하면서 더 작은 Loss를 만드는 Weight와 Bias를 찾아갑니다.

04 · DERIVATIVE & SLOPE

미분은 현재 위치에서의 순간 변화율과 기울기를 알려줍니다

POSITIVE
기울기 > 0

오른쪽으로 갈수록 함수값이 증가합니다.

ZERO
기울기 = 0

현재 위치에서 접선이 수평입니다.

NEGATIVE
기울기 < 0

오른쪽으로 갈수록 함수값이 감소합니다.

TANGENT LINE

곡선의 한 지점에서 접선의 기울기를 봅니다

●

곡선은 위치에 따라 기울기가 달라집니다. 그래서 현재 Weight 위치의 기울기를 계산해야 합니다.

AI에서는 이렇게 질문합니다
“현재 Weight를 아주 조금 바꾸면 Loss는 얼마나, 어느 방향으로 바뀌는가?”

05 · GRADIENT

Parameter가 여러 개라면 각 방향의 기울기를 함께 봅니다

ONE PARAMETER

Derivative

dLoss / dW

Weight 하나에 대한 Loss 변화율

→
MANY PARAMETERS

Gradient

∇Loss

여러 Parameter에 대한 기울기들의 집합

GRADIENT VECTOR · 보완 이해 [ ∂Loss/∂W₁, ∂Loss/∂W₂, ∂Loss/∂W₃, ..., ∂Loss/∂b ]
GRADIENT > 0 Weight 감소 W - α(+g)
GRADIENT < 0 Weight 증가 W - α(-g)
“Descent”는 Weight를 감소시킨다는 뜻이 아닙니다

Weight 자체를 작게 만드는 것이 아니라 Loss가 감소하는 방향으로 Weight를 이동시키는 것입니다.

06 · PARTIAL DERIVATIVE & CHAIN RULE

W와 b가 동시에 존재하므로 각각에 대해 편미분합니다

WEIGHT ∂Loss / ∂W

b를 고정하고 W 변화에 따른 Loss 변화를 봅니다.

BIAS ∂Loss / ∂b

W를 고정하고 b 변화에 따른 Loss 변화를 봅니다.

Chain Rule이 필요한 이유

PARAMETER W
→
MODEL ŷ = Wx + b
→
ERROR ŷ - y
→
LOSS MSE
CHAIN RULE
Weight가 Prediction에 미치는 영향과 Prediction이 Loss에 미치는 영향을 연쇄적으로 연결해 계산합니다.
교안의 선형회귀 MSE 연결 ∂E/∂W = 2/N × Σ x(ŷ - y) ∂E/∂b = 2/N × Σ(ŷ - y)

이번 단원에서는 식을 통째로 암기하기보다 MSE → 편미분 → dW, db라는 관계를 우선 이해합니다.

07 · PARAMETER UPDATE FORMULA

현재 Parameter에서 Gradient 방향의 반대로 이동합니다

WEIGHT UPDATE W_new = W_current - α × ∂Loss/∂W
W_current 현재 Weight
∂Loss/∂W Gradient
α Learning Rate
W_new 새 Weight
BIAS UPDATE b_new = b_current - α × ∂Loss/∂b
한국어로 읽기

현재 Parameter에서 현재 Loss의 기울기 × Learning Rate만큼 빼서 새로운 Parameter를 만듭니다.

10 · NUMPY CODE

교안의 NumPy 코드에서 Gradient Descent를 그대로 읽습니다

AI 이론 과목이므로 문법을 외우기보다 각 줄이 학습 과정에서 어떤 역할인지 읽습니다. 

# Prediction
y_pred = W * X + b

# Loss: MSE
loss = np.mean(
    (y_pred - y) ** 2
)

# Gradient
dW = np.mean(
    2 * (y_pred - y) * X
)

db = np.mean(
    2 * (y_pred - y)
)

# Parameter Update
W -= learning_rate * dW
b -= learning_rate * db

12 · BGD vs SGD vs MINI-BATCH

Gradient를 계산할 때 몇 개의 Sample을 사용하는지가 다릅니다

BGD

Batch Gradient Descent

1 2 3 4 ... N
전체 Dataset
  • 전체 Data로 Gradient 계산
  • 1 Epoch당 Update 1회
  • 상대적으로 안정적
  • 큰 Data에서는 계산 비용 큼
SGD

Stochastic Gradient Descent

1
Sample 1개
  • Sample마다 Gradient 계산
  • Update 매우 잦음
  • Noise에 민감
  • Loss가 많이 진동 가능
MINI-BATCH

Mini-Batch Gradient Descent

1 2 ... 32
Sample 여러 개
  • 일부 Data로 Gradient 계산
  • BGD보다 빠름
  • SGD보다 안정적
  • Deep Learning에서 주로 사용
기준 BGD SGD Mini-Batch
사용 Data 전체 1 Sample N Samples
Update 빈도 낮음 매우 높음 중간
Loss 안정성 높음 낮음 절충
Deep Learning 제한적 개념적 기반 주로 사용
Batch Size와 연결

Mini-Batch에서 한 묶음에 몇 개의 Sample을 넣을지는 Hyperparameter입니다. 예를 들어 1000개 Sample을 Batch Size 100으로 나누면 1 Epoch에 약 10번의 Parameter Update가 발생합니다.

기본 Gradient Descent의 한계가 이후 Optimizer와 활성화 함수 발전으로 연결됩니다

LIMIT 01

Fixed Learning Rate

Training 전체에서 같은 보폭을 사용하면 상황에 따라 비효율적일 수 있습니다.

LIMIT 02

→ Momentum
LIMIT 03

Saddle Point

Gradient가 0에 가까워도 실제 Global Minimum이 아닐 수 있습니다.

→ Advanced Optimizer
LIMIT 04

Vanishing Gradient

깊은 Network에서 작은 미분값이 반복 곱해지면 앞 Layer의 Gradient가 거의 0이 될 수 있습니다.

→ ReLU 등
VANISHING GRADIENT
0.25 × 0.25 × 0.25 × 0.25 → 아주 작은 값

교안은 Sigmoid와 tanh 계열의 작은 미분값이 깊은 신경망의 역전파 과정에서 반복적으로 곱해지면서 기울기 소실 문제가 발생할 수 있다고 설명합니다.

16 · COMMON MISTAKES

기울기, Parameter, Learning Rate를 서로 다른 역할로 구분해야 합니다

01

미분은 공식 암기 그 자체다

먼저 현재 지점에서 함수가 어느 방향으로 얼마나 변하는지 알려주는 변화율로 이해합니다.

02

Gradient와 Weight는 같다

Weight는 현재 Parameter, Gradient는 그 Parameter 방향의 Loss 변화율입니다.

03

Gradient Descent는 Weight를 계속 감소시킨다

Gradient가 음수이면 Weight는 증가할 수 있습니다. 줄이는 것은 Weight가 아니라 Loss입니다.

04

Gradient 방향으로 움직인다

Gradient는 Loss 증가 방향이므로 Gradient Descent는 반대 방향으로 이동합니다.

05

Gradient = Learning Rate

Gradient는 변화 방향, Learning Rate는 Update 크기입니다.

06

Learning Rate는 Parameter다

Weight와 Bias는 Parameter, Learning Rate는 Hyperparameter입니다.

07

Learning Rate가 클수록 무조건 좋다

너무 크면 최소점을 지나치며 진동하거나 발산할 수 있습니다.

08

Learning Rate가 작을수록 항상 정확하다

지나치게 작으면 학습 속도가 매우 느려질 수 있습니다.

09

Gradient = 0이면 항상 Global Minimum이다

단순 Convex 문제와 달리 복잡한 Deep Learning에서는 Local Minimum이나 Saddle Point 가능성도 있습니다.

10

Loss는 매 Step 반드시 감소한다

SGD·Mini-Batch에서는 Data Noise 때문에 Loss가 일부 진동할 수 있습니다.

11

Back Propagation과 Gradient Descent는 같다

Backprop은 Gradient 계산, Gradient Descent는 Parameter Update입니다.

12

모든 Machine Learning이 Gradient Descent를 쓴다

Decision Tree·Random Forest처럼 다른 방식으로 학습하는 Algorithm도 있습니다.

13

LinearRegression은 항상 Gradient Descent다

선형회귀 문제를 Gradient Descent로 풀 수 있지만 특정 Library 구현체가 반드시 같은 방식을 사용하는 것은 아닙니다.

14

BGD·SGD·Mini-Batch는 서로 다른 Loss다

차이는 Gradient 계산에 얼마만큼의 Training Data를 사용하는가입니다.

GRADIENT SHAPE
Error (100, 1) × X (100, 3) → (100, 3) mean(axis=0) → dW (3,)

여러 Feature가 있는 Model에서는 Parameter Shape와 Gradient Shape가 서로 맞는지 확인하는 습관이 중요합니다.

STATE 01

Loss 발산

Learning Rate ↑↑ → Update ↑↑ → Divergence
STATE 02

Loss 감소가 너무 느림

Learning Rate ↓↓ → Update ↓↓ → Slow
STATE 03

Loss 진동

Noisy Gradient → SGD / Small Batch
STATE 04

Parameter 거의 안 바뀜

  • Gradient가 너무 작은가?
  • Learning Rate가 너무 작은가?
  • Parameter가 Trainable한가?
Gradient 학습이 이상하면
Loss → Prediction → Gradient → Gradient Shape → Learning Rate → Parameter Update

Mini-Batch → Forward → Loss → Backprop → Gradient → Optimizer → Update

19 · INTERVIEW POINT

“Loss → Gradient → 반대 방향 Update”로 설명합니다

Q1. Gradient Descent란 무엇인가요?

Loss Function을 Parameter에 대해 미분해 Gradient를 계산하고, Gradient의 반대 방향으로 Parameter를 반복적으로 Update하여 더 작은 Loss를 만드는 Parameter를 찾는 최적화 방법입니다.

Q2. 미분은 왜 필요한가요?

현재 Parameter를 조금 변경했을 때 Loss가 어느 방향으로 얼마나 변하는지를 계산하기 위해 필요합니다.

Q3. Gradient란 무엇인가요?

Loss를 각 Parameter에 대해 미분한 값들의 집합으로, Loss가 증가하는 방향을 나타냅니다. Gradient Descent는 그 반대 방향으로 움직입니다.

Q4. 왜 Gradient를 빼나요?

Gradient가 Loss가 증가하는 방향이기 때문에 Loss를 줄이려면 그 반대 방향으로 Parameter를 이동해야 하기 때문입니다.

Q5. Learning Rate란 무엇인가요?

Gradient를 이용해 Parameter를 Update할 때 한 번에 얼마나 크게 이동할지 결정하는 Hyperparameter입니다.

Q6. Learning Rate가 너무 크면 어떻게 되나요?

Parameter Update 폭이 너무 커져 Loss Minimum을 반복해서 지나치거나 Training이 진동·발산할 수 있습니다.

Q7. Learning Rate가 너무 작으면 어떻게 되나요?

Parameter가 아주 조금씩만 바뀌기 때문에 Loss는 감소하더라도 Training에 매우 많은 시간이 필요할 수 있습니다.

Q8. 편미분은 무엇인가요?

Loss가 W와 b처럼 여러 Parameter의 함수일 때 다른 Parameter를 고정하고 특정 Parameter 하나에 대한 변화율을 계산하는 것입니다.

Q9. Chain Rule은 왜 필요한가요?

Weight가 Loss에 바로 연결되는 것이 아니라 Weight → Prediction → Error → Loss처럼 여러 계산을 거치기 때문에 각 단계의 미분값을 연결해야 합니다.

Q10. Back Propagation과 Gradient Descent의 차이는?

Back Propagation은 Chain Rule을 이용해 각 Parameter의 Gradient를 계산하는 과정이고, Gradient Descent는 계산된 Gradient를 이용해 Parameter를 Update하는 방법입니다.

Q11. BGD, SGD, Mini-Batch GD의 차이는?

한 번 Gradient를 계산할 때 사용하는 Training Sample 수가 다릅니다. BGD는 전체 Dataset, SGD는 Sample 하나, Mini-Batch는 여러 Sample을 사용합니다.

Q12. Gradient가 0이면 항상 최적값인가요?

단순 Convex 문제에서는 최소점과 연결하기 쉽지만, 일반적인 Non-Convex Deep Learning에서는 Local Minimum이나 Saddle Point 같은 다른 정지점일 수도 있습니다.

Q13. 모든 Machine Learning Model이 Gradient Descent를 사용하나요?

아닙니다. 선형회귀·로지스틱 회귀·Neural Network 등에서 Gradient 기반 최적화를 사용할 수 있지만, Decision Tree나 Random Forest는 다른 방식으로 학습합니다.

Q14. LinearRegression은 항상 Gradient Descent를 사용하나요?

아닙니다. 선형회귀 문제 자체는 Gradient Descent로 풀 수 있지만 실제 Library 구현에서는 선형대수 기반 Solver 등 다른 방법을 사용할 수 있습니다.
