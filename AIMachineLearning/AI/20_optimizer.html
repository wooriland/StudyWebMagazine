03 · BASIC UPDATE

Gradient의 반대 방향으로, 정한 크기만큼 이동합니다

교안 A의 기본식 · 표기·국소 근사는 보완 [A]

θ_t = θ_(t−1) − η_t g_t

θ_(t−1)은 Update 전 값, g_t는 그 현재 위치에서 계산한 Gradient, η_t는 이번 Learning Rate, θ_t는 새 값입니다. 교안의 W_new = W_current − 학습률 × Loss 미분값 을 기호로 옮겼습니다.

보완 수식 · 왜 Gradient를 빼는가?

g가 미분 가능한 현재 Loss의 Gradient라면 작은 이동의 1차 근사로 L(θ−ηg) ≈ L(θ)−η‖g‖² 입니다. 충분히 작은 국소 이동에서 Loss를 줄이는 방향으로 연결됩니다.

큰 Learning Rate나 일부 데이터의 Gradient에서는 실제 전체 Loss가 증가할 수 있습니다. 이 근사를 전역적인 감소 보장으로 사용하지 않습니다.

같은 Learning Rate가 같은 이동량은 아닙니다

보완 예제 g=[2,0.2], η=0.1이면 Δθ=[−0.2,−0.02]입니다. 기본 GD에서도 Gradient가 다르면 실제 이동량은 다릅니다.

적응형 방법은 여기에 과거 정보에 따른 Parameter별 조정을 더합니다.

교안은 기본식의 고정 학습률·과거 정보 미반영을 보완하는 방법을 Optimizer로 소개합니다. 보완 용어 범위로는 기본 GD도 최적화 알고리즘입니다. 기본 GD로 신경망을 학습하는 것이 불가능하다는 뜻은 아닙니다.

04 · BGD / SGD / MINI BATCH

하나의 Gradient를 어떤 Sample들로 만들까요?

교안 A · 24~26쪽 [A]

BGD · 전체 데이터

전체 학습 데이터로 Gradient를 계산한 뒤 한 번 Update합니다. 기본 전체 순회 기준으로 Epoch당 1회입니다.

교안은 평균적인 정보의 안정성과 한 번의 계산량이 큰 한계를 설명합니다.

SGD · Sample 하나

교안의 좁은 정의에서는 하나를 선택해 바로 Update합니다. 각 Sample을 한 번씩 사용하는 Epoch라면 N회입니다.

Sample별 정보가 달라 방향과 Loss가 흔들릴 수 있습니다.

Mini Batch · 일부 묶음

일부 Sample로 Gradient를 만들고 Update합니다. 묶음 크기는 Hyperparameter입니다.

교안은 전체 계산과 Sample 하나의 변동 사이의 절충으로 설명합니다.

평균 손실을 사용하는 보완 표기

L(θ) = (1/N) Σ_i ℓ_i(θ)

g_t = (1/|B_t|) Σ_(i∈B_t) ∇θℓ_i(θ_(t−1))

B_t는 이번 Sample 집합입니다. 전체면 BGD, 하나면 좁은 의미의 SGD, 일부 묶음이면 Mini Batch입니다. 한 Batch 안에서는 모두 같은 Update 전 Parameter에서 계산 합니다.

교안의 표현을 읽는 조건

SGD는 무작위 방향으로 걷는 것이 아니라 선택된 Sample의 실제 Gradient를 사용합니다. 섞어서 한 번씩 순회할지 복원추출할지는 구현 정책입니다.

BGD의 “안정적”은 전체 평균 정보의 특징이지 모든 Learning Rate에서 수렴한다는 보장이 아닙니다. Batch Size를 보통 2의 거듭제곱으로 잡는다는 설명도 수학적 제한은 아닙니다.

07 · MOMENTUM

이전 이동량을 현재 Gradient의 제안과 합칩니다

교안의 관성 비유 [A] · 수식은 보완, Keras SGD의 기본 Momentum과 연결 [C]

교안은 공이 언덕을 내려오는 관성을 비유로 사용합니다. 같은 방향의 이동을 이어 가고, 반복되는 좌우 진동을 줄이려는 방법입니다.

u_t = μu_(t−1) − ηg_t

θ_t = θ_(t−1) + u_t

여기서 u는 Parameter에 더하는 실제 이동량입니다. μ는 이전 이동을 얼마나 남길지 정하는 계수이며 이번 예제에서는 0.9입니다. μ=0이면 기본 GD가 됩니다.

  1. 이전 이동 μ × 이전 u
  2. 새 이동 제안 −η × 현재 g
  3. 이동 합치기 새 u를 Parameter에 더함

현재 Gradient와 실제 이동 방향이 잠시 다를 수도 있습니다

관성이 남으면 최솟값을 지나칠 수 있습니다. 이전 정보를 사용한다는 장점과 그에 따른 이동 경로를 함께 봅니다.

교안에는 빠르다는 설명과 뒤의 느리다는 표현이 함께 있습니다. 조건이 제시되지 않은 속도·사용 빈도 문장을 보편적인 순위로 합치지 않고, 현재 단원에서는 관성의 계산 원리를 우선 읽습니다.

08 · ADAGRAD

Parameter마다 제곱 Gradient 이력을 누적합니다

교안의 가중치별 조정 설명 [A] · 수식은 Step 1·2 보완

교안은 많이 업데이트된 가중치와 적게 업데이트된 가중치의 학습률을 다르게 조정한다고 설명합니다. 수식으로는 횟수만이 아니라 제곱 Gradient의 크기와 이력을 누적합니다.

G_t = G_(t−1) + g_t²

θ_t = θ_(t−1) − ηg_t / (√G_t + ε)

부호 있는 현재 g

이번 이동 방향에 사용합니다.

누적 상태 G

과거 g²를 모아 위치별 조정 크기에 사용합니다.

보완식은 초기 G=0, 제곱근 밖의 ε를 사용합니다. 실제 Keras에는 초기 누적값 설정이 있으므로 수식의 설정과 API를 구분합니다. [D]

교안의 “학습이 멈춘다”를 읽는 범위

고정 기본 η와 누적 상태를 유지하면 G는 감소하지 않아 조정 계수가 작아질 수 있습니다. 유용한 진행이 지나치게 느려진다는 취지이지, 모든 경우 특정 시점에 Update가 정확히 0이 된다는 뜻은 아닙니다.

Gradient 자체도 바뀌므로 실제 이동량까지 항상 단조롭게 감소한다고 단정하지 않습니다.

09 · RMSPROP

오래된 제곱 Gradient의 영향은 점차 줄입니다

교안의 AdaGrad 보완 설명 [A] · 기본 RMSProp의 제곱 평균 확인 [D]

교안은 과거 기울기의 이동평균을 사용하는 방법으로 설명합니다. 기본 수식을 구체화하면 Gradient 자체가 아니라 제곱 Gradient의 이동평균 입니다.

s_t = ρs_(t−1) + (1−ρ)g_t²

θ_t = θ_(t−1) − ηg_t / (√s_t + ε)

AdaGrad

과거 제곱 Gradient를 계속 더합니다.

RMSProp

이전 요약값을 할인하고 새 제곱 Gradient를 반영합니다.

과거 90%, 현재 10%인데 왜 최근 정보를 반영할까요?

ρ=0.9, s₀=0 → s_t=0.1g_t²+0.09g_(t−1)²+0.081g_(t−2)²+…

과거 요약 전체와 현재값의 비중을 비교하는 것과, 각 개별 Gradient의 비중을 비교하는 것은 다릅니다. 오래된 개별 정보일수록 영향이 작아집니다.

교안의 “학습률이 0으로 수렴하지 않는다”는 영구 누적의 축소 문제를 보완한다는 취지로 읽습니다. 실제 Update가 절대 작아지지 않는다는 뜻은 아닙니다. 이 페이지의 수식은 기본 원리를 설명하는 형태이며 추가 옵션의 전체 구현은 아닙니다.

10 · ADAM

방향 평균과 제곱 크기 평균을 함께 사용합니다

교안의 장점 결합 설명 [A] · 상세 수식은 Step 1·2 보완과 논문 Algorithm 1 [E]

교안 표현과 상세 수식을 구분합니다

교안은 “Momentum과 AdaGrad의 장점 결합”으로 설명합니다. 이는 방향의 기억과 Parameter별 조정의 개념적 연결입니다. 상세 수식에서는 두 지수이동평균과 초기화 편향 보정을 따로 확인합니다.

m · Gradient 평균

m_t=β₁m_(t−1)+(1−β₁)g_t

부호를 가진 방향 정보를 요약합니다.

v · 제곱 Gradient 평균

v_t=β₂v_(t−1)+(1−β₂)g_t²

크기 조정에 사용할 정보를 요약합니다.

0으로 시작한 이동평균의 편향 보정

m₀=v₀=0으로 시작하므로 초반 평균에는 0 초기화의 영향이 있습니다. 아래의 hat은 보정된 값을 표시합니다. t는 1부터 시작하는 Update 번호입니다.

m_hat_t = m_t / (1−β₁^t)

v_hat_t = v_t / (1−β₂^t)

θ_t = θ_(t−1) − η m_hat_t / (sqrt(v_hat_t) + ε)

β₁^t의 t는 거듭제곱 지수입니다. v는 2차 원점 Moment 추정값이며, 평균을 빼는 통계적 분산과 동일하게 외우지 않습니다.

  1. 현재 g 두 평균에 각각 반영
  2. 편향 보정 0 초기화 영향 보완
  3. 방향·크기 조합 보정된 m과 v로 이동

신경망의 Bias b와 Adam의 Bias Correction은 다릅니다. 전자는 모델 Parameter, 후자는 이동평균의 초기화 편향 보정입니다. Adam에도 기본 Learning Rate가 필요합니다.

17 · PURE PYTHON EXPERIMENT

동일한 작은 목적함수에서 Update 규칙을 확인합니다

독립 실행용 보완 코드 · Step 1·2의 목적함수·설정·수식 유지

J(w)=(w−3)², w=0, 기본 η=0.1, 10회 Update, 모든 상태 초기값 0입니다. 데이터를 BGD·SGD·Mini Batch로 나누는 실습이 아니므로 기본 규칙을 GD로 표시합니다.

아래 코드는 특정 Keras Optimizer의 재구현이 아닙니다. 적응형 분모는 sqrt(state)+epsilon, ε=1e−8입니다. 

import math


def optimize(
    method: str,
    steps: int = 10,
    learning_rate: float = 0.1,
) -> list[tuple[int, float, float]]:
    """보완 예제: J(w)=(w-3)^2. 특정 Library의 재구현은 아닙니다."""
    methods = {"GD", "Momentum", "AdaGrad", "RMSProp", "Adam"}
    if not isinstance(method, str) or method not in methods:
        raise ValueError("지원하지 않는 최적화 방법입니다.")
    if type(steps) is not int or steps < 1:
        raise ValueError("steps는 양의 정수여야 합니다.")
    if not math.isfinite(learning_rate) or learning_rate <= 0:
        raise ValueError("learning_rate는 유한한 양수여야 합니다.")

    # 새 실험마다 동일한 시작점과 새로운 상태를 사용합니다.
    w = 0.0
    velocity = sum_sq = mean_sq = m = v = 0.0
    mu = rho = beta1 = 0.9
    beta2 = 0.999
    epsilon = 1e-8
    history: list[tuple[int, float, float]] = []

    for t in range(1, steps + 1):
        # 현재 Parameter에서 Gradient를 다시 계산합니다.
        g = 2.0 * (w - 3.0)

        if method == "GD":
            w -= learning_rate * g
        elif method == "Momentum":
            velocity = mu * velocity - learning_rate * g
            w += velocity
        elif method == "AdaGrad":
            sum_sq += g * g
            w -= learning_rate * g / (math.sqrt(sum_sq) + epsilon)
        elif method == "RMSProp":
            mean_sq = rho * mean_sq + (1.0 - rho) * g * g
            w -= learning_rate * g / (math.sqrt(mean_sq) + epsilon)
        else:  # Adam
            m = beta1 * m + (1.0 - beta1) * g
            v = beta2 * v + (1.0 - beta2) * g * g
            m_hat = m / (1.0 - beta1 ** t)
            v_hat = v / (1.0 - beta2 ** t)
            w -= learning_rate * m_hat / (math.sqrt(v_hat) + epsilon)

        # Update 이후의 Loss를 기록합니다.
        loss = (w - 3.0) ** 2
        if not all(math.isfinite(value) for value in (
            w, loss, velocity, sum_sq, mean_sq, m, v
        )):
            raise FloatingPointError("계산에서 NaN·무한대가 발생했습니다.")
        history.append((t, w, loss))

    return history


for name in ("GD", "Momentum", "AdaGrad", "RMSProp", "Adam"):
    step, weight, loss = optimize(name)[-1]
    print(
        f"{name:8s} | step={step:2d} | "
        f"w={weight:.6f} | loss={loss:.6f}"
    )

assert math.isclose(optimize("GD", steps=1)[0][1], 0.6)
assert math.isclose(optimize("Adam", steps=1)[0][1], 0.1, abs_tol=1e-8)

초기화 위치를 확인하세요

함수 호출 시작은 새 실험이므로 w와 상태를 초기화합니다. 반복문 안에서는 상태를 지우지 않고 갱신합니다. 새로운 실험의 초기화와 같은 실험의 연속 Update를 구분합니다.

keras.optimizers.Adam 0.001 · 기본값 [E]

공식 SGD에는 기본 Momentum 외의 옵션도 있고, AdaGrad는 초기 누적값을, RMSProp은 추가 설정을 제공합니다. Keras Adam의 ε 정의는 논문 Algorithm 1의 ε와 구분된다고 문서에 명시되어 있습니다.

여기서는 새로운 Optimizer 변형을 추가로 학습하지 않습니다. API 차이는 교안·보완 수식과 실제 구현을 혼합하지 않기 위한 확인 사항 입니다.

22 · COMMON MISTAKES

분류·수식·실험 조건을 혼동하지 않습니다

앞 카드의 교안 내용과 보완 해석을 복습합니다

착각을 오른쪽 문장으로 바로잡아 봅니다
자주 하는 착각 올바른 해석
BGD와 Adam은 같은 기준의 선택지다 데이터 단위와 Update 규칙을 구분합니다.
SGD API는 항상 Batch Size 1이다 Mini Batch에도 사용할 수 있습니다.
Adam의 Batch Size를 1로 바꾸면 SGD 객체가 된다 데이터 단위만 달라지고 규칙은 Adam입니다.
Batch Size는 반드시 2의 거듭제곱이다 교안의 대표 관행이지 수학적 제한이 아닙니다.
같은 Learning Rate면 이동 크기도 같다 Gradient와 상태가 다르면 이동량도 다릅니다.
모든 Optimizer는 η 자체를 매번 변경한다 η·Schedule·적응적 조정·관성을 구분합니다.
AdaGrad는 횟수만 센다 제곱 Gradient를 누적합니다.
RMSProp은 부호 있는 Gradient 평균만 사용한다 여기서 설명한 기본 규칙은 제곱 Gradient 평균입니다.
Adam v는 정확한 통계적 분산이다 2차 원점 Moment 추정과 분산을 구분합니다.
Bias Correction은 신경망 b를 수정한다 이동평균의 0 초기화 영향을 보정합니다.
ε만 키우면 모든 NaN이 해결된다 분모 안정성과 입력·미분 오류를 구분합니다.
Gradient 0이면 최솟값이다 안장점 등 다른 정지점일 수 있습니다.
Gradient를 구하면 Parameter도 바뀐다 Update를 실제로 적용해야 합니다.
상태를 매번 0으로 초기화해도 같다 과거의 기억이 사라집니다.
10회 실행 결과가 일반적인 알고리즘 순위다 특정 함수·초기값·설정·횟수의 결과입니다.
같은 모델을 계속 학습하며 비교하면 공정하다 두 번째가 이미 학습된 값과 상태에서 시작할 수 있습니다.

23 · ERROR READING

Gradient·상태·실제 이동량에서 첫 이상 지점을 찾습니다

재실습용 보완 사례 · 원본 오류 로그가 아니며 버전마다 문구·발생 조건이 다릅니다

01. Gradient가 None

숫자 0과 다릅니다. Loss와 변수가 연결되었는지, 연산이 추적되었는지, 중간에 NumPy 계산으로 미분 경로를 벗어났는지 확인합니다. [H]

02. shape mismatch

W와 Gradient의 위치별 Shape을 확인합니다. 전체 Gradient를 Scalar로 축약하지 않았는지 살피고, 예외 없이 Broadcasting되는 잘못된 Update도 확인합니다.

03. NaN · inf · OverflowError

입력 → 출력 → Loss → Gradient → State → 이동량 → 새 Parameter 순으로 봅니다. 학습률·입력 Scale·수식 오류를 ε 문제와 구분합니다.

04. math domain error

직접 구현의 제곱근 안이 음수인지 확인합니다. 기본식의 제곱 상태에는 g가 아니라 g²를 반영합니다. 초기 상태·계수 조건도 확인합니다.

05. Parameter가 안 변함

실제 Update 호출, 학습률, 0·None Gradient, 출력 반올림, 모델 재초기화를 구분합니다. g가 0이어도 Momentum 상태가 남아 움직일 수 있습니다.

06. 매번 첫 Adam 단계처럼 보임

반복문 안에서 Optimizer나 m·v를 새로 만들지 않았는지 확인합니다. 새 실험의 초기화와 같은 실험의 연속 Update를 구분합니다.

07. Update 수가 예상과 다름

검증 분리 후 N, 마지막 Batch, Gradient 누적, steps_per_epoch 등을 확인합니다. Batch 처리와 Parameter Update 횟수는 다를 수 있습니다. [C]

예외 메시지뿐 아니라 Parameter·Gradient·State의 Shape, 유한값, 실제 변경량을 함께 확인합니다.

지속적 발산을 단순 진동으로 방치하지 않고, 한 번의 Batch Loss 상승을 무조건 실패로 보지도 않습니다. 같은 평가 조건에서 경로와 결과를 확인합니다.

예측 재현과 학습 재개에 필요한 정보가 다릅니다

Step 1·2의 개발 기록 보완 · 저장 형식 확인 [G]

추론

구조·Parameter·전처리·출력 의미를 확인합니다. 일반적으로 새 요청마다 Optimizer로 학습하지 않습니다.

학습 재개

Parameter에 더해 Optimizer State와 학습 단계를 확인합니다. 같은 Weight라도 상태가 다르면 다음 이동이 달라집니다.

새 비교 실험

모델과 상태를 어떤 초기 조건에서 시작했는지 명시합니다. 연속 재학습을 새 실험처럼 비교하지 않습니다.

Keras 전체 모델 저장은 Optimizer와 상태도 포함할 수 있습니다. 다만 완전히 같은 학습 경로에는 데이터 순서·난수·실행 환경도 관여하므로, 저장만으로 모든 환경의 비트 단위 재현을 보장하지 않습니다.

25 · INTERVIEW POINTS

어떤 데이터·어떤 기억·어떤 이동인지 설명해 보세요

먼저 답을 말한 뒤 펼쳐서 비교하세요. 앞 카드의 교안 내용과 보완 수식을 복습합니다.

Q1. Optimizer의 역할은 무엇인가요?

이번 신경망 학습에서는 Gradient를 이용해 Weight와 Bias를 수정하는 규칙입니다. 미분 계산과 실제 Update를 구분합니다.

Q2. BGD와 Adam은 무엇이 다른가요?

BGD는 전체 데이터를 사용하는 방식이고 Adam은 Gradient로 Parameter를 바꾸는 규칙입니다. 분류 기준이 다릅니다.

Q3. SGD API를 쓰면 Batch Size는 1인가요?

아닙니다. Mini Batch에도 사용할 수 있습니다. Optimizer 이름과 데이터 단위를 구분합니다.

Q4. 120개에 Batch Size 32면 몇 번 Update하나요?

마지막 작은 Batch를 쓰고 누적이 없다면 한 Epoch에 32+32+32+24로 네 번입니다.

Q5. Momentum은 무엇을 기억하나요?

이전 이동 정보를 기억하여 현재 Gradient의 제안과 합칩니다. 관성으로 최솟값을 지나칠 수도 있습니다.

Q6. AdaGrad는 Update 횟수만 세나요?

아닙니다. 제곱 Gradient를 누적하므로 빈도뿐 아니라 크기도 반영합니다.

Q7. AdaGrad와 RMSProp은 어떻게 다른가요?

전체 제곱 Gradient 누적과 할인된 이동평균의 차이입니다. RMSProp은 오래된 개별 정보의 영향을 줄입니다.

Q8. Adam의 m과 v는 무엇인가요?

Gradient와 제곱 Gradient의 이동평균입니다. 방향과 크기 조정 정보를 각각 요약합니다.

Q9. Bias Correction은 신경망 Bias를 고치나요?

아닙니다. 이동평균을 0으로 초기화한 데서 생기는 편향을 보정합니다.

Q10. Adam에서도 Learning Rate를 골라야 하나요?

네. 적응적 조정과 기본 Learning Rate는 별개입니다. 같은 η라도 실제 이동량은 달라집니다.

Q11. ε와 Learning Rate는 무엇이 다른가요?

ε는 작은 분모의 수치 안정성, η는 기본 이동 크기 설정입니다. ε가 잘못된 미분이나 입력까지 해결하지는 않습니다.

Q12. Gradient가 0이면 최솟값인가요?

아닙니다. 안장점 등 다른 정지점일 수 있습니다. g와 상태가 모두 0이면 기본식만으로 탈출이 보장되지 않습니다.

Q13. Loss가 한 번 상승하면 실패인가요?

Batch 차이와 관성, Learning Rate를 구분합니다. 고정된 평가 조건과 전체 경로를 함께 봅니다.

Q14. 같은 Weight로 복원하면 학습도 그대로 이어지나요?

Optimizer 상태가 다르면 다음 Update가 달라질 수 있습니다. 단계·데이터 순서·난수·환경도 확인합니다.

Q15. 같은 η로 10회 실행한 결과는 성능 순위인가요?

아닙니다. 설명용 함수와 설정에 한정된 비교입니다. 방법별 설정과 공통 계산·평가 조건을 관리해야 합니다.

Q16. compile과 fit의 차이는 무엇인가요?

compile은 Loss·Optimizer 등의 설정을 연결하고 fit은 실제 데이터를 이용한 학습을 수행합니다.
