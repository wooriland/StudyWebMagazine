12 · CODE EXAMPLE

교안의 NumPy 선형회귀 코드에서 역할을 찾아봅니다

이번 페이지에서는 코드를 새로 구현하는 것보다 각 변수의 역할을 구분해서 읽는 것이 핵심입니다. 

# Parameter 초기화
W = np.random.rand()
b = np.random.rand()

# Hyperparameter 설정
learning_rate = 0.001
epochs = 10000

for epoch in range(epochs):

    # Prediction
    y_pred = W * X + b

    # Loss
    loss = np.mean((y_pred - y) ** 2)

    # Gradient
    dW = np.mean(2 * (y_pred - y) * X)
    db = np.mean(2 * (y_pred - y))

    # Parameter Update
    W -= learning_rate * dW
    b -= learning_rate * db

14 · COMMON MISTAKES

Parameter와 Hyperparameter는 비슷해 보여도 역할이 완전히 다릅니다

01

Feature와 Weight가 같다

Feature는 Data이고, Weight는 Model 내부 Parameter입니다.

02

Bias는 Error를 뜻한다

이번 Bias는 Wx+b의 Model Parameter입니다.

03

Parameter 최종값은 개발자가 직접 정한다

초기값은 설정할 수 있지만 Training을 통해 Loss가 줄어들도록 Parameter를 Update합니다.

04

Hyperparameter는 더 큰 Parameter다

크기의 문제가 아니라 학습되는 값과 학습을 조절하는 값의 차이입니다.

05

Learning Rate도 Weight처럼 학습된다

기본 Gradient Descent 구조에서 Learning Rate는 Parameter Update 크기를 결정하는 설정입니다.

06

Epoch가 많을수록 무조건 좋다

너무 적으면 학습 부족, 지나치게 많으면 Overfitting 가능성을 함께 확인해야 합니다.

07

Batch Size가 Parameter다

Batch Size는 한 번의 Update에 사용할 Sample 수를 조절하는 Hyperparameter입니다.

08

Loss는 Parameter다

Loss는 현재 Prediction이 얼마나 틀렸는지 평가하는 값이고 Parameter는 그 Loss를 줄이도록 수정됩니다.

09

Training의 목적은 Weight를 0으로 만드는 것이다

Weight의 크기가 아니라 Loss를 잘 줄이는 적절한 Parameter를 찾는 것이 목적입니다.

10

Architecture와 Parameter가 같다

Architecture는 Layer와 Node의 구조, Parameter는 그 구조 안에서 학습되는 Weight와 Bias입니다.

11

Learning Rate는 항상 0.001이면 된다

교안도 정해진 값은 없다고 설명합니다. Problem과 Model에 맞는 설정이 필요합니다.

12

Loss는 매 Step마다 반드시 감소해야 한다

SGD나 Mini-Batch에서는 사용하는 Data가 달라 Loss가 부분적으로 흔들릴 수도 있습니다.

17 · INTERVIEW POINT

“학습되는 값인가, 학습을 조절하는 값인가?”로 답합니다

Q1. Parameter란 무엇인가요?

Machine Learning Model 내부에서 Training Data를 이용해 학습되는 값입니다. 대표적으로 Weight와 Bias가 있으며, Loss를 줄이는 방향으로 Training 과정에서 Update됩니다.

Q2. Hyperparameter란 무엇인가요?

Weight와 Bias처럼 Training에서 직접 학습되는 값이 아니라, Parameter가 어떻게 학습될지 또는 Model을 어떻게 구성할지를 조절하는 설정입니다. Learning Rate, Epoch, Batch Size 등이 대표적입니다.

Q3. Parameter와 Hyperparameter의 차이는?

Parameter는 Data로부터 학습되는 값이고, Hyperparameter는 그 학습 과정과 Model 구성을 바깥에서 조절하는 설정입니다.

Q4. Weight란 무엇인가요?

입력 Feature에 곱해져 Prediction 계산에 영향을 주는 Model Parameter입니다. Training 과정에서 Loss를 줄이도록 Update됩니다.

Q5. Bias란 무엇인가요?

Wx + b의 b에 해당하는 Parameter입니다. 입력값의 가중합에 더해지며 선형회귀에서는 절편과 연결해 이해할 수 있습니다.

Q6. Machine Learning에서 학습한다는 것은 무엇인가요?

Prediction과 실제값의 Loss가 줄어들도록 Weight와 Bias 같은 Parameter의 적절한 값을 반복적으로 찾아가는 과정이라고 설명할 수 있습니다.

Q7. Learning Rate란 무엇인가요?

Gradient를 이용해 Parameter를 Update할 때 한 번에 얼마나 크게 움직일지를 결정하는 Hyperparameter입니다.

Q8. Learning Rate가 너무 크거나 작으면?

너무 크면 최소점을 지나치면서 Parameter가 진동하거나 발산할 수 있고, 너무 작으면 Update 폭이 작아 Training 속도가 매우 느려질 수 있습니다.

Q9. Epoch란 무엇인가요?

Training Dataset 전체를 한 번 사용하는 학습 단위입니다. Epoch 수는 전체 Dataset을 몇 차례 반복할지를 결정합니다.

Q10. Batch Size란 무엇인가요?

한 번의 Gradient 계산과 Parameter Update에 사용할 Sample 묶음의 크기입니다.

Q11. Model Architecture와 Parameter의 차이는?

Architecture는 Layer와 Node가 어떻게 연결되는지를 나타내는 Model의 구조이고, Parameter는 그 구조 안에서 Training으로 학습되는 Weight와 Bias입니다.

Q12. CNN의 Filter도 Parameter인가요?

Convolution Filter는 여러 Weight로 이루어져 있으며, 학습 가능한 Filter 값은 CNN의 Trainable Parameter로 이해할 수 있습니다.

Q13. Weight 초기값과 Weight는 어떻게 다른가요?

실제 Weight는 Model Parameter이고 Training 과정에서 Update됩니다. Random, Xavier, He 같은 방식 중 어떤 초기화 전략을 선택할지는 Training Configuration에 해당합니다.
