11 · LIMITATION & TRADE-OFF

두 접근 모두 장점과 비용이 있습니다

CLASSICAL ML

복잡한 Raw Data에서는 Feature Engineering이 어려워질 수 있습니다

  • Domain Knowledge가 많이 필요할 수 있음
  • Image·Audio·Text의 복잡한 Feature를 사람이 직접 설계하기 어려울 수 있음
  • Feature 품질이 Model 성능에 큰 영향을 줄 수 있음
DEEP LEARNING

강력하지만 Data와 Computing Cost가 큽니다

  • 많은 Training Data가 유리
  • GPU / TPU 등 Computing Resource
  • 많은 Parameter
  • Training Time 증가 가능
  • Overfitting 위험
  • 복잡한 Model의 해석 어려움
OVERFITTING PREVIEW

Training Data에서는 잘하는데 새로운 Data에서는 못한다?

Complex Model → Train Performance ↑ → New Data Performance ↓ → Overfitting

교안은 Deep Learning에서 Parameter가 많고 Model이 복잡해질수록 Overfitting을 중요한 문제로 다룹니다. 자세한 해결 방법은 뒤의 딥러닝 성능 개선 단원에서 공부합니다.

복잡한 Model ≠ 항상 좋은 Model

Model Complexity가 증가하면 표현력뿐 아니라 Training Cost, Memory, Latency, Overfitting 위험도 함께 증가할 수 있습니다.

12 · COMMON MISTAKES

머신러닝과 딥러닝을 공부하며 가장 많이 생기는 오해

01

Machine Learning과 Deep Learning은 완전히 독립된 분야다

Deep Learning은 Machine Learning의 한 유형입니다.

02

Deep Learning은 AI보다 더 큰 개념이다

포함 관계는 AI → Machine Learning → Deep Learning입니다.

03

Deep Learning에서는 Feature가 필요 없다

Feature가 사라지는 것이 아니라 Network가 Feature Representation을 함께 학습하는 비중이 커집니다.

04

Deep Learning에서는 Data 전처리가 필요 없다

Scaling, Normalization, Data Augmentation 등은 Deep Learning에서도 중요할 수 있습니다.

05

Image는 무조건 Deep Learning이다

교안에서도 사람이 정의한 Feature와 SVM·Random Forest를 이용한 Classical ML 이미지 분류 사례를 소개합니다.

06

Structured Data에는 Deep Learning을 사용할 수 없다

교안은 상대적인 적합성을 설명합니다. 사용할 수 없다는 의미가 아닙니다.

07

Dataset이 크면 무조건 Deep Learning이다

Data Size는 Model 선택의 여러 기준 가운데 하나일 뿐입니다.

08

Deep Learning은 항상 Classical ML보다 좋다

핵심은 최신 기술인지가 아니라 현재 Problem에 적합한가입니다.

09

Deep Learning은 사람이 아무것도 설계하지 않는다

Problem, Data, Label, Architecture, Loss, Optimizer, Hyperparameter와 Evaluation은 여전히 설계해야 합니다.

10

모든 ML은 설명 가능하고 모든 DL은 설명 불가능하다

교안은 상대적인 경향을 설명합니다. Model마다 해석 난이도는 다릅니다.

15 · INTERVIEW POINT

관계 → 차이 → 선택 기준 순서로 설명합니다

Q1. Machine Learning이란 무엇인가요?

Data를 이용해 Pattern과 관계를 학습하고, 학습된 Model로 새로운 입력에 대해 Prediction을 수행하는 AI의 한 분야입니다. 교안에서는 확률과 통계 알고리즘의 중요성도 강조합니다.

Q2. Deep Learning이란 무엇인가요?

Machine Learning의 한 유형으로, Artificial Neural Network를 이용해 복잡한 Pattern과 Feature Representation을 학습하는 방법입니다.

Q3. AI, Machine Learning, Deep Learning의 관계는?

AI가 가장 큰 범위이고, Machine Learning은 그 안에서 Data를 이용해 학습하는 방법이며, Deep Learning은 Machine Learning 안에서 Neural Network를 사용하는 방식입니다.

Q4. ML과 DL의 가장 직관적인 차이는 무엇인가요?

Feature 처리 관점에서 볼 수 있습니다. Classical ML은 사람이 설계한 Feature의 비중이 크고, Deep Learning은 Neural Network가 Feature Representation을 함께 학습하는 비중이 큽니다.

Q5. Feature Engineering이란 무엇인가요?

원본 Data에서 Model 학습에 도움이 되는 Feature를 선택하거나 생성하고 변환하는 과정입니다.

Q6. Deep Learning의 Feature Learning은 무엇인가요?

Neural Network의 여러 Layer가 Training 과정에서 Prediction에 유용한 Representation을 학습하는 것을 의미합니다.

Q7. Structured Data란 무엇인가요?

교안에서는 Schema가 있는 Data라고 설명합니다. 일반적인 Table처럼 Column 구조가 명확한 데이터를 생각하면 이해하기 쉽습니다.

Q8. Semi-Structured Data의 예는 무엇인가요?

교안에서는 HTML과 XML을 대표적인 예로 제시합니다.

Q9. Unstructured Data에는 무엇이 있나요?

교안에서는 Image, Text, Audio, Video 등을 대표적인 비정형 Data로 설명합니다.

Q10. Deep Learning에서 GPU를 많이 사용하는 이유는?

많은 Parameter와 대규모 행렬 연산을 반복적으로 처리하기 때문에 병렬 계산에 유리한 GPU나 TPU가 많이 사용됩니다.

Q11. Image는 반드시 Deep Learning으로 처리해야 하나요?

아닙니다. 교안에서도 사전에 정의한 Feature와 SVM 또는 Random Forest를 사용하는 Machine Learning 이미지 분류 사례를 설명합니다.

Q12. Structured Data에는 Deep Learning을 사용할 수 없나요?

아닙니다. 교안의 정형·비정형 비교는 상대적인 적합성을 설명하는 것이며 사용 가능 여부를 절대적으로 제한하는 규칙이 아닙니다.

Q13. Deep Learning이 항상 Classical ML보다 좋은가요?

아닙니다. Problem Complexity, Data 형태와 양, Explainability, Hardware, Cost 등 여러 기준을 함께 고려해 선택해야 합니다.

Q14. ML과 DL을 함께 사용할 수 있나요?

가능합니다. 예를 들어 Pre-trained CNN으로 Feature를 추출하고, 그 Feature를 Classical ML Model에 입력하여 최종 Classification을 수행할 수 있습니다.

Q15. Deep Learning에서 전처리는 필요 없나요?

아닙니다. Scaling, Normalization, Data Augmentation 등 적절한 Data Preparation은 Deep Learning에서도 중요합니다.
