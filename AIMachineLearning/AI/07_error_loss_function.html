How Wrong Is the Model?

오차와 손실 함수 Model이 얼마나 틀렸는지를 하나의 숫자로 표현하다

Model이 Prediction을 만들었다고 해서 바로 학습할 수 있는 것은 아닙니다. 먼저 실제값 y와 예측값 ŷ가 얼마나 다른지를 측정해야 합니다.

한 Sample의 차이는 Error, 여러 Error를 학습 가능한 하나의 값으로 정리하는 기준은 Loss / Cost Function입니다. 회귀에서는 대표적으로 MSE와 MAE를 사용합니다.

07 · MEAN SQUARED ERROR

MSE는 Error를 제곱한 뒤 평균합니다

MSE MSE = 1/N × Σ(yᵢ - ŷᵢ)²
01 Actual y
↔
02 Prediction ŷ
→
03 Error y - ŷ
→
04 Square (y - ŷ)²
→
05 Mean MSE

직접 계산

Sample Actual y Prediction ŷ Error Error²
1 10 9 1 1
2 12 14 -2 4
3 14 13 1 1
(1 + 4 + 1) / 3 = MSE = 2

제곱의 특징

ERROR 1 → 1
ERROR 2 → 4
ERROR 10 → 100
보완 이해

MSE는 큰 Error의 영향을 강하게 받습니다

1 1 1 20
↓ square
1 1 1 400

큰 Prediction Error 하나가 전체 MSE에 매우 큰 영향을 줄 수 있습니다.

08 · MEAN ABSOLUTE ERROR

MAE는 Error의 절대값을 평균합니다

MAE MAE = 1/N × Σ|yᵢ - ŷᵢ|
01 Error y - ŷ
→
02 Absolute |y - ŷ|
→
03 Mean MAE

같은 Data로 계산

ERROR 1 → 1
ERROR -2 → 2
ERROR 1 → 1
(1 + 2 + 1) / 3 = MAE ≈ 1.33
INTERPRETATION

원래 Target 단위로 해석하기 쉽습니다

예를 들어 집값 Target의 단위가 원이고 MAE가 15,000,000이라면, 평균적으로 실제값과 Prediction이 약 1,500만원 정도 차이가 난다고 직관적으로 이해할 수 있습니다.

09 · MSE vs MAE

둘 다 Error를 측정하지만 큰 Error를 다루는 방식이 다릅니다

MSE

Mean Squared Error

Error² → Mean
  • Error 제곱
  • 큰 Error를 강하게 반영
  • Outlier 영향이 상대적으로 큼
  • Gradient Descent와 자연스럽게 연결
Error 10 → 100
VS
MAE

Mean Absolute Error

|Error| → Mean
  • Error 절대값
  • Error 크기에 비례
  • Outlier 영향이 상대적으로 덜함
  • 원래 Target 단위로 해석하기 쉬움
Error 10 → 10
기준 MSE MAE
부호 제거 제곱 절대값
큰 Error 강하게 반영 선형적으로 반영
Outlier 영향 상대적으로 큼 상대적으로 작음
단위 Target 단위² Target 원래 단위
어느 것이 무조건 더 좋은가?

그렇지 않습니다. “이 문제에서 어떤 Error를 더 중요하게 볼 것인가?”가 Loss Function 선택의 핵심입니다.

10 · EXTENDED REGRESSION ERROR

교안에 함께 등장하는 RMSE와 MAPE도 연결합니다

RMSE

Root Mean Squared Error

RMSE = √MSE

MSE에 제곱근을 적용합니다. Error 크기를 원래 Target 단위와 연결해 해석할 때 도움이 됩니다.

MAPE

Mean Absolute Percentage Error

Absolute Error / |Actual|

실제값 대비 Prediction Error의 비율을 평균하는 관점의 지표입니다.

MSE 제곱 Error
RMSE √MSE
MAE 절대 Error
MAPE 비율 Error
보완 이해 · RESIDUAL

회귀 분석에서는 실제값과 예측값의 차이를 Residual, 잔차라고 표현하기도 합니다. 이번 단계에서는 Error와 함께 실제값과 Prediction의 차이라는 큰 의미로 연결합니다.

14 · FORMULA BRIDGE

MSE는 W와 b의 함수가 되고, 그래서 미분할 수 있습니다

MODEL ŷ = Wx + b
↓
LOSS E = 1/N × Σ(y - ŷ)²
↓ substitute
PARAMETER FUNCTION E = E(W, b)
WEIGHT GRADIENT ∂E/∂W

W가 변할 때 Loss가 어떻게 변하는가?

BIAS GRADIENT ∂E/∂b

b가 변할 때 Loss가 어떻게 변하는가?

교안 연결
∂E/∂W = 2/N × Σ x(ŷ - y) ∂E/∂b = 2/N × Σ(ŷ - y)

이번 단원에서는 식의 유도보다 Loss를 Parameter에 대해 미분하면 Gradient가 나온다는 관계를 우선 이해합니다.

15 · CODE EXAMPLE

교안의 NumPy 코드에서 Error와 MSE를 직접 읽습니다 

# Prediction
y_pred = W * X + b

# Mean Squared Error
loss = np.mean((y_pred - y) ** 2)

# Gradient
dW = np.mean(
    2 * (y_pred - y) * X
)

db = np.mean(
    2 * (y_pred - y)
)

# Parameter Update
W -= learning_rate * dW
b -= learning_rate * db
y_pred Prediction
y Actual
y_pred - y Error
** 2 Square
np.mean() Mean
loss MSE
교안 식과 코드의 부호가 달라 보여도 괜찮습니다
(y - ŷ)² = (ŷ - y)²

제곱하기 때문에 MSE 값은 같습니다.

보완 코드 · MAE 구조 
mae = np.mean(
    np.abs(y_pred - y)
)

Prediction과 Actual의 차이에 절대값을 적용한 뒤 평균하면 MAE가 됩니다.

18 · COMMON MISTAKES

Error, Loss, Metric을 서로 같은 개념으로 섞지 않습니다

01

y와 ŷ는 같다

y는 Actual, ŷ는 Model Prediction입니다.

02

Error와 Loss의 역할은 완전히 같다

이번 학습에서는 Error를 개별 차이, Loss를 Model 학습에 사용할 평가값으로 구분하면 이해하기 쉽습니다.

03

Error를 그대로 평균하면 된다

Positive와 Negative Error가 서로 상쇄될 수 있습니다.

04

MSE는 Error의 단순 평균이다

MSE는 Error를 제곱한 뒤 평균합니다.

05

MAE는 Error를 제곱한다

MAE는 Error의 절대값을 평균합니다.

06

MSE는 큰 Error를 약하게 반영한다

반대입니다. 제곱하기 때문에 큰 Error의 영향이 빠르게 증가합니다.

07

MAE는 실제 Loss로 사용할 수 없다

교안 후반 TensorFlow/Keras에서도 MeanAbsoluteError를 회귀 Loss로 제시합니다.

08

Loss는 클수록 좋다

이번 교안의 Loss는 작게 만드는 방향으로 Parameter를 학습합니다.

09

Loss와 Accuracy는 같은 값이다

Loss는 Optimization 기준, Accuracy는 Classification Metric입니다.

10

MSE와 R²는 같은 방향으로 읽는다

MSE는 작을수록 좋고, 교안에서 R²는 1에 가까울수록 설명력이 좋다고 설명합니다.

11

Training Loss가 0이면 좋은 Model이 확정된다

Training Data를 과도하게 외운 Overfitting Model일 수 있으므로 Validation/Test 성능도 확인해야 합니다.

12

서로 다른 문제의 MSE를 숫자만 보고 비교한다

Dataset과 Target Scale이 다르면 Loss 절대값을 직접 비교하기 어렵습니다.

13

Loss가 한 번 증가하면 Training 실패다

SGD나 Mini-Batch에서는 Data Noise 때문에 Step별 Loss가 일부 진동할 수 있습니다.

14

Loss와 Parameter는 같은 것이다

Loss는 현재 Parameter를 평가하는 기준이고, Weight와 Bias가 실제 Update 대상입니다.

19 · LOSS STATE & DEBUGGING

이번 단원에서는 Exception보다 Loss의 모양을 읽는 연습이 중요합니다

STATE 01

Loss가 매우 큼

Prediction Error가 클 수도 있지만 Target Scale 자체가 큰 문제일 수도 있습니다.

숫자 하나만으로 실패를 확정하지 않습니다.
STATE 02

Loss가 계속 증가

Learning Rate가 너무 커서 Parameter Update가 불안정한 경우 등을 확인할 수 있습니다.

STATE 03

Loss가 거의 줄지 않음

  • Learning Rate
  • Gradient
  • Parameter Update
  • Model 표현력
STATE 04

Loss가 진동

SGD나 작은 Mini-Batch처럼 noisy한 Gradient를 사용하는 경우 일부 진동은 자연스러울 수 있습니다.

STATE 05

Train ↓ / Validation ↑

TRAIN ↓ ↓ ↓ ↓
VALIDATION ↓ → ↑ ↑

Overfitting 가능성을 확인합니다.

21 · INTERVIEW POINT

실제값 → Prediction → Error → Loss 순서로 답합니다

Q1. Error란 무엇인가요?

Model의 Prediction과 실제값 사이의 차이입니다. 회귀에서는 일반적으로 y - ŷ와 같은 형태로 생각할 수 있습니다.

Q2. Loss Function이란 무엇인가요?

Prediction과 실제값의 차이를 이용해 Model이 얼마나 틀렸는지를 수치화하는 함수입니다. Training에서는 이 값을 줄이는 방향으로 Parameter를 최적화합니다.

Q3. Cost와 Loss는 무엇이 다른가요?

이번 교안에서는 비용함수와 손실함수를 상당히 같은 의미로 사용합니다. 일부 자료에서는 Sample 단위 Loss와 Dataset 전체 Cost를 구분하기도 있지만, 용어 사용은 자료마다 다를 수 있습니다.

Q4. MSE란 무엇인가요?

Mean Squared Error로 실제값과 Prediction의 차이를 제곱한 뒤 전체 Sample에 대해 평균한 값입니다.

Q5. MAE란 무엇인가요?

Mean Absolute Error로 실제값과 Prediction 차이의 절대값을 평균한 값입니다.

Q6. 왜 Error를 그대로 평균하지 않나요?

Positive Error와 Negative Error가 서로 상쇄되어 실제 Prediction이 틀렸음에도 평균 Error가 0에 가까워질 수 있기 때문입니다.

Q7. MSE와 MAE의 차이는 무엇인가요?

MSE는 Error를 제곱하기 때문에 큰 Error의 영향을 강하게 반영합니다. MAE는 절대값을 사용하기 때문에 Error 크기에 비례하여 증가하고 원래 Target 단위로 해석하기 쉽습니다.

Q8. MSE가 Gradient Descent와 어떻게 연결되나요?

MSE는 Weight와 Bias에 대한 함수로 표현할 수 있고, 이를 Parameter에 대해 미분하면 Gradient를 계산할 수 있습니다. 그 Gradient를 이용해 Parameter를 Update합니다.

Q9. Loss가 낮으면 무조건 좋은 Model인가요?

같은 문제와 같은 평가 조건에서는 Prediction Error가 작다는 의미로 볼 수 있지만 Training Loss만으로 충분하지는 않습니다. Validation과 Test Data에서도 일반화 성능을 확인해야 합니다.

Q10. Loss와 Metric의 차이는 무엇인가요?

Loss는 Training 과정에서 Parameter를 최적화하기 위한 목적 함수 역할을 하고, Metric은 Model의 성능을 사람이 평가하고 해석하기 위한 지표입니다. 다만 같은 함수를 두 역할 모두에 사용할 수도 있습니다.

Q11. Regression과 Classification은 같은 Loss를 사용하나요?

일반적으로 문제 유형에 따라 다릅니다. 이번 교안은 대표적으로 Regression에는 MSE, Classification에는 Cross Entropy를 연결합니다.

Q12. RMSE란 무엇인가요?

Root Mean Squared Error로 MSE에 제곱근을 적용한 값입니다. MSE의 Error 강조 특성을 유지하면서 원래 Target과 같은 단위로 해석하는 데 도움이 됩니다.

Q13. Training Loss와 Validation Loss의 차이는 무엇인가요?

Training Loss는 실제 Parameter Update에 사용되는 Training Data에서 계산한 값이고, Validation Loss는 Training에 직접 사용하지 않은 Validation Data에서 Model의 일반화 상태를 확인하기 위해 계산하는 값입니다.

  1. y = Actual
  2. ŷ = Prediction
  3. Error = Actual - Prediction
  4. MSE = Error² 평균
  5. MAE = |Error| 평균
  6. Loss ↓ = 같은 조건에서 Error ↓
  7. Loss 다음은 Gradient
