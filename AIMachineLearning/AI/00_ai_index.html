03 · WHY IT APPEARED

AI 기술은 이전 방식의 한계를 해결하면서 발전합니다

새로운 기술을 이름으로만 외우지 않고 “무엇이 부족했기 때문에 다음 기술이 필요했는가?”라는 질문으로 연결합니다.

  1. 01

    Rule-Based

    사람이 모든 규칙을 직접 작성합니다.

    한계 예외와 복잡한 현실 문제의 모든 규칙을 사람이 작성하기 어렵습니다.
    다음 Machine Learning
  2. 02

    Linear Model

    입력과 출력의 관계를 단순한 선형식으로 표현합니다.

    한계 복잡한 비선형 관계를 표현하기 어렵습니다.
    다음 Perceptron · Neural Network
  3. 03

    Single Layer Perceptron

    입력에 Weight를 곱하고 Activation을 거쳐 출력을 만듭니다.

    한계 XOR 같은 비선형 분리 문제를 하나의 층으로 해결할 수 없습니다.
    다음 Multi Layer Perceptron
  4. 04

    Deep Neural Network

    Hidden Layer를 여러 층 쌓아 복잡한 관계를 표현합니다.

    한계 층이 깊어질수록 Gradient 전달과 학습이 어려워집니다.
    다음 Backpropagation · ReLU · Optimizer
  5. 05

    Dense Network + Image

    이미지를 1차원으로 펼쳐 일반 신경망에 넣을 수 있습니다.

    한계 위치 정보가 약해지고 Parameter 수가 매우 커질 수 있습니다.
    다음 CNN
  6. 06

    Image Classification

    이미지 전체가 어떤 클래스인지 판단합니다.

    한계 객체가 이미지의 어디에 있는지는 알 수 없습니다.
    다음 Object Detection · YOLO
  7. 07

    RNN / Seq2Seq

    순서가 중요한 시퀀스 데이터를 처리합니다.

    한계 긴 문맥 전달과 순차적인 계산에 어려움이 생길 수 있습니다.
    다음 Attention
  8. 08

    Attention 기반 Sequence Model

    현재 필요한 입력 정보에 더 높은 가중치를 줄 수 있습니다.

    한계 RNN 기반 구조에서는 여전히 순차 연산 문제가 남습니다.
    다음 Transformer

04 · FORMULA MEANING

수식을 외우기 전에 각 수식의 역할부터 읽습니다

00 단원에서는 복잡한 미분을 직접 계산하기보다 모델 학습에서 수식이 어떤 역할을 맡는지 이해합니다.

MODEL ŷ = Wx + b

예측식을 만든다

입력 X에 Weight W를 곱하고 Bias b를 더해 모델의 예측값 ŷ를 만듭니다.

ERROR error = y - ŷ

얼마나 틀렸는지 본다

실제 정답 y와 모델이 예측한 ŷ의 차이를 확인합니다.

LOSS MSE = mean((y - ŷ)²)

오차를 하나의 숫자로 요약한다

여러 데이터에서 발생한 오차를 학습 가능한 하나의 값으로 표현합니다.

UPDATE Wnew = Wcurrent - α × Gradient

Parameter를 수정한다

Gradient가 알려주는 방향과 Learning Rate α를 이용하여 Weight를 조금씩 변경합니다.

Prediction → Loss → Gradient → Update → Prediction

07 · LIMITATION & IMPROVEMENT

모델이 복잡해질수록 새로운 문제도 함께 생깁니다

문제 01

Overfitting

훈련 데이터에는 잘 맞지만 새로운 데이터에서 성능이 떨어집니다. Regularization · Dropout · Early Stopping

문제 02

Vanishing Gradient

깊은 신경망에서 앞쪽 Layer로 Gradient가 충분히 전달되지 않을 수 있습니다. ReLU · Initialization · Normalization

문제 03

Unstable Optimization

Learning Rate와 Gradient 변화에 따라 학습이 느리거나 불안정할 수 있습니다. Momentum · RMSProp · Adam

문제 04

Too Many Parameters

특히 이미지 데이터를 Dense 방식으로 다루면 Parameter 수가 매우 커질 수 있습니다. CNN · Pooling · GAP · Transfer Learning

08 · MINIMUM CODE

AI 학습 원리만 읽는 최소 코드

이번 단원에서 코드를 외우는 것이 목적은 아닙니다. 각 코드가 AI 학습의 어느 단계에 해당하는지만 봅니다. 

# 입력값
x = 3

# 학습을 통해 찾아야 하는 값
weight = 2.0
bias = 1.0

# 모델의 예측
prediction = weight * x + bias

# 실제 정답
answer = 8

# 오차
error = prediction - answer

# 단순한 손실
loss = error ** 2

print("prediction:", prediction)
print("error:", error)
print("loss:", loss)
01

입력

x는 Feature입니다.

02

Parameter

weight와 bias는 학습 대상입니다.

03

Prediction

모델이 현재 Parameter로 판단한 결과입니다.

04

Loss

Prediction과 정답의 차이를 숫자로 표현합니다.

다음 단계에서는?

실제 Machine Learning에서는 Loss를 Parameter에 대해 미분해 Gradient를 구하고, Learning Rate를 적용하여 Weight와 Bias를 반복적으로 업데이트합니다.

09 · COMMON MISTAKES

AI를 처음 공부할 때 자주 생기는 착각

01

AI와 Machine Learning을 같은 말로 생각한다

Machine Learning은 AI라는 더 큰 범위 안에서 데이터를 이용해 학습하는 하나의 접근 방법입니다.

02

학습을 데이터를 저장하거나 외우는 것으로만 생각한다

이 교안의 기본 관점에서 학습은 Prediction과 정답의 차이를 줄이도록 Parameter를 조정하는 과정입니다.

03

Parameter와 Hyperparameter를 뒤섞는다

Weight와 Bias는 학습되고, Learning Rate와 Batch Size 등은 학습 방식을 결정하기 위해 사람이 설정합니다.

04

Loss와 Metric을 같은 것으로 생각한다

Loss는 모델 학습에 직접 사용되는 값이고, Metric은 모델 성능을 사람이 평가하고 해석하기 위한 값입니다.

05

모든 Machine Learning이 Gradient Descent를 사용한다고 생각한다

경사하강법은 매우 중요한 학습 방법이지만 Decision Tree 계열처럼 다른 방식으로 학습하는 알고리즘도 존재합니다.

06

신경망의 Layer는 많을수록 무조건 좋다고 생각한다

모델이 커지면 표현력이 증가할 수 있지만 Overfitting, Gradient 문제, 연산량 증가도 함께 고려해야 합니다.

07

CNN을 단순한 이미지 분류 알고리즘으로만 생각한다

CNN의 핵심은 이미지의 공간 구조를 유지하면서 Filter를 이용해 Feature를 추출하는 것입니다.

08

Classification과 Object Detection을 같은 작업으로 생각한다

Classification은 무엇인지 판단하고, Object Detection은 무엇인지와 어디에 있는지를 함께 판단합니다.

09

RNN, LSTM, Attention, Transformer를 서로 고립된 기술로 외운다

시퀀스의 순서와 긴 문맥을 더 잘 처리하기 위해 이전 구조의 한계를 보완해가는 흐름으로 이해합니다.

12 · INTERVIEW POINT

전체 AI 구조를 설명할 수 있는지 확인합니다

AI, Machine Learning, Deep Learning의 관계는 무엇인가요?

AI가 가장 큰 개념이고, Machine Learning은 데이터를 통해 규칙과 관계를 학습하는 AI 구현 방법 중 하나입니다. Deep Learning은 인공신경망을 사용하는 Machine Learning의 한 영역입니다.

Rule-Based와 Machine Learning의 차이는 무엇인가요?

Rule-Based는 사람이 판단 규칙을 직접 정의하지만, Machine Learning은 데이터에서 관계나 패턴을 학습해 모델의 Parameter를 결정합니다.

머신러닝에서 “학습한다”는 것은 무엇인가요?

모델의 Prediction과 실제 정답의 차이를 Loss로 계산하고, 그 Loss가 감소하도록 Weight와 Bias 같은 Parameter를 조정하는 과정입니다.

Parameter와 Hyperparameter의 차이는 무엇인가요?

Parameter는 Weight와 Bias처럼 데이터 학습을 통해 모델이 찾아가는 값이고, Hyperparameter는 Learning Rate, Epoch, Batch Size처럼 학습 방식을 사람이 설정하는 값입니다.

Regression과 Classification의 차이는 무엇인가요?

Regression은 연속적인 수치를 예측하고, Classification은 데이터가 어느 범주에 속하는지를 예측합니다.

Loss Function은 왜 필요한가요?

모델이 예측한 값과 실제 정답이 얼마나 다른지를 숫자로 표현하여 모델이 개선되어야 할 방향을 계산하기 위해 필요합니다.

Gradient Descent란 무엇인가요?

Loss Function의 Gradient를 이용하여 Loss가 감소하는 방향으로 Parameter를 반복적으로 업데이트하는 최적화 방법입니다.

퍼셉트론에서 MLP가 필요해진 이유는 무엇인가요?

단층 퍼셉트론은 선형 분리가 가능한 문제에 한계가 있어 XOR 같은 비선형 문제를 해결하기 어렵습니다. Hidden Layer를 추가한 MLP는 비선형 관계를 표현할 수 있습니다.

순전파와 역전파의 차이는 무엇인가요?

순전파는 입력에서 출력 방향으로 계산하여 Prediction과 Loss를 만들고, 역전파는 Loss의 Gradient를 뒤쪽 Layer부터 전달하면서 각 Weight를 업데이트하기 위한 기울기를 계산합니다.

Activation Function은 왜 필요한가요?

선형 변환만 여러 층 연결하면 결국 하나의 선형 관계와 같은 한계를 가지므로, 비선형성을 추가해 복잡한 패턴을 학습하기 위해 필요합니다.

CNN이 이미지 처리에 적합한 이유는 무엇인가요?

CNN은 이미지의 가로·세로 공간 구조를 유지하면서 작은 Filter를 반복 적용해 지역적인 Feature를 추출하므로 Dense Network보다 이미지의 위치 관계를 효과적으로 활용할 수 있습니다.

Classification과 Object Detection의 차이는 무엇인가요?

Classification은 이미지가 무엇인지 판단하지만, Object Detection은 이미지 속 객체의 종류와 Bounding Box 위치를 함께 예측합니다.

Transformer는 어떤 흐름에서 등장했나요?

RNN과 Seq2Seq 계열에서 긴 문맥 전달과 순차적인 처리라는 한계를 개선하려는 과정에서 Attention을 중심으로 한 Transformer 구조로 발전했다고 이해할 수 있습니다.
