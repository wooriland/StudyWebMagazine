10 · BINARY CROSS ENTROPY

실제 정답 Class에 높은 Probability를 줄수록 Loss가 작아집니다

BINARY CROSS ENTROPY L = -1/N Σ[ y log(p) + (1-y) log(1-p) ]
ACTUAL y = 1 Loss = -log(p)
p = 0.99

Loss 작음

p = 0.05

Loss 큼

ACTUAL y = 0 Loss = -log(1-p)
p = 0.01

Loss 작음

p = 0.95

Loss 큼

Binary Cross Entropy를 한 문장으로

실제 Label에 해당하는 Probability가 높아지면 Loss를 줄이고, 실제 Label에 낮은 Probability를 주면 큰 Loss를 부여하는 분류용 손실 함수입니다.

14 · NUMPY EXAMPLE

교안의 핵심 코드를 개념 흐름과 함께 읽습니다 

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# Parameter
W = np.random.randn(2)
b = np.random.randn()

# Hyperparameter
learning_rate = 0.1
epochs = 1000

for epoch in range(epochs):

    # 1. Linear Score
    z = X_train @ W + b

    # 2. Probability
    y_pred = sigmoid(z).reshape(-1, 1)

    # 3. Binary Cross Entropy
    loss = -np.mean(
        y_train * np.log(y_pred + 1e-8)
        +
        (1 - y_train)
        * np.log(1 - y_pred + 1e-8)
    )

    # 4. Gradient
    dW = np.mean(
        (y_pred - y_train) * X_train,
        axis=0
    )

    db = np.mean(
        y_pred - y_train
    )

    # 5. Update
    W -= learning_rate * dW
    b -= learning_rate * db
X_train Features
y_train Actual Label
W / b Parameter
z Linear Score
sigmoid() Probability
loss BCE
dW / db Gradient
learning_rate Hyperparameter
보완 이해 · 1e-8

log(0)과 같은 수치적 문제를 피하기 위해 아주 작은 값을 더하는 구조로 이해할 수 있습니다.

18 · COMMON MISTAKES

로지스틱 회귀를 공부할 때 자주 하는 착각을 정리합니다

01

이름이 Regression이므로 회귀 문제다

Logistic Regression은 대표적인 Binary Classification Model입니다.

02

XW+b가 Probability다

XW+b는 Linear Score이고 Sigmoid를 통과한 값이 Probability입니다.

03

Sigmoid Output이 바로 Class다

Sigmoid Output은 Probability이고 Threshold를 적용한 뒤 Class가 됩니다.

04

Probability 0.8은 Class 0.8이다

Class는 0 또는 1이고, 0.8은 Class 1 Probability입니다.

05

Sigmoid와 Threshold는 같다

Sigmoid는 Probability 변환, Threshold는 Class 결정 기준입니다.

06

Threshold 0.5도 학습 Parameter다

W와 b는 학습되지만, Threshold는 Classification 판단 기준으로 봅니다.

07

Threshold는 언제나 반드시 0.5여야 한다

교안에서는 기본값 0.5를 사용합니다. 실제 문제에서는 평가 목적에 따라 조정할 수 있습니다.

08

Logistic Regression도 MSE가 핵심이다

교안은 MLE 기반 Binary Cross Entropy를 사용합니다.

09

Sigmoid가 W와 b를 학습한다

Sigmoid는 변환 함수이고 Training으로 Update되는 것은 W와 b입니다.

10

Learning Rate와 Epoch도 Parameter다

실습에서 W와 b는 Parameter, Learning Rate와 Epoch는 Hyperparameter입니다.

11

Shape는 수식만 맞으면 중요하지 않다

NumPy에서는 Shape에 따라 Broadcasting 결과 자체가 달라질 수 있습니다.

12

Test Accuracy 100%이므로 완벽한 Model이다

이번 저장 Test Sample은 2개뿐입니다. 실습의 구조를 확인하는 결과로 해석해야 합니다.

13

Binary와 Multi-Class는 같은 구조다

Binary는 현재 Sigmoid, Multi-Class는 다음 단원의 Softmax로 확장합니다.

21 · INTERVIEW POINT

“XW+b → Sigmoid → Probability → Threshold”를 먼저 설명하면 구조가 흔들리지 않습니다

Q1. Logistic Regression은 회귀인가요, 분류인가요?

이름에는 Regression이 들어가지만 대표적인 Binary Classification Model입니다.

Q2. 왜 Linear Regression을 그대로 Binary Classification에 사용하지 않나요?

XW+b는 -∞에서 +∞ 범위의 값이므로 그대로 0~1 Probability로 해석하기 어렵습니다. Logistic Regression은 Sigmoid를 이용해 이를 0~1로 변환합니다.

Q3. Logistic Regression의 Prediction 흐름은 무엇인가요?

X → XW+b → Sigmoid → Probability → Threshold → Class 순서입니다.

Q4. Sigmoid Function은 무엇인가요?

실수 범위의 Linear Score를 0과 1 사이의 값으로 변환하는 함수입니다.

Q5. Sigmoid 출력은 무엇을 의미하나요?

이진 분류에서는 보통 Class 1일 Prediction Probability로 해석합니다.

Q6. Threshold는 무엇인가요?

Prediction Probability를 최종 Class로 변환하는 기준입니다. 교안에서는 기본값 0.5를 사용합니다.

Q7. Probability와 Class의 차이는 무엇인가요?

Probability는 0~1 사이 연속값이고, Class는 Threshold를 적용해 결정한 0 또는 1입니다.

Q8. Logistic Regression의 Loss는 무엇인가요?

교안에서는 MLE에서 유도되는 Binary Cross Entropy를 사용합니다.

Q9. MLE란 무엇인가요?

관측된 실제 Label의 Likelihood를 최대화하는 Parameter W와 b를 찾는 Maximum Likelihood Estimation입니다.

Q10. Binary Cross Entropy를 직관적으로 설명해주세요.

실제 정답 Class에 높은 Probability를 주면 작은 Loss를 주고, 실제 정답 Class에 낮은 Probability를 주면 큰 Loss를 주는 함수입니다.

Q11. Logistic Regression에서도 Gradient Descent를 사용할 수 있나요?

네. BCE Gradient를 이용해 W와 b를 Loss가 감소하는 방향으로 Update할 수 있습니다.

Q12. Decision Boundary란 무엇인가요?

Feature 공간에서 Prediction Class가 바뀌는 경계입니다. 기본 Threshold 0.5와 Sigmoid의 관계에서는 XW+b=0과 연결해서 이해할 수 있습니다.

Q13. Parameter와 Hyperparameter를 구분하면?

W와 b는 Training으로 학습되는 Parameter이고, Learning Rate와 Epoch는 사용자가 설정하는 Hyperparameter입니다.

Q14. Binary Classification과 Multi-Class Classification의 차이는?

Binary는 두 Class를 구분하고, Multi-Class는 세 개 이상의 Class 중 하나를 구분합니다.

Q15. Sigmoid와 Softmax의 차이는?

이번 단원에서는 Sigmoid를 Binary Classification에 사용하고, 다음 단원에서는 Softmax를 이용해 여러 Class의 Probability를 계산합니다.
