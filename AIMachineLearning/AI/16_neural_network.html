01 · CORE CONCEPT

인공신경망은 입력을 여러 단계로 변환하는 모델입니다

교안 A · §6, §6-1~6-2 [A]

뉴런의 계산을 Layer로 묶고 여러 Layer를 연결하여 최종 출력을 만듭니다. 학습에서는 예측값과 실제값의 차이가 줄어들도록 Weight와 Bias를 조정합니다.

Neuron / Node

Dense에서는 입력을 받아 가중합과 활성화로 출력값 하나를 계산하는 단위입니다.

Layer

입력을 출력으로 변환하는 계산 단계입니다. 이번 단원은 여러 뉴런을 가진 Dense 중심입니다.

Network / Model

여러 Layer가 연결된 전체 구조입니다. 각 층의 출력이 다음 층의 입력이 됩니다.

생물학적 비유와 수학적 구현은 구분합니다

교안의 비유는 여러 신호를 받고 통합하여 다음 신호를 전달하는 구조입니다. 보완해서 읽으면, 신경망은 실제 뇌의 완전한 복제가 아니라 그 아이디어를 단순화한 계산 모델입니다.

FFNN은 Network 전체, Dense는 그 안을 구성할 수 있는 Layer 입니다. 교안의 건물 비유에서는 FFNN이 건물 전체라면 Dense는 그 건물을 구성하는 층에 해당합니다.

03 · INPUT / HIDDEN / OUTPUT

층의 역할과 연결 방식은 서로 다른 기준입니다

교안 A의 층 구성과 Dense 정의 [A]

INPUT LAYER

무엇을 받는가?

Sample 하나의 입력 형태를 정의합니다. X=[x₁,x₂,x₃,x₄]라면 Feature는 4개입니다.

HIDDEN LAYER

어떤 중간 표현을 만드는가?

각 뉴런이 서로 다른 Weight와 Bias로 입력을 조합하여 H=[h₁,…,h₆₄]를 만듭니다.

OUTPUT LAYER

최종적으로 무엇을 반환하는가?

수치, Positive 확률, Class별 확률처럼 문제에 맞는 출력을 생성합니다.

같은 기준으로 비교하면 안 되는 이름
구분 이름 질문
Network 안의 역할 Input · Hidden · Output 어디에서 무엇을 하는가?
연결·계산 방식 Dense · Fully Connected 이전 층과 어떻게 연결되는가?

Hidden Layer도 Dense로, Output Layer도 Dense로 구현할 수 있습니다.

Sample 수와 Feature 수를 혼동하지 않습니다

통합교안의 X_train.shape=(120,4)는 Feature 4개를 가진 Sample 120개입니다. 입력 Node 120개라는 뜻이 아닙니다. [B]

보완 이해 · 전처리 이후의 형태

모델의 입력 차원은 원본 열 수가 아니라 실제로 전달되는 최종 Vector의 길이와 맞춰야 합니다. Hidden 출력 64개는 원본에 열이 64개 있다는 뜻이 아니며, 각 Hidden Node의 의미가 반드시 사람이 붙인 이름으로 해석되는 것도 아닙니다.

04 · DENSE = FULLY CONNECTED

직전 층의 모든 입력을 현재 층의 각 뉴런이 받습니다

교안 A의 전결합 정의를 3 → 2로 축소한 보완 도식 [A]

z₁ = x₁w₁₁ + x₂w₂₁ + x₃w₃₁ + b₁

z₂ = x₁w₁₂ + x₂w₂₂ + x₃w₃₂ + b₂

h₁ = f(z₁), h₂ = f(z₂)

모든 연결이 있다는 것과 모든 Weight가 같다는 것은 다릅니다. 학습 결과 어떤 연결의 Weight가 0에 가까워질 수도 있습니다.

Fully Connected가 뜻하지 않는 것

Network의 모든 층끼리 직접 연결, 같은 층의 뉴런끼리 연결, Batch의 Sample끼리 연결한다는 뜻이 아닙니다. 여기서는 직전 층과 현재 층 사이의 전결합을 설명합니다.

05 · FORMULA & PARAMETERS

하나의 Dense를 H = f(XW+b)로 읽습니다

교안의 가중합·활성화 설명과 API 확인 [A] [C]

Z = XW+b → H = f(Z)
X · Input
현재 Layer에 들어오는 값입니다. 첫 층에서는 원래 Feature, 다음 층에서는 이전 Hidden 출력입니다.
W · Weight Matrix
입력과 출력 뉴런 사이의 연결별 학습 Parameter입니다.
b · Bias Vector
출력 뉴런별로 더하는 Parameter입니다. 상수 1에 곱해 더하는 경로로도 설명합니다.
Z · 가중합
Activation을 적용하기 전의 선형 계산값입니다.
H · Activation 출력
입력에 따라 달라지는 계산 결과입니다. Weight 자체가 아닙니다.

Weight·Bias

일반적인 추론에서는 고정합니다. 학습에서는 Update 대상입니다.

Hidden 값

같은 Parameter를 사용해도 Sample이 달라지면 계산 결과가 달라집니다.

보완 표기 규칙

이 페이지는 Sample을 행, Feature를 열로 두어 XW+b를 사용합니다. 교안의 Wx+b는 입력을 열벡터로 놓는 표기와 연결됩니다. 순서를 임의로 바꾸지 말고 Shape을 일관되게 맞춥니다.

Bias를 그림에서 Node로 표현하더라도 원본 데이터의 Feature가 추가되는 것은 아닙니다. zⱼ = Σᵢ xᵢwᵢⱼ + 1×bⱼ의 별도 Parameter로 읽습니다.

07 · SHAPE FLOW

Batch·Feature·Hidden 크기를 각각 분리해서 봅니다

교안 A의 4 → 64 → 3을 행렬 차원으로 전개한 보완 설명

  1. Input X (B,4) Sample마다 Feature 4개
  2. Hidden H₁ (B,64) Sample마다 중간값 64개
  3. Output P (B,3) Sample마다 출력값 3개
Batch 크기를 B로 놓은 기본 모델
값 Shape 의미
X (B,4) 입력 Feature
W₁ / b₁ (4,64) / (64,) 첫 Dense의 Parameter
Z₁ = XW₁+b₁ (B,64) Hidden 가중합
H₁ = ReLU(Z₁) (B,64) Hidden Activation
W₂ / b₂ (64,3) / (3,) 출력 Dense의 Parameter
Z₂ = H₁W₂+b₂ (B,3) Class별 Score
P = Softmax(Z₂) (B,3) Class별 확률 추정값

Batch가 바뀌어도 Weight는 그대로입니다

(1,4) → (1,64) → (1,3)과 (20,4) → (20,64) → (20,3)은 같은 W₁=(4,64), W₂=(64,3)를 사용합니다.

API 확인 · None과 고차원 Dense

(None,64)의 None은 이번 예제에서 고정하지 않은 Batch 차원입니다. 0개나 결측값이 아닙니다. [D]

Dense는 자동 Flatten이 아닙니다. (B,T,D) 입력에 Dense(H)를 적용하면 마지막 입력 차원을 계산해 (B,T,H)가 될 수 있습니다. 이번 2차원 예제를 모든 입력의 절대 규칙으로 확대하지 않습니다. [C]

08 · COUNT PARAMETERS

연결별 Weight와 출력별 Bias를 더합니다

Bias를 사용하는 기본 Dense에서 입력이 D개, 출력이 H개라면:

Parameter = D×H + H = (D+1)H
기본 Dense의 Weight·Bias만 계산합니다
모델 연결 Weight Bias 합계
A 4 → 64 256 64 320
A 64 → 3 192 3 195
A 전체 4 → 64 → 3 448 67 515
B 4 → 64 256 64 320
B 64 → 16 1,024 16 1,040
B 16 → 3 48 3 51
B 전체 4 → 64 → 16 → 3 1,328 83 1,411

A는 설계에서 직접 계산, B는 통합교안 summary와 대조 [B]

일반적인 ReLU·Softmax 자체에는 이 계산에 더할 학습 Weight와 Bias가 없습니다. Input 데이터, Hidden 계산값, Sample 수 역시 모델 Parameter로 세지 않습니다.

보완 범위: use_bias=False면 Bias를 빼고 계산합니다. 다른 Layer나 특수 설정을 추가했다면 그 구성의 Parameter도 별도로 세어야 합니다.

09 · NONLINEARITY

Layer 수만큼 중요한 것은 층 사이의 비선형 변환입니다

교안의 활성화 설명 + Step 1·2의 보완 수식 [A]

H = XW₁+b₁, Y = HW₂+b₂

Y = X(W₁W₂) + (b₁W₂+b₂) = XW′+b′

Linear 계산만 반복하면 하나의 Linear 변환으로 합칠 수 있습니다. Hidden에 ReLU 같은 비선형 변환을 넣으면 일반적으로 하나의 선형식으로 합칠 수 없습니다.

Dense(64)

기본적으로 가중합을 선형 출력합니다. Dense라는 이름에 ReLU가 자동으로 포함되지 않습니다.

Dense(64, activation="relu")

가중합 뒤에 ReLU를 적용합니다. 출력의 차원은 64로 유지됩니다.

Dense의 기본 activation 확인 [C]

출력층이 선형이어도 Network 전체는 비선형일 수 있습니다

Input → Dense+ReLU → Dense(1)은 마지막에 추가 비선형 변환이 없지만, 앞 Hidden의 ReLU 때문에 전체 관계는 비선형일 수 있습니다. 출력 Dense의 HW+b도 그대로 수행됩니다.

10 · OUTPUT DESIGN

출력의 의미에 맞춰 Node·Activation·Loss를 연결합니다

교안의 기본 문제 설정 [A]

교안 기본 구성이며 모든 문제의 유일한 구성은 아닙니다
문제 기본 출력층 의미 대표 Loss
단일값 회귀 Dense(1), 선형 출력 예측 수치 하나 MSE
이진 분류 Dense(1), Sigmoid Positive 확률 추정값 Binary Cross Entropy
단일 Label 다중 분류 Dense(K), Softmax K개 Class 확률 Cross Entropy

Activation

계산 결과를 어떻게 변환할 것인가? 교안의 은닉층 ReLU, 출력층 Softmax가 여기에 해당합니다.

Loss

실제 Label과 얼마나 다른가? 교안의 붓꽃 예제는 정수 Label에 Sparse Categorical Cross Entropy를 사용합니다.

Optimizer

Gradient로 Parameter를 어떻게 바꿀 것인가? 교안에서 선택한 Adam을 모든 문제의 최선으로 일반화하지 않습니다.

보완·API 확인 · Label과 Logits

정수 Class Label은 보통 (B,), 예측은 (B,K)입니다. 이때 둘의 Shape을 무조건 같게 만들지 않고 Sparse Loss의 기대 형식에 맞춥니다.

One-hot Label은 보통 (B,K)이고 Categorical Cross Entropy를 연결합니다. 확률 출력이면 from_logits=False, Softmax 전 Logits 출력이면 그에 맞는 설정을 사용합니다. [F]

여러 수치를 예측하는 회귀는 출력이 여러 개일 수 있습니다. 서로 배타적이지 않은 Multi-label 문제도 단일 Label 다중 분류와 구분합니다. 이번 표는 교안 기본 예제를 읽는 기준입니다.

11 · DEPTH / WIDTH

층의 개수, 뉴런의 개수, 학습값을 구분합니다

교안 A · 모델 구성 [A]

Depth
Layer의 수입니다. 설명할 때 입력층 포함 여부 등 기준을 밝힙니다.
Width
한 Layer의 Node 수입니다. Dense(64)는 너비 64인 Layer 하나입니다.
Parameter
학습에서 조정하는 Weight·Bias입니다.
Hyperparameter
Hidden Node 수, Layer 수, Learning Rate, Batch Size 등 설계·학습 설정입니다.

4 → 64 → 3은 역할 기준으로 입력·은닉·출력 3단계지만, 학습 가능한 Dense는 2개입니다. “은닉층 1개, Dense 2개”처럼 기준을 명시합니다.

교안 기준과 보완 해석

교안은 Hidden Layer가 두 개 이상인 신경망을 DNN으로 연결해 설명합니다. 여기서는 교안의 구분 기준으로 두고, 실제 모델은 층 수와 Node 수를 직접 명시합니다.

“은닉 Node 수를 임의로 정한다”는 것은 무의미하게 고른다는 뜻이 아니라 설계자가 후보를 정해 비교한다는 뜻으로 읽습니다. 더 깊거나 넓다고 일반화 성능까지 보장되지는 않습니다.

X  = [[1, 2, 3]]

14 · NUMPY EXAMPLE

손계산과 같은 결과를 코드로 확인합니다

독립 실행 가능한 보완 예제 · NumPy만 사용 · 학습 Loop 없음 [G] 

import numpy as np


def linear(inputs, weights, bias):
    """보완 예제: 2차원 Batch 입력에 XW+b를 적용합니다."""
    x = np.asarray(inputs, dtype=np.float64)
    w = np.asarray(weights, dtype=np.float64)
    b = np.asarray(bias, dtype=np.float64)

    if x.ndim != 2 or w.ndim != 2:
        raise ValueError("입력과 Weight는 2차원 배열이어야 합니다.")
    if x.shape[1] != w.shape[0]:
        raise ValueError("입력 Feature 수와 Weight 입력 차원이 다릅니다.")
    if b.shape != (w.shape[1],):
        raise ValueError("Bias는 출력 Node 수와 같은 길이여야 합니다.")
    if not all(np.isfinite(a).all() for a in (x, w, b)):
        raise ValueError("입력 또는 Parameter에 NaN·무한대가 있습니다.")

    result = x @ w + b
    if not np.isfinite(result).all():
        raise ValueError("계산 결과에 NaN·무한대가 생겼습니다.")
    return result


# 설명용 고정값입니다. 학습된 Parameter가 아닙니다.
x = np.array([[1.0, 2.0, 3.0]])
w1 = np.array([
    [0.2, -0.1],
    [0.5,  0.2],
    [-0.2, -0.3],
])
b1 = np.array([0.1, 0.2])
w2 = np.array([[0.4], [-0.6]])
b2 = np.array([0.1])

z1 = linear(x, w1, b1)
h1 = np.maximum(z1, 0.0)  # ReLU
prediction = linear(h1, w2, b2)  # 선형 출력

np.set_printoptions(precision=2, suppress=True)
print("X shape:", x.shape)
print("Z1:", z1)
print("H1:", h1)
print("Prediction:", prediction)

# 부동소수점 계산이므로 근사 비교를 사용합니다.
assert np.allclose(z1, [[0.7, -0.4]])
assert np.allclose(h1, [[0.7, 0.0]])
assert np.allclose(prediction, [[0.38]])

계산 결과

X shape: (1, 3)
Z1: [[ 0.7 -0.4]]
H1: [[0.7 0. ]]
Prediction: [[0.38]]

행렬곱과 Bias 계산 후 ReLU를 적용하고 다시 선형 계산합니다. np.allclose()는 부동소수점 값을 정확히 같은 문자열로 비교하지 않고 근사적으로 확인하기 위한 보완 검사입니다.

15 · KERAS STRUCTURE

Input(shape=(4,))에는 Batch 차원을 넣지 않습니다. Dense(units)의 units는 출력 차원입니다. 아래 코드는 데이터 다운로드나 학습 없이 구조만 확인합니다. 

import tensorflow as tf


# 교안의 두 구조를 비교하는 보완 코드입니다.
# 원본 학습 Cell 전체를 재현하는 코드는 아닙니다.
def build_structure(hidden_units, name):
    model = tf.keras.Sequential(name=name)
    model.add(tf.keras.Input(shape=(4,), name="features"))
    for index, units in enumerate(hidden_units, start=1):
        model.add(tf.keras.layers.Dense(
            units, activation="relu", name=f"hidden_{index}"
        ))
    model.add(tf.keras.layers.Dense(
        3, activation="softmax", name="output"
    ))
    return model


# A: AI 교안의 기본 설계 / B: 통합교안 51번의 층 구성
model_a = build_structure([64], "ai_textbook_structure")
model_b = build_structure([64, 16], "notebook_51_structure")

# 학습 전 구조만 확인합니다.
for model in (model_a, model_b):
    model.summary()
    print(model.name, "Parameters:", model.count_params())
    for layer in model.layers:
        if isinstance(layer, tf.keras.layers.Dense):
            kernel, bias = layer.get_weights()
            print(layer.name, "W:", kernel.shape, "b:", bias.shape)

assert model_a.count_params() == 515
assert model_b.count_params() == 1411

# compile은 학습 설정입니다. 이 코드에는 fit()이 없습니다.
model_a.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
    loss="sparse_categorical_crossentropy",
    metrics=["accuracy"],
)

# 가상 입력으로 Shape만 확인합니다. 실제 붓꽃 평가가 아닙니다.
sample_batch = tf.zeros((2, 4), dtype=tf.float32)
probabilities = model_a(sample_batch, training=False)
print("Input shape:", tuple(sample_batch.shape))
print("Output shape:", tuple(probabilities.shape))

17 · COMMON MISTAKES

모양이 비슷한 용어라도 같은 개념은 아닙니다

Step 1·2 복습 · 역할 정의 [A], 구현 동작 [C]~[E]

설명할 때 반드시 바로잡을 오해
자주 하는 착각 올바른 해석
Hidden과 Dense를 같은 기준으로 비교한다. Hidden은 역할, Dense는 연결 방식입니다. 출력층도 Dense일 수 있습니다.
Dense(64)는 Layer 64개라고 생각한다. 출력 Node 64개를 가진 Layer 하나입니다.
Sample 수와 입력 Node 수를 혼동한다. (120,4)는 4개 Feature를 가진 Sample 120개입니다.
Batch가 커지면 Weight도 늘어난다고 생각한다. 같은 Dense Parameter를 Sample별로 공유합니다.
Input(shape=(4,))와 Dense(4)를 동일하게 본다. 입력 형태 정의와 학습 가능한 변환을 구분합니다.
Bias Node를 새로운 원본 Feature로 센다. Bias는 상수 경로로 설명할 수 있는 별도 Parameter입니다.
Fully Connected가 모든 Layer끼리 직접 연결된다는 뜻이다. 이 예제는 직전 층과 현재 층 사이의 전결합입니다. Sample 사이 연결도 아닙니다.
Dense에는 ReLU가 자동으로 들어간다고 생각한다. activation을 지정하지 않으면 기본적으로 선형 출력입니다.
출력 활성화가 없으면 아무 계산도 하지 않는다. 출력 Dense의 HW+b 계산은 수행합니다.
출력층이 선형이면 Network 전체가 선형이다. 앞쪽 Hidden에 비선형 Activation이 있으면 전체 관계는 비선형일 수 있습니다.
Hidden 값이 0~1이면 Class 확률이다. 값의 범위와 역할은 다릅니다. Hidden은 중간 표현입니다.
Hidden 값이 크면 항상 더 중요하다. 다음 Layer의 Weight와 조합을 함께 봐야 합니다.
Dense는 언제나 압축하거나 자동 Flatten한다. 차원을 늘릴 수도 줄일 수도 있습니다. 고차원 입력의 마지막 축에 적용될 수도 있습니다.
Layer를 많이 쌓으면 무조건 좋다. 비선형성, 학습 가능성, 과적합, 검증 성능을 함께 봅니다.
모델 생성·summary·compile을 학습 완료로 본다. fit 등 실제 Parameter Update 절차와 구분합니다.
출력이 나왔으므로 정확한 모델이라고 생각한다. 초기 Parameter로도 출력은 나옵니다. 실제 Label과 별도로 평가합니다.

18 · ERROR READING

오류 문구보다 값의 의미와 차원을 먼저 확인합니다

재실습용 보완 예시입니다. 교안의 실제 오류 로그가 아니며 Library·버전에 따라 문구가 달라집니다.

입력 Feature 수 불일치

expected ... 4, received ... 5

기대 입력 (B,4)에 (B,5)를 넣은 상황입니다. 빠진 열이나 추가된 열을 확인합니다. 의미를 확인하지 않고 reshape로 억지로 맞추지 않습니다.

행렬곱 차원 불일치

matmul ... core dimension mismatch

(2,4) @ (5,3)은 불가능합니다. (2,4) @ (4,3)처럼 안쪽 차원이 같아야 합니다. [G]

Bias Broadcasting

operands could not be broadcast together

(B,64)에 (16,)을 더할 수 없습니다. Bias (64,) 또는 의도한 (1,64)를 확인합니다. 오류가 없어도 결과 Shape을 확인합니다. [G]

Sample 하나의 Batch 축 누락

expected ndim=2, found ndim=1

Sample 하나·Feature 4개가 맞다면 (4,) 대신 (1,4)로 전달합니다. sample.reshape(1,4)는 그 의미가 확인된 때 사용합니다.

출력과 Label 형식 불일치

정수 Label·One-hot·Loss 확인

Sparse Label (B,)와 예측 (B,3)은 정상 조합일 수 있습니다. 두 Shape을 무조건 같게 만들지 않습니다. 정수 Label 범위도 0~2와 맞춥니다. [F]

아직 Built되지 않은 모델

unbuilt

입력 차원을 모르면 Weight가 아직 없을 수 있습니다. Input Shape 정의 또는 실제 입력 호출로 Build 상태를 확인합니다. [E]

NaN·inf·지나치게 큰 값

np.isfinite(x).all()

X, Z₁, H₁, Z₂ 순서로 확인하여 처음 비정상이 생긴 지점을 찾습니다. 입력·Parameter·학습 중 발산을 나눠 살펴봅니다.

실행은 되지만 성능이 나쁨

구조 오류와 성능 문제를 분리

전처리·Label·실제 학습 여부·Loss·Learning Rate· 표현력·일반화를 확인합니다. Layer를 늘리는 것만을 정답으로 삼지 않습니다.

입력의 의미 → 입력 Shape → Layer별 Shape → 출력 의미 → Label 형식 → Loss → 학습·평가 순서로 확인합니다.

20 · INTERVIEW

역할 → 계산 → Shape → 결과 순서로 설명합니다

먼저 답을 말한 뒤 펼쳐서 비교하세요. 아래 답변은 본문의 교안 내용과 보완 설명을 복습합니다.

Q1. 인공신경망이란 무엇인가요?

여러 계산 단위를 Layer로 연결해 입력을 단계적으로 변환하고, Weight와 Bias를 학습하여 원하는 출력을 만드는 모델입니다.

Q2. Input·Hidden·Output은 무엇을 구분하나요?

Network 안에서의 역할을 구분합니다. 입력 형태를 정의하고, 중간 표현을 만들며, 최종 결과를 반환합니다.

Q3. Dense와 Fully Connected Layer는 무엇인가요?

이번 교안에서는 같은 전결합 구조를 뜻합니다. 직전 Layer의 모든 입력을 현재 Layer의 각 뉴런이 받습니다.

Q4. Hidden Layer와 Dense Layer의 차이는 무엇인가요?

Hidden은 역할이고 Dense는 연결·계산 방식입니다. Hidden Layer도 Output Layer도 Dense로 구현할 수 있습니다.

Q5. Dense(64)는 Layer가 64개라는 뜻인가요?

아닙니다. 출력 차원, 즉 출력 Node 수가 64인 Dense Layer 하나입니다.

Q6. Input(shape=(4,))와 Dense(4)는 무엇이 다른가요?

Input은 Sample 하나의 입력 형태를 정의합니다. Dense는 Weight와 Bias로 입력을 변환하여 출력값 4개를 생성합니다.

Q7. Bias를 사용하는 Dense의 Parameter 수는 어떻게 계산하나요?

입력 D개와 출력 H개 사이의 Weight DH개, 출력별 Bias H개를 더해 (D+1)H개입니다.

Q8. 4 → 64 → 3의 Parameter 수는 몇 개인가요?

(4×64+64) + (64×3+3) = 320+195 = 515개입니다.

Q9. 통합교안 51번의 구조와 Parameter 수는 무엇인가요?

4 → 64 → 16 → 3이며, 320+1,040+51 = 1,411개입니다. 기본 AI 교안의 단일 은닉층 예제와 구분합니다.

Q10. Batch 크기가 바뀌면 Parameter 수가 바뀌나요?

이 Dense 예제에서는 바뀌지 않습니다. 같은 Weight와 Bias를 각 Sample에 적용하므로 첫 번째 출력 차원만 Batch 크기를 따릅니다.

Q11. 출력 활성화가 없으면 계산도 하지 않나요?

HW+b는 계산합니다. 추가 비선형 변환 없이 가중합을 반환합니다. Hidden에 비선형성이 있으면 모델 전체는 비선형일 수 있습니다.

Q12. 비선형 Activation이 왜 필요한가요?

선형 계산만 여러 번 연결하면 하나의 선형 변환으로 합칠 수 있습니다. 중간 비선형 변환이 더 복잡한 관계를 표현하게 합니다.

Q13. FFNN인데 역전파를 사용해도 되나요?

네. FFNN은 예측 계산의 흐름이고, 역전파는 Loss의 Gradient를 계산하는 과정입니다. 두 개념은 모순되지 않습니다.

Q14. summary의 (None, 64)는 무엇인가요?

이번 예제에서는 Batch 크기를 고정하지 않았고, Sample 하나의 출력은 64차원이라는 뜻입니다. None은 0이나 결측값이 아닙니다.

Q15. compile을 호출하면 학습이 되나요?

아닙니다. 학습 설정을 지정합니다. 데이터를 이용해 Parameter를 Update하는 학습 절차와 구분해야 합니다.

Q16. 모델에서 출력이 나오면 좋은 모델인가요?

출력은 초기 Parameter로도 계산할 수 있습니다. 구조 검증, 실제 학습 여부, 학습하지 않은 데이터에서의 평가를 별도로 확인합니다.

Q17. Softmax 출력과 최종 Class는 어떻게 다른가요?

Softmax는 Class별 확률 추정값입니다. 단일 Label 분류에서 argmax 등으로 인덱스를 선택한 뒤 Label 이름과 연결합니다.

Q18. Hidden Layer가 많을수록 항상 좋은가요?

아닙니다. 표현력뿐 아니라 Parameter 수, 학습 난이도, 과적합과 일반화 성능을 함께 살펴야 합니다.
