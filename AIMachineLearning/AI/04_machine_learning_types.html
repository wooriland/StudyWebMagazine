Learning Signal

Machine Learning이라고 해서 모든 Model이 같은 방식으로 학습하는 것은 아닙니다. 가장 먼저 확인할 것은 “컴퓨터에게 어떤 학습 신호를 제공하는가?”입니다.

정답을 함께 제공하면 Supervised Learning, 정답 없이 Data의 구조를 찾으면 Unsupervised Learning, 행동의 결과로 Reward 또는 Penalty를 제공하면 Reinforcement Learning으로 구분할 수 있습니다.

10 · LOSS BRIDGE

지도학습에는 정답 y가 있기 때문에 Prediction과 정답을 직접 비교할 수 있습니다

이번 단원에서는 Loss 수식을 계산하지 않고, 왜 회귀와 분류에서 서로 다른 Loss로 연결되는지만 이해합니다.

PREDICTION ŷ
↔
ANSWER y
→
DIFFERENCE Loss
REGRESSION

숫자의 차이

Actual Number ↔ Predicted Number
대표 연결: MSE

실제값과 예측값의 수치 차이를 작게 만드는 방향으로 학습합니다.

CLASSIFICATION

확률 분포의 차이

Actual Class ↔ Predicted Probability
대표 연결: Cross Entropy

정답 Class에 대한 예측 확률을 높이는 방향으로 학습합니다.

뒤에서 다시 공부

MSE는 선형회귀와 오차·손실 함수 단원에서, Cross Entropy는 Logistic Regression과 다중 분류 단원에서 자세히 공부합니다.

14 · COMMON MISTAKES

학습 방법의 이름보다 분류 기준을 헷갈리지 않는 것이 중요합니다

01

지도학습과 Rule-Based를 같은 것으로 생각한다

Rule-Based는 사람이 Rule을 직접 작성합니다. Supervised Learning은 X와 정답 y를 이용해 Model이 관계를 학습합니다.

02

Supervised의 “지도”를 Map으로 생각한다

여기서 지도는 정답을 알려주며 학습을 가르친다는 의미입니다.

03

Regression을 하나의 Algorithm 이름으로만 생각한다

Regression은 먼저 연속형 Target을 예측하는 문제 유형입니다.

04

Classification과 Clustering을 같은 것으로 본다

Classification은 Label이 있고, Clustering은 정답 Label 없이 Group을 찾습니다.

05

Unsupervised는 정답이 없으니 아무것도 배우지 못한다

정답을 맞히는 대신 Data의 Pattern, Structure, Similarity와 Relationship을 찾습니다.

06

Reinforcement에서도 매번 정답 Action을 제공한다

강화학습의 핵심은 Action 결과의 Reward 또는 Penalty를 이용해 행동을 개선하는 것입니다.

07

Unsupervised와 Reinforcement는 Label이 없으니 같은 방식이다

Unsupervised는 Data 구조를, Reinforcement는 행동 전략을 학습합니다.

08

Classification은 항상 두 Class만 있다

Binary Classification도 있고 3개 이상 Class를 갖는 Multi-Class Classification도 있습니다.

09

Regression 결과는 정수만 나온다

Regression은 연속적인 수치를 다루므로 실수 값도 자연스럽게 예측할 수 있습니다.

10

Supervised Learning과 Deep Learning을 같은 분류로 본다

Supervised는 학습 신호 기준이고, Deep Learning은 Neural Network를 사용하는 Model 계열의 개념입니다.

15 · DESIGN ERROR

이번 단원에서는 Runtime Error보다 문제 정의 오류를 먼저 찾습니다

특정 Python Library를 배우는 단원이 아니므로 실제 Error Message보다 학습 문제를 잘못 정의한 상황을 분석합니다.

DESIGN ERROR 01
“내일 매출액 자체를 예측하지만 Classification으로 만들자.”
확인

Target이 연속적인 금액 자체라면 Regression 문제인지 먼저 검토합니다.

Continuous Target → Regression
DESIGN ERROR 02
“Cat / Dog 정답 Label이 있지만 Clustering으로 학습하자.”
확인

정답 Class가 이미 있다면 Supervised Classification을 먼저 검토할 수 있습니다.

Label 있음 → Classification
DESIGN ERROR 03
“Cluster 0은 원래 VIP라는 정답이다.”
문제

Clustering은 처음부터 VIP라는 정답을 제공한 것이 아닙니다. Cluster를 만든 뒤 특징을 분석해 의미를 해석합니다.

DESIGN ERROR 04
“강화학습에서는 매 행동마다 정답 Action을 직접 알려준다.”
수정

교안의 강화학습은 행동 결과에 대한 Reward 또는 Penalty의 경험을 이용합니다.

DESIGN ERROR 05
“CNN이니까 Supervised Learning이다.”
문제

CNN은 Deep Learning의 Model 구조이고, Supervised는 학습 신호를 구분하는 기준입니다.

CNN + Image Label → Supervised Classification
DESIGN ERROR 06
“Algorithm 이름만 보고 Regression인지 Classification인지 판단한다.”
수정

먼저 해결하려는 Target의 Type과 문제의 목표를 확인한 후 적절한 Algorithm을 선택합니다.

17 · INTERVIEW POINT

정의 → 차이 → 실제 예 순서로 설명합니다

Q1. Machine Learning의 대표적인 학습 방법은 무엇인가요?

지도학습, 비지도학습, 강화학습으로 구분할 수 있습니다. 지도학습은 Data와 정답을 함께 사용하고, 비지도학습은 정답 없는 Data의 구조를 찾으며, 강화학습은 행동의 결과인 Reward 또는 Penalty를 이용해 더 좋은 행동을 학습합니다.

Q2. 지도학습이란 무엇인가요?

입력 X와 정답 y를 함께 제공하여 X와 y 사이의 관계를 Model이 학습하도록 하는 Machine Learning 방식입니다.

Q3. 지도학습은 어떻게 다시 나뉘나요?

교안에서는 종속변수 y가 연속형이면 Regression, 범주형이면 Classification으로 구분합니다.

Q4. Regression이란 무엇인가요?

연속적인 수치를 Target으로 예측하는 지도학습 문제입니다. “얼마인가?”라는 질문으로 기억하면 쉽습니다.

Q5. Classification이란 무엇인가요?

입력 Data가 어느 Class 또는 Category에 속하는지 예측하는 지도학습 문제입니다.

Q6. 비지도학습이란 무엇인가요?

정답 Label이 없는 Data를 사용하여 Data 내부의 Pattern, Structure, Similarity 또는 Relationship을 찾는 학습 방식입니다.

Q7. Classification과 Clustering의 차이는 무엇인가요?

Classification은 미리 정의된 정답 Class가 있는 지도학습 문제이고, Clustering은 정답 Label 없이 비슷한 Data끼리 Group을 찾는 비지도학습 문제입니다.

Q8. 강화학습이란 무엇인가요?

환경에서 Action을 수행하고 그 결과로 얻는 Reward 또는 Penalty를 이용해 더 좋은 행동 전략을 학습하는 방식입니다. 교안에서는 MDP를 함께 연결합니다.

Q9. 비지도학습과 강화학습은 무엇이 다른가요?

비지도학습은 Data 자체의 구조나 Group을 찾는 것이 중심이고, 강화학습은 환경에서 행동하고 Reward를 받으며 행동 전략을 개선하는 것이 중심입니다.

Q10. Supervised Learning과 Deep Learning은 같은 개념인가요?

아닙니다. Supervised는 어떤 학습 신호를 사용하는가에 대한 분류이고, Deep Learning은 Neural Network를 사용하는 Machine Learning의 한 유형입니다.

Q11. CNN으로 지도학습을 할 수 있나요?

가능합니다. Image와 Class Label을 이용해 CNN을 Training하면 Deep Learning Model을 이용한 Supervised Classification 문제로 설명할 수 있습니다.

Q12. 지도학습에서 X와 y는 무엇인가요?

X는 Model에 입력되는 Feature이고, y는 Model이 맞혀야 하는 Target 또는 Label입니다. 이 관계가 바로 다음 단원의 핵심입니다.

Q13. 같은 Algorithm이 Classification과 Regression에 모두 사용될 수 있나요?

교안에서는 Decision Tree, SVM, KNN, Ensemble 등의 일부 알고리즘 계열이 분류와 회귀 문제 양쪽에서 사용될 수 있다고 설명합니다. 따라서 Algorithm 이름과 문제 유형을 완전히 동일시하면 안 됩니다.
