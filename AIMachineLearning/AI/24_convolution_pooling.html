01 · CORE IDEA

Convolution은 특징을 찾고, Pooling은 공간 정보를 요약합니다

AI 교안의 Padding·Stride·Pooling 흐름을 Step 1·2 구조로 재구성

입력 Feature Map → Padding → Convolution → Activation → Pooling

Convolution

Patch와 Filter를 곱하고 더하여 위치별 Feature를 계산합니다.

Padding

가장자리 계산 범위와 출력 공간 크기를 조절합니다.

Stride

Filter 또는 Pooling Window의 이동 간격을 결정합니다.

Pooling

지역 값을 Max 또는 Average로 요약하여 Down Sampling합니다.

Padding과 Stride는 같은 Filter 구조의 Parameter 수를 바꾸지 않고 출력 공간과 적용 위치를 바꿉니다. 일반적인 Max·Average Pooling은 학습 Weight 없이 Height·Width를 줄이고 Channel 수를 유지합니다.

02 · WHY?

특징을 찾는 것만큼 계산량과 위치 정보의 균형도 중요합니다

26×26×32 Feature Map은 이미지 한 장당 21,632개의 Activation을 가집니다. 다음 Layer가 이 값을 모두 처리하면 계산량과 메모리 사용량이 커집니다.

26 × 26 × 32 = 21,632 activations

  1. Convolution 지역 특징을 계산
  2. Padding 가장자리 참여와 출력 크기 조절
  3. Stride 적용 위치와 해상도 조절
  4. Pooling 지역 값을 대표값으로 요약
유지하고 싶은 것 유용한 특징·위치 정보
↔
줄이고 싶은 것 연산량·메모리·중복 정보

Down Sampling은 효율을 높일 수 있지만 한 번 줄어든 세밀한 공간 정보는 자동으로 복원되지 않습니다. 분류·탐지·분할 등 문제의 목적에 맞춰 축소 속도를 결정해야 합니다.

03 · CONVOLUTION

입력 Patch와 Filter를 곱하고 모든 Channel 결과를 합산합니다

Z[i,j,f] = Σu Σv Σc X[i·S_h+u, j·S_w+v, c] K[u,v,c,f] + b[f]
보완 수식의 기호
기호 의미
i, j 출력 Feature Map의 위치
f Filter 번호·출력 Channel
u, v Kernel 내부의 공간 위치
c 입력 Channel
S_h, S_w 세로·가로 Stride
b[f] Filter별 Bias
  1. Patch 선택 Kernel과 같은 공간 영역
  2. 곱셈 공간과 입력 Channel 전체
  3. 합산 + Bias 출력 Scalar 하나
  4. 이동 같은 Filter를 다음 위치에 적용

Filter는 공간 위치를 옮길 때 같은 Weight를 공유하지만, 학습 Step에서는 역전파와 Optimizer에 의해 업데이트됩니다.

04 · PADDING

입력 주변에 값을 추가하여 가장자리 계산 범위를 확장합니다

원본 3×3

1 2 3
4 5 6
7 8 9
→

Zero Padding 1

0 0 0 0 0
0 1 2 3 0
0 4 5 6 0
0 7 8 9 0
0 0 0 0 0

가장자리 참여

중앙보다 적게 사용되는 모서리·가장자리 Pixel의 계산 기회를 늘립니다.

출력 크기 조절

Kernel 적용 후 줄어드는 Height·Width를 조절합니다.

끝부분 손실 완화

Stride와 Kernel 때문에 계산에서 빠질 수 있는 끝부분을 다룹니다.

Padding은 실제 관측 정보를 새로 만드는 작업이 아닙니다

추가한 0은 이미지에서 관측한 Pixel이 아니라 계산 범위를 만들기 위한 인공 값입니다. Padding을 크게 넣는다고 원본 정보가 증가하는 것은 아닙니다.

05 · VALID VS SAME

Padding 사용 여부와 출력 공간 규칙을 구분합니다

대표적인 Stride 1 비교
구분 valid same
Padding 추가하지 않음 출력 규칙에 맞게 추가
5×5, K=3, S=1 3×3 5×5
가장자리 참여 상대적으로 적음 참여 기회 증가
Conv Parameter 같은 Filter 구조이면 동일 같은 Filter 구조이면 동일

5×5 input · 3×3 kernel · stride 1

valid: (5−3)/1+1 = 3

padding 1: (5+2−3)/1+1 = 5

same을 “어떤 Stride에서도 입력과 출력이 무조건 완전히 같다”로 외우지 않습니다. Stride가 1보다 크면 사용하는 Framework의 실제 출력 Shape을 확인합니다.

06 · STRIDE

Filter가 한 번에 이동하는 공간 간격을 결정합니다

Stride 1 0 → 1 → 2 → 3 적용 위치가 많고 출력 공간이 큼
Stride 2 0 → 2 → 4 적용 위치가 줄고 출력 공간이 작음
Stride가 커질 때의 변화
항목 변화
Filter 적용 위치 감소
출력 Height·Width 감소
연산 횟수 감소 가능
세밀한 위치 정보 손실 가능성 증가
Conv Parameter 수 같은 Filter 구조이면 변화 없음

Stride는 Parameter 개수를 줄이는 설정이 아니라, 같은 Filter를 적용할 위치와 출력 해상도를 조절하는 Hyperparameter입니다.

07 · CONV OUTPUT SHAPE

입력·Padding·Kernel·Stride를 공식에 넣어 계산합니다

Dilation이 1인 기본 Convolution의 보완 공식입니다.

H_out = floor((H_in + 2P_h − K_h) / S_h) + 1 W_out = floor((W_in + 2P_w − K_w) / S_w) + 1 C_out = Filter 수
CASE A

Valid · Stride 1

(5−3)/1+1 = 3

5×5 → 3×3
CASE B

Padding 1 · Stride 1

(5+2−3)/1+1 = 5

5×5 → 5×5
CASE C

Valid · Stride 2

floor((5−3)/2)+1 = 2

5×5 → 2×2

Height·Width는 공간 설정으로 결정되고, 출력 Channel은 Filter 수로 결정됩니다.

08 · POOLING

지역의 여러 값을 하나의 대표값으로 요약합니다

입력 H × W × C
→
Pooling Window Max 또는 Average
→
출력 작아진 H × W · 같은 C

Down Sampling

공간 해상도와 Activation 수를 줄입니다.

고정 요약 규칙

일반적인 Max·Average Pooling에는 학습 Weight가 없습니다.

Channel 유지

각 Channel 안에서 독립적으로 공간 정보를 요약합니다.

Parameter가 0이라는 뜻

학습되는 Weight와 Bias가 없다는 뜻입니다. Max 비교나 평균 계산까지 사라진다는 뜻은 아닙니다.

09 · POOL OUTPUT SHAPE

Pool Size와 Pooling Stride로 공간 크기를 계산합니다

H_pool = floor((H_in + 2P_h − F_h) / S_h) + 1

W_pool = floor((W_in + 2P_w − F_w) / S_w) + 1

C_out = C_in

26×26×32 → 2×2 Pool · Stride 2 → 13×13×32

대표적으로 Pool Size 2×2와 Stride 2를 함께 사용하면 Window가 겹치지 않습니다. 하지만 두 설정이 반드시 항상 같아야 하는 것은 아닙니다.

10 · MAX POOLING

지역에서 가장 강한 Activation을 대표값으로 남깁니다

입력 Feature Map

1 3 2 4
5 6 1 2
7 2 8 3
0 1 4 9

2×2 Max Pool · S=2

6 4
7 9
[1 3; 5 6] max = 6
[2 4; 1 2] max = 4
[7 2; 0 1] max = 7
[8 3; 4 9] max = 9

중간 Feature Map에서는 값이 원본 색이 아니라 Filter 반응입니다. 따라서 Max Pooling은 단순히 “가장 밝은 색”이 아니라 해당 Feature의 가장 강한 지역 반응을 남긴다고 해석합니다.

11 · AVERAGE POOLING

지역 전체의 평균적인 반응을 대표값으로 남깁니다

같은 입력 Feature Map

1 3 2 4
5 6 1 2
7 2 8 3
0 1 4 9

2×2 Average Pool · S=2

3.75 2.25
2.50 6.00
(1+3+5+6)/4 3.75
(2+4+1+2)/4 2.25
(7+2+0+1)/4 2.50
(8+3+4+9)/4 6.00

Max Pooling과 출력 Shape은 같을 수 있지만 값의 의미는 다릅니다. Max는 가장 강한 반응을, Average는 Window 전체의 평균 반응을 유지합니다.

12 · GLOBAL AVERAGE POOLING

각 Channel의 전체 공간을 값 하나로 요약합니다

입력 7×7×512 Feature Map 512개
→
Channel별 전체 평균 1×1×512 또는 길이 512 Vector
지역 평균과 전체 공간 평균
구분 AveragePooling2D GlobalAveragePooling2D
평균 범위 작은 지역 Window Channel 전체 공간
공간 출력 단계적으로 감소 Channel당 값 하나
대표 위치 중간 Feature Map 분류 Layer 직전
학습 Weight 없음 없음

Flatten과의 차이

7×7×512를 Flatten하면 25,088개 값을 유지합니다. Global Average Pooling은 각 Channel의 평균만 남겨 512개 값으로 줄입니다. 다음 Dense Layer의 Parameter를 크게 줄일 수 있지만 과적합 방지를 보장하지는 않습니다.

20 · NUMPY CHECK

Max와 Average Pooling을 직접 계산하여 결과를 확인합니다 

import numpy as np


def pool2d(
    feature_map: np.ndarray,
    pool_size: int = 2,
    stride: int = 2,
    mode: str = "max",
) -> np.ndarray:
    if feature_map.ndim != 2:
        raise ValueError(
            "feature_map은 2차원 배열이어야 합니다."
        )

    if type(pool_size) is not int or pool_size < 1:
        raise ValueError(
            "pool_size는 1 이상의 정수여야 합니다."
        )

    if type(stride) is not int or stride < 1:
        raise ValueError(
            "stride는 1 이상의 정수여야 합니다."
        )

    if mode not in {"max", "average"}:
        raise ValueError(
            "mode는 'max' 또는 'average'여야 합니다."
        )

    input_h, input_w = feature_map.shape

    output_h = (
        input_h - pool_size
    ) // stride + 1

    output_w = (
        input_w - pool_size
    ) // stride + 1

    if output_h < 1 or output_w < 1:
        raise ValueError(
            "Pool Window가 입력 공간보다 큽니다."
        )

    output = np.empty(
        (output_h, output_w),
        dtype=np.float64,
    )

    for out_y in range(output_h):
        for out_x in range(output_w):
            start_y = out_y * stride
            start_x = out_x * stride

            window = feature_map[
                start_y:start_y + pool_size,
                start_x:start_x + pool_size
            ]

            if mode == "max":
                output[out_y, out_x] = np.max(window)
            else:
                output[out_y, out_x] = np.mean(window)

    return output


feature_map = np.array([
    [1, 3, 2, 4],
    [5, 6, 1, 2],
    [7, 2, 8, 3],
    [0, 1, 4, 9],
], dtype=np.float64)

print(pool2d(feature_map, mode="max"))
print(pool2d(feature_map, mode="average"))

25 · INTERVIEW POINTS

무엇을 줄이고 무엇을 유지하는지 설명합니다

Q1. Convolution은 무엇인가요?

입력 Patch와 Filter를 곱하고 모든 공간·입력 Channel 결과를 합한 뒤 Bias를 더해 위치별 특징을 계산하는 연산입니다.

Q2. Padding은 왜 사용하나요?

가장자리 정보의 계산 참여와 출력 공간 크기, 끝부분 손실을 조절하기 위해 사용합니다.

Q3. Valid와 Same의 차이는 무엇인가요?

Valid는 추가 Padding을 사용하지 않고, Same은 Framework 규칙에 따라 Padding을 추가합니다.

Q4. Stride가 커지면 무엇이 달라지나요?

적용 위치와 출력 공간, 연산 횟수가 줄어들며 세밀한 위치 정보가 손실될 수 있습니다.

Q5. Stride나 Padding이 Conv Parameter 수를 바꾸나요?

같은 Kernel·입력 Channel·Filter 수라면 Parameter 수는 변하지 않습니다.

Q6. Pooling은 왜 사용하나요?

지역 값을 대표값으로 요약하여 Height·Width와 Activation 수를 줄이기 위해 사용합니다.

Q7. Pooling에도 학습 Parameter가 있나요?

일반적인 Max·Average Pooling에는 학습 Weight와 Bias가 없습니다.

Q8. Pooling은 Channel 수를 줄이나요?

일반적인 2D Pooling은 각 Channel을 독립 처리하므로 Channel 수를 유지합니다.

Q9. Max와 Average Pooling의 차이는 무엇인가요?

Max는 가장 강한 반응을, Average는 지역 전체의 평균 반응을 남깁니다.

Q10. Pool Size와 Stride는 같아야 하나요?

반드시 같아야 하는 것은 아니지만 2×2 Window와 Stride 2가 대표적으로 사용됩니다.

Q11. Strided Conv와 Pooling의 차이는 무엇인가요?

Strided Conv는 학습 가능한 Filter로, Pooling은 고정된 Max·Average 규칙으로 Down Sampling합니다.

Q12. Global Average Pooling은 무엇인가요?

각 Channel의 전체 Height·Width를 평균내어 Channel마다 값 하나만 남기는 방식입니다.

Q13. Flatten과 GAP의 차이는 무엇인가요?

Flatten은 모든 공간 값을 유지하고, GAP는 Channel별 평균만 유지합니다.

Q14. 26×26×32에 2×2 Max Pool, S=2를 적용하면?

출력은 13×13×32이며 Pooling Parameter 수는 0입니다.

Q15. Pooling을 많이 쓰면 왜 문제가 될 수 있나요?

공간 해상도가 너무 빨리 줄어 작은 객체와 세밀한 경계 정보가 사라질 수 있습니다.

Q16. 교안 주석과 Summary가 다르면 어떻게 하나요?

현재 활성화된 실제 Layer와 입력 Shape에서 Shape·Parameter를 다시 계산하여 같은 구조끼리 비교합니다.
