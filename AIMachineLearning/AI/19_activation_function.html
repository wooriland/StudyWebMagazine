01 · CORE CONCEPT

가중합을 바꾸는 함수이자 기울기 전달에 참여하는 함수입니다

교안 A §6-2-2 + Step 1·2의 보완 표기 [A]

Z=XW+b → A=f(Z)

교안은 활성화 함수를 선형 결과에 비선형성을 부여하고 출력 범위를 조절하는 함수로 설명합니다. 여기서는 Sample을 행에 놓아 XW+b를 사용합니다. 교안의 Wx+b와 표기 방향을 구분합니다.

순전파의 질문

같은 가중합 Z를 어떤 값 f(Z)으로 바꾸는가?

역전파의 질문

계산의 민감도인 미분 f′(z)가 어떤 Gradient를 전달하는가?

X
현재 Layer의 입력입니다. 원본 Feature 또는 이전 Layer의 출력입니다.
W · b
가중합을 만드는 Weight Matrix와 Bias입니다.
Z
활성화 전 가중합입니다. 원본 Feature X와 구분합니다.
A · f
활성화 후 값과 활성화 함수입니다. Hidden 값은 최종 Class와 다릅니다.

함수 이름뿐 아니라 입력·출력 범위, 미분, 사용 위치, 설정값을 함께 읽습니다.

02 · WHY ACTIVATION?

비선형 표현·출력 형식·학습 신호를 함께 이해합니다

교안의 비선형성·Hidden/Output 설명 [A] · 식 전개는 보완 이해

선형 계산만 쌓으면 하나로 합칠 수 있습니다

H=XW₁+b₁, Y=HW₂+b₂

Y=X(W₁W₂)+(b₁W₂+b₂)=XW′+b′

위 식은 교안의 설명을 풀어쓴 보완 전개입니다. 중간에 비선형 함수를 넣은 Y=f(XW₁+b₁)W₂+b₂는 일반적으로 하나의 선형식으로 합칠 수 없습니다.

Hidden Layer

중간 표현에 비선형성을 부여합니다. 같은 모델에서 여러 활성화를 함께 사용할 수 있습니다.

Output Layer

예측 수치·이진 확률·Class별 확률처럼 문제에 맞는 출력을 만듭니다.

Gradient

Scalar 활성화에서는 ∂L/∂z=(∂L/∂a)f′(z)로 로컬 미분이 반영됩니다.

출력층에 추가 활성화가 없더라도 HW+b는 계산합니다. 회귀의 모든 Layer에 활성화가 없다는 뜻은 아닙니다. 앞 Hidden에 비선형 함수가 있으면 선형 출력 모델 전체도 비선형일 수 있습니다.

03 · CONCEPT MAP

한계와 보완 관계를 따라 여섯 함수를 읽습니다

교안의 순서와 Step 1·2의 관계도 [A]

  1. Step 명확한 0·1 판단
    하지만 경계 밖 미분은 0
  2. Sigmoid · tanh 부드럽게 변함
    하지만 양 끝에서 포화
  3. ReLU 양수 구간의 미분 1
    음수 구간의 미분 0
  4. Leaky ReLU 음수 구간에도
    작은 기울기를 남김

이 흐름은 모든 앞 함수를 폐기하라는 뜻이 아닙니다

교안의 한계와 보완을 연결한 학습 지도입니다. 출력층은 별도로 “수치인가, 이진 확률인가, 여러 Class 중 하나인가?”를 묻습니다.

원소별 변환

z₁ → f(z₁), z₂ → f(z₂)
Step·Sigmoid·tanh·ReLU·Leaky ReLU의 각 위치를 따로 계산합니다.

Vector 공동 변환

[z₁,z₂,z₃] → [p₁,p₂,p₃]
Softmax는 같은 Class Vector의 여러 값을 함께 사용합니다.

04 · 01 / 06 · STEP

Step: 임계값을 넘었는지만 남깁니다

교안 A의 임계값·미분 설명 / 교안 B의 > 조건 [A] [B]

f(z)=0 (z≤0), 1 (z>0)

통합교안의 np.where(x > 0, 1, 0)를 기준으로 합니다. 정확히 0인 입력도 0입니다. >=로 바꾸면 경계값 처리도 바뀝니다.

순전파

[-2,-0.1,0,0.1,2] → [0,0,0,1,1]
양수의 크기는 남기지 않고 두 상태로 구분합니다.

미분 · 보완 구분

z≠0에서는 미분값 0, z=0에서는 불연속으로 미분이 정의되지 않습니다. 작은 변화 방향을 Gradient로 얻기 어렵습니다.

교안의 학습 한계는 일반적인 미분 기반 역전파의 문맥입니다. Step을 사용하는 어떤 알고리즘도 학습할 수 없다는 뜻으로 확대하지 않습니다.

05 · 02 / 06 · SIGMOID

Sigmoid: 0과 1 사이로 부드럽게 변환합니다

교안 A의 S자·이진 출력·기울기 소실 설명 / 미분·숫자·정확한 범위는 보완 [A]

σ(z)=1/(1+e^(−z))

σ′(z)=σ(z)(1−σ(z))

e는 자연상수입니다. 큰 음수에서는 0에, 큰 양수에서는 1에 가까워집니다. 중심 입력 0의 출력은 0.5, 미분값은 0.25입니다. 교안은 이진 분류 출력층에 연결합니다.

수식으로 계산한 보완 값
z σ(z) σ′(z)
−2 0.119203 0.104994
0 0.500000 0.250000
2 0.880797 0.104994
10 약 0.999955 약 0.000045

Saturation · 포화

양 끝에서는 입력이 더 변해도 출력 변화가 작습니다. 역전파에서 작은 로컬 미분이 반복되면 기울기 전달이 약해질 수 있습니다.

교안 설명과 수학적 범위를 나누어 읽습니다

교안은 양 끝에서 “미분값이 0이 된다”는 취지로 설명합니다. 유한 실수의 정확한 수학에서는 출력이 (0,1)이고 미분은 양수인 채 0에 가까워집니다. 컴퓨터에서는 반올림·표현 한계로 끝값이 표시될 수 있습니다.

Sigmoid는 확률값을 만들도록 사용하는 함수이고 Threshold는 Class를 고르는 규칙 입니다. Hidden에서 Sigmoid를 썼다고 그 값이 반드시 특정 Class의 확률인 것은 아닙니다.

06 · 03 / 06 · TANH

tanh: 0을 중심으로 음수와 양수를 표현합니다

교안 A의 tanh 설명과 Step 1·2의 수식 보완 [A]

tanh(z)=(e^z−e^(−z))/(e^z+e^(−z))

tanh′(z)=1−tanh²(z)

교안은 Sigmoid와 유사한 S자 함수로 설명하며 RNN·LSTM·GRU에 연결합니다. 정확한 유한 실수 출력은 (−1,1), 중심 출력은 0, 중심 미분은 1입니다.

Sigmoid와 중심 비교

σ(0)=0.5, tanh(0)=0
음수와 양수를 함께 표현합니다.

양 끝의 포화

z가 양·음의 방향으로 커지면 출력은 ±1에 가까워지고 미분은 0에 가까워집니다.

“항상 더 큰 Gradient”는 아닙니다

교안은 Sigmoid보다 출력 변화폭이 크고 기울기 소실 증상이 적다고 설명합니다. z=0에서 미분은 Sigmoid 0.25, tanh 1이지만, z=2에서는 각각 약 0.104994, 0.070651입니다. 모든 위치에서 tanh의 기울기가 더 크지는 않습니다.

tanh 자체는 −1·1만 고르지 않습니다. 교안의 임계값 판단 설명과 함수의 연속적인 출력을 구분합니다. 또한 0 중심 함수라는 사실이 어떤 Batch의 출력 평균도 항상 0임을 보장하지는 않습니다.

07 · 04 / 06 · RELU

ReLU: 음수는 0, 양수는 크기까지 유지합니다

교안 A의 ReLU·Dying ReLU 설명 / 경계와 지속 상태의 구분은 보완 [A]

ReLU(z)=max(0,z)

교안은 exp 없이 비교로 값을 정하는 단순 계산과 깊은 신경망·CNN의 사용을 연결합니다. Step은 양수를 1로 바꾸지만 ReLU는 0.5·2·10을 각각 그대로 전달합니다.

ReLU′(z)=0 (z<0), 1 (z>0)

보완해서 읽으면 교안의 “미분값 범위 0~1”은 0이 아닌 위치에서 0 또는 1이라는 뜻입니다. z=0에서는 양쪽 기울기가 달라 미분이 정의되지 않으며, Library의 경계 Gradient 규약은 별개입니다.

Step의 미분 한계와 같지 않습니다

Step은 경계 밖에서 모두 기울기 0입니다. ReLU는 넓은 양수 구간에서 기울기 1을 전달합니다. 한 점에서 미분이 안 된다는 사실만으로 같은 학습 특성이라고 판단하지 않습니다.

Dying ReLU를 해석하기

교안은 음수 구간의 기울기 0과 비활성 문제를 설명합니다. Sample 하나의 출력 0은 정상적인 결과일 수 있습니다. 관련 학습 입력 전반에서 같은 Node가 계속 음수 가중합을 받아 출력·로컬 기울기가 0인 지속 상태와 구분합니다.

양수 구간의 로컬 미분 1은 장점이지만, 모든 Gradient 소실·폭주나 모든 학습 문제의 해결을 보장하지 않습니다.

08 · 05 / 06 · LEAKY RELU

Leaky ReLU: 음수 구간에도 작은 기울기를 남깁니다

교안 A의 ε 설명, 교안 B 기본 0.01·그래프 0.1 [A] [B]

f(z)=αz (z≤0), z (z>0) · 이번 설명은 0<α<1

f′(z)=α (z<0), 1 (z>0)

AI 교안의 ε와 통합교안 코드의 alpha는 여기서 같은 음수 기울기 설정으로 연결합니다. 음수에 0.01을 출력하는 것이 아니라 그 입력에 0.01을 곱한 값을 출력합니다.

교안의 설정과 보완 손계산
구분 α z=−2의 출력
통합교안 함수 기본값 0.01 −0.02
통합교안 102쪽 그래프 호출 0.1 −0.2

np.where(x > 0, x, alpha*x)가 원본 정의입니다. 교안은 ReLU의 음수 구간 기울기 0을 완화하려는 변형으로 설명합니다. α≠1이면 z=0의 양쪽 기울기는 달라집니다.

α와 Learning Rate는 다릅니다

α는 Activation의 음수 구간 기울기, Learning Rate는 Optimizer의 Update 크기 설정입니다. 이번 교안의 α는 고정하여 선택하는 Hyperparameter입니다.

교안에는 ReLU와 Leaky ReLU의 성능 차이가 대부분 없다는 취지의 설명이 있습니다. 해당 절에는 모든 상황을 일반화할 실험 조건이 제시되지 않습니다. 구조적 차이는 이해하되 실제 우열은 문제와 실험에서 확인합니다.

09 · 06 / 06 · SOFTMAX

Softmax: 여러 Score를 하나의 확률 분포로 만듭니다

교안 A의 출력층 설명 / 숫자·2-Class 관계는 보완 [A]

pₖ = exp(zₖ) / Σⱼ exp(zⱼ)

K는 Class 수입니다. 한 확률을 계산할 때도 같은 Vector의 다른 Score가 필요합니다. 교안은 다중 분류 출력층과 합이 1인 확률을 연결합니다.

같은 [2,1,0]에 Sigmoid를 각각 적용하면 [0.880797,0.731059,0.5]로 합이 약 2.111856입니다. 독립적인 값 변환과 공동 정규화는 다릅니다.

교안의 Class 3개 이상은 대표 사용 예입니다

수학적으로 두 Score에도 적용할 수 있습니다. Softmax([z,0])의 첫 확률 = exp(z)/(exp(z)+1) = σ(z) 입니다. 반대로 값 하나만 있으면 Softmax([z])=[1]입니다.

정확한 유한 실수에서 K≥2라면 각 확률은 0과 1 사이입니다. 실제 계산에서는 반올림·Underflow로 0·1이 나타날 수 있습니다. 확률 분포와 실제 정답 여부도 구분합니다.

10 · SOFTMAX GRADIENT

Softmax의 미분은 Class들 사이의 편미분입니다

교안의 범위 설명 [A] · Jacobian 전개는 보완 이해

교안에는 미분값 범위가 −0.25~0.25라고 적혀 있습니다. 이를 Step 1·2의 보완 수식으로 읽으면 다음과 같습니다.

∂pᵢ/∂zⱼ = pᵢ(δᵢⱼ−pⱼ)

δᵢⱼ는 i=j이면 1, 다르면 0입니다.

자기 Score

∂pᵢ/∂zᵢ = pᵢ(1−pᵢ)
내 Score 증가에 내 확률이 증가하는 방향입니다.

다른 Score

∂pᵢ/∂zⱼ = −pᵢpⱼ (i≠j)
다른 Score 증가에 내 확률이 감소하는 방향입니다.

이 여러 편미분을 모은 것이 Jacobian, 야코비안 행렬입니다. 같은 Vector의 확률들이 서로 연결되어 있음을 보여줍니다.

−0.25~0.25는 Softmax 자체 편미분 성분의 범위로 읽습니다. 하나의 Scalar 미분값만 있는 것도 아니고, 최종 Loss의 전체 Gradient까지 그 범위로 제한된다는 뜻도 아닙니다.

11 · SIX-FUNCTION COMPARISON

출력 범위와 미분을 한 칸으로 섞지 않습니다

교안 정의를 Step 1·2의 수식으로 정리 [A]

수식에서 정리한 보완 표 · 경계점은 별도 확인
함수 출력 범위 핵심 미분 읽을 한계
Step {0,1} z≠0에서 0 z=0 불연속
Sigmoid (0,1) σ(z)(1−σ(z)) 양 끝 포화, 최대 0.25
tanh (−1,1) 1−tanh²(z) 양 끝 포화, 중심 1
ReLU [0,∞) 음수 0, 양수 1 z=0 미분 경계
Leaky ReLU 음수·양수 가능 음수 α, 양수 1 α 설정, z=0 경계
Softmax 확률 Vector, 합 1 pᵢ(δᵢⱼ−pⱼ) Vector·축·상호작용

Sigmoid·tanh의 열린 구간은 유한 실수의 정확한 범위입니다. ReLU·Leaky ReLU의 경계 미분은 일반적인 미분과 구현 규약을 구분합니다. Leaky ReLU 표는 0<α<1, Softmax의 성분 범위는 K≥2 기준입니다.

Shape은 같아도 계산은 다릅니다

앞의 다섯 원소별 함수는 (B,H)의 각 위치를 독립적으로 변환하여 (B,H)를 유지합니다. Softmax는 (B,K)를 유지하되, 같은 행의 K개 값을 함께 사용합니다. [C]

import numpy as np


def step_function(x):
    return np.where(x > 0, 1, 0)


def sigmoid(x):
    return 1 / (1 + np.exp(-x))


def tanh(x):
    return np.tanh(x)


def relu(x):
    return np.maximum(0, x)


def leaky_relu(x, alpha=0.01):
    return np.where(x > 0, x, alpha * x)


def softmax(x):
    # 원본: x를 벡터로 다루며 최대값을 빼줍니다.
    exp_x = np.exp(x - np.max(x))
    return exp_x / np.sum(exp_x, axis=0)

18 · SUPPLEMENTARY NUMPY CODE

함수 출력과 행별 Softmax를 검증합니다

Step 1·2의 보완 코드 · 함수 선택과 배열 연산 [F]

원본과 별도로 실행하는 보완 예제입니다. Sigmoid는 큰 지수 계산을 피하는 형태, Softmax는 (Sample,Class)의 행별 정규화로 작성했습니다. Label·Loss·Optimizer·Weight Update는 없습니다. 

import numpy as np
from numpy.typing import ArrayLike, NDArray

FloatArray = NDArray[np.float64]


def finite_array(values: ArrayLike) -> FloatArray:
    z = np.asarray(values, dtype=np.float64)
    if z.size == 0 or not np.isfinite(z).all():
        raise ValueError("비어 있지 않은 유한한 숫자 배열이 필요합니다.")
    return z


def sigmoid_stable(values: ArrayLike) -> FloatArray:
    z = finite_array(values)
    # exp에 큰 양수가 들어가지 않는 동등한 형태입니다.
    with np.errstate(under="ignore"):
        e = np.exp(-np.abs(z))
    return np.where(z >= 0, 1.0 / (1.0 + e), e / (1.0 + e))


def softmax_rows(values: ArrayLike) -> FloatArray:
    z = finite_array(values)
    if z.ndim != 2:
        raise ValueError("(Sample 수, Class 수)의 2차원 배열이 필요합니다.")
    with np.errstate(over="raise", invalid="raise", under="ignore"):
        shifted = z - np.max(z, axis=1, keepdims=True)
        e = np.exp(shifted)
        p = e / np.sum(e, axis=1, keepdims=True)
    return p


# 아래 값은 설명용 입력입니다. 학습 결과가 아닙니다.
z = finite_array([-2, -1, 0, 1, 2])
outputs = {
    "Step": np.where(z > 0, 1, 0),
    "Sigmoid": sigmoid_stable(z),
    "tanh": np.tanh(z),
    "ReLU": np.maximum(0.0, z),
    "Leaky ReLU (0.01)": np.where(z > 0, z, 0.01 * z),
    "Leaky ReLU (0.1)": np.where(z > 0, z, 0.1 * z),
}

np.set_printoptions(precision=6, suppress=True)
for name, values in outputs.items():
    print(f"{name}: {values}")

# 각 행은 다른 Sample의 Class Score입니다.
logits = np.array([[2.0, 1.0, 0.0], [0.0, 1.0, 2.0]])
p = softmax_rows(logits)

print("Softmax:\n", p, sep="")
print("Row sums:", p.sum(axis=1))
print("Class:", np.argmax(p, axis=1))

# 원본처럼 400개 값을 한 Vector로 정규화하는 경우
with np.errstate(under="ignore"):
    grid = np.linspace(-10, 10, 400)
    e_grid = np.exp(grid - np.max(grid))
    p_grid = e_grid / np.sum(e_grid, axis=0)

print("Grid includes exact zero:", bool(np.any(grid == 0)))
print(f"Original-vector last probability: {p_grid[-1]:.6f}")

assert outputs["Step"][2] == 0
assert np.isclose(outputs["Sigmoid"][2], 0.5)
assert np.isclose(outputs["tanh"][2], 0.0)
assert np.allclose(p.sum(axis=1), 1.0)
assert np.allclose(p, softmax_rows(logits + 1000.0))
assert np.isfinite(sigmoid_stable([-1000.0, 1000.0])).all()
assert np.allclose(softmax_rows([[2.0], [-2.0]]), 1.0)

NumPy가 설치된 Python 환경에서 실행합니다. 잘못된 Shape·빈 값·NaN·무한대를 검사합니다. 표현 범위를 벗어난 Softmax 계산은 알리도록 설정하며, 이 안정화가 모든 비정상 입력을 유효한 모델 출력으로 바꾼다는 뜻은 아닙니다.

교안 A의 설명과 Step 1·2 보완의 구분 [A]

Step 1·2의 개념 복습
착각 올바른 해석
활성화는 모두 0·1을 고른다 함수별 출력 범위와 원소별·Vector 계산이 다릅니다.
Step의 입력 0은 항상 1이다 이번 원본 > 0에서는 0입니다.
tanh는 −1 또는 1만 출력한다 사이의 연속적인 값이며 임계치 판단은 별도입니다.
0 중심 함수면 모든 Batch 평균도 0이다 함수 중심과 데이터 분포의 평균은 다릅니다.
ReLU 출력 0이면 Dying ReLU다 한 입력의 비활성과 지속적인 비활성을 구분합니다.
ReLU 미분은 0~1 사이 모든 값이다 경계 밖에서는 0 또는 1입니다.
음수 Leaky ReLU 출력은 항상 0.01이다 음수 입력에 α를 곱합니다.
Leaky α와 Learning Rate가 같다 활성화 기울기와 Optimizer Update 크기 설정은 다릅니다.
함수 이름이 같으면 기본값도 같다 교안 정의·호출 인수·함수 API·Layer API를 각각 봅니다.
Softmax(z₁)는 z₁만으로 정해진다 같은 Vector의 다른 Score도 필요합니다.
Softmax는 최종 Class 이름을 반환한다 확률 생성·argmax·Label Mapping을 구분합니다.
Sigmoid 여러 개면 Softmax와 같다 독립 변환과 합 1인 공동 정규화는 다릅니다.
확률이 높으면 반드시 정답이다 실제 Label과 비교하는 평가가 필요합니다.
Hidden 값이 크면 항상 더 중요하다 다음 Weight와 다른 경로의 조합도 봐야 합니다.
Activation을 바꿔도 같은 Weight면 같은 모델이다 계산하는 함수와 중간 출력이 달라집니다.
출력이 선형이면 Hidden에도 활성화가 없다 출력층과 Hidden Layer의 역할을 나눕니다.

교안의 표현을 보완해서 읽는 범위

왼쪽은 교안의 설명, 오른쪽은 Step 1·2의 보완 구분
교안의 설명 취지 보완해서 구분할 부분
Sigmoid·tanh의 미분값이 0이 됨 0에 가까워지는 수학적 성질과 컴퓨터의 끝값 표시를 구분합니다.
ReLU가 기울기 소실을 해결 양수 구간의 로컬 미분 1은 장점이지만 모든 문제의 보장은 아닙니다.
tanh의 기울기 소실 증상이 적음 모든 입력에서 Sigmoid보다 미분이 크다는 뜻은 아닙니다.
이미지 ReLU·시퀀스 tanh 교안의 대표 연결이며 모든 모델의 절대 규칙은 아닙니다.
회귀 출력층에 활성화 없음 기본 회귀 출력 설계이며 Hidden 활성화까지 없다는 뜻은 아닙니다.
ReLU·Leaky ReLU 성능 차이가 대부분 없음 해당 절에 모든 경우를 일반화할 비교 실험 조건은 제시되지 않습니다.
exp 연산 때문에 느리고 ReLU는 빠름 연산 특성의 비교로 읽고 전체 모델의 학습 시간을 함수 하나로 단정하지 않습니다.
활성화 출력이 클수록 더 기여 다음 계산 Σⱼhⱼwⱼ+b에서 wⱼ가 0이면 해당 곱도 0, 음수면 기여 방향도 달라질 수 있습니다.

교안 원문을 숨기거나 다른 주장으로 교체하지 않고, 본문 설명과 수학적·실험적 범위를 나누어 유지합니다.

01. Step 경계가 예상과 다름

예외 없는 논리 차이

>와 >=를 확인하고 정확한 0을 입력합니다. 그래프의 표본에 0이 없을 수 있습니다.

02. overflow encountered in exp

지수 계산 범위

Sigmoid의 −x나 Softmax의 Score가 큰 양수인지 확인합니다. 수치 안정화와 입력 Scale·Weight 발산 원인 점검은 별개입니다.

03. Softmax의 NaN·inf

입력·분모·축 확인

입력에 이미 비정상값이 있는지, exp가 Overflow되었는지, 분모와 정규화 축이 맞는지 확인합니다.

04. Softmax가 언제나 1

(B,1)의 Class 축 확인

행에 원소가 하나면 exp(z)/exp(z)=1입니다. Dense(1, activation="softmax")를 Sigmoid 이진 확률과 혼동하지 않습니다.

05. 행별 확률 합이 1이 아님

axis와 Vector 단위

(B,K)에서는 Class 축을 확인합니다. 원본의 1차원 axis=0은 자체가 잘못된 것이 아니라 다른 데이터 구조입니다.

06. 작은 음수 결과가 사라짐

dtype·저장 위치

Leaky 결과를 정수형으로 변환하거나 정수 배열에 저장하면 실수 부분을 잃을 수 있습니다. 실수 활성화와 최종 Class 정수 변환을 구분합니다.

07. ReLU 출력 0이 많음

한 입력인지 지속 상태인지

ReLU 전 Z, 후 A, 여러 Batch의 같은 Node, 학습 Gradient를 함께 확인합니다. 0의 존재만으로 오류라고 하지 않습니다.

08. Loss 설정이 맞지 않음

확률 vs Logits / Label 형식

출력과 from_logits, 정수 Label·One-hot 기대 형식을 확인합니다. 확률을 Logits라고 잘못 선언하거나 Softmax를 중복 적용하지 않습니다.

09. Leaky 그래프와 결과 불일치

α를 네 곳에서 확인

교안 기본값·실제 호출 인수·Library 기본값· 함수와 Layer API를 확인하고 의도한 값을 명시합니다.

Z의 범위·dtype → Activation과 설정 → 출력 범위·Shape → Softmax 축·합 → Loss 연결 → Gradient 순서로 확인합니다.

예외를 발생시키지 않는 계산 오류도 많습니다. np.isfinite(values).all(), values.dtype, values.shape를 확인하고 기대값을 작은 고정 입력으로 검증합니다.

24 · INTERVIEW POINTS

출력과 미분을 짝지어 자신의 말로 설명합니다

먼저 답을 말한 뒤 펼쳐서 비교하세요. 아래 문답은 본문의 교안 내용과 보완 해석을 복습합니다.

Q1. 활성화 함수란 무엇인가요?

가중합에 함수를 적용해 Layer의 출력을 만드는 연산입니다. 교안은 비선형성 부여와 출력 범위 조절을 강조합니다.

Q2. 비선형 활성화가 왜 필요한가요?

선형 계산만 쌓으면 하나의 선형식으로 합칠 수 있습니다. 비선형 변환이 더 복잡한 관계를 표현하게 합니다.

Q3. Step이 일반적인 역전파에 어려운 이유는 무엇인가요?

임계점에서는 불연속이고 다른 곳에서는 미분이 0이므로 작은 수정 방향을 전달하기 어렵습니다.

Q4. Sigmoid와 tanh의 핵심 차이는 무엇인가요?

Sigmoid는 0~1, tanh는 −1~1 사이의 연속값입니다. 중심 출력은 0.5와 0이며 둘 다 양 끝에서 포화됩니다.

Q5. Sigmoid의 최대 미분값은 얼마인가요?

σ(z)(1−σ(z))이며 z=0에서 최대 0.25입니다.

Q6. tanh가 항상 더 큰 Gradient를 전달하나요?

아닙니다. 중심의 미분은 더 크지만 모든 입력에서 그렇지는 않으며 tanh도 포화 구간에서는 작아집니다.

Q7. Step과 ReLU는 무엇이 다른가요?

Step은 양수를 1로 바꾸고 ReLU는 크기를 유지합니다. ReLU는 양수 구간에서 기울기 1입니다.

Q8. ReLU의 출력 0은 Dying ReLU인가요?

한 Sample의 0만으로 판단하지 않고 관련 입력 전반에서 계속 비활성인지 확인합니다.

Q9. Leaky ReLU는 무엇을 보완하나요?

음수 구간에도 작은 기울기를 남겨 ReLU의 로컬 Gradient 차단 문제를 완화하려는 함수입니다.

Q10. Leaky α와 Learning Rate는 어떻게 다른가요?

음수 구간의 함수 기울기와 Parameter Update 크기를 정하는 설정으로 역할이 다릅니다.

Q11. Softmax가 Vector 함수인 이유는 무엇인가요?

한 확률을 계산할 때 다른 Class의 Score도 공유 분모에 들어가기 때문입니다.

Q12. Sigmoid 여러 개와 Softmax는 어떻게 다른가요?

Sigmoid는 각 Score를 독립적으로 변환하고 Softmax는 같은 Vector를 합 1의 분포로 만듭니다.

Q13. Softmax의 미분은 왜 하나의 숫자가 아닌가요?

각 확률이 모든 입력 Score에 의존하므로 편미분을 모은 Jacobian으로 표현합니다.

Q14. 원본 Softmax 그래프에서 주의할 점은 무엇인가요?

400개 값을 Sample별로 분류한 것이 아니라 한 Vector로 정규화했습니다. Softmax(10)의 고정 함수값처럼 외우지 않습니다.

Q15. Activation 출력이 크면 최종 예측에 더 중요한가요?

출력 크기만으로 확정할 수 없습니다. 다음 Weight와 다른 경로의 조합을 함께 봅니다.

Q16. Activation·Loss·Optimizer의 차이는 무엇인가요?

값의 변환, 실제값과의 차이 평가, Gradient를 이용한 Parameter Update를 각각 담당합니다.

Q17. Leaky ReLU 교안값과 API 기본값을 어떻게 관리하나요?

교안 정의 0.01, 그래프 호출 0.1, 설치 Library의 함수·Layer 기본값을 분리하고 의도한 기울기를 명시합니다.

Q18. Sigmoid가 포화되니 이진 출력에 쓸 수 없나요?

로컬 미분만으로 결론 내리지 않습니다. 기본 Sigmoid+BCE의 Logits 미분은 p−y로 정리되며 Loss와 함께 해석합니다.
