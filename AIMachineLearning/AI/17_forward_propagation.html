01 · CORE CONCEPT

현재 Parameter로 출력값을 계산합니다

교안 기준 · A §6-2 [A]

교안은 입력과 가중치의 곱을 합산하고 활성화 함수를 통과시키는 연산을 출력층까지 수행하는 과정을 순전파라고 설명합니다. 학습을 정리할 때는 예측값과 실제값의 손실 계산까지 연결합니다.

모델 출력 계산

Ŷ = F(X; θ)

입력 X와 현재 Parameter θ로 답을 만듭니다. θ는 Weight·Bias 전체를 묶은 표기입니다.

실제값과 손실 계산

L = ℒ(Y, Ŷ)

만들어진 답을 실제값 Y와 비교합니다. 이 기본 지도학습의 모델 출력 계산에는 Y가 직접 들어가지 않습니다.

교안의 범위를 유지하면서 계산 단계를 나눕니다

교안은 “순전파에서 예측과 손실을 계산한다”는 학습 흐름으로 설명합니다. 여기서는 그 안의 모델 계산과 Loss 계산을 구분합니다. 이후 Gradient 계산과 Parameter Update는 별도로 연결합니다.

예측값을 만들었다는 사실과 모델이 학습되었다는 사실은 다릅니다.

02 · WHY FORWARD?

구조도에 실제 숫자를 넣는 단계입니다

  1. 16. 인공신경망 어떤 Layer가 연결되어 있는가?
  2. 17. 순전파 그 Layer에서 값이 어떻게 바뀌는가?
  3. 18. 역전파 각 계산이 Loss에 어떤 영향을 주는가?

현재 모델이 어떤 답을 내는지 계산해야 틀린 정도도 확인할 수 있습니다. 순전파는 학습이 끝난 뒤에만 사용하는 과정이 아니라 학습 중에도 반복해서 사용합니다. [A]

Weight를 적용한다

x=3, w=0.5 → wx=1.5

곱셈 결과가 생겼지만 w는 여전히 0.5입니다.

Weight를 학습한다

Loss에 대한 Gradient와 Update 규칙을 이용해 Parameter를 수정합니다. 순전파만 실행했다고 일어나는 변화가 아닙니다.

보완 비유

현재 설비 설정이 Parameter, 원재료가 입력, 가공 공정이 Layer 계산, 완성품이 예측값, 품질 검사가 Loss입니다. 제품을 만들고 검사한 뒤 설비 설정을 조정하는 단계가 별도로 필요합니다.

03 · VALUES & SYMBOLS

Z·H·예측값·실제값을 서로 다른 값으로 읽습니다

교안의 계산 흐름을 읽기 위한 보완 표기 정리

값의 이름보다 현재 계산에서의 역할을 확인합니다
기호 의미 확인할 점
X 입력 데이터 Sample 수와 Feature 수를 구분
W / b Weight Matrix / Bias Vector 현재 계산의 Parameter
Z 활성화 전 가중합 중간값인지 최종 Score인지 확인
H / A 활성화 후 값 Hidden에서는 중간 표현
P 분류의 확률 출력 선택한 Class와 구분
Ŷ 예측값 회귀값·확률 등 문맥에 맞게 해석
Y 실제값·Label 예측을 평가하는 비교 기준
L Loss 차이를 수치화한 값, Update 자체가 아님
θ Parameter 전체 모든 W와 b를 묶어 나타내는 기호

Hidden의 0은 Class 0이 아닙니다

Z=-0.4 → ReLU → H=0은 내부 계산 결과입니다. 최종 출력층에서 Class를 결정했다는 뜻이 아닙니다.

Parameter와 Hyperparameter도 다릅니다. W·b는 학습값이며, Learning Rate·Batch Size 같은 설정은 학습 방식을 정합니다. 이번 고정 순전파 예제에는 Learning Rate나 Optimizer가 필요하지 않습니다.

04 · NEURON → LAYER → NETWORK

한 번의 가중합을 여러 뉴런과 여러 Layer로 확장합니다

교안 A의 가중합·활성화, 교안 B의 순전파 코드 [A] [B]

뉴런 하나 z = w₁x₁+w₂x₂+w₃x₃+b → h=f(z)

Layer 전체 Z=XW+b → H=f(Z)

두 Layer Ŷ = g(f(XW₁+b₁)W₂+b₂)

Weight를 입력마다 곱한 뒤 합산하고 Bias를 더한 후 Activation을 적용합니다. Bias를 생략하면 일반적으로 원래 모델과 다른 함수를 계산합니다.

보완 표기 · Sample은 행, Feature는 열

X=(B,D), W=(D,H)이면 XW=(B,H)입니다. B는 Batch의 Sample 수, D는 입력 Feature 수, H는 여기서 출력 뉴런 수입니다.

교안의 Wx+b와 이 페이지의 XW+b는 벡터 방향에 따른 표기 차이입니다. 행렬곱 순서를 임의로 바꾸지 않습니다. Hidden 행렬 H₁과 차원 기호 H도 문맥으로 구분합니다.

보완 수식 · Layer가 더 많다면?

A⁽⁰⁾=X로 두고 각 Layer를 Z⁽ℓ⁾=A⁽ℓ−1⁾W⁽ℓ⁾+b⁽ℓ⁾, A⁽ℓ⁾=f⁽ℓ⁾(Z⁽ℓ⁾)로 반복합니다.

위첨자 (ℓ)는 거듭제곱이 아니라 Layer 번호입니다. 신경망은 이전 함수의 결과가 다음 함수의 입력이 되는 합성 함수로 읽을 수 있습니다.

05 · READ THE TWO PATHS

입력은 모델을 통과하고, Label은 비교 지점으로 들어갑니다

교안의 흐름을 계산 역할별로 나눈 보완 도식

Layer 1에서 H₁은 Output이지만 Layer 2에서는 Input입니다. 입력과 출력이라는 말을 전체 모델 기준인지, 개별 Layer 기준인지 구분합니다.

값은 계산·변환되며 이동합니다. 현재 Parameter는 각 단계에서 사용하는 기준입니다.

06 · ACTIVATION & ORDER

활성화는 모두 0과 1을 고르는 연산이 아닙니다

교안의 활성화 개념 + 공식 함수 동작 확인 [A] [C]

값의 범위와 사용 위치를 함께 확인합니다
함수 계산 읽는 방법
ReLU max(0,z) 원소별로 음수는 0, 양수는 그대로
Sigmoid 1 / (1+e⁻ᶻ) 각 Score를 0~1 사이 값으로 변환
Softmax exp(zₖ) / Σⱼexp(zⱼ) 지정된 축의 Score들을 합이 1인 분포로 변환
Linear / Identity g(z)=z 출력층의 가중합을 그대로 반환

교안의 Dense 흐름

H=ReLU(XW+b)

가중합과 Bias를 반영한 뒤 활성화합니다.

순서를 바꾼 다른 계산

H=ReLU(X)W+b

입력을 먼저 변환하므로 일반적으로 같은 결과가 아닙니다.

H=XW₁+b₁, Y=HW₂+b₂ → Y=X(W₁W₂)+(b₁W₂+b₂)

위 식은 비선형 활성화를 빼면 여러 선형 계산이 하나로 합쳐진다는 보완 전개입니다. Hidden Layer 수만 아니라 어떤 활성화를 어디에 적용했는지 확인합니다.

출력층이 선형이어도 앞 Hidden에 비선형 Activation이 있으면 전체 모델은 비선형일 수 있습니다. Hidden을 매번 Threshold로 0·1로 바꾸는 것은 이번 MLP 구조가 아닙니다.

07 · TRACE ONE SAMPLE

앞 단원의 3 → 2 → 1을 계산 순서대로 추적합니다

보완 예제 · 설명용 고정값 · Hidden ReLU + 선형 출력 · 학습 결과가 아닙니다 

X  = [[1, 2, 3]]
W₁ = [[ 0.2, -0.1],
      [ 0.5,  0.2],
      [-0.2, -0.3]]
b₁ = [0.1, 0.2]
W₂ = [[0.4], [-0.6]]
b₂ = [0.1]

Hidden Node 1

1×0.2 + 2×0.5 + 3×(-0.2) + 0.1

= 0.7

Hidden Node 2

1×(-0.1) + 2×0.2 + 3×(-0.3) + 0.2

= -0.4

  1. 가중합 Z₁ [0.7,-0.4]
  2. ReLU 출력 H₁ [0.7,0]
  3. 출력 가중합 Z₂ 0.7×0.4+0×(-0.6)+0.1
  4. 선형 예측값 Ŷ = 0.38

어느 값이 변했고 어느 값은 그대로인가?

X에서 중간값과 최종 출력이 계산되었습니다. 이 과정에서 지정한 W₁·b₁·W₂·b₂는 수정하지 않았습니다.

08 · BATCH & SHAPE

같은 Parameter를 두 Sample에 각각 적용합니다

손계산 보완 예제에 Sample [0,1,1] 추가

두 번째 Sample의 Hidden 가중합은 0×0.2+1×0.5+1×(-0.2)+0.1=0.4 , 0×(-0.1)+1×0.2+1×(-0.3)+0.2=0.1 입니다.

두 값 모두 ReLU 이후 유지됩니다. 출력은 0.4×0.4+0.1×(-0.6)+0.1=0.20입니다.

각 입력 행에 대응하는 예측값
입력 Z₁ H₁ Ŷ
[1,2,3] [0.7,-0.4] [0.7,0] 0.38
[0,1,1] [0.4,0.1] [0.4,0.1] 0.20
Batch 2개, 입력 3개, Hidden 2개, 출력 1개
값 Shape 역할
X (2,3) 두 Sample의 입력
W₁ / b₁ (3,2) / (2,) Hidden Parameter
Z₁ / H₁ (2,2) Sample별 Hidden 값
W₂ / b₂ (2,1) / (1,) Output Parameter
Z₂ / Ŷ (2,1) Sample별 출력 하나
(2,3) @ (3,2) → (2,2) @ (2,1) → (2,1)

여기서는 Sample들을 섞어 예측 하나를 만드는 것이 아닙니다. 같은 Bias Vector를 각 행에 더하는 데 Broadcasting을 사용합니다. [D]

원소별 곱과 행렬곱

X * W는 원소별 곱, X @ W는 행렬곱입니다. 뉴런 하나에서 sum(x*w)로 내적을 구한 예제와 Batch·여러 뉴런을 함께 계산하는 X@W를 구분합니다.

교안 구조와 손계산 모델을 하나로 섞지 않습니다

12 · FORWARD PASS ≠ EPOCH

한 Epoch 안에 여러 Batch의 순전파가 들어갈 수 있습니다

보완 가정 · Sample 120개, Batch Size 32, 마지막 작은 Batch 사용, 일반적인 Batch별 Update

  1. Batch 132개
  2. Batch 232개
  3. Batch 332개
  4. Batch 424개

이 가정에서는 한 Epoch에 네 번의 학습 Batch 순전파가 들어갑니다. 각 Batch에서 순전파 → Loss → 역전파 → Update를 수행합니다. 사용자 정의 Loop·Gradient 누적·마지막 Batch 제외 설정에는 같은 횟수를 강제하지 않습니다. [E]

교안의 구분 기준은 한 Update에 사용하는 데이터의 양입니다 [A]
방식 기본적으로 한 Update에 사용하는 데이터
BGD 전체 학습 데이터
SGD Sample 하나
Mini-batch 여러 Sample로 이루어진 일부 Batch

순전파는 한 입력 묶음의 계산이고, Epoch는 데이터 전체를 한 차례 사용하는 단위입니다.

13 · NUMPY FORWARD TRACE

Label 없이 계산하고 Parameter가 그대로인지 확인합니다

독립 실행 가능한 보완 예제 · 위 손계산과 동일한 고정값 · 원본 학습 코드 아님

입력·Weight·Bias의 Shape과 유한값을 검사합니다. 이 보완 함수는 Bias를 1차원으로 받도록 제한하며, 다른 Bias 표현까지 자동 변환하는 일반 라이브러리는 아닙니다. 

import numpy as np
from numpy.typing import ArrayLike, NDArray

FloatArray = NDArray[np.float64]


def forward(
    x: ArrayLike,
    w1: ArrayLike,
    b1: ArrayLike,
    w2: ArrayLike,
    b2: ArrayLike,
) -> dict[str, FloatArray]:
    """보완 예제: Hidden ReLU + 선형 출력. 학습은 하지 않습니다."""
    x, w1, b1, w2, b2 = [
        np.asarray(value, dtype=np.float64)
        for value in (x, w1, b1, w2, b2)
    ]

    if any(a.ndim != 2 for a in (x, w1, w2)):
        raise ValueError("입력과 Weight는 2차원 배열이어야 합니다.")
    if any(a.size == 0 for a in (x, w1, b1, w2, b2)):
        raise ValueError("빈 입력 또는 빈 Parameter는 사용할 수 없습니다.")
    if x.shape[1] != w1.shape[0]:
        raise ValueError("입력 Feature 수와 W1의 입력 차원이 다릅니다.")
    if w1.shape[1] != w2.shape[0]:
        raise ValueError("Hidden 출력 차원과 W2의 입력 차원이 다릅니다.")
    if b1.shape != (w1.shape[1],) or b2.shape != (w2.shape[1],):
        raise ValueError("각 Bias는 해당 출력 차원 길이의 1차원 배열이어야 합니다.")
    if not all(np.isfinite(a).all() for a in (x, w1, b1, w2, b2)):
        raise ValueError("입력 또는 Parameter에 NaN·무한대가 있습니다.")

    # 새 계산값을 만듭니다. 입력 Parameter를 수정하지 않습니다.
    with np.errstate(over="raise", invalid="raise"):
        z1 = x @ w1 + b1
        h1 = np.maximum(z1, 0.0)
        z2 = h1 @ w2 + b2

    if not all(np.isfinite(a).all() for a in (z1, h1, z2)):
        raise FloatingPointError("계산 결과에 NaN·무한대가 발생했습니다.")

    return {
        "Z1": z1,
        "H1": h1,
        "Z2": z2,
        "y_hat": z2.copy(),
    }


# 설명용 고정값입니다. 교안에서 학습된 Parameter가 아닙니다.
x = np.array([
    [1.0, 2.0, 3.0],
    [0.0, 1.0, 1.0],
])
w1 = np.array([
    [0.2, -0.1],
    [0.5,  0.2],
    [-0.2, -0.3],
])
b1 = np.array([0.1, 0.2])
w2 = np.array([[0.4], [-0.6]])
b2 = np.array([0.1])

parameters = (w1, b1, w2, b2)
before = [p.copy() for p in parameters]
trace = forward(x, *parameters)

np.set_printoptions(precision=2, suppress=True)
for name, value in trace.items():
    print(f"{name} shape={value.shape}")
    print(value)

unchanged = all(
    np.array_equal(old, current)
    for old, current in zip(before, parameters)
)
print("Parameter unchanged:", unchanged)

# 부동소수점 결과는 근사 비교합니다.
assert unchanged
assert np.allclose(trace["Z1"], [[0.7, -0.4], [0.4, 0.1]])
assert np.allclose(trace["H1"], [[0.7, 0.0], [0.4, 0.1]])
assert np.allclose(trace["y_hat"], [[0.38], [0.20]])

@는 행렬곱, Bias 덧셈은 Broadcasting, np.maximum(z1,0)은 ReLU입니다. 출력값 복사는 반환 결과를 구분하기 위한 보완 처리입니다. [D]

16 · SOFTMAX & AXIS

각 Sample의 Class Score를 함께 정규화합니다

별도 가상 Logits [2,1,0]의 보완 계산 · 공식 함수 의미 [C]

pₖ = exp(zₖ) / Σⱼexp(zⱼ)

[2,1,0] → [0.665241, 0.244728, 0.090031]

Class 순서가 [0,1,2]라면 가장 큰 값의 위치인 Class 0을 선택합니다. 이 Logits는 위 회귀 모델이나 교안 붓꽃 모델에서 나온 실제 출력이 아닙니다.

최댓값을 빼도 같은 분포가 되는 이유

exp(zₖ-m)/Σⱼexp(zⱼ-m)에서 공통 배율 exp(-m)이 약분됩니다. m을 행별 최댓값으로 두면 [2,1,0]은 [0,-1,-2]가 됩니다. 큰 양수의 exp 계산을 피하는 수치 안정화이며, 입력 오류나 Weight 발산을 치료하는 것은 아닙니다. 

import numpy as np
from numpy.typing import ArrayLike, NDArray


def softmax_rows(logits: ArrayLike) -> NDArray[np.float64]:
    """보완 예제: (Sample 수, Class 수)에 행별 Softmax를 적용합니다."""
    z = np.asarray(logits, dtype=np.float64)
    if z.ndim != 2 or z.size == 0:
        raise ValueError("비어 있지 않은 2차원 Logits가 필요합니다.")
    if not np.isfinite(z).all():
        raise ValueError("Logits에 NaN·무한대가 있습니다.")

    # 큰 양수의 exp 계산을 피합니다. 표현 범위를 벗어난 계산은 알립니다.
    with np.errstate(over="raise", invalid="raise", under="ignore"):
        shifted = z - np.max(z, axis=1, keepdims=True)
        exp_values = np.exp(shifted)
        probabilities = exp_values / np.sum(
            exp_values, axis=1, keepdims=True
        )

    return probabilities


# 별도의 가상 Class Score입니다. 위 회귀 예제의 출력이 아닙니다.
probabilities = softmax_rows([[2.0, 1.0, 0.0]])
np.set_printoptions(precision=6, suppress=True)
print(probabilities)
print("Class:", np.argmax(probabilities, axis=1))
print("Row sum:", probabilities.sum(axis=1))

assert np.allclose(probabilities.sum(axis=1), 1.0)

보완 코드의 실행 결과

[[0.665241 0.244728 0.090031]]
Class: [0]
Row sum: [1.]

(B,K)에서 axis=1은 같은 Sample의 Class끼리 계산한다는 뜻입니다. axis=0은 다른 Sample들을 같은 열에서 묶으므로 여기서는 의도와 다릅니다. 행별 확률 합이 약 1인지 확인합니다.

17 · PREDICTION → LOSS

손실 계산은 실제값과 비교하는 단계입니다

교안의 MSE·Cross Entropy 구분 [A] · 아래 숫자는 가정한 Label의 보완 예제

회귀 · Sample 하나

첫 Sample의 예측값 ŷ=0.38, 실제값을 y=1.00으로 가정합니다.

L=(1.00-0.38)²=0.3844

두 Sample 전체의 평균이 아니라, 이 Sample 하나의 제곱오차입니다.

다중 분류 · Sample 하나

앞 Softmax 예제의 실제 정답을 Class 0으로 가정합니다.

L=-ln(p₀)≈0.407606

자연로그와 반올림 전 확률로 계산한 보완 값입니다.

서로 다른 문제·손실 함수의 숫자 크기만 비교해 어느 모델이 좋다고 판단하지 않습니다. Loss를 계산했다고 Parameter가 수정된 것도 아닙니다.

MSE와 Cross Entropy의 역할

MSE는 교안의 회귀 예측 오차를, Cross Entropy는 분류 출력과 정답의 차이를 측정하는 기본 예입니다. Activation이 값을 만드는 방법이라면 Loss는 만들어진 값을 평가하는 기준입니다.

보완·API 확인 · Label Shape와 from_logits

단일 출력 예측 (N,1)과 Label (N,)을 NumPy로 직접 빼면 (N,N)으로 확장될 수 있습니다. 반면 다중 분류의 정수 Label (B,)와 예측 (B,K)은 Sparse Loss의 정상 형식일 수 있습니다.

Softmax 확률 입력인지, Softmax 전 Logits 입력인지에 맞춰 from_logits를 설정합니다. “항상 Shape을 같게 한다”보다 Loss의 기대 형식을 확인하는 것이 정확합니다. [F]

18 · TRAINING / INFERENCE MODE

고정 Dense 예제의 성질을 모든 Layer로 확대하지 않습니다

Step 1·2의 공식 문서 보완 영역 · 이후 성능 개선 단원과 연결 [G]

아래는 일반적인 설정 기준이며 Layer 설정도 함께 확인합니다
Layer 학습 모드 일반적인 추론 모드
이번 고정 Dense·ReLU 예제 같은 입력·Parameter에 같은 수학적 계산을 적용
Dropout 일부 값을 무작위로 제외 일반적으로 비활성화
Batch Normalization 현재 Batch 통계 사용, 이동 통계 갱신 저장된 이동 통계 사용

Dropout 때문에 같은 입력의 순방향 결과가 달라질 수 있습니다. Batch Normalization의 이동 평균·분산 갱신은 Optimizer가 학습 가능한 Weight를 수정하는 Update와 구분되는 상태 변화입니다.

순전파의 목적은 출력 계산입니다. 학습 가능한 Weight의 최적화와 일부 Layer의 모드·상태 변화를 구분합니다.

“순전파에서는 모든 상태가 절대 변하지 않는다” 대신, 이번 예제의 범위와 사용 중인 Layer를 명시합니다.

19 · COMMON MISTAKES

계산·해석·학습을 같은 일로 취급하지 않습니다

Step 1·2의 복습 · 교안 기준과 앞서 표시한 보완 설명

오해를 오른쪽 문장으로 바로잡아 봅니다
자주 하는 착각 올바른 해석
순전파가 Weight를 더 좋은 값으로 바꾼다. 현재 Parameter를 사용하며 Gradient·Update와 구분합니다.
순전파만 반복하면 자동으로 학습된다. Parameter를 수정하지 않으면 이번 고정 함수는 그대로입니다.
예측할 때 실제 Label을 먼저 넣어야 한다. 이 기본 모델의 출력 계산에는 불필요하며 Loss·평가에서 비교합니다.
입력을 그대로 다음 Layer에 전달한다. 가중합·활성화로 다른 값을 만들어 전달합니다.
Z와 H는 같은 값이다. Activation 전 가중합과 후의 출력을 구분합니다.
모든 Activation은 0·1을 고른다. ReLU·Sigmoid·Softmax·Linear의 계산과 출력이 다릅니다.
Hidden 값 0은 Class 0이다. 중간 계산 결과와 최종 Class 선택은 다릅니다.
X * W와 X @ W는 같다. 원소별 곱과 행렬곱을 구분합니다.
Bias를 빼도 같은 모델이다. 일반적으로 다른 함수를 계산합니다.
Activation의 위치를 바꿔도 된다. f(XW+b)와 f(X)W+b는 일반적으로 다릅니다.
출력 Activation이 없으면 아무 계산도 없다. 출력층의 HW+b는 계산합니다.
Softmax를 Batch 전체에 한 번 적용한다. 각 Sample의 Class 축을 확인합니다.
Shape만 맞으면 입력도 올바르다. Feature 의미·순서·전처리도 일치해야 합니다.
높은 확률은 정답을 보장한다. 실제 Label과 비교하는 평가가 필요합니다.
Loss를 구했으면 Update도 끝났다. Gradient 계산과 Parameter 수정은 별도입니다.
순전파 한 번이 Epoch 한 번이다. 한 Epoch 안에 여러 Batch 계산이 들어갈 수 있습니다.
어떤 모델도 순전파 중 상태가 바뀌지 않는다. Dropout·Batch Normalization 등의 모드와 설정을 구분합니다.

매번 Weight를 초기화하는지, 중간 학습 Update가 있었는지, Dropout·상태 있는 Layer가 학습 모드인지 확인합니다. [G]

보완 손계산 · Broadcasting이 조용히 잘못되는 경우 
y_pred = [[0.38], [0.20]]  # (2,1)
y_true = [1.0, 0.0]       # (2,)

직접 뺄셈 결과 (2,2):
[[-0.62, 0.38],
 [-0.80, 0.20]]

Sample별로 원한 차이 (2,1):
[[-0.62],
 [ 0.20]]

이 단일 출력 예제에서 의도가 확인되었다면 Label을 reshape(-1,1)로 맞춥니다. 모든 분류 Loss에 같은 변경을 적용하지는 않습니다. [D] [F]

입력 의미 → Shape·dtype·유한값 → W₁·b₁ → Z₁ → H₁ → W₂·b₂ → Z₂ → 출력 축·선택 규칙 → Label·Loss

22 · INTERVIEW POINTS

계산·해석·학습의 차이를 자신의 말로 설명합니다

먼저 답을 말하고 펼쳐서 비교하세요. 답변은 앞 카드의 교안 내용과 보완 설명을 복습합니다.

Q1. 순전파란 무엇인가요?

입력에서 출력 방향으로 현재 모델의 계산을 수행해 예측값을 만듭니다. 교안의 학습 설명에서는 실제값과의 손실 계산까지 연결합니다.

Q2. 순전파가 Weight를 학습시키나요?

현재 Weight를 사용합니다. 학습하려면 Loss에 대한 Gradient 계산과 Parameter Update가 추가로 필요합니다.

Q3. “가중치 계산”은 어떤 뜻인가요?

입력에 현재 Weight를 곱해 가중합을 계산한다는 뜻입니다. 최적의 Weight를 찾는 것과 구분합니다.

Q4. Z와 H는 무엇이 다른가요?

Z는 가중합, H는 Activation을 적용한 값입니다. Hidden Layer의 H는 중간 표현입니다.

Q5. 앞 Layer의 Output은 다음 Layer에서 무엇인가요?

다음 Layer의 Input입니다. 입력·출력을 전체 모델 기준인지 현재 Layer 기준인지 구분합니다.

Q6. 예측하려면 실제 Label이 필요한가요?

이 기본 모델의 출력 계산에는 필요하지 않습니다. 예측과 비교해 Loss·성능을 계산할 때 사용합니다.

Q7. 출력 활성화가 없으면 출력층도 생략되나요?

아닙니다. 출력층의 HW+b를 계산하고 그 결과를 그대로 반환합니다.

Q8. Hidden ReLU 출력 0은 Class 0인가요?

아닙니다. 내부 뉴런의 계산값이 0이라는 뜻이며 최종 Class 선택과 다릅니다.

Q9. 순전파 한 번과 Epoch 한 번은 무엇이 다른가요?

순전파는 한 입력 묶음의 계산, Epoch는 정해진 학습 데이터 전체를 한 차례 사용하는 단위입니다. 한 Epoch에 여러 Batch 계산이 들어갈 수 있습니다.

Q10. X * W와 X @ W는 무엇이 다른가요?

원소별 곱과 행렬곱입니다. Batch와 여러 뉴런을 함께 처리하는 Dense에서는 행렬곱의 연결 차원을 맞춥니다.

Q11. Softmax는 어느 축에 적용하나요?

(Batch, Class)라면 같은 Sample의 Class Score들을 함께 계산하는 Class 축입니다.

Q12. 높은 확률이면 정답인가요?

확률 추정값과 실제 정답 여부는 다릅니다. 동일 Sample의 실제 Label과 비교해야 합니다.

Q13. 원본 fit과 predict는 무엇이 다른가요?

둘 다 순전파를 사용합니다. fit은 학습 계산과 Update를 포함하고 predict는 Threshold로 Class를 반환합니다.

Q14. 순전파에서 아무 상태도 변하지 않나요?

Weight의 Gradient 기반 최적화와 구분해야 합니다. Batch Normalization은 학습 모드에서 이동 통계를 갱신할 수 있고 Dropout은 무작위성을 추가합니다.

Q15. 왜 중간값을 확인하나요?

처음 잘못된 계산 위치를 찾는 데 유용하고, 이후 역전파의 미분 계산에도 연결됩니다.

Q16. 다음 역전파 단원에서 무엇을 배우나요?

Loss에 대해 W₁·b₁·W₂·b₂가 미친 영향을 Gradient로 구하는 과정을 공부합니다.

24 · NEXT: BACKPROPAGATION

이제 Loss가 각 Parameter에 미친 영향을 계산합니다

이번에는 값을 계산했습니다. 다음 질문은 “W₁·b₁·W₂·b₂를 각각 어떻게 바꿔야 Loss가 줄어드는가?” 입니다. [A]

  1. 순전파 Prediction과 필요한 Loss 계산
  2. 역전파 Parameter별 Gradient 계산
  3. Optimizer Update Gradient로 Parameter 수정
  4. 다음 순전파 바뀐 Parameter로 다시 계산

중간값은 다음 계산에도 연결됩니다

예를 들어 h=σ(z)이면 dh/dz=h(1-h)입니다. 순전파에서 구한 h가 미분식에 등장합니다. 자동 미분 도구도 순방향 연산을 기록하고 Gradient 계산에 사용합니다. [H]

순전파는 “어떤 값이 계산되었는가?”, 역전파는 “그 계산이 Loss에 어떤 영향을 주었는가?”를 묻습니다.
