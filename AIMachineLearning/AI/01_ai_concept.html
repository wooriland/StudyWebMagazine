Concept Foundation

인공지능이란? AI라는 가장 큰 개념의 범위부터 정확하게 잡습니다

01 · CORE CONCEPT

Artificial Intelligence는 하나의 모델명이 아니라 가장 큰 기술 영역입니다

08 · COMMON MISTAKES

처음 AI를 공부할 때 가장 많이 헷갈리는 부분

01

Weak AI를 “성능이 낮은 AI”라고 이해한다

Weak 또는 Narrow는 주로 지능의 적용 범위가 제한되어 있음을 의미합니다. 특정 Task에서는 매우 높은 성능을 낼 수도 있습니다.

02

AI와 Machine Learning을 같은 말로 사용한다

AI가 더 큰 범위이며, Machine Learning은 데이터를 이용해 AI를 구현하는 접근 방법 중 하나입니다.

03

AI와 Deep Learning을 같은 개념으로 생각한다

Deep Learning은 Machine Learning 안에서 인공신경망을 이용하는 영역입니다.

04

Strong AI와 AGI를 완전히 독립된 순차 단계처럼 외운다

이번 교안에서는 Strong AI와 AGI를 매우 가까운 범용 지능의 개념으로 연결합니다.

05

특정 Benchmark에서 인간보다 잘하면 AGI라고 생각한다

특정 Task의 높은 성능과 여러 분야를 아우르는 범용 지능은 다른 개념입니다.

06

ASI를 지금 선택해서 사용할 수 있는 AI 모델 종류라고 생각한다

ASI는 현재 실습할 모델명이 아니라 인간 지능을 초월하는 미래적·가설적 개념입니다.

07

Weak/Strong과 Rule/Learning을 같은 분류 축으로 섞는다

하나는 지능의 범위, 다른 하나는 구현 방법을 설명합니다.

09 · CONCEPT ERROR

이번 단원에서는 Runtime Error보다 잘못된 문장을 읽는 연습이 중요합니다

아직 Python이나 TensorFlow를 실행하는 단원이 아니므로 실제 오류 메시지 대신 AI 개념을 잘못 해석한 문장을 찾아 수정합니다.

WRONG 01
“정확도가 99%니까 이 모델은 AGI다.”
왜 틀렸는가?

특정 Task의 정확도와 범용 지능 수준은 다른 개념입니다.

다시 질문
  • 어떤 Task의 정확도인가?
  • 다른 문제에도 지식을 적용할 수 있는가?
  • 새로운 문제에 범용적으로 적응하는가?
WRONG 02
“Machine Learning이 아니면 AI가 아니다.”
왜 틀렸는가?

AI는 더 큰 범위이며 Rule-Based 접근도 존재합니다.

수정된 구조 AI > Learning-Based > Machine Learning
WRONG 03
“Weak AI니까 Strong AI보다 정확도가 낮다.”
왜 틀렸는가?

Weak와 Strong은 단순 정확도 순위가 아닙니다.

핵심 구분 성능 점수 ≠ 지능의 적용 범위
WRONG 04
“ASI는 Parameter가 엄청 많은 LLM이다.”
왜 틀렸는가?

ASI는 모델 크기만을 의미하지 않고 인간의 지적 능력을 광범위하게 초월하는 미래적 초지능 개념입니다.

수정 ASI = capability concept

11 · INTERVIEW POINT

인공지능의 가장 기본적인 질문을 자신의 말로 설명해 봅니다

Q1. 인공지능이란 무엇인가요?

인간의 인지·추론·판단과 같은 지능적인 문제 해결 능력을 컴퓨터 시스템에서 수행하도록 만드는 기술의 큰 영역이라고 설명할 수 있습니다.

Q2. AI와 Machine Learning은 같은 개념인가요?

아닙니다. AI가 더 큰 범위이며, Machine Learning은 데이터에서 규칙과 패턴을 학습하여 AI를 구현하는 방법 중 하나입니다.

Q3. Weak AI란 무엇인가요?

특정 Task 또는 특정 문제 해결에 특화된 AI입니다. 범용 지능이 아니라 정해진 문제 범위 안에서 동작한다는 점이 핵심입니다.

Q4. Weak AI라는 말은 성능이 낮다는 뜻인가요?

아닙니다. 특정 Task에서는 매우 높은 성능을 낼 수 있습니다. Weak 또는 Narrow라는 표현은 주로 지능의 적용 범위가 제한되어 있음을 의미합니다.

Q5. Strong AI란 무엇인가요?

사람처럼 여러 종류의 문제를 이해하고 새로운 상황에도 적응할 수 있는 인간 수준의 범용 지능을 목표로 하는 개념입니다.

Q6. AGI란 무엇인가요?

Artificial General Intelligence의 약자로, 여러 분야에서 지식을 활용하고 새로운 문제에 적응하며 범용적으로 문제를 해결할 수 있는 지능을 목표로 하는 개념입니다.

Q7. Strong AI와 AGI의 관계는 무엇인가요?

이번 교안에서는 Strong AI와 AGI를 매우 가깝게 연결합니다. Strong AI가 인간 수준의 범용 지능이라는 큰 방향이라면, AGI는 그 범용성을 보다 구체적으로 표현하는 대표적인 개념으로 이해할 수 있습니다.

Q8. ASI란 무엇인가요?

Artificial Superintelligence의 약자로, 인간의 지적 능력을 광범위하게 크게 초월하는 미래적 초지능 개념입니다.

Q9. AGI와 ASI의 차이는 무엇인가요?

AGI가 인간 수준의 범용 지능을 목표로 한다면, ASI는 인간의 지적 능력을 전반적으로 크게 넘어서는 방향의 개념입니다.

Q10. AI는 반드시 Machine Learning을 사용해야 하나요?

아닙니다. 교안에서는 AI를 Rule-Based와 Learning-Based 접근으로 구분합니다. Machine Learning은 Learning-Based 접근에 연결됩니다.

Q11. 특정 분야에서 인간보다 잘하면 AGI인가요?

아닙니다. 특정 Task에서의 높은 성능과 여러 영역에서 지식을 활용하는 범용 지능은 서로 다른 개념입니다.
