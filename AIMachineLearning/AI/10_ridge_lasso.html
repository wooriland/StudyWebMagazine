Ridge와 Lasso는 “Error도 줄이고 Weight도 지나치게 키우지 말라”는 조건을 추가한 Linear Regression입니다

CORE QUESTION
Training Data의 MSE를 가장 작게 만드는 Model이 언제나 새로운 Data에서도 가장 좋은 Model일까?

+

필요 이상으로 큰 Weight에 비용을 부과합니다.

=
BALANCE Better Generalization

Regularization을 한국어로 읽으면

07 · L1 REGULARIZATION · LASSO

Lasso는 Weight 절대값에 Penalty를 주고 일부 Weight를 0까지 만들 수 있습니다

LASSO COST Cost = MSE + λ × Σ|Wⱼ|

L1 Penalty 계산 예

W [3, -2, 0.5]
↓ absolute
|W| [3, 2, 0.5]
↓ sum
Σ|W| 5.5

Lasso의 Weight 변화 직관

BEFORE
W₁ = 5.0 W₂ = 0.8 W₃ = 0.03 W₄ = -0.01
→ L1 →
POSSIBLE RESULT
W₁ = 4.4 W₂ = 0.5 W₃ = 0 W₄ = 0
위 숫자는 L1의 동작을 이해하기 위한 보완 예시이며 교안 저장 Weight를 그대로 사용한 값은 아닙니다.
FEATURE x₃
×
WEIGHT W₃ = 0
=
CONTRIBUTION 0
→
EFFECT Feature 영향 제거
Lasso 핵심

Lasso → L1 → 일부 Weight를 0까지 만들 수 있음 → Feature Selection 효과 가능

보완 이해 · SPARSE MODEL [4.3, 0, 0, -1.7, 0, 0, 0.2]

많은 Parameter가 0인 형태를 Sparse하다고 표현할 수 있습니다. Lasso는 이러한 희소한 Weight 구조를 만들 수 있습니다.

08 · L2 REGULARIZATION · RIDGE

Ridge는 Weight 제곱에 Penalty를 주어 큰 Weight를 강하게 억제합니다

RIDGE COST Cost = MSE + λ × ΣWⱼ²
교안 표현 + 보완 이해

교안에서는 Ridge를 L2 Penalty라고 부르고 실제 Cost 식을 ΣW² 형태로 제시합니다. 수학적으로는 Squared L2 Norm, 즉 ||W||₂²에 해당한다고 이해하면 됩니다.

L2 Penalty 계산 예

W [3, -2, 0.5]
↓ square
W² [9, 4, 0.25]
↓ sum
ΣW² 13.25

큰 Weight에 강한 Penalty

W 1 → 1² = 1
W 10 → 10² = 100
W 100 → 100² = 10,000
BEFORE [5.0, 0.8, 0.03, -0.01]
→ L2 →
CONCEPTUAL RESULT [4.4, 0.6, 0.02, -0.008]
Ridge 핵심

Ridge → L2 → 큰 Weight를 억제 → Weight 전반적 Shrinkage → Feature는 대체로 유지

보완 예제 · 통합 교안 검토 메모 반영

다음 코드는 원본 Notebook을 그대로 재현한 코드가 아니라 검토 메모의 Data Leakage 지적을 반영한 권장 재실습 구조입니다. 

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression, Lasso, Ridge
from sklearn.metrics import r2_score

# 1. Train / Test 먼저 분리
X_train, X_test, y_train, y_test = train_test_split(
    X_df,
    y_df,
    train_size=0.8,
    random_state=42
)

# 2. Scaler는 Training Data에만 fit
scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(
    X_train
)

X_test_scaled = scaler.transform(
    X_test
)

# 3. Model 생성
model_lr = LinearRegression()

model_lasso = Lasso(
    alpha=0.1
)

model_ridge = Ridge()

# 4. 동일한 Training/Test 조건에서 비교
models = [
    model_lr,
    model_lasso,
    model_ridge
]

for model in models:

    model.fit(
        X_train_scaled,
        y_train.values.ravel()
    )

    y_pred = model.predict(
        X_test_scaled
    )

    print(
        model.__class__.__name__,
        r2_score(
            y_test,
            y_pred
        )
    )

20 · LIMITS & COMPLEMENTS

Regularization도 강도와 상황을 잘못 선택하면 Model 성능을 오히려 제한할 수 있습니다

LIMIT 01

너무 약한 규제

Linear Regression과 거의 차이가 없어 Overfitting을 충분히 억제하지 못할 수 있습니다.

→ alpha 조정
LIMIT 02 · 보완 이해

너무 강한 규제

중요한 Weight까지 지나치게 줄이면 실제 Pattern을 표현하지 못할 수 있습니다.

→ Underfitting 가능
LIMIT 03

Lasso의 불필요한 단정

Lasso를 사용한다고 해서 반드시 Feature가 제거되는 것은 아닙니다.

→ zero coefficient 확인
LIMIT 04

Score 하나만 비교

R²만으로 Complexity와 실제 Error 특성을 모두 설명할 수 없습니다.

→ 여러 평가 관점 사용
LIMIT 05

Scale 영향

Feature Scale이 크게 다르면 Weight Penalty 해석이 영향을 받을 수 있습니다.

→ Scaling 검토
LIMIT 06

Leakage 위험

좋은 전처리 기법도 Test Data 정보를 미리 사용하면 평가 신뢰도가 깨집니다.

→ Split 먼저

Ridge/Lasso는 고전 Machine Learning의 한 단원으로 끝나지 않고, 이후 Deep Learning에서 Model Complexity와 Overfitting을 제어하는 사고방식의 기초가 됩니다.

22 · COMMON MISTAKES

Ridge와 Lasso에서 가장 많이 헷갈리는 것은 “무엇을 바꾸는 기술인가?”입니다

01

Regularization은 Data 정규화다

아닙니다. Regularization은 Weight에 Penalty를 주고, Standardization은 Feature Scale을 변환합니다.

02

Ridge와 Lasso는 Prediction 식이 완전히 다르다

기본 Prediction은 여전히 ŷ = XW + b입니다. 학습 Cost가 달라집니다.

03

L1은 Weight를 제곱한다

L1은 Weight 절대값의 합을 사용합니다.

04

L2는 Weight 절대값의 합이다

교안의 Ridge Penalty는 Weight 제곱의 합 ΣW²입니다.

05

Lasso는 항상 Feature를 제거한다

일부 Weight를 0으로 만들 수 있다는 뜻입니다. 교안 저장 실행에서는 12개 Weight가 모두 non-zero였습니다.

06

Ridge는 Weight를 무조건 0으로 만든다

Ridge는 Weight를 전반적으로 축소하되 일반적으로 Lasso처럼 0을 만드는 방식으로 설명하지 않습니다.

07

alpha가 클수록 무조건 좋다

규제를 지나치게 강하게 하면 중요한 관계까지 억제할 수 있습니다.

08

Regularization을 쓰면 R²가 반드시 크게 오른다

실제 교안 결과에서도 Linear, Lasso, Ridge의 R²가 거의 같습니다.

09

이번 결과에서 Ridge가 1등이므로 항상 Ridge가 최고다

한 Dataset, 한 Split, 한 Hyperparameter 설정의 결과일 뿐입니다.

10

Weight가 작으면 무조건 좋은 Model이다

목표는 Weight를 작게 만드는 자체가 아니라 Prediction과 Complexity의 균형입니다.

11

Feature가 많을수록 항상 좋다

불필요한 Feature와 Noise까지 추가되면 Overfitting 위험이 커질 수 있습니다.

12

Scaler를 전체 Data에 fit해도 된다

Test Data의 통계가 Training 과정에 들어가 Data Leakage가 발생할 수 있습니다.

13

Data Leakage와 Overfitting은 같은 말이다

Leakage는 평가 정보가 학습에 유입되는 문제이고, Overfitting은 Training Data에 지나치게 적합하는 문제입니다.

14

Training Score가 가장 높은 Model이 최종 Model이다

새로운 Data에 대한 Generalization을 Validation/Test 성능으로 확인해야 합니다.

23 · ERROR & TRAINING STATE

이번 단원은 특정 Exception보다 Model 상태와 Pipeline 오류를 읽는 능력이 중요합니다

STATE 01

Train ↑↑ / Test ↓

Overfitting 의심

Regularization과 Model Complexity를 확인합니다.

STATE 02 · 보완

Train ↓ / Test ↓

Underfitting 가능

alpha가 지나치게 강하지 않은지 확인합니다.

STATE 03

Lasso Weight 대부분 0

[3.2, 0, 0, 0, 0, ...] 규제 강도 확인

alpha, Scaling, Feature 관계를 점검합니다.

STATE 04

Lasso zero Weight 없음

[non-zero, non-zero, ...] 오류가 아님

실제 교안 실행도 이 상태입니다.

STATE 05

Test Score가 비정상적으로 좋아 보임

Leakage 확인

Split 전에 Scaler나 Feature Selector를 fit하지 않았는지 점검합니다.

STATE 06

Model 간 R² 차이가 거의 없음

정상일 수 있음

Regularization이 항상 큰 Score 차이를 만드는 것은 아닙니다.

Ridge/Lasso를 점검할 때
Train Score → Test Score → Train-Test Gap → alpha → Feature Scale → Weight → Leakage

실무에서는 Score 하나가 아니라 성능·복잡도·Weight·Pipeline을 함께 봅니다

01

02

Scaling

Weight Penalty 비교를 위해 Feature Scale을 확인합니다.

03

여러 alpha 후보를 Validation 성능으로 비교합니다.

04

R²뿐 아니라 MSE, MAE 등 Error 크기도 봅니다.

05

큰 Weight가 어디에 있는지, Lasso에서 0이 생겼는지 확인합니다.

06

07

Test 정보가 Training Pipeline에 들어가지 않았는지 확인합니다.

08

Model과 Hyperparameter 선택이 끝난 후 Test Data로 최종 평가합니다.

RIDGE를 먼저 생각할 상황 · 보완 이해 대부분 Feature가 어느 정도 필요하다

Feature를 유지하면서 Weight를 안정적으로 축소하고 싶은 경우 후보가 될 수 있습니다. 최종 선택은 Validation으로 확인합니다.

LASSO를 먼저 생각할 상황 · 보완 이해 일부 Feature는 제거될 수 있다

Feature Selection 효과와 Sparse한 Model이 유용한 문제에서 후보가 될 수 있습니다. 최종 선택은 Validation으로 확인합니다.

25 · INTERVIEW POINT

“Overfitting → Penalty → L1/L2 → Generalization” 순서로 설명합니다

Q1. Overfitting이란 무엇인가요?

Training Data에는 매우 잘 맞지만 새로운 Validation/Test Data에서는 성능이 떨어지는 상태입니다. Training Data의 일반적인 Pattern뿐 아니라 Noise까지 과도하게 학습한 경우 발생할 수 있습니다.

Q2. Generalization이란 무엇인가요?

Training에 사용하지 않은 새로운 Data에서도 Model이 안정적으로 좋은 Prediction을 하는 능력입니다.

Q3. Regularization이란 무엇인가요?

기존 Loss에 Weight의 크기에 대한 Penalty를 추가하여 Parameter가 지나치게 커지는 것을 억제하고 Model Complexity와 Overfitting을 제어하는 방법입니다.

Q4. L1 Regularization이란 무엇인가요?

Weight 절대값의 합 Σ|W|을 Penalty로 사용하는 방식입니다.

Q5. L2 Regularization이란 무엇인가요?

Ridge에서 Weight 제곱의 합 ΣW²을 Penalty로 사용하는 방식입니다.

Q6. Lasso란 무엇인가요?

L1 Regularization을 적용한 Linear Regression으로, 일부 Weight를 정확히 0으로 만들 수 있어 Feature Selection 효과가 나타날 수 있습니다.

Q7. Ridge란 무엇인가요?

L2 Regularization을 적용한 Linear Regression으로, 큰 Weight에 Penalty를 주고 Weight 전체를 부드럽게 축소하는 방식입니다.

Q8. Lasso와 Ridge의 가장 큰 차이는 무엇인가요?

Lasso는 일부 Weight를 0까지 만들 수 있지만, Ridge는 일반적으로 Feature를 유지하면서 Weight의 크기를 줄이는 방향으로 동작합니다.

Q9. alpha 또는 lambda는 무엇인가요?

Regularization Strength를 결정하는 Hyperparameter입니다. 값이 커질수록 Penalty의 영향도 커집니다.

Q10. Regularization은 강할수록 좋은가요?

아닙니다. 너무 약하면 Overfitting 억제 효과가 부족하고, 지나치게 강하면 중요한 Pattern까지 억제해 Underfitting이 발생할 수 있습니다. 후반 내용은 Regularization을 이해하기 위한 보완 설명입니다.

Q11. Regularization과 Standardization은 무엇이 다른가요?

Regularization은 Weight에 Penalty를 주는 학습 방법이고, Standardization은 Feature 값을 비슷한 Scale로 변환하는 Data 전처리입니다.

Q12. Ridge/Lasso에서 Scaling이 왜 중요한가요?

Regularization은 Weight 크기를 기준으로 Penalty를 부과하기 때문에 Feature Scale 차이로 필요한 Weight Scale이 크게 달라지면 규제의 영향도 달라질 수 있기 때문입니다.

Q13. Data Leakage란 무엇인가요?

Training에 사용하면 안 되는 Validation/Test Data의 정보가 전처리나 Feature Selection 등을 통해 Training 과정에 들어오는 문제입니다.

Q14. Lasso를 사용하면 반드시 Weight가 0이 되나요?

아닙니다. Weight를 0으로 만들 수 있다는 뜻입니다. 교안의 실제 Lasso(alpha=0.1) 저장 결과에서는 12개 Weight가 모두 non-zero였습니다.

Q15. Regularization을 사용하면 Score가 반드시 좋아지나요?

아닙니다. 목적은 무조건 Score를 높이는 것이 아니라 Model Complexity를 제어하고 새로운 Data에 대한 Generalization을 개선하는 것입니다.

Q16. Ridge와 Lasso도 Prediction 식이 다른가요?

기본 Prediction 구조는 여전히 ŷ = XW + b입니다. 달라지는 핵심은 Parameter를 학습할 때 최소화하는 Cost Function입니다.
