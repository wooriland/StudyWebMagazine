28. RNN · LSTM · Attention · Transformer

이미지가 아니라 순서가 있는 데이터를 AI는 어떻게 이해할까? 이 단원에서는 이전 정보를 기억하는 RNN에서 시작하여, 오래된 정보를 더 잘 유지하는 LSTM, Sequence를 다른 Sequence로 변환하는 Seq2Seq, 필요한 정보에 집중하는 Attention, 그리고 순환 구조를 제거하고 Self-Attention으로 전체 문맥 관계를 직접 학습하는 Transformer까지의 발전 과정을 연결해서 이해한다.

FFNN → RNN → LSTM → Seq2Seq → Attention → Transformer → LLM

학습 목표

  • RNN이 왜 등장했는지 FFNN의 한계와 연결해서 설명할 수 있다.
  • Sequence, Time Step, Hidden State, Parameter Sharing의 의미를 설명할 수 있다.
  • RNN 입력이 왜 (batch, time_steps, features) 형태인지 이해한다.
  • 자연어가 Tokenization → Integer Encoding → Padding → Embedding 과정을 거쳐 신경망에 입력되는 이유를 설명할 수 있다.
  • RNN의 장기 의존성 문제와 LSTM의 Cell State 및 Gate 구조가 어떻게 연결되는지 이해한다.
  • Seq2Seq의 Encoder / Decoder 구조와 Context Vector의 역할을 설명할 수 있다.
  • Attention이 왜 필요하고 Attention Score → Softmax → Weighted Sum이 무엇을 의미하는지 이해한다.
  • Transformer의 Query / Key / Value, Self-Attention, Multi-Head Attention, Positional Encoding, Masking을 연결해서 설명할 수 있다.

그림처럼 이해

RNN과 Transformer를 사람의 대화로 비유하기

RNN

앞사람이 다음 사람에게 메모를 전달한다.

사람 1 → 사람 2 → 사람 3 → 사람 4

사람 4는 사람 1의 말을 직접 듣는 것이 아니라 중간 사람들을 거쳐 전달된 기억을 받는다.

LSTM

전달받은 메모를 관리한다.

Forget → 필요 없는 내용 삭제 Input → 새로운 중요한 내용 기록 Output → 지금 필요한 내용 전달

Attention

지금 필요한 사람에게 직접 집중한다.

사람 1 사람 2 사람 3 ★ 사람 4

현재 질문과 관련된 정보에 더 높은 중요도를 부여한다.

Transformer

모두가 같은 회의실에서 서로를 동시에 참고한다.

A B C D

Token 하나가 다른 Token 전체와의 관계를 직접 계산할 수 있다.

RNN

Recurrent Neural Network

RNN은 현재 입력만 보는 것이 아니라 이전 Time Step의 Hidden State를 현재 계산에 다시 사용하는 신경망이다.

RNN의 핵심 식

Ht = tanh( XtWx + Ht-1Wh + b )

Xt

현재 Time Step의 입력

Ht-1

이전 Time Step의 Hidden State

Wx

현재 입력에 적용되는 Weight

Wh

이전 Hidden State에 적용되는 Weight

b

Bias

Ht

현재까지 문맥이 반영된 새로운 상태

나는 H1
→
오늘 H2
→
학교에 H3
→
간다 H4
중요: Hidden State는 문장을 문자열 그대로 저장하는 메모리가 아니다. 앞에서 처리한 시퀀스 정보가 반영된 숫자 벡터 형태의 내부 상태다.

LSTM의 핵심

LSTM은 Hidden State뿐 아니라 Cell State라는 장기 정보 전달 경로를 추가한다.

Hidden State · H

현재 Time Step의 출력이자 다음 Time Step 계산에 사용되는 상태

Cell State · C

오래 유지해야 할 정보를 다음 Time Step으로 전달하는 기억 경로

LSTM의 Gate

Forget Gate

무엇을 버릴까?

이전 Cell State에서 필요하지 않은 정보를 감소시킨다.

Input Gate

무엇을 새로 기억할까?

현재 입력에서 새로운 중요한 정보를 Cell State에 추가한다.

Output Gate

무엇을 출력할까?

현재 Cell State 중 현재 출력에 반영할 정보를 선택한다.

Ct-1 → Forget → Input → Ct → Output → Ht

Self-Attention

Query · Key · Value

Transformer는 Token Embedding을 그대로 비교하지 않고 서로 다른 학습 가능한 Weight Matrix를 사용하여 Q, K, V Vector를 만든다.

Q = XWQ K = XWK V = XWV
Q

Query

내가 지금 어떤 정보를 찾고 있는가?

K

Key

내가 찾는 정보와 얼마나 관련 있는가?

V

Value

최종적으로 전달할 실제 정보

14

핵심 수식

Scaled Dot-Product Attention

Attention(Q, K, V) = Softmax( QKT / √dk )V

1

QKᵀ

Query와 Key의 관련성 계산

2

÷ √dk

Score 크기 조정

3

Softmax

중요도 Weight 생성

4

× V

Value의 Weighted Sum

왜 √dk로 나누는가?

Query와 Key의 차원이 커질수록 내적값이 지나치게 커질 수 있다. 큰 값이 그대로 Softmax에 들어가면 일부 확률만 1에 가까워지고 나머지는 거의 0에 가까워져 학습이 불안정해질 수 있다.

따라서 √dk로 나누어 Score의 크기를 안정화한다.

Multi-Head Attention

하나의 관계만 보지 않는다

Input Embedding
Head 1 Head 2 Head 3 Head 4 ...
↓
Concat
↓
Linear Projection

각 Head는 서로 다른 Q/K/V Weight를 사용하여 서로 다른 표현 공간에서 Token 관계를 학습한다.

주의: Head 1은 반드시 문법, Head 2는 반드시 주어-동사 관계를 학습한다고 고정해서 해석하면 안 된다. 중요한 것은 여러 관계 표현을 병렬로 학습할 수 있다는 점이다.

Masking

AI가 정답을 미리 보지 못하게 한다

나는 ✓ 오늘 ✓ 학교에 ✕ 간다 ✕

Decoder가 현재 `"오늘"`까지 처리하고 있다면 미래 정답인 `"학교에"`, `"간다"`를 미리 보면 안 된다.

초보자가 많이 헷갈리는 부분

착각 1

✕ RNN은 텍스트 전용 알고리즘이다.

✓ RNN의 본질은 순서가 있는 Sequence Data를 처리하는 것이다.

착각 2

✕ Hidden State는 문장을 문자열로 기억한다.

✓ Hidden State는 문맥이 반영된 숫자 벡터다.

착각 3

✕ Token ID와 Embedding Vector는 같다.

✓ Token ID는 Vocabulary의 식별 번호이고, Embedding은 학습 가능한 Dense Vector다.

착각 4

✕ LSTM은 모든 정보를 계속 기억한다.

✓ LSTM은 어떤 정보를 버리고, 추가하고, 출력할지 학습한다.

착각 5

✕ Cell State와 Hidden State는 같은 것이다.

✓ Cell State는 장기 기억 경로, Hidden State는 현재 출력에 가까운 상태다.

착각 6

✕ Seq2Seq와 Attention은 같은 모델이다.

✓ Seq2Seq는 Encoder-Decoder 구조이고, Attention은 정보 병목을 보완하는 메커니즘이다.

착각 7

✕ Attention Weight는 일반 Weight Parameter다.

✓ Attention Weight는 입력마다 달라지는 관련성 기반 중요도 값이다.

착각 8

✕ Q, K, V는 원래 데이터에 존재한다.

✓ 입력 X에 서로 다른 Weight Matrix를 적용해 Q, K, V를 생성한다.

착각 9

✕ Transformer에는 순서 정보가 필요 없다.

✓ 병렬 처리하기 때문에 오히려 Positional Information을 별도로 제공해야 한다.

오류 메시지 읽는 법

RNN과 Transformer에서 Shape부터 확인하자

오류 1. RNN 입력 Dimension 오류

ValueError:
expected ndim=3,
found ndim=2
Expected (batch, time_steps, features)
Received (batch, features)

RNN은 Time Step 축이 필요하다. 입력 Tensor가 2차원이 아니라 3차원인지 확인한다.

오류 2. Stacked LSTM 연결 오류

layers.LSTM(64),
layers.LSTM(32)

첫 번째 LSTM이 마지막 Hidden State만 반환하면 두 번째 LSTM이 필요로 하는 Sequence 입력이 사라진다.

해결: return_sequences=True

오류 3. Embedding Index 범위 오류

indices[...] = 10001
is not in [0, 10000)

Token ID가 Embedding의 input_dim 범위를 벗어났다는 뜻이다.

Vocabulary Size, OOV Token, Padding Index, Embedding input_dim을 함께 확인한다.

오류 4. Mask 누락

Mask 문제는 반드시 Exception으로 나타나지 않을 수도 있다.

코드는 실행됨 → Padding까지 Attention → 학습 품질 저하

Transformer에서는 Padding Mask와 Look-Ahead Mask가 어느 Attention Layer에 들어가야 하는지 반드시 확인한다.

오류를 읽는 순서

  1. 오류 클래스 확인
  2. 어떤 Layer에서 발생했는지 확인
  3. Expected Shape 확인
  4. Received Shape 확인
  5. batch / time_step / feature 축 확인
  6. 이전 Layer의 output_shape 확인

면접 포인트

질문으로 다시 확인하기

Q1. RNN이 무엇인가요?

RNN은 순서가 있는 Sequence Data를 처리하기 위한 순환 신경망입니다. 현재 입력뿐 아니라 이전 Time Step의 Hidden State를 현재 계산에 함께 사용하여 과거 문맥을 반영합니다.

Q2. FFNN과 RNN의 가장 큰 차이는 무엇인가요?

FFNN은 입력에서 출력으로 정보가 순방향으로만 흐르지만, RNN은 이전 Time Step의 Hidden State를 다음 Time Step으로 전달합니다.

Q3. Hidden State란 무엇인가요?

현재 Time Step까지 입력된 Sequence의 문맥 정보를 압축해서 담고 있는 상태 벡터입니다.

Q4. RNN의 대표적인 한계는 무엇인가요?

긴 Sequence에서 먼 과거의 정보를 효과적으로 유지하기 어려운 장기 의존성 문제와 학습 과정의 기울기 소실 문제가 대표적입니다.

Q5. LSTM은 RNN의 문제를 어떻게 보완하나요?

Hidden State 외에 Cell State를 사용하고, Forget / Input / Output Gate를 통해 어떤 정보를 버리고, 추가하고, 출력할지 학습합니다.

Q6. Cell State와 Hidden State의 차이는 무엇인가요?

Cell State는 장기간 정보를 전달하는 내부 기억 경로이고, Hidden State는 현재 Time Step의 출력이자 다음 Time Step 계산에 전달되는 상태입니다.

Q7. Bidirectional LSTM이란 무엇인가요?

Sequence를 앞→뒤와 뒤→앞 두 방향에서 처리하여 현재 위치의 앞뒤 문맥을 모두 사용하는 LSTM 구조입니다.

Q8. return_sequences=True는 언제 사용하나요?

마지막 Hidden State 하나가 아니라 모든 Time Step의 출력 Sequence를 다음 Layer에 전달해야 할 때 사용합니다. Stacked LSTM의 중간 Layer가 대표적입니다.

Q9. Seq2Seq란 무엇인가요?

Encoder가 입력 Sequence를 내부 표현으로 변환하고 Decoder가 이를 사용해 새로운 출력 Sequence를 생성하는 Encoder-Decoder 모델입니다.

Q10. 초기 Seq2Seq의 한계는 무엇인가요?

긴 입력 Sequence 전체의 정보를 고정된 크기의 Context Vector 하나에 압축하기 때문에 정보 손실이 발생할 수 있다는 점입니다.

Q11. Attention의 목적은 무엇인가요?

출력 시점마다 입력 Sequence 중 현재 예측에 중요한 부분에 더 높은 가중치를 주어 선택적으로 참고하도록 만드는 것입니다.

Q12. Self-Attention이란 무엇인가요?

하나의 Sequence 안에서 각 Token이 같은 Sequence의 다른 모든 Token과의 관계를 계산하는 Attention입니다.

Q13. Query, Key, Value란 무엇인가요?

입력 표현에 서로 다른 학습 가능한 Weight Matrix를 적용해 만든 Vector입니다. Query와 Key로 관련도를 계산하고, 계산된 Attention Weight를 Value에 적용합니다.

Q14. Transformer와 RNN의 가장 큰 차이는 무엇인가요?

RNN은 이전 Hidden State를 순차적으로 전달하지만, Transformer는 순환 구조를 제거하고 Self-Attention을 이용하여 Token 간 관계를 직접 계산합니다.

Q15. Positional Encoding이 왜 필요한가요?

Transformer는 Token을 순차적으로 처리하지 않기 때문에 Token의 순서 정보를 별도로 제공해야 합니다.

Q16. Multi-Head Attention을 사용하는 이유는 무엇인가요?

여러 Attention Head를 병렬로 사용하여 서로 다른 표현 공간에서 다양한 Token 관계를 동시에 학습하기 위해서입니다.

Q17. Decoder Mask가 필요한 이유는 무엇인가요?

다음 Token을 예측할 때 아직 생성되지 않은 미래 정답 Token을 미리 보지 못하도록 하기 위해 사용합니다.

헷갈리기 쉬운 개념

Token ID ≠ Embedding

Token ID는 식별 번호, Embedding은 의미를 학습하는 Dense Vector다.

Hidden State ≠ Cell State

Hidden State는 현재 출력, Cell State는 장기 기억 전달 경로에 가깝다.

Seq2Seq ≠ Attention

Seq2Seq는 Encoder-Decoder 구조, Attention은 정보 선택 메커니즘이다.

Weight ≠ Attention Weight

모델 Weight는 학습되는 Parameter, Attention Weight는 입력마다 계산되는 중요도다.

Attention ≠ Self-Attention

일반 Attention은 서로 다른 표현 사이에서도 사용할 수 있고, Self-Attention은 같은 Sequence 내부 관계를 계산한다.

RNN의 순서 ≠ Transformer의 순서

RNN은 처리 순서 자체에 위치가 포함되지만 Transformer는 위치 정보를 별도로 제공해야 한다.
