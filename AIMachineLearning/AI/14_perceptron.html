10 · AND GATE

두 입력이 모두 1일 때만 활성화되는 퍼셉트론

WEIGHT W = [0.5, 0.5]
BIAS b = -0.6
FORMULA z = 0.5x₁ + 0.5x₂ - 0.6
OUTPUT [0, 0, 0, 1]
INPUT · (0,0) z = 0.5×0 + 0.5×0 - 0.6 = -0.6 z < 0 Output 0
INPUT · (1,0) z = 0.5×1 + 0.5×0 - 0.6 = -0.1 z < 0 Output 0
INPUT · (0,1) z = 0.5×0 + 0.5×1 - 0.6 = -0.1 z < 0 Output 0
INPUT · (1,1) z = 0.5×1 + 0.5×1 - 0.6 = 0.4 z ≥ 0 Output 1
AND 판단

입력 하나만 활성화되면 Score는 0.5이고, Threshold 0.6을 넘지 못합니다. 두 입력이 모두 1일 때만 Score 1.0이 되어 활성화됩니다.

11 · OR GATE

두 입력 중 하나만 1이어도 활성화되는 퍼셉트론

WEIGHT W = [0.5, 0.5]
BIAS b = -0.2
FORMULA z = 0.5x₁ + 0.5x₂ - 0.2
OUTPUT [0, 1, 1, 1]
INPUT · (0,0) z = 0.5×0 + 0.5×0 - 0.2 = -0.2 z < 0 Output 0
INPUT · (1,0) z = 0.5×1 + 0.5×0 - 0.2 = 0.3 z ≥ 0 Output 1
INPUT · (0,1) z = 0.5×0 + 0.5×1 - 0.2 = 0.3 z ≥ 0 Output 1
INPUT · (1,1) z = 0.5×1 + 0.5×1 - 0.2 = 0.8 z ≥ 0 Output 1
OR 판단

입력 하나만 활성화되어도 Weighted Sum은 0.5입니다. Threshold가 0.2이므로 입력 하나만 1이어도 활성화되어 Output 1을 반환합니다.

12 · NAND GATE

AND의 반대 출력을 만들며 다음 XOR 조합의 중간 판단으로 사용됩니다

교안 확장 내용

사용자의 핵심 학습 목록은 AND와 OR를 중심으로 하지만, 통합교안 45번 Notebook에는 NAND도 포함되어 있습니다. NAND는 다음 XOR 조합을 이해하기 위해 함께 정리합니다.

WEIGHT W = [-0.5, -0.5]
BIAS b = 0.5
FORMULA z = -0.5x₁ - 0.5x₂ + 0.5
OUTPUT [1, 1, 1, 0]
INPUT · (0,0) z = -0.5×0 - 0.5×0 + 0.5 = 0.5 z ≥ 0 Output 1
INPUT · (1,0) z = -0.5×1 - 0.5×0 + 0.5 = 0 교안 기준 z = 0 Output 1
INPUT · (0,1) z = -0.5×0 - 0.5×1 + 0.5 = 0 교안 기준 z = 0 Output 1
INPUT · (1,1) z = -0.5×1 - 0.5×1 + 0.5 = -0.5 z < 0 Output 0
NAND 판단

입력값이 증가할수록 Negative Weight 때문에 Score가 감소합니다. 두 입력이 모두 1일 때만 Score가 음수가 되어 Output 0이 됩니다.

교안 구조 재현

아래 코드는 통합교안의 Weight·Bias와 계산 순서를 유지하면서 공백과 이름을 학습용으로 정리한 예제입니다. 

import numpy as np


def and_gate(x1, x2):
    x = np.array([x1, x2])

    # 학습이 완료되었다고 가정하고
    # Weight와 Bias를 고정합니다.
    W = np.array([0.5, 0.5])
    b = -0.6

    z = np.sum(x * W) + b

    if z < 0:
        return 0

    return 1


def nand_gate(x1, x2):
    x = np.array([x1, x2])

    W = np.array([-0.5, -0.5])
    b = 0.5

    z = np.sum(x * W) + b

    if z < 0:
        return 0

    return 1


def or_gate(x1, x2):
    x = np.array([x1, x2])

    W = np.array([0.5, 0.5])
    b = -0.2

    z = np.sum(x * W) + b

    if z < 0:
        return 0

    return 1


def xor_gate(x1, x2):
    # 하나의 단층 퍼셉트론이 아니라
    # NAND와 OR의 출력을 AND에 전달합니다.
    s1 = nand_gate(x1, x2)
    s2 = or_gate(x1, x2)

    return and_gate(s1, s2)


inputs = [
    (0, 0),
    (1, 0),
    (0, 1),
    (1, 1),
]


for x1, x2 in inputs:
    print(
        x1,
        x2,
        and_gate(x1, x2),
        or_gate(x1, x2),
        nand_gate(x1, x2),
        xor_gate(x1, x2),
    )

공통 퍼셉트론 함수 · 보완 예제 

from __future__ import annotations

import numpy as np
from numpy.typing import NDArray


def step(score: float) -> int:
    """교안과 동일하게 0 이상이면 1을 반환합니다."""
    return 0 if score < 0 else 1


def perceptron_gate(
    inputs: NDArray[np.float64],
    weights: NDArray[np.float64],
    bias: float,
) -> tuple[float, int]:
    if inputs.shape != weights.shape:
        raise ValueError(
            f"Input Shape {inputs.shape}와 "
            f"Weight Shape {weights.shape}가 같아야 합니다."
        )

    score = float(
        np.dot(inputs, weights) + bias
    )

    prediction = step(score)

    return score, prediction


x = np.array(
    [1.0, 0.0],
    dtype=np.float64,
)

and_weights = np.array(
    [0.5, 0.5],
    dtype=np.float64,
)

score, prediction = perceptron_gate(
    inputs=x,
    weights=and_weights,
    bias=-0.6,
)

print(score)       # -0.1
print(prediction)  # 0

17 · STEP vs SIGMOID

Step Function

VS
LOGISTIC REGRESSION

Sigmoid

19 · COMMON MISTAKES

퍼셉트론을 공부할 때 자주 발생하는 개념적 착각

01

퍼셉트론 하나가 전체 신경망이라고 생각한다

퍼셉트론은 하나의 기본 계산 단위 또는 단층 분류 구조입니다. 신경망은 여러 뉴런과 Layer의 연결입니다.

02

Input과 Weight를 같은 값이라고 생각한다

Input은 현재 Sample의 Feature이고, Weight는 그 Feature에 적용되는 Parameter입니다.

03

Weighted Sum과 Step Function을 섞는다

WᵀX+b는 Linear Score 계산이고, Step은 그 Score를 0/1로 변환합니다.

04

Linear Score z를 Probability라고 생각한다

퍼셉트론의 z는 중간 Score입니다. Step Function은 Probability 없이 Hard Class를 반환합니다.

05

Output 1이 항상 정답이라는 뜻이라고 생각한다

1은 Positive Class Prediction입니다. 실제 정답 여부는 Label과 비교해야 알 수 있습니다.

06

Bias를 Error나 편견으로 이해한다

여기서 Bias는 활성화 기준과 Decision Boundary의 위치를 이동하는 Parameter입니다.

07

AND와 OR는 전혀 다른 Algorithm이라고 생각한다

두 Gate 모두 같은 퍼셉트론 구조를 사용하고, Parameter 값이 다릅니다.

08

교안의 Weight 숫자만 외운다

중요한 것은 특정 숫자 하나가 아니라, Weight와 Bias가 올바른 Boundary를 만드는 원리입니다.

09

Notebook이 W와 b를 학습했다고 생각한다

교안은 논리 Gate 설명을 위해 Weight와 Bias를 수동으로 고정합니다.

10

z=0의 경계 조건을 확인하지 않는다

통합교안 코드에서는 z가 0이면 Output 1입니다.

11

Step과 Sigmoid를 같은 함수라고 생각한다

Step은 0/1을 바로 출력하고, Sigmoid는 0~1 사이 Probability를 출력합니다.

12

XOR 함수가 있으므로 단층 퍼셉트론이 해결했다고 생각한다

교안의 XOR 함수는 NAND·OR·AND라는 여러 Gate를 단계적으로 연결합니다.

13

XOR는 Epoch를 늘리면 언젠가 해결된다고 생각한다

문제는 학습 시간이 아니라 Model의 표현력입니다. 하나의 선형 Boundary로는 XOR를 표현할 수 없습니다.

14

Weight가 크면 언제나 해당 Feature가 더 중요하다고 단정한다

실제 Data에서는 Feature Scale을 함께 고려해야 합니다.

22 · INTERVIEW POINT

“입력 → 가중합 → Bias → Step → Output” 순서로 설명하면 구조가 흔들리지 않습니다

Q1. 퍼셉트론이란 무엇인가요?

여러 입력에 Weight를 곱해 합산하고 Bias를 더한 뒤, Step Function을 적용하여 0 또는 1을 출력하는 선형 이진 분류 구조입니다.

Q2. 퍼셉트론의 기본 수식은 무엇인가요?

z = WᵀX+b를 계산한 뒤 ŷ = step(z)를 적용합니다.

Q3. Weight의 역할은 무엇인가요?

각 입력 Feature가 Linear Score에 기여하는 방향과 크기를 결정합니다.

Q4. Bias의 역할은 무엇인가요?

활성화 기준을 조정하고 Decision Boundary의 위치를 이동합니다.

Q5. Step Function은 무엇인가요?

임계 기준을 중심으로 입력을 0 또는 1로 변환하는 Activation Function입니다.

Q6. 통합교안에서 z=0의 Output은 무엇인가요?

코드가 z < 0이면 0, 그 외에는 1을 반환하므로 z=0은 Output 1입니다.

Q7. Decision Boundary란 무엇인가요?

Prediction Class가 바뀌는 경계이며 퍼셉트론에서는 WᵀX+b=0으로 표현합니다.

Q8. 선형 분리 가능이란 무엇인가요?

하나의 직선 또는 Hyperplane으로 두 Class를 완전히 분리할 수 있는 상태입니다.

Q9. AND Gate의 교안 Parameter는 무엇인가요?

W=[0.5,0.5], b=-0.6이며 두 입력이 모두 1일 때만 Output 1입니다.

Q10. AND와 OR의 구조적 차이는 무엇인가요?

통합교안에서는 같은 Weight를 사용하지만 Bias를 AND는 -0.6, OR는 -0.2로 설정하여 활성화 기준을 다르게 만듭니다.

Q11. 퍼셉트론은 왜 XOR를 해결하지 못하나요?

XOR의 Positive와 Negative가 대각선으로 배치되어 하나의 직선으로 완전히 분리할 수 없기 때문입니다.

Q12. 통합교안의 XOR 함수는 어떻게 동작하나요?

NAND와 OR의 출력을 중간값으로 만든 뒤, 두 결과를 AND Gate의 입력으로 전달합니다.

Q13. 교안의 XOR 함수는 단층 퍼셉트론 하나인가요?

아닙니다. NAND·OR·AND라는 여러 Gate, 즉 여러 퍼셉트론 계산을 단계적으로 연결한 구조입니다.

Q14. 통합교안의 Weight와 Bias는 학습 결과인가요?

아닙니다. 논리 Gate 동작을 설명하기 위해 수동으로 고정한 값입니다.

Q15. Step Function과 Sigmoid의 차이는 무엇인가요?

Step은 0 또는 1을 바로 출력하고, Sigmoid는 0~1 사이의 연속적인 Probability를 출력합니다.

Q16. Step Function을 깊은 신경망에서 사용하기 어려운 이유는 무엇인가요?

임계점에서 미분할 수 없고 대부분의 구간에서 미분값이 0이므로 역전파에 필요한 Gradient를 전달하기 어렵기 때문입니다.

Q17. Training과 Inference의 차이는 무엇인가요?

Training은 Data를 이용해 Weight와 Bias를 찾는 과정이고, Inference는 고정된 Parameter로 새로운 Input을 판단하는 과정입니다.

Q18. Single-Layer Perceptron과 MLP의 차이는 무엇인가요?

단층 퍼셉트론에는 Hidden Layer가 없고 하나의 선형 Boundary를 표현합니다. MLP는 Hidden Layer를 추가하여 여러 중간 판단을 조합합니다.
