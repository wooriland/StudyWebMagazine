01 · CORE IDEA

객체 탐지는 위치 회귀와 Class 분류를 함께 수행합니다

교안 기준: Localization은 회귀, Classification은 분류

입력 이미지 → CNN Backbone → Box·Score·Class 후보 → Confidence Filtering → NMS

Localization

객체의 위치와 크기를 연속 좌표로 예측합니다.

Classification

person·car·dog처럼 객체 종류를 예측합니다.

Confidence

현재 탐지를 얼마나 신뢰하는지 나타냅니다.

Post-processing

낮은 점수와 중복 Box를 제거합니다.

최종 탐지 결과의 기본 단위는 Bounding Box + Class + Confidence 입니다.

04 · BOUNDING BOX

같은 Box도 XYXY·XYWH·정규화 좌표로 다르게 표현됩니다

XYXY

[xmin, ymin, xmax, ymax]

(xmin, ymin) (xmax, ymax) Object

왼쪽 위와 오른쪽 아래 모서리를 사용합니다.

XYWH

[cx, cy, width, height]

(cx, cy) Object

중심 좌표와 Box의 너비·높이를 사용합니다.

width = xmax − xmin

height = ymax − ymin

area = width × height

Bounding Box 좌표 변환
변환 수식
XYWH → xmin cx − width / 2
XYWH → ymin cy − height / 2
XYWH → xmax cx + width / 2
XYWH → ymax cy + height / 2
XYXY → cx (xmin + xmax) / 2
XYXY → cy (ymin + ymax) / 2

좌표 기준을 함께 기록합니다

Pixel 좌표인지 정규화 좌표인지, 원본 이미지 기준인지 Resize·Letterbox된 입력 기준인지 확인해야 합니다.

05 · GT · ROI · ANCHOR

정답 Box와 예측 기준 Box의 역할을 분리합니다

GROUND TRUTH GT Box

사람이 Annotation한 실제 정답 위치와 Class입니다.

REGION ROI

객체가 있을 가능성이 있다고 보는 관심 영역입니다.

REFERENCE Anchor Box

일부 모델이 Box Offset을 예측할 때 사용하는 기준 상자입니다.

PREDICTION Predicted Box

모델이 현재 Weight로 계산한 Box 후보입니다.

Anchor 후보 ↔ IoU GT Box → Positive·Negative 매칭 → Offset 학습

Anchor Box는 학습 데이터가 아닙니다. 학습 데이터는 원본 이미지와 GT Box·Class Label이며, Anchor는 일부 모델에서 예측 기준으로 사용됩니다.

06 · IoU

두 Box의 교집합을 합집합으로 나누어 겹침 정도를 계산합니다

IoU = Intersection Area / Union Area
Box A
Box B
Intersection
BOX A [0, 0, 4, 4] Area = 16
BOX B [2, 2, 6, 6] Area = 16
INTERSECTION 2 × 2 Area = 4
UNION 16 + 16 − 4 Area = 28

IoU = 4 / 28 ≈ 0.143

같은 IoU 수식의 서로 다른 역할
단계 비교 대상 목적
학습 Anchor와 GT Box Positive·Negative 매칭
평가 Prediction과 GT Box 정답 탐지 여부 판단
NMS Prediction과 Prediction 중복 Box 제거

08 · THRESHOLDS

Confidence와 IoU 임계값은 서로 다른 질문에 답합니다

CONFIDENCE THRESHOLD

탐지 후보로 남길 것인가?

높이면 강한 탐지만 남고 실제 객체를 놓칠 수 있습니다.

NMS IoU THRESHOLD

두 예측 Box를 중복으로 볼 것인가?

낮추면 겹친 Box를 더 적극적으로 제거합니다.

EVALUATION IoU

예측을 정답으로 인정할 것인가?

Prediction과 GT Box의 위치 일치 기준입니다.

Confidence ↑ 오탐 감소 가능 · 미탐 증가 가능
↔
Confidence ↓ Recall 증가 가능 · 오탐 증가 가능

09 · ONE-STAGE VS TWO-STAGE

후보 영역 생성과 최종 판단을 분리하는지 비교합니다

ONE-STAGE

YOLO · SSD

Image → Feature → Box + Class

위치와 Class를 하나의 탐지 흐름에서 직접 예측합니다.

TWO-STAGE

R-CNN Family

Image → Region Proposal → Box + Class

후보 영역을 만든 뒤 각 후보를 정밀하게 판단합니다.

교안 표현의 적용 범위

교안은 Two-Stage의 속도 부담을 강조합니다. 핵심은 One-Stage가 일반적으로 속도에 유리하고 Two-Stage는 Region Proposal 단계를 분리한다는 점이며, 실제 사용 가능성은 모델·Hardware·Latency 요구에 따라 달라집니다.

10 · MULTI-SCALE FEATURE MAP

Feature Map 크기에 따라 잘 표현되는 객체 크기가 달라집니다

52×52 작은 객체

Cell이 많아 위치를 세밀하게 구분합니다.

26×26 중간 객체

공간 해상도와 Receptive Field의 중간 단계입니다.

13×13 큰 객체

한 Cell이 원본의 넓은 범위를 참고합니다.

작은 객체가 어려운 이유

Stride와 Down Sampling이 누적되면 작은 객체의 Feature가 약해지거나 사라질 수 있습니다. 그래서 큰 Feature Map의 세밀한 위치 정보가 필요합니다.

13 · ANCHOR-BASED VS ANCHOR-FREE

사전 정의 Box를 기준으로 삼는지 구분합니다

ANCHOR-BASED

기준 Box + Offset

  1. 여러 크기·비율의 Anchor 준비
  2. GT Box와 IoU Matching
  3. Positive Anchor 결정
  4. Anchor에서 GT까지 Offset 학습
ANCHOR-FREE

위치·경계를 직접 예측

  1. 객체 중심 또는 위치 후보 결정
  2. 경계까지 거리·Box 크기 회귀
  3. 사전 Anchor Template 불필요
  4. 모델별 Label Assignment 적용

교안은 YOLOv8을 Anchor-Free 방향으로 설명합니다. 이번 단원에서는 모든 세부 구현을 같다고 보지 않고, 기준 Anchor 사용 여부라는 설계 차이로 이해합니다.

17 · ULTRALYTICS YOLO

교안의 사전 학습 이미지 탐지 흐름을 안전하게 정리합니다 

from pathlib import Path

from ultralytics import YOLO


IMAGE_PATHS = [
    Path("datasets/yolo/office.jpg"),
    Path("datasets/yolo/highway.jpg"),
]


def validate_paths(paths: list[Path]) -> None:
    missing = [
        str(path)
        for path in paths
        if not path.is_file()
    ]

    if missing:
        raise FileNotFoundError(
            "다음 이미지 파일을 찾을 수 없습니다:\n"
            + "\n".join(missing)
        )


def main() -> None:
    validate_paths(IMAGE_PATHS)

    model = YOLO(
        "yolo11m.pt"
    )

    results = model.predict(
        source=[
            str(path)
            for path in IMAGE_PATHS
        ],
        imgsz=640,
        conf=0.5,
        iou=0.5,
        max_det=300,
        save=True,
        line_width=1,
        verbose=True,
    )

    for image_path, result in zip(
        IMAGE_PATHS,
        results,
    ):
        print(
            f"\n이미지: {image_path}"
        )

        boxes = result.boxes

        if boxes is None or len(boxes) == 0:
            print(
                "탐지된 객체가 없습니다."
            )

            continue

        for index, box in enumerate(
            boxes,
            start=1,
        ):
            class_id = int(
                box.cls[0]
                .cpu()
                .item()
            )

            class_name = result.names[
                class_id
            ]

            confidence = float(
                box.conf[0]
                .cpu()
                .item()
            )

            xmin, ymin, xmax, ymax = (
                box.xyxy[0]
                .cpu()
                .tolist()
            )

            print(
                {
                    "index": index,
                    "class_id": class_id,
                    "class_name": class_name,
                    "confidence": round(
                        confidence,
                        4,
                    ),
                    "xyxy": [
                        round(xmin, 2),
                        round(ymin, 2),
                        round(xmax, 2),
                        round(ymax, 2),
                    ],
                }
            )

        print(
            "결과 저장 경로:",
            result.save_dir,
        )


if __name__ == "__main__":
    main()

19 · IoU CODE

XYXY Box 두 개의 교집합과 합집합을 직접 계산합니다 

from typing import Sequence


def calculate_iou(
    box_a: Sequence[float],
    box_b: Sequence[float],
) -> float:
    """
    두 XYXY Bounding Box의 IoU를 계산합니다.
    """

    if len(box_a) != 4 or len(box_b) != 4:
        raise ValueError(
            "Bounding Box는 값 4개여야 합니다."
        )

    ax1, ay1, ax2, ay2 = map(
        float,
        box_a,
    )

    bx1, by1, bx2, by2 = map(
        float,
        box_b,
    )

    if ax2 < ax1 or ay2 < ay1:
        raise ValueError(
            "box_a의 최대 좌표가 잘못되었습니다."
        )

    if bx2 < bx1 or by2 < by1:
        raise ValueError(
            "box_b의 최대 좌표가 잘못되었습니다."
        )

    intersection_x1 = max(
        ax1,
        bx1,
    )

    intersection_y1 = max(
        ay1,
        by1,
    )

    intersection_x2 = min(
        ax2,
        bx2,
    )

    intersection_y2 = min(
        ay2,
        by2,
    )

    intersection_width = max(
        0.0,
        intersection_x2 - intersection_x1,
    )

    intersection_height = max(
        0.0,
        intersection_y2 - intersection_y1,
    )

    intersection_area = (
        intersection_width
        * intersection_height
    )

    area_a = (
        max(0.0, ax2 - ax1)
        * max(0.0, ay2 - ay1)
    )

    area_b = (
        max(0.0, bx2 - bx1)
        * max(0.0, by2 - by1)
    )

    union_area = (
        area_a
        + area_b
        - intersection_area
    )

    if union_area <= 0:
        return 0.0

    return (
        intersection_area
        / union_area
    )


print(
    f"IoU: {
        calculate_iou(
            [0, 0, 4, 4],
            [2, 2, 6, 6],
        )
        :.3f
    }"
)

# IoU: 0.143

20 · NMS CODE

같은 Class 안에서 높은 점수 Box부터 중복을 제거합니다 

from dataclasses import dataclass


@dataclass(frozen=True)
class Detection:
    box: tuple[
        float,
        float,
        float,
        float,
    ]

    confidence: float
    class_id: int


def non_maximum_suppression(
    detections: list[Detection],
    iou_threshold: float = 0.5,
) -> list[Detection]:
    if not 0.0 <= iou_threshold <= 1.0:
        raise ValueError(
            "iou_threshold는 0과 1 사이여야 합니다."
        )

    grouped: dict[
        int,
        list[Detection],
    ] = {}

    for detection in detections:
        grouped.setdefault(
            detection.class_id,
            [],
        ).append(detection)

    selected: list[Detection] = []

    for class_detections in grouped.values():
        remaining = sorted(
            class_detections,
            key=lambda item: item.confidence,
            reverse=True,
        )

        while remaining:
            best = remaining.pop(0)

            selected.append(
                best
            )

            remaining = [
                candidate
                for candidate in remaining
                if calculate_iou(
                    best.box,
                    candidate.box,
                ) < iou_threshold
            ]

    return sorted(
        selected,
        key=lambda item: item.confidence,
        reverse=True,
    )

이 코드는 NMS 원리를 이해하기 위한 예제입니다. 실제 Ultralytics 추론에서는 Library 내부의 최적화된 후처리를 사용합니다.

26 · INTERVIEW POINTS

Box의 의미와 학습·추론·후처리의 차이를 설명합니다

Q1. Classification과 Detection의 차이는 무엇인가요?

Classification은 이미지 전체 Class를, Detection은 객체 Instance마다 Box·Class·Confidence를 예측합니다.

Q2. 객체 탐지가 회귀와 분류를 함께 사용하는 이유는 무엇인가요?

Box 좌표는 연속값이므로 회귀이고, 객체 종류는 범주 선택이므로 분류입니다.

Q3. XYXY와 XYWH의 차이는 무엇인가요?

XYXY는 두 모서리 좌표를, XYWH는 중심 좌표와 Box 크기를 사용합니다.

Q4. Ground Truth Box란 무엇인가요?

사람이 Annotation한 객체의 정답 위치와 Class입니다.

Q5. Anchor Box란 무엇인가요?

일부 탐지 모델이 Box Offset을 예측하기 위한 사전 정의 기준 상자입니다.

Q6. IoU란 무엇인가요?

두 Box의 교집합 면적을 합집합 면적으로 나눈 겹침 비율입니다.

Q7. IoU는 어디에 사용하나요?

GT Matching·정답 평가·NMS 중복 판정 등에 사용합니다.

Q8. NMS는 무엇인가요?

높은 점수의 Box를 남기고 IoU가 높은 중복 Box를 제거하는 후처리입니다.

Q9. Confidence와 NMS IoU Threshold의 차이는 무엇인가요?

Confidence는 후보 자체를 제거하고, NMS IoU는 후보 Box끼리 중복인지 판단합니다.

Q10. One-Stage와 Two-Stage의 차이는 무엇인가요?

One-Stage는 Box와 Class를 직접 예측하고, Two-Stage는 Region Proposal 뒤에 각 후보를 판단합니다.

Q11. YOLO의 핵심 아이디어는 무엇인가요?

하나의 Forward Pass에서 객체 위치·Score·Class를 함께 예측하는 것입니다.

Q12. YOLOv1 출력 공식은 무엇인가요?

S × S × (5B + K)입니다.

Q13. 모든 YOLO 버전이 같은 공식을 사용하나요?

아닙니다. Anchor 기반·Anchor-Free·Multi-Scale 등 세대별 Head와 출력 구조가 달라졌습니다.

Q14. Objectness와 Class Probability의 차이는 무엇인가요?

Objectness는 객체 존재 여부를, Class Probability는 객체 종류를 나타냅니다.

Q15. Multi-Scale Feature가 필요한 이유는 무엇인가요?

큰 Feature Map은 작은 객체의 세밀한 위치에, 작은 Feature Map은 큰 객체의 넓은 특징에 유리하기 때문입니다.

Q16. Anchor-Based와 Anchor-Free의 차이는 무엇인가요?

Anchor-Based는 기준 Box의 Offset을 예측하고, Anchor-Free는 위치와 경계를 직접 예측합니다.

Q17. 객체 탐지 Loss는 어떻게 구성되나요?

개념적으로 Box·Objectness 또는 Detection Score·Class Loss로 구성됩니다.

Q18. mAP50과 mAP50-95의 차이는 무엇인가요?

mAP50은 IoU 0.5 기준이고, mAP50-95는 0.5~0.95의 여러 위치 기준을 평균합니다.

Q19. Ultralytics Detection 결과는 어디에서 읽나요?

주로 result.boxes의 cls·conf·xyxy·xywh를 사용합니다.

Q20. result.probs가 None인 이유는 무엇인가요?

probs는 주로 이미지 Classification에 사용되고, Detection 결과는 boxes에 저장되기 때문입니다.
