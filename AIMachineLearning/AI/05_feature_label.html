13 · COMMON MISTAKES

Feature와 Label은 이름이 단순해서 오히려 많이 헷갈립니다

01

X는 항상 Feature 하나다

X는 여러 Feature를 포함할 수 있습니다. 다중 입력에서는 X = [x₁, x₂, ..., xₙ]입니다.

02

Sample과 Feature를 같은 것으로 생각한다

표 Data에서 행은 Sample, 열은 Feature로 먼저 이해하면 쉽습니다.

03

y는 항상 하나의 숫자다

Regression에서는 연속값, Classification에서는 Class 또는 Encoding된 정답이 될 수 있습니다.

04

Feature와 Parameter가 같다

Feature는 Data이고, Parameter는 Weight와 Bias처럼 Model이 학습하는 내부 값입니다.

05

Label과 Prediction이 같다

Label y는 실제 정답, Prediction ŷ는 Model의 예상입니다.

06

Target과 Label은 언제나 완전히 다른 용어다

실제 문서와 Library에서는 상당히 겹쳐 사용됩니다. 교안도 Regression의 실제값을 Label이라고 표현합니다.

07

Classification Label은 반드시 문자열이다

Integer Encoding이나 One-Hot Encoding으로 표현될 수도 있습니다.

08

Feature는 많을수록 좋다

불필요한 Feature는 Noise와 Model Complexity를 증가시킬 수 있습니다.

09

Test의 y를 Training에 사용해도 된다

Test Label은 학습에 사용하지 않고 최종 성능을 평가하기 위해 남겨둡니다.

10

실제 Inference에도 y를 넣어야 한다

실제 예측 시점에는 y를 모르기 때문에 New X만 입력하고 Prediction을 얻습니다.

Feature와 Label에서는 Shape 오류를 읽는 습관이 중요합니다

Broadcasting Shape 불일치 

ValueError:
operands could not be
broadcast together

예 (100,) → (100, 1)
DATA ERROR 03

X와 y의 Sample 수가 다름

X.shape = (100, 4) y.shape = (97,)

각 X Sample에는 하나의 대응하는 y가 있어야 합니다.

X.shape[0] == y.shape[0]

16 · INTERVIEW POINT

X → Model → ŷ ↔ y 구조로 설명합니다

Q1. Feature란 무엇인가요?

Machine Learning Model이 Prediction을 만들기 위해 입력받는 정보 또는 특성입니다. 이번 교안에서는 독립변수 X와 연결해 이해할 수 있습니다.

Q2. Label이란 무엇인가요?

지도학습에서 Model이 맞혀야 하는 실제 정답입니다. Classification에서는 실제 Class를 Label이라고 부르는 경우가 많고, 이번 교안은 Regression의 실제 종속변수에도 Label이라는 표현을 사용합니다.

Q3. X와 y는 무엇인가요?

X는 Model에 입력되는 Feature 또는 독립변수이고, y는 Model이 맞혀야 하는 Target 또는 종속변수입니다.

Q4. Prediction은 무엇인가요?

입력 X를 이용해 Model이 계산한 예상 결과입니다. 수학적으로 흔히 ŷ로 표현합니다.

Q5. y와 ŷ의 차이는 무엇인가요?

y는 실제 정답이고, ŷ는 Model의 Prediction입니다. Training에서는 두 값을 비교하여 Error 또는 Loss를 계산합니다.

Q6. Feature와 Parameter의 차이는 무엇인가요?

Feature는 Dataset에서 Model로 입력되는 Data이고, Parameter는 Weight와 Bias처럼 Training 과정에서 Model 내부에서 학습되는 값입니다.

Q7. Target과 Label은 무엇이 다른가요?

문맥에 따라 상당히 겹쳐 사용됩니다. Target은 예측하려는 변수라는 역할 중심 표현이고, Label은 실제 정답이라는 의미로 많이 사용됩니다. 이번 교안에서는 Regression 실제값도 Label이라고 표현합니다.

Q8. Feature 수와 Input Layer Node 수는 어떤 관계인가요?

교안에서는 신경망 입력층 Node 수를 Feature 수와 같게 구성한다고 설명합니다. Feature가 4개라면 입력층도 개념적으로 4개의 입력을 받습니다.

Q9. Multi-Class Classification에서 Output Node 수는 어떻게 정하나요?

교안에서는 다중 분류의 경우 Label의 Class 수만큼 출력층 Node를 구성한다고 설명합니다.

Q10. Training과 Inference에서 y는 어떻게 다른가요?

Training에서는 X와 y를 함께 사용하여 Model의 Parameter를 학습합니다. 실제 Inference에서는 정답 y를 모르므로 새로운 X만 입력해 Prediction을 얻습니다.

Q11. Feature가 많을수록 Model 성능이 좋아지나요?

반드시 그렇지는 않습니다. 불필요한 Feature는 Noise와 Complexity를 증가시킬 수 있어 Feature Selection이나 Regularization이 필요할 수 있습니다.

Q12. Label 품질이 중요한 이유는 무엇인가요?

지도학습 Model은 Training Data에 제공된 y를 실제 정답으로 간주합니다. 잘못된 Label은 잘못된 관계를 학습시키는 Training Signal이 될 수 있습니다.

Q13. X의 기본 Shape는 어떻게 읽나요?

일반적인 표 형태 Machine Learning Data에서는 X를 (n_samples, n_features)의 2차원 구조로 이해합니다.
