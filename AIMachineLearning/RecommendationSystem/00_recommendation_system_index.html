Recommendation System Course

사용자와 Item의 관계를 읽고
어울리는 선택지를 추천하다

Recommendation System Course는 “어떤 사용자에게 어떤 Item을 보여 줄 것인가”를 공부하는 과목입니다. 콘텐츠 기반 추천, 협업 필터링, User-Based와 Item-Based 비교, Hybrid 전략, Embedding과 Ranking까지 추천 흐름을 전문적으로 정리합니다.

01 · Course Role

추천시스템은 데이터 분석과 AI 모델 사이에 놓인 응용 과목입니다

추천은 단순히 인기 상품을 보여 주는 기능이 아닙니다. 사용자의 과거 행동, Item의 특징, 다른 사용자와의 관계, 모델이 계산한 점수를 함께 사용해 우선순위를 정하는 문제입니다.

사용자 관점

사용자 취향, 행동 이력, 유사 사용자를 기반으로 추천 대상을 찾습니다.

Item 관점

상품, 영화, 문서, 콘텐츠의 속성과 유사도를 기반으로 추천합니다.

모델 관점

Embedding, Ranking, Hybrid 모델로 추천 품질을 개선합니다.

03 · Recommendation Flow

후보를 만들고 점수를 계산한 뒤 순위를 정합니다

User·Item 데이터 → 후보 생성 → 유사도·예측 점수 → Ranking → 추천 결과

MEMORY

CONFUSION

User-Based와 Item-Based

User-Based는 비슷한 사용자를 찾고, Item-Based는 비슷한 Item을 찾습니다.
