01 · 핵심 개념 설명

Collaborative Filtering이란?

Collaborative Filtering은 여러 사용자가 여러 아이템에 보인 행동을 모아서 User 또는 Item 사이의 행동 Pattern을 비교 하고, 아직 관찰되지 않은 선호를 추정하는 추천 방식입니다.

User Interaction Rating · Click · Purchase
→
User-Item Matrix 행동 관계 표현
→
Similarity User 또는 Item 비교

Recommendation 아직 사용하지 않은 Item
핵심

20 · 코드 예제

여러 Neighbor의 Rating으로 추천 Score 만들기

user_based_cf.py 

import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity


ratings = pd.DataFrame(
    [
        [5, 4, 0, 1],
        [5, 4, 3, 0],
        [1, 2, 5, 4],
        [5, 4, 4, 0]
    ],
    index=[
        "User_A",
        "User_B",
        "User_C",
        "User_D"
    ],
    columns=[
        "Movie_A",
        "Movie_B",
        "Movie_C",
        "Movie_D"
    ]
)


user_similarity = pd.DataFrame(
    cosine_similarity(ratings),
    index=ratings.index,
    columns=ratings.index
)


target_user = "User_A"


similarities = (
    user_similarity
    .loc[target_user]
    .drop(target_user)
    .sort_values(
        ascending=False
    )
)


# 상위 3명의 Neighbor
neighbors = similarities.head(3)


target_ratings = ratings.loc[target_user]

scores = {}


for movie in ratings.columns:

    # 이미 평가한 Movie 제외
    if target_ratings[movie] != 0:
        continue

    weighted_sum = 0.0
    weight_sum = 0.0

    for neighbor, similarity in neighbors.items():

        rating = ratings.loc[
            neighbor,
            movie
        ]

        # Neighbor도 평가하지 않았다면 제외
        if rating == 0:
            continue

        weighted_sum += (
            similarity * rating
        )

        weight_sum += similarity

    if weight_sum > 0:
        scores[movie] = (
            weighted_sum
            / weight_sum
        )


recommendations = sorted(
    scores.items(),
    key=lambda x: x[1],
    reverse=True
)


print("[Recommendation]")

for rank, (movie, score) in enumerate(
    recommendations,
    start=1
):
    print(
        f"{rank}. "
        f"{movie} "
        f"- predicted={score:.4f}"
    )
.drop(target_user) 자기 자신 제외
neighbors.head(3) Neighborhood 선택
rating == 0 이 학습 예제에서는 미평가로 처리
similarity * rating 비슷한 User의 Rating에 Weight 부여

21 · 코드 예제

Item-Based — R.T가 핵심

item_based_cf.py 

import pandas as pd
from sklearn.metrics.pairwise import cosine_similarity


ratings = pd.DataFrame(
    [
        [5, 4, 0, 1],
        [5, 4, 3, 0],
        [1, 2, 5, 4],
        [5, 4, 4, 0]
    ],
    index=[
        "User_A",
        "User_B",
        "User_C",
        "User_D"
    ],
    columns=[
        "Movie_A",
        "Movie_B",
        "Movie_C",
        "Movie_D"
    ]
)


# Item을 행으로 바꾼 뒤 비교
item_similarity = pd.DataFrame(
    cosine_similarity(
        ratings.T
    ),
    index=ratings.columns,
    columns=ratings.columns
)


target_user = "User_A"

history = ratings.loc[
    target_user
]


# 높은 Rating을 준 Item
liked_items = history[
    history >= 4
].index


scores = {}


for liked_item in liked_items:

    similar_items = (
        item_similarity
        .loc[liked_item]
        .sort_values(
            ascending=False
        )
    )

    for candidate, similarity in similar_items.items():

        # 같은 Item 제외
        if candidate == liked_item:
            continue

        # 이미 평가한 Item 제외
        if history[candidate] != 0:
            continue

        scores[candidate] = (
            scores.get(
                candidate,
                0.0
            )
            + similarity
        )


recommendations = sorted(
    scores.items(),
    key=lambda x: x[1],
    reverse=True
)


print("[Item-Based Recommendation]")

for rank, (movie, score) in enumerate(
    recommendations,
    start=1
):
    print(
        f"{rank}. "
        f"{movie} "
        f"- score={score:.4f}"
    )
R → User-Based
Rᵀ → Item-Based

22 · 실행 결과 해석

추천 결과의 숫자를 어떻게 읽을까?

1

질문 해석
4.72는 실제 Rating인가? 아닙니다. 현재 Neighbor와 계산식에서 나온 예상값입니다.
Similarity 0.9는 확률인가? 아닙니다.
Neighbor가 비슷하면 항상 추천이 생기는가? 아닙니다. 새로운 Candidate가 없을 수 있습니다.
User-Based와 Item-Based Score를 그대로 비교해도 되는가? 계산 의미가 다를 수 있으므로 점수 크기만으로 우열을 판단하지 않습니다.

어떤 Vector → 어떤 Similarity → 어떤 Candidate → 어떤 Score 인지 먼저 확인합니다.

23 · 자주 하는 실수

실행되더라도 의미가 잘못될 수 있다

실수 문제 확인
0 = 싫어요 Missing과 Negative 혼동 Interaction 의미 정의
User-Based만 CF라고 생각 Item-Based 누락 비교 축 확인
Item-Based CF = Content-Based Similarity 근거가 다름 Feature vs Reaction
자기 자신을 Neighbor로 사용 Self Similarity가 가장 큼 Self 제외
UserID = Array Index ID가 연속적이지 않을 수 있음 Label / Position 분리
Cosine = Probability Score 의미 왜곡 score_type 확인
neighbor_k = top_k 서로 다른 파라미터 역할 구분
Item-Based는 항상 빠름 Item 수가 더 클 수 있음 User / Item 규모 확인
모든 과거 Rating을 동일 취급 취향 변화 무시 Timestamp 확인
공통 Item 1개만으로 강한 Neighbor 판단 근거가 부족할 수 있음 Common Interaction 수 확인

27 · 면접 포인트

질문과 답변으로 복습하기

Q1. Collaborative Filtering이란 무엇인가요?

여러 사용자의 User-Item Interaction을 이용해 User 또는 Item 간 행동 Pattern의 유사성을 찾고, 아직 관찰하지 않은 선호를 추정하는 추천 방식입니다.

Q2. Content-Based와 차이는 무엇인가요?

Content-Based는 Item Feature를 비교하고, Collaborative Filtering은 Rating·Click 등의 User-Item Interaction Pattern을 비교합니다.

Q3. User-Item Matrix란 무엇인가요?

행은 User, 열은 Item, 셀은 Rating이나 Interaction을 나타내는 행렬입니다.

Q4. 행렬의 0은 항상 0점인가요?

아닙니다. 구현에서는 미평가 칸을 계산 편의를 위해 0으로 채울 수도 있습니다.

Q5. User-Based Filtering은 무엇인가요?

대상 User와 행동 Pattern이 비슷한 User를 찾고, 그 User들의 선호 Item을 추천에 활용합니다.

Q6. Item-Based Filtering은 무엇인가요?

여러 User가 Item에 보인 Rating Pattern을 이용하여 Item 간 유사도를 계산하고, 사용자가 좋아한 Item과 유사한 Item을 추천합니다.

Q7. Item-Based CF와 Content-Based는 무엇이 다른가요?

Content-Based는 Item의 장르·텍스트 같은 Feature를 비교하고, Item-Based CF는 User들의 Rating Pattern을 비교합니다.

Q8. User Similarity Matrix 크기는 어떻게 되나요?

User가 m명이면 전체 Matrix는 m×m입니다.

Q9. Item Similarity Matrix 크기는 어떻게 되나요?

Item이 n개이면 전체 Matrix는 n×n입니다.

Q10. Sparsity란 무엇인가요?

가능한 전체 User-Item 관계에 비해 실제 관찰된 Interaction이 적어 Matrix 대부분이 비어 있는 상태입니다.

Q11. Cold Start와 Sparsity는 무엇이 다른가요?

Cold Start는 신규 User·Item의 초기 데이터 부족이고, Sparsity는 기존 시스템에서도 전체 관계 대부분이 미관찰인 상태입니다.

Q12. Neighborhood란 무엇인가요?

Target User와 Similarity가 높은 User 집합입니다. 이들의 Rating을 추천 Score 계산에 사용할 수 있습니다.

Q13. neighbor_k와 top_k의 차이는 무엇인가요?

neighbor_k는 참고할 Neighbor 수, top_k는 최종 추천 Item 수입니다.

Q14. Cosine Similarity 0.9는 90% 선호 확률인가요?

아닙니다. 현재 Vector 표현에서 두 User 또는 Item의 방향이 비슷한 정도입니다.

Q15. User-Based의 대표적인 한계는 무엇인가요?

New User, Sparsity, User 증가에 따른 계산량, 사용자 취향 변화 반영 문제 등이 있습니다.

Q16. Item-Based는 항상 더 빠른가요?

아닙니다. User 수와 Item 수, 사전 계산 여부, 전체 Similarity Matrix 생성 여부에 따라 달라집니다.

Q17. Collaborative Filtering이 Hybrid와 어떻게 연결되나요?

Interaction에서 계산한 Collaborative Score를 Content-Based Score와 결합하여 서로의 단점을 보완할 수 있습니다.

Q18. Embedding과는 어떻게 연결되나요?

User-Item Interaction을 직접 Similarity로 계산하는 대신, 이후 Model-Based에서는 User와 Item의 잠재 Vector를 학습하여 Prediction에 사용할 수 있습니다.

오늘의 암기 포인트

  1. Collaborative Filtering의 중심은 User-Item Interaction입니다.
  2. User-Item Matrix의 행은 User, 열은 Item입니다.
  3. Missing Interaction은 Negative Rating과 다릅니다.
  4. User-Based는 User를 비교합니다.
  5. Item-Based는 Item을 비교합니다.
  6. User-Based 결과 Matrix는 User×User입니다.
  7. Item-Based 결과 Matrix는 Item×Item입니다.
  8. Cosine Similarity는 확률이 아닙니다.
  9. Sparsity는 Matrix 대부분이 미관찰인 상태입니다.
  10. Cold Start는 초기 Interaction 부족 문제입니다.
  11. Neighbor 수와 추천 Item 수는 다릅니다.
  12. Collaborative Score는 Hybrid의 한 입력이 됩니다.
