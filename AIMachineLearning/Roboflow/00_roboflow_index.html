01 · Course Role

Roboflow는 모델 코드 이전의 Dataset 제작 과목입니다

객체 탐지 모델은 이미지와 정답 라벨을 함께 학습합니다. Roboflow Course는 이 데이터를 프로젝트 단위로 관리하고, 학습 코드가 읽을 수 있는 형식으로 내보내는 방법을 다룹니다.

데이터 수집

이미지를 모으고 프로젝트 목적에 맞는 클래스 이름을 정합니다.

정답 표시

Bounding Box와 Label로 모델이 배워야 할 대상을 표시합니다.

학습 연결

Version, Augmentation, YOLO Export를 통해 모델 학습 폴더로 넘깁니다.
