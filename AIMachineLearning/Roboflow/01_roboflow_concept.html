01 · WHAT IS ROBOFLOW?

Roboflow란?

이번 교안에서 Roboflow의 역할은 Object Detection Model이 학습할 Dataset을 제작하고 관리하는 것 입니다.

AI Machine Learning

Model 중심

Model ↓ Loss ↓ Optimizer ↓ Training

Roboflow

Dataset 중심

Image ↓ Annotation ↓ Version ↓ Export
Roboflow의 최종 결과는 “학습된 Model”이 아닙니다.

최종 결과는 YOLO가 바로 학습에 사용할 수 있는 Training-ready Dataset입니다.

17 · TRAIN / VALID / TEST

Dataset Split

TRAIN

Model Weight 학습

Model이 실제 패턴을 배우는 Dataset

VALID

학습 중 일반화 확인

Training Image 밖에서도 잘 동작하는지 점검

TEST

최종 성능 평가

Model 설정이 끝난 뒤 최종 확인

Split 비율은 교안에 나오지 않습니다.

`data.yaml`에서 train / val / test 경로는 확인되지만, 몇 %로 나누었는지는 첨부 교안에 명시되어 있지 않습니다. 따라서 특정 비율을 원본 내용처럼 적지 않습니다.

보충 · Computer Vision Data Leakage

TRAIN frame_100
VALID frame_101
TEST frame_102

같은 Video의 연속 Frame처럼 거의 동일한 Image가 서로 다른 Split에 들어가면 실제보다 성능이 높아 보일 수 있습니다.

21 · INTERVIEW / REVIEW

면접 포인트

Q01. Roboflow는 무엇입니까?

이번 교안 기준으로 이미지 Upload, Annotation, Dataset Version, Preprocessing, Augmentation, Export를 관리하는 웹 기반 Computer Vision Dataset 제작 도구입니다.

Q02. 왜 Object Detection Project를 선택합니까?

객체의 Class뿐 아니라 Image 안의 위치를 Bounding Box로 학습해야 하기 때문입니다.

Q03. Bounding Box와 Class의 차이는 무엇입니까?

Bounding Box는 객체가 어디 있는지를, Class는 객체가 무엇인지를 나타냅니다.

Q04. Annotation이란 무엇입니까?

Image에 Model이 학습할 정답 정보를 입력하는 과정입니다. 이번 실습에서는 Bounding Box와 Class를 작성합니다.

Q05. Unannotated = 0은 무엇을 의미합니까?

Annotation 작업이 남은 Image가 없다는 의미입니다. Annotation 품질이 완벽하다는 뜻은 아닙니다.

Q06. Dataset Version을 왜 만듭니까?

특정 Dataset 상태와 Preprocessing/Augmentation 설정을 Snapshot으로 고정하여 재현성을 확보하기 위해서입니다.

Q07. Preprocessing과 Augmentation의 차이는 무엇입니까?

Preprocessing은 입력 Image를 일정한 규칙으로 변환하고, Augmentation은 Image 변형을 통해 학습 데이터의 다양성을 늘립니다.

Q08. 이번 교안의 Augmentation 상태는 무엇입니까?

Version 화면에서는 Turned Off로 보입니다.

Q09. Version 생성과 Model Training은 같은 단계입니까?

아닙니다. Version은 Dataset을 만드는 단계이고, Training은 그 Dataset으로 Model Weight를 학습하는 단계입니다.

Q10. data.yaml은 무엇입니까?

YOLO Dataset의 train, val, test 경로와 Class 수, Class 이름 등을 정의하는 설정 파일입니다.

Q11. nc: 2는 무엇입니까?

Number of Classes가 2라는 뜻입니다.

Q12. 이번 Dataset의 Class는 무엇입니까?

with-mask와 without-mask입니다.

Q13. images와 labels 폴더의 차이는 무엇입니까?

images에는 원본 Image가, labels에는 Object Detection Annotation 파일이 들어갑니다.

Q14. Train, Validation, Test의 역할은 무엇입니까?

Train은 Weight 학습, Validation은 학습 중 일반화 확인, Test는 최종 성능 평가에 사용합니다.

Q15. 교안의 Split 비율은 얼마입니까?

첨부 교안에는 구체적인 Split 비율이 명시되어 있지 않습니다.

Q16. YOLO Label의 일반적인 구조는 무엇입니까?

보통 class_id, x_center, y_center, width, height 형식을 사용합니다. 이 세부 구조는 교안의 직접 설명이 아니라 보충 내용입니다.

Q17. Class 이름을 왜 일관되게 사용해야 합니까?

같은 의미의 객체가 서로 다른 Class로 분리되어 Dataset 정답이 불일치하는 문제를 막기 위해서입니다.

Q18. Roboflow 다음 단계는 무엇입니까?

Export한 images, labels, data.yaml을 이용한 YOLO Training입니다.
