Python Database · Lesson 03

SQLite CRUD와 내장 함수 Table 안의 Row를 생성·조회·수정·삭제하고 SQL 함수로 데이터를 가공하기

앞 단원에서 Member Table의 구조를 만들었습니다. 이제 실제 데이터를 저장할 차례입니다. 이번 단원에서는 INSERT, SELECT, UPDATE, DELETE를 이용하여 Row의 생명주기를 이해하고, SQLite의 문자열·숫자·NULL·날짜·집계 함수를 이용하여 저장된 데이터를 계산하고 가공하는 방법을 학습합니다.

INSERT → SELECT → UPDATE → DELETE + SQLite Functions

학습 목표

  • CRUD가 무엇인지 설명하고 INSERT·SELECT·UPDATE·DELETE와 연결할 수 있다.
  • DDL이 Schema를 다루고 CRUD가 실제 Row를 다룬다는 차이를 이해한다.
  • INSERT로 새로운 Row를 추가할 수 있다.
  • SELECT와 WHERE를 이용해 필요한 데이터를 조회할 수 있다.
  • LIKE, ORDER BY, LIMIT의 역할을 이해한다.
  • UPDATE와 DELETE에서 WHERE 조건이 중요한 이유를 설명할 수 있다.
  • 문자열·숫자·NULL·날짜·집계 함수를 기능별로 구분할 수 있다.
  • count(*)와 count(column)의 차이를 이해한다.
  • Python에서 SELECT는 fetch(), 변경 SQL은 commit()으로 연결된다는 흐름을 이해한다.
  • 다음 Python DB-API 단원에서 Connection·Cursor·execute를 배워야 하는 이유를 설명할 수 있다.

Python Example

SQLite CRUD 전체 흐름 실행하기

03_sqlite_crud_function.py SQLite CRUD 
import sqlite3


# 1. Database 연결
conn = sqlite3.connect("crud_practice.db")


# 2. Cursor 생성
cur = conn.cursor()


# 3. 실습용 Table 준비
cur.execute("""
CREATE TABLE IF NOT EXISTS Member (
    _id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    tel TEXT NOT NULL DEFAULT 'unknown',
    joindate DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(name, tel),
    CHECK(length(tel) >= 3)
)
""")


# 4. CREATE - INSERT
cur.execute(
    """
    INSERT INTO Member(name, tel)
    VALUES (?, ?)
    """,
    ("홍길동", "010-1111-1111")
)

conn.commit()


# 5. READ - SELECT
cur.execute("""
SELECT
    _id,
    name,
    tel,
    joindate
FROM Member
""")


print("=== SELECT 결과 ===")

for row in cur.fetchall():
    print(row)


# 6. UPDATE
cur.execute(
    """
    UPDATE Member
    SET tel = ?
    WHERE name = ?
    """,
    ("010-9999-9999", "홍길동")
)

conn.commit()


# 7. SQLite 내장 함수
cur.execute("""
SELECT
    name,
    length(name),
    upper(name)
FROM Member
""")


print("=== 함수 결과 ===")

for row in cur.fetchall():
    print(row)


# 8. DELETE
cur.execute(
    """
    DELETE FROM Member
    WHERE name = ?
    """,
    ("홍길동",)
)

conn.commit()


# 9. 최종 Row 수 확인
cur.execute("""
SELECT count(*)
FROM Member
""")


print("=== 최종 회원 수 ===")
print(cur.fetchone())


# 10. 종료
cur.close()
conn.close()

Beginner Mistakes

초보자가 자주 하는 실수

01

CREATE TABLE과 INSERT를 혼동한다.

CREATE TABLE은 Schema, INSERT는 Row를 만듭니다.

02

SELECT만 실행하면 Python에 결과가 들어온다고 생각한다.

SELECT를 execute한 뒤 fetch 계열 메서드로 결과를 가져옵니다.

03

SELECT 후 commit(), INSERT 후 fetch()를 찾는다.

기본 흐름은 SELECT → fetch, 변경 SQL → commit으로 구분합니다.

04

UPDATE에서 WHERE를 빼먹는다.

특정 Row를 수정하려면 수정 대상 조건을 반드시 확인합니다.

05

DELETE에서 FROM을 빼먹는다.

SQLite 데이터 삭제는 DELETE FROM Table 형태로 작성합니다.

06

DELETE에서 WHERE를 확인하지 않는다.

WHERE가 없으면 의도보다 많은 Row가 삭제될 수 있습니다.

07

DELETE와 DROP을 혼동한다.

DELETE는 Row, DROP은 Table 자체를 삭제합니다.

08

UPDATE와 ALTER TABLE을 혼동한다.

UPDATE는 Row 값, ALTER는 Schema를 변경합니다.

09

사용자 값을 SQL 문자열에 직접 연결한다.

이후 Parameter 단원에서 배우는 Placeholder 방식을 기본 습관으로 사용합니다.

10

하나짜리 Tuple의 쉼표를 빼먹는다.

("홍길동",)
11

count(*)와 count(column)을 같은 것으로 생각한다.

전체 Row 수와 NULL이 아닌 Column 값의 수는 다릅니다.

12

NULL과 'NULL'을 같은 값으로 생각한다.

NULL은 값 없음이고, 'NULL'은 문자열입니다.

13

coalesce()와 nullif()를 혼동한다.

coalesce는 NULL 아닌 첫 값, nullif는 두 값이 같으면 NULL입니다.

14

Scalar와 Aggregate 함수를 구분하지 않는다.

개별 값 변환과 여러 Row 집계를 구분합니다.

Interview Point

면접에서 설명할 수 있어야 하는 질문

Q1. CRUD란 무엇인가요?
A.

Create, Read, Update, Delete의 약자로 데이터의 기본 생성·조회·수정·삭제 작업입니다. SQL에서는 INSERT, SELECT, UPDATE, DELETE와 연결할 수 있습니다.

Q2. CREATE TABLE과 INSERT의 차이는 무엇인가요?
A.

CREATE TABLE은 Schema 구조를 만들고, INSERT는 이미 존재하는 Table에 새로운 Row를 추가합니다.

Q3. WHERE가 중요한 이유는 무엇인가요?
A.

조회·수정·삭제 대상 Row의 범위를 제한하기 때문입니다. 특히 UPDATE와 DELETE에서 WHERE가 없다면 의도보다 많은 Row가 변경될 수 있습니다.

Q4. UPDATE와 ALTER TABLE의 차이는 무엇인가요?
A.

UPDATE는 기존 Row의 값을 변경하고, ALTER TABLE은 Table의 Schema 구조를 변경합니다.

Q5. DELETE와 DROP TABLE의 차이는 무엇인가요?
A.

DELETE는 Row를 삭제하지만 Table 구조를 유지하고, DROP TABLE은 Table 자체를 삭제합니다.

Q6. Scalar Function과 Aggregate Function의 차이는 무엇인가요?
A.

Scalar Function은 주로 개별 값을 계산하거나 변환하고, Aggregate Function은 여러 Row를 합쳐 개수·합계·평균 같은 하나의 결과를 계산합니다.

Q7. coalesce()는 무엇인가요?
A.

여러 값 중 왼쪽부터 확인하여 처음 만나는 NULL이 아닌 값을 반환하는 함수입니다.

Q8. count(*)와 count(column)의 차이는 무엇인가요?
A.

count(*)는 Row 수를 세고, count(column)은 해당 Column이 NULL이 아닌 Row의 수를 셉니다.

Q9. last_insert_rowid()는 언제 사용하나요?
A.

마지막 INSERT와 연결된 Row ID를 확인할 때 사용하는 SQLite 함수입니다.

Q10. Python에서 SELECT 결과는 어떻게 가져오나요?
A.

Cursor에서 SELECT를 execute한 뒤 fetchone(), fetchmany(), fetchall() 같은 fetch 계열 메서드를 이용해 결과를 가져옵니다.

Q11. INSERT·UPDATE·DELETE 후에는 무엇을 해야 하나요?
A.

변경 사항을 Database에 반영하기 위해 Transaction 흐름에서 commit()을 사용하고, 필요한 경우 rollback()을 고려합니다.

Q12. SQLite 내장 함수는 왜 사용하나요?
A.

Database에 저장된 데이터를 SQL 단계에서 문자열 변환, 숫자 계산, NULL 처리, 날짜 처리, 집계 등의 형태로 가공하기 위해 사용합니다.

Memory

오늘의 암기 포인트

  • CRUD는 Create · Read · Update · Delete다.
  • SQL에서는 INSERT · SELECT · UPDATE · DELETE 로 연결한다.
  • DDL은 Schema, CRUD는 Row를 다룬다.
  • WHERE는 대상 Row의 범위를 제한한다.
  • UPDATE와 DELETE에서는 WHERE 조건을 특히 주의한다.
  • DELETE FROM은 Row 삭제, DROP TABLE은 Table 삭제다.
  • length(), substr(), upper(), lower()는 문자열 처리와 연결한다.
  • abs()는 절대값, round()는 반올림이다.
  • coalesce()는 첫 NULL 아닌 값, nullif()는 같으면 NULL이다.
  • count(), sum(), avg(), min(), max()는 집계와 연결한다.
  • Python에서 SELECT → fetch(), 변경 SQL → commit() 흐름을 기억한다.
INSERT → SELECT → UPDATE → DELETE

Confusing Point

헷갈리기 쉬운 개념

CREATE ≠ INSERT

CREATE는 Schema, INSERT는 Row입니다.

ALTER ≠ UPDATE

ALTER는 Table 구조, UPDATE는 Row 값입니다.

DROP ≠ DELETE

DROP은 Table, DELETE는 Row를 제거합니다.

SELECT ≠ fetch

SELECT는 SQL 실행, fetch는 결과를 Python으로 가져오는 단계입니다.

count(*) ≠ count(column)

전체 Row 수와 NULL이 아닌 Column 값 수를 구분합니다.

NULL ≠ 'NULL'

NULL은 값 없음, 'NULL'은 문자열입니다.

coalesce ≠ nullif

NULL 대체와 같을 때 NULL 반환을 구분합니다.

Scalar ≠ Aggregate

개별 값 처리와 여러 Row 집계를 구분합니다.
