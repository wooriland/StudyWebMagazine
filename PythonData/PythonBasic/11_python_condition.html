01 · Core Concept

조건문은 실행 경로를 선택하는 제어문이다

조건문은 현재 데이터나 프로그램 상태를 검사한 뒤, 그 결과에 맞는 코드 블록만 실행합니다. 조건식은 먼저 하나의 값으로 평가되고, Python은 그 값을 참 또는 거짓으로 판정합니다.

01

조건식

참·거짓을 판단할 수 있는 표현식입니다.

score >= 60
02

분기 키워드

조건에 따라 경로를 나누는 문법입니다.

if · elif · else
03

같은 깊이로 들여쓴 실행 코드 묶음입니다.

03 · Boolean Context

True·False가 아니어도 참·거짓으로 판정된다

if 뒤에는 반드시 비교식만 오는 것이 아닙니다. Python은 조건 자리에 놓인 값을 bool() 규칙으로 해석합니다. 거짓으로 판정되는 값을 Falsy, 참으로 판정되는 값을 Truthy라고 부릅니다.

Falsy 거짓으로 판정
  • False
  • None
  • 0, 0.0, 0j
  • "", ''
  • [], (), {}
  • set(), range(0)
Truthy 참으로 판정
  • True
  • 1, -1, 3.14
  • "Python"
  • [1, 2], (0,)
  • {"name": "민수"}
  • 대부분의 내용이 있는 객체

빈 컬렉션 검사

items = []

if items:
    print("처리할 데이터가 있습니다.")
else:
    print("처리할 데이터가 없습니다.")

공백 입력 검사

raw_name = "   "
name = raw_name.strip()

if name:
    print("유효한 이름입니다.")
else:
    print("이름을 입력하세요.")
공백 문자열 주의

" "는 문자가 있으므로 Truthy입니다. 사용자 입력이 비었는지 확인하려면 strip()으로 앞뒤 공백을 제거한 값을 검사합니다.

None Check

값이 없음은 동일성으로 검사

result = None

if result is None:
    print("결과가 없습니다.")
else:
    print("결과가 있습니다.")
  • is None: 정확히 None 객체인지 검사
  • is not None: 결과가 존재하는지 검사
  • if result: 0, ""도 함께 거짓 처리

and

모두 참

길어진 조건은 우선순위를 외우는 것보다 괄호로 의도를 드러내세요.

괄호로 의미가 보이는 조건 Boolean Logic 
age = 20
is_member = True
has_coupon = False

can_discount = (
    is_member
    and (age >= 19 or has_coupon)
)

if can_discount:
    print("할인을 적용합니다.")

Short-circuit Evaluation

결과가 확정되면 오른쪽을 평가하지 않는다

and는 왼쪽이 Falsy이면 전체 조건이 이미 거짓이고, or는 왼쪽이 Truthy이면 전체 조건이 이미 참입니다. 그래서 오른쪽 표현식을 실행하지 않습니다.

A and B A가 Falsy B 평가 생략
A or B A가 Truthy B 평가 생략

단락 평가로 오류 방지

numbers = []

if numbers and numbers[0] > 0:
    print("첫 값은 양수입니다.")

numbers가 빈 리스트라 Falsy이므로 numbers[0]을 평가하지 않아 IndexError를 피합니다.

0으로 나누기 방지

denominator = 0

if denominator != 0 and 10 / denominator > 1:
    print("몫이 1보다 큽니다.")

첫 조건이 거짓이므로 나눗셈을 실행하지 않아 ZeroDivisionError를 피합니다.

한 단계 더

and와 or는 항상 True 또는 False를 돌려주는 것이 아니라, 판단에 사용한 피연산자 자체를 돌려줄 수 있습니다. 

print("Python" and 10)   # 10
print("" or "기본값")   # 기본값
print(bool("Python" and 10))  # True
Membership

in / not in

role = "admin"

if role in {"admin", "manager"}:
    print("관리 권한이 있습니다.")
Identity

is / is not

record = None

if record is not None:
    print("레코드를 처리합니다.")

로그인했는가?

pass

문법상 블록은 필요하지만 아직 할 일이 없을 때

Python의 콜론 다음에는 최소 한 개의 문장이 필요합니다. pass는 아무 동작도 하지 않는 유효한 문장이라, 구조를 먼저 설계하거나 구현을 잠시 미룰 때 사용합니다. 

status_code = 204

if status_code == 204:
    pass  # 나중에 '내용 없음' 처리를 구현
else:
    print("응답을 처리합니다.")
주석은 Python 문장이 아니므로 빈 블록을 채우지 못합니다. pass는 실행해도 아무 일도 하지 않는 Python 문장입니다.

Conditional Expression

두 값 중 하나를 간단히 선택

참일_때_값 if 조건식 else 거짓일_때_값
일반 조건문 
score = 85

if score >= 60:
    result = "합격"
else:
    result = "불합격"
조건 표현식 
score = 85

result = (
    "합격"
    if score >= 60
    else "불합격"
)

단순한 값 선택에는 조건 표현식이 편리합니다. 실행할 문장이 많거나 조건이 복잡하면 일반 if-else가 더 읽기 쉽습니다.

elif response.status_code == 404:
    print("페이지가 없습니다.")

11 · Interview Points

질문에 “선택 규칙과 예외”까지 답한다

Q1 if-elif-else는 어떤 순서로 실행됩니까?

위에서 아래로 조건을 평가하고, 처음으로 참이 된 블록 하나만 실행합니다. 그 뒤의 elif와 else는 검사하지 않습니다. 모든 조건이 거짓일 때만 else가 실행되며 else는 생략할 수 있습니다.

Q2 독립된 여러 if와 elif의 차이는 무엇입니까?

독립된 if는 각 조건을 모두 평가하므로 여러 블록이 실행될 수 있습니다. 하나의 if-elif-else 사슬은 상호 배타적인 선택을 표현하며 최대 한 블록만 실행됩니다.

Q3 Truthy와 Falsy란 무엇입니까?

조건식에서 객체가 참 또는 거짓으로 해석되는 성질입니다. False, None, 숫자 0, 빈 문자열과 빈 컬렉션은 대표적인 Falsy이고, 대부분의 0이 아닌 숫자와 내용이 있는 객체는 Truthy입니다.

Q4 단락 평가란 무엇이며 왜 유용합니까?

논리식 결과가 확정되면 오른쪽 피연산자를 평가하지 않는 동작입니다. and는 왼쪽이 Falsy일 때, or는 왼쪽이 Truthy일 때 멈춥니다. 불필요한 계산을 줄이고 빈 컬렉션 인덱싱이나 0으로 나누기 같은 오류를 방지할 수 있습니다.

Q5 ==와 is는 어떻게 다릅니까?

==는 두 객체의 값이 같은지 비교하고, is는 두 이름이 같은 객체를 가리키는지 확인합니다. 일반 값 비교에는 ==를 사용하고, None 검사는 관례적으로 is None을 사용합니다.

Q6 pass와 주석의 차이는 무엇입니까?

pass는 실행 가능한 문장이지만 아무 동작도 하지 않습니다. 주석은 인터프리터가 무시하므로 문장이 아니며, 빈 조건문 블록을 채울 수 없습니다.

Q7 복잡한 조건문을 읽기 좋게 만드는 방법은 무엇입니까?

의미 있는 불리언 변수로 조건을 나누고, 괄호로 결합 순서를 보여주며, 겹치는 조건은 구체적인 것부터 배치합니다. 중첩이 깊다면 조건 결합, 조기 반환 또는 작은 함수 분리를 고려합니다.

Q8 Pandas Series를 바로 if에 넣으면 왜 문제가 됩니까?

Series는 여러 개의 불리언 값을 가질 수 있어 전체를 참으로 볼지 거짓으로 볼지 모호하기 때문입니다. 행 필터링은 불리언 마스크를 사용하고, 전체 판단은 .any() 또는 .all()로 의도를 명시합니다.

NOTE 01

오늘의 암기 포인트

  1. if 조건식: 다음 줄은 반드시 들여쓴다.
  2. elif는 위 조건이 거짓일 때만 검사한다.
  3. else에는 조건식을 쓰지 않는다.
  4. 분기 사슬에서는 첫 번째 True 블록 하나만 실행된다.
  5. 독립된 if는 각각 모두 검사한다.
  6. Falsy: False, None, 0, 빈 문자열·컬렉션.
  7. 논리 우선순위: not → and → or.
  8. 값 비교는 ==, None은 is None.
  9. 범위는 0 <= value <= 100처럼 쓸 수 있다.
  10. pass는 아무 일도 하지 않는 유효한 문장이다.
