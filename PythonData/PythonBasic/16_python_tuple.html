01 · Core Concept

튜플은 순서를 유지하면서 요소 구성을 보호하는 불변 시퀀스다

튜플은 리스트처럼 여러 값을 순서대로 보관하고 인덱스로 조회합니다. 그러나 생성이 끝난 뒤에는 요소를 추가·삭제·교체할 수 없습니다. 따라서 좌표, RGB 색상, 함수의 여러 반환값, DB의 한 행처럼 순서와 필드 구성이 고정된 값 묶음을 표현하기 좋습니다.

01

순서가 있다

저장 위치가 유지되며 0부터 시작하는 인덱스로 조회합니다.

point[0]
02

중복을 허용한다

같은 값과 서로 다른 자료형을 한 튜플에 함께 저장할 수 있습니다.

(10, 10, "A", True)
03

구조가 불변이다

요소 추가·삭제·교체는 불가능하며 조회와 전달에 집중합니다.

immutable
04

언패킹할 수 있다

위치에 맞는 여러 변수로 요소를 간결하게 나눌 수 있습니다.

x, y = point

괄호가 아니라 쉼표가 튜플을 만든다

여러 요소

numbers = (10, 20, 30) tuple

괄호를 생략한 10, 20, 30도 튜플입니다.

괄호만 사용

value = (10) int

계산 순서를 나타내는 괄호일 뿐 튜플이 아닙니다.

한 요소 튜플

value = (10,) tuple

요소가 하나일 때도 반드시 쉼표를 붙입니다.

빈 튜플

empty = () tuple

tuple()로도 빈 튜플을 만들 수 있습니다.

핵심 규칙

괄호는 범위를 분명하게 해 주지만, 튜플을 결정하는 핵심 표시는 쉼표입니다. 특히 SQL 매개변수처럼 한 값만 전달할 때 (1,)의 쉼표를 빠뜨리지 않습니다.

인덱싱과 슬라이싱

양수012
값PythonJavaJavaScript
음수-3-2-1
인덱싱은 한 값, 슬라이싱은 새 튜플을 반환 index / slice 
languages = ("Python", "Java", "JavaScript")

print(languages[0])      # Python
print(languages[-1])     # JavaScript
print(languages[1:])     # ('Java', 'JavaScript')
print(languages[::-1])   # ('JavaScript', 'Java', 'Python')

03 · Rules & Choice

조회는 자유롭고 구조 변경은 막히며, 언패킹은 데이터 모양과 맞아야 한다

작업 튜플 결과 또는 대안
인덱싱 가능 data[0]
슬라이싱 가능 새 튜플 반환
포함 여부 가능 value in data
요소 교체 불가능 새 튜플 생성 또는 리스트 선택
추가·삭제 불가능 + 또는 자료형 변환
정렬 직접 불가능 tuple(sorted(data))
검색 가능 index(), count()

리스트와 튜플의 용도 차이

[ ]

LIST · MUTABLE

계속 변하는 데이터 모음

  • 수집 결과를 계속 추가한다.
  • 항목을 수정·삭제·정렬한다.
  • 상품 목록이나 작업 대기열을 관리한다.
( )

TUPLE · IMMUTABLE

구성이 고정된 값 묶음

  • 좌표·색상·행처럼 위치별 의미가 있다.
  • 함수에서 여러 결과를 함께 반환한다.
  • 구조를 변경하지 않겠다는 의도를 표현한다.
생성 후 요소를 바꿔야 하는가? → 예 리스트 → 아니요 튜플

언패킹 규칙

EXACT

기본 언패킹

a, b = (10, 20)

변수와 요소 개수가 정확히 같아야 합니다.

STARRED

별표 언패킹

first, *rest = data

남는 요소를 하나의 리스트로 모읍니다.

NESTED

중첩 언패킹

name, (x, y) = data

왼쪽 변수 구조와 오른쪽 데이터 구조가 같아야 합니다.

IGNORE

사용하지 않는 값

name, score, _ = row

_는 사용하지 않을 값이라는 관례적 표시입니다.

해시 가능성과 딕셔너리 키

사용 가능 locations[(37.5, 126.9)]

튜플과 모든 내부 요소가 해시 가능할 때 키로 사용할 수 있습니다.

사용 불가 data[(1, [2, 3])]

변경 가능한 리스트가 포함되면 unhashable type 오류가 발생합니다.

괄호 함정

(number ** 2 for number in range(5))는 튜플이 아니라 제너레이터 표현식입니다. 튜플 결과가 필요하면 tuple(number ** 2 for number in range(5))로 변환합니다.

def analyze_scores(scores):
    minimum = min(scores)
    maximum = max(scores)
    average = sum(scores) / len(scores)
    return minimum, maximum, average


minimum, maximum, average = analyze_scores((90, 85, 100, 75))

print("최솟값:", minimum)
print("최댓값:", maximum)
print("평균:", average)

06 · Mistakes & Traceback

오류 이름은 실패한 작업의 종류를 알려 준다

마지막 줄 읽기 → 오류 이름 분류 → 자료형 확인 → 인덱스·값·개수 확인 → 문법 또는 자료형 수정
SEMANTIC TRAP

한 요소 튜플의 쉼표 누락

value = (10)

오류는 없지만 결과가 int이므로 의도와 다릅니다.

수정: (10,)
TYPE ERROR

요소 교체 시도

point[0] = 100

tuple은 특정 위치에 값을 다시 저장하지 못합니다.

새 튜플 생성 또는 리스트 선택
ATTRIBUTE ERROR

append() 호출

point.append(30)

튜플에는 구조 변경 메서드가 존재하지 않습니다.

point + (30,)
VALUE ERROR

언패킹 개수 불일치

a, b = (10, 20, 30)

오른쪽 요소가 왼쪽 변수보다 많습니다.

변수 수 조정 또는 별표 사용
INDEX ERROR

범위를 벗어난 위치

(10, 20)[2]

길이가 2이므로 유효한 양수 인덱스는 0과 1입니다.

len()으로 길이 확인
KEY ERROR

없는 튜플 키 조회

locations[(35.1, 129.0)]

딕셔너리에 해당 좌표 키가 없다는 뜻입니다.

dict.get() 사용

대표 Traceback 해석

TypeError: 'tuple' object does not support item assignment

튜플의 특정 인덱스에 새 값을 저장하려 했습니다. 기존 튜플은 불변이므로 새 튜플을 만들거나 리스트를 사용합니다.

AttributeError: 'tuple' object has no attribute 'append'

append()는 리스트 메서드입니다. type()으로 현재 객체의 자료형을 먼저 확인합니다.

ValueError: too many values to unpack

오른쪽 요소가 왼쪽 변수보다 많습니다. 데이터 구조를 출력하고 변수 수 또는 별표 위치를 조정합니다.

ValueError: not enough values to unpack

오른쪽 요소가 왼쪽 변수보다 적습니다. DB 조회 열이나 중첩 구조가 예상과 같은지 확인합니다.

TypeError: cannot unpack non-iterable NoneType object

fetchone() 또는 선택 결과가 None인데 바로 언패킹했습니다. 먼저 is None으로 검사합니다.

TypeError: unhashable type: 'list'

딕셔너리 키로 쓴 튜플 안에 리스트가 포함되었습니다. 모든 내부 요소도 해시 가능해야 합니다.

08 · Interview Points

문법 이름보다 선택 이유와 실행 결과를 설명한다

Q1. 튜플이란 무엇인가요?

여러 값을 순서대로 저장하는 불변 시퀀스입니다. 인덱싱과 슬라이싱은 가능하지만 요소의 추가·삭제·교체는 할 수 없습니다.

Q2. 리스트와 튜플의 가장 큰 차이는 무엇인가요?

리스트는 변경 가능하고 튜플은 요소 구성이 불변입니다. 계속 변하는 데이터에는 리스트, 고정 구조에는 튜플을 선택합니다.

Q3. 요소 하나인 튜플은 어떻게 만드나요?

(10,)처럼 값 뒤에 쉼표를 붙입니다. 튜플을 만드는 핵심 문법은 괄호가 아니라 쉼표입니다.

Q4. 패킹과 언패킹은 무엇인가요?

패킹은 여러 값을 하나의 튜플로 묶는 것이고, 언패킹은 그 요소를 위치에 맞는 여러 변수로 나누는 것입니다.

Q5. 튜플 안의 리스트는 변경할 수 있나요?

튜플 슬롯을 다른 객체로 교체할 수는 없지만, 슬롯이 가리키는 기존 리스트 내부는 변경할 수 있습니다.

Q6. 함수에서 여러 값을 반환하면 실제 결과는 무엇인가요?

쉼표로 나열된 값들이 튜플로 패킹되어 반환됩니다. 호출 위치에서 한 변수로 받거나 여러 변수로 언패킹할 수 있습니다.

Q7. 튜플을 딕셔너리 키로 사용할 수 있나요?

튜플과 내부의 모든 요소가 해시 가능할 때 사용할 수 있습니다. 리스트가 포함된 튜플은 키가 될 수 없습니다.

Q8. NumPy의 shape와 튜플은 어떤 관계인가요?

shape는 각 차원의 크기를 담은 튜플입니다. 2차원 배열이라면 rows, columns = array.shape처럼 언패킹할 수 있습니다.

시험·면접·실습 전 10문장

  1. 튜플은 순서가 있는 불변 시퀀스다.
  2. 튜플 생성의 핵심은 괄호가 아니라 쉼표다.
  3. (10)은 정수이고 (10,)은 튜플이다.
  4. 인덱싱은 한 값, 슬라이싱은 새 튜플을 반환한다.
  5. 요소 추가·삭제·교체는 불가능하다.
  6. +와 *는 새 튜플을 만든다.
  7. 패킹은 묶고 언패킹은 변수로 나눈다.
  8. 별표 언패킹 결과는 리스트다.
  9. 함수의 여러 반환값은 튜플로 패킹된다.
  10. shape는 차원 크기를 담은 튜플이다.
