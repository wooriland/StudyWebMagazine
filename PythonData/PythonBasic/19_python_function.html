01 · Core Concept

함수는 반복 작업을 의미 있는 이름으로 묶고 입력과 결과의 통로를 만든다

함수는 단순히 코드 길이를 줄이는 문법이 아닙니다. 하나의 작업을 독립된 단위로 만들고, 매개변수로 입력을 받으며, 지역변수로 중간 과정을 표현하고, 반환값으로 다른 코드와 연결합니다. 좋은 함수는 이름만 읽어도 무엇을 하는지 알 수 있고 입력과 결과의 관계가 분명합니다.

함수의 네 가지 형식

FORM 01 · INPUT × / EXPLICIT RETURN ×

DOCSTRING

PASS

아직 구현하지 않은 블록의 자리 채우기

def save_data():
    pass

pass는 종료도 반환도 하지 않습니다. 아무 작업 없이 다음 문장으로 진행하며 함수 끝에서는 None이 반환됩니다.

지역 범위와 원본 객체 변경

LOCAL BINDING

함수 안팎의 같은 이름은 다른 범위일 수 있다

message = "함수 밖"

def make_message(name):
    message = f"{name}님 환영합니다."
    return message

매개변수와 함수 안에서 대입한 이름은 기본적으로 현재 호출의 지역 범위에 속합니다.

SHARED MUTABLE OBJECT

지역 이름이라고 객체가 복사되는 것은 아니다

def add_item(items):
    items.append("python")

languages = ["java"]
add_item(languages)

외부 이름과 지역 매개변수가 같은 리스트를 가리키면 append() 결과가 원본에서도 보입니다.

COPY & RETURN

원본을 보존하려면 복사본을 반환한다

def add_item(items):
    copied = items.copy()
    copied.append("python")
    return copied

함수의 계약에 원본 변경 여부를 분명히 하고 필요하면 복사본을 처리합니다.

EXAMPLE 07 · INTEGRATED

학생 점수를 분석해 딕셔너리 반환

빈 입력 처리, 평균 계산, 지역변수, 불리언 판정, 딕셔너리 반환을 연결합니다.

def analyze_student(name, scores):
    """학생 이름과 점수를 받아 분석 결과를 반환한다."""
    if not scores:
        return {
            "name": name,
            "average": 0,
            "passed": False
        }

    average = sum(scores) / len(scores)
    passed = average >= 60

    result = {
        "name": name,
        "average": average,
        "passed": passed
    }

    return result


student = analyze_student("민지", [90, 80, 100])
print(student)

08 · Interview Points

문법 암기보다 호출 시점의 실행과 값의 이동을 설명한다

Q1. 함수란 무엇인가요?

특정 작업을 수행하는 코드를 하나의 이름으로 묶은 것입니다. 반복 제거뿐 아니라 책임 분리, 재사용, 테스트와 유지보수를 위해 사용합니다.

Q2. 함수 정의와 호출의 차이는 무엇인가요?

def 문은 함수 객체를 만들고 이름에 연결합니다. 함수 이름 뒤에 괄호를 붙인 호출은 새 지역 프레임에서 함수 본문을 실행합니다.

Q3. def 문이 실행되면 본문도 바로 실행되나요?

아닙니다. 함수 객체만 준비되고 본문은 해당 함수가 호출될 때 실행됩니다.

Q4. 매개변수와 인수의 차이는 무엇인가요?

매개변수는 정의에서 전달값을 받을 지역 이름이고, 인수는 호출할 때 전달하는 실제 표현식과 값입니다.

Q5. print()와 return의 차이는 무엇인가요?

print()는 화면에 표시하고, return은 객체를 호출 위치로 전달하면서 현재 함수를 즉시 종료합니다.

Q6. 명시적인 return이 없으면 무엇을 반환하나요?

함수 끝에 도달하면 None을 반환합니다. 따라서 명시적 반환이 없는 함수도 실제로는 객체 하나를 반환합니다.

Q7. return a, b는 몇 개의 객체를 반환하나요?

쉼표에 의해 (a, b)로 패킹된 튜플 하나를 반환하며 호출한 쪽에서 언패킹할 수 있습니다.

Q8. 매개변수도 지역변수인가요?

매개변수는 호출할 때 전달된 객체를 가리키는 지역 이름입니다. 호출마다 별도의 지역 실행 공간이 만들어집니다.

Q9. 리스트를 함수에 전달하면 자동으로 복사되나요?

아닙니다. 외부 이름과 지역 매개변수가 같은 리스트를 가리킬 수 있어 함수 안의 변경이 원본에 보일 수 있습니다.

Q10. 독스트링이란 무엇인가요?

모듈·클래스·함수 본문의 첫 문자열 문장으로 작성하는 문서화 문자열이며 __doc__와 help()로 확인할 수 있습니다.

Q11. pass의 역할은 무엇인가요?

문법적으로 코드 블록이 필요하지만 아직 구현할 내용이 없을 때 쓰는 자리 채우기 문장입니다. 종료나 반환을 의미하지 않습니다.

Q12. function과 function()은 어떻게 다른가요?

앞은 함수 객체를 가리키고 뒤는 함수를 호출합니다. 스케줄러나 다른 고차 함수에 전달할 때는 괄호 없이 함수 객체를 넘깁니다.

Q13. 좋은 함수의 특징은 무엇인가요?

하나의 분명한 책임을 가지며, 입력은 매개변수로 받고, 결과와 부수효과가 명확하며, 이름과 독스트링으로 계약을 이해할 수 있어야 합니다.

  9. 명시적 return이 없으면 None이다.
  10. return a, b는 튜플 하나다.
  11. print()는 표시하고 return은 전달한다.

  13. 독스트링은 함수 본문의 첫 문자열 문장이다.
