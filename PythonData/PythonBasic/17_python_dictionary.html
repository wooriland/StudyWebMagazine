01 · Core Concept

딕셔너리는 의미 있는 키와 값을 연결하는 변경 가능한 매핑이다

리스트가 위치 인덱스로 값을 관리한다면 딕셔너리는 키로 값을 관리합니다. 현대 Python의 딕셔너리는 키가 삽입된 순서를 보존하지만, 리스트처럼 위치 번호로 조회하는 시퀀스가 아닙니다. 키는 중복될 수 없고 해시 가능해야 하며, 값에는 거의 모든 Python 객체를 저장할 수 있습니다.

01

Key → Value

하나의 키가 하나의 값을 가리키며 키로 필요한 데이터를 찾습니다.

student["score"]
02

키는 고유하다

같은 키를 다시 저장하면 새로운 키가 생기지 않고 값이 덮어써집니다.

{"a": 1, "a": 2}
03

변경할 수 있다

키-값 쌍을 추가·수정·삭제하며 현재 상태를 계속 갱신할 수 있습니다.

mutable mapping
04

삽입 순서를 지킨다

반복할 때 키가 들어온 순서를 따르지만 위치 인덱싱은 하지 않습니다.

for key in data

{key: value} 문법 해부

{"name": "민지", "score": 90}
중괄호딕셔너리 범위 Key값을 찾는 이름표 콜론키와 값을 연결 Value실제 저장 데이터 쉼표다음 쌍과 구분

LITERAL

{"name": "민지"}

가장 읽기 쉽고 일반적인 생성 방법입니다.

EMPTY

{} / dict()

빈 중괄호는 빈 집합이 아니라 빈 딕셔너리입니다.

KEYWORD

dict(name="민지")

키가 문자열 식별자일 때 따옴표 없이 작성합니다.

PAIRS

dict([("name", "민지")])

각 반복 요소는 키와 값 두 개를 가져야 합니다.

ZIP

dict(zip(keys, values))

같은 위치의 키와 값을 쌍으로 연결합니다.

FROMKEYS

dict.fromkeys(keys, None)

여러 키에 같은 초기값을 지정합니다.

키와 값의 규칙

KEY · HASHABLE

키는 고유하고 해시 가능해야 한다

가능str · int · tuple
불가능list · dict · set

튜플도 내부의 모든 요소가 해시 가능할 때만 키가 됩니다.

VALUE · ANY OBJECT

값에는 모든 객체를 저장할 수 있다

number · str · list · tuple · dict

여러 키가 같은 값을 가져도 되며 중첩 딕셔너리도 값으로 저장할 수 있습니다.

현대 Python 기준

딕셔너리를 단순히 “순서가 없는 자료형”으로 외우지 않습니다. 삽입 순서는 보존하지만 data[0]처럼 위치로 찾는 것이 아니라 data["name"]처럼 키로 찾는 매핑이라고 이해합니다.

03 · Rules & Choice

키가 없을 가능성과 데이터 변경 목적에 맞는 메서드를 선택한다

목적 문법·메서드 키가 없을 때 원본 변경
반드시 있는 값 조회 data[key] KeyError 아니요
안전한 값 조회 get(key, default) 기본값 반환 아니요
없는 키 초기화 setdefault(key, default) 추가 후 반환 예
한 항목 추가·수정 data[key] = value 새 항목 추가 예
여러 항목 추가·수정 update(...) 새 항목 추가 예
삭제 후 값 받기 pop(key, default) 기본값 또는 오류 예

삭제 메서드 선택

DEL

del data[key]

키를 반드시 삭제하고 반환값은 사용하지 않습니다.

POP

data.pop(key, default)

키를 삭제하면서 삭제된 값을 받아야 할 때 사용합니다.

POPITEM

data.popitem()

가장 나중에 삽입한 키-값 쌍을 튜플로 반환합니다.

CLEAR

data.clear()

딕셔너리 객체는 유지하고 모든 항목만 제거합니다.

뷰 객체는 현재 딕셔너리를 비춘다

student = {"name": "민지"}
keys_view = student.keys()

student["score"] = 90
print(keys_view)
처음dict_keys(['name']) → 항목 추가 후 현재dict_keys(['name', 'score'])

keys()·values()·items()는 복사 목록이 아니라 현재 상태를 반영하는 뷰입니다.

반복 중 크기 변경 금지

WRONG

for key in scores:
    if scores[key] < 60:
        del scores[key]
RuntimeError

반복 중인 원본의 키 개수를 변경했습니다.

SAFE COPY OF KEYS

for key in list(scores):
    if scores[key] < 60:
        del scores[key]
정상 실행

키 목록을 별도로 만들어 반복합니다.

COMPREHENSION

scores = {
    name: score
    for name, score in scores.items()
    if score >= 60
}
새 딕셔너리 생성

조건에 맞는 항목만 다시 구성합니다.

참조·얕은 복사·깊은 복사

REFERENCE

backup = original

두 변수가 같은 딕셔너리를 가리킵니다.

SHALLOW COPY

backup = original.copy()

바깥 딕셔너리는 새 객체지만 내부 가변 객체는 공유할 수 있습니다.

DEEP COPY

backup = deepcopy(original)

중첩된 리스트와 딕셔너리까지 재귀적으로 복사합니다.

fromkeys() 가변 기본값 주의 
data = dict.fromkeys(["a", "b"], [])
data["a"].append(10)

print(data)
# {'a': [10], 'b': [10]}

두 키가 같은 리스트를 공유합니다. 독립된 리스트가 필요하면 {key: [] for key in keys}를 사용합니다.

06 · Mistakes & Traceback

오류 이름에서 문법·키 부재·해시·반복 변경 문제를 구별한다

Traceback 마지막 줄 → 오류 이름 → 현재 딕셔너리 출력 → 키·자료형 확인 → 메서드 선택 수정
SYNTAX ERROR

콜론·쉼표 누락

{"name" "민지"}

키와 값 사이에는 콜론, 다음 쌍 사이에는 쉼표가 필요합니다.

{"name": "민지"}
KEY ERROR

없는 키 대괄호 조회

student["email"]

현재 딕셔너리에 해당 키가 없습니다.

student.get("email")
TYPE ERROR

가변 객체를 키로 사용

{[1, 2]: "value"}

리스트는 변경 가능하여 해시할 수 없습니다.

{(1, 2): "value"}
VALUE ERROR

dict() 쌍 길이 오류

dict([("a", 1, 2)])

각 반복 요소는 정확히 키와 값 두 개여야 합니다.

dict([("a", 1)])
ATTRIBUTE ERROR

리스트 메서드 호출

student.append(...)

딕셔너리에는 append()가 없습니다.

student[key] = value
RUNTIME ERROR

반복 중 크기 변경

for key in data: del data[key]

반복 대상의 키 개수를 실행 중 변경했습니다.

for key in list(data):

대표 Traceback 해석

KeyError: 'score'

현재 딕셔너리에 score 키가 없습니다. data.keys()와 "score" in data를 확인하고 선택적 키라면 get()을 사용합니다.

TypeError: unhashable type: 'list'

변경 가능한 리스트를 키로 사용했습니다. 키의 의미가 고정된 좌표라면 해시 가능한 튜플로 바꿀 수 있습니다.

ValueError: dictionary update sequence element #0 has length 3; 2 is required

dict() 또는 update()에 전달한 요소가 키와 값 두 개가 아니라 세 개입니다.

RuntimeError: dictionary changed size during iteration

반복 중 원본의 키를 추가하거나 삭제했습니다. 키 목록을 복사하거나 새 딕셔너리를 만듭니다.

AttributeError: 'dict' object has no attribute 'append'

append()는 리스트 메서드입니다. 딕셔너리에는 대괄호 할당 또는 update()를 사용합니다.

TypeError: 'NoneType' object is not subscriptable

get()이 반환한 None에 다시 대괄호를 사용했을 가능성이 있습니다. 중첩 경로마다 값을 확인합니다.

08 · Interview Points

메서드 이름보다 키 규칙과 선택 이유를 설명한다

Q1. 딕셔너리란 무엇인가요?

키와 값을 한 쌍으로 저장하는 변경 가능한 매핑 자료형입니다. 위치가 아니라 키로 값을 조회합니다.

Q2. 현대 Python 딕셔너리는 순서가 있나요?

키가 삽입된 순서를 보존합니다. 하지만 리스트처럼 위치 인덱스로 접근하는 시퀀스가 아니라 키로 조회하는 매핑입니다.

Q3. 리스트를 딕셔너리 키로 사용할 수 없는 이유는 무엇인가요?

딕셔너리 키는 해시 가능해야 하는데 리스트는 내용이 변경될 수 있어 해시할 수 없기 때문입니다.

Q4. 대괄호 조회와 get()의 차이는 무엇인가요?

대괄호 조회는 키가 없으면 KeyError를 발생시키고, get()은 None 또는 지정한 기본값을 반환합니다.

Q5. get()과 setdefault()의 차이는 무엇인가요?

get()은 원본을 바꾸지 않지만, setdefault()는 키가 없을 때 기본값을 실제로 추가합니다.

Q6. update()는 어떻게 동작하나요?

기존 키의 값은 수정하고 없는 키는 추가합니다. 여러 키-값 쌍을 한 번에 처리할 수 있습니다.

Q7. keys()·values()·items()는 무엇을 반환하나요?

현재 딕셔너리 상태를 반영하는 뷰 객체를 반환합니다. items()의 각 요소는 키와 값의 튜플입니다.

Q8. 얕은 복사와 깊은 복사의 차이는 무엇인가요?

copy()는 바깥 딕셔너리만 복사해 내부 가변 객체를 공유할 수 있고, deepcopy()는 중첩 객체까지 재귀적으로 복사합니다.

Q9. JSON과 딕셔너리는 같은 것인가요?

JSON은 문자열 기반 데이터 교환 형식이고 딕셔너리는 Python 객체입니다. JSON 객체를 디코딩하면 보통 딕셔너리가 되지만 JSON 배열은 리스트가 됩니다.

Q10. **dictionary는 무엇인가요?

딕셔너리의 키와 값을 함수의 키워드 인수로 언패킹하는 문법이며 키가 함수 매개변수 이름과 맞아야 합니다.

09 · Final Check

실행 전에 키의 존재·해시 가능성·변경 목적·중첩 경로를 점검한다

  • 01 키와 값 사이에 콜론이 있는가?

  • 06 여러 항목 추가·수정에는 update()를 사용했는가?

MEMORY · 오늘의 암기 포인트

시험·면접·실습 전 12문장

  1. 딕셔너리는 키와 값을 연결하는 변경 가능한 매핑이다.
  2. 현대 Python 딕셔너리는 삽입 순서를 보존한다.
  3. 키는 중복될 수 없고 해시 가능해야 한다.
  4. 값에는 모든 객체를 저장할 수 있다.
  5. 대괄호 조회는 키가 없으면 KeyError다.
  6. get()은 키가 없으면 기본값을 반환한다.
  7. 대괄호 할당은 없는 키를 추가하고 기존 키를 수정한다.
  8. setdefault()는 키가 없을 때만 추가한다.
  9. update()는 여러 항목을 추가·수정한다.
  10. items()는 키-값 튜플을 제공한다.
  11. 딕셔너리를 직접 반복하면 키가 나온다.
  12. copy()는 얕은 복사다.
