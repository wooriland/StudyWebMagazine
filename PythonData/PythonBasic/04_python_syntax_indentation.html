이 단원의 중심 질문

Python은 중괄호 없이 코드의 시작·소속·종료를 어떻게 구분할까요?

Python은 복합문 헤더 끝의 콜론으로 코드 블록의 시작을 알리고, 같은 깊이의 들여쓰기로 블록에 속한 코드를 묶습니다. 다시 바깥 수준으로 내어쓰기하면 현재 코드 블록이 끝납니다.

학습 목표

  • Python이 변수·함수·키워드의 대소문자를 구분한다는 것을 설명할 수 있습니다.
  • 물리적 줄과 논리적 명령문의 차이를 구분할 수 있습니다.

  • 긴 표현식을 괄호 안에서 여러 줄로 작성할 수 있습니다.
  • 복합문 헤더의 콜론과 코드 블록의 관계를 이해합니다.
  • 들여쓰기와 내어쓰기로 코드의 소속과 블록 종료를 구분할 수 있습니다.
  • 공백 4칸을 권장하는 이유를 설명할 수 있습니다.
  • 탭 문자와 공백 문자의 차이를 이해하고 혼용 문제를 해결할 수 있습니다.
  • SyntaxError, IndentationError, TabError를 구분하여 읽을 수 있습니다.

01 · Core Concept

Python에서 줄바꿈, 콜론과 들여쓰기는 단순한 화면 정렬이 아닙니다. Python 인터프리터가 명령문의 끝과 코드 블록의 소속을 판단하는 문법 요소입니다.

09 · Python Example

다음 코드는 대소문자, 줄바꿈, 콜론, 여러 줄 리스트, 여러 줄 함수 호출, 중첩 블록과 내어쓰기를 함께 사용합니다.

from __future__ import annotations


def calculate_average(
    scores: list[int],
) -> float:
    """점수 목록의 평균을 계산한다."""

    if not scores:
        return 0.0

    return sum(scores) / len(scores)


def decide_grade(
    average: float,
) -> tuple[str, str]:
    """평균 점수에 맞는 등급과 메시지를 반환한다."""

    if average >= 90:
        grade = "A"
        message = "매우 우수합니다."
    elif average >= 80:
        grade = "B"
        message = "학습 목표를 달성했습니다."
    elif average >= 70:
        grade = "C"
        message = "기본 목표를 달성했습니다."
    else:
        grade = "D"
        message = "복습이 필요합니다."

    return grade, message


def print_report(
    student_name: str,
    scores: list[int],
) -> None:
    """학생의 점수 보고서를 출력한다."""

    average = calculate_average(scores)
    grade, message = decide_grade(average)

    print("=" * 50)
    print("학생 성적 보고서")
    print("=" * 50)

    print("학생:", student_name)
    print("점수:", scores)
    print("과목 수:", len(scores))
    print("합계:", sum(scores))
    print("평균:", average)
    print("등급:", grade)
    print("평가:", message)

    print("=" * 50)
    print("보고서 생성 완료")


def main() -> None:
    """프로그램의 기본 실행 흐름을 담당한다."""

    student_name = "김길동"

    scores = [
        85,
        92,
        78,
    ]

    print_report(
        student_name,
        scores,
    )


if __name__ == "__main__":
    main()

코드 실행 순서

11 · Common Mistakes

초보자가 자주 하는 문법·들여쓰기 실수

01

대소문자를 임의로 바꿉니다

student_name과 Student_Name은 서로 다른 이름입니다.

02

논리값을 소문자로 작성합니다

Python에서는 True와 False로 작성합니다.

03

모든 줄 끝에 세미콜론을 붙입니다

Python은 일반적으로 줄바꿈으로 명령문의 끝을 구분합니다.

04

여러 명령문을 한 줄에 압축합니다

한 줄에 하나의 명령문을 작성하는 것이 읽고 수정하기 쉽습니다.

05

복합문 헤더의 콜론을 빠뜨립니다

if, for, def 헤더 끝에는 콜론이 필요합니다.

06

콜론 다음 줄을 들여쓰지 않습니다

복합문 블록 내부 코드는 공백 4칸을 기준으로 들여씁니다.

07

블록이 없는데 코드를 들여씁니다

블록 헤더 없이 들여쓰기하면 unexpected indent가 발생할 수 있습니다.

08

같은 블록의 깊이를 다르게 작성합니다

같은 블록의 명령문은 같은 수의 공백을 사용해야 합니다.

09

탭과 공백을 혼용합니다

화면에서 같아 보여도 실제 문자가 달라 TabError가 발생할 수 있습니다.

10

if·elif·else의 수준을 다르게 맞춥니다

세 헤더는 같은 들여쓰기 수준에 있어야 합니다.

11

모든 콜론을 블록 시작으로 생각합니다

딕셔너리와 슬라이싱의 콜론은 다른 문법적 역할을 합니다.

12

빈 함수나 조건문을 그대로 둡니다

아직 구현하지 않았다면 블록 내부에 pass를 작성합니다.

14 · Interview

면접 포인트

Python에서 들여쓰기가 중요한 이유는 무엇입니까?

Python은 중괄호 대신 들여쓰기로 코드 블록을 구분합니다. 따라서 들여쓰기는 단순한 가독성 요소가 아니라 조건문, 반복문, 함수 등에 속한 코드의 범위를 결정하는 문법입니다.

Python에서 권장하는 들여쓰기 크기는 얼마입니까?

일반적으로 한 단계당 공백 4칸을 권장합니다. 같은 블록에서는 동일한 들여쓰기 깊이를 사용하고 탭과 공백을 혼용하지 않아야 합니다.

Python에서 세미콜론은 필수입니까?

필수가 아닙니다. Python은 기본적으로 줄바꿈으로 명령문의 끝을 구분합니다. 세미콜론으로 한 줄에 여러 단순문을 작성할 수 있지만 일반적으로 권장하지 않습니다.

Python의 코드 블록은 어떻게 시작하고 끝납니까?

복합문 헤더 끝에 콜론을 작성하고 다음 줄을 들여써서 코드 블록을 시작합니다. 다시 바깥 수준으로 내어쓰기하면 해당 블록이 끝납니다.

SyntaxError와 IndentationError의 차이는 무엇입니까?

SyntaxError는 Python 문법 전체와 관련된 오류입니다. IndentationError는 그중에서도 들여쓰기 구조가 잘못된 경우 발생하는 하위 오류입니다.

TabError는 무엇입니까?

같은 들여쓰기 구조에서 탭 문자와 공백 문자를 일관되지 않게 혼용했을 때 발생할 수 있는 오류입니다. TabError는 IndentationError의 하위 오류입니다.

expected an indented block은 무엇을 의미합니까?

콜론으로 복합문 블록을 시작했지만 다음 줄에 들여쓰기된 명령문이 없다는 뜻입니다. 아직 구현할 내용이 없다면 pass를 사용할 수 있습니다.

unexpected indent는 무엇을 의미합니까?

현재 위치에서 새로운 블록이 시작되지 않았는데 불필요하게 들여쓰기된 코드가 등장했다는 뜻입니다.

한 명령문을 여러 줄로 작성하려면 어떻게 합니까?

소괄호, 대괄호 또는 중괄호 안에서 자연스럽게 여러 줄로 작성할 수 있습니다. 역슬래시도 가능하지만 괄호 방식이 더 안전하고 읽기 좋습니다.

모든 콜론이 코드 블록을 시작합니까?

아닙니다. 복합문 헤더 끝의 콜론은 코드 블록을 시작하지만, 딕셔너리에서는 Key와 Value를 구분하고 슬라이싱에서는 범위를 구분합니다.

들여쓰기가 실행 결과에도 영향을 줍니까?

그렇습니다. 명령문이 조건문이나 반복문 안에 있는지 바깥에 있는지를 들여쓰기가 결정하므로, 같은 코드라도 들여쓰기 위치에 따라 실행 여부와 횟수가 달라집니다.

물리적 줄과 논리적 명령문의 차이는 무엇입니까?

물리적 줄은 편집기에서 실제로 보이는 한 줄입니다. 논리적 명령문은 Python이 하나의 명령으로 처리하는 단위입니다. 괄호 안에서는 여러 물리적 줄이 하나의 논리적 명령문이 될 수 있습니다.

pass는 어떤 역할을 합니까?

아무 작업도 수행하지 않는 유효한 Python 명령문입니다. 아직 구현하지 않은 조건문, 함수 또는 클래스의 코드 블록을 문법적으로 유지할 때 사용합니다.

오늘의 암기 포인트

  • Python은 대소문자를 구분합니다.
  • name, Name, NAME은 서로 다른 이름입니다.
  • Python은 기본적으로 줄바꿈으로 명령문의 끝을 구분합니다.
  • 세미콜론은 필수가 아니며 일반적으로 사용하지 않습니다.
  • 긴 명령문은 괄호 안에서 여러 줄로 작성합니다.
  • 복합문 헤더 끝에는 콜론을 작성합니다.
  • 들여쓰기는 코드 블록의 소속을 결정하는 Python 문법입니다.
  • 들여쓰기 한 단계에는 공백 4칸을 권장합니다.
  • 같은 블록은 같은 들여쓰기 수준을 사용합니다.
  • 탭 문자와 공백을 혼용하지 않습니다.
