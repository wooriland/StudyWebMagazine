  • 대표적인 오류 메시지의 종류와 기본적인 해석 순서를 익힙니다.
  • 파이썬 기초가 데이터베이스·웹크롤링· 데이터 분석·시각화로 어떻게 이어지는지 이해합니다.

06 · Python Example

전체 과정을 미리 연결하는 코드

다음 예제는 아직 배우지 않은 문법도 포함하고 있습니다. 지금은 코드를 모두 외우지 않고 각 문법이 어떤 역할을 하는지만 확인합니다. 

students: list[dict[str, object]] = [
    {"name": "김길동", "score": 85},
    {"name": "이길동", "score": 72},
    {"name": "박길동", "score": 91}
]


def get_result(score: int) -> str:
    """점수를 받아 학습 결과를 반환한다."""

    if score >= 80:
        return "통과"

    return "재학습"


def print_student_result(
    student: dict[str, object]
) -> None:
    """학생 한 명의 결과를 출력한다."""

    name = student["name"]
    score = student["score"]

    if not isinstance(score, int):
        raise TypeError("score는 정수여야 합니다.")

    result = get_result(score)

    print(
        "이름: {0}, 점수: {1}, 결과: {2}".format(
            name,
            score,
            result
        )
    )


for student in students:
    try:
        print_student_result(student)

    except (KeyError, TypeError) as error:
        print("학생 데이터 처리 실패:", error)

실행 결과

이름: 김길동, 점수: 85, 결과: 통과
이름: 이길동, 점수: 72, 결과: 재학습
이름: 박길동, 점수: 91, 결과: 통과
종합 예제와 각 기초 단원의 연결
코드 역할 연결 개념
students = [...] 여러 학생 데이터를 저장 리스트
{"name": ..., "score": ...} 학생의 속성과 값을 저장 딕셔너리
def get_result() 판정 기능을 정의 함수
score: int 입력값의 의도를 표시 타입 힌트
if score >= 80 점수를 비교하고 분기 연산자·조건문
for student in students 학생을 한 명씩 처리 반복문
student["score"] Key를 이용해 값을 조회 딕셔너리
try · except 처리 실패 상황에 대응 예외 처리

코드 실행 순서

  1. 학생 정보를 담은 리스트와 딕셔너리를 생성합니다.
  2. 점수를 판정하는 get_result() 함수를 정의합니다.
  3. 학생 한 명을 출력하는 함수를 정의합니다.
  4. for문으로 학생을 한 명씩 꺼냅니다.
  5. 점수를 확인하고 통과 여부를 반환합니다.
  6. 결과 문자열을 완성하여 콘솔에 출력합니다.
  7. 잘못된 학생 데이터가 있으면 예외를 처리합니다.

08 · Common Mistakes

파이썬 기초에서 자주 하는 실수

01

Python과 PyCharm을 같은 것으로 생각합니다

Python은 언어와 실행 환경이고, PyCharm은 Python을 사용하는 IDE입니다.

02

모든 문법을 먼저 암기하려 합니다

문법의 목적을 이해하고 실행 결과를 확인하면서 반복적으로 사용하는 편이 좋습니다.

03

들여쓰기를 디자인 요소로 생각합니다

Python에서 들여쓰기는 코드 블록을 구분하는 실제 문법입니다.

04

input()이 숫자를 반환한다고 생각합니다

input()의 결과는 문자열이므로 숫자 계산 전 형 변환이 필요합니다.

05

리스트와 딕셔너리 접근법을 혼동합니다

리스트는 위치 인덱스, 딕셔너리는 Key로 값에 접근합니다.

06

print와 return을 같은 것으로 생각합니다

print는 화면 출력이고, return은 함수 호출 위치로 값을 돌려줍니다.

07

함수를 정의하면 바로 실행된다고 생각합니다

def는 함수를 정의하며, 실제 실행을 위해서는 함수를 호출해야 합니다.

08

패키지를 다른 Python 환경에 설치합니다

패키지를 설치한 인터프리터와 IDE가 사용하는 인터프리터가 같아야 합니다.

12 · Interview

면접 포인트

Python 인터프리터와 PyCharm의 차이는 무엇인가요?

Python 인터프리터는 Python 코드를 실제로 읽고 실행하는 프로그램입니다. PyCharm은 코드를 작성하고 실행하고 디버깅하도록 돕는 IDE이며, 선택된 Python 인터프리터를 사용합니다.

REPL과 Python 스크립트는 무엇이 다른가요?

REPL은 코드를 한 줄씩 입력해 결과를 즉시 확인하는 대화형 실행 방식입니다. 스크립트는 여러 줄의 코드를 .py 파일에 저장한 뒤 실행하는 방식입니다.

Python이 동적 타이핑 언어라는 것은 무엇인가요?

변수를 선언할 때 자료형을 고정하지 않고 실행 중 변수 이름이 가리키는 객체에 따라 자료형이 결정된다는 의미입니다.

리스트와 튜플은 무엇이 다른가요?

둘 다 순서가 있는 자료구조입니다. 리스트는 요소를 추가·수정·삭제할 수 있지만, 튜플은 생성 후 요소를 변경할 수 없습니다.

for문과 while문은 어떻게 구분하나요?

for문은 반복 가능한 객체에서 값을 하나씩 꺼내 처리할 때 주로 사용합니다. while문은 특정 조건이 참인 동안 반복할 때 사용합니다.

매개변수와 인수의 차이는 무엇인가요?

매개변수는 함수를 정의할 때 입력값을 받을 변수이고, 인수는 함수를 호출할 때 실제로 전달하는 값입니다.

print와 return은 무엇이 다른가요?

print는 값을 화면에 출력합니다. return은 함수의 처리 결과를 호출 위치로 반환하며, 반환값은 다른 연산에 다시 사용할 수 있습니다.

모듈과 패키지의 차이는 무엇인가요?

모듈은 함수, 변수, 클래스 등을 담은 하나의 Python 파일입니다. 패키지는 관련된 여러 모듈을 디렉터리 단위로 묶은 구조입니다.

예외 처리를 사용하는 이유는 무엇인가요?

실행 중 예상 가능한 오류가 발생했을 때 프로그램이 무조건 종료되지 않도록 대응하고, 오류 처리와 정리 작업을 분리하기 위해 사용합니다.

타입 힌트는 자료형을 강제하나요?

기본적으로 런타임 자료형을 강제하지 않습니다. 코드의 입력과 반환 의도를 표현하며, mypy나 pyright 같은 정적 검사 도구와 함께 사용합니다.

오늘의 암기 포인트

  • Python 코드는 Python 인터프리터가 실행합니다.
  • 변수는 Python 객체를 가리키는 이름입니다.
  • 조건문은 실행할 코드를 선택하고, 반복문은 같은 작업을 여러 데이터에 적용합니다.
  • 리스트는 순서가 있고 수정할 수 있으며, 딕셔너리는 Key와 Value로 데이터를 저장합니다.
  • 함수는 반복되는 작업을 재사용 가능한 코드로 묶습니다.
  • 모듈은 하나의 Python 파일이고, 패키지는 관련 모듈의 묶음입니다.
  • 예외 처리는 실행 실패 상황에 대응하며, 타입 힌트는 코드의 자료형 의도를 표현합니다.

환경 → 값 → 흐름 → 자료구조 → 함수 → 모듈 → 예외 → 타입

헷갈리기 쉬운 개념

Python과 PyCharm
Python은 언어와 실행 환경이고, PyCharm은 Python 개발을 돕는 IDE입니다.
변수와 객체
변수는 값 자체라기보다 Python 객체를 가리키는 이름입니다.
print와 return
print는 출력하고, return은 함수 결과를 호출 위치로 전달합니다.
Iterable과 Iterator
Iterable은 반복 가능한 객체이고, Iterator는 값을 하나씩 꺼낼 수 있는 객체입니다.
문법 오류와 실행 중 오류
문법 오류는 코드를 해석할 수 없는 상태이고, 실행 중 오류는 문법은 맞지만 실행 과정에서 실패한 상태입니다.
