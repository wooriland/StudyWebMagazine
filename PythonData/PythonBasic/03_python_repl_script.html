Python Basics · Lesson 03

REPL과 Python 스크립트 실행

Python과 대화하듯 한 줄씩 코드를 실험하는 REPL과, 여러 줄의 코드를 .py 파일로 저장해 실행하는 Python 스크립트를 비교합니다. 또한 python 파일명.py 명령이 인터프리터 선택부터 파일 탐색, 문법 분석, 코드 실행과 프로세스 종료까지 어떤 흐름으로 처리되는지 살펴봅니다.

REPL Read Eval Print Loop Python Shell .py Script Working Directory __main__ sys.argv

이 단원의 중심 질문

REPL과 .py 스크립트는 어떤 상황에서 사용하며, python 파일명.py를 입력하면 내부에서 어떤 일이 일어날까요?

REPL은 짧은 코드를 즉시 실험하는 공간이고, 스크립트는 코드를 저장하고 반복 실행하는 파일입니다. 실행 위치와 방식을 구분해야 >>> 프롬프트, 터미널 명령, 파일 경로와 출력 결과를 혼동하지 않을 수 있습니다.

학습 목표

  • 운영체제 터미널, Python REPL, .py 파일의 역할을 구분합니다.
  • REPL의 Read-Eval-Print-Loop 흐름을 단계별로 설명할 수 있습니다.
  • >>> 기본 프롬프트와 ... 보조 프롬프트를 구분합니다.
  • REPL의 표현식 자동 출력과 스크립트의 print() 출력을 비교할 수 있습니다.
  • REPL 세션과 스크립트 프로세스의 변수 상태 유지 범위를 설명할 수 있습니다.
  • python 파일명.py 명령의 전체 실행 흐름을 설명할 수 있습니다.
  • 현재 작업 폴더와 스크립트 파일 위치를 각각 확인할 수 있습니다.
  • __name__, __file__, sys.argv의 기본 역할을 이해합니다.
  • REPL·스크립트 실행 중 발생하는 주요 오류 메시지를 구분해 읽을 수 있습니다.

11 · Python Example

실행 정보와 학생 점수 보고서를 출력하는 종합 코드

다음 코드는 인터프리터 경로, 스크립트 경로, 현재 작업 폴더, __name__, 명령행 인수와 일반적인 스크립트 실행 흐름을 함께 확인합니다.

파일명: student_report.py 

from __future__ import annotations

import sys
from pathlib import Path


def calculate_average(scores: list[int]) -> float:
    """점수 목록의 평균을 반환한다."""

    if not scores:
        raise ValueError(
            "점수 목록은 비어 있을 수 없습니다."
        )

    return sum(scores) / len(scores)


def print_runtime_information() -> None:
    """현재 스크립트의 실행 정보를 출력한다."""

    script_path = Path(__file__).resolve()

    print("=" * 60)
    print("Python 스크립트 실행 정보")
    print("=" * 60)

    print("실행 인터프리터:", sys.executable)
    print("스크립트 파일:", script_path)
    print("스크립트 폴더:", script_path.parent)
    print("현재 작업 폴더:", Path.cwd())
    print("모듈 이름:", __name__)
    print("명령행 인수:", sys.argv)


def main() -> None:
    """학생 점수 보고서를 출력한다."""

    student_name = "김길동"
    scores = [85, 72, 91]

    average = calculate_average(scores)

    print_runtime_information()

    print("\n학생 점수 보고서")
    print("-" * 60)
    print("학생:", student_name)
    print("점수:", scores)
    print("합계:", sum(scores))
    print("과목 수:", len(scores))
    print("평균:", average)
    print("-" * 60)
    print("보고서 생성 완료")


if __name__ == "__main__":
    main()

14 · Common Mistakes

REPL과 스크립트 실행에서 자주 하는 실수

01

>>>까지 코드로 복사합니다

>>>는 Python이 표시하는 프롬프트이며 입력 코드가 아닙니다.

02

실행 결과까지 다시 입력합니다

교재에서 코드 아래에 보이는 값은 다음 명령이 아니라 이전 코드의 결과입니다.

03

터미널 명령을 REPL에서 실행합니다

python hello.py는 >>>가 아니라 운영체제 터미널에 입력합니다.

04

Python 코드를 터미널에 직접 입력합니다

터미널에서 print("Hello")를 직접 입력하면 운영체제가 명령으로 해석합니다.

05

보조 프롬프트에서 빈 줄을 입력하지 않습니다

여러 줄 코드 블록은 마지막 빈 줄을 입력해야 실행됩니다.

06

REPL 상태가 영구 저장된다고 생각합니다

REPL 세션을 종료하면 변수, 함수와 import 상태가 사라집니다.

07

스크립트 표현식도 자동 출력된다고 생각합니다

스크립트에서 화면 출력을 원하면 print()를 사용해야 합니다.

08

현재 작업 폴더를 확인하지 않습니다

파일이 실제로 존재해도 현재 폴더가 다르면 상대경로 실행이 실패할 수 있습니다.

09

파일 확장자가 실제로 .txt입니다

파일 탐색기의 확장자 표시를 켜고 실제 파일명을 확인합니다.

10

코드를 저장하지 않고 실행합니다

변경한 코드를 저장하지 않으면 이전 파일 내용이 실행될 수 있습니다.

11

Run과 Terminal이 같은 Python이라고 가정합니다

각각 sys.executable을 출력하여 실제 인터프리터를 비교합니다.

12

명령행 인수를 숫자로 바로 사용합니다

sys.argv의 값은 문자열이므로 필요한 경우 int()로 변환합니다.

17 · Interview

면접 포인트

REPL이란 무엇입니까?

REPL은 Read-Eval-Print Loop의 약자입니다. 사용자의 입력을 읽고, Python 코드로 평가하거나 실행하고, 표현식 결과를 출력한 뒤 다시 다음 입력을 기다리는 대화형 실행 방식입니다.

REPL은 어떻게 시작합니까?

터미널에서 python, 환경에 따라 py 또는 python3를 실행합니다. 정상적으로 시작되면 >>> 프롬프트가 표시됩니다.

>>>와 ...는 무엇이 다릅니까?

>>>는 새로운 Python 코드를 입력하는 기본 프롬프트입니다. ...는 조건문, 반복문, 함수처럼 여러 줄이 필요한 코드에서 추가 입력을 기다리는 보조 프롬프트입니다.

REPL과 Python 스크립트의 차이는 무엇입니까?

REPL은 코드를 한 줄 또는 블록 단위로 즉시 실행하고 표현식 결과를 자동 표시합니다. 스크립트는 코드를 .py 파일에 저장해 파일 전체를 실행하며, 결과를 표시하려면 일반적으로 print()가 필요합니다.

REPL에서 만든 변수는 언제까지 유지됩니까?

현재 Python 프로세스가 살아 있는 동안 유지됩니다. REPL을 종료하고 다시 시작하면 이전 세션의 변수와 함수는 사라집니다.

스크립트를 다시 실행하면 이전 상태가 유지됩니까?

일반적으로 유지되지 않습니다. 스크립트를 실행할 때마다 새로운 Python 프로세스와 전역 네임스페이스가 생성됩니다.

python hello.py는 어떻게 해석됩니까?

python은 실행할 Python 인터프리터 명령이고, hello.py는 인터프리터에 전달되는 스크립트 경로입니다. 인터프리터는 파일을 읽고 문법을 분석한 뒤 최상위 코드를 위에서 아래로 실행합니다.

스크립트에서 표현식 결과가 자동 출력되지 않는 이유는 무엇입니까?

스크립트 실행은 REPL처럼 표현식의 평가 결과를 자동 표시하지 않기 때문입니다. 화면에 표시하려면 print()와 같은 출력 기능을 사용해야 합니다.

현재 작업 디렉터리와 스크립트 위치는 무엇이 다릅니까?

현재 작업 디렉터리는 명령을 실행한 기준 폴더이며 Path.cwd()로 확인합니다. 스크립트 위치는 현재 .py 파일의 위치이며 일반 스크립트에서는 __file__로 확인할 수 있습니다.

__name__ == "__main__"은 무엇을 의미합니까?

현재 파일이 다른 모듈에서 import된 것이 아니라 직접 실행된 경우에만 특정 코드를 실행하도록 하는 프로그램 진입점 패턴입니다.

명령행 인수는 어떻게 받습니까?

sys.argv 리스트로 받습니다. sys.argv[0]은 스크립트 이름이나 경로이고, 이후 요소가 추가 인수입니다. 모든 인수는 기본적으로 문자열입니다.

Ctrl+C와 exit()의 차이는 무엇입니까?

Ctrl+C는 현재 실행 중인 작업을 중단해 KeyboardInterrupt를 발생시킵니다. exit()는 Python 대화형 셸 자체를 종료합니다.

python -c는 언제 사용합니까?

파일을 만들지 않고 짧은 Python 코드를 한 번 실행할 때 사용합니다. 인터프리터 경로나 패키지 상태 확인에 유용합니다.

python -i script.py는 무엇입니까?

스크립트를 먼저 실행한 뒤 대화형 모드로 들어가는 옵션입니다. 스크립트에서 생성한 변수와 함수를 REPL에서 이어서 확인할 수 있습니다.

오늘의 암기 포인트

  • REPL은 Read-Eval-Print Loop의 약자입니다.
  • >>>는 Python의 기본 프롬프트입니다.
  • ...는 여러 줄 코드의 추가 입력을 기다립니다.
  • 운영체제 터미널과 Python REPL은 입력하는 명령이 다릅니다.
  • REPL은 표현식 결과를 자동 표시합니다.
  • 스크립트에서는 출력할 값에 print()가 필요합니다.
  • REPL 상태는 현재 세션 동안 유지됩니다.
  • 스크립트는 실행할 때마다 일반적으로 새 상태로 시작합니다.
  • 상대경로는 현재 작업 디렉터리의 영향을 받습니다.
  • 직접 실행한 파일의 __name__은 "__main__"입니다.

REPL은 표현식 결과를 자동 표시하지만, 스크립트에서는 print()가 필요합니다.
세션과 영구 저장
REPL 변수는 세션 동안만 유지되며, 종료 이후에는 파일이나 DB가 필요합니다.
작업 폴더와 스크립트 폴더
Path.cwd()는 실행 기준 폴더, __file__은 스크립트 위치입니다.
can't open file과 FileNotFoundError
전자는 실행할 스크립트를 못 찾은 것이고, 후자는 실행된 코드가 내부 파일을 못 찾은 상황입니다.
Ctrl+C와 exit()
Ctrl+C는 현재 작업 중단, exit()는 REPL 종료입니다.
