Infinite Loop

갱신식 누락, continue에 의한 갱신식 건너뛰기, 도달할 수 없는 break가 대표 원인입니다.

while count <= 5:

break

반복 종료

현재 들어 있는 가장 안쪽 반복문을 즉시 빠져나갑니다.

for number in range(10):

continue

다음 회차

현재 회차의 나머지를 건너뛰고 다음 반복으로 이동합니다.

for number in range(5):
    if number == 2:
        continue
    print(number)
pass

아무 동작 없음

흐름을 바꾸지 않고 바로 다음 문장을 계속 실행합니다.

for number in range(3):
    if number == 1:
        pass
    print(number)

while + continue

갱신식을 건너뛰지 않는가?

continue 아래에 갱신식을 두면 해당 회차에서 상태가 바뀌지 않아 무한 반복이 될 수 있습니다. 필요한 갱신을 먼저 수행합니다.

위험한 구조 
count = 0

while count < 5:
    if count == 2:
        continue
    count += 1
안전한 구조 
count = 0

while count < 5:
    count += 1
    if count == 2:
        continue
    print(count)

Loop else

break 없이 끝났을 때 실행

for가 모든 항목을 처리했거나 while 조건이 False가 되어 끝나면 else가 실행됩니다.

for number in numbers:

Example 01

결측치를 제외한 판매 합계와 평균

모든 값을 반복하되 None은 건너뛰고, 유효한 값만 합계와 개수에 누적합니다.

sales_summary.pyfor + continue
sales = [12000, None, 35000, 0, 28000]
total = 0
count = 0

for sale in sales:
    if sale is None:
        print("결측치 건너뜀")
        continue

    total += sale
    count += 1

if count > 0:
    print("합계:", total)
    print("평균:", total / count)
else:
    print("유효한 판매 데이터가 없습니다.")

09 · Interview Points

문법보다 반복 기준과 종료 이유를 설명한다

Q1 for와 while의 차이는 무엇입니까?

for는 반복 가능한 객체에서 항목을 하나씩 가져와 처리하고 항목이 소진되면 끝납니다. while은 조건식이 참인 동안 반복하며 조건이 거짓이 되도록 상태값을 직접 갱신해야 합니다.

Q2 반복 가능한 객체와 이터레이터는 어떻게 다릅니까?

반복 가능한 객체는 이터레이터를 만들 수 있는 데이터 원본입니다. 이터레이터는 현재 위치를 기억하면서 next()로 값을 하나씩 제공합니다. for는 이 과정을 자동으로 수행합니다.

Q3 Python 3의 range()는 리스트입니까?

아닙니다. 정수 범위를 표현하는 불변 시퀀스이며, 전체 숫자를 저장하지 않고 시작·끝·증감 규칙을 이용해 필요한 값을 계산합니다.

Q4 range()가 끝값을 포함하지 않는 장점은 무엇입니까?

range(len(sequence))가 유효한 인덱스 범위와 정확히 맞고, range(0, 3)과 range(3, 6)처럼 인접 범위를 겹침 없이 표현하기 쉽습니다.

Q5 break·continue·pass의 차이는 무엇입니까?

break는 가장 안쪽 반복문을 종료하고, continue는 현재 회차의 나머지를 건너뛰며, pass는 아무 동작도 하지 않고 다음 문장을 계속 실행합니다.

Q6 반복문의 else는 언제 실행됩니까?

for가 항목을 모두 소진하거나 while 조건이 False가 되어 정상 종료되었을 때 실행됩니다. break로 종료되면 실행되지 않습니다.

Q7 무한 반복의 대표 원인은 무엇입니까?

조건에 사용하는 상태값 갱신 누락, continue에 의한 갱신식 건너뛰기, 도달할 수 없는 break, 변하지 않는 외부 상태가 대표 원인입니다.

Q8 enumerate()와 zip()은 언제 사용합니까?

enumerate()는 인덱스와 값을 함께 얻을 때, zip()은 여러 반복 가능 객체의 같은 위치 값을 묶어 처리할 때 사용합니다. 기본 zip()은 가장 짧은 객체가 끝나면 종료됩니다.

Q9 원본 리스트를 반복하면서 삭제하면 왜 위험합니까?

삭제로 나머지 요소의 위치가 이동해 아직 처리하지 않은 값을 건너뛸 수 있습니다. 새 결과 리스트를 만들거나 복사본을 순회하는 방식을 사용합니다.

Q10 Pandas에서 일반 반복보다 벡터화를 권장하는 이유는 무엇입니까?

열과 배열 전체를 대상으로 최적화된 연산을 사용하므로 일반적인 Python 반복보다 간결하고 빠른 경우가 많습니다. 외부 객체나 복잡한 항목별 동작에는 반복문이 여전히 필요합니다.
