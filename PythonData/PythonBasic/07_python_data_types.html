Python Basics · Lesson 07

파이썬 자료형 전체 구조

Python의 모든 값은 객체이며, 각 객체는 자신이 표현하는 데이터의 의미와 사용할 수 있는 연산을 결정하는 자료형을 가집니다. 이번 단원에서는 int, float, complex, bool, NoneType, str, list, tuple, dict, set을 하나의 전체 지도에서 정리합니다. 또한 순서·중복·접근 방식·가변성·해시 가능성의 차이를 비교하고, 데이터베이스·웹크롤링· NumPy·Pandas·시각화 객체와 연결합니다.

int float complex bool NoneType str list tuple dict set Mutable Immutable Iterable dtype shape

이 단원의 중심 질문

같은 데이터처럼 보여도 자료형에 따라 프로그램의 동작은 왜 달라질까요?

자료형은 단순히 값의 모양을 구분하는 이름이 아닙니다. 어떤 연산을 사용할 수 있는지, 여러 값을 저장할 수 있는지, 순서와 중복을 허용하는지, 인덱스 또는 키로 접근하는지, 생성 후 내부 상태를 바꿀 수 있는지를 결정합니다.

학습 목표

  • Python의 주요 내장 자료형을 전체 구조로 분류할 수 있습니다.
  • 자료형이 변수 이름이 아니라 객체에 속한다는 것을 설명할 수 있습니다.
  • type()과 isinstance()의 차이를 이해하고 사용할 수 있습니다.
  • int, float, complex의 역할을 구분합니다.
  • bool과 NoneType의 의미를 구분합니다.
  • str, list, tuple의 공통점과 차이를 설명할 수 있습니다.
  • dict의 키 접근과 set의 집합 연산을 이해합니다.
  • 가변 객체와 불변 객체를 전체 자료형에서 구분할 수 있습니다.
  • Iterable과 Iterator의 차이를 설명합니다.
  • 딕셔너리 키와 집합 요소가 해시 가능해야 하는 이유를 이해합니다.
  • NumPy의 dtype, shape, axis와 Pandas 결측치 변화를 기본 자료형과 연결합니다.

10 · Hashability

딕셔너리 키와 집합 요소의 해시 가능성

딕셔너리 키와 집합 요소는 빠르게 검색하고 중복 여부를 판단할 수 있도록 일반적으로 해시 가능한 객체여야 합니다.

튜플은 내부 요소도 모두 해시 가능해야 합니다.

대표적인 해시 불가능 객체
list dict set

변경 가능한 객체는 값이 달라질 수 있으므로 일반적으로 해시할 수 없습니다.

    [1, 2],

튜플이라고 항상 해시 가능한 것은 아닙니다.

    "scores",
    [85, 92],
)

튜플 안에 해시할 수 없는 리스트가 있으므로 이 튜플도 딕셔너리 키나 집합 요소로 사용할 수 없습니다.

    "passed": True,
    "email": None,
}
변수 이름 student
→

dict

set
참·거짓 또는 값 없음 상태인가?
bool None

14 · Python Example

Python 자료형 전체 구조 종합 예제

다음 코드는 주요 자료형의 값·자료형·가변성과 논리 평가 결과를 확인하고, 문자열 불변성, 리스트 공유, 튜플 내부 리스트, 딕셔너리와 집합 연산, 자료형 변환을 연결합니다.

파일명: data_types_overview.py 

from __future__ import annotations


MUTABLE_TYPES = (
    list,
    dict,
    set,
)


def is_mutable_type(
    value: object,
) -> bool:
    """대표 내장 자료형 기준으로 가변 객체인지 반환한다."""

    return isinstance(
        value,
        MUTABLE_TYPES,
    )


def print_type_info(
    label: str,
    value: object,
) -> None:
    """객체의 값과 자료형 특징을 출력한다."""

    print("-" * 60)
    print("구분:", label)
    print("값:", repr(value))
    print("자료형:", type(value).__name__)
    print("가변 객체:", is_mutable_type(value))
    print("논리 평가:", bool(value))


def demonstrate_immutable_string() -> None:
    """문자열 메서드가 새 객체를 반환하는지 확인한다."""

    print("\n" + "=" * 60)
    print("문자열 불변성")
    print("=" * 60)

    original = "python"
    changed = original.upper()

    print("원본:", original)
    print("변환 결과:", changed)
    print("같은 객체:", original is changed)


def demonstrate_mutable_list() -> None:
    """리스트 가변성과 별칭 관계를 확인한다."""

    print("\n" + "=" * 60)
    print("리스트 가변성과 객체 공유")
    print("=" * 60)

    scores_a = [
        85,
        92,
    ]

    scores_b = scores_a

    scores_b.append(78)

    print("scores_a:", scores_a)
    print("scores_b:", scores_b)
    print("같은 값:", scores_a == scores_b)
    print("같은 객체:", scores_a is scores_b)


def demonstrate_tuple() -> None:
    """튜플과 내부 가변 객체의 관계를 확인한다."""

    print("\n" + "=" * 60)
    print("튜플과 내부 리스트")
    print("=" * 60)

    student = (
        "김길동",
        [85, 92],
    )

    student[1].append(78)

    print(student)


def demonstrate_dictionary() -> None:
    """딕셔너리의 키 조회와 변경을 확인한다."""

    print("\n" + "=" * 60)
    print("딕셔너리")
    print("=" * 60)

    student = {
        "name": "김길동",
        "score": 85,
        "email": None,
    }

    student["score"] = 92
    student["city"] = "서울"

    print("이름:", student["name"])
    print("점수:", student["score"])

    print(
        "전화번호:",
        student.get(
            "phone",
            "등록되지 않음",
        ),
    )

    print("전체 데이터:", student)


def demonstrate_set() -> None:
    """집합의 중복 제거와 집합 연산을 확인한다."""

    print("\n" + "=" * 60)
    print("집합")
    print("=" * 60)

    frontend_skills = {
        "HTML",
        "CSS",
        "JavaScript",
    }

    backend_skills = {
        "Python",
        "SQL",
        "JavaScript",
    }

    print(
        "공통 기술:",
        frontend_skills
        & backend_skills,
    )

    print(
        "전체 기술:",
        frontend_skills
        | backend_skills,
    )


def demonstrate_type_conversion() -> None:
    """기본 자료형 변환 결과를 확인한다."""

    print("\n" + "=" * 60)
    print("자료형 변환")
    print("=" * 60)

    print(int("100"))
    print(float("3.14"))
    print(str(100))
    print(list("ABC"))
    print(tuple([1, 2, 3]))
    print(set([1, 2, 2, 3]))


def main() -> None:
    """Python 주요 자료형을 전체적으로 확인한다."""

    samples = {
        "정수": 100,
        "실수": 3.14,
        "복소수": 3 + 4j,
        "문자열": "Python",
        "리스트": [1, 2, 3],
        "튜플": (1, 2, 3),
        "딕셔너리": {
            "name": "김길동",
            "score": 85,
        },
        "집합": {1, 2, 3},
        "논리값": True,
        "값 없음": None,
    }

    print("=" * 60)
    print("Python 주요 자료형")
    print("=" * 60)

    for label, value in samples.items():
        print_type_info(
            label,
            value,
        )

    demonstrate_immutable_string()
    demonstrate_mutable_list()
    demonstrate_tuple()
    demonstrate_dictionary()
    demonstrate_set()
    demonstrate_type_conversion()


if __name__ == "__main__":
    main()

16 · Common Mistakes

초보자가 자주 하는 자료형 실수

01

숫자와 숫자 문자열을 같은 값으로 생각합니다

100은 int, "100"은 str입니다.

02

리스트와 튜플은 괄호만 다르다고 생각합니다

리스트는 가변이고 튜플은 요소 연결을 바꿀 수 없는 불변 객체입니다.

03

한 요소 튜플에 쉼표를 생략합니다

(100)은 정수이고 (100,)이 튜플입니다.

04

빈 집합을 중괄호로 만듭니다

{}는 빈 딕셔너리이고 빈 집합은 set()입니다.

05

집합의 출력 순서에 의존합니다

순서가 필요하면 리스트·튜플을 사용하거나 sorted() 결과를 사용합니다.

06

딕셔너리를 숫자 인덱스로 접근합니다

딕셔너리는 위치가 아니라 키로 값에 접근합니다.

07

중복 딕셔너리 키가 모두 저장된다고 생각합니다

같은 키를 다시 사용하면 나중 값이 기존 값을 덮어씁니다.

08

문자열 메서드가 원본을 변경한다고 생각합니다

문자열은 불변이므로 메서드가 새로운 문자열 객체를 반환합니다.

09

리스트 할당을 객체 복사로 생각합니다

copied = original은 같은 객체를 공유합니다.

10

튜플 내부는 전혀 변경할 수 없다고 생각합니다

튜플 요소가 가변 객체를 가리키면 그 객체의 내부는 변경될 수 있습니다.

11

None과 빈 컨테이너를 같은 의미로 사용합니다

값 없음과 비어 있는 유효한 객체는 서로 다른 상태입니다.

12

type()과 isinstance()를 동일하게 생각합니다

하나는 실제 클래스를 반환하고, 다른 하나는 클래스 계열 포함 여부를 검사합니다.

13

리스트를 딕셔너리 키로 사용합니다

리스트는 변경 가능하며 해시할 수 없습니다.

14

반복 가능한 객체를 모두 Iterator라고 부릅니다

리스트는 Iterable이지만 직접 next()를 사용할 수 있는 Iterator는 아닙니다.

15

bool을 일반 수량과 같은 의미로 사용합니다

계산상 정수처럼 보일 수 있지만 상태와 수량의 의미를 구분해야 합니다.

19 · Interview

면접 포인트

Python의 자료형이란 무엇입니까?

객체가 표현하는 값의 종류와 사용할 수 있는 연산, 저장 구조, 접근 방식과 변경 가능 여부를 결정하는 분류입니다. 자료형은 변수 이름이 아니라 객체에 속합니다.

Python의 주요 내장 자료형에는 무엇이 있습니까?

숫자형의 int, float, complex, 논리형의 bool, 값 없음 상태의 NoneType, 순서형의 str, list, tuple, 매핑형의 dict, 집합형의 set이 있습니다.

type()과 isinstance()의 차이는 무엇입니까?

type()은 객체의 실제 클래스를 반환하고, isinstance()는 객체가 지정한 클래스 또는 하위 클래스에 해당하는지를 확인합니다.

가변 객체와 불변 객체의 차이는 무엇입니까?

가변 객체는 생성 후 내부 상태를 변경할 수 있지만, 불변 객체는 내부 값을 직접 변경할 수 없습니다. list, dict, set은 가변이고, 숫자형·bool· str·tuple· NoneType은 불변입니다.

문자열과 리스트의 공통점과 차이는 무엇입니까?

둘 다 순서가 있고 인덱싱과 슬라이싱이 가능합니다. 문자열은 불변이지만 리스트는 요소 추가·수정·삭제가 가능한 가변 객체입니다.

리스트와 튜플의 차이는 무엇입니까?

둘 다 순서와 중복을 허용하지만 리스트는 가변이고 튜플은 요소의 연결을 변경할 수 없는 불변 객체입니다.

한 요소 튜플은 어떻게 만듭니까?

(100,)처럼 값 뒤에 쉼표를 작성합니다. 튜플을 만드는 핵심은 괄호보다 쉼표입니다.

튜플이 불변인데 내부 리스트가 변경되는 이유는 무엇입니까?

튜플의 요소가 계속 같은 리스트 객체를 가리키고 있기 때문입니다. 튜플의 요소 연결은 변하지 않았지만, 그 요소가 가리키는 가변 리스트 객체의 내부 상태가 변경된 것입니다.

딕셔너리의 핵심 특징은 무엇입니까?

키와 값의 대응 관계를 저장하며 위치 인덱스가 아니라 키로 접근합니다. 키는 중복될 수 없고 딕셔너리 자체는 변경 가능합니다.

현대 Python 딕셔너리는 순서를 보존합니까?

삽입 순서를 보존합니다. 다만 리스트처럼 숫자 위치 인덱스로 접근하는 시퀀스는 아니며, 값 접근에는 키를 사용합니다.

집합의 특징은 무엇입니까?

중복을 허용하지 않고 위치 인덱스가 없으며, 합집합·교집합·차집합과 같은 집합 연산을 지원합니다.

빈 집합은 어떻게 만듭니까?

set()으로 만듭니다. {}는 빈 집합이 아니라 빈 딕셔너리입니다.

None과 빈 리스트는 무엇이 다릅니까?

None은 값이나 결과가 아직 없다는 상태이고, 빈 리스트는 리스트 객체는 존재하지만 요소가 없는 상태입니다.

bool()로 변환했을 때 거짓이 되는 값은 무엇입니까?

False, None, 숫자 0, 빈 문자열과 빈 리스트·튜플· 딕셔너리·집합 등이 있습니다. 논리 평가 결과가 같더라도 자료형과 의미는 서로 다릅니다.

다른 변수에 리스트를 할당하면 객체가 복사됩니까?

일반적으로 복사되지 않습니다. 새 이름도 같은 리스트 객체를 가리키므로 한쪽을 통한 변경이 다른 쪽에서도 보일 수 있습니다.

딕셔너리 키와 집합 요소에 리스트를 사용할 수 없는 이유는 무엇입니까?

리스트는 가변 객체이고 해시할 수 없기 때문입니다. 딕셔너리 키와 집합 요소는 일반적으로 해시 가능한 객체여야 합니다.

Iterable과 Iterator의 차이는 무엇입니까?

Iterable은 반복 가능한 원본 객체이고, Iterator는 next()로 다음 요소를 하나씩 꺼내며 현재 진행 상태를 보관하는 객체입니다.

NumPy의 dtype과 Python의 type()은 무엇이 다릅니까?

type()은 배열 객체 자체의 Python 클래스를 확인합니다. dtype은 NumPy 배열 내부의 요소들이 어떤 공통 데이터 타입으로 저장되는지를 나타냅니다.

NumPy의 shape와 ndim은 무엇입니까?

shape는 각 축의 크기를 튜플로 표현하고, ndim은 배열의 축 또는 차원 수를 반환합니다.

데이터 분석에서 결측치 처리가 중요한 이유는 무엇입니까?

결측치 제거 또는 대체 방식에 따라 값, 컬럼 자료형, 행 개수, shape, 평균과 통계 결과가 달라질 수 있기 때문입니다.
