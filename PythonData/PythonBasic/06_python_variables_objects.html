Python Basics · Lesson 06

변수와 객체의 관계

Python의 변수는 값을 직접 담는 고정된 상자라기보다, 메모리에 만들어진 객체를 찾아가기 위해 연결된 이름입니다. 할당은 이름과 객체를 연결하고, 재할당은 그 연결 대상을 바꾸며, del은 현재 네임스페이스에서 이름의 바인딩을 제거합니다. 이번 단원에서는 None, 다중 할당, 언패킹, 연쇄 할당, 객체 공유, ==와 is, id()와 type()까지 하나의 흐름으로 연결합니다.

Name Object Binding Namespace Assignment Reassignment None Unpacking Aliasing Identity id() del

이 단원의 중심 질문

Python의 변수는 값을 보관하는 상자일까요, 아니면 객체를 찾아가기 위한 이름일까요?

score = 85는 score라는 상자에 숫자 85를 넣는다는 의미보다, score라는 이름을 정수 객체 85에 연결한다는 의미로 이해하는 것이 더 정확합니다. 이 관점을 이해해야 여러 변수가 같은 리스트를 공유하는 현상과 is, id(), del을 올바르게 설명할 수 있습니다.

학습 목표

  • 변수, 객체와 바인딩의 차이를 설명할 수 있습니다.
  • 할당문에서 오른쪽 표현식이 먼저 평가되는 이유를 이해합니다.
  • 재할당과 변경 가능한 객체의 내부 상태 변경을 구분합니다.
  • 자료형이 변수 이름이 아니라 객체에 속한다는 것을 설명할 수 있습니다.
  • None과 정의되지 않은 이름, 0, 빈 문자열을 구분합니다.
  • 다중 할당, 언패킹, 확장 언패킹과 값 교환을 사용할 수 있습니다.
  • 연쇄 할당으로 여러 이름이 같은 객체를 공유한다는 것을 이해합니다.
  • ==와 is의 비교 기준을 구분합니다.
  • id(), type(), isinstance()를 사용할 수 있습니다.
  • del이 이름의 바인딩을 제거한다는 것을 설명할 수 있습니다.
  • 변수 이름 규칙, 예약어와 내장 이름 덮어쓰기 문제를 이해합니다.

09 · Object Inspection

id(), type(), isinstance()

id()

객체 식별값 확인

id(scores)

현재 실행 중인 Python에서 객체를 구분하는 식별값을 반환합니다.

type()

객체 클래스 확인

type(scores)

이름이 현재 가리키는 객체의 클래스·자료형을 반환합니다.

isinstance()

특정 자료형인지 확인

isinstance(scores, list)

객체가 지정한 클래스에 해당하는지 참·거짓으로 확인합니다. 

scores = [85, 92]

print("값:", scores)
print("자료형:", type(scores))
print("식별값:", id(scores))
print("리스트인가:", isinstance(scores, list))

같은 객체를 가리키면 식별값도 같다

scores_a = [85, 92]
scores_b = scores_a

print(id(scores_a))
print(id(scores_b))
print(scores_a is scores_b)
id()를 영구 식별자로 사용하지 않습니다.
  • 객체가 살아 있는 현재 실행에서만 식별 의미를 가집니다.
  • 프로그램을 다시 실행하면 값이 달라질 수 있습니다.
  • 객체가 정리된 뒤 같은 식별값이 재사용될 수 있습니다.
  • 데이터베이스 기본키나 사용자 ID로 사용하면 안 됩니다.

16 · Common Mistakes

초보자가 자주 하는 변수·객체 실수

01

변수를 값이 든 상자로만 이해합니다

여러 이름이 같은 객체를 가리키는 별칭 관계를 설명하기 어렵습니다.

02

변수 이름만 쓰면 선언된다고 생각합니다

이름만 작성하면 객체 조회가 일어나며 정의되지 않았다면 NameError가 발생합니다.

03

할당문의 왼쪽부터 실행된다고 생각합니다

오른쪽 표현식을 먼저 평가한 뒤 결과 객체를 왼쪽 이름에 연결합니다.

04

자료형이 변수 이름에 고정된다고 생각합니다

자료형은 객체에 속하며 이름은 다른 자료형 객체에 재할당될 수 있습니다.

05

None과 이름 없음 상태를 혼동합니다

result = None에서는 result 이름이 존재합니다.

06

None, 0, 빈 문자열을 같은 상태로 사용합니다

조건식에서는 거짓처럼 평가될 수 있지만 의미와 자료형은 서로 다릅니다.

07

다중 할당의 개수를 맞추지 않습니다

받을 이름 수와 분리할 값 수를 확인해야 합니다.

08

정수 하나를 여러 변수로 언패킹합니다

정수 객체 하나는 여러 요소로 분리할 수 없습니다.

09

연쇄 할당이 서로 다른 리스트를 만든다고 생각합니다

a = b = []는 두 이름이 같은 리스트를 공유합니다.

10

별칭을 객체 복사로 생각합니다

copied = original은 같은 객체에 이름 하나를 추가합니다.

11

is로 문자열과 숫자의 값을 비교합니다

값의 내용 비교에는 ==를 사용합니다.

12

id()를 영구 식별자로 사용합니다

현재 객체 생존 기간 동안의 디버깅용 식별값입니다.

13

del이 객체를 즉시 삭제한다고 생각합니다

다른 이름이 객체를 참조하면 객체는 계속 사용됩니다.

14

내장 함수 이름을 변수로 덮어씁니다

list, sum, type 같은 이름을 피합니다.

15

대문자 상수명은 변경할 수 없다고 생각합니다

대문자 이름은 변경하지 않기로 한 관례이며 문법적 강제는 아닙니다.

16

Jupyter의 셀 실행 순서를 무시합니다

Kernel에서 마지막으로 실행된 할당이 현재 이름의 상태를 결정합니다.

면접 포인트

Python 변수란 무엇입니까?

Python 변수는 값을 직접 담는 고정된 상자라기보다 객체에 연결된 이름입니다. 할당문이 실행되면 오른쪽 표현식을 먼저 평가하고 그 결과 객체를 왼쪽 이름에 연결합니다.

score = 85는 어떤 순서로 처리됩니까?

오른쪽의 정수 객체 85를 먼저 평가하거나 준비한 뒤, score라는 이름을 그 객체에 연결합니다.

Python 변수에는 자료형이 없습니까?

이름 자체에 고정된 자료형이 없다고 이해하는 것이 정확합니다. 자료형은 객체에 속하며, 같은 이름이 실행 중 서로 다른 자료형의 객체를 가리킬 수 있습니다.

동적 타이핑이란 무엇입니까?

변수 이름에 자료형을 미리 고정하지 않고, 실행 시점에 이름이 가리키는 객체의 자료형에 따라 처리하는 방식입니다.

재할당과 객체 변경의 차이는 무엇입니까?

재할당은 이름이 다른 객체를 가리키도록 연결을 바꾸는 것입니다. 객체 변경은 이름이 같은 객체를 계속 가리키는 상태에서 객체 내부를 수정하는 것입니다.

None이란 무엇입니까?

값이 아직 없거나 결과가 존재하지 않는 상태를 표현하는 특별한 객체입니다. 자료형은 NoneType이며 일반적으로 is None으로 확인합니다.

None과 정의되지 않은 변수는 무엇이 다릅니까?

result = None에서는 result라는 이름이 존재하며 None 객체를 가리킵니다. 정의되지 않은 변수는 이름 자체가 없어 사용하면 NameError가 발생합니다.

다중 할당이란 무엇입니까?

여러 값을 여러 이름에 한 번에 연결하는 문법입니다. 오른쪽 값들을 먼저 평가한 뒤 왼쪽 이름에 순서대로 언패킹합니다.

다중 할당의 개수가 다르면 어떻게 됩니까?

값이 이름보다 많으면 too many values to unpack, 부족하면 not enough values to unpack 오류가 발생합니다.

연쇄 할당이란 무엇입니까?

하나의 오른쪽 객체를 여러 이름이 함께 가리키도록 만드는 할당입니다. 예를 들어 a = b = value에서는 a와 b가 같은 객체를 가리킵니다.

a = b = []를 조심해야 하는 이유는 무엇입니까?

각각 다른 리스트가 만들어지는 것이 아니라 두 이름이 하나의 같은 리스트 객체를 가리키기 때문입니다. 한쪽을 통해 리스트를 변경하면 다른 쪽에서도 변경 결과가 보입니다.

별칭이란 무엇입니까?

여러 이름이 동일한 객체를 가리키는 관계입니다. b = a는 일반적으로 객체를 복사하는 것이 아니라 b를 같은 객체에 연결합니다.

==와 is의 차이는 무엇입니까?

==는 객체의 값이나 내용이 같은지를 비교하고, is는 두 이름이 정확히 같은 객체를 가리키는지 확인합니다.

id()는 무엇입니까?

현재 실행 중인 Python에서 객체를 구분하는 식별값을 반환합니다. 객체가 살아 있는 동안 사용할 수 있지만 영구 데이터 ID로 사용해서는 안 됩니다.

type()은 무엇을 반환합니까?

이름이 현재 가리키는 객체의 클래스, 즉 자료형 객체를 반환합니다.

del은 객체를 삭제합니까?

del 변수명은 현재 네임스페이스에서 이름과 객체 사이의 바인딩을 제거합니다. 다른 이름이 같은 객체를 가리키면 객체는 계속 존재합니다.

del value와 value = None의 차이는 무엇입니까?

value = None은 이름을 유지하면서 None 객체에 연결합니다. del value는 현재 범위에서 그 이름의 바인딩을 제거합니다.

Python에는 상수가 있습니까?

일반 변수와 다른 별도의 상수 키워드는 없습니다. 대문자와 밑줄로 이름을 작성하여 변경하지 않겠다는 관례를 표현합니다.

내장 함수 이름을 변수로 사용하면 왜 문제가 됩니까?

현재 네임스페이스의 이름이 내장 함수 대신 직접 할당한 객체를 가리키게 됩니다. 이후 내장 함수를 호출하려 하면 호출할 수 없는 객체라는 TypeError가 발생할 수 있습니다.

객체는 언제 메모리 정리 대상이 됩니까?

객체를 가리키는 참조가 더 이상 없으면 Python의 메모리 관리 대상이 됩니다. 구체적인 정리 방식은 Python 구현에 따라 달라질 수 있습니다.
