01 · Core Concept

리스트는 순서가 있고 원본을 바꿀 수 있는 데이터 묶음이다

변수 하나에는 보통 값 하나를 연결하지만, 실제 프로그램은 학생 점수, 상품명, 검색 결과, DB 조회 행처럼 여러 값을 함께 다뤄야 합니다. 리스트는 값을 대괄호 [] 안에 쉼표로 구분해 저장하며, 각 값에는 0부터 시작하는 위치 번호인 인덱스가 붙습니다.

02 · Visual Flow

인덱스는 칸 하나, 슬라이스는 칸 사이의 범위를 가리킨다

Index Map

앞에서는 0, 뒤에서는 -1부터 센다

길이가 4인 리스트의 마지막 양수 인덱스는 3, 마지막 음수 인덱스는 -1입니다. 따라서 유효한 양수 인덱스 범위는 0부터 len(list) - 1까지입니다.

0123
redgreenblueblack
-4-3-2-1
colors[0] → red colors[-1] → black len(colors) → 4

Slice Map

start는 포함하고 stop은 포함하지 않는다

슬라이스는 [start:stop:step] 형식을 사용합니다. start 위치에서 시작해 stop 바로 전까지 선택하고, step만큼 건너갑니다. 생략된 값은 방향에 맞는 기본값을 사용합니다.

012345
ABCDE

letters[1:4] → 인덱스 1, 2, 3 선택 → ['B', 'C', 'D']

data[:3]처음부터 3 직전까지
data[2:]2부터 끝까지
data[::2]처음부터 두 칸씩
data[::-1]역방향으로 전체

Mutation Timeline

변경 메서드는 같은 리스트 객체의 상태를 바꾼다

메서드 호출식의 결과만 출력하면 대부분 None이 보입니다. 메서드 실행 뒤 리스트 변수 자체를 다시 출력해야 바뀐 상태를 확인할 수 있습니다.

Reference & Copy

변수 이름 복사와 리스트 복사는 다르다

별칭

b = a
a ─┐b ─┴→ [1, 2, 3]

두 이름이 같은 객체를 가리켜 한쪽 변경이 다른 쪽에도 보입니다.

얕은 복사

b = a.copy()
a → [1, 2, 3]b → [1, 2, 3]

바깥 리스트는 새 객체지만 중첩된 내부 객체는 공유할 수 있습니다.

깊은 복사

b = deepcopy(a)
a → [[1], [2]]b → [[1], [2]]

중첩된 내부 객체까지 재귀적으로 복사해 독립성을 높입니다.

열 0열 1열 2
행 0102030

2. 인덱싱은 값 하나, 슬라이싱은 새 리스트를 반환한다

표현 선택 범위 결과 주의점
items[0] 첫 번째 값 하나 요소 자체 범위를 벗어나면 IndexError
items[-1] 마지막 값 하나 요소 자체 빈 리스트에서는 오류
items[1:4] 1부터 4 직전 새 리스트 stop은 제외
items[10:20] 존재하는 범위만 빈 리스트 가능 슬라이스는 범위 초과에 관대
items[::-1] 전체 역순 새 리스트 원본 순서는 그대로

3. 단일 대입과 슬라이스 대입은 길이 변화가 다르다

단일 위치 변경

numbers = [10, 20, 30]
numbers[1] = 200
print(numbers)

[10, 200, 30]

요소 하나가 다른 값 하나로 교체되어 길이는 그대로입니다.

슬라이스 범위 변경

numbers = [10, 20, 30]
numbers[1:2] = [200, 300]
print(numbers)

[10, 200, 300, 30]

범위와 대입할 요소 수가 달라도 되어 길이가 바뀔 수 있습니다.

4. 연결과 반복도 새 리스트를 만든다

a = [1, 2]
b = [3, 4]
c = a + b
print(c)

[1, 2, 3, 4]

zeros = [0] * 4
print(zeros)

[0, 0, 0, 0]

중첩 리스트 반복 주의 
rows = [[]] * 3
rows[0].append("X")
print(rows)  # [['X'], ['X'], ['X']]

빈 내부 리스트 하나의 참조가 세 번 반복되기 때문입니다. 서로 독립된 행이 필요하면 [[] for _ in range(3)]처럼 생성합니다.

빈 리스트: [] 빈 슬라이스: items[2:2] 전체 복사: items[:] 역순 복사: items[::-1]

04 · List Methods

추가·삭제·정렬 메서드는 목적과 반환값이 서로 다르다

ADD

값 추가하기

하나를 넣을지, 여러 요소를 펼쳐 넣을지, 위치를 지정할지 판단합니다.

append(x)

값 x 하나를 맨 뒤에 추가합니다.

data = [1, 2]
data.append([3, 4])
# [1, 2, [3, 4]]

extend(iterable)

반복 가능한 값의 각 요소를 맨 뒤에 펼쳐 추가합니다.

data = [1, 2]
data.extend([3, 4])
# [1, 2, 3, 4]

insert(i, x)

인덱스 i 앞에 값 x를 삽입합니다.

data = [1, 3]
data.insert(1, 2)
# [1, 2, 3]
append([3, 4])
12[3, 4]

리스트 자체를 값 하나로 추가 → 길이 3

extend([3, 4])
1234

내부 요소를 하나씩 추가 → 길이 4

DELETE

값 삭제하기

값 기준인지, 위치 기준인지, 삭제한 값을 다시 쓸지 구분합니다.

remove(x)

왼쪽에서 처음 만난 값 x를 삭제합니다.

없으면 ValueError

pop([i])

위치 i의 값을 삭제하면서 반환합니다.

생략하면 마지막 값

clear()

모든 요소를 지워 같은 빈 리스트 객체로 만듭니다.

결과는 []

del

인덱스·슬라이스 또는 변수 이름 자체를 삭제합니다.

메서드가 아닌 문장 
queue = ["A", "B", "C", "B"]
queue.remove("B")        # ["A", "C", "B"]
served = queue.pop(0)    # "A", queue는 ["C", "B"]
del queue[1:]            # ["C"]
queue.clear()            # []
ORDER

순서 바꾸기

정렬 기준, 원본 변경, 반환값을 함께 확인합니다.

list.sort()

원본 리스트를 정렬하고 None을 반환합니다.

scores = [70, 95, 80]
result = scores.sort()
print(scores)  # [70, 80, 95]
print(result)  # None

sorted(iterable)

원본을 유지하고 정렬된 새 리스트를 반환합니다.

scores = [70, 95, 80]
result = sorted(scores)
print(scores)  # [70, 95, 80]
print(result)  # [70, 80, 95]
data.sort(reverse=True)내림차순으로 원본 정렬
words.sort(key=len)문자열 길이를 기준으로 정렬
users.sort(key=lambda x: x["age"])딕셔너리의 age 값을 기준으로 정렬
data.reverse()정렬이 아니라 현재 순서만 뒤집기
FIND & COPY

찾기와 복사하기

위치·개수·참조 관계를 확인합니다.

표현 의미 반환 원본 변경
x in data 값 포함 여부 bool 아니오
data.index(x) 첫 번째 x의 위치 int 아니오
data.count(x) x의 개수 int 아니오
data.copy() 얕은 복사 새 리스트 아니오
data[:] 전체 슬라이스 복사 새 리스트 아니오
변경 메서드의 공통 규칙

append(), extend(), insert(), remove(), clear(), sort(), reverse()는 원본을 직접 바꾸고 일반적으로 None을 반환합니다. pop()만 삭제한 값을 반환합니다.

07 · Mistakes & Errors

오류 메시지는 실패한 연산과 현재 자료형·범위를 함께 읽는다

IndexError

인덱스가 리스트 범위를 벗어남

ValueError

슬라이스의 step이 0

print(data[::0])

# ValueError: slice step cannot be zero

이동 간격 0은 다음 위치를 결정할 수 없으므로 양수나 음수를 사용합니다.

TypeError

비교할 수 없는 자료형을 함께 정렬

# TypeError: '<' not supported between

리스트와 튜플을 +로 연결

[1, 2] + list((3, 4))처럼 같은 자료형으로 변환합니다.

AttributeError

튜플에 리스트 메서드를 사용

# AttributeError: 'tuple' object has
# no attribute 'append'

type(data)로 자료형을 확인합니다. 튜플은 변경할 수 없습니다.

KeyError

리스트 속 딕셔너리에 없는 키 사용

print(users[0]["age"])

# KeyError: 'age'

del data[:]는 요소를, del data는 변수 이름을 삭제합니다.

09 · Interview Point

답변에는 반환값, 원본 변경, 시간·메모리 관점을 포함한다

Q1 Python 리스트의 주요 특징은 무엇인가요?

입력 순서를 유지하고 인덱스로 접근하며, 생성 뒤에도 요소를 변경할 수 있습니다. 중복과 서로 다른 자료형을 허용하지만 실무에서는 일관된 자료형이 관리하기 쉽습니다.

Q2 인덱싱과 슬라이싱의 차이는 무엇인가요?

인덱싱은 특정 위치의 요소 하나를 반환하고 범위를 벗어나면 IndexError가 납니다. 슬라이싱은 범위의 요소를 새 리스트로 반환하며 범위를 일부 벗어나도 가능한 구간만 반환합니다.

Q3 슬라이스의 stop이 제외되는 장점은?

data[:n]의 길이가 자연스럽게 n이 되고, data[:i]와 data[i:]를 겹침이나 누락 없이 이어 붙일 수 있습니다.

Q4 append()와 extend()의 차이는?

append(x)는 x 전체를 요소 하나로 추가합니다. extend(iterable)는 반복 가능한 객체의 각 요소를 꺼내 여러 요소로 추가합니다.

Q5 remove()와 pop()은 어떻게 다른가요?

remove(x)는 첫 번째 일치값 x를 삭제하고 반환값은 None입니다. pop(i)는 위치 i의 값을 삭제하면서 그 값을 반환하며, i를 생략하면 마지막 값을 대상으로 합니다.

Q6 sort()와 sorted()의 차이는?

list.sort()는 리스트 원본을 정렬하고 None을 반환합니다. sorted()는 모든 반복 가능한 객체를 받아 정렬된 새 리스트를 반환하므로 원본을 보존합니다.

Q7 reverse()와 내림차순 정렬은 같은가요?

아닙니다. reverse()는 현재 배치를 뒤집을 뿐 값의 크기를 비교하지 않습니다. 내림차순은 sort(reverse=True) 또는 sorted(..., reverse=True)를 사용합니다.

Q8 b = a와 b = a.copy()의 차이는?

전자는 두 이름이 같은 리스트 객체를 가리키는 별칭입니다. 후자는 새 바깥 리스트를 만드는 얕은 복사지만, 중첩된 내부 가변 객체는 여전히 공유할 수 있습니다.

Q9 얕은 복사와 깊은 복사는 언제 구분해야 하나요?

숫자나 문자열만 담은 단순 리스트는 얕은 복사로 충분한 경우가 많습니다. 내부에 리스트·딕셔너리 같은 가변 객체가 있고 독립적인 변경이 필요하면 깊은 복사를 검토합니다.

Q10 리스트에서 값 검색과 끝 추가의 일반적인 비용은?

인덱스로 요소를 읽는 것은 보통 상수 시간이고, 값 포함 여부 검색은 앞에서부터 비교하므로 보통 선형 시간입니다. 끝에 append하는 작업은 평균적으로 상수 시간으로 설명합니다.

Q11 반복 중인 리스트에서 요소를 삭제하면 왜 위험한가요?

삭제 뒤 뒤쪽 요소의 인덱스가 앞으로 당겨져 반복자가 다음 요소를 건너뛸 수 있습니다. 필터링한 새 리스트를 만들거나 복사본을 순회하는 방법이 안전합니다.

Q12 Python 리스트와 NumPy 배열의 차이는?

리스트는 일반 목적의 동적 자료구조로 서로 다른 자료형을 담을 수 있습니다. NumPy 배열은 보통 동일 dtype의 데이터를 연속적으로 다루며 벡터 연산과 다차원 수치 계산에 적합합니다.
