01 · Core Concept

함수는 전달할 수 있는 객체이고, 범위는 이름 검색 위치를, 내장 함수는 호출 시점을 결정한다

def와 lambda는 모두 함수 객체를 만듭니다. 괄호 없이 적은 함수 이름은 객체 자체이고, 괄호를 붙이면 지금 함수를 호출합니다. 함수가 실행되면 매개변수와 지역변수를 담는 지역 프레임이 생기며, 이름을 읽을 때는 Local → Enclosing → Global → Built-in 순서로 검색합니다. 이 원리를 알면 내장 함수에 처리 규칙을 안전하게 전달하고, 지연 반복자의 결과가 언제 만들어지는지 설명할 수 있습니다.

함수 객체와 호출 결과는 완전히 다르다

FUNCTION OBJECT · 괄호 없음

def double(number):
    return number * 2

rule = double
print(callable(rule))

double은 나중에 호출할 함수 객체입니다. 출력은 True입니다.

CALL RESULT · 괄호 있음

value = double(5)
print(value)

double(5)는 함수를 지금 실행한 결과이며 출력은 10입니다.

LEGB는 이름을 읽는 검색 경로다

L · Local현재 함수의 매개변수와 지역변수
E · Enclosing현재 함수를 감싼 바깥 함수의 지역 이름
G · Global현재 모듈 최상위 영역의 이름
B · Built-inprint·len 같은 내장 이름
이번 단원의 세 가지 계약 함수를 전달할 때는 괄호 없이 함수 객체를 준다. 이름을 읽을 때는 가장 가까운 범위부터 찾는다. 반복자는 한 번 소비될 수 있으므로 최종 자료형과 사용 횟수를 확인한다.

MUTATION · 객체 내용 변경

items = ["사과"]

def add_item():
    items.append("바나나")

전역 이름을 다시 연결하지 않으므로 global이 문법상 필요하지 않습니다.

REBINDING · 이름 재대입

items = ["사과"]

def reset_items():
    global items
    items = []

items가 새 리스트를 가리키게 하므로 전역 이름 재대입을 선언합니다.

반복자는 필요한 순간 값을 만들고 한 번 소비된다

생성mapped = map(...) → 대기함수와 원본을 기억 → 요청next 또는 list → 생산요소별 함수 호출 → 소진다시 읽으면 남은 값 없음

DATA TRANSFORMATION TRACE

raw_scores = ["78", "45", "92", "81"]

converted = map(int, raw_scores)
passed = filter(lambda score: score >= 60, converted)
ordered = sorted(passed, reverse=True)
ranked = list(enumerate(ordered, start=1))

print(ranked)
문자열→정수→합격만→내림차순→순위 [(1, 92), (2, 81), (3, 78)]

03 · Syntax & Rules

람다는 표현식 하나, 이름은 LEGB, 내장 함수는 반환 자료형과 종료 조건까지 확인한다

NO PARAMETER

say_hello = lambda: "안녕하세요"
print(say_hello())

MULTIPLE PARAMETERS

add = lambda x, y: x + y
print(add(10, 20))

CONDITIONAL EXPRESSION

label = lambda n: "짝수" if n % 2 == 0 else "홀수"
print(label(7))
def와 lambda 비교
기준deflambda
본문여러 문장표현식 하나
반환return 사용표현식 결과 자동 반환
이름·문서화이름과 독스트링에 적합오류에 <lambda>로 표시
권장 용도재사용·복잡한 업무 규칙짧은 일회성 변환·판정·키

범위 규칙

01
전역 이름은 읽기만 하면 선언이 필요 없다.return price * rate
02
함수 안의 대입 대상은 기본적으로 지역 이름이다.count = count + 1
03
전역 이름을 재대입할 때만 global을 선언한다.global count
04
가장 가까운 바깥 함수 이름 재대입에는 nonlocal을 쓴다.nonlocal count
05
일반 if·for는 새 함수 범위를 만들지 않는다.for index in range(3): ...
06
공유 상태보다 매개변수와 반환값을 먼저 고려한다.count = increase(count)

zip 길이 규칙

기본값은 가장 짧은 입력까지만 묶습니다. 길이가 같아야 한다면 Python 3.10 이상의 strict=True로 누락을 오류로 바꿉니다.

sorted와 list.sort

sorted는 모든 반복 가능한 객체에서 새 리스트를 반환합니다. list.sort()는 원본 리스트를 바꾸고 None을 반환합니다.

빈 반복 가능 객체

all([])은 True, any([])는 False입니다. 반례도 참인 요소도 없다는 논리입니다.

람다 지연 바인딩

바깥 이름은 호출 시 검색될 수 있습니다. 반복 중 현재 값을 고정하려면 lambda n=n: n처럼 기본값을 이용합니다.

가독성 판단

map·filter가 항상 리스트 표현식보다 우수한 것은 아닙니다. 이름 있는 기존 함수를 전달하거나 지연 파이프라인이 필요하면 내장 함수가 자연스럽고, 짧은 변환과 조건을 즉시 목록으로 만들 때는 리스트 표현식이 더 읽기 쉬울 수 있습니다.

도구 공통 진단 코드

import inspect

rate = 0.1

def calculate(price):
    discounted = price * (1 - rate)
    print("지역:", locals())
    return discounted

print("시그니처:", inspect.signature(calculate))
print("전역 rate:", globals()["rate"])
print("결과:", calculate(10000))
  • locals(): 현재 실행 프레임의 지역 이름
  • globals(): 현재 모듈의 전역 이름
  • callable(): 호출 가능한 객체인지 판정
  • type(): map·filter·zip·enumerate 반환 자료형 확인
  • help()·inspect.signature(): 매개변수 구조 확인
디버깅 주의

디버거의 평가 창에서 list(iterator)를 실행해도 반복자가 실제로 소비됩니다. 관찰 자체가 프로그램 상태를 바꿀 수 있으므로 필요하면 반복자를 새로 생성하거나 처음부터 리스트에 저장합니다. 또한 locals()는 진단용으로 읽고, 반환된 딕셔너리를 수정해 지역변수를 제어하는 방식에는 의존하지 않습니다.

EXAMPLE 05

클로저와 nonlocal 미리보기

def make_counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase

counter = make_counter()
print(counter())
print(counter())
실행 결과
1
2

06 · Mistakes & Errors

오류의 마지막 줄에서 종류와 이름을 찾고, 생성·범위·소비 단계 중 어디가 잘못됐는지 판정한다

SyntaxError

람다에 return 또는 문장 작성

# 잘못된 문법
# lambda number: return number * 2

람다 본문은 표현식 하나이며 결과를 자동 반환합니다. lambda number: number * 2로 고칩니다.

TypeError

람다 호출 인수 누락

add = lambda first, second: first + second
# add(10)

missing 1 required positional argument: 'second'는 두 번째 인수가 빠졌다는 뜻입니다.

NameError

지역변수를 함수 밖에서 조회

def calculate():
    result = 100

# print(result)

지역값이 필요하면 return으로 반환하고 호출 위치의 변수에 저장합니다.

UnboundLocalError

대입 전에 지역 이름 읽기

count = 0

def increase():
    count += 1

대입이 있어 count가 지역 이름으로 판정됐지만 값은 없습니다. 매개변수·반환값을 우선 검토합니다.

SyntaxError

이름 사용 뒤 global 선언

# def change():
#     print(count)
#     global count

name 'count' is used prior to global declaration이면 선언을 함수 안의 첫 사용보다 앞에 둡니다.

TypeError

내장 이름 가리기

list = [10, 20]
# values = list(range(3))

'list' object is not callable은 변수 list가 내장 함수를 가렸다는 신호입니다.

Silent Data Loss

zip의 짧은 입력 종료

names = ["A", "B", "C"]
scores = [90, 80]
print(list(zip(names, scores)))

오류 없이 C가 사라질 수 있습니다. 길이를 검사하거나 지원 버전에서 strict=True를 씁니다.

KeyError

정렬 키가 없는 딕셔너리

rows = [{"score": 90}, {"name": "민수"}]
# sorted(rows, key=lambda row: row["score"])

필수 키를 사전 검증하거나 정책에 따라 row.get("score", 0)처럼 기본값을 정합니다.

Iterator Exhaustion

소진된 반복자 재사용

mapped = map(str, [1, 2])
print(list(mapped))
print(list(mapped))

두 번째 결과는 빈 목록입니다. 여러 번 필요하면 처음 한 번 리스트로 저장합니다.

Late Binding

반복문 람다가 모두 마지막 값 조회

functions = [lambda: number for number in range(3)]
print([function() for function in functions])

결과는 [2, 2, 2]입니다. 현재 값 고정이 필요하면 lambda number=number: number를 사용합니다.

StopIteration

끝난 반복자에 next 호출

iterator = iter([10])
print(next(iterator))
# print(next(iterator))

첫 호출이 마지막 값을 소비했습니다. 반복문은 이 신호를 내부에서 처리하지만 직접 next를 쓸 때는 기본값을 주거나 종료를 처리합니다.

RequestException

웹 요청 경계의 연결·시간 초과·HTTP 오류

try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
except requests.RequestException as error:
    print("요청 실패:", error)

람다나 선택자 오류보다 먼저 요청 자체가 실패했을 수 있습니다. 오류 계층을 네트워크 → HTTP → HTML → 선택자 순서로 나눠 읽습니다.

TypeError

map 객체를 인덱싱하거나 len으로 확인

mapped = map(int, ["10", "20"])
# print(mapped[0])
# print(len(mapped))

'map' object is not subscriptable 또는 object of type 'map' has no len()이 나타납니다. 인덱싱·길이·재사용이 필요하면 values = list(mapped)로 한 번 구체화합니다.

ValueError

zip(..., strict=True) 입력 길이 불일치

names = ["민수", "지수"]
scores = [90]
# list(zip(names, scores, strict=True))

Python 3.10 이상에서 zip() argument 2 is shorter than argument 1과 같은 메시지가 납니다. 조용한 데이터 누락을 막기 위해 두 입력의 생성 단계와 길이를 확인합니다.

TypeError

enumerate의 start에 문자열 전달

names = ["민수", "지수"]
# enumerate(names, start="1")

'str' object cannot be interpreted as an integer는 시작 번호가 정수가 아니라는 뜻입니다. 화면에 문자열로 표시하더라도 start=1처럼 정수를 전달합니다.

TypeError

서로 비교할 수 없는 자료형을 그대로 정렬

values = [10, "20", 3]
# sorted(values)

정수와 문자열의 크기를 직접 비교할 수 없습니다. 먼저 자료형을 정규화하거나 sorted(values, key=int)처럼 의도에 맞는 비교 기준을 전달합니다.

TypeError

key에 함수 객체가 아니라 호출 결과 전달

def get_score(student):
    return student["score"]

# sorted(students, key=get_score())

get_score()는 정렬 전에 즉시 호출되어 필수 인수 누락 오류가 납니다. sorted(students, key=get_score)처럼 괄호 없이 함수 객체를 전달합니다.

Unexpected None

list.sort() 반환값을 정렬된 리스트로 저장

scores = [80, 95, 70]
result = scores.sort()
print(result)  # None

sort()는 원본 scores를 바꾸고 None을 반환합니다. 새 리스트가 필요하면 result = sorted(scores)를 사용합니다.

오류 메시지 읽는 순서 ① Traceback 마지막 줄의 오류 종류 ② 오류 이름·인수·키 확인 ③ 표시된 사용자 코드 줄로 이동 ④ 함수 생성·이름 검색·반복자 소비 단계 판정 ⑤ 최소 입력으로 다시 실행

def load_users(connection):
    with connection.cursor() as cursor:
        cursor.execute(
            "SELECT id, name, score "
            "FROM users "
            "WHERE score IS NOT NULL "
            "ORDER BY score DESC"
        )
        return cursor.fetchall()

Q1. 람다 표현식이란 무엇인가요?

표현식 하나로 짧은 함수 객체를 만드는 문법입니다. 콜론 오른쪽 표현식의 결과를 자동 반환하며 정렬 키나 간단한 변환·판정 함수를 그 자리에서 전달할 때 유용합니다.

Q2. def와 lambda의 차이는 무엇인가요?

def는 여러 문장·독스트링·명확한 이름에 적합하고, 람다는 표현식 하나만 허용합니다. 복잡한 업무 규칙은 def, 짧은 일회성 규칙은 람다가 읽기 좋습니다.

Q3. 함수 이름과 함수 호출의 차이는 무엇인가요?

function은 함수 객체 자체이고 function()은 지금 호출한 반환값입니다. sorted(key=...)에는 보통 괄호 없는 함수 객체를 전달합니다.

Q4. Python의 LEGB 규칙은 무엇인가요?

이름을 Local, Enclosing, Global, Built-in 순서로 검색하는 규칙입니다. 가까운 영역에서 이름을 발견하면 바깥 영역의 같은 이름을 더 찾지 않습니다.

Q5. 지역변수와 전역변수의 차이는 무엇인가요?

지역변수는 함수 호출 프레임에 속하고 기본적으로 함수 안에서만 사용합니다. 전역변수는 현재 모듈 최상위 네임스페이스에 속합니다.

Q6. 전역변수를 읽을 때도 global이 필요한가요?

아닙니다. 읽기만 하면 LEGB 검색으로 전역 이름을 찾습니다. 함수 안에서 그 전역 이름을 다시 대입하려 할 때 global이 필요합니다.

Q7. UnboundLocalError는 왜 발생하나요?

함수 안의 대입 때문에 이름이 지역으로 판정됐지만 값을 대입하기 전에 읽으려 할 때 발생합니다. 전역값이 같은 이름으로 있어도 지역 판정이 우선합니다.

Q8. 객체 변경과 이름 재대입은 어떻게 다른가요?

items.append()는 기존 리스트 객체의 내용을 바꾸고, items = []는 이름을 새 객체에 연결합니다. 후자로 전역 이름을 바꾸려면 global이 필요합니다.

Q9. nonlocal은 언제 사용하나요?

중첩 함수에서 가장 가까운 바깥 함수 영역의 이름을 다시 대입할 때 사용합니다. 모듈 전역을 가리키는 global과 대상 범위가 다릅니다.

Q10. 클로저란 무엇인가요?

중첩 함수가 바깥 함수 실행이 끝난 뒤에도 필요한 바깥 변수를 기억하고 사용하는 구조입니다. 상태를 캡슐화한 함수 생성에 활용할 수 있습니다.

Q11. map과 filter의 차이는 무엇인가요?

map은 각 요소를 함수 결과로 변환하고, filter는 판정 결과가 참인 원래 요소만 통과시킵니다. 둘 다 Python 3에서 지연 반복자를 반환합니다.

Q12. map과 리스트 표현식 중 무엇이 더 좋은가요?

항상 한쪽이 우수하지 않습니다. 기존 함수 전달과 지연 파이프라인에는 map이 자연스럽고, 단순 변환을 즉시 리스트로 만들 때는 리스트 표현식이 더 명확할 수 있습니다.

Q13. zip 입력 길이가 다르면 어떻게 되나요?

기본적으로 가장 짧은 입력이 끝날 때 멈춰 남은 값은 결과에서 사라집니다. 길이가 같아야 한다면 사전 검사나 지원 버전의 strict=True를 사용합니다.

Q14. enumerate의 장점은 무엇인가요?

수동 인덱스 증가 없이 순번과 요소를 함께 제공하므로 오프바이원 오류를 줄입니다. 사용자 순번이라면 start=1을 명시할 수 있습니다.

Q15. sorted와 list.sort는 어떻게 다른가요?

sorted는 반복 가능한 객체에서 새 리스트를 만들고 원본을 보존합니다. list.sort()는 리스트 원본을 정렬하고 None을 반환합니다.

Q16. sorted의 key에는 무엇을 전달하나요?

각 요소를 받아 비교 기준값을 반환할 함수 객체를 전달합니다. 정렬 결과에는 키 값이 아니라 원래 요소가 들어갑니다.

Q17. 안정 정렬이란 무엇인가요?

정렬 키가 같은 요소끼리는 원래 상대 순서를 유지하는 정렬입니다. Python의 정렬은 안정적이어서 여러 단계 정렬을 예측하기 쉽습니다.

Q18. all과 any의 차이는 무엇인가요?

all은 모든 요소가 참일 때 참이고 거짓 하나에서 종료합니다. any는 하나 이상 참이면 참이고 참 하나에서 종료합니다.

Q19. all([])과 any([])의 결과는 무엇인가요?

all([])은 반례가 없어 True, any([])는 참인 요소가 없어 False입니다. 빈 입력을 유효하게 볼지는 별도로 검사해야 합니다.

Q20. 지연 반복자의 장점과 주의점은 무엇인가요?

필요한 순간 값을 하나씩 생산해 중간 목록 생성을 줄일 수 있습니다. 그러나 한 번 끝까지 소비하면 다시 읽을 값이 없으므로 재사용 여부를 설계해야 합니다.

Q21. 반복문 안에서 만든 람다가 모두 마지막 값을 반환하는 이유는 무엇인가요?

람다가 각 값을 즉시 복사하지 않고 같은 바깥 이름을 호출 시점에 검색하기 때문입니다. 현재 값을 고정하려면 기본 매개변수 등 명시적인 캡처 방식을 씁니다.

Q22. DB 입력 전에 all을 사용할 때 주의할 점은 무엇인가요?

전체 행의 유효성을 확인하기 좋지만 빈 입력에서도 True이므로 최소 한 행이 필요한 업무 규칙은 if not rows로 따로 검사해야 합니다.

Q23. HTTP 200이면 크롤링 선택도 성공한 것인가요?

아닙니다. HTTP 성공은 통신 계층 결과이고 CSS 선택자 일치는 문서 구조 계층의 결과입니다. 상태 코드와 선택 결과를 별도로 검사해야 합니다.

Q24. 데이터 분석 변환 뒤 무엇을 확인해야 하나요?

shape, 처리 방향인 axis, 열별 dtype, 결측치 개수, 원본 변경 여부를 전후로 비교해야 합니다.

Q25. 대량 DB 행도 Python의 filter와 sorted로 처리하면 되나요?

가능하더라도 불필요한 데이터 전송과 메모리 사용이 커질 수 있습니다. 가능한 필터와 정렬은 SQL의 WHERE·ORDER BY로 먼저 수행하고 Python은 작은 후처리를 담당하게 합니다.

Q26. dict(zip(columns, row))의 위험은 무엇인가요?

길이가 다르면 기본 zip이 조용히 짧은 쪽에서 멈춰 열이나 값이 누락될 수 있습니다. 길이 일치가 계약이라면 지원 버전에서 strict=True를 사용합니다.

Q27. CSS 선택자 문법 오류와 단순 미일치는 어떻게 다른가요?

문법 오류는 선택자 파서가 예외를 발생시키고, 문법은 맞지만 현재 HTML과 일치하지 않으면 보통 None이나 빈 목록이 반환됩니다. 두 경우의 수정 지점이 다릅니다.

Q28. Python map과 Pandas Series.map은 같은 함수인가요?

아닙니다. 내장 map은 일반 iterable에서 지연 반복자를 만들고, Series.map은 Series 값에 함수나 매핑을 적용해 인덱스를 유지한 Series를 반환합니다.

Q29. Pandas에서 람다보다 벡터화 연산을 우선하는 이유는 무엇인가요?

열 단위 연산이 더 간결하고 대체로 빠르며 결측치와 dtype 처리도 Pandas의 연산 규칙을 일관되게 활용할 수 있기 때문입니다.

Q30. figure, axes = plt.subplots()와 zip(*ordered)의 별표는 같은 언패킹인가요?

figure, axes = ...는 반환값 대입 언패킹입니다. zip(*ordered)의 별표는 호출할 때 iterable 요소를 위치 인수로 푸는 호출 인수 언패킹입니다.

Q31. 모듈을 나누면 global 변수도 하나로 공유되나요?

각 모듈은 자신의 전역 네임스페이스를 가집니다. 다른 모듈의 이름은 보통 모듈 객체를 통해 module.name으로 접근하며, 무분별한 전역 상태 공유보다 명시적인 함수 인수와 반환을 우선합니다.

MEMORY · 오늘의 암기 포인트

시험·면접·실습 전 20문장

  1. Python에서 함수도 변수에 저장하고 인수로 전달할 수 있는 객체다.
  2. 함수 이름은 객체이고 괄호를 붙이면 호출 결과다.
  3. 람다는 표현식 하나로 짧은 함수 객체를 만든다.
  4. 람다는 return 없이 표현식 결과를 자동 반환한다.
  5. 복잡한 로직과 재사용 함수에는 def가 읽기 쉽다.
  6. 이름은 Local → Enclosing → Global → Built-in 순서로 찾는다.
  7. 함수 안의 대입 대상은 기본적으로 지역 이름이다.
  8. 전역 이름을 읽기만 할 때는 global이 필요 없다.
  9. 전역 이름을 재대입할 때 global을 사용한다.
  10. nonlocal은 가장 가까운 바깥 함수의 이름을 재대입한다.
  11. 객체 내용 변경과 이름 재대입은 다른 동작이다.
  12. map은 모든 요소를 변환한다.
  13. filter는 판정이 참인 원래 요소를 통과시킨다.
  14. zip은 같은 위치를 묶고 기본적으로 가장 짧은 입력에서 멈춘다.
  15. enumerate는 순번과 요소를 함께 제공한다.
  16. sorted는 원본을 보존하고 새 리스트를 반환한다.
  17. all은 거짓 하나, any는 참 하나에서 결과가 결정된다.
  18. all([])은 True, any([])는 False다.
  19. map·filter·zip·enumerate는 지연 반복자다.
  20. 한 번 소비한 반복자는 다시 읽을 값이 없을 수 있다.

이름을 찾는 범위를 배웠다면 코드를 모듈과 패키지로 나눈다

이번 단원에서 전역 영역은 현재 Python 모듈의 네임스페이스라고 배웠습니다. 다음에는 함수를 별도 .py 파일로 나누고 import하여 재사용하는 모듈과, 여러 모듈을 폴더 구조로 묶는 패키지로 확장합니다. 이때 각 모듈이 자신의 전역 네임스페이스를 가진다는 사실이 중요합니다.

이번 단원LEGB→ 파일 분리module→ 코드 사용import→ 이름 접근module.name→ 구조화package 
# score_tools.py
PASS_SCORE = 60

def is_passed(score):
    return score >= PASS_SCORE

def main():
    print(is_passed(80))

if __name__ == "__main__":
    main()

# main.py · 모듈 이름을 유지하는 import
import score_tools
print(score_tools.is_passed(75))

# 필요한 이름을 직접 가져오는 방식
from score_tools import is_passed
print(is_passed(90))

모듈별 Global

score_tools.PASS_SCORE와 main.py의 전역 이름은 서로 다른 모듈 네임스페이스에 속합니다.

__name__ 경계

파일을 직접 실행하면 __name__ == "__main__"이고, import되면 모듈 이름이 들어가므로 테스트 실행과 재사용 코드를 분리할 수 있습니다.

score_tools.is_passed처럼 모듈 이름을 붙이면 함수가 어느 네임스페이스에서 왔는지 분명합니다. 함수 객체·변수 범위·내장 함수에 대한 이해가 모듈 재사용과 이름 충돌 방지의 기반이 됩니다.

연결 포인트: 함수의 Local·Enclosing 범위에서 출발해 모듈별 Global 영역과 Python의 import 시스템으로 학습 범위를 넓힙니다.
