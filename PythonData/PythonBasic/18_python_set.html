01 · Why Set?

왜 집합이 필요한가?

프로그램을 만들다 보면 같은 값이 여러 번 들어오는 경우가 많습니다. 같은 상품 코드가 여러 번 수집되거나, 같은 사용자가 같은 게시글에 여러 번 접근하거나, 설문 응답에서 같은 선택지가 반복될 수 있습니다. 이때 모든 값을 그대로 보관해야 한다면 리스트가 어울립니다. 하지만 값의 존재 여부나 중복 없는 목록이 중요하다면 집합이 더 자연스럽습니다.

크롤링 URL, 태그, 카테고리, 회원 ID처럼 고유값이 중요한 데이터에 자주 씁니다.

unique_ids = set(ids)

리스트가 “받은 순서대로 줄 세운 목록”이라면, 집합은 “같은 이름표는 하나만 남기는 고유값 상자”입니다. 그래서 집합은 data[0]처럼 첫 번째 값을 꺼내는 용도가 아니라, "서울" in cities처럼 값의 존재를 묻거나 old_tags & new_tags처럼 두 묶음을 비교하는 데 사용합니다.

02 · Use Cases

어떤 상황에서 집합을 사용하는가?

중복 제거

크롤링한 URL, 게시글 ID, 이메일 주소처럼 같은 값이 여러 번 들어올 때 사용합니다.

공통 데이터 찾기

두 반에 모두 등록된 학생, 두 상품을 모두 구매한 고객을 찾을 때 교집합을 씁니다.

누락 데이터 찾기

전체 회원 목록에서 결제한 회원을 빼면 미결제 회원을 찾을 수 있습니다.

권한과 태그 관리

사용자 권한, 게시글 태그, 관심 키워드처럼 고유값 묶음이 필요한 곳에 적합합니다.

데이터 분석 전처리

카테고리의 종류, 지역의 종류, 결측 전후 컬럼 차이를 확인할 때 유용합니다.

변경 사항 비교

이전 데이터와 새 데이터를 비교해 추가된 값과 사라진 값을 추적합니다.

값이 여러 개 있다 → 중복이 의미 없다 → 순서보다 존재 여부가 중요하다 → set 사용

03 · Syntax

문법과 개념은 무엇인가?

집합은 중괄호 안에 값을 쉼표로 구분해서 만들거나, set() 함수에 반복 가능한 객체를 넣어 만들 수 있습니다. 단, {}는 빈 집합이 아니라 빈 딕셔너리입니다. 빈 집합은 반드시 set()으로 만들어야 합니다.

LITERAL

값이 있는 집합

numbers = {1, 2, 3, 3}
print(numbers)

중복된 3은 하나만 남습니다.

EMPTY

빈 집합

empty_set = set()
empty_dict = {}

print(type(empty_set))
print(type(empty_dict))

{}는 딕셔너리라는 점이 중요합니다.

CONVERT

리스트에서 변환

names = ["민지", "하준", "민지"]
unique_names = set(names)

print(unique_names)

리스트의 중복값을 제거할 때 자주 씁니다.

개념 설명 초보자 주의점
중복 불가 같은 값은 한 번만 저장됩니다. 중복 횟수를 세야 하면 리스트나 딕셔너리가 더 적합합니다.
순서 없음 출력 순서나 반복 순서를 학습 로직의 기준으로 삼지 않습니다. data[0]처럼 인덱싱할 수 없습니다.
변경 가능 add(), remove() 등으로 원본 집합을 바꿀 수 있습니다. 함수에 전달할 때 원본 변경 여부를 생각해야 합니다.
해시 가능한 요소 집합 요소는 빠른 비교를 위해 해시 가능한 값이어야 합니다. 리스트, 딕셔너리, 집합 자체는 일반적으로 집합 요소가 될 수 없습니다.

왜 리스트를 집합 안에 넣을 수 없을까요?

집합은 “이 값이 이미 있나?”를 빠르게 판단해야 합니다. 그러려면 값이 변하지 않는 기준으로 비교되어야 합니다. 리스트는 내부 값이 바뀔 수 있기 때문에 집합의 요소로 사용할 수 없습니다. 반면 문자열, 숫자, 튜플처럼 해시 가능한 값은 집합 요소로 사용할 수 있습니다.

04 · Execution Flow

코드는 어떤 순서로 동작하는가?

집합 코드는 “값을 준비한다 - 집합으로 변환한다 - 중복이 제거된다 - 필요한 연산을 한다 - 결과를 확인한다”의 순서로 읽으면 쉽습니다. 아래 예제는 수강생이 선택한 관심 분야에서 중복을 제거하고, 필수 분야와 비교하는 흐름입니다.

예제 코드

selected_tracks = [
    "Python",
    "Database",
    "Python",
    "Web Crawling",
    "Data Analysis"
]

required_tracks = {"Python", "Database", "Data Analysis"}

unique_tracks = set(selected_tracks)
completed_required = unique_tracks & required_tracks
missing_required = required_tracks - unique_tracks

print(unique_tracks)
print(completed_required)
print(missing_required)

실행 결과를 읽는 법

{'Python', 'Database', 'Web Crawling', 'Data Analysis'}
{'Python', 'Database', 'Data Analysis'}
set()

unique_tracks에서 중복된 "Python"은 하나만 남습니다. &는 공통 관심 분야를 찾고, -는 아직 없는 필수 분야를 찾습니다. 마지막 결과가 set()이면 빠진 필수 항목이 없다는 뜻입니다.

05 · Set Operations

합집합, 교집합, 차집합, 대칭 차집합

집합의 가장 큰 장점은 두 데이터 묶음을 비교하는 문법이 짧고 명확하다는 점입니다. 연산자는 빠르게 읽기 좋고, 메서드는 이름으로 의미를 설명하기 좋습니다. 처음에는 연산자와 메서드를 한 쌍으로 외우면 좋습니다.

A

{"Python", "DB", "React"}

B

{"Python", "DB", "Spring"}
|

합집합

A 또는 B에 있는 모든 값을 모읍니다. 중복은 제거됩니다.

a | b
a.union(b)
{"Python", "DB", "React", "Spring"}
&

교집합

A와 B에 모두 있는 공통값만 남깁니다.

a & b
a.intersection(b)
{"Python", "DB"}
-

차집합

A에서 B와 겹치는 값을 빼고 A에만 있는 값을 남깁니다.

a - b
a.difference(b)
{"React"}
^

대칭 차집합

A와 B의 공통값을 제외하고 한쪽에만 있는 값들을 남깁니다.

a ^ b
a.symmetric_difference(b)
{"React", "Spring"}

차집합은 방향이 중요합니다

a - b와 b - a는 결과가 다릅니다. a - b는 “A에는 있지만 B에는 없는 값”이고, b - a는 “B에는 있지만 A에는 없는 값”입니다. 실무에서는 “신규 데이터”와 “삭제된 데이터”를 구분할 때 이 방향을 자주 사용합니다.

06 · Methods

집합에 값을 추가하고 삭제하는 방법

add(value)

값 하나를 추가합니다. 이미 있으면 변화가 없습니다.

tags = {"python", "db"}
tags.add("python")
tags.add("react")
print(tags)

update(iterable)

여러 값을 한 번에 추가합니다. 문자열을 넣으면 문자 단위로 들어가니 주의합니다.

tags = {"python"}
tags.update(["db", "react"])
print(tags)

remove(value)

값을 삭제합니다. 값이 없으면 KeyError가 발생합니다.

tags = {"python", "db"}
tags.remove("db")
print(tags)

discard(value)

값을 삭제합니다. 값이 없어도 에러가 나지 않습니다.

tags = {"python", "db"}
tags.discard("react")
print(tags)

REMOVE

반드시 있어야 하는 값을 지울 때

삭제 대상이 없으면 에러를 내기 때문에, “이 값은 반드시 있어야 정상”이라는 검증 효과가 있습니다. 

users = {"민지", "하준"}
users.remove("서연")

# KeyError: '서연'

DISCARD

있으면 지우고 없어도 넘어갈 때

삭제 대상이 없어도 조용히 넘어가므로, 반복 정리나 선택 해제 처리에 적합합니다. 

users = {"민지", "하준"}
users.discard("서연")

print(users)
원본을 바꾸는 메서드 같은 의미의 연산 결과
update(other) | 현재 집합에 합집합 결과를 저장합니다.
intersection_update(other) & 현재 집합에 교집합 결과를 저장합니다.
difference_update(other) - 현재 집합에서 다른 집합의 값을 뺀 결과를 저장합니다.
symmetric_difference_update(other) ^ 현재 집합에 서로 겹치지 않는 값만 저장합니다.

실무에서는 어디에 쓰이는가?

raw_urls = [

regions = ["서울", "부산", "서울", "대구"]

print(len(unique_regions))

current_roles = {"read", "write"}

missing_roles = required_roles - current_roles

사용자에게 부족한 권한이 무엇인지 찾습니다.

태그 변경 추적

old_tags = {"python", "db", "basic"}

added = new_tags - old_tags
removed = old_tags - new_tags

print(added)
print(removed)

추가된 태그와 제거된 태그를 분리해서 기록할 수 있습니다.

집합 표현식도 알아두기

리스트 표현식처럼 집합도 한 줄로 만들 수 있습니다. 결과가 집합이므로 중복값은 자동으로 제거됩니다. 

numbers = [1, 2, 2, 3, 4, 4, 5]
even_squares = {number ** 2 for number in numbers if number % 2 == 0}

print(even_squares)

실행 결과는 {16, 4}처럼 순서가 고정되지 않을 수 있습니다.

08 · Common Mistakes

자주 하는 실수와 에러 읽기

빈 집합을 {}로 만듭니다

empty = {}
print(type(empty))

# <class 'dict'>

빈 집합은 set()으로 만듭니다.

집합을 인덱스로 꺼내려 합니다

numbers = {10, 20, 30}
print(numbers[0])

# TypeError: 'set' object is not subscriptable

집합에는 위치 번호가 없습니다. 필요하면 리스트로 변환한 뒤 사용합니다.

출력 순서에 의존합니다

print({"A", "B", "C"})

보이는 순서가 항상 학습자가 입력한 순서와 같다고 생각하면 안 됩니다.

없는 값을 remove()로 지웁니다

tags = {"python"}
tags.remove("react")

# KeyError: 'react'

없어도 괜찮은 삭제라면 discard()를 사용합니다.

리스트를 집합 요소로 넣습니다

items = {[1, 2], [3, 4]}

# TypeError: unhashable type: 'list'

집합 요소는 해시 가능해야 합니다. 필요하다면 튜플로 바꿉니다.

반복 중 원본을 바꿉니다

numbers = {1, 2, 3}

for number in numbers:
    numbers.remove(number)

반복 중 원본 크기를 바꾸면 에러나 누락이 생길 수 있습니다. 복사본을 반복하세요.

09 · Interview Points

면접에서는 “특징과 선택 이유”를 설명한다

Q1. Python의 set은 무엇인가요?

중복을 허용하지 않고 순서를 보장하지 않는 변경 가능한 컬렉션입니다. 값의 존재 여부 확인, 중복 제거, 집합 연산에 사용합니다.

Q2. 빈 집합은 어떻게 만드나요?

set()으로 만듭니다. {}는 빈 집합이 아니라 빈 딕셔너리입니다.

Q3. 집합은 왜 인덱싱할 수 없나요?

집합은 위치 순서를 기준으로 값을 저장하는 자료형이 아니기 때문입니다. 특정 위치의 값이 필요하면 리스트나 튜플을 사용해야 합니다.

Q4. remove()와 discard()의 차이는 무엇인가요?

remove()는 삭제할 값이 없으면 KeyError를 발생시키고, discard()는 값이 없어도 에러 없이 넘어갑니다.

Q5. 합집합과 교집합은 어떻게 표현하나요?

합집합은 a | b 또는 a.union(b), 교집합은 a & b 또는 a.intersection(b)로 표현합니다.

Q6. 리스트를 집합으로 바꾸면 어떤 장단점이 있나요?

중복이 제거되고 포함 여부 확인과 비교 연산이 쉬워집니다. 대신 원래 순서와 중복 횟수 정보는 잃을 수 있습니다.

집합 단원에서는 “여러 값 중 고유한 값만 남기고 비교하는 방법”을 배웠습니다. 다음 함수 단원에서는 이런 처리 흐름을 재사용 가능한 코드 묶음으로 만들게 됩니다. 예를 들어 URL 중복 제거, 권한 비교, 태그 변경 추적을 매번 직접 쓰지 않고 함수로 분리할 수 있습니다.

지금까지는 직접 실행

urls = ["/a", "/b", "/a"]
unique_urls = set(urls)
print(unique_urls)

다음 단원에서는 함수로 분리

def make_unique(values):
    return set(values)

print(make_unique(["/a", "/b", "/a"]))

MEMORY · 오늘의 암기 포인트

집합은 “중복 없는 값의 묶음”이다

  1. 집합은 중복을 허용하지 않습니다.
  2. 집합은 순서를 보장하지 않습니다.
  3. 집합은 인덱싱과 슬라이싱을 지원하지 않습니다.
  4. 빈 집합은 set()으로 만듭니다.
  5. {}는 빈 딕셔너리입니다.
  6. |는 합집합입니다.
  7. &는 교집합입니다.
  8. -는 차집합입니다.
  9. ^는 대칭 차집합입니다.
  10. remove()는 없는 값을 지우면 에러가 납니다.
  11. discard()는 없는 값을 지워도 에러가 나지 않습니다.
  12. 집합 요소는 해시 가능한 값이어야 합니다.

CONFUSION · 헷갈리기 쉬운 개념

비슷해 보여도 선택 기준이 다르다

list vs set
순서와 중복이 중요하면 리스트, 고유값과 비교가 중요하면 집합입니다.
{} vs set()
{}는 빈 딕셔너리이고 set()이 빈 집합입니다.
remove() vs discard()
없는 값을 에러로 잡고 싶으면 remove(), 조용히 넘기려면 discard()입니다.
a - b vs b - a
차집합은 방향이 바뀌면 결과도 바뀝니다.
union() vs update()
union()은 새 결과를 만들고, update()는 원본을 바꿉니다.
