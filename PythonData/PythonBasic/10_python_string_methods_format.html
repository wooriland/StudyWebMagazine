Python Basics · Lesson 10

문자열 메서드와 형식 문자열

문자열 메서드는 문자열을 직접 수정하는 기능이 아니라, 문자열을 분리·결합·검색·교체·정리한 결과를 새로운 객체로 반환하는 기능입니다. 이번 단원에서는 split(), join(), replace(), strip(), find(), index(), count(), 대소문자 변환과 zfill()을 공부합니다. 이어서 % 포매팅과 str.format()으로 값의 위치, 출력 폭, 정렬, 소수점 자릿수와 백분율을 표현하는 방법을 정리합니다.

split() join() replace() strip() find() index() count() upper() lower() zfill() % Formatting str.format()

이 단원의 중심 질문

하나의 긴 문자열을 어떻게 정리하고 분리하며, 여러 값을 읽기 좋은 문장과 표로 표현할까요?

외부에서 받은 문자열은 공백, 구분자, 대소문자와 숫자 문자열이 섞여 있을 수 있습니다. 문자열 메서드로 데이터를 정리하고 필요한 자료형으로 변환한 뒤, 형식 문자열을 이용해 사람이 이해하기 쉬운 결과 문자열을 만듭니다.

학습 목표

  • 문자열 메서드의 호출 구조와 반환값을 설명할 수 있습니다.
  • 문자열 메서드가 원본을 직접 변경하지 않는 이유를 문자열 불변성과 연결할 수 있습니다.
  • split()으로 문자열을 리스트로 분리할 수 있습니다.
  • split()과 split(" ")의 차이를 설명할 수 있습니다.
  • join()으로 문자열 목록을 하나의 문자열로 결합할 수 있습니다.
  • replace()와 strip() 계열로 문자열을 정리할 수 있습니다.
  • find()와 index()의 검색 실패 동작을 구분할 수 있습니다.
  • count()로 부분 문자열의 출현 횟수를 확인할 수 있습니다.
  • 대소문자 변환과 zfill()을 데이터 정규화에 활용할 수 있습니다.
  • %s, %d, %.2f의 의미를 설명할 수 있습니다.
  • format()의 위치 필드와 이름 필드를 사용할 수 있습니다.
  • 정렬, 출력 폭, 천 단위 쉼표, 소수점과 백분율 형식을 지정할 수 있습니다.
  • DB 플레이스홀더와 Python 문자열 포매팅을 구분할 수 있습니다.
  • 웹크롤링과 Pandas 문자열 처리에 현재 단원의 개념을 연결할 수 있습니다.

def demonstrate_pipeline() -> None:
    """문자열 정리와 형식화를 연결한다."""

    print_section(
        "9. 문자열 처리 파이프라인"
    )

    raw_data = (
        "  KIM,20,Python,85.75  "
    )

    fields = (
        raw_data
        .strip()
        .split(",")
    )

    name = fields[0].title()
    age = int(fields[1])
    language = fields[2]
    score = float(fields[3])

    result = (
        "이름: {name:<8} | "
        "나이: {age:>3}세 | "
        "과목: {language:^10} | "
        "점수: {score:>6.2f}"
        .format(
            name=name,
            age=age,
            language=language,
            score=score,
        )
    )

    print(result)

10 · Common Mistakes

초보자가 자주 하는 문자열 메서드 실수

01

메서드가 원본을 바꾼다고 생각합니다

문자열은 불변 객체이므로 반환값을 저장해야 합니다.

02

split() 결과를 문자열로 생각합니다

split() 결과는 리스트입니다.

03

join()을 리스트에서 호출합니다

구분자 문자열에서 호출해야 합니다.

04

숫자 리스트를 바로 join()합니다

모든 요소를 문자열로 변환해야 합니다.

05

split()과 split(" ")을 같게 생각합니다

연속 공백과 빈 요소 처리 방식이 다릅니다.

06

strip()이 중간 공백도 제거한다고 생각합니다

양쪽 끝의 공백이나 문자만 제거합니다.

07

strip(".txt")로 확장자를 제거합니다

인수는 정확한 접미사가 아니라 문자 집합입니다.

08

find() 결과를 조건식에 바로 넣습니다

위치 0과 실패값 -1의 논리 평가 때문에 잘못된 결과가 나올 수 있습니다.

09

find()와 index()의 실패 동작을 혼동합니다

전자는 -1, 후자는 ValueError입니다.

10

replace()가 한 번만 교체한다고 생각합니다

기본적으로 모든 일치 부분을 교체합니다.

11

count()가 겹치는 위치도 모두 센다고 생각합니다

겹치지 않는 부분 문자열을 계산합니다.

12

% 값 여러 개를 튜플로 묶지 않습니다

여러 값은 튜플로 전달해야 합니다.

13

나머지 연산과 문자열 포매팅을 혼동합니다

왼쪽 피연산자의 자료형을 확인합니다.

14

퍼센트 문자에 %%를 사용하지 않습니다

기존 퍼센트 포매팅에서 문자 %는 %%로 출력합니다.

15

format() 위치 번호를 1부터 시작합니다

첫 번째 위치는 {0}입니다.

16

자동 필드와 수동 필드를 섞습니다

{} 또는 {0} 방식으로 통일합니다.

17

중괄호 자체를 한 번만 작성합니다

문자 중괄호는 {{, }}를 사용합니다.

18

문자열에 숫자 형식 코드를 적용합니다

먼저 int()나 float()로 변환해야 합니다.

19

DB의 %s를 Python 포매팅으로 처리합니다

DB 플레이스홀더는 드라이버에 맡겨야 합니다.

20

긴 메서드 체인을 한 번에 디버깅합니다

중간 결과를 변수로 나누어 확인합니다.

면접 포인트

문자열 메서드란 무엇입니까?

문자열 객체가 제공하는 기능입니다. 문자열.메서드() 형태로 호출하며 문자열이 불변 객체이므로 대부분 원본을 수정하지 않고 처리 결과를 새로운 객체로 반환합니다.

문자열 메서드를 호출했는데 원본이 바뀌지 않는 이유는 무엇입니까?

Python 문자열은 불변 객체입니다. upper(), strip(), replace() 등은 변경 결과를 가진 새 문자열을 반환합니다.

split()은 무엇을 반환합니까?

문자열을 지정한 기준으로 나누고, 각 부분 문자열을 요소로 담은 리스트를 반환합니다.

split()과 split(" ")의 차이는 무엇입니까?

인수가 없는 split()은 연속된 공백·탭·줄바꿈을 하나의 구분 영역으로 처리하고 앞뒤 공백을 무시합니다. split(" ")은 스페이스 한 칸을 명시적 구분자로 사용하므로 빈 요소가 만들어질 수 있습니다.

maxsplit은 무엇입니까?

문자열을 최대로 몇 번 분리할지 지정하는 인수입니다. 제한에 도달하면 나머지 문자열은 하나의 요소로 유지됩니다.

join()은 왜 구분자에서 호출합니까?

join()을 호출하는 문자열이 각 요소 사이에 삽입될 구분자 역할을 하기 때문입니다.

숫자 리스트를 join()하면 왜 오류가 발생합니까?

join()은 모든 요소가 문자열일 것을 요구합니다. str()이나 map(str, values)로 변환해야 합니다.

replace()는 원본을 변경합니까?

원본을 변경하지 않고 교체 결과를 담은 새 문자열을 반환합니다. 세 번째 인수로 최대 교체 횟수를 지정할 수 있습니다.

strip(chars)의 인수는 정확한 문자열입니까?

아닙니다. 제거할 문자들의 집합입니다. 양쪽 끝에서 해당 문자 중 하나가 반복해서 나타나는 동안 제거합니다.

find()와 index()의 차이는 무엇입니까?

둘 다 부분 문자열 위치를 반환하지만 검색 실패 시 find()는 -1을 반환하고, index()는 ValueError를 발생시킵니다.

포함 여부에는 왜 in이 더 적합합니까?

in은 바로 True 또는 False를 반환합니다. find()의 결과인 0과 -1을 조건식에 바로 넣으면 잘못 해석될 수 있습니다.

count()는 겹치는 부분도 모두 셉니까?

아닙니다. 겹치지 않는 부분 문자열의 출현 횟수를 반환합니다. "aaaa".count("aa")는 2입니다.

casefold()는 무엇입니까?

대소문자 구분 없는 Unicode 문자열 비교를 위해 문자열을 적극적으로 정규화하는 메서드입니다.

zfill()은 무엇을 합니까?

지정한 전체 길이가 될 때까지 문자열 왼쪽에 0을 채웁니다. 부호가 있는 경우 부호 뒤에 0을 삽입합니다.

% 포매팅과 나머지 연산은 어떻게 구분합니까?

왼쪽 피연산자가 숫자이면 나머지 연산이고, 왼쪽이 형식 지정자를 포함한 문자열이면 문자열 포매팅으로 동작합니다.

%.2f는 무엇을 의미합니까?

실수를 소수점 이하 두 자리까지 반올림하여 표현한다는 의미입니다.

기존 퍼센트 포매팅에서 문자 %는 어떻게 출력합니까?

%%처럼 두 번 작성합니다.

format() 위치 번호는 어디서 시작합니까?

0부터 시작합니다. 첫 번째 인수는 {0}, 두 번째 인수는 {1}입니다.

{:>10}은 무엇을 의미합니까?

최소 출력 폭 10을 확보하고 값을 오른쪽 정렬합니다. <는 왼쪽, ^는 가운데 정렬입니다.

{:,.2f}는 무엇을 의미합니까?

숫자에 천 단위 쉼표를 넣고 소수점 이하 두 자리까지 표시합니다.

{:.1%}는 무엇을 의미합니까?

값을 100배한 뒤 소수점 이하 한 자리의 백분율로 표현합니다.

중괄호 자체는 어떻게 출력합니까?

여는 중괄호는 {{, 닫는 중괄호는 }}로 두 번 작성합니다.

DB의 %s와 Python 퍼센트 포매팅은 같은 기능입니까?

아닙니다. DB 플레이스홀더는 드라이버가 SQL 구조와 값을 안전하게 결합하기 위한 자리이고, Python 퍼센트 포매팅은 문자열 자체를 생성하는 연산입니다.

Pandas 문자열 컬럼에는 메서드를 어떻게 적용합니까?

Series.str 접근자를 사용해 series.str.strip(), series.str.lower(), series.str.split()처럼 처리합니다.

오늘의 암기 포인트

  • 문자열은 불변 객체입니다.
  • 문자열 메서드는 대부분 새 결과 객체를 반환합니다.
  • 반환값을 저장하지 않으면 처리 결과를 다시 사용할 수 없습니다.
  • split()은 문자열을 리스트로 분리합니다.
  • join()은 문자열 목록을 하나의 문자열로 결합합니다.
  • join()의 모든 요소는 문자열이어야 합니다.
  • strip(chars)의 인수는 제거할 문자들의 집합입니다.
  • find()는 실패 시 -1입니다.
  • index()는 실패 시 ValueError입니다.
  • 포함 여부만 필요하면 in을 사용합니다.
  • %s는 문자열, %d는 정수입니다.
  • %.2f는 소수점 이하 두 자리입니다.
  • format() 위치 번호는 0부터 시작합니다.
  • DB 플레이스홀더와 문자열 포매팅은 서로 다른 기능입니다.
