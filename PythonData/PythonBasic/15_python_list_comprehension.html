01 · Core Concept

리스트 표현식은 반복·선택·변환을 이용해 새 리스트를 만든다

리스트 표현식은 기존 리스트를 짧게 적는 기능이 아니라, 반복 가능한 객체에서 값을 하나씩 가져와 필요한 계산과 조건을 적용하고 새로운 리스트를 생성하는 문법입니다. 맨 앞의 표현식은 일반 반복문의 append()에 전달할 값과 대응합니다.

[number ** 2 for number in range(1, 6)]
결과 표현식새 리스트에 저장할 값 반복 변수현재 값을 임시로 받음 반복 대상값을 차례대로 제공

일반 반복문

squares = []

for number in range(1, 6):
    squares.append(number ** 2)

빈 리스트, 반복, 변환, 추가 과정을 줄 단위로 확인합니다.

⇄

리스트 표현식

squares = [
    number ** 2
    for number in range(1, 6)
]

같은 생성 패턴을 하나의 표현으로 묶습니다.

01

변환

[x * 2 for x in data]

모든 입력값을 계산한 새 값으로 바꿉니다.

02

필터

[x for x in data if x > 0]

조건이 참인 입력값만 결과에 포함합니다.

03

조건부 변환

[x if x > 0 else 0 for x in data]

모든 입력을 유지하면서 결과값만 다르게 만듭니다.

04

중첩 반복

[(r, c) for r in rows for c in cols]

여러 반복 대상의 조합이나 2차원 결과를 만듭니다.

목적 문법 결과 길이 핵심 질문
복사 [x for x in data] 원본과 같음 그대로 담는가?
변환 [f(x) for x in data] 원본과 같음 무엇으로 바꾸는가?
필터링 [x for x in data if condition] 줄어들 수 있음 어떤 값을 제외하는가?
조건부 변환 [A if condition else B for x in data] 원본과 같음 참·거짓일 때 무엇을 담는가?
중첩 반복 [f(x, y) for x in xs for y in ys] 조합 수에 따라 증가 바깥·안쪽 순서는 무엇인가?
핵심 관찰 기준

표현식을 볼 때는 ① 무엇을 반복하는가, ② 어떤 조건에서 포함하는가, ③ 포함할 값을 무엇으로 변환하는가, ④ 결과가 몇 개가 되는가를 순서대로 확인합니다.

03 · Comprehension Rules

필터 위치·평가 방식·변수 범위를 구분한다

1. 변환은 앞, 반복은 뒤에 작성한다

결과값for현재 값in반복 대상
[transform(value) for value in data]

해석은 for value in data부터 시작하고, 포함할 값은 맨 앞에서 찾습니다.

2. 필터와 조건부 변환은 서로 다른 문법이다

Filter

[value for value in data if condition]

else가 없고 거짓인 요소를 제외합니다.

Conditional Expression

[A if condition else B for value in data]

else가 필요하고 모든 요소를 A 또는 B로 바꿉니다.

3. 여러 조건은 왼쪽에서 오른쪽으로 통과한다

targets = [
    number
    for number in range(1, 21)
    if number % 2 == 0
    if number % 3 == 0
]
짝수인가?→3의 배수인가?→결과에 추가

위 코드는 if number % 2 == 0 and number % 3 == 0과 같은 결과를 만듭니다.

4. 리스트 표현식은 결과를 즉시 계산한다

리스트 표현식

[x ** 2 for x in range(1_000_000)]

모든 결과를 계산해 리스트 전체를 메모리에 저장합니다.

제너레이터 표현식

(x ** 2 for x in range(1_000_000))

값을 요청할 때 하나씩 계산하며 전체 결과를 바로 저장하지 않습니다.

list(x ** 2 for x in data)는 제너레이터를 만든 뒤 list()가 모두 소비해 리스트로 바꿉니다.

5. 반복 변수는 표현식 내부에서만 사용한다

result = [number ** 2 for number in range(5)]
print(number)  # NameError

Python 3에서 number는 표현식 내부의 이름입니다. 바깥 변수와 같은 이름도 피하면 읽기 쉽습니다.

GOOD[f(x) for x in data]

변환 하나

GOOD[f(x) for x in data if valid(x)]

변환 하나 + 필터 하나

REVIEW[f(x, y) for x in xs for y in ys if ...]

중첩부터는 줄바꿈과 일반 반복문 비교

EXPAND[... for ... if ... for ... if ...]

설명하기 어렵다면 일반 반복문으로 확장

04 · Two-Dimensional Patterns

행을 만드는 안쪽 표현식과 행을 쌓는 바깥 표현식을 구분한다

Create

초기값으로 채우기

matrix = [
    [0 for column in range(3)]
    for row in range(2)
]

[[0, 0, 0], [0, 0, 0]]

Calculate

행·열 번호로 값 계산

matrix = [
    [row * 10 + column for column in range(3)]
    for row in range(2)
]

[[0, 1, 2], [10, 11, 12]]

Flatten

2차원을 1차원으로 펼치기

flat = [
    value
    for row in matrix
    for value in row
]

행을 고른 뒤 그 행의 값을 모두 추가합니다.

Transpose

행과 열 바꾸기

transposed = [
    [row[column] for row in matrix]
    for column in range(3)
]

열 번호를 고정하고 모든 행에서 같은 열을 꺼냅니다.

행 수len(matrix)바깥 리스트 길이
열 수len(matrix[0])첫 행이 존재하고 직사각형일 때
요소matrix[row][column]행 선택 후 열 선택
행별 길이[len(row) for row in matrix]불규칙 구조 진단

Ragged List

행마다 열 개수가 다를 수 있다

ragged = [
    [1, 2, 3],
    [4, 5],
    [6, 7, 8, 9],
]

lengths = [len(row) for row in ragged]
print(lengths)  # [3, 2, 4]
행 0 행 1 행 2

직사각형 여부: len(set(lengths)) == 1

2차원 데이터 안전 기준
  • 빈 리스트에서 matrix[0]에 접근하지 않습니다.
  • 모든 행의 길이가 같은지 확인한 뒤 열 번호를 고정합니다.
  • 가변 객체를 *로 반복해 내부 참조를 공유하지 않습니다.
  • 분석 배열로 변환하기 전 값의 자료형과 결측치를 확인합니다.

EXAMPLE 01

기본 변환

numbers = [1, 2, 3, 4, 5]
squares = [number ** 2 for number in numbers]

print(squares)
실행 결과

필터와 변환 결합

even_squares = [

실행 결과

조건부 변환

print(results)

['불합격', '합격', '합격', '합격', '불합격']

EXAMPLE 04

문자열 정제

raw_names = ["  minji ", "", " junho", "   "]
clean_names = [

]

print(clean_names)

공백을 제거했을 때 빈 문자열인 값은 제외합니다.

enumerate()와 딕셔너리 요소

names = ["민지", "준호", "서연"]

EXAMPLE 10

행과 열 바꾸기

matrix = [[1, 2, 3], [4, 5, 6]]
transposed = [
    [row[column] for row in matrix]
    for column in range(3)
]

print(transposed)
실행 결과 
[[1, 4], [2, 5], [3, 6]]

모든 행의 열 수가 같다는 전제가 필요합니다.

예제를 읽는 네 단계
  1. for ... in ...에서 반복 순서를 먼저 찾습니다.
  2. 뒤쪽 if가 있다면 포함 여부를 판단합니다.
  3. 맨 앞 표현식이 만들어 내는 값을 계산합니다.
  4. 결과 개수와 2차원 구조의 행별 객체 관계를 확인합니다.

07 · Mistakes & Errors

문법 위치, 현재 자료형, 행 길이, 선택자 반환값을 함께 읽는다

오류 종류→마지막 실행 줄→반복 대상 자료형→현재 값·행 길이→일반 for문으로 재현

SyntaxError

for와 표현식 순서가 잘못됨

result = [for x in range(5) x * 2]

# SyntaxError: invalid syntax

[x * 2 for x in range(5)]처럼 결과 표현식을 앞에 둡니다.

SyntaxError

조건부 표현식의 else 누락

result = ["짝수" if x % 2 == 0 for x in range(5)]

# SyntaxError: expected 'else' after 'if' expression

앞쪽 조건부 변환에는 참값·조건·else·거짓값이 모두 필요합니다.

TypeError

정수를 반복 대상으로 사용

result = [x * 2 for x in 10]

# TypeError: 'int' object is not iterable

range(10)이나 실제 리스트처럼 반복 가능한 객체를 사용합니다.

TypeError

내장 함수 이름을 리스트로 덮어씀

list = [1, 2, 3]
numbers = list(range(5))

# TypeError: 'list' object is not callable

items, numbers처럼 다른 변수명을 사용합니다.

NameError

표현식 반복 변수를 밖에서 사용

result = [x ** 2 for x in range(5)]
print(x)

# NameError: name 'x' is not defined

Python 3에서 반복 변수는 표현식 내부에 한정됩니다.

IndexError

불규칙 행에 고정 열 번호 사용

matrix = [[1, 2, 3], [4, 5]]
values = [row[2] for row in matrix]

# IndexError: list index out of range

if len(row) > 2로 보호하거나 행 구조를 먼저 정규화합니다.

KeyError

리스트 속 딕셔너리에 키가 없음

users = [{"name": "민지"}]
scores = [user["score"] for user in users]

# KeyError: 'score'

user.get("score", 0) 또는 키 존재 조건을 사용합니다.

AttributeError

select_one() 결과가 None

element = soup.select_one(".title")
title = element.get_text(strip=True)

# AttributeError: 'NoneType' object has no attribute 'get_text'

단일 선택 결과가 존재하는지 확인한 뒤 메서드를 호출합니다.

ValueError · Plot

필터 뒤 x와 y 길이가 다름

x = ["1월", "2월", "3월"]
y = [100, 200]
plt.plot(x, y)

# ValueError: x and y must have same first dimension

짝을 먼저 묶어 함께 필터링하고 두 길이를 확인합니다.

No Exception, Wrong Result

오류 메시지가 없는 공유 참조 문제

matrix = [[0] * 3] * 2
matrix[0][0] = 1
print(matrix)

# [[1, 0, 0], [1, 0, 0]]

09 · Interview Point

답변에는 생성 목적·조건 위치·평가 시점·참조 관계를 포함한다

Q1 리스트 표현식이란 무엇인가요?

반복 가능한 객체에서 값을 하나씩 가져와 변환하거나 조건으로 선택하여 새로운 리스트를 만드는 문법입니다.

Q2 일반 반복문과 어떤 차이가 있나요?

단순한 새 리스트 생성은 간결하게 표현하지만, 복잡한 상태 변경·예외 처리·로그가 필요하면 일반 반복문이 더 적합합니다.

Q3 맨 앞 표현식의 역할은?

새 리스트에 저장할 값을 계산하며, 일반 반복문의 result.append(표현식)과 대응합니다.

Q4 필터 if와 조건부 if-else의 차이는?

뒤쪽 if는 거짓인 요소를 제외하고, 앞쪽 if-else는 모든 요소를 참값 또는 거짓값으로 변환합니다.

Q5 중첩 for는 어떤 순서로 실행되나요?

일반 중첩 반복문과 같은 순서입니다. 첫 번째 for가 바깥 반복, 다음 for가 안쪽 반복입니다.

Q6 2차원 리스트 요소에 어떻게 접근하나요?

matrix[행][열]로 접근합니다. 먼저 행 리스트를 선택한 뒤 그 안의 열 요소를 선택합니다.

Q7 [[0] * c] * r가 위험한 이유는?

행들이 같은 내부 리스트 객체를 공유할 수 있어 한 행 변경이 다른 행에도 나타납니다. 행마다 새 리스트를 생성해야 합니다.

Q8 리스트 표현식은 지연 평가되나요?

아닙니다. 결과 전체를 즉시 계산하고 저장합니다. 지연 평가에는 괄호를 사용하는 제너레이터 표현식을 사용합니다.

Q9 불규칙 리스트란 무엇인가요?

행마다 열 개수가 다른 중첩 리스트입니다. Python에서는 가능하지만 고정 열 접근과 NumPy 변환 전에 구조를 확인해야 합니다.

Q10 2차원 리스트를 펼치는 표현식은?

[value for row in matrix for value in row]입니다. 행을 고른 뒤 그 행의 값을 차례로 추가합니다.

Q11 언제 리스트 표현식을 피해야 하나요?

중첩과 조건이 많아 읽기 어렵거나 예외 처리, break, 로그, 외부 상태 변경이 필요할 때 일반 반복문을 사용합니다.

Q12 크롤링 결과가 비면 데이터가 없는 것인가요?

반드시 그렇지 않습니다. 상태 코드, 선택자 변경, 차단 화면, 동적 렌더링과 응답 HTML을 함께 확인합니다.

Q13 Python 2차원 리스트와 NumPy 배열의 차이는?

리스트는 불규칙 구조와 혼합 자료형을 허용하지만, NumPy 배열은 보통 직사각형 구조와 동일 dtype의 수치 연산에 적합합니다.
