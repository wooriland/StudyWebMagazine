01 · Programming Language

프로그래밍 언어는 왜 필요한가?

프로그래밍 언어는 사람이 원하는 작업 절차를 컴퓨터가 실행할 수 있도록 정해진 문법으로 표현하는 언어입니다.

사람의 요구

“학생의 점수가 80점 이상이면 통과라고 표시해 줘.”

→
작업 절차

알고리즘으로 분해

  1. 학생 점수를 저장합니다.
  2. 점수를 80과 비교합니다.
  3. 참과 거짓에 따라 결과를 선택합니다.
  4. 선택된 결과를 출력합니다.
→

if score >= 80:

07 · Object-Oriented Programming

객체지향 언어라는 말은 무엇인가?

객체지향은 데이터와 그 데이터를 다루는 기능을 객체라는 단위로 묶어 프로그램을 구성하는 방식입니다.

자동차 객체

Car Object

  • 현재 속도
  • 연료량

클래스

객체를 만들기 위한 구조

class Car:
    def __init__(self, model):
        self.model = model
        self.speed = 0

    def accelerate(self):
        self.speed += 10

08 · Python Implementations

CPython, Jython, IronPython, PyPy 비교

Python은 언어의 이름이고, Python 문법으로 작성된 코드를 실제로 처리하는 실행 프로그램을 구현체라고 합니다.

Python Source Code 같은 Python 계열 문법
CPython

가장 일반적인 구현체

Python 코드 ↓ CPython ↓ Python VM
  • C를 중심으로 구현된 대표 실행 환경
  • 일반적인 Python 학습의 기본 기준
  • 패키지와 오류 해결 자료가 많음
Jython

JVM·Java 환경 연결

Python 코드 ↓ Jython ↓ JVM
  • Java 생태계와 연결하는 구현체
  • JVM 기반 시스템과의 통합에 의미
  • 일반 입문 과정의 기본 선택은 아님
IronPython

.NET 환경 연결

Python 코드 ↓ IronPython ↓ .NET Runtime
  • C#·.NET 생태계와 연결
  • 기존 .NET 시스템 통합에 의미
  • Windows 업무 환경에서 고려 가능
PyPy

JIT와 성능 개선 방향

Python 코드 ↓ PyPy ↓ JIT
  • 대안 Python 구현체
  • 반복 실행 코드의 성능 개선 방향
  • 패키지 호환성 확인이 필요함
Python 구현체 비교
구현체 연결 기반 핵심 목적 주요 고려 상황
CPython C · Python VM 일반적인 Python 실행 입문, 일반 개발, 대부분의 패키지
Jython JVM · Java Java 생태계와 통합 기존 Java 시스템과 연동
IronPython .NET · C# .NET 생태계와 통합 기존 .NET 시스템과 연동
PyPy JIT 실행 환경 Python 실행 성능 개선 반복 연산과 패키지 호환성 검토
입문 과정의 기본 선택

Java 또는 .NET 통합, 특정 성능 요구 같은 특별한 이유가 없다면 CPython 기반 Python 3 환경을 사용합니다.

09 · Python Version

Python 2와 Python 3의 대표적인 차이

현재 학습 매거진은 Python 3 문법을 기준으로 합니다. 과거 Python 2 예제를 그대로 실행하면 문법이나 실행 결과가 달라질 수 있습니다.

Python 2와 Python 3 비교
구분 Python 2 Python 3 현재 학습 기준
출력 print "Hello" print("Hello") print() 함수
큰 정수 int와 long 구분 int로 통합 큰 정수도 int
정수 나눗셈 1 / 2 → 0 1 / 2 → 0.5 몫은 //
문자열 str과 unicode 구분 Unicode 기반 str 한글도 일반 str
range 실제 리스트 생성 반복 가능한 range 객체 필요하면 list() 변환

print("Python 3")

print(1 / 2)
print(1 // 2)

python

초보자가 자주 하는 실수

01

Python과 PyCharm을 같은 것으로 봅니다

Python은 언어와 실행 환경이고, PyCharm은 Python 개발을 돕는 IDE입니다.

02

Python과 CPython을 완전히 같은 개념으로 봅니다

Python은 언어이고 CPython은 그 언어를 실행하는 대표 구현체입니다.

03

버전과 구현체를 혼동합니다

Python 3.12는 버전이고, CPython과 PyPy는 구현체입니다.

04

동적 타이핑은 자료형이 없다는 뜻이라고 생각합니다

인터프리터 언어는 내부 변환이 전혀 없다고 단정합니다

06

스크립트 언어는 작은 프로그램만 만든다고 생각합니다

Python은 자동화 파일부터 웹·데이터·AI 시스템까지 확장할 수 있습니다.

07

객체지향 언어라서 모든 코드를 클래스로 작성합니다

문제의 크기와 성격에 따라 절차형, 함수, 객체지향 방식을 선택합니다.

08

Python 2 예제를 Python 3에서 그대로 실행합니다

print, 나눗셈, 문자열, range 등의 문법과 동작 차이를 확인해야 합니다.

09

IDE와 터미널이 같은 Python을 쓴다고 가정합니다

각각의 sys.executable 경로가 같은지 확인해야 합니다.

10

구현체가 달라도 모든 패키지가 똑같이 동작한다고 생각합니다

15 · Interview

면접 포인트

Python은 어떤 프로그래밍 언어입니까?

Python은 문법이 비교적 간결한 범용 고수준 프로그래밍 언어입니다. 동적 타이핑과 객체지향을 지원하며 자동화, 웹 개발, 데이터 처리, 분석과 AI 등 다양한 분야에 활용됩니다.

Python과 CPython의 차이는 무엇입니까?

Python은 프로그래밍 언어의 문법과 규칙이고, CPython은 그 Python 코드를 실제로 실행하는 대표적인 구현체입니다.

Python과 PyCharm의 차이는 무엇입니까?

Python은 언어와 실행 환경이고, PyCharm은 Python 코드를 작성하고 실행하며 디버깅하도록 돕는 IDE입니다. PyCharm은 프로젝트에 연결된 Python 인터프리터를 사용합니다.

인터프리터 언어란 무엇입니까?

사용자가 별도의 전체 빌드 과정을 크게 의식하지 않고 실행 환경이 코드를 읽고 처리해 결과를 제공하는 방식으로 설명할 수 있습니다. CPython 내부에서는 소스를 바이트코드로 변환한 뒤 Python 가상 머신에서 실행합니다.

스크립트 언어란 무엇입니까?

특정 작업 절차를 코드로 빠르게 작성하고 실행하기 편리한 언어적 특성을 의미합니다. Python은 자동화 스크립트뿐 아니라 대규모 서비스도 만들 수 있는 범용 언어입니다.

동적 타이핑이란 무엇입니까?

변수를 선언할 때 자료형을 고정하지 않고, 실행 중 변수 이름이 가리키는 객체에 따라 자료형이 결정되는 방식입니다. 자료형이 없다는 뜻은 아닙니다.

객체지향 프로그래밍이란 무엇입니까?

데이터와 해당 데이터를 처리하는 기능을 객체 단위로 묶어 프로그램을 구성하는 방식입니다. 클래스는 객체의 구조를 정의하고, 객체는 상태와 메서드를 가질 수 있습니다.

Python은 객체지향만 지원합니까?

아닙니다. Python은 절차형, 함수 중심, 객체지향, 함수형 스타일 등 여러 방식을 함께 사용할 수 있는 다중 패러다임 언어입니다.

주요 Python 구현체의 차이는 무엇입니까?

CPython은 가장 일반적인 구현체이고, Jython은 JVM·Java 환경, IronPython은 .NET 환경과 연결됩니다. PyPy는 JIT를 활용하는 대안 구현체로 이해할 수 있습니다.

Python 버전과 구현체는 무엇이 다릅니까?

버전은 Python 언어 규칙의 세대를 의미합니다. Python 3.12가 버전의 예입니다. 구현체는 그 언어를 실행하는 프로그램으로, CPython과 PyPy가 구현체의 예입니다.

현재 Python 실행 환경은 어떻게 확인합니까?

platform.python_implementation() 으로 구현체를 확인하고, sys.version으로 버전을, sys.executable로 현재 인터프리터의 실행 경로를 확인할 수 있습니다.

PyCharm에서 패키지를 찾지 못하는 이유는 무엇입니까?

패키지를 설치한 Python 환경과 PyCharm 프로젝트에서 사용하는 Python 인터프리터가 서로 다를 수 있습니다. 양쪽의 sys.executable 경로를 비교해야 합니다.
