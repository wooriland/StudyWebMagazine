Python Basics · Lesson 09

문자열, 인덱싱과 슬라이싱

Python의 문자열은 문자들이 순서대로 나열된 불변 str 객체입니다. 이번 단원에서는 작은따옴표·큰따옴표·삼중 따옴표로 문자열을 생성하고, len()으로 문자열 길이를 확인하며, 양수·음수 인덱스로 문자 하나에 접근하는 방법을 공부합니다. 이어서 [start:stop:step] 구조로 문자열 일부를 가져오고, 문자열을 역순으로 만들거나 일정 간격으로 문자를 선택하는 방법을 살펴봅니다. 마지막으로 문자열 문자를 직접 수정할 수 없는 이유와 슬라이싱·연결·메서드를 이용해 새로운 문자열을 만드는 흐름을 정리합니다.

str Sequence Index Positive Index Negative Index Slice start stop step len() Immutable Unicode

이 단원의 중심 질문

문자열에서 원하는 문자나 범위를 어떻게 가져오며, 특정 문자를 직접 바꾸면 왜 오류가 발생할까요?

인덱싱은 문자열에서 정확한 위치의 문자 하나를 가져오고, 슬라이싱은 시작 위치부터 끝 위치 직전까지 일정 범위의 문자를 새로운 문자열로 가져옵니다. 문자열은 불변 객체이므로 특정 인덱스의 문자를 직접 바꿀 수 없으며, 변경이 필요하다면 원하는 결과를 가진 새 문자열을 만들어야 합니다.

학습 목표

  • 문자열이 순서가 있는 불변 str 객체임을 설명할 수 있습니다.
  • 작은따옴표·큰따옴표·삼중 따옴표로 문자열을 생성할 수 있습니다.
  • 빈 문자열과 None의 차이를 설명할 수 있습니다.
  • 이스케이프 시퀀스와 원시 문자열의 차이를 이해합니다.
  • len()으로 문자열의 문자 수를 확인할 수 있습니다.
  • 양수 인덱스와 음수 인덱스를 이용해 원하는 문자에 접근할 수 있습니다.
  • 유효한 인덱스 범위를 문자열 길이와 연결해 계산할 수 있습니다.
  • [start:stop] 슬라이싱에서 시작은 포함되고 끝은 제외됨을 이해합니다.
  • [start:stop:step]으로 이동 간격과 방향을 지정할 수 있습니다.
  • 인덱싱과 슬라이싱의 범위 초과 동작을 구분할 수 있습니다.
  • 문자열 불변성과 변수 재할당의 차이를 설명할 수 있습니다.
  • DB·웹크롤링·Pandas·시각화에서 문자열 처리 개념을 연결할 수 있습니다.

stop 끝 위치 결과에 포함하지 않음
step 이동 간격과 방향 기본값은 1

text[1:4] 처리

문자 P y t h o n

음수 시작 text[-3:] "hon"
뒤쪽 제외 text[:-2] "Pyth"

앞 구간 text[:3] "Pyt"
뒤 구간 text[3:] "hon"
다시 연결 text[:3] + text[3:] "Python"

05 · Indexing vs Slicing

인덱싱과 슬라이싱의 차이

Indexing

정확한 위치 하나

text[2]
  • 문자 하나를 가져옵니다.
  • 결과는 길이 1인 str입니다.
  • 존재하지 않는 위치는 오류입니다.
  • 범위 초과 시 IndexError입니다.
Slicing

일정한 범위

text[1:4]
  • 문자열 일부를 가져옵니다.
  • 결과는 새로운 문자열 값입니다.
  • 범위를 벗어나도 가능한 구간만 반환합니다.
  • 선택할 문자가 없으면 빈 문자열입니다.
범위를 벗어난 인덱싱 
text = "Python"

print(text[100])
IndexError
범위를 벗어난 슬라이싱 
print(text[:100])
print(text[100:200])
Python
""
인덱싱과 슬라이싱 비교
구분 인덱싱 슬라이싱
문법 text[index] text[start:stop:step]
목적 문자 하나 접근 문자열 일부 접근
결과 자료형 str str
결과 길이 1 0 이상
범위 초과 IndexError 가능한 범위만 반환
빈 결과 위치가 없으면 오류 빈 문자열 가능

기존 "Python" 객체의 문자를 수정한 것이 아니라 변수 이름의 연결 대상을 새로운 문자열로 변경한 것입니다.

슬라이싱과 연결

    "J"
    + original[1:]
)
Jython
replace()

    "Py",
    "Jy",
)
Jython
리스트로 변환 
characters = list(original)

characters[0] = "J"

changed = "".join(characters)
Jython
원본 original → "Python"
→
슬라이싱 original[1:] → "ython"
→
연결 "J" + "ython"
→
새 결과 changed → "Jython"
문자열의 전체 슬라이싱을 리스트 복사와 같은 개념으로 이해할 필요는 없습니다. 
text = "Python"
copied = text[:]

print(copied == text)
print(copied is text)

두 문자열의 내용은 같지만, 불변 문자열은 Python 구현의 최적화에 따라 같은 객체가 재사용될 수 있습니다. 문자열에서는 is로 복사 여부를 판단하지 않습니다.

def print_section(
    title: str,
) -> None:
    """실습 영역의 제목을 출력한다."""

    print("\n" + "=" * 60)
    print(title)
    print("=" * 60)


def demonstrate_creation() -> None:
    """여러 방법으로 문자열을 생성한다."""

    print_section(
        "1. 문자열 생성"
    )

    single_quote = 'Python'
    double_quote = "Database"

    multiline_text = """Python
Database
Web Crawling"""

    empty_text = str()

12 · Common Mistakes

초보자가 자주 하는 문자열 실수

01

첫 번째 인덱스를 1이라고 생각합니다

Python의 첫 번째 문자열 인덱스는 0입니다.

02

마지막 문자를 text[len(text)]로 가져옵니다

마지막 양수 인덱스는 len(text) - 1입니다.

03

슬라이싱의 끝 인덱스가 포함된다고 생각합니다

text[1:4]는 1, 2, 3번 문자만 가져옵니다.

04

인덱싱과 슬라이싱의 범위 초과를 같게 생각합니다

인덱싱은 오류가 발생하지만 슬라이싱은 가능한 범위만 반환합니다.

05

음수 인덱스가 0부터 시작한다고 생각합니다

마지막 문자는 -1, 뒤에서 두 번째는 -2입니다.

06

문자열의 문자를 직접 수정합니다

문자열은 불변 객체이므로 새로운 문자열을 만들어야 합니다.

07

문자열 메서드가 원본을 변경한다고 생각합니다

변경 결과를 반환하므로 반환값을 저장해야 합니다.

08

문자열과 숫자를 바로 연결합니다

숫자를 str()로 변환하거나 f-string을 사용해야 합니다.

09

슬라이싱의 step에 0을 사용합니다

이동할 수 없으므로 ValueError가 발생합니다.

10

음수 step의 이동 방향을 반대로 설정합니다

뒤로 이동할 때는 시작 위치가 끝 위치보다 뒤에 있어야 합니다.

11

공백과 줄바꿈을 길이에서 제외합니다

공백·줄바꿈·탭도 문자열의 문자입니다.

12

빈 문자열과 None을 같은 값으로 생각합니다

빈 문자열은 길이가 0인 str 객체입니다.

13

파일 확장자가 항상 세 글자라고 가정합니다

실제 파일 처리에서는 pathlib 같은 전용 도구를 사용해야 합니다.

14

문자 수와 바이트 수를 혼동합니다

len(text)와 len(text.encode())는 다른 의미입니다.

15

빈 문자열을 검사하지 않고 인덱싱합니다

문자 접근 전에 문자열이 비어 있지 않은지 확인해야 합니다.

전체 슬라이싱의 객체 동일성에 의존합니다

면접 포인트

Python 문자열이란 무엇입니까?

문자들이 순서대로 나열된 str 자료형의 불변 객체입니다. 순서가 있으므로 인덱싱과 슬라이싱이 가능하지만 문자열 내부 문자를 직접 수정할 수는 없습니다.

Python에는 char 자료형이 있습니까?

별도의 char 자료형은 없습니다. 문자열에서 인덱싱한 문자 하나도 길이가 1인 str 객체입니다.

문자열은 어떤 방법으로 생성할 수 있습니까?

작은따옴표, 큰따옴표, 삼중 작은따옴표와 삼중 큰따옴표를 사용할 수 있습니다. str()로 빈 문자열이나 다른 객체의 문자열 표현을 만들 수도 있습니다.

문자열의 첫 번째 인덱스는 무엇입니까?

0입니다. Python의 문자열·리스트·튜플 같은 순서형 객체는 0부터 인덱스를 시작합니다.

음수 인덱스는 어떻게 동작합니까?

문자열 뒤에서부터 접근합니다. 마지막 문자는 -1, 뒤에서 두 번째 문자는 -2입니다.

문자열의 마지막 양수 인덱스는 어떻게 계산합니까?

len(text) - 1입니다. 문자열 길이가 6이라면 유효한 양수 인덱스는 0부터 5까지입니다.

인덱싱과 슬라이싱의 차이는 무엇입니까?

인덱싱은 특정 위치의 문자 하나를 가져오고, 슬라이싱은 지정한 범위의 문자열을 가져옵니다. 범위를 벗어난 인덱싱은 IndexError를 발생시키지만 슬라이싱은 가능한 범위만 반환합니다.

슬라이싱에서 끝 인덱스를 포함합니까?

포함하지 않습니다. text[1:4]는 1, 2, 3번 인덱스의 문자만 가져옵니다.

슬라이싱의 전체 문법은 무엇입니까?

text[start:stop:step]입니다. 시작 위치는 포함되고 끝 위치는 제외되며, step은 이동 간격과 방향을 결정합니다.

문자열을 역순으로 만드는 방법은 무엇입니까?

text[::-1]을 사용할 수 있습니다. step을 -1로 지정해 문자열 끝에서 처음 방향으로 이동합니다.

문자열이 불변 객체라는 뜻은 무엇입니까?

문자열 객체가 생성된 뒤 내부 문자를 직접 변경할 수 없다는 뜻입니다. text[0] = "J"처럼 특정 위치에 값을 할당하면 TypeError가 발생합니다.

문자열 변수를 다른 문자열로 재할당하는 것은 왜 가능합니까?

기존 문자열 객체 내부를 수정하는 것이 아니라 변수 이름이 새로운 문자열 객체를 가리키도록 연결을 바꾸는 것이기 때문입니다.

문자열을 수정하려면 어떻게 해야 합니까?

슬라이싱과 연결, replace(), 문자 리스트 변환 등을 이용해 원하는 결과를 가진 새 문자열을 만들어야 합니다.

len()은 무엇을 반환합니까?

문자열을 구성하는 Python 문자 단위의 개수를 반환합니다. 화면에 표시되는 폭이나 UTF-8 바이트 수와는 다를 수 있습니다.

공백과 줄바꿈도 문자열 길이에 포함됩니까?

포함됩니다. 공백, 탭과 줄바꿈도 문자열 내부에서는 각각 하나의 문자로 처리됩니다.

빈 문자열과 None의 차이는 무엇입니까?

빈 문자열은 길이가 0인 str 객체이고, None은 값이나 결과가 없음을 나타내는 NoneType 객체입니다.

text[100]과 text[:100]은 어떻게 다릅니까?

text[100]은 정확한 위치 하나를 요구하므로 해당 위치가 없으면 IndexError가 발생합니다. text[:100]은 범위 요청이므로 실제 문자열 끝까지만 반환합니다.

문자열 슬라이싱은 원본을 변경합니까?

변경하지 않습니다. 슬라이싱 결과로 문자열 값을 얻으며 원본 문자열은 그대로 유지됩니다.

Pandas 문자열 컬럼에는 인덱싱을 어떻게 적용합니까?

Series.str 접근자를 사용합니다. 예를 들어 series.str[0], series.str[:3], series.str.len()처럼 사용할 수 있습니다.

웹크롤링에서 문자열 슬라이싱은 어디에 사용할 수 있습니까?

긴 HTML 응답의 앞부분을 미리 확인하거나, URL·수집 텍스트·선택자 결과를 검사하고, 수집한 제목이나 설명의 길이를 제한하는 작업에 사용할 수 있습니다.

  • text[::-1]은 문자열 역순입니다.

  • 슬라이싱 범위 초과는 가능한 범위만 반환합니다.
  • 문자열 문자는 직접 수정할 수 없습니다.
