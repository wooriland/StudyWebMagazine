Data Visualization 데이터 시각화 전체 로드맵

데이터 시각화는 단순히 데이터를 예쁜 그래프로 바꾸는 작업이 아닙니다. 데이터에서 질문을 만들고, 가설을 세우고, 질문에 적합한 그래프를 선택하여 패턴·관계·분포· 이상치를 탐색한 뒤 가설을 검증하고 새로운 Insight와 데이터 정제 방향을 발견하는 데이터 분석 과정입니다.

데이터 → 질문 → 가설 → 시각화 → 검증 → Insight → 정제

학습 목표

  • 데이터 시각화가 단순한 그래프 작성이 아니라 데이터 분석 과정인 이유를 설명할 수 있다.
  • 데이터의 종류와 분석 질문을 보고 적합한 그래프를 선택할 수 있다.
  • Line, Bar, Scatter, Histogram, KDE, Boxplot, Heatmap, Pie Chart의 목적을 구분할 수 있다.
  • Matplotlib의 Figure, Axes, Plot, Axis 구조를 구분할 수 있다.
  • Matplotlib과 Seaborn의 역할과 관계를 설명할 수 있다.
  • 그래프에서 변화, 비교, 분포, 관계, 이상치를 읽고 가설 검증으로 연결할 수 있다.
  • 시각화 결과를 Insight와 데이터 정제, 추가 분석으로 연결할 수 있다.

01 · Core Concept

핵심 개념 — 그래프보다 질문이 먼저다

데이터 시각화의 목적은 숫자와 문자만으로는 발견하기 어려운 변화, 비교, 관계, 분포, 이상치 를 시각적으로 탐색하는 것입니다.

가장 중요한 원칙

그래프가 질문을 결정하는 것이 아니라, 분석 질문과 데이터 유형이 그래프를 결정합니다.

잘못된 접근

Scatter Plot을 배웠다 ↓ 아무 데이터나 Scatter로 그린다 ↓ 왜 그렸는지 설명하기 어렵다

분석적인 접근

광고비와 매출에 관계가 있는가? ↓ 수치형 + 수치형 ↓ Scatter Plot

그래프 선택 기준

분석 질문 데이터 조합 추천 그래프 그래프에서 확인할 것
시간에 따라 값이 어떻게 변하는가? 시간 + 수치 Line Plot 증가, 감소, 추세, 변곡점
여러 범주의 크기를 비교하는가? 범주 + 수치 Bar Plot 크기, 순위, 격차
두 수치형 변수에 관계가 있는가? 수치 + 수치 Scatter Plot 관계 방향, 밀집도, 군집
하나의 수치 데이터가 어떻게 분포하는가? 수치 Histogram / KDE 중심, 퍼짐, 왜도, 봉우리
범주별 수치 분포와 이상치를 확인하는가? 범주 + 수치 Boxplot Median, IQR, Outlier
여러 변수의 상관관계를 한 번에 확인하는가? 여러 수치 변수 Heatmap 양·음의 상관관계, 관계 강도
전체에서 범주가 차지하는 비율을 보는가? 범주 + 비율 Pie Chart 구성 비율
범주별 수치를 비교하는가? 범주 + 수치 Barplot / Boxplot / Catplot 범주별 차이
시간과 범주를 동시에 비교하는가? 시간 + 범주 + 수치 Lineplot + hue 그룹별 시간 추세

04 · Python Example

Python 코드로 전체 흐름 연결하기

하나의 DataFrame을 여러 질문으로 바라보면서 질문에 따라 그래프가 달라지는 것을 확인합니다.

1단계 · 예제 데이터 준비 

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.DataFrame({
    "month": [
        1, 2, 3, 4, 5, 6,
        1, 2, 3, 4, 5, 6
    ],
    "channel": [
        "Online", "Online", "Online",
        "Online", "Online", "Online",
        "Offline", "Offline", "Offline",
        "Offline", "Offline", "Offline"
    ],
    "sales": [
        120, 135, 150, 170, 190, 220,
        100, 110, 115, 125, 130, 140
    ],
    "advertising": [
        10, 12, 15, 18, 22, 28,
        8, 9, 10, 11, 12, 13
    ]
})

print(df)

month → 시간/순서

channel → 범주형

sales → 수치형

advertising → 수치형

2단계 · 시간 + 수치 → Line Plot

질문: 온라인 매출은 월이 지나면서 어떻게 변하는가? 

online = df[df["channel"] == "Online"]

plt.plot(
    online["month"],
    online["sales"],
    marker="o"
)

plt.xlabel("Month")
plt.ylabel("Sales")
plt.title("Online Monthly Sales")
plt.show()
month → X축 + sales → Y축 → 시간에 따른 변화

3단계 · 시간 + 범주 + 수치 → Lineplot + hue

질문: 온라인과 오프라인의 월별 매출 추세는 어떻게 다른가? 

sns.lineplot(
    data=df,
    x="month",
    y="sales",
    hue="channel",
    marker="o"
)

plt.title("Monthly Sales by Channel")
plt.show()
data

사용할 DataFrame

x

X축에 사용할 열

y

Y축에 사용할 열

hue

범주를 나누어 표현할 열

4단계 · 수치 + 수치 → Scatter Plot

질문: 광고비와 매출 사이에는 관계가 있는가? 

sns.scatterplot(
    data=df,
    x="advertising",
    y="sales",
    hue="channel"
)

plt.title("Advertising vs Sales")
plt.show()
해석 주의

광고비가 높은 데이터에서 매출도 높아 보인다고 해서 광고비가 매출 증가의 원인이라고 즉시 결론내릴 수는 없습니다. 상관관계와 인과관계는 다릅니다.

5단계 · 범주 + 수치 → Boxplot

질문: 채널마다 매출 분포가 어떻게 다른가? 

sns.boxplot(
    data=df,
    x="channel",
    y="sales"
)

plt.title("Sales Distribution by Channel")
plt.show()
Q1 25%
Q2 50% · Median
Q3 75%
IQR Q3 - Q1

6단계 · 여러 수치 변수 → Heatmap

질문: month, sales, advertising은 서로 어떤 관계를 보이는가? 

numeric_df = df[
    ["month", "sales", "advertising"]
]

corr = numeric_df.corr()

sns.heatmap(
    corr,
    annot=True
)

plt.title("Correlation Heatmap")
plt.show()
수치형 열 선택 → corr() → 상관관계 행렬 → Heatmap

7단계 · Figure 안에 여러 Axes 배치 

fig, axes = plt.subplots(
    2,
    2,
    figsize=(12, 8)
)

online = df[df["channel"] == "Online"]

axes[0, 0].plot(
    online["month"],
    online["sales"],
    marker="o"
)
axes[0, 0].set_title("Online Sales")

sns.scatterplot(
    data=df,
    x="advertising",
    y="sales",
    ax=axes[0, 1]
)
axes[0, 1].set_title("Advertising vs Sales")

sns.boxplot(
    data=df,
    x="channel",
    y="sales",
    ax=axes[1, 0]
)
axes[1, 0].set_title("Sales Distribution")

corr = df[
    ["month", "sales", "advertising"]
].corr()

sns.heatmap(
    corr,
    annot=True,
    ax=axes[1, 1]
)
axes[1, 1].set_title("Correlation")

plt.tight_layout()
plt.show()
axes[0, 0] Line
axes[0, 1] Scatter
axes[1, 0] Boxplot
axes[1, 1] Heatmap

05 · Error Reading

오류 메시지 읽는 법

시각화에서 오류가 발생하면 Traceback의 가장 아래쪽에 있는 오류 종류와 메시지부터 확인합니다.

Traceback → 오류 종류 → 오류 메시지 → 문제 줄 → 데이터 확인

ModuleNotFoundError 

ModuleNotFoundError:
No module named 'seaborn'

현재 Python 실행 환경에서 Seaborn을 찾지 못했다는 뜻입니다.

  • 패키지가 설치되었는가?
  • 어느 Python 환경에 설치했는가?
  • PyCharm Interpreter가 같은가?
  • Jupyter Kernel이 같은 환경인가?

NameError 

NameError:
name 'plt' is not defined

plt라는 이름이 현재 실행 환경에 정의되지 않았습니다. 

import matplotlib.pyplot as plt

KeyError 

KeyError: 'sale'

DataFrame에 해당 열 이름이 존재하지 않을 가능성이 큽니다. 

print(df.columns)

sale과 sales처럼 철자가 다른지 확인합니다.

TypeError

기대한 데이터 타입과 실제 타입이 다를 때 자주 만납니다. 

print(df.dtypes)

숫자로 생각한 열이 object 또는 문자열인지 확인합니다.

ValueError 

x = [1, 2, 3]
y = [10, 20]

plt.plot(x, y)

X와 Y 데이터의 길이가 맞지 않아 좌표 쌍을 만들 수 없는 상황입니다. 

print(len(x))
print(len(y))

SyntaxError 

plt.plot(x, y

그래프 문제가 아니라 Python 문법이 완성되지 않은 상태입니다.

  • 괄호
  • 따옴표
  • 쉼표
  • 콜론
  • 들여쓰기

오류는 없는데 그래프가 보이지 않는다 

plt.plot(x, y)
plt.show()

Python 스크립트 환경에서는 plt.show() 호출 여부도 확인합니다.

오류는 없는데 그래프가 이상하다

코드 오류가 아니라 데이터 자체의 문제일 수 있습니다. 

df.describe()

df["sales"].min()
df["sales"].max()

df.isnull().sum()

비정상적으로 큰 값, 결측치, 타입 오류, 단위 오류를 확인합니다.

중요한 구분

코드가 실행된다와 분석이 올바르다는 같은 뜻이 아닙니다. 오류 메시지가 없어도 데이터나 그래프 해석이 잘못될 수 있습니다.

면접 포인트

Q1. 데이터 시각화를 사용하는 이유는 무엇입니까?

숫자와 문자만으로 확인하기 어려운 데이터의 패턴, 변화, 관계, 분포, 이상치를 직관적으로 탐색하기 위해 사용합니다. 분석 과정에서는 가설을 검토하고 추가적인 Insight와 분석 질문을 발견하는 데 활용할 수 있습니다.

Q2. Matplotlib과 Seaborn의 차이는 무엇입니까?

Matplotlib은 Figure, Axes, Axis 등 그래프의 기본 구조와 세밀한 제어를 제공하는 시각화 라이브러리입니다. Seaborn은 Matplotlib을 기반으로 하며 DataFrame 중심의 통계적·범주형 시각화를 보다 편리하게 작성할 수 있도록 도와줍니다.

Q3. Figure와 Axes의 차이는 무엇입니까?

Figure는 전체 그래프를 담는 그림판이고, Axes는 Figure 내부에서 실제 그래프 하나가 그려지는 영역입니다. 하나의 Figure 안에 여러 Axes를 구성할 수 있습니다.

Q4. Axes와 Axis는 어떻게 다릅니까?

Axes는 실제 그래프 영역이고, Axis는 그 영역 안의 X축이나 Y축처럼 축, 눈금, 값의 기준을 담당합니다.

Q5. Bar Plot과 Histogram의 차이는 무엇입니까?

Bar Plot은 범주별 값을 비교하는 데 사용하고, Histogram은 연속적인 수치형 데이터를 구간으로 나누어 빈도와 분포를 확인하는 데 사용합니다.

Q6. Scatter Plot은 언제 사용합니까?

두 수치형 변수 사이의 관계를 탐색할 때 사용합니다. 점의 방향, 밀집도, 군집, 이상점을 확인할 수 있습니다.

Q7. 상관관계와 인과관계는 어떻게 다릅니까?

상관관계는 두 변수가 함께 변화하는 경향을 의미하지만, 한 변수가 다른 변수의 원인이라는 의미는 아닙니다. 인과관계를 판단하려면 추가적인 검증이 필요합니다.

Q8. Boxplot에서 무엇을 확인할 수 있습니까?

중앙값, Q1, Q3, IQR과 데이터의 분포 범위, 이상치를 빠르게 확인할 수 있으며 범주별 수치 분포 비교에도 유용합니다.

Q9. Seaborn의 hue는 어떤 역할을 합니까?

범주형 열을 기준으로 데이터를 그룹별로 나누어 표현합니다. 예를 들어 하나의 Lineplot에서 온라인과 오프라인의 시간별 변화를 서로 구분하여 비교할 수 있습니다.

Q10. 데이터 시각화와 전처리는 어떤 관계가 있습니까?

시각화를 통해 이상치나 비정상적인 분포, 데이터 입력 오류 가능성을 발견할 수 있습니다. 문제를 확인하여 데이터를 정제한 뒤 다시 시각화하는 반복 구조로 연결됩니다.

오늘의 암기 포인트

  • 데이터 시각화는 예쁜 그림을 만드는 작업이 아니라 데이터에서 의미를 찾는 분석 과정이다.
  • 그래프보다 질문이 먼저다.
  • 질문 → 데이터 타입 → 그래프 선택 순서로 생각한다.
  • 시간 변화 → Line
  • 범주 비교 → Bar
  • 수치 + 수치 관계 → Scatter
  • 수치 분포 → Histogram / KDE
  • 범주별 분포·이상치 → Boxplot
  • 여러 변수의 상관관계 → Heatmap
  • 시간 + 범주 + 수치 → Lineplot + hue
  • Figure는 전체 그림판, Axes는 실제 그래프 영역이다.
  • 상관관계 ≠ 인과관계
  • 시각화 → 검증 → Insight → 데이터 정제 → 재시각화는 반복된다.

헷갈리기 쉬운 개념

Figure vs Axes

전체 그림판 vs 실제 그래프 영역

Axes vs Axis

그래프 영역 vs X·Y축

Bar vs Histogram

범주 비교 vs 수치 분포

Line vs Scatter

시간·순서 변화 vs 두 수치 변수 관계

Countplot vs Barplot

범주 빈도 vs 범주별 수치 비교

Observation vs Insight

보이는 사실 vs 의미와 다음 분석 질문

Correlation vs Causation

함께 움직이는 경향 vs 원인·결과 관계

Outlier 발견 vs Outlier 삭제

이상치를 발견했다고 즉시 삭제하는 것은 아니다.
