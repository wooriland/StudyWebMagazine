Data Visualization · Lesson 08

Seaborn과 데이터 분포 Count Plot · Rug Plot · Histogram · KDE · Distribution

이번 단원에서는 데이터를 먼저 범주형(Categorical)과 수치형(Numerical)으로 구분한 뒤, 데이터가 얼마나 자주 등장하고 어느 구간에 몰려 있으며 얼마나 퍼져 있는지를 시각적으로 확인합니다. 범주형 데이터는 countplot(), 연속형 수치 데이터는 rugplot(), Histogram, kdeplot()을 중심으로 공부합니다.

그래프 선택 기준 데이터 유형 → 질문 → 분포 그래프 선택
Data → Data Type → Count / Distribution → Pattern → Insight → Cleaning
가장 중요한 기억

범주형 데이터에서는 “각 범주가 몇 번 등장했는가?”를 보고, 수치형 데이터에서는 “어디에 몰려 있고, 얼마나 퍼져 있으며, 어떤 형태로 분포하는가?” 를 봅니다.

학습 목표

  • Seaborn이 Matplotlib을 기반으로 하는 시각화 라이브러리임을 설명할 수 있다.
  • 범주형 데이터와 연속형 수치 데이터를 구분할 수 있다.
  • countplot()이 범주별 등장 횟수를 표현한다는 것을 이해한다.
  • Count Plot과 Matplotlib Bar Plot의 차이를 설명할 수 있다.
  • Count Plot과 Histogram의 차이를 설명할 수 있다.
  • rugplot()의 작은 선 하나가 실제 관측값 하나의 위치를 의미함을 설명할 수 있다.
  • Histogram의 Bin 개념을 설명할 수 있다.
  • Bin 수가 Histogram의 시각적 형태에 영향을 줄 수 있음을 이해한다.
  • kdeplot()이 부드러운 Density Curve를 표현한다는 것을 설명할 수 있다.
  • KDE의 Y축 Density와 Histogram의 Count를 구분할 수 있다.
  • KDE Peak와 평균을 구분할 수 있다.
  • KDE가 실제 관측값을 선으로 연결한 그래프가 아님을 설명할 수 있다.
  • Bandwidth가 KDE의 부드러움에 영향을 준다는 것을 이해한다.
  • 교안의 distplot() 역할을 설명할 수 있다.
  • Step 1·2 보완 기준으로 histplot(kde=True)의 의미를 설명할 수 있다.
  • Histogram·KDE·Rug가 각각 제공하는 정보를 구분할 수 있다.
  • Center, Spread, Peak, Skew, Multiple Peaks, Extreme Values를 그래프에서 관찰할 수 있다.
  • 이상한 분포를 발견한 뒤 원본 Row와 데이터 품질을 확인할 수 있다.

kdeplot() — 부드러운 Density Curve

KDE = Kernel Density Estimation

실제 관측값 주변의 Density를 추정하고 그 결과를 합쳐 부드러운 분포 곡선으로 표현합니다.

KDE는 원본 Point를 연결한 Line Plot이 아니다

KDE는 실제 데이터의 순서를 연결한 선이 아니라 통계적으로 계산한 Density Estimate입니다.

Histogram의 Count와 KDE의 Density를 구분한다

Histogram Y Count

KDE Y Density

특정 값 주변의 상대적인 밀도가 얼마나 높은가?

반드시 구분
KDE Peak Density가 높은 위치 ≠ Mean 산술 평균

예제 10 · Histogram + KDE + Rug 

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt


df = pd.DataFrame({
    "score": [
        55, 57, 60, 61, 62,
        63, 65, 65, 66, 67,
        68, 70, 71, 72, 73,
        74, 75, 76, 78, 80,
        82, 85, 90
    ]
})


sns.histplot(
    data=df,
    x="score",
    bins=8,
    kde=True
)


sns.rugplot(
    data=df,
    x="score"
)


plt.title(
    "Score Distribution"
)


plt.xlabel(
    "Score"
)


plt.ylabel(
    "Count"
)


plt.show()

histplot() Bin Count
kde=True Density Curve

05 · Mistakes & Error Reading

자주 하는 실수와 오류 메시지 읽는 법

초보자가 실제로 많이 틀리는 부분

01 · Data Type을 확인하지 않음

범주형인지 수치형인지 먼저 확인합니다.

02 · Count Plot과 Histogram 혼동

Category 빈도와 Numerical Bin 빈도를 구분합니다.

03 · Count Plot과 Bar 혼동

Raw Count인지 별도 Value인지 확인합니다.

04 · Rug 선 하나를 Bin으로 해석

선 하나는 실제 Observation 하나입니다.

05 · KDE를 Line Plot으로 생각

KDE는 Density Estimate입니다.

06 · KDE Peak를 Mean으로 해석

Peak와 평균은 다른 개념입니다.

07 · Histogram 최고 Bin을 Mean으로 해석

빈도 중심과 산술 평균은 다릅니다.

08 · Bin을 무시

Bin 설정도 Histogram 모양에 영향을 줍니다.

09 · Bandwidth를 무시

KDE smoothing도 그래프 형태에 영향을 줍니다.

10 · distplot을 현재 기본 문법으로 암기

교안 개념과 Step 1·2 실습 보완을 구분합니다.

11 · Numeric ID 분석

ID 숫자의 크기는 분석 의미가 없을 수 있습니다.

12 · Null 미확인

결측 비율이 분포 해석에 영향을 줄 수 있습니다.

13 · 작은 Sample의 KDE 과신

부드러운 곡선이 실제보다 정교해 보일 수 있습니다.

14 · Sample을 모집단과 동일시

Sample 대표성을 확인합니다.

15 · Multiple Peaks를 바로 두 그룹으로 확정

먼저 가설로 두고 다른 변수를 확인합니다.

16 · Extreme Value를 즉시 삭제

원본 Row 확인이 먼저입니다.

17 · Category 문자열 정제를 하지 않음

대소문자·공백으로 범주가 나뉠 수 있습니다.

07 · Interview

면접 포인트

Q1. Seaborn이란 무엇입니까?

Matplotlib을 기반으로 하는 하이레벨 Python 시각화 라이브러리입니다. DataFrame과 통계적 시각화를 편리하게 연결할 수 있습니다.

Q2. Count Plot은 언제 사용합니까?

범주형 변수에서 각 Category가 몇 번 등장하는지 빈도를 비교할 때 사용합니다.

Q3. Count Plot과 Bar Plot의 차이는?

Count Plot은 Raw Category의 관측 횟수를 자동으로 집계하고, Bar Plot은 Category와 별도의 수치 Value를 표현하는 데 사용합니다.

Q4. Count Plot과 Histogram의 차이는?

Count Plot은 원래 존재하는 Category의 빈도, Histogram은 Numerical Data를 Bin으로 나눈 뒤 각 구간의 빈도를 표현합니다.

Q5. Rug Plot은 무엇입니까?

실제 관측값이 축의 어느 위치에 존재하는지를 작은 선분으로 보여주는 그래프입니다.

Q6. Histogram이란 무엇입니까?

하나의 수치형 데이터를 여러 Bin으로 나누고 각 Bin에 들어가는 관측 수를 이용해 분포를 표현하는 그래프입니다.

Q7. Bin이란 무엇입니까?

연속적인 수치 범위를 Histogram에서 집계하기 위해 나눈 구간입니다.

Q8. KDE란 무엇입니까?

Kernel Density Estimation의 약자로, 데이터가 어느 영역에 집중되는지를 부드러운 Density Curve로 추정해 표현합니다.

Q9. KDE Peak는 평균입니까?

아닙니다. KDE Peak는 추정 Density가 높은 위치이고 Mean은 산술 평균입니다.

Q10. Rug와 KDE의 차이는?

Rug는 실제 Observation의 위치를 직접 보여주고, KDE는 데이터로부터 계산한 Distribution Estimate를 보여줍니다.

Q11. Histogram과 KDE의 차이는?

Histogram은 Bin을 이용하여 구간별 빈도를 보여주고, KDE는 연속적인 Density Curve를 추정합니다.

Q12. Histogram의 모양에 영향을 주는 설정은?

대표적으로 Bin 수나 Bin 폭이 있습니다. 지나치게 적거나 많은 Bin은 분포의 인상을 바꿀 수 있습니다.

Q13. KDE 모양에 영향을 주는 것은?

Bandwidth와 같은 Smoothing 설정이 중요한 영향을 줍니다.

Q14. 교안의 distplot은 무엇입니까?

첨부 교안에서는 Histogram과 KDE를 함께 시각화하는 함수로 설명합니다. 이번 Step 1·2에서는 현재 실습 형태로 histplot(kde=True)를 별도로 보완했습니다.

Q15. 분포에서 무엇을 관찰합니까?

Center, Spread, Peak, Skew, Multiple Peaks, Extreme Values 등을 확인합니다.

Q16. Peak가 두 개라면 두 그룹이 있다는 뜻입니까?

가능성을 탐색할 단서는 되지만 그래프만으로 원인을 확정할 수는 없습니다.

Q17. 대용량 데이터에서는 무엇을 주의합니까?

교안에서는 Seaborn의 통계 계산으로 인해 많은 데이터를 시각화할 때 느릴 수 있어 Sample 활용을 언급합니다. Sample을 사용한다면 대표성도 확인해야 합니다.

Q18. Extreme Value는 바로 삭제합니까?

아닙니다. 입력 오류인지 실제 특수 관측인지 원본 Row를 확인한 후 처리해야 합니다.

오늘의 암기 포인트

  • Seaborn = Matplotlib 기반 High Level 시각화
  • 범주형 데이터의 빈도는 countplot().
  • 연속형 수치 데이터의 분포는 Histogram과 KDE를 중심으로 본다.
  • rugplot()은 실제 관측 위치를 표시한다.
  • histplot()은 Bin별 빈도를 표현한다.
  • kdeplot()은 부드러운 Density Curve를 표현한다.
  • Histogram의 핵심 설정은 Bin이다.
  • KDE의 핵심 설정은 Bandwidth다.
  • KDE Peak는 Mean이 아니다.
  • Rug는 Observation, KDE는 Estimate다.
  • 교안의 distplot()은 Histogram + KDE의 의미로 이해한다.
  • Step 1·2 현재 실습 보완에서는 histplot(kde=True)를 사용한다.
  • 분포에서는 Center, Spread, Peak, Skew, Multiple Peaks, Extreme Values를 본다.
  • Numeric dtype라고 모두 의미 있는 수치 Feature는 아니다.
  • Extreme Value는 삭제가 아니라 조사의 시작이다.
