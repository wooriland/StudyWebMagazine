Data Visualization · Lesson 01

데이터 시각화의 목적과 그래프 선택 Visualization Concept & Chart Selection

데이터 시각화는 데이터를 예쁘게 꾸미는 작업이 아니라, 숫자와 문자만으로 발견하기 어려운 변화, 비교, 관계, 분포, 이상치와 패턴 을 눈으로 탐색하는 분석 과정입니다. 이 단원에서는 분석 질문과 데이터 유형을 먼저 판단한 뒤 Line, Bar, Scatter, Histogram, KDE, Boxplot, Heatmap, Pie Chart 등 적절한 그래프를 선택하는 기준을 학습합니다.

핵심 공식 분석 질문 + 데이터 유형 = 그래프 선택
데이터 → 질문 → 데이터 유형 → 그래프 선택 → 관찰 → 해석 → 다음 질문

학습 목표

  • 데이터 시각화가 필요한 이유를 설명할 수 있다.
  • 표와 그래프의 역할 차이를 설명할 수 있다.
  • 범주형, 수치형, 시간형 데이터의 차이를 구분할 수 있다.
  • 분석 질문과 데이터 유형을 바탕으로 적절한 그래프를 선택할 수 있다.
  • Line, Bar, Scatter, Histogram, KDE, Boxplot, Heatmap, Pie Chart의 목적을 구분할 수 있다.
  • Countplot, Barplot, Boxplot, Catplot, Lineplot의 기본 사용 목적을 설명할 수 있다.
  • 상관관계와 인과관계의 차이를 설명할 수 있다.
  • 그래프에서 관찰한 사실과 해석을 구분할 수 있다.
  • 시각화 결과를 추가 분석과 데이터 정제로 연결할 수 있다.

01 · Core Concept

핵심 개념 — 그래프보다 질문이 먼저다

데이터 시각화의 목적은 숫자나 문자로만 구성된 데이터를 단순히 그림으로 바꾸는 것이 아닙니다. 데이터 안에 숨어 있는 변화, 비교, 관계, 분포, 이상치 를 사람이 빠르게 이해할 수 있도록 표현하고, 그 결과를 새로운 분석 질문으로 연결하는 데 목적이 있습니다.

가장 중요한 원칙

“어떤 그래프를 사용할까?”부터 생각하지 말고 “무엇을 알고 싶은가?” 부터 생각합니다.

잘못된 접근

그래프부터 선택하기

Scatter Plot을 배웠다 ↓ 아무 데이터나 Scatter로 그린다 ↓ 무엇을 분석한 것인지 설명하기 어렵다
분석적인 접근

Time

시간형 데이터

date month year timestamp

핵심 질문: 언제 어떻게 변하는가?

숫자로 저장됐다고 모두 수치형 분석 대상은 아니다

예를 들어 customer_id = 10001, 10002, 10003은 숫자로 저장될 수 있지만 고객을 식별하는 번호이므로 평균값을 계산하는 것은 보통 분석적으로 의미가 없습니다.

dtype + 열의 실제 의미 = 데이터 유형 판단

그래프 선택 기준

데이터와 질문 데이터 조합 적합한 그래프 확인할 것
시간에 따라 값이 어떻게 변하는가? 시간 + 수치 Line Plot 증가, 감소, 추세, 변곡점
여러 범주의 크기를 비교하는가? 범주 + 수치 Bar Plot 크기, 순위, 격차
두 수치형 변수에 관계가 있는가? 수치 + 수치 Scatter Plot 방향, 밀집도, 군집
하나의 수치형 데이터가 어떻게 분포하는가? 수치 Histogram / KDE 중심, 퍼짐, 왜도
범주별 수치 분포와 이상치를 확인하는가? 범주 + 수치 Boxplot Median, IQR, Outlier
여러 변수의 상관관계를 한 번에 보는가? 여러 수치 변수 Heatmap 관계의 방향과 강도
범주가 전체에서 차지하는 비율을 보는가? 범주 + 구성비 Pie Chart 전체 중 구성 비율
범주와 수치형 변수를 동시에 비교하는가? 범주 + 수치 Barplot / Boxplot / Catplot 그룹별 수치 차이
시간과 범주를 함께 비교하는가? 시간 + 범주 + 수치 Lineplot + hue 그룹별 시간 추세

같은 데이터라도 질문이 다르면 그래프가 달라진다

region + sales

04 · Python Example

Python 코드 — 하나의 데이터로 여러 질문 만들기

동일한 DataFrame이라도 질문이 달라지면 사용하는 열과 그래프도 달라집니다.

1단계 · 예제 데이터 준비 

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.DataFrame({
    "month": [
        1, 2, 3, 4, 5, 6,
        1, 2, 3, 4, 5, 6
    ],
    "channel": [
        "Online", "Online", "Online",
        "Online", "Online", "Online",
        "Offline", "Offline", "Offline",
        "Offline", "Offline", "Offline"
    ],
    "sales": [
        120, 135, 150, 170, 190, 220,
        100, 110, 115, 125, 130, 140
    ],
    "advertising": [
        10, 12, 15, 18, 22, 28,
        8, 9, 10, 11, 12, 13
    ]
})

print(df)
month 시간 / 순서
channel 범주형
sales 수치형
advertising 수치형

2단계 · 시간 + 수치 → Line Plot

질문 온라인 매출은 월이 지나면서 어떻게 변하는가? 
online = df[
    df["channel"] == "Online"
]

plt.plot(
    online["month"],
    online["sales"],
    marker="o"
)

plt.xlabel("Month")
plt.ylabel("Sales")
plt.title("Online Monthly Sales")

plt.show()
Online 데이터 선택 → month = X → sales = Y → 시간 변화

3단계 · 시간 + 범주 + 수치 → Lineplot + hue

질문 온라인과 오프라인의 월별 매출 추세는 어떻게 다른가? 
sns.lineplot(
    data=df,
    x="month",
    y="sales",
    hue="channel",
    marker="o"
)

plt.title("Monthly Sales by Channel")

plt.show()
data

9단계 · 여러 수치 변수 → Heatmap

질문 month, sales, advertising은 서로 어떤 관계가 있는가? 
numeric_df = df[
    [
        "month",
        "sales",
        "advertising"
    ]
]

corr = numeric_df.corr()

sns.heatmap(
    corr,
    annot=True
)

plt.title("Correlation Heatmap")

plt.show()
수치형 열 → corr() → 상관관계 행렬 → Heatmap

10단계 · 전체 구성 비율 → Pie Chart

예를 들어 결제 방식별 주문 수처럼 전체 구성비 자체를 보여주고 싶을 때 사용할 수 있습니다.

    "Card",

    "Cash"

values = [
    50,

    20

07 · Interview

면접 포인트

Q1. 데이터 시각화란 무엇입니까?

숫자나 문자만으로 발견하기 어려운 데이터의 패턴, 관계, 분포, 변화, 이상치를 그래프로 표현하여 직관적으로 탐색하는 방법입니다. 분석 과정에서는 가설을 검토하고 Insight와 추가 분석 방향을 찾는 데 활용할 수 있습니다.

Q2. 어떤 그래프를 사용할지 어떻게 결정합니까?

먼저 분석 질문을 정하고 필요한 열과 데이터 유형을 확인합니다. 시간 변화인지, 범주 비교인지, 수치 변수 간 관계인지, 분포인지에 따라 적합한 그래프를 선택합니다.

Q3. Bar Plot과 Histogram의 차이는?

Bar Plot은 서로 다른 범주의 값을 비교하는 그래프이고, Histogram은 연속형 수치 데이터를 여러 구간으로 나누어 분포를 확인하는 그래프입니다.

Q4. Line Plot은 언제 사용합니까?

시간이나 순서에 따라 값이 어떻게 변화하는지 확인할 때 사용합니다. 추세, 증가·감소, 변곡점 등을 탐색할 수 있습니다.

Q5. Scatter Plot은 언제 사용합니까?

두 수치형 변수 사이의 관계를 탐색할 때 사용합니다. 각 점의 위치를 이용해 관계 방향, 밀집도, 군집, 이상점을 확인할 수 있습니다.

Q6. 상관관계와 인과관계는 어떻게 다릅니까?

상관관계는 두 변수가 함께 변화하는 경향을 의미하지만, 한 변수가 다른 변수의 원인이라는 뜻은 아닙니다. 인과관계를 확인하려면 추가 검증이 필요합니다.

Q7. Histogram과 KDE의 차이는?

Histogram은 수치 데이터를 구간으로 나누어 빈도를 막대로 표현하고, KDE는 데이터 분포의 전체적인 형태를 부드러운 곡선으로 표현합니다.

Q8. Boxplot을 사용하는 이유는?

중앙값, Q1, Q3, IQR과 데이터의 분포 및 이상치를 빠르게 파악할 수 있기 때문입니다. 범주별 수치 분포 비교에도 유용합니다.

Q9. Countplot과 Barplot의 차이는?

Countplot은 범주별 데이터 개수를 표현하고, Barplot은 범주에 따른 수치 값을 요약하여 비교하는 데 사용합니다.

Q10. Heatmap은 언제 사용합니까?

여러 변수의 상관관계와 같이 행렬 형태의 값을 색상으로 표현하여 관계의 강도와 방향을 빠르게 비교할 때 사용합니다.

Q11. Seaborn의 hue는 무엇입니까?

범주형 변수를 기준으로 데이터를 여러 그룹으로 나누어 같은 그래프 안에서 시각적으로 구분하는 데 사용하는 인수입니다.

Q12. 데이터 시각화와 전처리는 어떤 관계입니까?

시각화를 통해 이상치, 비정상적인 분포, 입력 오류 가능성을 발견할 수 있습니다. 원본 데이터를 확인하고 필요하면 정제한 후 다시 시각화하는 반복 과정으로 이어집니다.

오늘의 암기 포인트

  • 데이터 시각화는 예쁜 그림을 만드는 작업이 아니라 데이터의 의미를 찾는 분석 과정 이다.
  • 그래프보다 질문이 먼저다.
  • 분석 질문 + 데이터 유형 = 그래프 선택 기준이다.
  • 시간 변화 → Line
  • 범주 비교 → Bar
  • 수치 + 수치 관계 → Scatter
  • 수치 분포 → Histogram / KDE
  • 범주별 분포·이상치 → Boxplot
  • 여러 수치 변수의 상관관계 → Heatmap
  • 전체 구성 비율 → Pie
  • 시간 + 범주 + 수치 → Lineplot + hue
  • Correlation ≠ Causation
  • Outlier 발견과 Outlier 삭제는 같은 의미가 아니다.

헷갈리기 쉬운 개념

Bar vs Histogram

범주 비교 vs 수치 데이터 분포

Line vs Scatter

시간·순서 변화 vs 두 수치 변수 관계

Countplot vs Barplot

범주 개수 vs 범주별 수치 비교

Histogram vs KDE

구간별 빈도 막대 vs 부드러운 분포 곡선

Correlation vs Causation

함께 움직이는 경향 vs 원인·결과

Observation vs Interpretation

직접 보이는 사실 vs 이유에 대한 추론

Outlier vs Error

이상치는 오류일 수도 있지만 실제 중요한 데이터일 수도 있다.

숫자 dtype vs 분석용 수치형

ID·전화번호처럼 숫자로 저장되어도 계산 의미가 없을 수 있다.
