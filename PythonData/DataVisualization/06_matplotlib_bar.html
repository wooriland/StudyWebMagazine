Data Visualization · Lesson 06

막대그래프와 값 표시 Bar · Barh · Tick Label · Rotation · Text

막대그래프(Bar Plot)는 여러 범주의 수치 크기를 막대의 길이로 표현하여 서로 비교하는 그래프 입니다. 이번 단원에서는 수직 막대 bar(), 수평 막대 barh(), 범주 이름을 표시하는 xticks()·yticks(), 긴 레이블을 회전하는 rotation, 막대의 폭과 두께, 그리고 text()를 이용해 실제 값을 막대 위에 표시하는 방법까지 공부합니다.

그래프 선택 기준 범주(Category) + 수치(Value) → Bar Plot
Question → Category + Value → Aggregate → bar / barh → Tick Label → Text → Compare
가장 중요한 기억

Bar Plot의 핵심 질문은 “어느 범주의 값이 더 큰가?” 입니다. 원본 데이터가 여러 행이라면 바로 막대를 그리는 것이 아니라, 질문에 따라 SUM, COUNT, MEAN 같은 집계를 먼저 수행해야 할 수도 있습니다.

학습 목표

  • Bar Plot이 범주별 값의 크기를 비교하는 그래프임을 설명할 수 있다.
  • Category와 Value가 하나의 막대를 만드는 관계를 설명할 수 있다.
  • 원본 데이터와 범주별 집계 결과의 차이를 이해할 수 있다.
  • bar()와 barh()의 차이를 설명할 수 있다.
  • 수직 막대에서는 X축이 Category, Y축이 Value라는 것을 설명할 수 있다.
  • 수평 막대에서는 Y축이 Category, X축이 Value라는 것을 설명할 수 있다.
  • xticks()와 yticks()를 이용해 범주 이름을 표시할 수 있다.
  • Tick Position과 Tick Label의 차이를 설명할 수 있다.
  • rotation이 데이터가 아니라 레이블의 표시 각도를 변경한다는 것을 이해한다.
  • 수직 Bar와 수평 Bar에서 width와 height의 역할을 구분할 수 있다.
  • text()를 이용해 막대 끝에 실제 값을 표시할 수 있다.
  • ha와 va의 역할을 설명할 수 있다.
  • 수직·수평 Bar에서 텍스트 X·Y 좌표가 어떻게 달라지는지 설명할 수 있다.
  • Bar와 Line, Scatter, Histogram, Pie의 분석 질문 차이를 구분할 수 있다.
  • Pandas GroupBy 또는 SQL GROUP BY 결과를 Bar Plot으로 연결할 수 있다.
  • 가장 큰 범주, 가장 작은 범주, 주요 차이를 분석 문장으로 표현할 수 있다.

예제 8 · text()로 Bar 위에 값 표시 

import matplotlib.pyplot as plt


positions = [
    0,
    1,
    2,
    3
]


categories = [
    "Laptop",
    "Monitor",
    "Keyboard",
    "Mouse"
]


values = [
    120,
    85,
    160,
    210
]


fig = plt.figure(
    figsize=(9, 5)
)


ax = fig.add_subplot(
    1,
    1,
    1
)


ax.bar(
    positions,
    values,
    width=0.6
)


ax.set_xticks(
    positions,
    categories,
    rotation=30
)


for position, value in zip(
    positions,
    values
):
    ax.text(
        position,
        value,
        str(value),
        ha="center",
        va="bottom"
    )


ax.set_title(
    "Product Count by Category"
)


ax.set_xlabel(
    "Category"
)


ax.set_ylabel(
    "Count"
)


plt.show()
zip(positions, values) → Bar 1 위치 + 값 → ax.text() → Value Label

07 · Interview

면접 포인트

Q1. Bar Plot이란 무엇입니까?

여러 범주의 수치값을 막대 길이로 표현하여 범주별 값의 크기를 비교하는 그래프입니다. 교안에서는 동일한 너비의 여러 막대를 사용하고 각 막대의 높이를 특정 집계값 표현에 활용한다고 설명합니다.

Q2. 언제 Bar Plot을 사용합니까?

지역, 상품군, 부서, 응답 유형처럼 여러 범주의 수치를 서로 비교할 때 사용합니다.

Q3. Bar Plot의 기본 데이터 구조는 무엇입니까?

하나의 Category와 그 Category에 대응하는 하나의 Value가 기본 구조입니다.

Q4. Bar Plot에서 집계가 중요한 이유는?

하나의 Category가 원본 데이터에 여러 행으로 존재할 수 있기 때문에 질문에 맞게 SUM, COUNT, MEAN 등으로 먼저 요약해야 할 수 있기 때문입니다.

Q5. bar()와 barh()의 차이는?

bar()는 수직 막대, barh()는 수평 막대를 그릴 때 사용합니다.

Q6. 수직 Bar에서 Category와 Value는 어느 축에 있습니까?

일반적으로 Category는 X축, Value는 Y축의 막대 높이로 표현합니다.

Q7. 수평 Bar에서는 어떻게 됩니까?

Category를 Y축에 배치하고 Value를 X축 방향의 막대 길이로 표현합니다.

Q8. xticks()는 어떤 역할을 합니까?

교안의 위치 기반 수직 Bar에서 각 X 위치에 Category 이름을 연결하는 데 사용합니다.

Q9. yticks()는 무엇입니까?

수평 Bar의 Y축 막대 위치에 Category Label을 표시할 때 사용합니다.

Q10. rotation은 무엇을 변경합니까?

데이터가 아니라 Tick Label의 표시 각도를 변경하여 긴 Category 이름의 가독성을 높일 수 있습니다.

Q11. text()는 무엇을 합니까?

지정한 X·Y 위치에 문자열을 표시합니다. 막대 끝에 실제 값을 표시하는 데 사용할 수 있습니다.

Q12. ha와 va의 차이는?

ha는 Horizontal Alignment, va는 Vertical Alignment로 텍스트의 수평·수직 정렬을 설정합니다.

Q13. 수직 Bar의 text 좌표는 어떻게 생각합니까?

일반적으로 X에는 막대의 Category Position, Y에는 막대의 Value 또는 끝 위치를 사용합니다.

Q14. 수평 Bar의 text 좌표는?

일반적으로 X에는 막대 Value의 끝 위치, Y에는 Category Position을 사용합니다.

Q15. Bar와 Histogram의 차이는?

Bar는 서로 다른 범주별 값을 비교하고, Histogram은 하나의 연속형 수치 데이터를 구간으로 나누어 분포를 확인합니다.

Q16. 범주가 매우 많다면 어떻게 합니까?

분석 목적에 따라 Top N을 선택하거나 Category를 다시 그룹화하고, 긴 범주명이라면 수평 Bar를 고려할 수 있습니다.

Q17. 항상 값 순으로 정렬해야 합니까?

아닙니다. 순위 비교가 목적이면 정렬이 유용하지만 요일이나 만족도처럼 Category의 논리적 순서가 중요하다면 원래 순서를 유지하는 것이 좋습니다.

Q18. Bar Plot에서 Axis Range가 중요한 이유는 무엇입니까?

Bar는 막대 길이로 값의 크기를 전달하므로 축의 시작점과 끝점에 따라 범주 간 차이가 실제보다 크거나 작게 보일 수 있기 때문입니다.

오늘의 암기 포인트

  • 범주 + 수치 → Bar Plot
  • 핵심 질문은 “어느 범주의 값이 더 큰가?” 이다.
  • bar()는 수직 막대다.
  • barh()는 수평 막대다.
  • 수직 Bar는 X = Category, Y = Value로 생각한다.
  • 수평 Bar는 Y = Category, X = Value로 생각한다.
  • xticks()는 수직 Bar의 Category Label과 연결한다.
  • yticks()는 수평 Bar의 Category Label과 연결한다.
  • rotation은 Label 표시 각도다.
  • text()는 정확한 값을 화면에 표시한다.
  • ha는 Horizontal Alignment다.
  • va는 Vertical Alignment다.
  • 수직 Text 좌표는 X = Position, Y = Value로 생각한다.
  • 수평 Text 좌표는 X = Value, Y = Position으로 생각한다.
  • Bar는 원본 데이터보다 범주별 집계 결과를 표현하는 경우가 많다.
  • Bar의 막대 길이를 볼 때 Axis Range도 함께 확인한다.
