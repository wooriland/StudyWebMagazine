Data Visualization · Lesson 03

Matplotlib 선 그래프와 그래프 구성 요소 Line Plot · Marker · Label · Legend · Grid · Axis

선 그래프(Line Plot)는 시간 또는 순서에 따라 수치가 어떻게 변하는지 표현하는 대표적인 그래프입니다. X와 Y의 값을 좌표로 대응시키고 각 데이터 포인트를 선으로 연결하여 증가·감소·정체·급등·급락과 같은 Trend를 탐색합니다. 이 단원에서는 plot()을 중심으로 제목, X·Y축 레이블, 범례, 눈금, 격자, 축 범위, Marker, Color, Line Style까지 하나의 완성된 그래프로 연결합니다.

그래프 선택 기준 시간 + 수치 → Line Plot
X / Y → plot() → Line / Marker → Title / Label → Legend / Grid → Axis Range → Trend
가장 중요한 기억

X는 시간·순서와 같은 기준, Y는 관찰하려는 측정값으로 생각합니다. Marker는 실제 데이터 포인트, Line은 포인트 사이의 변화 흐름을 보여줍니다.

학습 목표

  • Line Plot이 시간 또는 순서에 따른 변화를 표현하는 그래프임을 설명할 수 있다.
  • X값과 Y값이 어떻게 좌표로 대응되는지 설명할 수 있다.
  • X값을 생략했을 때 자동으로 생성되는 좌표의 의미를 설명할 수 있다.
  • plot(x, y)를 이용해 기본 선 그래프를 작성할 수 있다.
  • Marker와 Line의 역할 차이를 구분할 수 있다.
  • Color, Marker, Line Style을 그래프에 적용할 수 있다.
  • title(), xlabel(), ylabel()로 그래프의 의미를 명확하게 표현할 수 있다.
  • label과 legend()의 관계를 설명할 수 있다.
  • Tick과 Grid의 역할을 구분할 수 있다.
  • axis()와 figsize가 데이터 자체가 아니라 그래프 표시 방식에 영향을 준다는 것을 이해한다.
  • 여러 개의 Line Plot을 하나의 Axes에서 비교할 수 있다.
  • Line Plot을 통해 Trend를 관찰하고 다음 분석 질문을 만들 수 있다.

01 · Core Concept

핵심 개념 — X와 Y를 연결하여 변화의 흐름을 읽는다

Line Plot의 핵심은 단순히 점들을 선으로 연결하는 것이 아닙니다. 순서가 있는 X에 따라 Y가 어떻게 변화하는가 를 한눈에 읽도록 만드는 것이 목적입니다.

QUESTION 시간에 따라 값이 어떻게 변하는가?
↓
CHART Line Plot

X와 Y의 역할

X

기준 / 시간 / 순서

month date hour year
Y

측정하려는 수치

sales temperature visitors price

기본 문법

Y만 전달 
plt.plot(
    y
)

X는 자동으로 0, 1, 2, ... 형태로 생성됩니다.

X와 Y 전달 
plt.plot(
    x,
    y
)

같은 위치의 X와 Y가 하나의 좌표를 만듭니다.

X와 Y는 같은 위치끼리 짝을 이룬다

X 1 2 3 4
+ + + +
Y 10 20 15 30
→ → → →
Coordinate (1, 10) (2, 20) (3, 15) (4, 30)

X를 생략하면 0부터 자동 증가한다 

plt.plot(
    [10, 20, 30, 40]
)
입력한 Y [10, 20, 30, 40]
→
자동 X [0, 1, 2, 3]
→
실제 좌표 (0,10) (1,20) (2,30) (3,40)
주의

자동 생성된 0, 1, 2, 3은 단순한 위치 좌표입니다. 실제 1월·2월·3월이나 특정 날짜를 의미하는 것이 아니라면 분석 의미를 임의로 부여해서는 안 됩니다.

X와 Y는 좌표를 만들 수 있어야 한다

len(x) = len(y)

일반적인 1차원 Line Plot에서는 각 X가 하나의 Y와 짝을 이루어야 합니다.

    marker="o"

07 · Interview

면접 포인트

Q1. Line Plot은 언제 사용합니까?

시간이나 순서에 따라 수치가 어떻게 변화하는지 확인할 때 사용합니다. 증가·감소 추세, 정체, 급등·급락, 변곡점 등을 탐색하는 데 적합합니다.

Q2. plot(x, y)는 어떻게 동작합니까?

같은 위치에 있는 X와 Y 값을 하나의 좌표로 대응시키고, 만들어진 데이터 포인트를 전달된 순서대로 선으로 연결합니다.

Q3. X를 생략하면 어떻게 됩니까?

교안의 설명 기준으로 X는 0부터 시작하여 1씩 증가하는 좌표로 자동 매칭됩니다. 예를 들어 plot([1,2,3])은 (0,1), (1,2), (2,3)을 연결합니다.

Q4. Line과 Marker의 차이는 무엇입니까?

Line은 데이터 포인트 사이의 변화 흐름을 보여주고, Marker는 실제 관측값이 존재하는 위치를 표시합니다.

Q5. Marker와 Tick의 차이는 무엇입니까?

Marker는 실제 데이터 좌표를 나타내는 기호이고 Tick은 X·Y Axis 위에서 값의 위치를 나타내는 눈금입니다.

Q6. label과 legend()는 어떤 관계입니까?

label은 각각의 Plot에 이름을 지정하고, legend()는 지정된 이름을 그래프 범례로 화면에 표시합니다.

Q7. title(), xlabel(), ylabel()의 역할은 무엇입니까?

title()은 그래프 전체의 의미를 설명하고, xlabel()과 ylabel()은 각 축이 어떤 데이터를 의미하는지 설명합니다.

Q8. Tick과 Grid의 차이는 무엇입니까?

Tick은 Axis 위의 값이나 레이블 위치이고, Grid는 그 위치를 그래프 안쪽까지 확장해 값을 읽기 쉽게 해주는 보조선입니다.

Q9. axis()로 범위를 변경하면 데이터도 바뀝니까?

아닙니다. 실제 데이터는 그대로이고 화면에서 보여주는 X·Y축의 범위만 변경됩니다.

Q10. 축 범위를 확인해야 하는 이유는?

동일한 데이터도 축의 시작값과 끝값에 따라 차이가 크게 또는 작게 보일 수 있어 그래프 해석에 영향을 주기 때문입니다.

Q11. 시계열 데이터를 정렬해야 하는 이유는 무엇입니까?

Line Plot은 전달된 순서대로 데이터 포인트를 연결하기 때문에 시간 순서가 섞이면 실제 변화 흐름을 잘못 표현할 수 있습니다.

Q12. 여러 개의 선을 비교할 때 무엇을 추가해야 합니까?

각 Plot에 label을 지정하고 legend()로 범례를 표시하는 것이 중요합니다. 필요하면 Marker나 Line Style도 다르게 지정할 수 있습니다.

Q13. figsize는 무엇입니까?

Figure 전체의 가로·세로 표시 크기를 지정하는 옵션입니다. 데이터 값 자체를 변경하지 않습니다.

Q14. Line Plot에서 가장 중요한 분석 대상은 무엇입니까?

개별 데이터 포인트뿐 아니라 시간 또는 순서에 따른 전체적인 변화 방향, 즉 Trend입니다.

오늘의 암기 포인트

  • 시간 + 수치 → Line Plot
  • X는 시간·순서, Y는 측정하려는 값으로 생각한다.
  • plot(x, y)는 X와 Y의 좌표를 순서대로 연결한다.
  • X를 생략하면 0부터 자동 증가하는 좌표가 사용된다.
  • X와 Y는 좌표 쌍을 만들 수 있어야 한다.
  • Marker는 실제 데이터 포인트다.
  • Line은 데이터 포인트 사이의 변화 흐름이다.
  • Tick은 축의 눈금이다.
  • Grid는 값을 읽기 쉽게 하는 보조선이다.
  • label은 Plot 이름, legend()는 범례 표시다.
  • title()은 그래프 제목이다.
  • xlabel(), ylabel()은 각 축의 의미를 나타낸다.
  • axis()는 데이터 자체가 아니라 표시 범위를 조정한다.
  • figsize는 Figure 전체 크기다.
  • Line Plot에서는 개별 값보다 Trend를 읽는다.
