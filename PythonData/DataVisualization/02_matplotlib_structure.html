Data Visualization · Lesson 02

Figure, Axes, Plot과 Axis Matplotlib 그래프 구조 이해하기

Matplotlib의 그래프는 단순히 plot() 함수 하나로 만들어지는 것이 아닙니다. 전체 그래프 화면인 Figure, 실제 그래프가 위치하는 Axes, 선·점·막대처럼 데이터를 표현하는 Plot, X축·Y축과 눈금·레이블을 담당하는 Axis 가 서로 관계를 이루며 하나의 시각화를 구성합니다.

Figure 전체 도화지
→
Axes 그래프 영역
→
Plot 데이터 표현
+
Axis X·Y축
가장 중요한 암기

Figure는 집 전체, Axes는 방, Plot은 방 안의 가구, Axis는 그래프를 읽는 가로·세로 기준이라고 생각하면 이해하기 쉽습니다.

학습 목표

  • Figure, Axes, Plot, Axis의 역할을 각각 설명할 수 있다.
  • Figure와 Axes의 관계를 이해하고 하나의 Figure에 여러 Axes를 구성할 수 있다.
  • 하나의 Axes 안에 여러 Plot을 추가할 수 있다는 것을 이해한다.
  • Axes와 Axis의 차이를 정확하게 설명할 수 있다.
  • plt.figure()와 fig.add_subplot()의 역할을 구분할 수 있다.
  • add_subplot(행, 열, 위치)의 위치 번호를 읽을 수 있다.
  • ax.plot(), ax.set_title(), ax.set_xlabel(), ax.set_ylabel()의 대상이 무엇인지 이해한다.
  • pyplot 방식과 Axes 객체 중심 방식의 차이를 이해한다.
  • 여러 그래프를 하나의 Figure에 배치하는 기본 구조를 작성할 수 있다.
  • 다음 단원의 Line Plot 문법을 Figure/Axes 구조와 연결할 준비를 한다.

01 · Core Concept

핵심 개념 — Matplotlib 그래프의 계층 구조

Matplotlib을 이해할 때 가장 중요한 것은 plot() 같은 함수 이름을 무조건 외우는 것이 아니라, 지금 전체 화면을 다루는지, 그래프 영역을 다루는지, 실제 데이터를 그리는지, 축을 설정하는지 구분하는 것입니다.

01
Figure 전체 그래프 화면 / 도화지

하나 이상의 Axes를 담는 가장 바깥쪽 컨테이너입니다.

fig = plt.figure()
↓
02
Axes 실제 그래프 영역

Figure 안에서 Line, Bar, Scatter 등의 실제 그래프가 그려지는 개별 공간입니다.

ax = fig.add_subplot(1, 1, 1)
↓
03
Plot 실제 데이터 표현

선, 점, 막대 등 데이터가 실제로 표현되는 그래프 요소입니다.

ax.plot(x, y)
04
Axis X축 · Y축

그래프의 가로·세로 축과 눈금, 축 레이블 등의 기준을 담당합니다.

ax.set_xlabel("Month")

Axes 방

각각의 그래프가 들어가는 개별 공간

Plot 가구와 그림

방 안에 실제로 배치되는 데이터 표현

Axis 위치 기준

값을 읽을 수 있게 해 주는 X·Y축

Figure — 전체 도화지 

fig = plt.figure()

plt.figure()는 새로운 Figure 객체를 생성합니다.

아직 Axes나 Plot을 명시적으로 추가하지 않았다면 전체 그래프 화면만 준비된 상태라고 생각하면 됩니다.

Figure 크기 

fig = plt.figure(
    figsize=(10, 6)
)
10 가로 × 6 세로 → Figure 전체 크기

figsize는 개별 Plot의 크기가 아니라 전체 Figure의 크기를 의미합니다.

Axes — 실제 그래프가 들어가는 공간 

ax = fig.add_subplot(
    1,
    1,
    1
)
첫 번째 1 행 개수
두 번째 1 열 개수
세 번째 1 위치

add_subplot(2, 2, 위치)

1 왼쪽 위
2 오른쪽 위
3 왼쪽 아래
4 오른쪽 아래 
ax1 = fig.add_subplot(2, 2, 1)
ax2 = fig.add_subplot(2, 2, 2)
ax3 = fig.add_subplot(2, 2, 3)
ax4 = fig.add_subplot(2, 2, 4)

Plot — Axes 안에 들어가는 실제 데이터 표현

ax.plot() Line
ax.scatter() Scatter
ax.bar() Bar
하나의 Axes에 Plot 여러 개도 가능 
ax.plot(x, sales_a)
ax.plot(x, sales_b)

Figure 하나에 Axes 여러 개가 들어갈 수 있고, Axes 하나에도 여러 Plot이 들어갈 수 있습니다.

Axis — 그래프를 읽는 기준

X Axis

가로축과 X 방향 눈금

set_xlabel()
Y Axis

세로축과 Y 방향 눈금

set_ylabel()
Axis 표시

필요하면 축 자체를 숨길 수 있음

ax.axis("off")
Axes 그래프 영역

Line, Scatter, Bar 등이 실제로 들어가는 공간

≠
Axis X축 · Y축

눈금과 값을 읽는 기준

pyplot 방식과 Axes 객체 방식

pyplot 
plt.plot(x, y)
plt.title("Sales")
plt.xlabel("Month")
plt.ylabel("Amount")
plt.show()

간단하고 짧아서 그래프 하나를 빠르게 작성하기 좋습니다.

Axes Object 
fig = plt.figure()

ax = fig.add_subplot(1, 1, 1)

ax.plot(x, y)

ax.set_title("Sales")
ax.set_xlabel("Month")
ax.set_ylabel("Amount")

plt.show()

어떤 Axes를 수정하는지가 분명해 여러 그래프를 관리하기 좋습니다.

학습 보완

plt.subplots()

교안의 중심은 figure()와 add_subplot()입니다. 실제 Matplotlib 코드에서는 Figure와 Axes를 한 번에 만드는 다음 형태도 자주 사용합니다. 

fig, ax = plt.subplots()

개념적으로는 여전히:

Figure + Axes → fig, ax

ax.plot(...)

특정 Axes의 제목 을 설정

Figure 하나에 Axes 네 개

Figure
ax1 Line
ax2 Scatter
ax3 Bar
ax4 Line
add_subplot 1부터 시작 add_subplot(2, 2, 1)
VS
axes 배열 0부터 시작 axes[0, 0]
자주 틀리는 부분

add_subplot(2,2,1)의 위치 번호와 axes[0,0]의 배열 인덱스를 같은 규칙이라고 생각하지 않습니다.

plt.plot()만 호출해도 그래프가 나오는 이유

plt.plot(x, y) ↓ 사용할 Figure 확인 ↓ 사용할 Axes 확인 ↓ Axes에 Plot 추가

간단한 pyplot 방식에서는 Figure와 Axes를 코드에서 직접 만들지 않아도 필요한 그래프 객체가 자동으로 준비될 수 있습니다. 그러나 구조가 사라진 것은 아닙니다.

05 · Error Reading

오류 메시지 읽는 법

이번 단원의 오류는 Figure → Axes → Plot 중 어느 계층의 객체가 준비되지 않았는지를 생각하면서 읽으면 이해하기 쉽습니다.

Traceback → 오류 종류 → 문제 변수 → Figure / Axes / Plot 중 어디?

ModuleNotFoundError 

ModuleNotFoundError:
No module named 'matplotlib'

현재 Python 환경에서 Matplotlib을 찾지 못한 상황입니다. 

pip install matplotlib

PyCharm Interpreter나 Jupyter Kernel도 같은 환경인지 확인합니다.

name 'plt' is not defined

fig = plt.figure()

ax가 가리킬 Axes 객체가 아직 생성되지 않은 상태입니다.

현재 변수에 저장된 객체가 내가 생각한 Figure 또는 Axes 객체가 맞는지 확인합니다.

07 · Interview

면접 포인트

Q1. Matplotlib의 Figure란 무엇입니까?

하나 이상의 그래프 영역을 담는 전체 도화지 또는 전체 그래프 화면입니다. 하나의 Figure 내부에 여러 Axes를 배치할 수 있습니다.

Q2. Axes란 무엇입니까?

Figure 안에서 실제 Line, Scatter, Bar 등의 Plot이 그려지는 개별 그래프 영역입니다.

Q3. Axes와 Axis의 차이는 무엇입니까?

Axes는 그래프 하나가 들어가는 전체 영역이고, Axis는 Axes 내부의 X축과 Y축, 눈금과 레이블을 의미합니다.

Q4. Plot이란 무엇입니까?

Axes 내부에 실제로 표현되는 데이터 시각화 요소입니다. Line, Scatter, Bar 등이 대표적입니다.

Q5. Figure 하나에 Axes 여러 개를 만들 수 있습니까?

가능합니다. add_subplot() 등을 이용하여 하나의 Figure 안에 여러 Axes를 배치할 수 있습니다.

Q6. 하나의 Axes에 Plot 여러 개를 그릴 수 있습니까?

가능합니다. 동일한 Axes에 여러 번 plot()을 호출해 여러 데이터 시리즈를 함께 표현할 수 있습니다.

Q7. add_subplot(2, 2, 1)은 어떤 의미입니까?

Figure를 2행 2열로 구성한다고 생각하고 그중 첫 번째 위치에 Axes를 추가한다는 의미입니다.

Q8. plt.plot()만 호출해도 그래프가 나오는 이유는 무엇입니까?

pyplot이 필요한 Figure와 그래프 영역을 준비하여 현재 Axes에 Plot을 그릴 수 있기 때문입니다. 명시적으로 객체를 작성하지 않았을 뿐 Figure/Axes 구조 자체가 사라진 것은 아닙니다.

Q9. plt.title()과 ax.set_title()은 어떤 차이로 이해하면 됩니까?

pyplot 방식의 plt.title()은 현재 그래프를 대상으로 사용하고, ax.set_title()은 특정 Axes 객체를 명시적으로 대상으로 지정합니다. 여러 Axes를 관리할 때 객체 방식이 구조를 이해하기 쉽습니다.

Q10. figsize는 무엇을 설정합니까?

개별 Plot이 아니라 Figure 전체의 가로·세로 크기를 설정합니다.

Q11. Matplotlib의 일반적인 작성 순서는 무엇입니까?

Figure를 만들고, Figure에 Axes를 추가하고, Axes에 Plot을 추가한 뒤 축과 레이블을 조정하고 마지막으로 plt.show()로 표시합니다.

Q12. Figure와 Axes 구조를 알아야 하는 이유는 무엇입니까?

여러 그래프를 한 화면에 배치할 때 어느 그래프에 데이터를 그리고, 어느 그래프의 제목·축·옵션을 수정하는지 명확하게 관리할 수 있기 때문입니다.

오늘의 암기 포인트

  • Figure = 전체 도화지
  • Axes = 실제 그래프 영역
  • Plot = 선·점·막대 등의 데이터 표현
  • Axis = X축·Y축과 눈금·레이블
  • 하나의 Figure에는 여러 Axes가 들어갈 수 있다.
  • 하나의 Axes에는 여러 Plot이 들어갈 수 있다.
  • Axes 안에 Axis가 있다.
  • plt.figure() → Figure 생성
  • fig.add_subplot() → Axes 생성
  • ax.plot() → Axes에 Plot 추가
  • ax.set_xlabel() → X축 레이블 설정
  • plt.show() → 완성된 Figure 표시
