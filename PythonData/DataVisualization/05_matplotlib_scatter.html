Data Visualization · Lesson 05

산점도와 변수 관계 Scatter Plot · Density · Direction · Cluster · Outlier

Scatter Plot은 두 수치형 변수의 값을 X·Y 좌표로 표현 하고, 각 관측값을 하나의 점(Point)으로 표시하여 두 변수 사이에 어떤 관계가 보이는지 탐색하는 그래프입니다. 점들이 어디에 밀집하는지 확인하는 것이 기본이며, 실제 분석에서는 방향, 군집, 이상치, 관계의 형태까지 함께 살펴볼 수 있습니다.

그래프 선택 기준 수치형 X + 수치형 Y → Scatter Plot
Question → X / Y → (X, Y) → Point → Density → Pattern → Insight
가장 중요한 기억

Scatter Plot에서는 점 하나의 위치보다 전체 Point 집합이 만드는 패턴 을 읽습니다. 관계가 보이더라도 그것을 곧바로 원인과 결과로 해석하지 않습니다.

학습 목표

  • Scatter Plot이 두 수치형 변수의 관계를 탐색하는 그래프임을 설명할 수 있다.
  • 한 관측 행의 X와 Y가 하나의 Point가 되는 과정을 설명할 수 있다.
  • plt.scatter(x, y)의 기본 구조를 이해하고 실행할 수 있다.
  • marker, c, label의 역할을 설명할 수 있다.
  • Point가 어디에 많이 모여 있는지 Density를 읽을 수 있다.
  • 양의 방향, 음의 방향, 뚜렷한 방향 없음의 차이를 구분할 수 있다.
  • Cluster가 보일 때 다른 변수와 연결하여 추가 분석할 수 있다.
  • Outlier가 보일 때 곧바로 삭제하지 않고 원본 데이터를 확인할 수 있다.
  • 선형 관계와 비선형 관계를 구분할 수 있다.
  • Correlation과 Causation을 구분할 수 있다.
  • 숫자로 저장된 ID와 분석 가능한 수치형 변수를 구분할 수 있다.
  • Pandas DataFrame의 두 수치형 열을 Scatter Plot과 연결할 수 있다.
  • 앞 단원의 Subplot 안에 Scatter Plot을 배치할 수 있다.
  • 출력된 Scatter에서 관찰·해석·다음 질문을 구분하여 기록할 수 있다.

01 · Core Concept

핵심 개념 — 두 수치형 변수의 관계를 Point 분포로 본다

Scatter Plot의 핵심은 X가 얼마나 크고 Y가 얼마나 큰지를 각각 따로 보는 것이 아니라, 두 값이 만나는 위치들을 한꺼번에 보는 것 입니다.

07 · Interview

면접 포인트

Q1. Scatter Plot이란 무엇입니까?

두 연속형 또는 수치형 변수의 값을 X와 Y 좌표에 배치하고 각 관측값을 하나의 Point로 표현하여 두 변수의 관계를 탐색하는 그래프입니다.

Q2. 언제 Scatter Plot을 사용합니까?

두 수치형 변수 사이에 어떤 관계나 패턴이 있는지 확인하고 싶을 때 사용합니다.

Q3. Point 하나는 무엇을 의미합니까?

일반적인 2차원 Scatter에서는 한 관측값의 X와 Y가 만난 하나의 좌표를 의미합니다.

Q4. scatter(x, y)의 X와 Y는 무엇입니까?

X는 첫 번째 수치형 변수이고 Y는 두 번째 수치형 변수입니다.

Q5. marker는 무엇입니까?

Scatter Plot에서 각 Point를 화면에 어떤 모양으로 표시할지 지정합니다.

Q6. c는 무엇입니까?

Scatter Point의 색상을 지정하는 인수입니다.

Q7. Scatter에서 가장 먼저 무엇을 봅니까?

교안 기준으로는 데이터가 어느 영역에 밀집되어 있는지 확인하는 것이 핵심입니다. 실제 분석에서는 방향, 군집, 이상치와 관계 형태도 함께 살펴볼 수 있습니다.

Q8. Line Plot과 Scatter Plot의 차이는?

Line Plot은 시간이나 순서에 따른 변화 흐름을 강조하고 Scatter Plot은 두 수치형 변수의 좌표 관계와 분포를 강조합니다.

Q9. 양의 방향이란 무엇입니까?

X값이 큰 관측값에서 Y값도 큰 경향이 나타나 Point가 대체로 왼쪽 아래에서 오른쪽 위로 배치되는 모습입니다.

Q10. 음의 방향이란 무엇입니까?

X가 큰 관측값에서 Y가 작아지는 경향으로 Point가 대체로 왼쪽 위에서 오른쪽 아래로 배치되는 모습입니다.

Q11. Cluster란 무엇입니까?

Point가 특정 영역별로 여러 무리를 이루는 패턴입니다. 다른 범주형 변수가 이 차이를 설명하는지 추가로 확인할 수 있습니다.

Q12. Outlier를 발견하면 바로 삭제합니까?

아닙니다. 원본 Row를 확인하여 입력·단위·수집 오류인지, 실제 특수 사례인지 판단한 뒤 처리합니다.

Q13. 양의 관계가 보이면 인과관계입니까?

아닙니다. 두 변수가 함께 변하는 패턴은 관찰할 수 있지만 원인과 결과를 확정하려면 다른 변수와 추가 검증이 필요합니다.

Q14. 직선 패턴이 없으면 관계가 없습니까?

반드시 그렇지는 않습니다. 뚜렷한 선형 관계가 없더라도 곡선 등 비선형 관계가 있을 수 있습니다.

Q15. 숫자형 ID도 Scatter에 사용하면 됩니까?

dtype가 숫자라는 이유만으로 적합하지는 않습니다. 고객번호처럼 값의 크기 자체에 분석 의미가 없는 식별자는 수치형 관계 분석에 부적합할 수 있습니다.

Q16. Point가 너무 많이 겹치면 어떻게 할 수 있습니까?

학습 보완 관점에서는 Marker 크기를 줄이거나 alpha를 적용하여 중첩 영역을 더 쉽게 확인할 수 있습니다.

오늘의 암기 포인트

  • 수치형 + 수치형 → Scatter
  • Scatter는 두 변수의 관계를 Point 분포로 탐색한다.
  • 일반적인 2차원 Scatter에서는 한 Row의 X와 Y가 Point 하나를 만든다.
  • scatter(x, y)로 기본 산점도를 그린다.
  • marker는 Point 모양이다.
  • c는 Point 색상이다.
  • label은 그룹 이름이다.
  • 교안의 핵심은 어디에 밀집되어 있는지 확인하는 것이다.
  • Direction은 Point의 전체적인 방향을 본다.
  • Cluster는 Point가 여러 무리로 나뉘는지 본다.
  • Outlier 발견은 삭제가 아니라 원본 확인의 시작이다.
  • 직선 패턴이 없다고 관계가 없다고 단정하지 않는다.
  • Correlation ≠ Causation
  • 숫자 dtype와 분석 가능한 수치 변수는 같은 개념이 아니다.
  • Point 하나보다 Point 전체가 만드는 Pattern 을 읽는다.

헷갈리기 쉬운 개념

Line vs Scatter

시간 변화 vs 두 수치 변수 관계

X vs Y

첫 번째 수치 변수 vs 두 번째 수치 변수

Row vs Point

원본 관측행 vs 그래프의 좌표 표현

Marker vs Data

Point의 모양 vs 실제 X·Y 값

c vs label

Point 색상 vs 그룹 이름

Density vs Direction

어디에 모이는가 vs 어느 방향으로 분포하는가

Cluster vs Outlier

여러 Point의 무리 vs 무리에서 떨어진 Point

Correlation vs Causation

함께 변하는 패턴 vs 원인과 결과

Numerical dtype vs 의미 있는 수치

숫자 저장 형식과 분석 의미는 별도 확인

Point Count vs Row Count

Point가 겹치면 화면상 개수와 실제 행 수가 다를 수 있음
