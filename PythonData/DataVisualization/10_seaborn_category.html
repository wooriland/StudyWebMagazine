Data Visualization · Lesson 10

범주형 데이터 시각화 Barplot · Boxplot · Pointplot · Lineplot · Lmplot · Catplot · Hue

이번 단원에서는 범주형 변수(Category)와 수치형 변수(Numerical Value)를 함께 비교합니다. 같은 데이터라도 평균 같은 대표값을 비교할 것인지, Median·IQR·Outlier를 포함한 전체 분포를 볼 것인지, Category별 대표값 변화 Pattern을 볼 것인지, 시간에 따른 변화를 볼 것인지에 따라 적합한 Seaborn 함수가 달라집니다.

그래프 선택 기준 Category + Numerical → 질문에 따라 Plot 선택
Category + Numerical → Question → Plot Choice → Comparison → Insight
가장 중요한 기억

Barplot은 대표값, Boxplot은 분포, Pointplot은 대표값 Pattern, Lineplot은 시간·순서 변화, Lmplot은 수치-수치 선형 관계, Catplot은 범주형 Plot의 Facet 확장에 초점이 있습니다. 그리고 hue는 단순한 색상 꾸미기가 아니라 데이터를 추가 Category로 나누는 역할입니다.

대표값? Barplot
분포·Outlier? Boxplot
대표값 Pattern? Pointplot
시간 변화? Lineplot
선형 관계? Lmplot
여러 Facet? Catplot

  • 범주형 변수와 수치형 변수가 서로 어떤 역할을 가지는지 설명할 수 있다.
  • 범주별 대표값을 비교할 때 barplot()을 선택할 수 있다.
  • Seaborn Barplot의 막대 높이가 Raw Row 하나가 아니라 범주별 대표 통계량이라는 것을 이해한다.
  • Matplotlib bar()와 Seaborn barplot()의 데이터 처리 차이를 설명할 수 있다.
  • estimator가 여러 관측값을 하나의 대표값으로 요약하는 역할임을 이해한다.
  • Error Bar와 Bar Height의 역할을 구분할 수 있다.
  • 교안의 ci와 현재 API의 errorbar를 구분할 수 있다.
  • Confidence Interval과 Standard Deviation의 의미를 혼동하지 않는다.
  • Boxplot의 Q1·Median·Q3·IQR·Whisker·Outlier를 설명할 수 있다.
  • IQR을 Q3 - Q1로 설명할 수 있다.
  • Whisker가 항상 전체 데이터의 Min·Max는 아님을 설명할 수 있다.
  • Outlier를 발견했다고 즉시 삭제하지 않아야 하는 이유를 설명할 수 있다.
  • Barplot과 Boxplot의 분석 목적 차이를 설명할 수 있다.
  • Mean과 Median의 차이를 설명할 수 있다.
  • hue가 추가 Category를 의미한다는 것을 이해한다.
  • Pointplot Point와 Scatterplot Point의 의미 차이를 설명할 수 있다.
  • 시간 또는 순서에 따라 값을 비교할 때 lineplot()을 사용할 수 있다.
  • 시간 + 범주 질문에서 lineplot()과 hue를 함께 사용할 수 있다.
  • lmplot()이 시간 Line Plot이 아니라 Linear Model Plot임을 이해한다.
  • catplot()이 단일 그래프 유형이 아니라 여러 Categorical Plot을 FacetGrid로 확장하는 Interface임을 설명할 수 있다.
  • Axes-Level과 Figure-Level 함수의 차이를 이해한다.
  • 실무 데이터에서 Category Label, Null, Sample Size를 확인한 뒤 그래프를 해석할 수 있다.

estimator

CI와 SD는 같은 개념이 아니다

Confidence Interval은 추정값의 불확실성과, Standard Deviation은 관측값의 퍼짐과 관련됩니다. Error Bar를 읽을 때 어떤 방법을 사용했는지 확인해야 합니다.

lmplot() — Numerical X/Y Regression + Category

Numerical X + Numerical Y + Category → Group별 Regression
lmplot()은 시간 Line Plot이 아니다

lm = linear model입니다. 시간 변화는 Lineplot, 수치형 X·Y의 선형 관계는 Lmplot으로 구분합니다. Regression Line이 존재한다고 인과관계가 자동으로 증명되는 것도 아닙니다.

01 · Barplot을 Raw Bar로 생각

막대는 기본적으로 범주별 대표 통계량입니다.

02 · Mean과 Median 혼동

통계적 유의성을 그래프만으로 확정하지 않습니다.

07 · Box 높이 = 전체 Range

08 · Outlier 즉시 삭제

원본 Row와 데이터 의미를 먼저 확인합니다.

09 · 평균이 같으면 분포도 같다고 판단

10 · Pointplot Point = Raw Row

Pointplot Point는 대표 통계량입니다.

11 · Scatter Point와 Pointplot Point 혼동

Raw Observation과 Estimate를 구분합니다.

12 · Lineplot을 항상 Raw Point 연결로 생각

14 · hue를 단순 색상 옵션으로 이해

15 · Group Sample Size 무시

17 · lmplot을 시간 Line Plot으로 이해

07 · Interview

면접 포인트

Q1. Seaborn barplot은 무엇을 보여줍니까?

Category별 Numerical Value의 대표 통계량을 막대 높이로 표현합니다. 기본적으로 평균을 사용하며 Error Bar로 추가 통계 정보를 표현할 수 있습니다.

Q2. Matplotlib bar와 Seaborn barplot의 차이는?

Matplotlib bar는 준비된 값을 직접 막대로 표현하는 경우가 많고, Seaborn barplot은 Raw Data를 Category별로 묶어 대표 통계량을 계산할 수 있습니다.

Q3. estimator란 무엇입니까?

Category 안의 여러 Numerical Observation을 하나의 대표값으로 요약하기 위한 함수입니다. 현재 Barplot의 기본값은 Mean입니다.

Q4. Error Bar는 항상 Standard Deviation입니까?

아닙니다. 설정에 따라 CI, PI, SE, SD 등 서로 다른 의미를 가질 수 있습니다.

Q5. 교안의 ci와 현재 API 차이는?

교안에서는 ci="sd"와 ci=None을 사용하지만, 현재 API에서는 errorbar="sd"와 errorbar=None을 사용합니다.

Q6. Boxplot은 무엇을 보여줍니까?

Numerical Distribution을 Q1, Median, Q3, IQR, Whisker, Outlier로 요약해서 Category별로 비교합니다.

Q7. IQR이란 무엇입니까?

Q3에서 Q1을 뺀 값이며 데이터의 중간 50% 범위를 나타냅니다.

Q8. Boxplot 가운데 선은 평균입니까?

아닙니다. Median, 즉 Q2입니다.

Q9. Whisker는 항상 Min과 Max입니까?

아닙니다. 1.5×IQR Fence 범위 안에서 실제 가장 바깥 관측값까지 이어지므로 Outlier가 있다면 전체 Min·Max와 다를 수 있습니다.

Q10. Outlier는 바로 삭제합니까?

아닙니다. 입력 오류인지 실제 희귀 사례인지 원본 Row를 확인한 뒤 처리해야 합니다.

Q11. hue는 어떤 역할을 합니까?

추가 범주형 변수 기준으로 Data를 Subgroup으로 나누어 같은 Plot 안에서 구분해서 보여줍니다.

Q12. Scatter Point와 Pointplot Point의 차이는?

Scatter Point는 Raw Observation 하나이며, Pointplot Point는 Category별 대표 통계량입니다.

Q13. Pointplot은 언제 유용합니까?

Category별 대표값과 Group별 변화 Pattern을 Point 위치와 연결선의 기울기로 비교할 때 유용합니다.

Q14. Lineplot은 언제 사용합니까?

시간 또는 순서가 있는 X에 따라 Numerical Value가 어떻게 변하는지 볼 때 사용하며, hue로 Category별 Line을 나눌 수 있습니다.

Q15. Pointplot과 Lineplot의 차이는?

Pointplot은 Categorical Level의 대표값 비교, Lineplot은 시간·순서에 따른 수치 변화에 더 적합합니다.

Q16. Lmplot은 무엇입니까?

Numerical X와 Y의 Regression Relationship을 Scatter와 회귀선으로 나타내고, hue·col·row를 이용하여 그룹별로 비교하는 Figure-Level 함수입니다.

Q17. Catplot은 무엇입니까?

여러 Categorical Plot을 선택하고 FacetGrid 형태로 확장할 수 있는 Figure-Level Interface입니다.

Q18. Catplot과 Boxplot의 차이는?

Boxplot은 하나의 Axes에 분포를 그리는 함수이고, Catplot의 kind="box"는 Boxplot 계열을 여러 Facet으로 확장할 수 있습니다.

Q19. 평균이 같으면 Distribution도 같습니까?

아닙니다. Median, IQR, Spread, Outlier 등이 전혀 다를 수 있습니다.

Q20. 범주형 데이터 분석의 안전한 순서는?

Category Label과 Sample Size를 확인하고, Barplot으로 대표값을 본 뒤 Boxplot으로 분포를 확인합니다. 이후 hue, Pointplot, Lineplot, Catplot 등으로 질문을 확장하는 흐름이 좋습니다.

오늘의 암기 포인트

  • Category + Numerical → Categorical Visualization
  • 대표값 비교는 barplot().
  • Barplot의 기본 막대 높이는 Category별 Mean이다.
  • 교안의 ci는 현재 API에서 errorbar로 연결한다.
  • Distribution과 Outlier는 boxplot().
  • Q2는 Median이다.
  • IQR = Q3 - Q1.
  • Box는 Q1~Q3, 즉 중앙 50%다.
  • Whisker는 1.5×IQR Fence 안의 실제 끝 Observation까지다.
  • Outlier는 자동 삭제 대상이 아니다.
  • hue는 추가 Category다.
  • Pointplot Point는 Raw Row가 아니라 Category별 Estimate다.
  • 시간 + Category는 lineplot() + hue.
  • lmplot()의 lm은 Linear Model이다.
  • catplot()은 Categorical Plot + FacetGrid다.
  • Axes-Level과 Figure-Level을 구분한다.
