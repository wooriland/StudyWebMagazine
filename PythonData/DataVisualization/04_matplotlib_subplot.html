Data Visualization · Lesson 04

여러 그래프와 Subplot Figure · Axes · add_subplot · Rows · Columns · Position

Subplot은 하나의 Figure 안에 여러 Axes를 배치하여 여러 그래프를 한 화면에서 비교할 수 있도록 만드는 Matplotlib의 핵심 구성 방식입니다. 이번 단원에서는 figure(), add_subplot(행, 열, 위치), 행·열·위치 번호의 의미, 각 Axes에 Plot을 추가하는 방법, set_title(), set_xlabel(), set_ylabel()까지 연결합니다.

Figure → Rows × Columns → add_subplot() → Axes → Plot → Title / Label → Compare
핵심 문법 fig.add_subplot(rows, cols, position)
가장 중요한 기억

Subplot은 새로운 그래프 종류가 아닙니다. Line, Scatter, Bar 같은 Plot을 Figure 안의 여러 Axes에 배치하는 구조 입니다.

학습 목표

  • Figure와 여러 Axes의 관계를 설명할 수 있다.
  • Subplot이 그래프 종류가 아니라 그래프 영역을 구성하는 방식임을 설명할 수 있다.
  • plt.figure()의 역할을 설명할 수 있다.
  • fig.add_subplot(rows, cols, position)의 세 인수를 각각 설명할 수 있다.
  • 1×2, 2×1, 2×2, 2×3 배치의 위치 번호를 읽을 수 있다.
  • add_subplot(2, 2, 1)의 위치 번호가 1부터 시작한다는 것을 이해한다.
  • Axes 생성과 Plot 생성이 서로 다른 단계임을 설명할 수 있다.
  • 각 Axes에 plot()을 적용할 수 있다.
  • 각 Axes에 set_title(), set_xlabel(), set_ylabel()을 적용할 수 있다.
  • 여러 Axes의 Y축 단위와 축 범위를 독립적으로 읽을 수 있다.
  • NumPy arange()로 만든 공통 X값을 여러 Axes에 사용할 수 있다.
  • 교안의 add_subplot() 방식과 학습 보완인 plt.subplots() 방식을 구분할 수 있다.
  • 여러 그래프를 하나의 분석 화면으로 구성하고 공통점·차이점을 비교할 수 있다.

05 · Error Reading

오류 메시지 읽는 법

Subplot 오류를 만났을 때는 Figure → Axes → Position → Plot → Data 중 어느 단계에서 문제가 발생했는지 먼저 분류합니다.

Syntax → Figure → Axes → Position → Plot → Data

ModuleNotFoundError 

ModuleNotFoundError:
No module named 'matplotlib'

현재 Python 환경에 Matplotlib이 설치되어 있는지 확인합니다. 

pip install matplotlib

    2,
    2,
    5
)

2×2에는 총 4개의 위치만 존재합니다.

2 × 2 = 4 position ≤ 4

    2

오류가 아닐 수 있습니다. Axes만 생성하고 Plot을 추가하지 않았다면 빈 그래프 영역이 정상적으로 나타납니다. 

ax2 = fig.add_subplot(
    2,
    2,
    2
)

# ax2.plot() 없음

07 · Interview

면접 포인트

Q1. Matplotlib의 Subplot이란 무엇입니까?

하나의 Figure 안에 여러 Axes를 배치하여 여러 그래프를 한 화면에서 구성하고 비교할 수 있도록 하는 구조입니다.

Q2. Figure와 Axes의 차이는 무엇입니까?

Figure는 전체 그래프 화면이고, Axes는 그 안에서 실제 Plot이 그려지는 개별 그래프 영역입니다. 하나의 Figure에는 여러 Axes가 들어갈 수 있습니다.

Q3. add_subplot()의 기본 형식은 무엇입니까?

fig.add_subplot(rows, cols, position) 형태이며 행, 열, 위치 순서로 그래프 영역을 지정합니다.

Q4. add_subplot(2, 2, 1)은 무엇을 의미합니까?

Figure를 2행 2열 구조로 보고 첫 번째 위치에 Axes를 하나 만든다는 의미입니다.

Q5. 2×2 Subplot의 위치 순서는 어떻게 됩니까?

왼쪽 위부터 1, 2, 3, 4 순서입니다.

Q6. add_subplot()이 Plot까지 생성합니까?

아닙니다. add_subplot()은 Axes를 생성하고 실제 Plot은 이후 ax.plot(), ax.scatter() 등의 메서드로 추가합니다.

Q7. 각 Subplot의 제목은 어떻게 설정합니까?

특정 Axes 객체에 set_title()을 호출합니다. 예를 들어 ax1.set_title("Sales")처럼 작성합니다.

Q8. set_xlabel()과 set_ylabel()의 역할은?

특정 Axes의 X축과 Y축에 어떤 데이터가 표현되고 있는지 설명하는 레이블을 설정합니다.

Q9. figsize는 무엇을 변경합니까?

데이터 자체가 아니라 Figure 전체의 가로·세로 표시 크기를 변경합니다.

Q10. 여러 Subplot을 비교할 때 주의할 것은?

각 Axes의 제목, Y축 단위, Tick, Axis Range를 함께 확인해야 합니다. 그래프 모양이 비슷하더라도 값의 규모는 다를 수 있습니다.

Q11. Subplot은 그래프 종류입니까?

아닙니다. Line, Scatter, Bar 같은 Plot을 Figure 안의 여러 Axes에 배치하기 위한 레이아웃 구조입니다.

Q12. NumPy arange()는 Subplot 실습에서 어떻게 사용할 수 있습니까?

공통 X좌표 배열을 생성한 뒤, 서로 다른 Y값을 만들어 여러 Axes에서 동일한 X 기준으로 그래프를 비교할 수 있습니다.

Q13. add_subplot()과 plt.subplots()의 차이를 어떻게 공부하면 됩니까?

첨부 교안에서는 figure()와 add_subplot()이 중심입니다. plt.subplots()는 실제 코드에서 자주 보이는 보완 방식으로, Figure와 여러 Axes를 한 번에 만드는 형태로 이해하면 됩니다.

Q14. Subplot의 실무적인 장점은 무엇입니까?

여러 분석 결과를 가까이 배치하여 공통점과 차이를 빠르게 비교하고, 하나의 Figure를 작은 분석 리포트나 대시보드처럼 구성할 수 있다는 점입니다.

오늘의 암기 포인트

  • Figure = 전체 그래프 화면
  • Axes = Figure 안의 개별 그래프 영역
  • Figure 하나에 Axes 여러 개를 둘 수 있다.
  • Subplot은 Plot 종류가 아니라 Axes 배치 구조다.
  • fig.add_subplot(rows, cols, position) 을 사용한다.
  • add_subplot(2,2,1) 은 2행 2열의 첫 번째 위치다.
  • 위치 번호는 1부터 시작한다.
  • 2×2 위치는 1 → 2 → 3 → 4 순서다.
  • Axes 생성과 Plot 생성은 다른 단계다.
  • ax.plot()은 해당 Axes에 Plot을 추가한다.
  • ax.set_title()은 해당 Axes의 제목을 설정한다.
  • set_xlabel(), set_ylabel()은 해당 Axes의 축 의미를 설정한다.
  • figsize는 Figure 전체의 크기다.
  • 여러 그래프의 Y축 단위와 범위를 반드시 확인한다.
  • Subplot의 목적은 여러 분석 결과를 비교하기 쉽게 만드는 것 이다.
