Data Analysis · Lesson 13 · Pandas String & Sorting

Pandas 문자열 처리와 정렬

실제 데이터에는 이름·주소·지역·상품명·URL·이메일처럼 문자열 데이터가 매우 많이 포함됩니다. 그러나 같은 의미의 문자열도 앞뒤 공백이나 대소문자, 표현 형식이 다르면 서로 다른 값으로 분석될 수 있습니다. 이번 단원에서는 Series의 .str을 이용해 문자열을 정규화·검색·치환·분리하고, sort_index()와 sort_values()로 Label과 실제 값을 원하는 순서로 정렬하는 방법 을 공부합니다.

.str strip lower upper len contains startswith endswith replace split sort_index sort_values ascending na_position

학습 목표

  • 문자열 정규화가 왜 필요한지 설명할 수 있다.
  • 같은 의미의 문자열이라도 공백·대소문자가 다르면 다른 값으로 처리될 수 있음을 이해한다.
  • Pandas 문자열 Series에서 .str accessor를 사용할 수 있다.
  • .str.strip()을 이용해 문자열 앞뒤 공백을 제거할 수 있다.
  • lower(), upper(), title()을 이용해 문자열 표현 규칙을 통일할 수 있다.
  • Method Chaining을 이용해 여러 문자열 정제 단계를 연결할 수 있다.
  • .str.len()으로 문자열 길이를 계산할 수 있다.
  • .str.contains()으로 문자열 포함 여부를 Boolean Mask로 만들 수 있다.
  • case, na, regex 옵션의 의미를 이해한다.
  • startswith()와 endswith()으로 문자열의 시작·끝 조건을 검사할 수 있다.
  • .str.replace()로 문자열 내부 패턴을 치환할 수 있다.
  • 문자열 형태의 숫자를 정제한 뒤 실제 Numeric dtype으로 변환할 수 있다.
  • .str.split()과 expand=True의 결과 구조 차이를 이해한다.
  • sort_index()와 sort_values()의 기준 차이를 설명할 수 있다.
  • sort_index(axis=0)과 axis=1을 구분할 수 있다.
  • 단일 Column 및 여러 Column 기준으로 DataFrame을 정렬할 수 있다.
  • 여러 정렬 기준마다 서로 다른 ascending 방향을 지정할 수 있다.
  • na_position, ignore_index, key의 사용 목적을 이해한다.
  • 문자열 처리·정렬 전후의 shape, axis, dtype, Missing, Index 변화를 확인할 수 있다.

01 · Core Concept

문자열을 같은 규칙으로 정리한 뒤 순서를 제어한다

사람이 보기에는 같은 값이라도 컴퓨터는 공백과 대소문자가 다르면 서로 다른 문자열로 판단할 수 있습니다. 따라서 문자열 분석은 정규화 → 검사 → 변환 → 정렬 순서로 생각하면 이해하기 쉽습니다.

16 · Multi-key Sorting

첫 번째 기준이 같을 때 두 번째 기준을 사용한다 

result = df.sort_values(
    by=[
        "city",
        "score"
    ],
    ascending=[
        True,
        False
    ]
)
PRIORITY 1 city ASC
→
SAME CITY score DESC
city score
busan 95
busan 70
seoul 90
seoul 80
여러 번 전체 정렬하는 개념이 아니다

첫 번째 기준으로 그룹화된 순서를 만든 뒤, 그 값이 동일한 Row들 안에서 다음 기준을 적용한다고 이해합니다.

19 · key Sorting

원본 값을 바꾸지 않고 정렬용 기준만 변환한다 

result = df.sort_values(
    by="name",
    key=lambda column: column.str.lower()
)
ORIGINAL Apple banana Cherry
→
TEMP SORT KEY apple banana cherry
→
RESULT 원본 문자열 유지 순서만 결정
key는 데이터 정제 함수가 아니다

key는 정렬을 위한 임시 값을 만들 뿐, 원본 Column 값을 직접 소문자로 변경하지 않습니다.

import numpy as np
import pandas as pd


def show_state(name, obj):
    print()
    print("=" * 70)
    print(name)
    print("=" * 70)

    print(obj)

    print()
    print("type:", type(obj))
    print("shape:", obj.shape)

    if isinstance(obj, pd.DataFrame):
        print("index:", obj.index)
        print("columns:", obj.columns)

        print("dtypes:")
        print(obj.dtypes)

        print("missing:")
        print(obj.isna().sum())

    elif isinstance(obj, pd.Series):
        print("index:", obj.index)
        print("dtype:", obj.dtype)
        print("missing:", obj.isna().sum())

23 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

Series에 lower()를 직접 사용한다

Pandas 문자열 Series에서는 .str.lower()를 사용합니다.

Mistake 02

DataFrame 전체에 .str을 사용한다

일반적으로 문자열 Series나 Index를 대상으로 사용합니다.

Mistake 03

앞뒤 공백을 무시한다

눈에 보이지 않는 공백도 문자열 비교에 영향을 줍니다.

Mistake 04

대소문자가 다른 값을 같은 문자열이라고 생각한다

필요한 경우 lower 또는 upper로 정규화합니다.

Mistake 05

contains를 항상 단순 문자열 검색이라고 생각한다

Regex와 literal 검색을 구분합니다.

Mistake 06

Boolean 문자열 검색에서 Missing을 생각하지 않는다

필요하면 na=False를 명시합니다.

Mistake 07

str.replace와 Series.replace를 같은 기능으로 생각한다

문자열 내부와 값 자체의 치환을 구분합니다.

Mistake 08

"10000"을 숫자 10000이라고 생각한다

문자열 정제 후 실제 Numeric dtype 변환이 필요할 수 있습니다.

Mistake 09

split은 항상 DataFrame이라고 생각한다

기본과 expand=True의 결과 구조가 다릅니다.

Mistake 10

문자열 dtype은 항상 object라고 외운다

현재 환경의 실제 dtype을 확인합니다.

Mistake 11

교안의 sort_value()를 그대로 사용한다

현재 값 기준 정렬은 sort_values()입니다.

Mistake 12

sort_index와 sort_values를 같은 것으로 생각한다

하나는 Label, 다른 하나는 Value 기준입니다.

Mistake 13

sort_index(axis=1)을 Row 정렬이라고 생각한다

axis=1은 Column Label 방향입니다.

Mistake 14

Multi-key 정렬을 여러 번의 독립 정렬로 생각한다

1차 기준이 같은 범위 안에서 다음 기준을 적용합니다.

Mistake 15

ascending List와 by 순서를 연결하지 않는다

두 List의 같은 위치끼리 정렬 기준과 방향이 대응됩니다.

Mistake 16

정렬하면 Index가 자동으로 재설정된다고 생각한다

기본적으로 기존 Index Label이 Row와 함께 이동합니다.

Mistake 17

정렬하면 원본이 항상 바뀐다고 생각한다

결과를 새로운 변수에 받아 비교하는 습관을 둡니다.

Mistake 18

NaN의 정렬 위치를 확인하지 않는다

na_position을 확인합니다.

Mistake 19

문자열 정렬에서 대소문자를 고려하지 않는다

필요하면 key를 이용해 정렬 기준을 변환합니다.

Mistake 20

key가 원본 데이터를 변경한다고 생각한다

정렬용 임시 기준을 만들 뿐입니다.

Mistake 21

정렬 후 shape를 확인하지 않는다

일반적인 정렬은 데이터 수를 바꾸지 않습니다.

Mistake 22

정규화 결과를 확인하지 않고 바로 Merge한다

Join Key가 실제로 같은 형태인지 먼저 검증합니다.

26 · Interview

면접 포인트

Q1. Pandas에서 문자열 Series를 처리하는 기본 방법은?
A. Series 또는 Index의 .str accessor를 이용해 문자열 메서드를 적용합니다.
Q2. 문자열 앞뒤 공백을 제거하려면?
A. series.str.strip()을 사용합니다.
Q3. 문자열 대소문자를 통일하려면?
A. str.lower(), str.upper() 등을 사용할 수 있습니다.
Q4. 문자열 정규화가 중요한 이유는?
A. 공백·대소문자가 다른 동일 의미의 값이 GroupBy나 Merge에서 서로 다른 Key로 처리되는 문제를 줄일 수 있기 때문입니다.
Q5. str.contains()는 무엇인가요?
A. 각 문자열에 특정 패턴이 포함되는지 검사하고 Boolean 결과를 만들어 Boolean Indexing과 연결할 수 있습니다.
Q6. contains()에서 na=False를 사용하는 이유는?
A. 문자열이 Missing인 위치를 Boolean False로 취급하겠다는 정책을 명시적으로 표현할 수 있습니다.
Q7. contains()의 regex 옵션은 왜 중요한가요?
A. 정규표현식 패턴 검색과 문자 그대로의 Literal 검색을 구분하기 때문입니다.
Q8. startswith()과 endswith()은 언제 사용하나요?
A. 접두사·접미사나 파일 확장자처럼 문자열의 시작·끝 조건을 검사할 때 사용합니다.
Q9. str.replace와 Series.replace 차이는?
A. str.replace는 문자열 내부 패턴을, Series.replace는 값 자체의 대응을 변경하는 관점으로 구분할 수 있습니다.
Q10. str.split()은 무엇인가요?
A. 하나의 문자열을 delimiter 기준으로 나눕니다.
Q11. split(expand=True)는 무엇이 다른가요?
A. 분리 결과를 여러 Column으로 확장할 수 있어 Series가 DataFrame으로 바뀌고 shape도 달라질 수 있습니다.
Q12. sort_index()란?
A. Index 또는 Column Label을 기준으로 정렬합니다.
Q13. sort_values()란?
A. 지정한 Column 등의 실제 데이터 Value를 기준으로 정렬합니다.
Q14. 교안의 sort_value()는 현재 어떻게 공부하나요?
A. 현재 정확한 API인 sort_values()로 연결합니다.
Q15. sort_index(axis=0)과 axis=1 차이는?
A. axis=0은 Row Index, axis=1은 Column Label을 정렬합니다.
Q16. 여러 Column을 기준으로 정렬하려면?
A. by=["city", "score"]처럼 정렬 우선순위 순서대로 전달합니다.
Q17. 기준마다 ASC/DESC를 다르게 할 수 있나요?
A. ascending=[True, False]처럼 각 기준과 대응시킬 수 있습니다.
Q18. NaN은 정렬에서 어디로 가나요?
A. 기본적으로 뒤쪽에 둘 수 있고, na_position="first"로 앞쪽에 배치할 수도 있습니다.
Q19. 정렬하면 Index가 자동으로 다시 번호 매겨지나요?
A. 기본적으로 기존 Index가 Row와 함께 이동합니다. 새 순번이 필요하면 ignore_index=True를 사용할 수 있습니다.
Q20. key 정렬은 무엇인가요?
A. 원본 값을 직접 수정하지 않고 정렬 기준으로 사용할 임시 변환값을 만들어 정렬하는 기능입니다.
Q21. 문자열 dtype은 항상 object인가요?
A. 현재 Pandas에서는 문자열 dtype 동작이 달라질 수 있으므로 object라고 고정해서 외우기보다 실제 dtype을 확인하는 것이 좋습니다.
Q22. 문자열 정규화와 Merge는 왜 연결되나요?
A. Join Key의 공백·대소문자·형식 차이를 줄여 같은 의미의 값이 같은 Key로 비교되도록 준비하기 위해서입니다.

오늘의 암기 포인트

  • Pandas 문자열 처리 = .str
  • strip()은 앞뒤 공백 제거다.
  • lstrip()은 왼쪽, rstrip()은 오른쪽이다.
  • lower()은 소문자, upper()은 대문자다.
  • 중요한 것은 대소문자 선택 자체보다 하나의 규칙으로 통일하는 것이다.
  • Method Chaining으로 여러 정제 과정을 연결할 수 있다.
  • len()은 문자열 길이를 숫자로 반환한다.
  • contains() → Boolean Mask
  • 문자열 Boolean 검색에서는 Missing 처리 정책을 확인한다.
  • Regex 검색과 Literal 검색을 구분한다.
  • startswith()은 시작, endswith()은 끝 검사다.
  • str.replace()는 문자열 내부 가공이다.
  • 문자열이 숫자처럼 보여도 실제 dtype은 문자열일 수 있다.
  • split()은 문자열 분리다.
  • split(expand=True)는 DataFrame으로 확장될 수 있다.
  • sort_index() = Label 기준
  • sort_values() = Value 기준
  • 교안의 sort_value()는 현재 sort_values()로 연결한다.
  • axis=0은 Row Index, axis=1은 Columns다.
  • ascending=True는 오름차순, False는 내림차순이다.
  • Multi-key Sorting에서는 by 순서가 우선순위다.
  • ascending List는 각 정렬 기준과 순서대로 대응한다.
  • Missing의 정렬 위치도 결정할 수 있다.
  • 정렬해도 Row의 Label과 Values는 함께 움직인다.
  • 새 번호가 필요할 때만 ignore_index=True를 고려한다.
  • 문자열 dtype을 무조건 object라고 외우지 않는다.
