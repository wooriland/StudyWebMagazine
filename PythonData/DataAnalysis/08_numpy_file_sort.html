Data Analysis · Lesson 08 · NumPy File I/O & Array Utility

NumPy 배열 파일 입출력과 정리

지금까지의 NumPy 학습은 대부분 메모리 안에 존재하는 ndarray를 대상으로 했습니다. 이번 단원에서는 완성한 배열을 텍스트 또는 NumPy 전용 바이너리 파일로 저장하고, 다음 실행에서 다시 ndarray로 복원합니다. 이후 copy()로 원본을 보존하고, sort()로 순서를 정리하고, unique()로 고유값과 빈도를 파악하며, astype()으로 dtype을 분석 목적에 맞게 통일합니다.

loadtxt savetxt save savez load copy sort unique astype dtype

학습 목표

  • 메모리 안의 ndarray를 파일에 저장해야 하는 이유를 설명할 수 있다.
  • Text 파일과 NumPy Binary 파일의 목적 차이를 구분할 수 있다.
  • np.savetxt()와 np.loadtxt()를 이용해 숫자 텍스트 파일을 저장·복원할 수 있다.
  • fmt, delimiter, skiprows, usecols의 역할을 이해한다.
  • np.save()와 np.load()를 이용해 단일 ndarray를 .npy로 저장·복원할 수 있다.
  • np.savez()를 이용해 여러 ndarray를 하나의 .npz 파일에 이름을 붙여 저장할 수 있다.
  • .npy와 .npz의 사용 목적 차이를 설명할 수 있다.
  • 단순 대입과 copy()의 차이를 설명할 수 있다.
  • np.sort()와 arr.sort()의 차이를 이해한다.
  • axis=-1, axis=0, axis=None의 정렬 차이를 설명할 수 있다.
  • np.unique()로 고유값과 빈도를 구할 수 있다.
  • astype()으로 dtype을 변경하고 값 손실 가능성을 점검할 수 있다.
  • 파일 입출력과 배열 정리 전후의 shape, axis, dtype, NaN 상태를 비교할 수 있다.

01 · Core Concept

메모리의 ndarray를 파일로 보존하고 다시 분석한다

Python 변수는 프로그램이 실행되는 동안에는 사용할 수 있지만 프로그램이 종료되면 메모리에서 사라집니다. 분석 결과를 다음 실행에서도 사용하려면 ndarray를 파일로 저장해야 합니다.

NumPy File I/O & Array Utility

13 · Python Example

파일 입출력과 배열 정리 통합 실습 

from pathlib import Path

import numpy as np


def show_state(name, arr):
    print()
    print("=" * 60)
    print(name)
    print("=" * 60)

    print(arr)
    print("type :", type(arr))
    print("ndim :", arr.ndim)
    print("shape:", arr.shape)
    print("size :", arr.size)
    print("dtype:", arr.dtype)


# ==================================================
# 1. 실습 폴더
# ==================================================

DATA_DIR = Path(
    "numpy_io_data"
)

DATA_DIR.mkdir(
    exist_ok=True
)

print(
    "DATA DIR:",
    DATA_DIR.resolve()
)


# ==================================================
# 2. 원본 배열
# ==================================================

scores = np.array([
    [80.0, 90.0, 70.0],
    [75.0, 85.0, 95.0],
    [88.0, 91.0, 79.0]
])

show_state(
    "Original Scores",
    scores
)


# ==================================================
# 3. Text 저장
# ==================================================

csv_path = DATA_DIR / "scores.csv"

np.savetxt(
    csv_path,
    scores,
    delimiter=",",
    fmt="%.1f"
)

print()
print(
    "CSV saved:",
    csv_path
)


# ==================================================
# 4. Text 로드
# ==================================================

loaded_text = np.loadtxt(
    csv_path,
    delimiter=","
)

show_state(
    "Loaded Text",
    loaded_text
)


# ==================================================
# 5. NPY 저장
# ==================================================

npy_path = DATA_DIR / "scores.npy"

np.save(
    npy_path,
    scores
)


# ==================================================
# 6. NPY 로드
# ==================================================

loaded_npy = np.load(
    npy_path
)

show_state(
    "Loaded NPY",
    loaded_npy
)


# ==================================================
# 7. NPZ 저장
# ==================================================

student_ids = np.array([
    101,
    102,
    103
])

npz_path = DATA_DIR / "class_data.npz"

np.savez(
    npz_path,
    scores=scores,
    student_ids=student_ids
)


# ==================================================
# 8. NPZ 로드
# ==================================================

with np.load(
    npz_path
) as data:

    print()
    print(
        "NPZ keys:",
        data.files
    )

    loaded_scores = data["scores"]
    loaded_ids = data["student_ids"]

    show_state(
        "NPZ Scores",
        loaded_scores
    )

    show_state(
        "NPZ Student IDs",
        loaded_ids
    )


# ==================================================
# 9. Copy
# ==================================================

values = np.array([
    30,
    10,
    20,
    10,
    30
])

copied = values.copy()

copied[0] = 999

show_state(
    "Copy Original",
    values
)

show_state(
    "Copied & Modified",
    copied
)


# ==================================================

14 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

파일 저장 위치를 확인하지 않는다

상대 경로는 현재 작업 디렉터리를 기준으로 합니다.

Mistake 02

17 · Interview

면접 포인트

Q1. np.savetxt()는 무엇인가요?
A. NumPy의 1차원 또는 2차원 배열을 텍스트 파일로 저장하는 함수입니다. delimiter와 fmt를 이용해 값의 구분 방식과 출력 표현을 지정할 수 있습니다.
Q2. np.loadtxt()는 무엇인가요?
A. 규칙적인 숫자 Text 파일을 읽어 ndarray로 만드는 함수입니다. delimiter, dtype, skiprows, usecols 등을 사용할 수 있습니다.
Q3. fmt와 dtype의 차이는 무엇인가요?
A. dtype은 ndarray 내부의 실제 자료형이고, fmt는 savetxt가 값을 Text에 어떤 문자열 형태로 기록할지 지정하는 형식입니다.
Q4. loadtxt()와 load()의 차이는?
A. loadtxt는 Text 데이터를 파싱하고, load는 주로 NumPy의 NPY·NPZ 바이너리 파일을 복원할 때 사용합니다.
Q5. .npy는 무엇인가요?
A. 하나의 ndarray를 저장·복원하기 위한 NumPy 바이너리 파일 형식입니다.
Q6. .npz는 무엇인가요?
A. 여러 ndarray를 하나의 archive에 저장할 수 있는 형식입니다. savez에서 keyword 이름을 주면 로드 후 같은 이름으로 접근할 수 있습니다.
Q7. npz를 load하면 ndarray 하나가 나오나요?
A. 아닙니다. 여러 배열에 이름으로 접근할 수 있는 dictionary-like NpzFile을 사용하게 됩니다.
Q8. allow_pickle은 왜 주의해야 하나요?
A. Pickle 기반 object 데이터는 신뢰하지 않는 파일에서 보안 위험이 있을 수 있으므로 일반 수치 배열에서는 안전한 기본 정책을 유지하는 것이 좋습니다.
Q9. 단순 대입과 copy의 차이는?
A. 단순 대입은 같은 ndarray를 참조할 수 있지만 copy는 작업용 복사 배열을 만들어 원본과 분리하는 데 사용할 수 있습니다.
Q10. np.sort와 arr.sort의 차이는?
A. 현재 NumPy에서 np.sort는 정렬된 새 배열을 반환하고, ndarray의 sort 메서드는 원본을 in-place로 정렬합니다.
Q11. NumPy sort의 기본 axis는?
A. -1, 즉 마지막 axis입니다.
Q12. sort(axis=None)은 어떻게 동작하나요?
A. 다차원 배열을 flatten한 뒤 1차원 결과를 정렬합니다.
Q13. np.unique()는 무엇인가요?
A. 입력 배열의 고유값을 구하는 함수이며 기본적인 사용에서는 정렬된 고유값 결과를 얻습니다.
Q14. 고유값 빈도도 구할 수 있나요?
A. return_counts=True를 이용하면 각 고유값이 몇 번 등장했는지를 함께 구할 수 있습니다.
Q15. 2D 배열에 np.unique(arr)를 사용하면?
A. 기본 axis=None에서는 배열 전체를 flatten한 뒤 개별 원소의 고유값을 구합니다.
Q16. astype()는 무엇인가요?
A. ndarray를 원하는 dtype으로 변환한 배열을 만드는 메서드입니다.
Q17. astype하면 shape도 바뀌나요?
A. dtype 변환 자체는 배열의 shape를 바꾸는 작업이 아닙니다.
Q18. 실수에서 정수로 astype할 때 무엇을 확인해야 하나요?
A. 소수 정보 등이 손실될 수 있으므로 변환 결과 값이 분석 목적과 맞는지 확인해야 합니다.
Q19. 파일 Load 직후 무엇을 확인해야 하나요?
A. type, ndim, shape, size, dtype을 확인하고 데이터 분석에서는 NaN 상태도 함께 확인합니다.
Q20. Text와 NPY를 어떻게 선택하나요?
A. 사람이 직접 확인하거나 다른 프로그램과 교환해야 하면 Text, NumPy에서 ndarray를 다시 사용할 목적이면 NPY 같은 전용 형식을 고려할 수 있습니다.

오늘의 암기 포인트

  • savetxt = ndarray → Text
  • loadtxt = Text → ndarray
  • loadtxt의 기본 dtype은 float라는 점을 확인한다.
  • 저장·로드의 delimiter를 서로 맞춘다.
  • dtype과 fmt는 다른 개념이다.
  • save = ndarray 하나 → NPY
  • savez = 여러 ndarray → NPZ
  • load = NPY / NPZ 복원
  • NPZ에서는 배열 이름으로 접근할 수 있다.
  • 신뢰하지 않는 파일의 pickle 로드는 주의한다.
  • 단순 대입과 copy는 다르다.
  • np.sort = 정렬 결과 배열
  • arr.sort = 원본 정렬
  • sort의 기본 axis는 -1, 즉 마지막 axis다.
  • sort(axis=None)은 flatten 후 1D 정렬이다.
  • unique는 고유값을 구한다.
  • return_counts=True로 빈도도 구할 수 있다.
  • unique의 기본 axis=None은 전체 원소 대상으로 생각한다.
  • astype는 shape가 아니라 dtype을 변경한다.
  • dtype 변환 성공과 값 의미 보존은 다르다.
  • Load 후에는 항상 shape · dtype · NaN을 다시 확인한다.

헷갈리기 쉬운 개념

dtype ≠ fmt

dtype은 메모리 내부 타입, fmt는 Text 출력 표현입니다.

loadtxt ≠ load

Text 파싱과 NumPy 바이너리 로드는 목적이 다릅니다.

NPY ≠ NPZ

하나의 배열과 여러 배열 archive로 구분합니다.

NPZ Load ≠ ndarray 하나

여러 배열에 key로 접근합니다.

assignment ≠ copy

원본과 독립적인 작업본이 필요하면 copy를 사용합니다.

np.sort ≠ arr.sort

반환 배열과 in-place 원본 정렬을 구분합니다.

axis=-1 ≠ 오류

마지막 axis를 의미합니다.

sort(axis=None) ≠ shape 유지

flatten된 1차원 결과가 됩니다.

unique ≠ 순서 보존용 함수

기본적으로 고유값을 정리된 결과로 반환합니다.

astype ≠ 안전한 값 보존 보장

dtype에 따라 정보가 손실될 수 있습니다.

Save / Load ≠ 결측치 정제

NaN도 데이터 값으로 함께 저장·복원됩니다.
