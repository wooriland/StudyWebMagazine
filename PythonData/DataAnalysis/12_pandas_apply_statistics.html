Pandas 함수 적용과 기술 통계

03 · Series.map()

Series 값을 하나씩 새로운 값으로 변환한다 

scores = pd.Series(
    [80, 90, 70],
    index=[
        "A",
        "B",
        "C"
    ]
)

result = scores.map(
    lambda x: x + 5
)
BEFORE

B 90
C 70
x + 5 →
AFTER
A 85
B 95
C 75
type Series → Series
shape (3,) → (3,)
index 유지
value 변환

숫자를 등급으로 변환 

def to_grade(score):
    if score >= 90:
        return "A"

    if score >= 80:
        return "B"

    if score >= 70:
        return "C"

    return "D"


grades = scores.map(
    to_grade
)
BEFORE 80 · 90 · 70 Numeric
→
AFTER B · A · C String Category
map은 dtype도 바꿀 수 있다

함수가 무엇을 반환하느냐에 따라 숫자 Series가 문자열·Boolean 등의 다른 dtype 계열 결과로 변할 수 있습니다.

09 · map vs apply

요소 단위와 축 단위를 절대 혼동하지 않는다

SERIES.MAP Scalar → Scalar Series 값 하나씩
DATAFRAME.MAP Scalar → Scalar 모든 Cell 하나씩
APPLY AXIS=0 Series → Result Column 하나씩
APPLY AXIS=1 Series → Result Row 하나씩
기억 값 → map 축 → apply

17 · Missing & Statistics

통계 함수의 Missing 처리도 확인한다

DATA
80 NaN 100
→
MEAN skipna=True 정상값 기준 계산
→
RESULT (80 + 100) / 2 90
“Pandas는 항상 NaN을 무시한다”라고 일반화하지 않는다

많은 집계·통계 함수에는 Missing을 제외하는 기본 동작이 있지만, 일반 산술이나 누적 함수에서는 Missing의 위치와 전파 방식을 별도로 확인해야 합니다.

import numpy as np
import pandas as pd


def show_series(name, series):
    print()
    print("=" * 70)
    print(name)
    print("=" * 70)

    print(series)

    print("type :", type(series))
    print("shape:", series.shape)
    print("dtype:", series.dtype)
    print("missing:", series.isna().sum())


def show_dataframe(name, frame):
    print()
    print("=" * 70)
    print(name)
    print("=" * 70)

    print(frame)

    print("type :", type(frame))
    print("shape:", frame.shape)

    print("dtypes:")
    print(frame.dtypes)

    print("missing:")
    print(frame.isna().sum())

21 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

map과 apply를 같은 기능이라고 생각한다

map은 요소, DataFrame apply는 Row·Column 축 단위입니다.

Mistake 02

교안의 applymap()을 현재 코드에 그대로 사용한다

현재 DataFrame 요소별 변환은 DataFrame.map()으로 연결합니다.

Mistake 03

apply()가 Cell 하나씩 함수를 호출한다고 생각한다

axis에 따라 Column 또는 Row Series가 전달됩니다.

Mistake 04

axis=0과 axis=1을 반대로 기억한다

axis=0은 Column, axis=1은 Row 단위입니다.

Mistake 05

map 이후 dtype이 그대로라고 생각한다

숫자를 문자열 등급으로 바꾸면 dtype도 달라집니다.

Mistake 06

Dictionary Mapping에 모든 Key가 있다고 가정한다

대응 Key가 없으면 Missing이 생길 수 있습니다.

Mistake 07

Missing이 사용자 함수에 전달된다는 점을 잊는다

필요하면 na_action="ignore"를 고려합니다.

Mistake 08

단순 곱셈도 무조건 map으로 처리한다

가능한 단순 산술은 벡터 연산을 먼저 생각합니다.

Mistake 09

describe 철자를 descibe라고 작성한다

올바른 메서드 이름은 describe()입니다.

Mistake 10

count가 전체 Row 수라고 생각한다

count는 non-NA 값 수입니다.

Mistake 11

sum과 cumsum을 같은 것으로 생각한다

sum은 축약, cumsum은 누적 과정 전체입니다.

Mistake 12

평균만 보고 데이터 분포를 판단한다

median과 std 등도 같이 확인해야 합니다.

Mistake 13

median을 원본 순서의 가운데 값이라고 생각한다

값을 크기순으로 정렬한 뒤 중앙을 판단합니다.

Mistake 14

var와 std를 같은 통계량이라고 생각한다

var는 분산, std는 표준편차입니다.

Mistake 15

std를 분산이라고 외운다

교안 표현을 보완하여 표본 표준편차로 기억합니다.

Mistake 16

Pandas와 NumPy의 std가 항상 같다고 생각한다

기본 ddof 차이를 확인해야 합니다.

Mistake 17

문자열과 숫자가 섞인 전체 DataFrame에 숫자 통계를 적용한다

숫자 Column을 먼저 명확히 선택하면 이해하기 쉽습니다.

Mistake 18

통계 함수가 Missing을 모두 똑같이 처리한다고 생각한다

skipna와 누적 함수의 NA 위치 동작을 확인합니다.

Mistake 19

apply 결과 shape가 항상 원본과 같다고 생각한다

함수가 scalar를 반환하면 Series로 축약될 수 있습니다.

Mistake 20

함수 실행 후 결과 Type을 확인하지 않는다

Scalar, Series, DataFrame 중 무엇인지 확인합니다.

24 · Interview

면접 포인트

Q1. Series.map()은 무엇인가요?
A. Series의 각 값을 함수 또는 Mapping 규칙에 따라 다른 값으로 변환하는 기능입니다.
Q2. Dictionary를 map에 전달하면 무엇을 할 수 있나요?
A. 숫자 코드와 문자열 의미처럼 기존 값과 새로운 값을 대응시킬 수 있습니다.
Q3. Mapping Dictionary에 Key가 없으면 어떻게 되나요?
A. 일반적인 Dictionary Mapping에서는 대응값이 없어 Missing이 만들어질 수 있습니다.
Q4. na_action="ignore"는 무엇인가요?
A. Missing 값을 Mapping 함수에 전달하지 않고 그대로 유지할 때 사용합니다.
Q5. 현재 DataFrame 모든 Cell에 함수를 적용하려면?
A. 현재 Pandas에서는 DataFrame.map()을 사용합니다.
Q6. 교안의 applymap()은 현재 어떻게 연결하나요?
A. 교안에서 applymap이 담당하던 DataFrame 요소별 함수 적용은 현재 DataFrame.map()으로 연결합니다.
Q7. DataFrame.apply()는 어떻게 동작하나요?
A. axis에 따라 Column 또는 Row를 Series 단위로 함수에 전달합니다.
Q8. axis=0과 axis=1의 차이는?
A. axis=0은 Column 단위, axis=1은 Row 단위 함수 적용입니다.
Q9. map과 apply의 핵심 차이는?
A. map은 요소 단위, DataFrame apply는 축 단위라는 점이 핵심입니다.
Q10. describe()는 무엇인가요?
A. 데이터의 개수·중심·퍼짐·범위를 여러 기술 통계로 한 번에 요약하는 기능입니다.
Q11. describe()의 50%는 무엇인가요?
A. Median, 즉 중앙값입니다.
Q12. count()와 Row 수의 차이는?
A. Row 위치 수에는 Missing도 포함될 수 있지만, count()는 non-NA 값의 수를 계산합니다.
Q13. min/max와 idxmin/idxmax 차이는?
A. min/max는 실제 최소·최대값을, idxmin/idxmax는 그 값이 위치한 Label을 찾습니다.
Q14. axis=0 통계는 무엇인가요?
A. 기본적으로 Column마다 하나의 결과를 계산합니다.
Q15. axis=1 통계는 무엇인가요?
A. Row마다 하나의 결과를 계산합니다.
Q16. mean과 median 차이는?
A. 평균은 모든 값의 크기에 영향을 받고, 중앙값은 정렬 후 중앙 위치를 사용하므로 극단값의 영향을 상대적으로 덜 받습니다.
Q17. var()는 무엇인가요?
A. 데이터가 평균을 중심으로 얼마나 퍼져 있는지를 나타내는 분산을 계산합니다.
Q18. std()는 무엇인가요?
A. 표준편차를 계산하며, 값이 평균 주변에서 얼마나 퍼져 있는지 해석하는 데 사용합니다.
Q19. Pandas var/std 기본 ddof는?
A. 기본적으로 ddof=1인 표본 기준 계산과 연결됩니다.
Q20. sum과 cumsum의 차이는?
A. sum은 최종 합으로 축약하고, cumsum은 각 위치까지의 누적값을 원본 크기에 맞춰 유지합니다.
Q21. 통계 함수는 Missing을 어떻게 처리하나요?
A. 많은 집계·통계 함수에는 기본적으로 Missing을 제외하는 skipna 동작이 있지만, 함수마다 세부 동작을 확인해야 합니다.
Q22. 함수 적용 후 반드시 확인해야 할 것은?
A. 결과의 type, shape, axis, dtype 그리고 Missing 상태를 확인해야 합니다.

오늘의 암기 포인트

  • Series.map() = Series 값 하나씩
  • DataFrame.map() = DataFrame Cell 하나씩
  • apply(axis=0) = Column 하나씩
  • apply(axis=1) = Row 하나씩
  • 교안의 applymap()은 현재 DataFrame.map()으로 연결한다.
  • 가능한 단순 산술은 먼저 Vector 연산을 생각한다.
  • Dictionary Mapping에서 대응 Key가 없으면 Missing이 생길 수 있다.
  • na_action="ignore"는 Missing을 함수에 전달하지 않을 때 사용한다.
  • describe() = 기술 통계 전체 요약
  • describe의 50%는 median이다.
  • count() = non-NA 개수
  • min()·max()는 값, idxmin()·idxmax()는 Label이다.
  • axis=0은 Column별 결과다.
  • axis=1은 Row별 결과다.
  • sum()은 합계다.
  • mean()은 평균이다.
  • median()은 정렬 후 중앙값이다.
  • var()은 표본 분산이다.
  • std()는 표본 표준편차다.
  • Pandas var/std 기본은 ddof=1과 연결한다.
  • sum() ≠ cumsum()
  • cumsum은 누적 과정을 남기므로 shape를 유지한다.
  • 함수 실행 후에는 type · shape · dtype · Missing을 확인한다.

헷갈리기 쉬운 개념

Series.map ≠ DataFrame.apply

값 하나씩과 축 단위 처리의 차이입니다.

DataFrame.map ≠ apply

Cell 하나씩과 Row·Column 단위 처리를 구분합니다.

applymap ≠ 현재 권장 API

교안의 개념은 현재 DataFrame.map으로 연결합니다.

axis 0 ≠ axis 1

Column과 Row 방향을 구분합니다.

shape ≠ count

shape는 위치, count는 non-NA 값 개수입니다.

mean ≠ median

평균과 중앙값은 극단값의 영향을 다르게 받습니다.

var ≠ std

분산과 표준편차를 구분합니다.

std ≠ 분산

std는 표준편차입니다.

sum ≠ cumsum

최종 합계와 누적 과정을 구분합니다.

Mapping Missing ≠ 원본 Missing만 존재

변환 규칙의 누락 때문에 새 NaN이 생길 수도 있습니다.
