Data Analysis · Lesson 03 · NumPy Array Creation

NumPy 배열 생성

NumPy에서는 배열의 값을 하나씩 직접 작성하지 않아도 필요한 shape, dtype, 초기값, 범위, 간격, 개수, 확률분포라는 규칙을 이용해 ndarray를 자동으로 생성할 수 있습니다. 이번 단원에서는 array(), zeros(), ones(), full(), empty(), arange(), linspace(), logspace(), 그리고 random 계열 함수를 목적에 맞게 선택하는 방법을 공부합니다.

array zeros ones full empty arange linspace logspace random

학습 목표

  • 필요한 배열의 조건을 shape, dtype, 초기값, 범위, 간격, 개수, 분포 로 나누어 생각할 수 있다.
  • 값이 이미 존재할 때 np.array()를 사용할 수 있다.
  • zeros(), ones(), full(), empty()의 차이를 설명할 수 있다.
  • zeros_like(), ones_like()가 기존 배열의 구조를 활용한다는 것을 이해한다.
  • arange()와 linspace()의 step 중심 / 개수 중심 차이를 설명할 수 있다.
  • logspace()가 로그 스케일 수열을 만드는 함수임을 이해한다.
  • normal(), rand(), randn(), randint(), random()의 생성 규칙을 구분할 수 있다.
  • 생성 후 ndim, shape, size, dtype을 확인할 수 있다.
  • 배열 생성 전후에 shape, axis, dtype, 결측치 상태를 비교하는 습관을 익힌다.

01 · Core Concept

배열 생성은 값을 입력하는 것이 아니라 규칙을 정의하는 작업이다

작은 배열은 직접 값을 입력해 만들 수 있지만, 실제 데이터 분석에서는 수백·수천·수백만 개의 값을 직접 작성할 수 없습니다. 따라서 NumPy에서는 원하는 배열의 생성 규칙 을 먼저 정의하고, 그 규칙에 맞는 함수를 선택합니다.

NumPy Array Creation

필요한 ndarray의 shape, dtype, 초기값, 수치 범위, 간격, 데이터 개수 또는 확률분포를 지정하여 NumPy가 자동으로 배열을 생성하도록 하는 과정입니다.

array · zeros · ones · full · empty

실제 값을 이미 알고 있을 때 사용합니다.

모두 0으로 초기화

0 0 0

초기 상태를 0으로 명확하게 정의할 때 사용합니다.

np.ones()

모두 1로 초기화 

arr = np.ones(
    (2, 3)
)
1 1 1
1 1 1

초기값 1이 필요한 계산이나 가중치 배열에 활용할 수 있습니다.

np.full()

원하는 값으로 초기화 

arr = np.full(
    (2, 3),
    7

7 7 7
7 7 7

0과 1 이외의 특정 초기 상태가 필요할 때 사용합니다.

np.empty()

초기화하지 않고 공간 확보 

arr = np.empty(
    (2, 3)
)
? ? ?
? ? ?

생성 직후 값은 신뢰하지 않고 반드시 새 값을 채운 뒤 사용합니다.

empty의 핵심 오해

empty()는 “값이 없는 배열”이나 “0 배열”을 의미하지 않습니다. 메모리 공간만 확보하고 원소 초기화를 수행하지 않는다는 뜻입니다.

03 · Like Functions

zeros_like · ones_like ― 기존 배열의 구조 재사용

_like 계열은 새로운 shape를 직접 적는 대신 기존 배열의 shape와 dtype을 기준으로 새 배열을 생성 하는 방식입니다.

BASE ARRAY 
base = np.array([
    [10, 20, 30],
    [40, 50, 60]
])
shape=(2,3) dtype=integer

zeros_like 

np.zeros_like(base)
0 0 0
0 0 0
shape=(2,3)

ones_like 

np.ones_like(base)
1 1 1
1 1 1
shape=(2,3)
_like = “이 배열처럼 만들어줘”

값 자체를 복사하는 것이 아니라, 기존 배열의 구조와 자료형을 기준으로 새로운 초기화 배열을 만든다고 기억하면 쉽습니다.

난수 함수 선택

randn 표준정규분포

Supplement · Random Generator

Step 1·2 보완 ― default_rng() 방식도 알아두기

교안의 중심 학습 범위는 np.random.* 방식입니다. 이 단원에서는 교안 코드를 우선 이해하고, 별도의 보완 개념으로 default_rng()를 사용한 Generator 방식도 같이 알아둡니다. 

import numpy as np

rng = np.random.default_rng(42)

normal_data = rng.normal(
    loc=0,
    scale=1,
    size=(2, 3)
)

uniform_data = rng.random(
    (2, 3)
)

standard_data = rng.standard_normal(
    (2, 3)
)

integer_data = rng.integers(
    0,
    10,
    size=(2, 3)
)
교안 np.random.randint(...)
↔
보완 rng.integers(...)
seed와 재현성

np.random.default_rng(42)처럼 동일한 seed에서 시작하면 테스트와 디버깅에서 동일한 난수 흐름을 다시 재현하는 개념과 연결할 수 있습니다.

09 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

zeros는 정수 배열이라고 생각한다

기본 dtype이 실수형 계열이므로 0. 형태가 나타날 수 있습니다.

Mistake 02

shape와 size를 같은 것으로 본다

shape = (2, 3)
size  = 6
Mistake 03

empty가 0 배열이라고 생각한다

초기값은 보장되지 않습니다.

Mistake 04

empty의 기존 값을 그대로 계산한다

새 값을 입력한 후 사용해야 합니다.

Mistake 05

zeros_like가 원본 값도 복사한다고 생각한다

구조와 dtype을 참고하고 값은 0으로 만듭니다.

Mistake 06

arange의 stop도 포함한다고 생각한다

[start, stop)
Mistake 07

arange의 세 번째 값을 개수라고 생각한다

세 번째 값은 step입니다.

Mistake 08

linspace의 세 번째 값을 step이라고 생각한다

세 번째 값은 num입니다.

Mistake 09

arange와 linspace의 stop 규칙을 혼동한다

arange는 제외, linspace는 기본적으로 포함합니다.

Mistake 10

logspace 결과가 0,1,2,3이라고 생각한다

그것은 지수이고 실제 값은 거듭제곱 결과입니다.

Mistake 11

rand와 random의 인자 형태를 동일하게 사용한다

np.random.rand(2, 3)

np.random.random(
    size=(2, 3)
)
Mistake 12

난수의 실제 결과 숫자를 외운다

값보다 범위·분포·shape를 확인합니다.

Mistake 13

randint의 high도 포함한다고 생각한다

[low, high)
Mistake 14

random 함수의 size와 arr.size를 혼동한다

함수의 size는 결과 구조, arr.size는 전체 원소 수입니다.

Mistake 15

NaN은 배열 칸이 사라진 것이라고 생각한다

배열 위치는 그대로 존재합니다.

Mistake 16

생성 후 shape와 dtype을 확인하지 않는다

생성 함수 실행 직후 상태 확인을 습관화합니다.

12 · Interview

면접 포인트

Q1. NumPy 배열 생성 방법에는 무엇이 있나요?
A. 직접 값을 이용하는 array(), 초기값 배열을 만드는 zeros(), ones(), full(), empty(), 수열을 만드는 arange(), linspace(), logspace(), 그리고 난수 생성 함수들이 있습니다.
Q2. zeros와 zeros_like의 차이는 무엇인가요?
A. zeros는 shape를 직접 지정하고, zeros_like는 기존 배열의 shape와 dtype을 기준으로 0 배열을 생성합니다.
Q3. full()은 무엇인가요?
A. 지정한 shape의 배열을 생성한 뒤 모든 원소를 사용자가 지정한 fill value로 채우는 함수입니다.
Q4. empty()는 왜 주의해야 하나요?
A. 배열 공간을 만들지만 원소를 특정 값으로 초기화하지 않기 때문에 생성 직후 값은 신뢰해서는 안 됩니다.
Q5. arange와 linspace의 차이는 무엇인가요?
A. arange는 step을 중심으로 값을 생성하고, linspace는 start와 stop 사이에서 지정한 num개의 값을 균등하게 생성합니다.
Q6. arange의 stop은 포함되나요?
A. 아닙니다. 기본적으로 start 이상 stop 미만의 범위를 사용합니다.
Q7. linspace의 세 번째 인자는 무엇인가요?
A. step이 아니라 생성할 데이터의 개수인 num입니다.
Q8. logspace란 무엇인가요?
A. 로그 스케일에서 균등한 간격을 갖는 값을 생성하는 함수입니다.
Q9. normal과 randn의 차이는 무엇인가요?
A. normal은 평균과 표준편차를 직접 지정할 수 있고, randn은 평균 0, 표준편차 1인 표준정규분포를 사용합니다.
Q10. randint의 high 값도 포함되나요?
A. 기본적으로 high는 제외됩니다. 따라서 1부터 6까지의 주사위 값을 만들려면 high를 7로 지정합니다.
Q11. random 함수의 size와 ndarray.size의 차이는?
A. 함수의 size 인자는 생성할 배열의 구조를 지정하는 역할을 하고, 생성 후 ndarray의 size 속성은 전체 원소 개수를 의미합니다.
Q12. 배열 생성에서 dtype은 왜 중요한가요?
A. 같은 shape의 배열이라도 dtype에 따라 값의 표현과 메모리 크기, 가능한 연산 특성이 달라질 수 있기 때문입니다.
Q13. np.zeros((3,4), dtype=np.int32)를 설명해보세요.
A. 3행 4열의 2차원 배열을 만들고, 전체 12개 원소를 0으로 초기화하며, 각 원소를 int32 dtype으로 저장하는 코드입니다.
Q14. np.full((2,3), np.nan)의 size는 얼마인가요?
A. shape가 (2,3)이므로 전체 원소 수는 6입니다. NaN도 배열의 각 위치를 차지합니다.
Q15. 난수 배열을 만든 뒤 무엇을 확인해야 하나요?
A. 정확한 난수값 자체보다 shape, dtype, 값의 범위와 의도한 확률분포에 맞는 생성 규칙을 확인해야 합니다.

오늘의 암기 포인트

  • 배열 생성은 값을 하나씩 작성하는 것이 아니라 생성 규칙을 정의하는 작업 이다.
  • 값을 직접 알고 있으면 np.array().
  • 모두 0은 zeros().
  • 모두 1은 ones().
  • 원하는 특정 값은 full().
  • empty()는 값을 초기화하지 않는다.
  • _like는 기존 배열의 shape와 dtype을 기준으로 생성한다.
  • arange() = step 중심.
  • linspace() = 개수 중심.
  • logspace() = 로그 스케일.
  • arange는 stop을 제외하고, linspace는 기본적으로 stop을 포함한다.
  • normal()의 loc는 평균, scale은 표준편차이다.
  • randn()은 표준정규분포와 연결한다.
  • randint()의 high는 기본적으로 제외된다.
  • 난수에서는 실제 값보다 범위·분포·shape를 확인한다.
  • 생성 후에는 ndim, shape, size, dtype을 다시 확인한다.

헷갈리기 쉬운 개념

zeros ≠ empty

zeros는 0으로 초기화하지만 empty는 초기화하지 않습니다.

zeros ≠ zeros_like

zeros는 shape 직접 지정, zeros_like는 기존 배열 구조 활용입니다.

arange step ≠ linspace num

arange는 간격, linspace는 개수입니다.

arange stop ≠ linspace stop

arange는 제외, linspace는 기본적으로 포함합니다.

linspace ≠ logspace

linspace는 선형 간격, logspace는 로그 간격입니다.

normal ≠ randn

normal은 평균·표준편차 지정, randn은 표준정규분포입니다.

rand(2,3) ≠ random(size=(2,3)) 문법

비슷한 결과 구조라도 인자 작성 방식이 다릅니다.

함수 size ≠ arr.size

함수 인자의 size는 결과 구조, arr.size는 전체 원소 수입니다.

dtype 변화 ≠ shape 변화

같은 shape를 유지하면서 dtype만 다르게 만들 수 있습니다.

NaN ≠ 배열 칸 삭제

NaN도 배열의 한 위치를 차지합니다.
