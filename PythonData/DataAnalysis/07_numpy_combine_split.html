Data Analysis · Lesson 07 · NumPy Combine & Split

NumPy 배열 추가·결합과 분할

앞 단원에서는 하나의 ndarray 안에서 reshape(), resize(), ravel()을 이용하여 배열의 구조를 변경했습니다. 이번 단원에서는 한 단계 더 나아가 값을 추가·삽입·삭제하고, 여러 ndarray를 원하는 axis를 기준으로 결합하며, 큰 배열을 다시 여러 조각으로 분할하고, 마지막으로 Transpose를 이용해 axis의 방향까지 바꾸는 방법을 공부합니다.

append insert delete concatenate vstack hstack vsplit hsplit Transpose axis

학습 목표

  • np.append()를 이용해 ndarray의 끝에 값을 추가할 수 있다.
  • np.insert()를 이용해 원하는 index 앞에 값을 삽입할 수 있다.
  • np.delete()를 이용해 특정 원소·행·열을 제거할 수 있다.
  • axis=None과 axis를 명시한 경우의 차이를 설명할 수 있다.
  • np.concatenate()의 axis별 결합 규칙을 이해한다.
  • vstack()과 hstack()의 차이를 설명할 수 있다.
  • 특히 1차원 배열에서 vstack과 hstack의 결과 shape 차이를 이해한다.
  • vsplit()과 hsplit()을 이용해 배열을 행·열 방향으로 나눌 수 있다.
  • split 결과가 여러 ndarray를 담는 구조라는 것을 이해한다.
  • .T를 이용해 2차원 배열의 행·열을 전치할 수 있다.
  • 배열 조작 전후의 shape, axis, size, dtype, 결측치 상태를 비교할 수 있다.
  • 여러 Source에서 수집한 데이터를 실무 분석용 ndarray로 결합할 수 있다.

01 · Core Concept

이번에는 배열의 구성 자체를 바꾼다

reshape()는 하나의 배열 안에서 같은 원소를 다른 shape로 표현하는 작업이었습니다. 이번 단원에서는 새로운 원소를 추가하거나 제거하고, 서로 다른 배열을 하나로 묶거나, 하나의 배열을 다시 여러 조각으로 나누게 됩니다.

03 · axis=None

axis를 생략하면 2차원 구조가 사라질 수 있다

append(), insert(), delete()에서 axis를 지정하지 않으면 배열을 1차원으로 펼친 상태를 기준으로 처리하게 됩니다.

ORIGINAL
10 20
30 40
shape=(2,2)
↓ axis=None
FLATTEN
10 20 30 40
shape=(4,)
↓ append [50,60]
RESULT
10 20 30 40 50 60
shape=(6,)
2차원 구조를 유지해야 하는가?

그렇다면 함수 호출 전에 axis=0 또는 axis=1 등 어떤 axis를 변경할 것인지 명확하게 지정합니다.

axis=0은 행, axis=1은 열 방향으로 확장

새 열 추가

(2,2) + (2,1) → (2,3)
axis로 추가할 때의 shape 규칙
axis=0 (A,B) + (C,B) → (A+C,B)
axis=1 (A,B) + (A,C) → (A,B+C)

06 · concatenate()

여러 배열을 원하는 axis로 결합한다 

result = np.concatenate(
    (
        array_a,
        array_b
    ),
    axis=0
)
정확한 shape 규칙

모든 shape가 완전히 같아야 하는 것이 아니라 결합할 axis를 제외한 나머지 axis의 크기가 같아야 합니다.

1 2 3

axis=1

1 2
3 4
+
B · (2,1)

→

concatenate 판정 공식
  1. 결합할 axis를 정한다.
  2. 그 axis의 크기는 서로 달라도 된다.
  3. 나머지 axis들의 크기를 비교한다.
  4. 나머지 크기가 모두 같으면 결합할 수 있다.

Supplement · Split Rule

정수로 분할하면 동일 크기로 나뉘어야 한다

SUCCESS axis size = 4 ÷ 2 sections 2 + 2

동일 크기이므로 가능

FAIL axis size = 3 ÷ 2 sections 동일 크기 불가

ValueError

index를 직접 경계로 사용할 수도 있다 

parts = np.vsplit(
    matrix,
    [1, 3]
)
matrix[:1] 첫 조각
matrix[1:3] 두 번째 조각
matrix[3:] 세 번째 조각
보완 동일하지 않은 크기로 분할해도 된다면? np.array_split()

이번 교안의 직접 학습 범위는 아니지만, 동일 크기로 나뉘지 않는 경우 사용할 수 있는 별도 함수로 연결할 수 있습니다.

13 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

np.append가 원본을 바꾼다고 생각한다

반환된 ndarray를 저장해야 합니다.

Mistake 02

axis=None인데 2D shape가 유지될 것으로 생각한다

flatten된 뒤 처리될 수 있습니다.

Mistake 03

2D 배열에 axis=0 append하면서 1D 값을 넣는다

행 하나라면 `(1,N)` 구조가 필요합니다.

Mistake 04

insert가 기존 값을 교체한다고 생각한다

지정 index 앞에 새 값이 삽입됩니다.

Mistake 05

delete가 원본을 직접 삭제한다고 생각한다

삭제된 결과 배열을 반환받아야 합니다.

Mistake 06

concatenate는 모든 shape가 완전히 같아야 한다고 생각한다

결합 axis를 제외한 나머지 shape가 같아야 합니다.

Mistake 07

concatenate에 배열들을 sequence로 묶지 않는다

(a, b)처럼 하나의 sequence로 전달합니다.

Mistake 08

1D vstack의 결과가 1D라고 생각한다

`(3,) + (3,) → (2,3)`입니다.

Mistake 09

1D hstack 결과가 `(3,2)`라고 생각한다

1차원으로 이어져 `(6,)`이 됩니다.

Mistake 10

vsplit과 hsplit 방향을 반대로 기억한다

2D 기준 vsplit은 axis 0, hsplit은 axis 1입니다.

Mistake 11

아무 크기나 원하는 개수로 split할 수 있다고 생각한다

정수 분할은 동일 크기로 나눠져야 합니다.

Mistake 12

split 결과가 ndarray 하나라고 생각한다

여러 ndarray를 담은 list입니다.

Mistake 13

1D .T가 Column Vector를 만든다고 생각한다

1D `.T`는 shape를 바꾸지 않습니다.

Mistake 14

Transpose가 원소 수를 바꾼다고 생각한다

axis 순서가 바뀔 뿐 size는 유지됩니다.

Mistake 15

결합 후 dtype을 확인하지 않는다

서로 다른 입력 dtype의 영향을 확인해야 합니다.

Mistake 16

결합·분할 후 shape를 확인하지 않는다

이번 단원의 핵심은 결과 shape 예측입니다.

16 · Interview

면접 포인트

Q1. np.append()는 Python List의 append()와 어떻게 다른가요?
A. NumPy의 np.append()는 원본 ndarray를 직접 수정하는 방식이 아니라 값이 추가된 새로운 ndarray를 반환합니다.
Q2. append에서 axis를 생략하면 어떻게 되나요?
A. 원본과 추가값이 1차원으로 펼쳐진 상태를 기준으로 append될 수 있으므로 기존 2D shape가 유지되지 않습니다.
Q3. (2,3) 배열에 axis=0으로 행을 추가하려면 추가 배열 shape는?
A. 한 행을 추가한다면 (1,3) 형태가 적절합니다. 결합하지 않는 나머지 axis의 크기 3이 같아야 합니다.
Q4. append와 insert의 차이는 무엇인가요?
A. append는 끝에 추가하고, insert는 지정한 index 앞에 값을 삽입합니다.
Q5. np.delete()는 원본을 직접 수정하나요?
A. 아닙니다. 특정 위치가 제거된 새로운 ndarray를 결과로 사용합니다.
Q6. concatenate()는 무엇인가요?
A. 여러 ndarray를 기존 axis 중 하나를 기준으로 연결하는 범용 결합 함수입니다.
Q7. concatenate하려면 모든 shape가 완전히 같아야 하나요?
A. 아닙니다. 결합하는 axis의 크기는 달라도 되지만 나머지 axis들의 크기는 같아야 합니다.
Q8. (2,3)과 (1,3)을 axis=0으로 concatenate할 수 있나요?
A. 가능합니다. axis 0은 결합되는 차원이므로 크기가 달라도 되고, axis 1의 크기 3이 같기 때문입니다. 결과 shape는 (3,3)입니다.
Q9. vstack()은 무엇인가요?
A. 배열을 수직 방향으로 쌓는 함수입니다. 특히 1D 배열 두 개를 vstack하면 각 배열이 행처럼 배치되어 2차원 결과가 만들어집니다.
Q10. 두 (3,) 배열을 vstack하면 결과 shape는?
A. (2,3)입니다.
Q11. 두 (3,) 배열을 hstack하면 결과 shape는?
A. 한 줄로 이어 붙으므로 (6,)입니다.
Q12. vsplit()은 어느 axis를 기준으로 하나요?
A. 첫 번째 axis, 즉 axis 0을 기준으로 분할합니다.
Q13. hsplit()은 어느 axis를 기준으로 하나요?
A. 2차원 이상에서는 두 번째 axis인 axis 1을 기준으로 분할합니다.
Q14. split 결과는 어떤 타입인가요?
A. 여러 개의 ndarray를 담고 있는 list 형태로 사용할 수 있습니다.
Q15. 정수 N으로 split할 때 주의할 점은?
A. 해당 axis의 크기가 N개의 동일한 크기 조각으로 정확하게 나뉘어야 합니다.
Q16. .T는 무엇인가요?
A. ndarray의 전치 결과를 얻는 속성으로, 2D에서는 행과 열을 서로 바꾸는 효과가 있습니다.
Q17. (2,3) 배열을 전치하면 shape는?
A. (3,2)입니다.
Q18. 1차원 배열에 .T를 사용하면 Column Vector가 되나요?
A. 아닙니다. (3,) 배열은 전치해도 (3,)입니다. Column 형태가 필요하면 reshape(-1,1)처럼 새로운 axis 구조를 만들어야 합니다.
Q19. 배열 결합 후 무엇을 확인해야 하나요?
A. 결과의 ndim, shape, size, dtype을 확인하고 데이터 분석에서는 NaN 개수와 위치도 확인합니다.

오늘의 암기 포인트

  • append = 끝에 추가
  • insert = 지정 index 앞에 삽입
  • delete = 특정 위치 제거
  • NumPy의 append·insert·delete는 결과 배열을 반환한다.
  • axis=None이면 flatten을 먼저 의식한다.
  • axis=0은 첫 번째 차원 방향을 변경한다.
  • axis=1은 두 번째 차원 방향을 변경한다.
  • concatenate는 지정 axis를 따라 여러 배열을 결합한다.
  • concatenate에서는 결합 axis를 제외한 나머지 shape가 같아야 한다.
  • vstack의 V는 Vertical.
  • hstack의 H는 Horizontal.
  • 1D 두 배열의 vstack: (3,) + (3,) → (2,3)
  • 1D 두 배열의 hstack: (3,) + (3,) → (6,)
  • vsplit은 axis 0 방향으로 나눈다.
  • hsplit은 2D 이상에서 axis 1 방향으로 나눈다.
  • split 결과는 여러 ndarray를 담는 구조다.
  • 정수 N으로 split할 때는 동일한 크기로 나뉘어야 한다.
  • 2D의 .T는 행과 열을 바꾼다.
  • 1D의 .T는 shape를 바꾸지 않는다.
  • 모든 결합·분할 뒤 shape · dtype · NaN을 확인한다.

헷갈리기 쉬운 개념

np.append ≠ list.append

NumPy append는 새 결과 배열을 사용합니다.

axis=None ≠ shape 유지

2D 배열이 1D로 flatten될 수 있습니다.

insert ≠ 교체

지정 index 앞에 값을 추가합니다.

delete ≠ 원본 직접 삭제

삭제 결과를 새 배열로 사용합니다.

concatenate ≠ 완전히 같은 shape만 가능

결합 axis만 달라도 되고 나머지 shape가 같아야 합니다.

vstack ≠ hstack

특히 1D 입력에서 결과 ndim과 shape가 다릅니다.

vsplit ≠ hsplit

2D 기준으로 각각 axis 0과 axis 1을 나눕니다.

split result ≠ ndarray 하나

여러 ndarray가 들어 있는 결과 구조입니다.

.T ≠ 1D Column 변환

1D 배열은 전치해도 1D입니다.

결합 ≠ 결측치 정제

NaN도 데이터 원소로 그대로 함께 이동합니다.
