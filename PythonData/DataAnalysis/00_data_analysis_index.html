데이터 분석 전체 로드맵

데이터 분석은 단순히 숫자를 계산하는 작업이 아닙니다. 현실의 문제를 분석 질문으로 바꾸고, 필요한 데이터를 수집한 뒤 데이터의 구조와 품질을 확인하고, 정제·변환·분석·시각화하여 최종적으로 결과의 의미를 해석하는 전체 과정입니다. 이번 단원에서는 NumPy, Pandas, Matplotlib를 중심으로 앞으로 공부하게 될 데이터 분석의 전체 지도를 먼저 만듭니다.

  • 데이터 처리 전후에 shape·dtype·결측치가 어떻게 변하는지 확인하는 습관 을 익힌다.

01 · Core Concept

핵심 개념 ― 데이터가 의미 있는 정보가 되는 과정

데이터 분석의 목적은 데이터를 많이 모으는 것도, 함수를 많이 사용하는 것도 아닙니다. 현실에서 발생한 기록을 사람이 판단할 수 있는 정보로 바꾸는 것 이 핵심입니다.

데이터 분석

현실의 문제를 질문으로 바꾸고, 필요한 데이터를 수집·확인·정제·변환·계산·시각화한 뒤 그 결과의 의미를 해석하여 의사결정에 사용할 수 있는 정보로 만드는 과정입니다.

단순 계산

10 20 30 40

평균을 계산하면 25입니다.

하지만 이것만으로는 데이터가 무엇을 의미하는지 알 수 없습니다.

데이터 분석

  • 25는 높은 값인가?
  • 지난달보다 증가한 값인가?
  • 지역별 차이가 있는가?
  • 특정 이상치 때문에 평균이 높아진 것은 아닌가?

04 · Data State

데이터 분석에서 반드시 추적해야 할 4가지 상태

데이터 분석에서는 함수를 실행하는 것보다 실행 전과 후에 데이터가 어떻게 변했는지 확인하는 것이 중요합니다.

shape

데이터의 구조가 어떻게 변했는가? 

df.shape
# (1000, 8)

일반적인 DataFrame에서 (1000, 8)은 1000행 8열을 의미합니다.

axis

어느 축을 따라 연산하는가? 

arr.sum(axis=0)
arr.sum(axis=1)

단순히 0=행, 1=열 로 외우기보다 어느 축을 접어서 계산하는가 로 이해합니다.

dtype

컴퓨터가 이 값을 어떤 자료형으로 보는가? 

df.dtypes

"10000"과 10000은 사람에게 비슷해 보여도 컴퓨터에게는 다릅니다.

Missing Value

사용할 수 없는 값이 어디에 얼마나 있는가? 

df.isna().sum()

결측치는 무조건 삭제하지 않고 발생 이유와 분석 목적을 확인한 뒤 삭제·대체·유지 여부를 결정합니다.

shape 변화로 분석 과정 추적하기

RAW (1000, 8)

최초 수집 데이터

→
결측치 처리 (950, 8)

사용할 수 없는 50행 제거

→
컬럼 선택 (950, 5)

필요한 컬럼만 유지

→
파생열 생성 (950, 6)

분석용 컬럼 추가

결측치 · Missing Value

20 · 22 · 21 · NaN

값 자체가 존재하지 않는 상태입니다.

이상치 · Outlier

20 · 22 · 21 · 350

값은 존재하지만 다른 데이터와 지나치게 다른 값입니다.

07 · Python Example

하나의 코드로 전체 분석 흐름 연결하기

아래 예제의 목적은 함수를 암기하는 것이 아닙니다. 데이터의 상태가 각 단계에서 어떻게 변하는지 읽는 것이 핵심입니다. 

import pandas as pd


# --------------------------------------------------
# 1. 데이터 수집 / 생성
# --------------------------------------------------
data = {
    "order_id": [1001, 1002, 1003, 1004, 1005, 1006],
    "region": [
        "서울",
        "부산",
        "서울",
        "서울",
        "부산",
        "대전"
    ],
    "product": [
        "A",
        "B",
        "A",
        "C",
        "B",
        "C"
    ],
    "price": [
        "10000",
        "20000",
        None,
        "15000",
        "12000",
        "18000"
    ],
    "quantity": [2, 1, 3, 2, 2, 1]
}

df = pd.DataFrame(data)


# --------------------------------------------------
# 2. 데이터 확인
# --------------------------------------------------
print("=== 원본 데이터 ===")
print(df)

print("\n=== shape ===")
print(df.shape)

print("\n=== dtype ===")
print(df.dtypes)

print("\n=== 결측치 ===")
print(df.isna().sum())


# --------------------------------------------------
# 3. dtype 변환
# --------------------------------------------------
df["price"] = pd.to_numeric(
    df["price"],
    errors="coerce"
)


# --------------------------------------------------
# 4. 결측치 처리
# --------------------------------------------------
df = df.dropna(
    subset=["price"]
)

print("\n=== 결측치 처리 후 shape ===")
print(df.shape)


# --------------------------------------------------
# 5. 파생 컬럼 생성
# --------------------------------------------------
df["sales"] = (
    df["price"]
    * df["quantity"]
)

print("\n=== sales 추가 후 shape ===")
print(df.shape)


# --------------------------------------------------
# 6. 전체 분석
# --------------------------------------------------
total_sales = df["sales"].sum()
average_sales = df["sales"].mean()

print("\n=== 전체 매출 ===")
print(total_sales)

print("\n=== 평균 주문 매출 ===")
print(average_sales)


# --------------------------------------------------
# 7. 그룹별 분석
# --------------------------------------------------
summary = (
    df
    .groupby("region")["sales"]
    .agg([
        "count",
        "sum",
        "mean"
    ])
)

print("\n=== 지역별 분석 ===")
print(summary)


# --------------------------------------------------
# 8. 시각화
# --------------------------------------------------
summary["sum"].plot(
    kind="bar",
    title="지역별 매출"
)

08 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

데이터를 보지 않고 바로 계산한다 

df.groupby("region")["sales"].sum()

계산 전에 먼저 shape, dtypes, 결측치와 컬럼을 확인합니다.

Mistake 02

숫자처럼 보이면 숫자라고 생각한다

"10000" ≠ 10000

보이는 값과 실제 dtype은 다를 수 있습니다.

Mistake 03

shape만 보고 정상 데이터라고 판단한다

(1000, 5)라는 정보는 결측치나 중복, 오류값이 없다는 의미가 아닙니다.

Mistake 04

axis를 숫자로만 외운다

axis=0, axis=1을 단순 암기하지 말고 어느 축을 따라 계산하는지 생각합니다.

Mistake 05

결측치를 무조건 삭제한다

결측치 발생 이유, 개수, 분석 목적을 먼저 확인합니다.

Mistake 06

결측치와 이상치를 같은 것으로 본다

결측치는 값이 없고, 이상치는 값은 있지만 특이한 상태입니다.

Mistake 07

평균만 확인한다

극단적인 값이 존재하면 평균이 크게 흔들릴 수 있으므로 중앙값도 함께 확인합니다.

Mistake 08

Series와 DataFrame을 구분하지 않는다 

df["price"]    # Series
df[["price"]]  # DataFrame
Mistake 09

loc와 iloc을 혼동한다

loc는 label, iloc는 위치 번호 기준입니다.

Mistake 10

분석 결과를 원인이라고 단정한다

“A 지역 매출이 높다”는 결과이지 “광고 때문에 높다”는 원인 증명이 아닙니다.

ModuleNotFoundError 현재 Python 환경에서 모듈을 찾지 못함 Conda 환경, Interpreter, Kernel, 설치 여부
FileNotFoundError 읽으려는 파일을 찾지 못함 파일명, 상대경로, 작업 디렉터리
KeyError 해당 컬럼 또는 Key가 존재하지 않음 df.columns, 오타, 공백, 대소문자
TypeError 연산할 수 없는 자료형 조합 type(), df.dtypes
ValueError 값이 요구되는 형태에 맞지 않음 숫자 변환 실패, shape 불일치
IndexError 존재하지 않는 배열 위치에 접근 shape, size, index 범위
오류 마지막 줄 → Error Type → 발생 코드 → shape / dtype / columns → 문제 데이터 확인

11 · Interview

면접 포인트

Q1. 데이터 분석이란 무엇인가요?
A. 데이터 분석은 문제와 질문을 정의하고, 필요한 데이터를 수집한 뒤 데이터 구조와 품질을 확인하고 정제·변환·분석·시각화하여 결과의 의미를 해석하는 과정입니다. 단순 계산이 아니라 의사결정 가능한 정보로 만드는 과정까지 포함합니다.
Q2. NumPy와 Pandas의 차이는 무엇인가요?
A. NumPy는 ndarray를 중심으로 다차원 배열과 빠른 수치 연산을 제공하고, Pandas는 Series와 DataFrame을 중심으로 표 형태 데이터를 정제·선택·병합·그룹화하는 기능을 제공합니다.
Q3. shape란 무엇인가요?
A. 배열이나 DataFrame의 각 차원 크기를 나타냅니다. 일반적인 2차원 DataFrame에서 (100, 5)는 100행 5열이라는 의미입니다.
Q4. axis란 무엇인가요?
A. 다차원 데이터에서 연산이 진행되는 축입니다. 2차원 배열에서 axis=0을 따라 집계하면 행 축이 축약되어 열별 결과가 남고, axis=1을 따라 집계하면 열 축이 축약되어 행별 결과가 남습니다.
Q5. dtype이 왜 중요한가요?
A. 같은 값처럼 보여도 저장된 자료형에 따라 가능한 연산이 달라지기 때문입니다. 숫자가 문자열로 저장되어 있다면 합계나 평균을 계산하기 전에 숫자형으로 변환해야 합니다.
Q6. 결측치는 무조건 삭제해야 하나요?
A. 아닙니다. 결측치 발생 원인, 비율, 컬럼의 중요성, 분석 목적을 확인한 뒤 삭제·대체·유지 여부를 결정해야 합니다.
Q7. 결측치와 이상치의 차이는 무엇인가요?
A. 결측치는 값 자체가 없는 상태이고, 이상치는 값은 존재하지만 다른 데이터와 지나치게 다른 값입니다.
Q8. GroupBy란 무엇인가요?
A. 데이터를 특정 기준으로 나눈 뒤 각 그룹에 집계 함수를 적용하고 결과를 다시 합치는 방식입니다. 일반적으로 Split → Apply → Combine으로 설명합니다.
Q9. 평균과 중앙값의 차이는 무엇인가요?
A. 평균은 모든 값을 사용하지만 극단적인 값의 영향을 크게 받을 수 있습니다. 이상치가 많은 데이터에서는 중앙값이 데이터 중심을 더 잘 표현할 수 있습니다.
Q10. 분석 결과와 해석은 어떻게 다른가요?
A. 분석 결과는 계산을 통해 확인된 사실이고, 해석은 그 결과가 현실의 문제에서 무엇을 의미하는지를 설명하는 단계입니다. 데이터가 검증하지 않은 원인을 결과만 보고 단정하면 안 됩니다.

오늘의 암기 포인트

  • 데이터 분석 = 질문 → 수집 → 확인 → 정제 → 변환 → 분석 → 시각화 → 해석
  • NumPy 는 수치 배열, Pandas 는 표 데이터, Matplotlib 는 시각화를 담당한다.
  • shape는 데이터 구조, dtype은 자료형, axis는 연산 축이다.
  • 데이터 처리 전후에는 shape·dtype·결측치를 다시 확인 한다.
  • 결측치는 값이 없는 것이고, 이상치는 값은 존재하지만 특이한 값이다.
  • 결측치는 발견했다고 무조건 삭제하지 않는다.
  • GroupBy = Split → Apply → Combine
  • 계산 결과와 결과의 해석은 서로 다른 단계다.
  • 좋은 분석은 좋은 질문에서 시작하고 새로운 질문으로 이어진다.

헷갈리기 쉬운 개념

shape ≠ size

shape는 각 차원의 크기, size는 전체 요소 개수입니다.

ndim ≠ shape

ndim은 차원의 개수, shape는 각 차원의 실제 크기입니다.

결측치 ≠ 이상치

결측치는 값이 없고, 이상치는 값은 존재합니다.

Series ≠ DataFrame

Series는 1차원, DataFrame은 2차원 표 구조입니다.

loc ≠ iloc

loc는 label, iloc는 위치 번호 기준입니다.

계산 ≠ 해석

계산은 숫자를 만들고, 해석은 그 숫자가 무엇을 의미하는지 설명합니다.

상관관계 ≠ 인과관계

두 값이 함께 움직인다고 해서 한쪽이 다른 쪽의 원인이라고 바로 결론 내릴 수 없습니다.
