Data Analysis · Lesson 15 · Pandas Time Series

Pandas 시계열 데이터

지금까지는 숫자·문자열·범주 Key를 중심으로 데이터를 선택하고 정제하고 결합하고 그룹화했습니다. 이번 단원에서는 날짜와 시간을 단순 문자열이 아니라 데이터의 실제 분석 축으로 사용하는 방법 을 공부합니다. 문자열 날짜를 datetime으로 변환하고, DatetimeIndex를 만들어 시간 순서를 표현하며, shift()로 이전·다음 관측값을 비교하고, resample()로 일·주·월·시간 등 서로 다른 시간 간격으로 데이터를 다시 구성합니다.

Time Series Datetime DatetimeIndex Timestamp to_datetime date_range freq shift Lag Resample Downsampling Upsampling NaT NaN

학습 목표

  • 시계열 데이터가 일반 데이터와 어떤 점에서 다른지 설명할 수 있다.
  • 문자열 날짜와 실제 datetime dtype의 차이를 설명할 수 있다.
  • pd.to_datetime()으로 문자열 날짜를 datetime으로 변환할 수 있다.
  • 날짜 Parsing 실패와 NaT의 의미를 이해한다.
  • errors="coerce"를 이용해 잘못된 날짜를 Missing으로 처리할 수 있다.
  • 날짜 Column을 DatetimeIndex로 바꿀 수 있다.
  • DatetimeIndex의 Label 간격이 반드시 일정할 필요는 없음을 이해한다.
  • 시간 순서 분석 전에 sort_index()가 왜 중요한지 설명할 수 있다.
  • pd.date_range()의 start, end, periods, freq를 이해한다.
  • 일·시간·월 등 Frequency 개념을 설명할 수 있다.
  • shift(1)으로 이전 관측값을 만들 수 있다.
  • shift(-1)으로 다음 관측값을 만들 수 있다.
  • shift(periods)와 shift(freq=...)의 차이를 설명할 수 있다.
  • 현재값과 이전값을 이용해 변화량을 계산할 수 있다.
  • resample()을 시간 기반 GroupBy 관점으로 이해한다.
  • Downsampling과 Upsampling을 정확하게 구분할 수 있다.
  • Downsampling에서 sum·mean 같은 Aggregation이 왜 필요한지 이해한다.
  • Upsampling에서 새로운 Timestamp와 NaN이 왜 만들어지는지 설명할 수 있다.
  • asfreq()와 ffill()의 역할을 이해한다.
  • 모든 작업에서 shape, Index, dtype, frequency, NaT·NaN 변화를 추적할 수 있다.

01 · Core Concept

시간은 단순한 Column이 아니라 분석의 축이 된다

일반 DataFrame에서는 Row를 0, 1, 2 같은 번호로 구분해도 문제가 없습니다. 하지만 시계열에서는 언제 발생한 값인지, 어떤 값이 이전인지, 얼마의 시간 간격을 두고 측정됐는지 가 분석 결과에 직접 영향을 줍니다.

Time Series

시간의 순서와 간격이 데이터의 의미에 포함되는 데이터입니다. 교안에서는 Index가 날짜 또는 시간인 데이터를 시계열 데이터로 설명하고 DatetimeIndex를 시계열 분석의 기본 Index로 소개합니다.

ORDER 시간 순서 과거 → 현재 → 미래
INTERVAL 시간 간격 분 · 시간 · 일 · 월
RAW "2026-08-01"
→

→
INDEX DatetimeIndex
→

→
INTERVAL resample()

04 · Invalid Date & NaT

날짜 Parsing 실패는 NaT로 추적한다

"2026-08-01" "not-a-date" "2026-08-03" ↓ errors="coerce" 2026-08-01 NaT 2026-08-03 
converted = pd.to_datetime(
    source,
    errors="coerce"
)

print(
    converted.isna().sum()
)
NaN 수치 Missing에서 자주 등장
≠
NaT 날짜·시간 Missing
변환 성공 여부보다 변환 실패 건수를 함께 본다

실제 데이터에서는 날짜 형식이 잘못된 Row가 존재할 수 있으므로 datetime 변환 직후 dtype과 Missing 개수를 함께 확인하는 것이 좋습니다.

05 · DatetimeIndex

날짜 Column을 실제 시간축으로 이동한다 

df[
    "date"
] = pd.to_datetime(
    df[
        "date"
    ]
)

ts = df.set_index(
    "date"
)

ts = ts.sort_index()
BEFORE
Index date sales
0 2026-08-01 100
1 2026-08-02 120
→
AFTER
DatetimeIndex sales
2026-08-01 100
2026-08-02 120
shape=(N,2) → set_index("date") → shape=(N,1)
Index가 단순 번호가 아니라 시간 의미를 가진다 2026-08-01 → 100 2026-08-02 → 120

06 · Irregular DatetimeIndex

DatetimeIndex는 반드시 일정 간격일 필요가 없다

09:00 + 5분
09:05 + 32분
09:37 + 3시간 43분
13:20 불규칙
Timestamp의 간격과 DatetimeIndex 여부는 다른 문제

서버 로그·IoT·사용자 이벤트처럼 발생 시간이 불규칙해도 날짜·시간 Label을 가진 시계열 데이터로 사용할 수 있습니다.

11 · periods vs freq

값의 위치 이동과 시간 Index 이동을 구분한다

VALUE SHIFT shift(1) Index 유지
8/1 → NaN 8/2 → 100 8/3 → 120

Lag 분석에 주로 사용합니다.

INDEX SHIFT shift(1, freq="D") Value 유지
8/2 → 100 8/3 → 120 8/4 → 90

Timestamp Label 자체를 이동합니다.

“shift(1) = 무조건 하루 전”이 아니다

기본 shift(1)은 현재 데이터 순서에서 한 period 위치를 이동시키는 사고가 핵심이고, freq="D"를 지정하면 날짜 Index 자체를 하루 이동시키는 의미가 됩니다.

14 · Upsampling

더 촘촘한 시간축을 만들면 새로운 빈 시간이 생긴다

ORIGINAL
8/1 00:00 → 100 8/2 00:00 → 200
↓ 12h
UPSAMPLED
8/1 00:00 → 100 8/1 12:00 → NaN 8/2 00:00 → 200 
upsampled = (
    ts[
        [
            "sales"
        ]
    ]
    .resample(
        "12h"
    )
    .asfreq()
)
새로운 Timestamp ≠ 새로운 실제 관측값

시간 Label은 만들어졌지만 해당 시간에 실제 측정·거래 데이터가 존재하지 않기 때문에 값은 Missing으로 남을 수 있습니다.

시간 간격 큼 → 시간 간격 작음 → Row 증가

15 · Upsampling Missing

새로 생긴 빈 시간은 데이터 의미를 보고 채운다 

filled = (

→
FFILL 00:00 → 100 12:00 → 100 24:00 → 200
가능할 수 있음 상태 데이터

다음 변경 전까지 이전 상태가 유지되는 데이터

주의 필요 발생량 데이터

실제 매출·방문량처럼 없는 시점의 값을 임의 복제하면 의미가 바뀔 수 있음

16 · asfreq() vs resample()

시간축 변경과 시간 구간 집계를 구분한다

AS FREQ asfreq() Frequency 변환

새 Frequency에 맞는 시간축으로 데이터를 재배치하는 관점입니다.

RESAMPLE resample().sum() Time Bucket 분석

시간 구간별로 묶어 합계·평균 등으로 요약하는 데 적합합니다.

빠른 판단
시간축 자체를 새 Frequency로? asfreq
시간 구간별 통계? resample

19 · Python Example

Datetime · Shift · Resample 통합 실습 

import numpy as np
import pandas as pd


def show_state(name, obj):
    print()
    print("=" * 80)
    print(name)
    print("=" * 80)

    print(obj)

    print()
    print("type:", type(obj))

    if hasattr(obj, "shape"):
        print("shape:", obj.shape)

    if isinstance(obj, pd.DataFrame):
        print(
            "index type:",
            type(obj.index)
        )

        print("index:")
        print(obj.index)

        print("dtypes:")
        print(obj.dtypes)

        print("missing:")
        print(obj.isna().sum())

# 1. Raw Data
# ==================================================

20 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

날짜처럼 보이면 datetime이라고 생각한다

먼저 실제 dtype을 확인합니다.

Mistake 02

교안의 DataFrame.to_datetime()을 그대로 사용한다

현재 실습에서는 pd.to_datetime()으로 연결합니다.

Mistake 03

to_datetime()을 하면 자동으로 Index가 된다고 생각한다

Column dtype 변환과 set_index()는 별도 단계입니다.

Mistake 04

Parsing 실패 Row를 확인하지 않는다

필요하면 errors="coerce" 후 NaT 개수를 확인합니다.

Mistake 05

NaN과 NaT를 같은 표시라고 생각한다

수치 Missing과 datetime Missing을 구분합니다.

Mistake 06

DatetimeIndex는 반드시 일정 간격이라고 생각한다

불규칙한 Timestamp도 사용할 수 있습니다.

Mistake 07

시간 정렬 없이 이전값을 계산한다

먼저 Index 순서를 확인하고 필요하면 sort_index()를 사용합니다.

Mistake 08

periods를 날짜 수라고만 외운다

date_range에서 생성할 Timestamp 개수입니다.

Mistake 09

교안의 5H를 현재 코드에 그대로 사용한다

현재 학습에서는 5h로 연결합니다.

Mistake 10

shift(1)을 무조건 하루 전이라고 생각한다

기본적으로 한 period 위치 이동이라는 점을 기억합니다.

Mistake 11

shift(periods)와 shift(freq)를 같은 것으로 생각한다

Value 이동과 Index 이동을 구분합니다.

Mistake 12

shift의 첫 NaN을 오류라고 생각한다

이전값이 존재하지 않기 때문에 생기는 정상적인 Missing입니다.

Mistake 13

resample()만 호출하면 분석이 끝난다고 생각한다

이후 sum·mean·asfreq 등의 작업이 필요합니다.

Mistake 14

교안의 오래된 resample how 문법을 그대로 사용한다

현재는 Resampler 뒤에 집계 메서드를 연결합니다.

Mistake 15

Downsampling과 Upsampling을 반대로 외운다

간격이 커지면 Down, 작아지면 Up입니다.

Mistake 16

Downsampling에서 집계 의미를 정하지 않는다

합계·평균·최대 중 무엇이 맞는지 데이터 의미로 판단합니다.

Mistake 17

Upsampling이 새 실제 관측값을 만든다고 생각한다

새로운 시간 Label을 만들 뿐 실제 값은 존재하지 않을 수 있습니다.

Mistake 18

Upsampling 후 무조건 ffill한다

이전값 유지가 업무적으로 타당한 데이터에서만 사용합니다.

Mistake 19

resample에는 무조건 DatetimeIndex만 필요하다고 생각한다

현재는 datetime-like Column을 on=으로 사용할 수도 있습니다.

Mistake 20

Resampling 후 shape를 확인하지 않는다

Down은 Row 감소, Up은 Row 증가가 핵심 변화입니다.

23 · Interview

면접 포인트

Q1. 시계열 데이터란 무엇인가요?
A. 시간의 순서와 간격이 데이터 의미에 포함되는 데이터입니다. Pandas에서는 DatetimeIndex 등을 시간축으로 사용할 수 있습니다.
Q2. DatetimeIndex란 무엇인가요?
A. Timestamp 형태의 날짜·시간 Label을 사용하는 Pandas Index입니다.
Q3. DatetimeIndex는 일정 간격이어야 하나요?
A. 아닙니다. 불규칙한 시간 간격도 DatetimeIndex가 될 수 있습니다.
Q4. 문자열 날짜를 datetime으로 바꾸려면?
A. pd.to_datetime()을 사용합니다.
Q5. errors="coerce"는 무엇인가요?
A. 변환할 수 없는 날짜 값을 NaT로 처리하도록 지정합니다.
Q6. NaT는 무엇인가요?
A. 날짜·시간 계열의 Missing 값을 나타내는 표현입니다.
Q7. pd.date_range()는 무엇인가요?
A. start·end·periods·freq 등을 이용해 일정한 규칙의 DatetimeIndex를 생성합니다.
Q8. periods는 무엇인가요?
A. 생성할 Timestamp 개수입니다.
Q9. freq는 무엇인가요?
A. Timestamp 사이의 시간 간격을 지정합니다.
Q10. shift(1)은 무엇인가요?
A. 값을 한 period 이동시켜 이전 관측값을 현재 Row에 대응시킬 때 사용할 수 있습니다.
Q11. shift(-1)은?
A. 다음 관측값을 현재 Row에 대응시키는 방향으로 사용할 수 있습니다.
Q12. shift(1)과 shift(1, freq="D") 차이는?
A. 전자는 기본적으로 값 위치를 이동해 Lag를 만들고, 후자는 Datetime Index Label 자체를 이동합니다.
Q13. Resampling이란 무엇인가요?
A. 시계열 데이터를 새로운 시간 Frequency에 맞춰 다시 구성하는 과정입니다.
Q14. Downsampling이란?
A. 더 촘촘한 시간 데이터를 더 큰 시간 구간으로 묶는 과정이며 일반적으로 데이터 Row 수가 감소합니다.
Q15. Upsampling이란?
A. 더 큰 시간 간격을 더 촘촘한 시간축으로 확장하는 과정이며 새로운 Timestamp가 추가될 수 있습니다.
Q16. Upsampling 후 NaN은 왜 생기나요?
A. 새로운 Timestamp는 생겼지만 해당 시점에 실제 관측값이 존재하지 않기 때문입니다.
Q17. ffill은 언제 사용하나요?
A. 이전 유효값이 다음 관측 시점까지 유지된다고 보는 것이 데이터 의미상 타당한 경우 사용할 수 있습니다.
Q18. GroupBy와 Resample 차이는?
A. GroupBy는 일반 범주 Key를, Resample은 시간 Frequency를 기준으로 데이터를 묶는다는 차이가 있습니다.
Q19. Resample에는 반드시 DatetimeIndex가 필요한가요?
A. 초보 학습에서는 DatetimeIndex가 기본이지만, 현재 Pandas에서는 datetime-like Column을 on=으로 지정하는 방법도 사용할 수 있습니다.
Q20. 시계열 처리 후 반드시 확인할 것은?
A. shape, Index type, 시간 정렬, datetime dtype, frequency, NaT와 NaN 상태를 확인해야 합니다.

오늘의 암기 포인트

  • 날짜 문자열 ≠ datetime
  • 문자열 날짜 변환은 pd.to_datetime()이다.
  • 날짜·시간 Missing은 NaT로 볼 수 있다.
  • 잘못된 날짜를 NaT로 처리할 때 errors="coerce"를 사용할 수 있다.
  • 날짜 Column을 시간축으로 사용하려면 set_index()를 사용할 수 있다.
  • DatetimeIndex는 반드시 일정 간격일 필요가 없다.
  • 시계열 Lag 분석 전에는 시간 정렬 상태를 확인한다.
  • pd.date_range()는 일정한 날짜·시간 범위를 만든다.
  • periods는 생성할 Timestamp 개수다.
  • freq는 시간 간격이다.
  • shift(1) = 이전값
  • shift(-1) = 다음값
  • shift(periods)와 shift(freq=...)는 다르다.
  • 기본 shift는 Index를 유지하고 값 위치를 이동한다.
  • freq shift는 시간 Index 자체를 이동한다.
  • resample = 시간 간격 재구성
  • Downsampling은 시간 간격이 커지고 Row가 줄어드는 방향이다.
  • Upsampling은 시간 간격이 작아지고 Row가 늘어나는 방향이다.
  • Downsampling에는 sum·mean 같은 집계 의미가 필요하다.
  • Upsampling은 새 Timestamp와 Missing을 만들 수 있다.
  • 새 Timestamp는 새 실제 관측값이 아니다.
  • ffill은 데이터 의미를 확인하고 사용한다.
  • 시계열에서도 shape·dtype·Missing을 계속 추적한다.

헷갈리기 쉬운 개념

날짜 문자열 ≠ Datetime

화면 표시가 비슷해도 dtype이 다릅니다.

datetime Column ≠ DatetimeIndex

날짜 dtype 변환과 Index 설정은 별도의 작업입니다.

NaN ≠ NaT

둘 다 Missing이지만 날짜·시간 계열에서는 NaT를 만나게 됩니다.

shift(1) ≠ 하루 이동

기본적으로 한 period 위치 이동이라는 점이 중요합니다.

shift(periods) ≠ shift(freq)

Value Lag와 시간 Index 이동을 구분합니다.

Downsampling ≠ Upsampling

시간 간격이 커지는지 작아지는지로 판단합니다.

Upsampling ≠ 실제 값 생성

시간 Label만 새로 만들어질 수 있습니다.

asfreq ≠ Aggregation

Frequency 변경과 시간 구간 집계를 구분합니다.

GroupBy ≠ Resample

범주 Key와 시간 구간이라는 기준이 다릅니다.

ffill ≠ 항상 정답

업무 의미가 이전값 유지와 맞는지 먼저 판단합니다.
