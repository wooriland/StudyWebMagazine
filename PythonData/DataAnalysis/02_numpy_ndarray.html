Data Analysis · Lesson 02 · NumPy ndarray

NumPy ndarray와 배열 구조

NumPy의 핵심 자료구조인 numpy.ndarray는 데이터를 N차원 배열로 표현합니다. 이번 단원에서는 Python 리스트와 NumPy 배열을 비교하고, 배열을 처음 받았을 때 반드시 확인해야 하는 ndim, shape, size, dtype, itemsize, axis를 이용해 배열의 구조와 저장 상태를 읽는 방법을 공부합니다.

NumPy ndarray ndim shape size dtype itemsize axis

학습 목표

  • Python list와 NumPy ndarray의 차이를 설명할 수 있다.
  • np.array()와 numpy.ndarray를 구분할 수 있다.
  • 0차원, 1차원, 2차원, 3차원 배열의 차이를 그림과 코드로 설명할 수 있다.
  • ndim으로 배열의 차원 수를 확인할 수 있다.
  • shape를 보고 각 axis의 크기를 해석할 수 있다.
  • size와 len()의 차이를 이해한다.
  • dtype과 dtype.name으로 배열의 저장 자료형을 확인할 수 있다.
  • itemsize가 원소 하나의 메모리 크기를 나타낸다는 것을 이해한다.
  • axis=0, axis=1, axis=2를 shape와 연결해서 설명할 수 있다.
  • 배열 처리 전후의 shape · dtype · 결측치 상태 를 확인하는 습관을 익힌다.

01 · Core Concept

ndarray는 값과 구조를 함께 다루는 배열 객체다

Python 리스트도 여러 값을 저장할 수 있지만 데이터 분석에서는 대량의 수치 데이터를 일정한 구조와 자료형으로 저장하고 계산 해야 하는 일이 많습니다. NumPy는 이를 위해 numpy.ndarray라는 N차원 배열 객체를 사용합니다.

numpy.ndarray

N-Dimensional Array의 의미로, NumPy가 수치 데이터를 0차원부터 N차원까지 규칙적인 배열 형태로 다루기 위해 사용하는 핵심 자료구조입니다.

np.array()와 ndarray를 먼저 구분하자

배열을 처음 받으면 type, ndim, shape, size, dtype, itemsize를 함께 확인해야 합니다.

04 · Axis

axis를 행·열 암기가 아니라 차원의 번호로 이해하기

2차원 배열에서는 흔히 axis=0을 행 방향, axis=1을 열 방향과 연결해 설명합니다. 하지만 앞으로의 NumPy 연산까지 생각하면 shape의 몇 번째 차원인가 로 이해하는 것이 더 중요합니다.

shape = (2, 3)
↑ axis 0 size = 2 ↑ axis 1 size = 3
axis 1 →
axis 0 ↓
1 2 3
4 5 6

axis를 기준으로 합계를 계산하면?

전체 합계 

arr.sum()
21

모든 원소를 하나로 계산

axis = 0 

arr.sum(axis=0)
[5 7 9]

axis 0이 축약되고 axis 1 구조가 남습니다.

(2, 3) → (3,)

axis = 1 

arr.sum(axis=1)
[6 15]

axis 1이 축약되고 axis 0 구조가 남습니다.

(2, 3) → (2,)
axis 연산을 읽는 좋은 방법

“0은 행, 1은 열”만 외우지 말고 지정한 axis가 계산 과정에서 축약되고, 나머지 axis의 구조가 결과에 남는다 고 이해합니다.

06 · Data State

shape · dtype · 결측치 상태 변화 읽기

데이터 분석에서는 함수를 실행한 뒤 값만 확인하지 않고 shape, dtype, 결측치가 어떻게 변했는가 를 같이 보는 습관이 중요합니다.

dtype만 변경하는 경우

BEFORE np.array([1, 2, 3])
  • shape = (3,)
  • size = 3
  • dtype = integer
→
dtype=np.float64 np.array(..., dtype=np.float64)
→
AFTER [1. 2. 3.]
  • shape = (3,)
  • size = 3
  • dtype = float64
shape (3,) → (3,) 변화 없음
size 3 → 3 변화 없음
dtype integer → float64 변화

np.nan이 들어오는 경우 

missing_arr = np.array([
    10,
    20,
    np.nan
])
10 20 NaN
  • 원소 위치는 세 개 그대로 존재
  • shape = (3,)
  • size = 3
  • 결측 표현이 추가되면서 dtype을 확인할 필요가 있음
이번 단원에서는 NaN을 처리하지 않는다

여기서는 np.nan이라는 특수 값이 배열의 dtype과 연결될 수 있다는 정도만 확인합니다. 실제 결측치 삭제·대체는 뒤의 Pandas 단원에서 자세히 다룹니다.

print("\n=== Array Structure ===")

print("size       :", arr.size)

09 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

np.array와 ndarray를 같은 것으로 생각한다

np.array()는 생성 함수, numpy.ndarray는 객체 타입입니다.

Mistake 02

ndim을 원소 개수라고 생각한다

ndim은 차원 수, size가 전체 원소 수입니다.

Mistake 03

shape=(3,)을 3차원이라고 읽는다

`(3,)`은 크기가 3인 축 하나를 가진 1차원 배열입니다.

Mistake 04

shape=(3,5)를 3차원과 5차원으로 읽는다

shape tuple 원소가 두 개이므로 2차원이고 각 축 크기가 3과 5입니다.

Mistake 05

len()과 size를 같은 것으로 본다 

shape = (3, 5)

len(arr) = 3
arr.size = 15
Mistake 06

size와 itemsize를 혼동한다

size는 원소 개수, itemsize는 한 원소의 byte 크기입니다.

Mistake 07

type과 dtype을 혼동한다 

type(arr)
# numpy.ndarray

arr.dtype
# 배열 원소 저장 타입
Mistake 08

ndarray 안에서 모든 Python 타입이 그대로 유지된다고 생각한다

일반적인 NumPy 배열은 하나의 dtype으로 데이터를 표현합니다.

Mistake 09

axis를 0=세로합, 1=가로합으로만 암기한다

axis는 특정 합계 방식이 아니라 배열의 차원을 구분하는 번호입니다.

Mistake 10

dtype이 바뀌면 shape도 반드시 바뀐다고 생각한다

저장 자료형과 배열 구조는 서로 다른 상태입니다.

Mistake 11

NaN을 넣으면 원소 하나가 사라진다고 생각한다

NaN 역시 배열의 한 위치를 차지하며 shape와 size는 그대로일 수 있습니다.

Mistake 12

배열 값을 전부 출력한 뒤 구조를 판단한다

실무에서는 큰 데이터를 모두 출력하기보다 shape와 dtype을 먼저 확인합니다.

10 · Error Reading

NumPy 오류 메시지 읽는 법

NumPy에서 오류가 발생하면 코드만 계속 수정하지 말고 배열의 타입 → 차원 → shape → dtype → 실제 값 순서로 확인합니다.

1 type ndarray인가?
→
2 ndim 몇 차원인가?
→
3 shape 어떤 구조인가?
→
4 dtype 어떤 자료형인가?
→
5 values 실제 값은?
오류 의미 먼저 확인할 것
ModuleNotFoundError 현재 Python에서 NumPy를 찾지 못함 Conda Environment, Interpreter, Kernel, NumPy 설치 여부
NameError np 등의 이름이 정의되지 않음 import numpy as np 실행 여부
SyntaxError Python 문법 오류 괄호, 대괄호, 쉼표, 따옴표
TypeError 예상하지 않은 객체나 타입 사용 type(), dtype
ValueError 데이터 형태나 값이 요구 조건과 맞지 않음 중첩 리스트 길이, shape, dtype 변환 대상
IndexError 존재하지 않는 배열 위치에 접근 shape, index 범위
axis 관련 오류 존재하지 않는 axis를 지정 ndim과 사용 가능한 axis 번호

NumPy 디버깅 기본 세트 

print("type     :", type(arr))
print("ndim     :", arr.ndim)
print("shape    :", arr.shape)
print("size     :", arr.size)
print("dtype    :", arr.dtype)
print("itemsize :", arr.itemsize)
print(arr)
IndexError 또는 axis 오류를 만났다면?

가장 먼저 arr.ndim과 arr.shape를 출력합니다. 배열이 실제 몇 차원인지 확인하지 않고 index나 axis 번호를 추측해서 사용하면 오류 원인을 찾기 어렵습니다.

면접 포인트

Q1. NumPy란 무엇인가요?
A. NumPy는 N차원 배열인 ndarray를 중심으로 수치 데이터를 효율적으로 저장하고 벡터·행렬 등의 수치 연산을 수행하기 위한 Python 라이브러리입니다.
Q2. ndarray란 무엇인가요?
A. N-Dimensional Array의 의미이며, NumPy에서 데이터를 N차원 배열 형태로 표현하기 위한 핵심 객체입니다.
Q3. Python List와 ndarray의 차이는?
A. Python List는 서로 다른 종류의 Python 객체를 함께 담을 수 있는 범용 자료구조이고, NumPy의 일반적인 수치형 ndarray는 하나의 dtype을 사용해 규칙적인 N차원 배열을 구성하고 효율적인 수치 연산을 지원합니다.
Q4. np.array()와 ndarray의 차이는?
A. np.array()는 ndarray를 생성하는 함수이고, 생성된 배열 객체의 타입이 numpy.ndarray입니다.
Q5. ndim은 무엇인가요?
A. 배열의 차원 수, 즉 배열이 가진 axis의 개수를 의미합니다.
Q6. shape란 무엇인가요?
A. 배열의 각 axis 크기를 tuple로 표현한 값입니다. 예를 들어 shape=(3,5)이면 axis 0의 크기는 3, axis 1의 크기는 5입니다.
Q7. size란 무엇인가요?
A. 배열 전체의 원소 개수입니다. shape=(3,5)라면 전체 원소 수는 15개입니다.
Q8. ndim과 shape의 차이는?
A. ndim은 축의 개수이고, shape는 각 축의 실제 크기입니다.
Q9. len()과 size의 차이는?
A. 다차원 ndarray에서 len(arr)은 첫 번째 axis의 크기를 반환하고, arr.size는 전체 원소 개수를 반환합니다.
Q10. dtype이란 무엇인가요?
A. ndarray 원소를 어떤 자료형으로 저장하는지를 나타내는 정보입니다.
Q11. itemsize란 무엇인가요?
A. 배열 원소 하나를 저장하는 데 필요한 byte 수를 나타냅니다.
Q12. size와 itemsize의 차이는?
A. size는 전체 원소 개수이고, itemsize는 원소 하나의 메모리 크기입니다.
Q13. axis란 무엇인가요?
A. ndarray의 각 차원을 구분하는 번호입니다. shape의 첫 번째 차원이 axis 0, 두 번째 차원이 axis 1입니다.
Q14. axis=0과 axis=1을 어떻게 이해하나요?
A. 2차원 배열에서 axis 0은 shape의 첫 번째 차원, axis 1은 두 번째 차원입니다. 집계 연산에서는 지정한 axis가 축약되고 나머지 축의 구조가 결과로 남는다고 이해하면 좋습니다.
Q15. shape=(3,)은 무슨 뜻인가요?
A. 크기가 3인 하나의 axis를 가진 1차원 배열입니다. `(3,)`은 Python에서 원소 하나를 가진 tuple 표현입니다.
Q16. dtype이 변경되면 shape도 변경되나요?
A. 반드시 그렇지는 않습니다. 같은 원소 구조를 유지하면서 dtype만 정수형에서 float64 등으로 변경될 수 있습니다.
Q17. NumPy 배열 오류를 디버깅할 때 무엇을 확인하나요?
A. 배열의 type, ndim, shape, dtype, 실제 값을 확인하고 적용하려는 연산이 요구하는 구조와 현재 배열 구조가 맞는지 확인합니다.

오늘의 암기 포인트

  • NumPy의 핵심 자료구조는 N차원 배열인 ndarray 이다.
  • np.array()는 배열 생성 함수, numpy.ndarray는 배열 객체의 타입이다.
  • ndim = 배열의 차원 수 = axis의 개수.
  • shape = 각 axis 크기를 가진 tuple.
  • shape=(3,5)라면 axis 0의 크기는 3, axis 1의 크기는 5이다.
  • size = 배열 전체 원소 개수.
  • len(arr)는 다차원 배열에서 첫 번째 axis의 크기를 반환한다.
  • dtype = 배열 원소의 저장 자료형.
  • itemsize = 원소 하나의 byte 크기.
  • size ≠ itemsize
  • axis는 단순히 행·열 이름이 아니라 배열의 각 차원을 구분하는 번호이다.
  • axis 연산에서는 지정한 axis가 축약되고 나머지 axis 구조가 결과에 남는다.
  • 데이터 처리 전후에는 shape · dtype · 결측치 를 확인한다.

헷갈리기 쉬운 개념

np.array() ≠ ndarray

전자는 생성 함수, 후자는 배열 객체 타입입니다.

ndim ≠ size

ndim은 차원 수, size는 전체 원소 수입니다.

shape ≠ size

shape는 구조, size는 전체 원소 개수입니다.

size ≠ itemsize

size는 몇 개인지, itemsize는 한 개가 몇 byte인지 나타냅니다.

type ≠ dtype

type은 배열 객체 자체의 타입, dtype은 배열 원소의 저장 자료형입니다.

len(arr) ≠ arr.size

다차원 배열에서 len은 첫 axis 길이, size는 모든 원소 개수입니다.

shape=(3,) ≠ 3차원

`(3,)`은 크기가 3인 1차원 배열입니다.

axis ≠ 특정 계산 방법

axis는 배열 차원의 번호이며 sum, mean, concatenate 등 여러 함수가 이 축을 기준으로 동작합니다.

dtype 변경 ≠ shape 변경

저장 타입만 달라지고 배열 구조는 그대로일 수 있습니다.

NaN ≠ 원소 삭제

NaN도 배열 안의 한 위치를 차지하는 특수 값입니다.
