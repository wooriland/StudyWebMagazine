Data Analysis · Lesson 10 · Pandas Selection

Pandas 데이터 선택과 loc · iloc

앞 단원에서는 Series와 DataFrame의 index, columns, shape, dtype을 공부했습니다. 이번 단원에서는 그 구조를 실제로 사용합니다. 단일·복수 Column을 선택하고, Row를 Slice하고, Boolean 조건과 isin()으로 필요한 행을 걸러낸 뒤, .loc으로 Label 기준, .iloc으로 Position 기준 데이터를 선택합니다. 마지막에는 선택한 Cell이나 Row를 수정하고 새로운 Row를 추가하는 방법까지 연결합니다.

head tail Column Selection Row Slice Boolean Mask isin loc iloc Label Position Update Copy-on-Write

학습 목표

  • head()와 tail()을 이용해 선택 전에 DataFrame의 실제 데이터를 확인할 수 있다.
  • df["column"]과 df[["column"]]의 결과 타입 차이를 설명할 수 있다.
  • 여러 Column 이름을 List로 전달해 부분 DataFrame을 만들 수 있다.
  • Position 기반 Row Slice와 Label 기반 Row Slice의 차이를 설명할 수 있다.
  • 조건식이 Boolean Series를 만들고, 그 Mask가 Row Filtering에 사용되는 과정을 이해한다.
  • isin()을 이용해 여러 후보 값 중 포함 여부를 검사할 수 있다.
  • 여러 조건을 &, |, ~로 결합할 수 있다.
  • .loc이 Label 기반이라는 것을 설명할 수 있다.
  • .iloc이 정수 Position 기반이라는 것을 설명할 수 있다.
  • loc의 Label Slice와 iloc의 Position Slice에서 stop 처리 방식이 다름을 이해한다.
  • Row와 Column을 동시에 선택할 수 있다.
  • Boolean 조건과 Column 선택을 하나의 .loc에서 함께 사용할 수 있다.
  • 선택된 Cell이나 Row를 loc 또는 iloc으로 수정할 수 있다.
  • 새로운 Index Label을 이용해 Row를 추가할 수 있다.
  • 선택·수정 전후의 shape, axis, dtype, NaN 변화를 추적할 수 있다.

01 · Core Concept

전체 DataFrame에서 필요한 부분만 가져온다

실제 데이터 분석에서는 전체 DataFrame을 그대로 사용하는 것보다 필요한 Column, Row, 조건 데이터만 선택하는 일이 훨씬 많습니다.

10 · loc vs iloc

Label과 Position을 절대 혼동하지 않는다

LOC Label df.loc["student_B"]
A B C D
loc["B":"D"]

B, C, D

Stop Label 포함
≠
ILOC Integer Position df.iloc[1]
0 1 2 3
iloc[1:3]

1, 2

Stop Position 제외
구분 loc iloc
기준 Label Integer Position
Row Index 이름 행 위치
Column Column 이름 열 위치
Slice Start 포함 포함
Slice Stop 포함 제외
대표 오류 KeyError IndexError
숫자 Index에서도 loc는 Label이다

11 · Boolean + loc

조건 Row와 필요한 Column을 한 번에 선택한다

실무에서 매우 자주 사용하는 공식 df.loc[조건, 필요한_컬럼]

14 · iloc Update

iloc은 존재하는 Position의 값을 수정한다 

df.iloc[
    0,
    2
] = 90
POSITION Row = 0 Column = 2
→
EXISTING CELL 88
→
UPDATED 90
iloc은 “새 Position 생성”보다 기존 위치 접근으로 이해

존재하지 않는 Position의 Row를 새로 만드는 것이 아니라 현재 DataFrame의 정수 위치를 선택하고 그 값을 읽거나 수정하는 데 사용합니다.

15 · Data State

Selection 이후 shape · axis · dtype · NaN을 추적한다

작업 결과 타입 shape dtype NaN
df["col"] Series (N,) 해당 Column dtype 기존 NaN 유지
df[["a","b"]] DataFrame (N,2) Column별 dtypes 기존 NaN 유지
loc[label] Series (M,) Row Series dtype 확인 선택 Row의 NaN 유지
loc[[label]] DataFrame (1,M) Column dtypes 유지 유지
Boolean Row Filter DataFrame (True 수,M) Column dtypes 남은 Row의 NaN 유지
Cell Mask DataFrame 기존 shape 유지 NaN 생성으로 변화 가능 새 NaN 생성 가능
새 Row 추가 DataFrame (N+1,M) 입력값에 따라 재확인 누락값 여부 확인
기존 Cell 수정 DataFrame 유지 입력값에 따라 확인 대체에 따라 변동

axis 관점

AXIS 0 Row / Index loc[rows, ...] iloc[rows, ...]
AXIS 1 Column / Columns loc[..., columns] iloc[..., columns]

def show_state(name, obj):
    print()
    print("=" * 70)
    print(name)
    print("=" * 70)

    print(obj)
    print("type :", type(obj))
    print("ndim :", obj.ndim)
    print("shape:", obj.shape)

    if isinstance(obj, pd.DataFrame):
        print("index:", obj.index)
        print("columns:", obj.columns)

        print("dtypes:")
        print(obj.dtypes)

    elif isinstance(obj, pd.Series):
        print("index:", obj.index)
        print("dtype:", obj.dtype)

18 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

단일·복수 Column의 결과 타입을 구분하지 않는다

df["score"]는 Series, df[["score"]]는 DataFrame입니다.

Mistake 02

Row Label을 df["row"]로 선택한다

기본 대괄호 문자열은 Column 선택과 연결됩니다. Row Label은 loc을 사용합니다.

Mistake 03

loc와 iloc을 반대로 기억한다

loc는 Label, iloc은 Integer Position입니다.

Mistake 04

loc의 숫자를 Position이라고 생각한다

loc에서는 숫자도 Index Label일 수 있습니다.

Mistake 05

iloc에 문자열 Label을 전달한다

iloc은 정수 위치 기반입니다.

Mistake 06

loc Slice의 마지막 Label을 제외한다고 생각한다

loc Label Slice는 마지막 Label을 포함합니다.

Mistake 07

iloc Slice의 마지막 Position도 포함한다고 생각한다

Python Slice처럼 stop 위치는 제외됩니다.

Mistake 08

Boolean 조건에서 and / or를 사용한다

Series 조건 결합에는 &, |, ~를 사용합니다.

Mistake 09

여러 Boolean 조건에서 괄호를 생략한다

각각의 비교식을 괄호로 감싸는 습관이 중요합니다.

Mistake 10

Boolean Mask 자체가 필터 결과라고 생각한다

Mask는 True/False Series이고, 다시 DataFrame에 적용해야 Row가 선택됩니다.

Mistake 11

Row Filter와 Cell Mask를 혼동한다

하나는 Row 수가 줄고, 다른 하나는 shape를 유지하며 NaN을 만들 수 있습니다.

Mistake 12

Chained Assignment로 값을 수정한다

현재는 df.loc[mask, "column"] = value 패턴을 사용합니다.

Mistake 13

iloc으로 존재하지 않는 새 Row 위치를 만든다

iloc은 기존 Position 선택·수정 중심으로 사용합니다.

Mistake 14

교안의 DataFrame.append()를 그대로 사용한다

21 · Interview

면접 포인트

Q1. DataFrame에서 한 Column을 선택하면 어떤 타입이 반환되나요?
A. 일반적으로 Series가 반환됩니다. 예를 들어 df["score"]는 하나의 Series입니다.
Q2. 여러 Column을 선택하려면 어떻게 하나요?
A. Column 이름을 List로 전달합니다. 예: df[["name", "score"]]. 결과는 DataFrame입니다.
Q3. df["score"]와 df[["score"]]의 차이는?
A. 전자는 Series, 후자는 1개의 Column을 가진 DataFrame입니다.
Q4. Boolean Indexing이란 무엇인가요?
A. 조건식으로 True/False Mask를 만든 뒤 True에 해당하는 Row를 선택하는 방식입니다.
Q5. isin()은 언제 사용하나요?
A. 하나의 값과 비교하는 것이 아니라 여러 후보 값 중 포함되는지를 검사할 때 사용합니다.
Q6. Pandas에서 여러 조건은 어떻게 결합하나요?
A. AND는 &, OR는 |, NOT은 ~를 사용하며 각 비교식을 괄호로 묶습니다.
Q7. loc는 무엇인가요?
A. Index와 Column의 Label을 기준으로 데이터를 선택하는 indexer입니다.
Q8. iloc는 무엇인가요?
A. 0부터 시작하는 정수 Position을 기준으로 데이터를 선택하는 indexer입니다.
Q9. loc와 iloc의 가장 중요한 차이는?
A. loc = Label, iloc = Integer Position입니다.
Q10. loc의 Slice에서 stop Label은 포함되나요?
A. 네. Label Slice에서는 마지막 Label도 포함됩니다.
Q11. iloc Slice의 stop Position은 포함되나요?
A. 아닙니다. Python과 NumPy Slice처럼 stop은 제외됩니다.
Q12. df.loc["A", "score"]는 무엇을 의미하나요?
A. Row Label A와 Column Label score가 만나는 하나의 Cell을 선택합니다.
Q13. df.iloc[1, 2]는 무엇을 의미하나요?
A. 두 번째 Row 위치와 세 번째 Column 위치가 만나는 Cell을 선택합니다.
Q14. 조건 Row와 특정 Column을 동시에 선택하려면?
A. df.loc[조건, 컬럼] 패턴을 사용할 수 있습니다.
Q15. 현재 Pandas에서 조건에 맞는 값을 수정하는 권장 패턴은?
A. chained assignment보다 df.loc[mask, "column"] = value 형태로 한 번에 선택하고 할당합니다.
Q16. loc로 새로운 Row를 추가할 수 있나요?
A. 존재하지 않는 Index Label에 값을 할당하면 새로운 Row를 추가할 수 있습니다.
Q17. iloc로 새로운 Row를 추가하나요?
A. iloc은 현재 존재하는 정수 Position의 선택·수정 중심으로 이해하는 것이 좋습니다.
Q18. DataFrame.append()는 지금도 사용하나요?
A. 현재 Pandas에서는 제거된 과거 API입니다. 여러 Series/DataFrame을 결합할 때는 pd.concat()으로 연결합니다.
Q19. Row Filter와 Cell Masking 차이는?
A. Row Filter는 조건에 맞는 Row만 남겨 Row 수가 줄 수 있지만, Cell Masking은 표 shape를 유지하면서 조건에 맞지 않는 Cell이 NaN이 될 수 있습니다.
Q20. Selection 이후 무엇을 확인해야 하나요?
A. 결과가 Scalar, Series, DataFrame 중 무엇인지 확인하고, shape, dtype/dtypes, Index, Columns, 결측치 변화를 함께 확인합니다.

오늘의 암기 포인트

  • df["column"] → Series
  • df[["column"]] → DataFrame
  • 여러 Column은 Column 이름 List를 전달한다.
  • Boolean Indexing은 조건식 → Boolean Mask → True Row 선택 순서다.
  • isin()은 여러 후보 값 중 포함 여부를 확인한다.
  • AND는 &.
  • OR는 |.
  • NOT은 ~.
  • 여러 Boolean 조건은 각각 괄호로 묶는다.
  • loc = Label
  • iloc = Integer Location = Position
  • loc의 Label Slice는 마지막 Label까지 포함한다.
  • iloc의 Position Slice는 마지막 Position을 제외한다.
  • df.loc[rows, columns]에서 앞은 Row, 뒤는 Column이다.
  • 단일 Row Label은 Series가 될 수 있다.
  • Row Label을 List로 넘기면 DataFrame 구조를 유지할 수 있다.
  • 조건과 Column을 동시에 선택할 때 df.loc[조건, 컬럼]을 사용한다.
  • 수정 시 chained assignment를 피한다.
  • 새 Label에 loc로 값을 넣으면 새 Row가 될 수 있다.
  • iloc은 기존 정수 Position 선택·수정 중심이다.
  • 교안의 DataFrame.append()는 현재 pd.concat()으로 연결한다.
  • Selection 뒤에는 type · shape · dtype · NaN을 확인한다.

헷갈리기 쉬운 개념

"score" ≠ ["score"]

Series와 DataFrame의 차이를 만듭니다.

Row Label ≠ df["row"]

문자열 하나의 대괄호 선택은 기본적으로 Column 선택과 연결합니다.

loc ≠ iloc

Label과 Position의 차이입니다.

loc 숫자 ≠ Position

Index가 숫자라면 숫자도 Label입니다.

loc Stop ≠ iloc Stop

loc Stop Label은 포함, iloc Stop Position은 제외합니다.

Boolean Mask ≠ 필터 결과

Mask는 True/False Series입니다.

Row Filter ≠ Cell Mask

하나는 Row를 줄이고, 다른 하나는 NaN을 만들면서 shape를 유지할 수 있습니다.

and / or ≠ & / |

Pandas Series 조건은 요소별 Boolean 연산을 사용합니다.

chained assignment ≠ 안전한 수정

한 번의 loc assignment를 기본으로 합니다.

iloc ≠ 새 Position 생성

기존 위치의 선택·수정 중심입니다.
