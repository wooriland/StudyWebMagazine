Data Analysis · Lesson 09 · Pandas Data Structures

Pandas Series와 DataFrame

NumPy에서는 ndarray의 shape, axis, dtype, 위치 index를 중심으로 데이터를 다뤘습니다. Pandas에서는 여기에 index와 columns라는 Label이 추가됩니다. 이번 단원에서는 1차원 자료구조인 Series와 2차원 표 자료구조인 DataFrame을 만들고, index, columns, 값의 NumPy 표현, dtype / dtypes, shape, axis, 결측치와 전치 .T까지 하나의 구조로 이해합니다.

Series DataFrame index columns values to_numpy dtype dtypes shape axis NaN Transpose

학습 목표

  • NumPy ndarray와 Pandas의 가장 중요한 차이를 Label 관점에서 설명할 수 있다.
  • 1차원 Series의 구조를 이해하고 List, Dictionary, NumPy ndarray로 생성할 수 있다.
  • Series의 index, dtype, name, index.name을 설명할 수 있다.
  • 2차원 DataFrame의 index와 columns 구조를 이해한다.
  • List와 Dictionary로 DataFrame을 생성하고 행·열 Label을 지정할 수 있다.
  • Series의 dtype과 DataFrame의 dtypes 차이를 설명할 수 있다.
  • values와 to_numpy()가 Label을 제외한 값의 배열 표현과 연결됨을 이해한다.
  • Series와 DataFrame의 shape, ndim, axis를 NumPy 개념과 연결할 수 있다.
  • DataFrame의 .T 전치 전후 index, columns, shape 변화를 설명할 수 있다.
  • NaN이 있어도 데이터 위치와 shape가 자동으로 사라지지 않는다는 것을 이해한다.
  • 다음 단원의 Label 선택과 위치 선택 loc, iloc 학습을 준비한다.

01 · Core Concept

NumPy의 값에 의미 있는 Label을 붙인다

Pandas를 처음 배울 때 가장 중요한 것은 새로운 문법보다 “위치 중심 배열에서 Label 중심 표 구조로 확장된다” 는 변화입니다.

Pandas Data Model

NumPy의 shape·axis·dtype 개념을 기반으로 각 데이터에 index와 columns라는 Label을 연결하여 실제 데이터의 의미를 구조에 포함시킵니다.

NUMPY

위치 중심

101 25 85000
102 31 92000
arr[0, 1]

“0번째 행의 1번째 열”

→ Label 추가
PANDAS

의미 중심

member_id age purchase
101 25 85000
102 31 92000
"age"

“나이 Column”

NumPy에서 사라지는 개념이 아니라 확장된다
shape axis dtype + index columns

11 · Python Example

Series와 DataFrame 통합 실습 

import numpy as np
import pandas as pd


def show_series(name, series):
    print()
    print("=" * 60)
    print(name)
    print("=" * 60)

    print(series)

    print("type :", type(series))
    print("ndim :", series.ndim)
    print("shape:", series.shape)
    print("index:", series.index)
    print("dtype:", series.dtype)
    print("name :", series.name)
    print("numpy:", series.to_numpy())


def show_dataframe(name, df):
    print()
    print("=" * 60)
    print(name)
    print("=" * 60)

    print(df)

    print("type :", type(df))
    print("ndim :", df.ndim)
    print("shape:", df.shape)
    print("index:", df.index)
    print("columns:", df.columns)

    print("dtypes:")
    print(df.dtypes)

    print("numpy:")
    print(df.to_numpy())

12 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

Series를 Python List와 같다고 생각한다

Series에는 index, dtype, name 같은 Pandas 구조가 추가됩니다.

Mistake 02

Index는 반드시 0, 1, 2라고 생각한다

문자열 등 의미 있는 Label을 지정할 수 있습니다.

Mistake 03

Index와 Position을 같은 것으로 생각한다

Label과 몇 번째 위치인지는 다른 개념입니다.

Mistake 04

Series.values가 Series를 반환한다고 생각한다

값의 배열 표현과 연결되는 속성입니다.

Mistake 05

Series와 DataFrame 모두 dtype 하나라고 생각한다

Series는 dtype, DataFrame은 Column별 dtypes입니다.

Mistake 06

DataFrame의 모든 Column dtype이 같아야 한다고 생각한다

DataFrame은 서로 다른 Column dtype을 가질 수 있습니다.

Mistake 07

to_numpy() 결과에 Index와 Columns도 있다고 생각한다

값만 ndarray로 표현되며 Label은 별도입니다.

Mistake 08

df.dtypes와 df.to_numpy().dtype을 같다고 생각한다

Column별 타입과 전체 ndarray 표현의 dtype은 다릅니다.

Mistake 09

DataFrame은 그냥 NumPy 2D 배열이라고 생각한다

Index, Columns, Label 정렬 의미가 추가됩니다.

Mistake 10

.T가 데이터를 추가·삭제한다고 생각한다

Index와 Columns 방향을 전환합니다.

Mistake 11

Series.T가 2차원으로 바뀐다고 생각한다

Series는 여전히 1차원 Series입니다.

Mistake 12

Mixed dtype DataFrame도 전치 후 dtype이 그대로라고 생각한다

전치 후 Column별 dtype 구조가 달라질 수 있습니다.

Mistake 13

NaN이 있는 행은 shape에서 제외된다고 생각한다

결측치도 하나의 위치를 차지합니다.

Mistake 14

Series.name과 index.name을 혼동한다

Series 전체 이름과 Index axis 이름은 별도입니다.

Mistake 15

Dictionary Key를 DataFrame의 행으로 생각한다

기본적인 Dictionary DataFrame에서는 Key가 Column 이름입니다.

15 · Interview

면접 포인트

Q1. Pandas의 핵심 자료구조는 무엇인가요?
A. 1차원 Series와 2차원 DataFrame입니다.
Q2. Series란 무엇인가요?
A. 값과 Index Label을 연결한 1차원 Pandas 자료구조입니다.
Q3. DataFrame이란 무엇인가요?
A. Index와 Columns Label을 가진 2차원 표 자료구조이며 Column마다 서로 다른 dtype을 가질 수 있습니다.
Q4. NumPy ndarray와 Series의 중요한 차이는?
A. Series에는 각 값에 대응하는 Index Label이 있다는 점입니다.
Q5. Series의 주요 속성은 무엇인가요?
A. index, dtype, name, index.name, shape, ndim 등을 확인할 수 있습니다.
Q6. Series.values와 to_numpy()는 무엇과 관련되나요?
A. Series가 가진 값의 배열 표현과 관련됩니다. NumPy ndarray가 명확하게 필요할 때는 to_numpy()를 사용할 수 있습니다.
Q7. Index와 Columns의 차이는?
A. Index는 Row Label, Columns는 Column Label입니다.
Q8. Series는 dtype인데 DataFrame은 왜 dtypes인가요?
A. Series는 하나의 dtype을 가지지만, DataFrame은 Column마다 다른 dtype을 가질 수 있기 때문입니다.
Q9. DataFrame의 Column dtype은 서로 달라도 되나요?
A. 가능합니다. 문자열, 정수, 실수, Boolean 등의 Column을 하나의 DataFrame에서 함께 관리할 수 있습니다.
Q10. DataFrame을 to_numpy()로 바꾸면 Label도 포함되나요?
A. 아닙니다. Index와 Columns Label은 제외되고 Cell 값의 배열 표현을 얻습니다.
Q11. df.dtypes와 df.to_numpy().dtype은 같은가요?
A. 아닙니다. 전자는 각 Column별 dtype이고, 후자는 하나의 ndarray 결과를 표현하는 dtype입니다.
Q12. DataFrame.T는 무엇인가요?
A. DataFrame의 Index와 Columns 방향을 서로 전환한 전치 결과입니다.
Q13. shape=(2,3) DataFrame을 전치하면?
A. shape는 (3,2)가 됩니다.
Q14. Series.T를 사용하면 2차원이 되나요?
A. 아닙니다. Series는 1차원 구조이므로 Series 자체의 transpose로 이해합니다.
Q15. Mixed dtype DataFrame 전치에서 무엇을 확인해야 하나요?
A. 기존 Column별 dtype 구조가 달라질 수 있으므로 전치 후 dtypes를 다시 확인하는 것이 좋습니다.
Q16. NaN이 있으면 shape에서 빠지나요?
A. 아닙니다. NaN도 하나의 데이터 위치를 차지합니다.
Q17. NumPy에서 Pandas로 넘어가면서 추가되는 핵심 개념은?
A. 값의 의미를 나타내는 Index와 Columns Label입니다.
Q18. 다음에 loc와 iloc을 배우는 이유는?
A. 이번에 배운 Index와 Columns를 이용해 실제 원하는 행과 열을 Label 또는 위치 기준으로 선택하기 위해서입니다.

오늘의 암기 포인트

  • Series = 1차원 + Index
  • DataFrame = 2차원 + Index + Columns
  • Series는 dtype을 확인한다.
  • DataFrame은 Column별 dtypes를 확인한다.
  • Index는 Row Label과 연결된다.
  • Columns는 Column Label과 연결된다.
  • Index를 지정하지 않으면 기본 정수 Label이 생성될 수 있다.
  • Dictionary → Series에서는 Key가 Index가 된다.
  • Dictionary → DataFrame에서는 Key가 Column 이름으로 연결된다.
  • Series.name과 Series.index.name은 다르다.
  • to_numpy()에서는 Index와 Columns Label이 포함되지 않는다.
  • df.dtypes와 df.to_numpy().dtype은 서로 다른 개념이다.
  • Series의 shape는 (N,)이다.
  • DataFrame의 shape는 (rows, columns)이다.
  • DataFrame의 axis 0은 Index, axis 1은 Columns와 연결한다.
  • DataFrame.T는 Index와 Columns를 전환한다.
  • Series.T는 2차원 변환 기능이 아니다.
  • NaN도 하나의 위치를 차지한다.

헷갈리기 쉬운 개념

List ≠ Series

Series에는 Index와 dtype 같은 Pandas 구조가 있습니다.

Position ≠ Index Label

몇 번째인지와 어떤 이름인지는 다릅니다.

Index ≠ Columns

Row Label과 Column Label로 구분합니다.

dtype ≠ dtypes

Series 하나의 dtype과 DataFrame Column별 dtype입니다.

values ≠ Label 포함

값의 배열 표현에는 Index와 Columns가 포함되지 않습니다.

df.dtypes ≠ to_numpy().dtype

Column별 타입과 ndarray 전체 타입을 구분합니다.

DataFrame ≠ ndarray 단순 대체품

Label과 Column별 dtype이라는 별도 데이터 모델이 있습니다.

DataFrame.T ≠ Series.T

2D DataFrame은 행·열이 바뀌지만 1D Series는 별도 2D 구조가 되지 않습니다.

NaN ≠ Row 삭제

결측값은 데이터 위치 안에 존재합니다.
