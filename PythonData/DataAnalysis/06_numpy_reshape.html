Data Analysis · Lesson 06 · NumPy Shape Manipulation

NumPy 배열 형태 변경

ndarray에서는 값의 개수와 값 자체가 같더라도 shape가 달라지면 차원, axis의 의미, Broadcasting 가능 여부, 머신러닝이나 이미지 데이터의 입력 구조가 달라집니다. 이번 단원에서는 전체 원소 수를 유지하면서 배열 구조를 변경하는 reshape(), 원소 수까지 바꿀 수 있는 resize 계열, 다차원 배열을 1차원으로 펼치는 ravel()을 비교하면서 배열의 값과 구조를 분리해서 이해합니다.

reshape resize ravel shape size ndim axis View / Copy

학습 목표

  • 배열의 값과 shape는 서로 다른 개념 임을 설명할 수 있다.
  • reshape()를 이용해 전체 원소 수를 유지하면서 1차원·2차원·3차원 구조를 변경할 수 있다.
  • reshape가 가능한 조건을 arr.size = new_shape의 곱 관계로 판단할 수 있다.
  • -1을 이용해 reshape의 한 차원을 자동 계산할 수 있다.
  • (N,), (1,N), (N,1)의 차이를 설명할 수 있다.
  • reshape()와 resize의 원소 수 처리 차이를 설명할 수 있다.
  • np.resize()와 ndarray.resize()의 동작 차이를 구분할 수 있다.
  • ravel()을 이용해 다차원 배열을 1차원으로 펼칠 수 있다.
  • reshape 전후의 shape, axis, size, dtype, 결측치 상태를 비교할 수 있다.
  • Broadcasting이나 실무 입력 구조에 맞게 적절한 shape를 설계할 수 있다.

01 · Core Concept

배열의 값과 배열의 구조는 서로 다르다

배열 형태 변경의 핵심은 “같은 데이터라도 어떤 shape로 해석하느냐에 따라 배열의 의미가 달라진다” 는 것입니다.

Shape Manipulation

ndarray 안의 값을 어떤 차원과 axis 구조로 해석할 것인지 다시 정의하거나, 필요에 따라 전체 원소 수까지 변경하는 작업입니다.

03 · Shape Compatibility

reshape 가능 여부는 size로 판단한다

arr.size = new_shape 각 차원의 곱

원소가 6개인 배열이라면 새 shape 역시 정확히 6개의 위치를 가져야 합니다.

(6,) 6 가능
(1,6) 1 × 6 = 6 가능
(6,1) 6 × 1 = 6 가능
(2,3) 2 × 3 = 6 가능
(3,2) 3 × 2 = 6 가능
(1,2,3) 1 × 2 × 3 = 6 가능
(2,4) 2 × 4 = 8 불가능
모양보다 먼저 size를 확인한다

(2,4)가 보기 좋은 2차원 구조여도 원본에 원소가 6개뿐이라면 reshape할 수 없습니다.

Supplement · -1 Inference

-1은 NumPy에게 한 차원의 크기를 계산해 달라는 뜻

전체 원소 수는 알지만 한 차원의 크기를 직접 계산하기 번거로운 경우 하나의 차원에 -1을 사용할 수 있습니다.

reshape(2,-1)
2 × ? = 6
? = 3 shape=(2,3)
reshape(-1,1)
? × 1 = 6
? = 6 shape=(6,1)
reshape(1,-1)
1 × ? = 6
? = 6 shape=(1,6)
-1은 실제 음수 크기가 아니다

“이 차원은 전체 size와 나머지 차원을 보고 NumPy가 계산해줘”라는 의미입니다. 자동 추론할 차원은 하나만 둡니다.

04 · Shape Meaning

(N,), (1,N), (N,1)은 서로 다른 배열이다

1D
10 20 30
shape=(3,) ndim=1
2D ROW
10 20 30
shape=(1,3) ndim=2
2D COLUMN
10 20 30
shape=(3,1) ndim=2
(3,) ≠ (1,3) ≠ (3,1)
이 차이는 Broadcasting에서 직접적인 의미를 가진다

원소가 3개라는 사실만 보고 배열을 같다고 생각하지 말고 ndim과 axis 구조까지 함께 확인합니다.

05 · Axis Change

reshape는 axis 구조를 다시 정의한다

BEFORE shape=(6,)
axis 0 →
1 2 3 4 5 6
↓ reshape(2,3)
AFTER shape=(2,3)
axis 1 →
axis 0 ↓
1 2 3
4 5 6
shape를 바꾸면 이후 axis 연산의 의미도 바뀐다

같은 6개 값을 가지고 있어도 (6,)에서는 axis 0 하나뿐이지만 (2,3)에서는 axis 0과 axis 1이 존재합니다.

06 · resize

resize는 원소 수까지 변경할 수 있다

reshape와 달리 resize 계열은 새 shape에 필요한 전체 원소 수가 달라도 사용할 수 있습니다. 하지만 np.resize()와 arr.resize()는 동작이 다르므로 반드시 구분해야 합니다.

FUNCTION

np.resize()

  • 새 ndarray 반환
  • 원본은 그대로
  • size 증가 가능
  • 부족한 값은 원본을 반복
≠
METHOD

arr.resize()

  • 원본 ndarray 변경
  • in-place
  • size 증가 가능
  • 늘어난 공간은 0

같은 원본을 크게 만들어 비교

ORIGINAL
1 2 3 4
size=4
np.resize(arr, (2,3))
1 2 3
4 1 2
부족한 2개 → 1, 2 반복
arr.resize((2,3))
1 2 3
4 0 0
새 공간 → 0, 0
np.resize는 이미지 보간 함수가 아니다

shape를 크게 만든다고 이미지 해상도가 자연스럽게 확대되는 것이 아닙니다. 필요한 원소 수만큼 기존 데이터를 반복하거나 잘라내므로 axis별 의미가 중요한 데이터에서는 주의합니다.

ravel()과 flatten()

ravel()

1차원 결과를 만들며 가능한 경우 불필요한 복사를 피할 수 있습니다.

flatten()

1차원으로 펼친 독립적인 Copy를 반환하는 방식입니다.

Supplement · Memory

reshape와 ravel의 결과가 항상 Copy인 것은 아니다

이번 단원의 가장 중요한 목표는 shape와 size이지만, NumPy에서는 배열의 메모리를 공유하는 View와 독립적인 Copy의 차이도 존재합니다.

reshape 가능한 경우 View

메모리 배치에 따라 Copy가 필요할 수도 있습니다.

ravel 가능한 경우 복사 회피

항상 View라고 단정하지 않습니다.

flatten Copy

독립적인 1차원 복사본을 만드는 방향입니다.

11 · Python Example

reshape · resize · ravel 통합 실습 

import numpy as np


def show_state(name, arr):
    print()
    print("=" * 60)
    print(name)
    print("=" * 60)

    print(arr)
    print("type :", type(arr))
    print("ndim :", arr.ndim)
    print("shape:", arr.shape)
    print("size :", arr.size)
    print("dtype:", arr.dtype)


# ==================================================
# 1. 원본
# ==================================================

base = np.arange(
    1,
    7
)

show_state(
    "Original",
    base
)


# ==================================================
# 2. reshape 2 × 3
# ==================================================

matrix_2x3 = base.reshape(
    2,
    3
)

show_state(
    "reshape(2,3)",
    matrix_2x3
)


# ==================================================
# 3. reshape 3 × 2
# ==================================================

matrix_3x2 = base.reshape(
    3,
    2
)

show_state(
    "reshape(3,2)",
    matrix_3x2
)


# ==================================================
# 4. -1 자동 계산
# ==================================================

auto_shape = base.reshape(
    2,
    -1
)

show_state(
    "reshape(2,-1)",
    auto_shape
)


# ==================================================
# 5. Column 형태
# ==================================================

column = base.reshape(
    -1,
    1
)

show_state(
    "reshape(-1,1)",
    column
)


# ==================================================
# 6. Row 형태의 2D 배열
# ==================================================

row = base.reshape(
    1,
    -1
)

show_state(
    "reshape(1,-1)",
    row
)


# ==================================================
# 7. 3차원
# ==================================================

cube = base.reshape(
    1,
    2,
    3
)

show_state(
    "reshape(1,2,3)",
    cube
)


# ==================================================
# 8. ravel
# ==================================================

flat = matrix_2x3.ravel()

show_state(
    "ravel()",
    flat
)


# ==================================================
# 9. np.resize()
# 새 배열 반환
# 부족하면 기존 값 반복
# ==================================================

resize_function = np.resize(
    base,
    (2, 4)
)

show_state(
    "np.resize(base, (2,4))",
    resize_function
)


# ==================================================
# 10. ndarray.resize()
# 원본을 직접 변경하므로 copy로 실습
# ==================================================

resize_method = base.copy()

resize_method.resize(
    (2, 4)
)

show_state(
    "resize_method.resize((2,4))",
    resize_method
)


# ==================================================
# 11. base 원본 확인
# ==================================================

show_state(
    "Original Again",
    base
)


# ==================================================
# 12. NaN 배열
# ==================================================

missing = np.array([
    10.0,
    np.nan,
    30.0,
    40.0,
    50.0,
    60.0
])

show_state(
    "Missing Original",
    missing
)

missing_matrix = missing.reshape(
    2,
    3
)

show_state(
    "Missing reshape(2,3)",
    missing_matrix
)


# ==================================================
# 13. Broadcasting 준비
# ==================================================

scores = np.array([
    [80, 90, 70],
    [75, 85, 95]
])

bonus = np.array([
    5,
    10
])

bonus_column = bonus.reshape(
    -1,
    1

show_state(
    "Scores",
    scores

show_state(
    "Bonus Original",
    bonus

show_state(
    "Bonus Column",
    bonus_column

show_state(
    "Broadcast Result",
    result

12 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

원하는 아무 shape로 reshape할 수 있다고 생각한다

새 shape의 전체 원소 수가 기존 size와 같아야 합니다.

Mistake 02

shape만 보고 size를 확인하지 않는다

reshape 오류에서는 size 계산이 가장 먼저입니다.

Mistake 03

reshape가 원소 수까지 늘려준다고 생각한다

reshape는 size를 유지합니다.

Mistake 04

reshape가 원본 shape를 자동으로 바꾼다고 생각한다

반환값을 새 변수나 원본 변수에 저장해야 합니다.

Mistake 05

-1을 실제 음수 크기로 생각한다

NumPy가 해당 차원의 크기를 추론하라는 의미입니다.

Mistake 06

여러 차원에 -1을 넣으려고 한다

자동 추론할 차원은 하나만 둡니다.

Mistake 07

(N,), (1,N), (N,1)을 같다고 생각한다

ndim과 axis 구조가 서로 다릅니다.

Mistake 08

np.resize와 arr.resize를 같다고 생각한다

전자는 새 배열, 후자는 원본 변경입니다.

Mistake 09

두 resize가 늘어난 값을 똑같이 채운다고 생각한다

np.resize는 반복, arr.resize는 0을 사용합니다.

Mistake 10

np.resize 결과를 저장하지 않는다

반환값을 받아야 새 배열을 사용할 수 있습니다.

Mistake 11

arr.resize 반환값에 ndarray가 있다고 생각한다

원본을 변경하며 반환값은 None입니다.

Mistake 12

np.resize를 이미지 해상도 변경 기능으로 사용한다

이미지 보간 기능과는 다릅니다.

Mistake 13

ravel이 원본도 1D로 바꾼다고 생각한다

1차원 결과를 반환하고 원본 shape는 유지됩니다.

Mistake 14

ravel은 항상 Copy라고 생각한다

메모리 배치에 따라 복사를 피할 수도 있습니다.

Mistake 15

reshape는 항상 View라고 생각한다

경우에 따라 Copy가 필요할 수 있습니다.

Mistake 16

reshape하면 dtype도 바뀐다고 생각한다

shape 변경과 dtype 변경은 별개의 작업입니다.

Mistake 17

reshape하면 NaN이 사라진다고 생각한다

결측치 정제가 아니라 구조 변경입니다.

Mistake 18

reshape 후 axis 의미를 다시 확인하지 않는다

ndim이 바뀌면 이후 axis 연산의 의미도 달라집니다.

print("size :", arr.size)
print("dtype:", arr.dtype)

15 · Interview

면접 포인트

Q1. reshape()는 무엇인가요?
A. ndarray의 전체 원소 수는 유지하면서 새로운 shape로 배열 구조를 변경하여 결과 배열을 반환하는 기능입니다.
Q2. reshape가 가능한 조건은 무엇인가요?
A. 기존 배열의 size와 새 shape의 각 차원 크기를 곱한 값이 같아야 합니다.
Q3. 원소 6개를 (2,4)로 reshape할 수 있나요?
A. 불가능합니다. 기존 size는 6이고 2 × 4 = 8이므로 필요한 원소 수가 다릅니다.
Q4. reshape의 -1은 무엇인가요?
A. 해당 차원의 크기를 전체 원소 수와 나머지 차원을 이용하여 NumPy가 자동 계산하도록 하는 표현입니다.
Q5. (N,)과 (N,1)은 같은가요?
A. 아닙니다. `(N,)`은 1차원이고 `(N,1)`은 두 개의 axis를 가진 2차원 배열입니다.
Q6. reshape가 원본 shape도 바로 변경하나요?
A. 일반적인 arr.reshape()는 변경된 shape의 결과 배열을 반환하므로 그 반환값을 저장해야 합니다.
Q7. reshape와 resize의 차이는 무엇인가요?
A. reshape는 전체 원소 수를 유지해야 하지만 resize 계열은 원소 수 자체를 늘리거나 줄일 수 있습니다.
Q8. np.resize와 arr.resize는 같은가요?
A. 아닙니다. np.resize()는 새 배열을 반환하고, arr.resize()는 원본 배열 자체를 in-place로 변경합니다.
Q9. 크게 만들 때 두 resize는 어떻게 다른가요?
A. np.resize()는 부족한 부분을 기존 값 반복으로 채우고, arr.resize()는 새 공간을 0으로 채웁니다.
Q10. ravel()은 무엇인가요?
A. 다차원 배열의 원소를 1차원 형태로 펼친 배열을 반환합니다.
Q11. ravel() 후 size는 변하나요?
A. 아닙니다. shape와 ndim은 바뀌지만 전체 원소 수는 유지됩니다.
Q12. ravel과 flatten의 차이는 무엇인가요?
A. 보완 개념으로, ravel은 가능한 경우 불필요한 복사를 피할 수 있지만 flatten은 1차원 Copy를 반환합니다.
Q13. reshape하면 dtype도 바뀌나요?
A. 단순 shape 변경은 dtype 변경 작업이 아니므로 기본적으로 기존 dtype을 유지합니다.
Q14. reshape하면 NaN이 사라지나요?
A. 아닙니다. reshape는 결측치 처리 함수가 아니므로 NaN도 원소로 그대로 유지됩니다.
Q15. reshape와 Broadcasting은 어떻게 연결되나요?
A. Broadcasting이 불가능한 배열을 계산 의도에 맞는 shape로 변경할 때 reshape를 사용할 수 있습니다. 예를 들어 `(2,)`를 `(2,1)`로 변경하면 `(2,3)` 배열과 행별 Broadcasting이 가능합니다.
Q16. reshape 후 가장 먼저 확인해야 할 것은?
A. 결과의 ndim, shape, size, dtype을 확인하고 데이터 분석에서는 NaN 상태도 같이 확인합니다.

오늘의 암기 포인트

  • 값과 shape는 서로 다른 개념이다.
  • reshape는 size를 유지한다.
  • reshape가 가능하려면 arr.size = new_shape의 곱 이어야 한다.
  • -1은 한 차원의 크기를 NumPy가 자동 계산한다는 뜻이다.
  • (N,), (1,N), (N,1)은 서로 다른 shape다.
  • reshape는 shape와 ndim, axis 구조를 변경할 수 있다.
  • 단순 reshape는 dtype을 변경하는 기능이 아니다.
  • resize는 원소 수까지 변경할 수 있다.
  • np.resize()는 새로운 배열을 반환한다.
  • arr.resize()는 원본 배열을 변경한다.
  • np.resize()로 크게 만들면 기존 값을 반복한다.
  • arr.resize()로 크게 만들면 새로운 공간은 0으로 채워진다.
  • ravel()은 다차원 배열을 1차원으로 펼친다.
  • ravel 후에도 전체 size는 유지된다.
  • reshape와 ravel은 원본 shape를 자동으로 바꾸는 것이 아니라 결과 배열을 반환한다.
  • reshape는 결측치를 제거하지 않는다.
  • shape를 바꾸면 이후 axis 계산과 Broadcasting 의미가 달라질 수 있다.

헷갈리기 쉬운 개념

shape 변경 ≠ 값 변경

reshape는 같은 데이터를 다른 구조로 해석하는 작업입니다.

shape ≠ size

shape는 각 axis 크기, size는 전체 원소 개수입니다.

reshape ≠ resize

reshape는 size 유지, resize는 size 변경이 가능합니다.

np.resize ≠ arr.resize

새 배열 반환과 원본 변경이라는 큰 차이가 있습니다.

값 반복 ≠ 0 추가

np.resize와 arr.resize의 확대 규칙이 서로 다릅니다.

-1 ≠ 음수 크기

NumPy가 한 차원을 자동 추론하라는 의미입니다.

(N,) ≠ (N,1)

각각 1차원과 2차원입니다.

ravel ≠ 원본 shape 변경

1차원 결과 배열을 반환합니다.

ravel ≠ flatten

flatten은 독립 Copy를 반환하는 방향으로 구분합니다.

reshape ≠ astype

전자는 shape, 후자는 dtype 변경입니다.

reshape ≠ 결측치 정제

NaN의 개수는 그대로 유지됩니다.
