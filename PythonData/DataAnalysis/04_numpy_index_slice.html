Data Analysis · Lesson 04 · NumPy Indexing & Slicing

NumPy 인덱싱과 슬라이싱

NumPy 배열을 만들었다면 이제 배열 전체가 아니라 필요한 데이터만 선택할 수 있어야 합니다. 이번 단원에서는 위치 하나를 선택하는 Indexing, 연속된 범위를 선택하는 Slicing, 배열의 뒤쪽에서 접근하는 Negative Index, 비교 조건으로 Boolean Mask를 만든 뒤 True 위치만 선택하는 Boolean Indexing을 공부합니다. 선택 전후의 shape, axis, dtype, 결측치 상태도 함께 추적합니다.

Indexing Slicing Negative Index Boolean Indexing Mask shape axis dtype

학습 목표

  • NumPy 배열의 인덱스가 0부터 시작한다는 것을 이해한다.
  • 1차원 배열에서 arr[index]로 값을 읽고 수정할 수 있다.
  • 2차원 배열에서 arr[row, column]으로 특정 원소를 선택할 수 있다.
  • 음수 인덱스를 이용해 배열 끝을 기준으로 위치를 지정할 수 있다.
  • arr[start:stop] 형태의 슬라이싱 규칙을 이해한다.
  • :를 이용해 특정 axis의 전체 범위를 선택할 수 있다.
  • 2차원 배열에서 특정 행, 열, 직사각형 영역을 슬라이싱할 수 있다.
  • 비교 연산으로 Boolean Mask를 만들고, True인 원소만 선택할 수 있다.
  • 여러 조건을 &, |, ~와 연결할 수 있다.
  • 선택 전후의 shape, axis, dtype, 결측치 상태를 비교할 수 있다.
  • 기본 Slice와 Copy의 차이를 이해하고 원본 데이터의 예상하지 못한 변경을 예방한다.

01 · Core Concept

전체 배열에서 필요한 데이터만 선택한다

데이터 분석에서는 배열 전체를 항상 사용하는 것이 아니라 특정 원소, 특정 행과 열, 연속된 범위 또는 특정 조건을 만족하는 값만 골라서 사용하는 일이 많습니다. NumPy는 이를 위해 인덱싱, 슬라이싱, Boolean Indexing을 제공합니다.

NumPy Selection

ndarray의 모든 데이터를 사용하는 대신 위치, 범위 또는 조건을 지정하여 필요한 일부 데이터만 읽거나 수정하는 과정입니다.

02 · Indexing

1차원 배열 ― 위치 하나를 선택한다

NumPy 배열의 인덱스는 Python 리스트와 마찬가지로 0부터 시작합니다.

10 20 30 40 50
0 1 2 3 4
-5 -4 -3 -2 -1

첫 번째 값 

arr[0]
10

세 번째 값 

arr[2]
30

마지막 값 

arr[-1]
50

뒤에서 세 번째 

arr[-3]
30

인덱싱으로 값 수정

BEFORE
10 20 30
shape=(3,)
→
arr[1] = 200
10 200 30
shape=(3,)
값 수정 ≠ shape 수정

20 → 200으로 값은 바뀌지만 배열의 원소 수와 shape는 그대로입니다.

03 · 2D Indexing

2차원 배열 ― arr[row, column]

2차원 배열은 행과 열을 가진 표처럼 생각하면 쉽습니다. 첫 번째 인덱스는 행, 두 번째 인덱스는 열을 선택합니다.

col 0 col 1 col 2
row 0 10 20 30
row 1 40 50 60
row 2 70 80 90
arr[1, 2] = 60
첫 번째 위치 row index = 1 axis 0의 위치
두 번째 위치 column index = 2 axis 1의 위치

2차원 값 수정 

arr[1, 1] = 500
10 20 30
40 500 60
70 80 90
shape=(3,3) dtype=integer

위치의 값만 변경되고 구조는 유지됩니다.

04 · Slicing

연속된 범위를 선택한다

arr[start : stop]
start 포함 stop 제외
10 20 30 40 50
0 1 2 3 4
arr[1:4] → [20 30 40]

시작·끝 생략

처음부터 

arr[:3]
[10 20 30]

끝까지 

arr[3:]
[40 50 60]

전체 

arr[:]
전체 범위

뒤에서 세 번째부터 

arr[-3:]
[40 50 60]
Step 1·2 보완

start : stop : step

교안의 기본 [start:stop]에 이동 간격인 step까지 연결할 수 있습니다. 

arr[::2]
10 30 50

2칸씩 이동 

arr[::-1]
60 50 40 30 20 10

step=-1 → 역순

행 · 열 · 직사각형 영역 선택

2차원 배열에서는 axis 0의 선택과 axis 1의 선택을 쉼표로 구분합니다.

arr[row_selection, column_selection]

한 행 

arr[1, :]

arr[:, 1]

정수 Index와 Slice의 shape 차이

INTEGER INDEX

axis 하나가 줄어듭니다.

≠
SLICE

06 · Boolean Indexing

조건 → Mask → 선택

Boolean Indexing에서는 위치를 직접 지정하지 않습니다. 배열 원소마다 조건을 검사하여 True와 False로 이루어진 Boolean Mask를 만든 뒤, True 위치의 값만 통과시킵니다.

ORIGINAL
60 75 80 95 55
dtype = integer
↓ scores >= 80
MASK
False False True True False
dtype = bool
↓ scores[mask]
RESULT
80 95
shape = (2,)

기본 코드 

scores = np.array([
    60,
    75,
    80,
    95,
    55
])

mask = scores >= 80

result = scores[mask]

print(mask)
print(result)
Mask = 선택 허가표
True 선택 False 제외

조건에 맞는 위치 수정 

scores[scores < 60] = 0
[60 75 80 95 55] → [60 75 80 95 0]

Supplement · Multiple Conditions

여러 조건의 Boolean Mask

실제 데이터 분석에서는 조건 하나보다 여러 조건을 동시에 적용하는 일이 많습니다.

AND &

두 조건이 모두 True

OR |

둘 중 하나라도 True

NOT ~

True / False 반전

70 이상 90 이하 

result = scores[
    (scores >= 70)
    &
    (scores <= 90)
]
scores >= 70 조건 A
AND
scores <= 90 조건 B
→
[75 80] 두 조건 모두 만족
조건별 괄호를 사용한다 
(condition1) & (condition2)

복잡한 조건은 먼저 mask1, mask2로 나누어 출력하면 디버깅하기 쉽습니다.

Supplement · View & Copy

Slice를 수정했는데 왜 원본도 바뀔까?

이 부분은 첨부 교안의 인덱싱 페이지보다 한 단계 더 나아간 보완 내용입니다. NumPy의 기본 Slice는 원본 데이터와 연결된 View가 될 수 있으므로 주의해야 합니다.

ORIGINAL MEMORY
10 20 30 40 50
↑ 공유
part = arr[1:4]
20 30 40 
arr = np.array([
    10,
    20,
    30,
    40,
    50
])

part = arr[1:4]

part[0] = 999

print(arr)
[10 999 30 40 50]

Slice를 통한 변경이 원본에 영향을 줄 수 있습니다.

독립 배열이 필요하면 copy() 

part = arr[1:4].copy()
Basic Slice arr[1:4] View 가능
Explicit Copy arr[1:4].copy() 독립 데이터
Boolean Indexing arr[mask] 선택 결과 배열
하지만 arr[mask] = value는 원본 수정 
arr[arr < 0] = 0

Boolean Indexing 결과를 변수로 받는 것과, Boolean 조건을 원본의 왼쪽에 두고 값을 대입하는 것은 서로 다른 작업입니다.

10 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

첫 번째 값의 index를 1이라고 생각한다

첫 번째 값은 index 0입니다.

Mistake 02

Slice stop까지 포함한다고 생각한다

arr[1:4]는 index 1, 2, 3을 선택합니다.

Mistake 03

arr[1]과 arr[1:2]의 shape를 같다고 생각한다

arr[1]   → (3,)
arr[1:2] → (1,3)
Mistake 04

행과 열 순서를 반대로 사용한다

arr[row, column]
Mistake 05

콜론(:)의 의미를 모른다

해당 axis의 전체 범위를 의미합니다.

Mistake 06

-1을 첫 번째 값이라고 생각한다

-1은 마지막 값입니다.

Mistake 07

Mask를 숫자 배열이라고 생각한다

Mask의 dtype은 Boolean입니다.

Mistake 08

Mask를 만들면 원본도 필터링된다고 생각한다

비교 결과는 별도의 Boolean 배열입니다.

Mistake 09

Boolean Indexing 결과 shape가 원본과 같다고 생각한다

선택 원소가 1차원으로 모일 수 있습니다.

Mistake 10

여러 조건에 괄호를 사용하지 않는다

(cond1) & (cond2)
Mistake 11

Slice를 항상 독립 배열이라고 생각한다

기본 Slice는 원본과 연결된 View가 될 수 있습니다.

Mistake 12

선택과 대입을 혼동한다

selected = arr[mask]

arr[mask] = 0
Mistake 13

NaN을 == np.nan으로 찾으려 한다

보완 학습에서는 np.isnan()으로 Boolean Mask를 만듭니다.

Mistake 14

선택 후 shape를 확인하지 않는다

값이 같아 보여도 차원 구조가 달라질 수 있습니다.

13 · Interview

면접 포인트

Q1. NumPy Indexing이란 무엇인가요?
A. ndarray의 특정 위치를 index로 지정하여 하나의 원소나 특정 행·열의 값을 읽거나 수정하는 방법입니다.
Q2. NumPy 인덱스는 어디부터 시작하나요?
A. 0부터 시작합니다.
Q3. 2차원 배열의 원소는 어떻게 선택하나요?
A. arr[row_index, column_index]처럼 첫 번째 위치에 행, 두 번째 위치에 열 index를 지정합니다.
Q4. 음수 인덱스란 무엇인가요?
A. 배열의 끝을 기준으로 위치를 지정하는 방법으로 -1은 마지막 원소, -2는 뒤에서 두 번째 원소입니다.
Q5. Slicing이란 무엇인가요?
A. 하나의 위치가 아니라 연속된 범위의 여러 원소를 선택하는 방식입니다. 기본 문법은 arr[start:stop]입니다.
Q6. Slice의 stop은 포함되나요?
A. 아닙니다. start는 포함하고 stop은 제외합니다.
Q7. : 는 무엇을 의미하나요?
A. 해당 axis의 전체 범위를 의미합니다. 예를 들어 arr[:,1]은 모든 행의 두 번째 열을 선택합니다.
Q8. arr[1]과 arr[1:2]의 차이는 무엇인가요?
A. 정수 인덱싱인 arr[1]은 해당 axis가 줄어들 수 있지만, Slice인 arr[1:2]는 해당 axis를 유지할 수 있어 결과 shape가 서로 다를 수 있습니다.
Q9. Boolean Indexing이란 무엇인가요?
A. 각 원소에 조건을 적용해 True와 False의 Boolean Mask를 만들고, True인 위치의 원소만 선택하는 방식입니다.
Q10. Mask란 무엇인가요?
A. 배열의 각 위치를 선택할 것인지 True 또는 False로 표현한 Boolean 배열입니다.
Q11. Mask의 dtype은 무엇인가요?
A. Boolean이므로 bool 계열입니다.
Q12. 여러 조건을 어떻게 결합하나요?
A. 각 조건을 괄호로 묶고 &를 AND, |를 OR처럼 사용합니다. 
(arr >= 30) & (arr <= 70)
Q13. Boolean Mask로 원본 값을 수정할 수 있나요?
A. 가능합니다. 
arr[arr < 0] = 0
처럼 조건에 맞는 위치에 값을 직접 대입할 수 있습니다.
Q14. arr[:,1]과 arr[:,1:2]의 차이는?
A. 전자는 정수 인덱싱으로 일반적으로 (N,), 후자는 Slice를 이용하므로 (N,1) 형태로 axis를 유지할 수 있습니다.
Q15. NaN 위치를 어떻게 선택할 수 있나요?
A. 보완 학습에서는 np.isnan()으로 Boolean Mask를 만든 뒤 Boolean Indexing과 연결합니다.
Q16. NumPy Slice의 View란 무엇인가요?
A. 기본 Slice 결과가 원본 데이터와 메모리를 공유할 수 있는 상태입니다. 따라서 Slice를 변경하면 원본에 영향을 줄 수 있습니다.
Q17. 원본과 독립적인 배열이 필요하면 어떻게 하나요?
A. 
result = arr[1:4].copy()
처럼 명시적으로 복사합니다.
Q18. 인덱싱 후 가장 먼저 확인할 것은 무엇인가요?
A. 선택된 값뿐 아니라 결과의 type, ndim, shape, dtype을 확인해 의도한 데이터 구조인지 검증하는 것이 좋습니다.

오늘의 암기 포인트

  • NumPy 인덱스는 0부터 시작한다.
  • 하나의 위치는 Indexing.
  • 연속된 범위는 Slicing.
  • 2차원 원소는 arr[row, column].
  • -1은 마지막 원소.
  • Slice는 start 포함, stop 제외.
  • :는 해당 axis의 전체 범위.
  • arr[:,1]은 모든 행의 두 번째 열.
  • arr[1]과 arr[1:2]은 shape가 다를 수 있다.
  • Boolean Indexing은 조건 → Mask → 선택 순서다.
  • Mask의 dtype은 bool.
  • True는 선택, False는 제외.
  • 여러 조건은 (조건1) & (조건2)처럼 조건별 괄호를 사용한다.
  • arr[mask] = 값은 원본을 변경한다.
  • 선택 후에는 shape · dtype · NaN 상태 를 확인한다.

헷갈리기 쉬운 개념

index 0 ≠ 첫 번째 이전 값

index 0이 첫 번째 원소입니다.

stop ≠ 포함

Slice의 stop 위치는 결과에 포함되지 않습니다.

arr[1] ≠ arr[1:2]

정수 Indexing은 axis를 줄일 수 있지만 Slice는 axis를 유지할 수 있습니다.

row ≠ column

arr[row, column] 순서입니다.

: ≠ 빈 값

해당 axis의 전체 범위를 뜻합니다.

Mask ≠ 원본 데이터

Mask는 True / False로 구성된 Boolean 배열입니다.

Mask 생성 ≠ 원본 수정

비교 연산만으로 원본 값은 변경되지 않습니다.

arr[mask] ≠ arr[mask] = value

전자는 선택, 후자는 원본 위치 수정입니다.

Slice View ≠ 독립 Copy

독립 데이터가 필요하면 .copy()를 사용합니다.

NaN ≠ == np.nan

보완 학습에서는 np.isnan()을 사용합니다.
