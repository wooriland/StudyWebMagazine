Data Analysis · Lesson 11 · Pandas Missing Data & Reindex

Pandas 결측치와 재색인

실제 데이터에는 값이 비어 있거나, 수집되지 않았거나, 새로운 Index를 만들면서 기존 데이터와 대응하지 않는 위치가 생길 수 있습니다. 이번 단원에서는 Missing을 발견하고 → 규모를 확인하고 → 삭제·대체·유지 정책을 결정하고 → Index·Columns 구조를 다시 정리하는 과정 을 공부합니다. isna(), dropna(), fillna(), ffill(), bfill(), reindex(), drop()을 shape·axis·dtype·NaN 변화와 함께 추적합니다.

NaN Missing Value isna isnull notna dropna fillna ffill bfill reindex drop axis

학습 목표

  • Missing Value가 무엇인지 설명하고 Outlier와 구분할 수 있다.
  • NaN이 존재해도 해당 데이터 위치와 shape가 자동으로 사라지지 않는다는 것을 이해한다.
  • isna()와 isnull()을 이용해 결측 위치를 Boolean Mask로 확인할 수 있다.
  • isna().sum()으로 Column별 결측 개수를 계산할 수 있다.
  • isna().mean()을 이용한 결측 비율 확인 방법을 이해한다.
  • dropna()의 axis, how, subset, thresh를 구분할 수 있다.
  • 결측 데이터를 무조건 삭제하지 않고 데이터 의미에 따라 제거·대체·유지 전략을 결정할 수 있다.
  • fillna()로 고정값 또는 Column별 값을 사용해 결측치를 채울 수 있다.
  • ffill()과 bfill()의 방향 차이를 이해한다.
  • reindex()가 단순 Rename이 아니라 새로운 Axis 구조를 정의하는 작업임을 이해한다.
  • 새로운 Label이 생기면서 NaN이 만들어질 수 있음을 설명할 수 있다.
  • reindex(fill_value=...)와 fillna()의 처리 대상 차이를 설명할 수 있다.
  • dropna()와 drop()의 삭제 기준 차이를 구분할 수 있다.
  • 행·열 정리 전후의 shape, axis, dtype, Missing 개수를 비교할 수 있다.
  • 다음 단원의 함수 적용과 통계 분석을 위한 정제된 DataFrame을 준비할 수 있다.

01 · Core Concept

데이터 정제는 Missing을 찾는 것부터 시작한다

02 · Missing vs Outlier

값이 없는 것과 값이 이상한 것은 다르다

MISSING VALUE

값 자체를 알 수 없음

score = NaN age = NaN
  • 입력되지 않음
  • 관측되지 않음
  • 수집되지 않음
  • NULL일 수 있음
≠
OUTLIER

값은 있지만 비정상적일 수 있음

age = 999 score = -100
  • 실제 값은 존재
  • 범위가 비정상적일 수 있음
  • 도메인 규칙 검증 필요
  • NaN과 별도 문제
이번 단원은 Missing Value를 다룬다

이상치는 값이 존재하므로 Boolean 조건, 통계 분포, 도메인 기준 등 별도의 방법으로 찾아야 합니다.

any · all · subset · thresh를 구분한다

10 · ffill / bfill

데이터 순서에 의미가 있을 때 주변 값을 전달한다

FFILL

이전 정상값을 앞으로

10 NaN NaN 40
↓
10 10 10 40 
df.ffill()
BFILL

다음 정상값으로 앞쪽을

10 NaN NaN 40
↑
10 40 40 40 
df.bfill()
순서 의미가 없는 데이터에는 함부로 사용하지 않는다

이전 Row의 값이 다음 Row의 결측값을 대신할 수 있는지, 또는 다음 Row의 값이 이전 시점의 결측을 설명할 수 있는지 데이터 의미를 먼저 확인합니다.

현재 Pandas 학습 보완
고정값 fillna(value)
이전값 ffill()
다음값 bfill()

11 · Decision

dropna와 fillna 중 무엇을 사용할 것인가?

Missing 발견 이 데이터가 분석에 필요한가?
NO 삭제 가능 dropna()
YES 의미 있는 대체값이 있는가? fillna() ffill() bfill()
UNCERTAIN 결측 상태 유지 keep NaN

12 · reindex()

새로운 Index 구조에 맞춰 데이터를 다시 배열한다 

result = scores.reindex(
    [
        "A",
        "B",
        "C",
        "D"
    ]
)
ORIGINAL
A 80
C 95
Index = A, C
reindex() →
NEW STRUCTURE
A 80
B NaN
C 95
D NaN
Index = A, B, C, D

reindex는 세 가지 일을 할 수 있다

REORDER A B C ↓ C A B 순서 변경
ADD A C ↓ A B C D Label 추가
REMOVE A B C D ↓ A C 일부 Label 제외
reindex ≠ rename

reindex()는 단순히 Label의 글자를 바꾸는 것이 아니라 결과가 가져야 할 새로운 Axis 구조를 정의합니다.

13 · Column Reindex

Columns도 새로운 구조로 재배열할 수 있다 

result = df.reindex(
    columns=[
        "name",
        "score",
        "grade"
    ]
)
BEFORE
name age score city
→
AFTER
name score grade
grade는 원본에 없었다 grade → NaN

14 · reindex(fill_value)

새 Label의 빈 위치와 기존 NaN을 구분한다

ORIGINAL
A 80
C NaN
↓ 
reindex(
    ["A", "B", "C"],
    fill_value=0
)
↓
RESULT
A 80
B 0
C NaN
B reindex가 새로 만든 위치 fill_value=0 적용
C 원본부터 존재한 NaN 그대로 NaN
reindex(fill_value) ≠ fillna()

기존 데이터의 결측치를 채우고 싶다면 fillna()를 별도로 사용합니다.

import numpy as np
import pandas as pd


def show_state(name, df):
    print()
    print("=" * 70)
    print(name)
    print("=" * 70)

    print(df)

    print()
    print("shape:", df.shape)

    print()
    print("index:")
    print(df.index)

    print()
    print("columns:")
    print(df.columns)

    print()
    print("dtypes:")
    print(df.dtypes)

    print()
    print("missing:")
    print(df.isna().sum())

    filled.isna().sum().sum()
)

    "Original Shape:",
    df.shape

    dropped.shape

19 · Common Mistakes

초보자가 자주 하는 실수

Mistake 01

Missing과 Outlier를 같은 것으로 생각한다

Missing은 값이 없고, Outlier는 값은 존재하지만 비정상적일 수 있습니다.

Mistake 02

NaN을 == np.nan으로 찾는다

Missing 검사는 isna()를 사용합니다.

Mistake 03

isna()가 데이터를 삭제한다고 생각한다

isna()는 같은 구조의 Boolean Mask를 만듭니다.

Mistake 04

isna와 isnull이 서로 다른 Missing 종류를 찾는다고 생각한다

같은 목적의 이름으로 이해합니다.

Mistake 05

빈 문자열도 자동으로 NaN이라고 생각한다

Empty String과 Missing Marker를 구분해야 합니다.

Mistake 06

Missing을 확인하자마자 dropna()를 실행한다

먼저 개수·비율·데이터 의미를 확인합니다.

Mistake 07

axis=0과 axis=1을 반대로 이해한다

axis 0은 Row, axis 1은 Column입니다.

Mistake 08

how="any"와 how="all"을 반대로 기억한다

any는 하나라도, all은 전부 Missing입니다.

Mistake 09

subset이 결과 Column을 선택한다고 생각한다

Missing 판정에 사용할 Column을 정합니다.

Mistake 10

thresh를 허용 가능한 NaN 개수라고 생각한다

유지에 필요한 non-NA 최소 개수입니다.

Mistake 11

모든 NaN을 무조건 0으로 채운다

0이라는 값이 실제 의미와 맞는지 판단해야 합니다.

Mistake 12

ffill을 모든 데이터에 사용한다

Row 순서가 의미 있을 때만 사용합니다.

Mistake 13

ffill과 bfill 방향을 반대로 기억한다

ffill은 이전값, bfill은 다음값을 사용합니다.

Mistake 14

reindex를 Rename이라고 생각한다

새로운 Index·Columns 구조를 정의하는 작업입니다.

Mistake 15

새 Label에 값도 자동 생성된다고 생각한다

대응 데이터가 없다면 Missing이 생성될 수 있습니다.

Mistake 16

reindex(fill_value)가 기존 NaN도 채운다고 생각한다

기존 Missing은 fillna()로 처리합니다.

Mistake 17

drop과 dropna를 같은 기능으로 생각한다

dropna는 Missing, drop은 Label이 삭제 기준입니다.

Mistake 18

drop(axis=1)이 Row 삭제라고 생각한다

axis=1은 Column 방향입니다.

Mistake 19

inplace=True 반환값을 다시 DataFrame 변수에 저장한다

초보 실습에서는 새 결과 변수를 사용하는 편이 명확합니다.

Mistake 20

처리 후 검증하지 않는다

shape, dtypes, Missing 개수를 다시 확인합니다.

22 · Interview

면접 포인트

Q1. Missing Value란 무엇인가요?
A. 데이터 위치는 존재하지만 실제 관측값을 알 수 없거나 제공받지 못한 상태입니다.
Q2. Missing Value와 Outlier의 차이는?
A. Missing은 값 자체가 없는 상태이고, Outlier는 값은 존재하지만 정상 범위에서 크게 벗어난 관측값입니다.
Q3. isna()는 무엇을 반환하나요?
A. Missing이면 True, 정상값이면 False인 동일 구조의 Boolean 객체를 반환합니다.
Q4. isnull()과 isna()의 차이는?
A. Pandas에서는 같은 Missing 검사 목적의 이름으로 이해할 수 있습니다.
Q5. NaN을 == np.nan으로 찾지 않는 이유는?
A. NaN은 일반적인 값과 같은 방식의 동등 비교를 사용하지 않으므로 isna()를 사용합니다.
Q6. Column별 Missing 개수를 구하는 방법은?
A. df.isna().sum()을 대표 패턴으로 사용할 수 있습니다.
Q7. dropna()의 기본 목적은?
A. Missing을 포함한 Row 또는 Column을 조건에 따라 제거하는 것입니다.
Q8. axis=0과 axis=1의 차이는?
A. axis 0은 Row/Index, axis 1은 Column/Columns 방향입니다.
Q9. how="any"와 how="all" 차이는?
A. any는 하나라도 Missing이면 제거하고, all은 모든 값이 Missing일 때 제거합니다.
Q10. subset은 무엇인가요?
A. dropna에서 Missing 여부를 판단할 특정 Column들을 지정하는 옵션입니다.
Q11. thresh는 무엇인가요?
A. 해당 축 항목을 유지하기 위해 필요한 최소 non-NA 값 개수입니다.
Q12. fillna()와 dropna() 차이는?
A. dropna는 구조 자체를 제거하고, fillna는 shape를 유지하면서 Missing을 다른 값으로 대체합니다.
Q13. ffill()은 무엇인가요?
A. 이전 정상값을 뒤쪽 Missing으로 전달하는 방식입니다.
Q14. bfill()은 무엇인가요?
A. 다음 정상값을 이용해 앞쪽 Missing을 채우는 방식입니다.
Q15. reindex()란 무엇인가요?
A. Pandas 객체를 새로운 Index 또는 Columns Label 구조에 맞춰 다시 구성하는 기능입니다.
Q16. reindex에서 새 Label의 값은 어떻게 되나요?
A. 대응하는 기존 데이터가 없다면 기본적으로 Missing이 생길 수 있습니다.
Q17. reindex(fill_value=0)과 fillna(0)의 차이는?
A. fill_value는 재색인으로 새롭게 생긴 위치, fillna는 기존 데이터 내부의 Missing을 처리하는 데 사용합니다.
Q18. drop()과 dropna() 차이는?
A. dropna는 Missing 상태가 삭제 기준이고, drop은 사용자가 지정한 Label이 삭제 기준입니다.
Q19. Row를 직접 삭제하려면?
A. df.drop(index=[...])처럼 Index Label을 지정할 수 있습니다.
Q20. Column을 직접 삭제하려면?
A. df.drop(columns=[...])처럼 Column Label을 지정할 수 있습니다.
Q21. Pandas는 모든 연산에서 NaN을 무조건 무시하나요?
A. 아닙니다. 많은 통계·집계 메서드는 Missing을 제외하는 기본 동작을 가질 수 있지만, 일반 산술에서는 Missing이 결과로 전파될 수 있습니다.
Q22. 결측치 처리 후 무엇을 검증해야 하나요?
A. shape, dtype/dtypes, Missing 개수, Index, Columns를 처리 전 상태와 비교해야 합니다.

오늘의 암기 포인트

  • Missing Value ≠ Outlier
  • NaN도 하나의 데이터 위치를 차지한다.
  • isna() → Missing이면 True
  • isnull() ≈ isna()
  • notna()는 정상값을 True로 확인한다.
  • NaN은 == np.nan이 아니라 isna()로 검사한다.
  • df.isna().sum()은 Column별 Missing 개수 확인의 대표 패턴이다.
  • Missing 처리 전에 개수와 비율을 먼저 확인한다.
  • dropna = 삭제
  • fillna = 대체
  • axis 0은 Row, axis 1은 Column이다.
  • how="any"는 하나라도 Missing.
  • how="all"은 전부 Missing.
  • subset은 Missing 판정에 사용할 Column을 지정한다.
  • thresh는 필요한 정상값의 최소 개수다.
  • 모든 Missing을 무조건 0으로 채우지 않는다.
  • ffill = 이전 정상값
  • bfill = 다음 정상값
  • reindex는 Rename이 아니라 새로운 Axis 구조를 정의한다.
  • 새 Label에는 Missing이 생길 수 있다.
  • reindex(fill_value) ≠ fillna()
  • dropna는 Missing 기준, drop은 Label 기준 삭제다.
  • 처리의 마지막은 항상 Validation이다.
